# bilibili toy 本地包

在零号仓库根执行：

```powershell
node tools/toy-build/build.cjs
node tools/toy-build/smoke.cjs
```

输出 `dist/toy/index.html` 与 `dist/whale-toy.zip`。解压后双击 `index.html`，无需安装程序或启动服务器。构建使用根工作区已有的 Vite，不需要 Electron 运行时。ZIP 根目录就是 HTML 入口。

这是独立参赛目标：复用正式网页入口、启动流程、游戏源码、全部音频与两套字体；标准压缩，不运行线上混淆插件。只有参赛配置会放行本地和平台托管，并关闭线上版本轮询。Worker 通过 Vite 内嵌为 Blob，字体内嵌为 data URL，入口输出普通脚本，其他素材保留相对路径。版权声明沿用现有发布插件，参赛包另附 KLineChart 及其上游项目的许可和声明。

构建同时检查解压后的总字节数和 ZIP 字节数，任一达到 50,000,000 字节即失败。报告写在 `dist/toy-size.json`，不放入参赛 ZIP。不会删除玩法、音乐、素材或更改正式存档版本。此处 50 MB 按十进制保守处理，尚未核实平台其他提交要求。

冒烟工具使用独立临时浏览器配置与合成数据，以普通 Chrome 的 `file://` 协议检查启动、图片、字体、音频、两个 Worker、存盘重载和导出导入。不添加关闭浏览器安全策略的参数，不读取个人存档。产物及测试截图均不入库。

参赛版在两套布局顶栏的“设置”右侧提供画面方向按钮，点击依次切换自动、横屏、竖屏。自动档仅在实际可见窗口高度达到宽度的1.5倍（含边界）时旋转；横屏档在高度大于宽度时旋转，已横向窗口不重复旋转；竖屏档关闭旋转。以`visualViewport`为主、`innerWidth/innerHeight`回退，不依赖宿主方向/触控/UA，不锁定系统屏幕方向。偏好保存在`whale-idle:toy-orientation`，不进存档，存储失败仍可切换本次画面。普通网页及桌面版不显示按钮。

`node node_modules/vitest/vitest.mjs run tools/toy-build/orientation.test.ts`验证1.5阈值/三档循环/损坏偏好/存储失败。浏览器冒烟覆盖两布局的1.5倍前后、手动覆盖、刷新保持、按钮固定尺寸与设置右侧位置，以及窗口宽高与系统方向不一致的情况。

本地存档依赖浏览器对文件页的存储支持，移动文件或更换浏览器前应在游戏内导出存档。云端、聊天和交易所仍需网络及服务端对平台来源的支持，本地启动通过不代表平台联调完成。
