# 玩家空间站独立经营预览

当前包含六项科研计划、首次9→16格扩站、两项保障升级、三座科研解锁建筑、有限批量制造、额外基础培训席位、近域返航信号和基础维修。实现范围/数值见`docs/design/player-station-preset-completion-20261120.md`，本预览不是正式游戏。

第二阶段续作加入舰员团队、长期模拟训练、学习机会/技能点/永久特性/事后二择、有限外派/真实来源清剿/专用守备与八项目标确认。范围及尚未实现内容见`docs/design/second-stage-crew-security-20261121.md`，不等于全部第二阶段内容或正式接入完成。

本工具以 `packages/core/src/playerStation/index.ts`为独立模块入口，不启动主游戏循环、正式库存或正式游戏存档。展示组件为 `PlayerStationPanel`、人口/课程/精炼/采矿/科研面板，通过视图、回调及`text`注入；开发文案仅在本目录 `text.ts`。合成宿主在模块外调用既有主控采矿/精炼函数取数，不复制公式，也不代表正式资源已接入。

## 输入与边界

- 仅手动推进 1、15、60 分钟，没有实时时钟、主游戏离线补算或正式游戏资源；C1可推进实际配方的人类精炼，B1仍为已确认本地阶段的合成副船，不冒充正式船舶航行。
- 工程学 0–5；变更当刻调用模块协调入口，已开工项目保持原投入账。
- 建造轮盘为固定八方位单圈，未使用位置留空；发电固定上方、生命维持右上、服务中心右方，缺料/缺电不改位置。中央只有地块编号与关闭，不建设施。鼠标详情沿用统一Tooltip并放到轮盘外侧；键盘详情在宽窗右侧、窄窗下方，触屏仍先选详情再明确建造。小屏详情区可独立滚动，轮盘与建造按钮保留可达。
- 空地块可同时开工，每格限一项；各项目独立暂停/恢复/取消。普通工程每项占4点施工电力，先保障运行设施，再按开工顺序分配；缺电保进度，暂停不占电。仅首项发电工程享受启动豁免，未完工电源不提供电力。
- 初始预览库存按模块原始料单生成，允许逐项改数或恢复。新增精炼原料/产物初始为0，不自动发矿；名称优先沿预览映射、其余读实际物品目录，价格和体积只读 `packages/data/src/static/items.json`，没有第二套料单或折扣公式。
- 本次到货单可填主体缺口、清空或逐项编辑。点击面板的“模拟到货”才扣预览库存：过滤零项，整单不足不扣，拒收原物回到预览库存；异常同时回滚库存与模块状态。
- 回收调用 `takePlayerStationRecovery` 后只给预览库存；设施取消若通过 `host.give` 返还，预览只接收单次返还，不再重复回收。
- 独立快照外层格式为 `whale-player-station-preview-session` v7，整体保存设施、人口、副船锁定、课程/资格、精炼、采矿/返航/船货/随机状态、科研与测试输入，限2MiB；内层设施仍为v3。旧v1至v5只补空采矿账、空舱开发矿船，旧v1至v6只补空科研账，其他迁移边界保持，不补原矿/产物/人口/资格/技术。人员多岗、任务与副船锁定不一致、重复船货、未知采集点或伪造航程、缺新账或旧版本夹带新账时整份拒读。导入只在点击后整体替换，无效保持当前状态，拒绝正式游戏存档与裸模块快照，不写浏览器存储。
- 人口测试输入默认未发现来源；勾选“模拟发现古代休眠站”只打开6单位来源，不添加居民。合成副船默认600m³有效余舱，可在空闲时调整，任务期间锁定。此输入不来自船表、不赠正式舰船，也不验证正式战斗/采矿/物流占用。
- 生命维持与中心正常运行后可安排有限目标，首趟1人，之后按实际剩余目标/余舱/来源/名额续趟。首人18分钟，仅接收完成后成为居民；来源保护仍占原名额，不能派工。每单位复苏材料、预览可用量及来源待用余料直接显示在面板。
- 工程/研究课程各30分钟、共用1席，不收费、不减料、不受工程学缩时；队列最多覆盖六个来源身份，未到站时可预排，实际开课才占普通待命居民。暂停/缺保障保留席位、人员和进度，恢复后继续；移除队列只作用于未开始项。完成后原居民保留单工种资格，不新增人口、不自动派工或跨工种转训。人口表同步显示受训占用与工程师/研究员待命。
- 五种实际建筑均在同一轮盘：原三种位置不变，基础精炼在右下、初级研究室在下方。新两项各需1名工程师，开工按可用身份顺序绑定，暂停/缺电仍占用；两名工程师可跨格并行，同一人不能承担两项。完工或取消释放占用，不自动改派。完工待机各1点，C1精炼作业总负荷6点、C3科研总负荷4点已接；未派工时不自动生产或研究。
- 精炼面板明确选择设备、居民与原料；普通居民不需课程，工程师/研究员同样可派但不能多岗。缺料/缺电/手动暂停保留人员与进度，条件恢复续作；主动停止释放人员且清未完成批次进度，完成产物不丢、不重复领。原料每批到点扣，整批不足不扣尾批，产物直接回同份预览库存。
- 精炼测试技能0至5是合成主控的统一技能等级，不是正式玩家技能编辑器；批量/周期调用现有`startRefineRun(..., 'pilot', ...)`锁在派工时，产物调用现有`refineBatchOutputOf`按当前测试等级读取，无额外人类倍率或debug一秒化。虚空科技等未提供的条件保持合成状态默认，不能代替正式真实配置验收。复用入口使开发构建JS约1.61MB，Vite有体积提示，未为压提示改全局打包配置。
- 采矿面板明确选择合成矿船、普通居民与本站磷光霾场，无采矿课程或新建筑。开发矿船采用真实磷虾基础船型/双MK1采集器，技能统一0至5；可采目录由测试宿主显式开放，不冒充正式探索和协会声望，暂不支持跨星系/复合带、燃料或真实AI交接。矿船与人口转运共用锁定账，不能同船双用；所有副船空闲时才可改变采矿技能输入，真实装配编辑留接入阶段。
- 离港5秒、采掘循环、富矿和货仓占比返航复用既有单点，空船去程已并入返航，不另加航程。矿先在船舱，返港整仓卸货才供精炼；不足一批时精炼仍等待。停止采矿后人员和船只保留到港，返航不受暂停/停电影响；尚未离港撤回保留原船货物，不伪造入库。卸货异常会整体回滚，读档保留航程/船货与随机状态，自动循环跨趟保留未结束富矿窗口。
- 首项科研为“初次站体扩容”，60分钟为授权的可调测试工时，不是正式平衡。每站同时一项研究，占1名基础研究员及1座初级研究室，作业总负荷4点。暂停/断电保留岗位与进度；撤出只释放岗位、保留项目进度，重新派工后续研。完成自动掌握技术并释放岗位，不收试验材料、不生成通用科研点、不开放扩站施工，也不直接改地块面积。

## 经营扩展（当前规则）

本节覆盖上方A至C3批次记录中“仅五设施/首项研究/外层v7/不开放扩站”的阶段性边界，不改变其验证留痕。

- 八类建筑沿固定八方位单圈展示；新增组装机/培训中心/警戒阵列须先完成对应科研。不够条件仍可查看材料和原因；真实建造需原工程师、库存与施工功率。
- 科研六项互不强制串联；当前项目和非当前项目各自保存有效进度，有限计划支持加入、上移、移除。前项完成自动衔接，只使用后续有效时间；计划结束释放研究员。能源/生活/制造/培训/警戒时长为120/120/90/90/60分钟，初次扩容保持60分钟。
- 扩站4小时、2工程师、6点电，只增外围7格空地。原3×3编号0至8保持原坐标，新右列9至11、新底行12至15。满原9格也能扩建，不强制拆设施；原能力不提前提高。
- 电源升级60分钟，24→36点；生命维持升级90分钟，容量6→10、运行6→8点。各占原格、1工程师、额外4点施工负荷，原能力施工期间保持，完工才替换。
- 三座新设施为基础组装机（90分钟、待机1/工作5）、基础培训中心（90分钟、待机1/工作5）、警戒阵列（60分钟、自动2）。前三者需实际材料与工程师建设；组装机一人一台、按真实已有七类零件配方和有限批数运行，培训中心提供一个额外基础课程席位，不是舰员团队模拟器。
- 警戒在线才显示实际人口转运/矿船返航信号与抵达时间，不产生敌袭、奖励或额外船只。敌方预警须正式敌袭宿主输入，不把返航识别当作完整站防已完成。
- 起步三保障可通过开发控制台模拟故障，原能力失效，人口转运仍遵守安全保护；维修不需人或额外电力，恢复最近完成等级。暂停保进度，取消只按原实际投入剩余比例退料，重复取消拒绝。
- 外层独立快照v8保存发展/制造/额外课程/科研及全部原资源。旧v1至v7只补空新账，不补成果，不能夹带新建筑；v1提前返回亦拒绝新建筑。身份互斥、资格、材料配方与发展技术交叉验证，任何交接异常整体回滚。
- `development-ready.json`为六项科研齐备/6名居民、未扩建；`development-built.json`为扩站、升级和三类新设施完成；均由`make-development-fixture.ts`正常命令生成，位于`tools/_ui-artifacts/player-station-lab/`，只能导入本预览。`development-costs.json`记录现有物价折算，不重复收信用点。
- `operations-smoke.cjs`在1366×900与390×844真实操作扩站暂停恢复、保障升级、新建筑触屏确认、有限制造、课程结业、停电维修和整体快照；输出`tools/_ui-artifacts/player-station-operations/`。不读个人档、不代表主游戏上线或观感验收。

## 手动验收

### 第二阶段续作

1. 从`tools/_ui-artifacts/second-stage/stage-two-ready.json`导入筹备完成场景；六人中3名为原普通居民，第三舰团队需实际占这3人。组建“先锋舰员队”、选择锤头鲨，推进30分钟取得基础资格，原岗位不能抢成员。
2. 安排火控/损管/机群长期模拟，占培训中心单席和原训练舰；暂停/缺电不计工时且保船锁，转待命释放训练船但不归还团队成员。每10分钟推进一步，学习机会、点数、属性/潜力和永久特性显示在队卡；技能需满足实际要求后购买。
3. 有待答二择时只在点击后应用所选结果，不超时/默认代选；待答仍可训练或出击。导出/导入不会重抽事件；解散需确认且清培养，原成员归还，不能复制成长给新队。
4. 勾选空闲团队，安排一次补给护航。去程/作业/返航实际占船；途中不能解散、换船或训练，停止仍需返航。护航出发固定扣民用组件4/基础弹60；实际清剿战斗另按原引擎耗用结算，缺补给回家或守备暂停。
5. 三处清剿来源取既有异常卡/战斗引擎，胜利后永久标记清除，不能重复领奖；失败安全归来，不删除居民/团队/船。守备与外派不能使用同队同船，警戒在线才显示下一次检查时间；无守备时风险报告不掠母港全仓。
6. 八项目标依据实际经历逐项记录。有效守备30分钟或实际击退可满足防守；全部来源清除后不需故意留敌。条件齐备手动“确认建立自主据点”，不改协会声望/原资产或开放第三阶段。
7. `stage-two-trained.json`为培养后待命，`stage-two-before-independence.json`为条件齐备但未确认，`stage-two-complete.json`为已确认；均只供本预览，不能导入正式游戏。外层快照包住原经营v8，旧经营文件仍能读取但不赠团队/成长/安全成果。
8. `stage-two-choice.json`为自然培养产生的待答场景，可直接检查事件情境、两种结果及一次性回复；暂停保留原随机与候选，不直接改种子或注入结果。新档无团队空档也保存时间轴，后续来袭计划不会因导入被重新计时。

### 原站内经营

1. 批准主体，填主体缺口并模拟到货；手动推进两次 60 分钟，检查主体与 3×3 地块。
2. 点击空地块打开轮盘，悬停/聚焦建筑，检查说明、效果、占地、工期、施工/运行电力、折后耗材及缺口；缺料按钮仍能查看详情，不能开工。触屏先点建筑显示详情，再点建造。
3. 建成发电设施，在不同地块同时开工生命维持和服务中心；分别暂停、推进、恢复、取消，检查另一个项目不受误操作。停用发电，检查缺电保进度，重新启用后恢复；主体取消后回收两次，第二次不能重复入库。
4. 在低工程学下只交高工程学足量材料，再提升工程学，检查立即开工、模块时间不变。
5. 导出快照，修改库存和项目后导入，检查整体恢复；以正式游戏存档尝试导入，应拒读且当前预览不变。
6. 在窗口边缘打开轮盘，检查菜单与详情不出屏；用键盘切换建筑，Esc、点外部或建造成功后检查回焦原地块。
7. 建成三项保障并发现来源，安排1人；推进15分钟仍无居民，再推进3分钟接收完成。将副船余舱设99时应等待，不扣料/预留人口；补到100以上才开始。
8. 复苏或返程中停用服务中心，检查安全返回、原舱保护与副船释放；恢复中心自动续行，或先停止计划，恢复后保持保护，须重新安排才接回。保护接回不再扣材料、保留接收进度且不多加一人；导出/导入中途快照后重复核对。
9. 预排工程/研究两门课程，接收首人后工程课才从0开始；暂停或关闭服务中心后推进时间不增进度，人员仍显示占用。恢复并累计30分钟后，第一名成为工程师，研究课等另一个普通居民接收；不能拿同一人自动取得第二工种。
10. 排队多项并移除其中一项，检查当前课不受影响。导出正在受训/暂停/缺电快照后导入，检查进度、队列、资格与人口身份整体一致。培养工程师和研究员需要两名不同居民、课程有效工时合计60分钟，材料库存不因课程变化。
11. 培养工程师后，在空地块建精炼；暂停时另一地块的研究室应显示缺工程师，不能扣料开工。取消后检查按原投入退剩余材料、人员释放；重建精炼需60分钟，随后同一工程师建设研究室需90分钟。断电/暂停时间不计有效工时，读档保留用工，完工后人口表回待命，两设施只待机、不自动生产。
12. 在库存输入中给橄榄岩150，派普通居民精炼（无技能每批100、10秒）；推进1分钟只完成一批，余50停工不扣尾批，产物按真实公式进库存。排课程不得抢人；补矿并停电再推进无产物，恢复电力后继续。导出中途快照整体导入不重发产物，停止精炼释放普通居民后，排队课程才可开课；原精炼不自动重启。
13. 用两名不同居民分别精炼磷光霾和开合成矿船采磷光霾场；不手填气体。采到船上时共仓仍0、精炼不动；满舱自动返航或点“停止并返航”，到港前不能改派该人/船。卸货后精炼自动使用后续有效时间加工；停止的采矿不重启，排队课程此时才可取得已释放普通居民。返航中导出/导入仍只卸一次货。
14. 用基础研究员在已建研究室安排首项科研；推进15分钟、暂停或断电后再推进，进度仍为15分钟、人口仍占用。导出/导入整体保持；撤出后推进不再增长，重新安排后累计60分钟有效工时自动掌握技术并释放人员。地块数量、居民数和建筑不因完成研究改变，关闭研究室后技术仍保留。
