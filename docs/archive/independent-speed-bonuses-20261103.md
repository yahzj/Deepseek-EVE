# 非推进器独立速度加成

状态：已实现；船长2026-11-03批准本地合入，二号完成独立合入回归，本批收口归档。现行定义见`docs/single-source.md`及`docs/glossary.md`。

## 授权与范围

- 船长原话：「这些不是推进器，不应该套用推进器周期格式，需要独立出来」。
- 追问已说明当前引擎也把非推进器速度加成按推进器周期启停，建议改为独立持续生效，并给出文案「战斗机动 +{p1}」；船长回复「确认」。
- 功能域：战斗速度与装备效果显示。沿用增压加速腔的持续速度计算、现有速度件折权单点及装备摘要/参数行，不增加独立叠加乘区。
- 生体脉搏加速器和几丁质骨架层的速度加成持续生效，不随推进器冷却消失；增压加速腔保留原渐增效果。
- 推进器仍按原周期启停；捕获网的停推进器效果仅移除推进器槽速度来源，整体减速照旧生效。
- 当前有效速度件仍在同一个池中按强度折权；非推进器原始数值、脉搏加速器装填效果、CPU、槽位与渐增时间不改。
- 不处理势力图鉴漏项，不改存档字段、技能、掉落、市场或玩家真档，不准备英文、不写入公告。

## 实现入口

- `combat/player/create.ts`：构建包含槽位的速度来源明细；`thrusterBoost`仅记录推进器自身加成。
- `combat/alienEquipment.ts`：推进器按相位筛选，其他来源持续生效，沿用`weightedSum`。
- `combat/captureWebs.ts`：停机仅移除推进器槽来源；运行规格不入存档。
- `features/ships/info/moduleEffects.tsx`与`moduleLines.tsx`：非推进器共用独立模板，推进器继续显示周期。
- 仅有常规推进器的装配保留原折权合计值和无来源明细的快速路径，非推进器或渐增速度件存在时才附来源明细。
