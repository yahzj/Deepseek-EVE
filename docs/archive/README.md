# 旧记录区

> **没有船长明确查阅要求，平时工作禁止阅读、检索、批量扫描或自动载入本目录正文。禁止用Git历史绕过。**
> 原因：这里保存已经不现行的过程、方案、数值和权限，不能成为当前开发依据。

## 查阅边界

- 普通开发、修复、续接、查规则及现行文档中的旧链接，不构成查阅授权。
- 船长明确要求后，只查指定主题或文件，查阅结束恢复禁读；历史结论仍需核实现行实现，不自动取得实施许可。
- 日常工作从`AGENTS.md`、`docs/catalog.md`和当前文档开始；`docs/INDEX.md`不收录或读取本区正文。

## 归档维护

- 新归档按明确清单搬迁或复制原文，校验字节和SHA256；可以维护本入口和清单，不通读无关旧卷。
- 已归档正文冻结，不改写原叙述；发现错误，在当前任务的现行结论里纠正，不回改档案。
- 当前有效定义和未决摘要留在现行文档，过程、旧读数及已办结流水放本区；不能把清理等同办结。
- 现有分卷保持路径；本次常用文档快照目录为`common-docs-20261029/`，其清单只用于明确授权后的维护。
- `docs/design/archive/`属于同一旧记录范围，保留既有路径；默认搜索在读取前排除所有`archive`目录。
