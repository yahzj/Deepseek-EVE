# 封存区（`docs/archive/`）—— 冻结的历史件

> **一句话**：这里放**已经不现行、但一个字都不能丢**的东西。规则就一条 —— **只读、不改、不追加**。
>
> 立区日期 **2026-09-15**（船长：「roadmap/glossary 也要进行精简，**删除过时内容，或者将过时内容移入另外一个文档并封存**」）。

## 怎么用

- **找老决策**：先看 `docs/roadmap.md` 底部的「封存卷索引」（哪天的事 → 哪一卷），再在本目录 grep；
  或者 `git log -S "<关键词>" -- docs/roadmap.md`（历史版本随时可翻，git 是最终兜底）。
- **找老术语**：`docs/glossary.md` 里作废词条只留一行「已废弃 + 现行叫法 + 指针」，全文在 `glossary-retired-20260915.md`。
- **全仓文档总索引**：`docs/INDEX.md`（`npm run docs:index` 生成，含 `docs/archive/` 全量）。

## 纪律（写给下一个接手的人，也写给 AI）

1. **不要在这里追加新内容**：新东西写进 `docs/roadmap.md` 的滚动窗口 / `docs/glossary.md` 的现行词条；
   越窗或过时后由 `npm run docs:seal`（roadmap）或人工改版（glossary）**封存成新卷**。
2. **不要重写卷内文字**：卷是"当时那一版"的取证。发现卷里有错，**在新条目/新词条里更正并指回本卷**，别回头改。
3. **别把"禁用信息"一起搬走**：旧称/作废叫法怕的是**回流**（仓库有陈旧术语黑名单守着）
   ⇒ 词典原位**必须**留「旧称 X → 现行 Y（禁用）」那一行，详解才进卷。
4. **加卷就更新本表**：新增一卷 = 在本清单加一行 + 重跑 `npm run docs:index`。
