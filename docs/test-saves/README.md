# 测试门槛存档（Test Saves）

> 约定见 `docs/development-conventions.md` 第八章。B 批次 / 新玩法数值交付时，用
> `tools/make-test-save.ts` 基于船长当前真档注入门槛，生成存档提交到本目录。

## 命名规则（2026-09-08 船长定）

测试存档命名必须符合用途：文件名 `<feature>` 段 = `make-test-save.ts` 中注册的
case 名（即该档服务的唯一测试用途），格式固定为 `test-save-<feature>-<stamp>.json`，
**禁止随意命名**。新增测试用途时：先在脚本头注释 + `INJECTORS` 注册新 case，再在本
「档案清单」补一段说明（注入门槛 + 建议测试路径），然后才生成存档。

## 加载方法（固定步骤）
1. 游戏内「存档管理 → 备份」（保留当前档）；
2. 退出游戏；
3. 把目标 `test-save-<feature>-<stamp>.json` **复制替换** `%APPDATA%\whale-idle\save.json`；
4. 启动游戏即测；测完回到游戏「存档管理 → 恢复备份」还原原档。

每个测试档旁都带一份生成时刻的 `user-backup-<stamp>.json`（注入前的原档副本，双保险）。

> **2026-09-11 去重说明**：`user-backup-20260910-233010.json` 与 `user-backup-20260910-233013.json` 当时**字节完全相同**
> （同一份真档在 3 秒内被备份两次，MD5 均为 `BDA8EE38…`），已按船长裁决**只保留一份**（`-233010`）。
> 故 `lairgear` 档（233013）没有独立配对备份 —— 其配对内容与 `etier` 档（233010）的那一份相同，信息无损。
> 其余真档备份一律不删；同 case 的旧版本（drone / redtide 各两版）保留，取用时**取最新一份**。

### 蓝图碎片 · 逆向解锁入口（fragments）
- 文件：`test-save-fragments-*.json`（取最新一份）
- 用途（2026-09-19 · 船长：「**帮我准备一个蓝图碎片的存档，玩家反应依旧找不到，我要实机测试一下**」）：
  一档同时给出**三种状态**，用来判定"找不到入口"到底是**界面没渲染**还是**位置/材料不满足**。
- 注入门槛：主控**停在母港**（`redeemFragments` 要求 `isAtHomeLike`）· 清空进行中作业 · 钱包 +100 万；
  ⚠ **把五本碎片书从 `learnedRecipes` 里摘掉**（真档六本已全会——不摘则六行全是"已解锁配方"、
  按钮全都不可点，这也正是玩家报"找不到在哪换"的一种情形）。
- 物品页 →「**蓝图碎片**」分组（或货仓页同一行）应看到 6 行：

| 行 | 现有/门槛 | 应显示 |
|---|---|---|
| 强化采集器 MK2 | 25/25（仓库） | **逆向解锁（可点）** |
| 货舱扩展 MK2 | 25/25（仓库 15 ＋ **当前船货舱 10**） | **逆向解锁（可点）**——顺带验证"仓库＋货舱一本账" |
| 精密采集器 MK3 | 250/250（仓库） | **逆向解锁（可点）** |
| 折叠货舱扩展 MK3 | 120/250（仓库） | 差 130 片 |
| 重型炮台 MK2 | 0/25 | 未集齐 |
| 攻坚炮台 MK3（动能） | 0/250 · **蓝图已掌握** | 已解锁配方（对照） |

- 点「逆向解锁」后：扣片 → 该蓝图进 `learnedRecipes`（永久）→ 该行转「已解锁配方」；
  **不在空间站时按钮应置灰**（本档停在母港，故默认可点）。

### 玩家舰船残骸（shipwreck）
> **2026-09-26 新增**（**船长：「可以生成一个存档给我核验」**；注入器 `shipwreck`）。

- 机制一句话：船在**正常星系**损毁 ⇒ 该星系留一具「**<船名>的残骸**」，48 **游戏**小时线性衰减；
  在那儿打捞时它**排在最前**（压过稀有池与普通池），每轮从它身上捞 1 件、**逐件掷概率**回收装备
  （武器 60% / 装甲·护盾·货舱 40% / 无人机 25%）；**没有矿物、没有信用点、没有其它资源**。
- 现场（四个验证面，开档即测，不必先去死一艘船）：
  1. **暗星坟场**（驾驶船所在地）：**灰鲭鲨**满配残骸 —— 6 件 ＋ 无人机 6 架（重型 ×4 / 哨戒 ×2）；
  2. **红环航道**：**鲣鱼**残骸 —— 4 件（验证**跨星系各算各的**）；
  3. **穹顶墓园**：**鹦鹉螺**残骸 —— 带**加固结构插件回收率（手工写成 0.6）**，第一次捞这具时先掷**整船回收**，
     命中即整船回母港（**结构 ×0.3 / 装甲 ×0.5**、不自动上驾驶位、货舱不回）；未命中即记下"已掷过"、此后走逐件；
     ⚠ 正式插件尚未入库，这一条是给接口留白做的**临时把手**——插件上线时请把生成器里 `reinforceChance` 那一行删掉；
  4. **驾驶船**：白鲨级 4×打捞器 MK2（与 `b3` 档同款），停在暗星坟场。
- 三个星系另预置普通残骸密度 60 / 30 / 40（用来对照"残骸立着期间不产普通残骸"）。
- 建议测试路径与看点：① 星图 → **暗星坟场** → 星系详细/打捞区 → 面板**置顶**那组「舰船残骸 N 具（优先打捞）」
  读数卡（船名 ＋ 可回收件数 ＋ 剩余小时）② 点「开始打捞」⇒ 事件日志逐条出「打捞舰船残骸：捞回 ◯◯ ×N」
  ③ 一具捞空后该卡消失，捞回的件进**装备库**（模块）/ **物品仓库**（无人机）④ 残骸立着期间
  **普通残骸与稀有残骸一点都不动**（这就是"最高优先"的直接证据）⑤（穹顶墓园那具）整船回收命中时
  日志写「舰船残骸里捞回了一艘还能修的船」、舰船页多出一艘带伤的鹦鹉螺。
- 已知口径：残骸**不占货舱**（捞回的是装备，不触发满仓返航）；衰减按**游戏时间**走，离线也消耗。
