# 指挥编队门槛档

> 状态：已实现，待船长验收。仅二号合成，不读取个人档。

## 生成与加载

运行`npx tsx tools/make-command-fleet-saves.ts`。三份档均从当前初始状态合成，使用正式装配、序列化和读档入口，不给舰体或敌人额外血量，不代为出击。

| 文件 | 门槛 | 检查路径 |
|---|---|---|
| `test-save-command-fleet-locked-20261030.json` | 累计声望19，指挥技能未训练 | 舰船页打开战斗编队，选第二艘，核对声望拒因 |
| `test-save-command-fleet-unlocked-20261030.json` | 累计声望20，基础容量25 | 选两护卫成本20可出击；三护卫成本30超预算；训练指挥基础后再试 |
| `test-save-command-fleet-twelve-20261030.json` | 累计声望20，三指挥技能满级，容量125 | 已记住12护卫成本120，尚未出击；另有一艘用于数量上限操作 |

先在游戏存档管理中备份当前进度，再导入测试档；桌面手动替换须先退出游戏，替换`%APPDATA%\whale-idle\save.json`。测试结束恢复自己的备份。生成器不会自动操作个人目录或创建个人档备份。

## 验收步骤

1. 在舰船页检查每艘成本、总成本、舰数、勾选与关闭后记忆；长名单在弹层正文内滚动。
2. 十二舰档对普通悬赏出击，检查所有舰体、三层血条和武器逐舰列表；最小化后战斗继续，点击浮动入口重新观战。
3. 战斗和返航期间检查参战舰不能改装、入仓、卸货或另派任务，其他空闲舰不受牵连。
4. 检查撤退、战后返航、逐舰承伤和货仓卸货。沉船留正常星系残骸，不在撤退后复活；主控沉没由本队幸存舰接任，全损不接管其他出勤舰。
5. 对照单舰与多舰，奖金、首胜声望和每日任务按目标发一次，不乘舰数。

敌我十二舰与96架玩家无人机的压力档由`node tools/battle-command-native-check.cjs`生成到`tools/_ui-artifacts/battle-command-20261030/`。这些压力档额外增加双方血量，仅用于持续表现压力，不能当正常难度或收益档。该脚本先构建后运行，自建隐藏离屏Electron与独立临时userData，退出按PID与目录边界清理，不触碰个人档。
