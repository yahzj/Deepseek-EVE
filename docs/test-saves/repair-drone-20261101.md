# 修理无人机与后勤测试档

独立合成，不读取或覆盖个人档。`npx tsx tools/make-repair-drone-save.ts`生成上海时间命名的唯一JSON，重名拒绝覆盖；正式装载、CPU及预算检查、两轮序列化读档及落盘回读。

预置三艘锤头鲨、一艘亡军后勤舰、一艘哨戒电子舰，指挥成本90/125，全技能5级、弹药与组件充足。亡军后勤舰装有2架军用修理无人机，占80m³；全修停在母港、加速关闭、未出战。双维修技能与后勤加成后，无人机每次装甲/结构各23点；单架每次有效修理消耗1军用组件。

1. 游戏内先备份当前进度，再退出。
2. 将本档加载到二号最新客户端；替换存档前确认已备份且客户端已退出，默认目录为`%APPDATA%\whale-idle\save.json`，独立客户端以实际目录为准。
3. 在装配页核对后勤80m³机舱、2架无人机、维修输出+50%，第3架装载应被拒绝。
4. 自行选择悬赏出战，观察队友装甲或结构受损后，无人机按周期修理并消耗组件；单独的维修装置只修本舰，修理机不修母舰或复活沉船。战内维修周期列表和战后消耗信息可核对。
5. 可在港内卸下无人机对照，测试结束恢复个人备份。未做长期平衡或观感验收。

新机型目前通过市场成品获取；本批未新增生产图纸。旧五舰运输测试档没有预装修理无人机，不能继续把之前的20种子胜率当作新配置结果。
