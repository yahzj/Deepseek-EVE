# 皇带鱼五舰运输护航测试档

船长要求「给我一个存档，我实机测试下」。本档为独立合成的运输护航门槛，不读取、备份或覆盖个人真档；不修改生产规则或参数，不代开运输或战斗。

## 生成与配置

在二号工作树运行 `npx tsx tools/make-oarfish-escort-save.ts`，另写 `test-save-oarfish-escort-<上海时间>.json`，重名拒绝覆盖。通过正式序列化、两轮读档和落盘回读，校验装配、技能、补给、编队、预算及停港状态；另在副本验证运输和三波遇袭入口，不改变交付档。

- 主控皇带鱼级旗舰货舰；护航为两艘锤头鲨级炮击巡洋舰、一艘亡军后勤舰、一艘哨戒电子舰。编队成本110/125。
- 皇带鱼低槽扩展插件、4件原型货舱；民用炮台2件、船体维修装置MK1、护盾扩展MK1两件。其余配装与护航实战读数的 `two-gun-mixed` 相同，电子舰带一件势力电子舱。
- 全技能5级、累计协会声望100、十亿信用点、充足弹药与修理补给、全站已建。调试加速关闭，五舰满修，停在母港，未开启任何作业。
- 皇带鱼货舱1,527,660m³；整队可装空间另含护航舰。为复现前次读数，手动填总货量1,527,660m³，不用整队默认满载量。

## 加载与测试

1. 先在游戏内「存档管理」备份当前进度，再退出游戏。
2. 用本测试档替换目标客户端的存档文件，再启动二号最新构建。默认正式客户端目录为 `%APPDATA%\whale-idle\save.json`；独立测试客户端若使用其他目录，以其实际路径为准，不动未备份真档。
3. 核对主控和五舰编队，打开长途运输，选择母港与烬火前哨站，输入总货量1,527,660m³，由船长手动出发。
4. 此条件在烬火遭遇的目标威胁为196；观察多波援军、辅助舰支援、战损、胜后续运与到站结算。遇袭按正常概率触发，没有预置强制倒计时。
5. 测完退出游戏，恢复此前个人档备份。

存档不携带运行时代码，旧版或主树未合入客户端不能验证本批多波机制。此前20种子全胜只代表每场独立满修、补给充足的抽样，不保证长期挂机胜率或净时薪。
