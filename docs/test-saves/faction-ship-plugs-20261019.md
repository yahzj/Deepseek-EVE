## 验收路径

1. 游戏内存档管理先备份现有进度，再导入本验收档。验收结束恢复备份，不将测试资产带入正常存档。
2. 装配页切换单件对照舰，核对插件参数、叠加方式、CPU、货仓和无人机舱。组合舰核对五个插件格均占用。
3. 章鱼人兑换窗口不应出现五张势力插件图纸；直接调用也应拒绝且不扣声望。若测试制造链，专项会手动注入已学配方，再核对黑匣料单和1小时基础工时。
4. 单件镀膜舰开战为零护盾、额外装甲；原装甲受损后再次开战不能被镀膜修满。战中保存重载和换波不再次增加装甲。
5. 单件蓄能舰有盾时被动恢复提高50%，破盾不回充；组合舰由于镀膜为零盾，蓄能不凭空生成盾。
6. 打印舰无人机仍会被击落、停火；储备甲板更快重建且不消耗备用机，本舰存活离场后恢复原编制。母舰沉没仍按原沉船规则处理，不额外返还到仓库。
