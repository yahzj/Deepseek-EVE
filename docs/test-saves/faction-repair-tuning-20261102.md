## 门槛与步骤

- 停靠母港、调试关闭、未开战或开工；五艘单插件对照舰、一艘组合舰和一艘预装两架修理机的后勤舰。
- 两种修理机图纸各两本，尚未学习永久图纸；材料和补给充足。不要先学习永久图纸，先验证一次性制造。
1. 装配页逐船看插件：空间压缩不扣CPU上限，仍减最大速度；镀膜保留少量护盾并将半数原最终护盾容量转甲；打印机体为75%、伤害为90%，仍保持原启动与甲板周期。
2. 用镀膜对照舰交战，观察战后装甲比例；未修满再次出击，转换装甲不应自动补满。初始护盾容量按新上限重建，装甲损伤按总量比例延续。
3. 组装机用一次性图纸造50架，开工扣一本、取消退回图纸和实扣材料；正常完成仅交付50架。基础工期6分钟，技能加成按现有规则。
4. 学习永久图纸后可反复造100架，基础工期12分钟，不重复消耗书。两种图纸单位料价相同。
5. 市场核对：成品R2稀有订单，一次性图纸R3稀有订单、基价84万信用点；永久图纸R4奇货、基价1680万信用点。渠道刷新有随机性，不能要求载入后立即刷到。

本档不代为完成制造或战斗；所有插件原有兑换禁用保持不变。机群修理与防复活另有确定性专项，不能以本档存在视为已做实机验收。
