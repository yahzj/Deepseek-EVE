## 加载与恢复

1. 在游戏「存档管理」备份当前进度，另保留导出的个人档。
2. 退出游戏后，用测试档替换`%APPDATA%\whale-idle\save.json`；也可使用游戏现有的存档导入入口选择本文件。
3. 重启后从舰船页查看全部船型及战斗编队；测试结束，在「存档管理」恢复自己的备份。

生成器没有读取个人档，因此不会自动生成个人档备份，也不会替你安装测试档。

## 验收路线

1. 默认驾驶鲣鱼，全部舰船停靠母港。打开战斗编队，默认12舰：6艘鲣鱼、梭鱼、掠袭电子舰、幼虫截击舰、哨戒电子舰、构件鱼雷舰、幽影侦察舰，成本122/125。
2. 先选母港低威胁悬赏，核对12舰入场、逐舰血条、武器及无人机、最小化后再观战、撤退/战后返航与出勤锁定；满级多舰可能迅速结束低级目标，需要看持续交火时换高威胁目标。
3. 重型混编参考：邓氏鱼旗舰、巨齿鲨战列、陵卫指挥舰、亡军后勤舰、掠袭电子舰，5舰共124/125。先切驾驶，再重新选编队；默认12舰不会自动变成此队。
4. 尝试第13舰与超125点名单，核对拒绝；不要把仓内全部舰船一次选满当作合法编队。
5. 核对战后逐舰战损、沉船、返航卸货与单次收益；测完恢复原档，重复复测可重新导入测试档。
