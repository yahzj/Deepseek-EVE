# 装配靶场验收

全新合成档，不读取或覆盖个人档。生成命令：`npx tsx tools/make-test-save.ts fitting-range`。
文件：`test-save-fitting-range-20261009.json`。先在游戏内备份当前进度，再从存档管理导入本档；验收后恢复原备份。不要直接覆盖未备份的个人主档。

- 装配页左侧舰名旁点击「进入靶场」，看到本舰与不反击的靶机。
- 默认交距5000米，护盾层。切换装甲/结构，观察真实层位伤害；改为50000米应停火，回到射程内继续累计。
- 查看累计伤害、包含启动/装填等待的平均每秒伤害、命中/发射及按武器/无人机型号合并的贡献。
- 暂停时伤害与飘字进度冻结，重置从零重新启动；测试60秒停止，退出再进入新场。
- 库存仅有普通初始弹药，靶场弹药/组件为虚拟供给；测试不扣真实库存，不出奖励，不覆盖真实活动。
- 无人机出击加速器详情使用「无人机启动时间」且只说明多装递减；增压腔显示5%→35%、60秒峰值。

自动读数：先`npm run build`，再`node tools/fitting-range-native-check.cjs`。隐藏独立Electron、合成临时档、两布局×桌面/手机逻辑旋转；读数和截图不是观感验收或实体手机性能结论。
