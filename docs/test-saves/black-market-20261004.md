# 黑市页面验收档

用途：独立黑市入口、货架、ASCII商人、确认购买、售罄与刷新验收。状态：随功能待船长验收。

- 生成命令：`npx tsx tools/make-black-market-save.ts`。
- 输出：`docs/test-saves/test-save-black-market-20261004.json`。
- 来源：全新初始档；不读取或复制个人存档。教程完成、星系点亮、累计协会声望100、可支配声望0、资金1万亿信用点，母港停靠；未注入已购商品。
- 合成门槛已标记旧声望回正完成，避免读档把测试注入值按空悬赏进度清掉；不改变正式玩家的回正规则。
- 加载：使用游戏设置的导入存档选择此JSON。先导出当前进度或使用独立浏览器配置，勿覆盖正在玩的个人档。
- 入口：市场顶部黑市按钮。查看九件报价，选货观察对白，购买时核对总价；取消不能扣款，确认后卡片售罄。返回市场再进入、刷新或重新导入购买后导出的档，售罄不应恢复。
- 午夜后只产生当日一批新货架；较旧测试档首次导入会按当前设备本地日期更新货架，这是正常行为。
- 两版界面与中英双语均可验收；手机按现有旋转逻辑查看，左栏内部滚动可达全部商品，减少动效时商人静止。

自动检查：先构建网页版，再运行`npx tsx tools/black-market-browser-check.ts`；独立无头Edge与合成档验证，不等同真机观感验收。
