# 虫洞第一批合成测试档

> 状态：未来虫洞整备/事件/警戒的隔离验收材料；旧玩法已改名信号空间，本文件不用于普通入口。
> 船长确认第一批跨域与配套测试档后生成，仅使用全新初始状态，不读取或覆写个人档。

## 生成与范围

命令：`npm run save:whexpedition`。工具`tools/make-wormhole-expedition-saves.ts`生成三份档并核对双轮读写、补给来源标记和明确取舍后的超载撤离。

| 档 | 局面 | 验证目标 |
|---|---|---|
| `test-save-whexpedition-ready-20261004.json` | 两艘长尾鲨、基础弹/MK2、修理组件与备用机；未入场 | 本机调试进入整备清单；预览/模板无扣款，缺额不改目标，确认才装载 |
| `test-save-whexpedition-ground-20261004.json` | 新趟暂停，携入有限物资、随行货柜/矿物，当前地点留下100发基础弹 | 重新进入原趟不重装；地点弹药标记保留，取回回补给账，不算战利品 |
| `test-save-whexpedition-overload-20261004.json` | 新趟暂停；容量缩小到一舰、3000枚军用组件占6格，容量5格 | 空取舍不可撤离；明确留下500枚后一次确认入港，取消/过期不改实物 |

测试档将地图敌人清空，供状态转移验证；超载档直接设置缩容后的状态，不伪称真实战斗发生，也不用于敌人平衡、收益或胜率判断。

## 隔离加载

1. 在本机预览的独立浏览器配置或无痕窗口打开，不使用个人正在玩的浏览器存储或桌面档。
2. 从游戏「设置 → 存档管理 → 导入」选择本目录三份测试档之一。测试档已补齐声望60、模式选择和首次任务门槛，不需要修改个人进度。
3. 准备档需在本机「设置 → 调试模式」启用，再明确勾选「未来虫洞实验」。仅开启调试不切新入口；公网域名及桌面打包版的`file:`协议不允许启用实验新趟入口。
4. 星图 → 扫描信号空间 → 未来虫洞实验 → 探索这一处，选择编队后进入整备清单。该区域只显示合成档带`expeditionRules=2`的实验坐标；普通扫描坐标仍进信号空间，开实验开关也不升级。地面/超载档点「返回虫洞」，或顶部活动窗返回原实验趟。

## 建议操作

| 局面 | 操作 | 应看到 |
|---|---|---|
| 准备 | 基础弹目标设为5000，再确认 | 保留5000目标及缺额，母港库存不扣，不能入场 |
| 准备 | 携入数量改为25，保存具名模板，改为1再选择模板并按模板补齐 | 选择时仍为1；补齐恢复25；关闭重开仍保留草稿，按实时库存重验 |
| 准备 | 两次核对确认装载 | 新趟携入25发；只有入场成功才扣仓库/入口 |
| 无人机编队 | 装配页部署机群；手填备用目标32并保存为具名模板，改为0后选择模板并按模板补齐 | 选择不改变清单，补齐恢复32；现役机舱数量不变，备份目标不再自动推算 |
| 无人机编队 | 保存另一个备用目标0的模板，选择后按模板补齐 | 明确0保留；已有舰载备用超模板时保留并显示超额，不暗卸，库存/容量不足不降低目标 |
| 地点货 | 货仓页装入100发基础弹，再留下50发 | 补给增减按id记账；留地货不再可用，不计战利品 |
| 地点货 | 切探索，前往邻格并确认留下物资 | 未确认不移动；确认后货留原格，返回可再装入 |
| 在途 | 关闭虫洞、刷新页面、从活动窗返回 | 恢复原趟，不重新装载或扣库存；刷新无免费补给 |
| 超载 | 撤离核对不做取舍 | 超出1格、确认不可用；可修改留下数量 |
| 超载 | 选择留下500枚军用组件后取消 | 取消不改货物；返回原视图，可再次核对 |
| 超载 | 再选留下500枚并按清单撤离 | 一次结算入港，归还补给与新收益分开 |

## 复跑与边界

`npm run save:whexpedition`重生成合成档；`npm run build --prefix web`后运行`npm run ui:whexpedition`。工具自建随机本机端口和独立无头Chrome配置，用真实CDP鼠标/触摸/键盘输入及可达性命中核对中英、classic/modern、六种视口与三种局面。`--quick`仅中文旧版桌面/手机两组尺寸，`--lowheight`只测568×320，`--legacy`另跑8组普通入口隔离；产物在`tools/_ui-artifacts/whexpedition-ui-check.json`、`whexpedition-legacy-ui-check.json`及同前缀截图，不接个人档。

`npm run ui:whexpedition -- --dronefill`基于准备合成档在工具内创建4艘鹦鹉螺、各部署8架蜂鸟，手填并保存备用32与明确0的多套模板，验证选择不执行、按模板补齐、缺额、双确认及库存守恒，输出`whexpedition-dronefill-ui-check.json`。只改测试进程副本，不修改输入档案。原生链复跑`npm run build`后`npm run ui:whexpedition-desktop`：临时存档目录、隐藏窗口、本机HTTP入口与真实Electron存档桥，核对模板保存/导出与入场、重载后的现役/备用数量；不访问个人档。

引擎回归入口：`wormhole-cargo-flow-20261004.test.ts`、`wormhole-supplies-20261004.test.ts`；组件回归：`wormhole-expedition-ui-20261004.test.ts`。普通信号空间手动/自动探索仍走旧入场规则，不因本地测试档交付改为有限补给。

读数只证明共享界面在浏览器仿真视口中可操作，不等于观感验收、实体手机软键盘/刘海实测。第一批空敌人档不用于第二批内容平衡或十层通关结论。

## 第二批十层整备档（2026-10-06）

`test-save-whexpedition-journey-20261006.json`由`npm run save:wormhole-journey`生成：未进洞的A族通道与4艘合法配装鹦鹉螺。相关技能5级、完整探索/战斗科技；每舰16架赤鸢，携入备用64架、军用组件500、损管组件8。含「完整补给」「不带备用机」两套随档模板，后者仅用于明确0对照，不保证续航。初始资产与悬赏首胜记录为合成测试前提，不代表普通玩家档或真实游玩进度。

加载后，在localhost预览开启既有调试开关并勾选「未来虫洞实验」，进入「出港→扫描信号空间→未来虫洞实验→探索这一处」，选中4艘鹦鹉螺，再进入整备。选择「完整补给」后点击工具条末尾「按模板补齐」，核对备用64/军用500/损管8并双确认入场；入场后有限物资不会连接母港。目标选择器已撤下，结算保留探索记录。此档不清敌、不跳层、不途中补料，与真实旅程工具冻结配置同源。

- `npm run ui:wormhole-journey`：自建Chrome、隔离localStorage与localhost，实际UI进入第一层、逐拍战斗、清第十层守卫、撤离。
- `npm run ui:wormhole-journey-native`：临时userData、隐藏Electron窗口与真实IPC存档，同一路径；在3/7/10层关闭暂停、重载、从活动栏恢复。
- `node tools/wormhole-expedition-journey-ui.cjs --matrix-only`：六事件专项合成分支，中英/双布局/低高度/手机视口，验证选项、拒因及免费离开。不是十层胜率工具。
- `npm run wormhole:journey`及`--baseline`：五族×五种子×四类编队×两策略，真引擎旅程与失败记录；`--heavy`增加合法T4/T3混编。
- `npm run wormhole:economy-new`：从旅程输出逐项核对携入、消耗、归还、洞内补给和实收战利品；未开箱货柜只计件数。
- `npm run ui:wormhole-templates`：多模板与左右布局专项，中英、双布局、7种视口；真实输入保存/选择/补齐/覆盖删除取消、10套上限、手动旧模板导入、缺货/超容/已有货保留、重载/导出及迎战/免费离开。`--quick`为两组快速检查，`--viewport=568x320 --locale=zh --layout=classic --report-tag=rerun-568`可定点取证，标记只接受字母数字横线下划线。

测试API只在显式本机验收标记开启时可用，工具只用快照、真引擎步进和落盘；没有任意写档、改血、改层、清敌或强制胜利接口。上述工具不访问个人档，也不作为船长观感验收结论。

## 信号空间与未来虫洞隔离复核

普通信号空间不用整备测试档。可在独立窗口导入既有`test-save-wh-all-20260914-145912.json`，由「返回信号空间」恢复旧网格；临时货物对照档为`test-save-wh-bag-20260914-150050.json`。这些历史测试档文件保持原样，不改名或写回；界面使用新名，不新增携入账、警戒或事件。

旧玩法来源为验证工作区当时的`c5f8be8346e2bde9b1e738e7ddbfd5ca4740d519`，面板源文件blob为`98012b1a55ece1473e226f7bb499887b5b628ce5`；保留在零号`SignalSpace.tsx`。自动探索仍用原时长、损伤与不丢船规则，临时背包仍随队；不是从新虫洞删除控件后拼出的替代玩法。

- `npm run ui:signal-space -- --legacy-only --report-tag=signal-legacy`：中英×双布局×桌面/低高度/手机8组，逐组手动、临时货仓、自动探索；默认`debug=1/future=0/TEST=0`，再验证实验开关也不升级旧坐标。
- `npm run ui:signal-space -- --future-only --report-tag=signal-future`：明确实验坐标与普通坐标混存，真实整备入场，暂停/活动恢复后仍显示虫洞，旧坐标不动；不是十层工具。
- `node tools/signal-space-ui-check.cjs --compat-only --report-tag=signal-compat`：早期有限补给兼容趟无`expeditionRules=2`，恢复仍显示信号空间、保留供货/地点货物操作，不加新事件警戒。
- `npm run ui:signal-space -- --self-test`：纯工具自检，不起浏览器、不读个人档。UI工具的离线自动结算只回拨隔离合成档的存盘墙钟，不改探索种子、舰血、伤害或运行账。

新旧内部`wormhole*`字段、物品和任务ID保持原样；历史存档日志与已发布公告不重写。合成新库存标记仅供未来内容验收，正常扫描及奖励不产生该标记。
