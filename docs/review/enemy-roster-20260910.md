## 旋钮清单（您调哪一列，改哪里）

| 列 | 数据位置 | 说明 / 影响面 |
|---|---|---|
| **威胁** | `anomalies.ts` `threat` | 敌人一切的基础：总火力 = 威胁 × 0.8、僚机摊薄、悬赏奖金、日板派发 |
| **族** | `foeFamily`（美术层 `shipArt.tsx` `FOE_FAMILY` 同源） | 决定混伤副系、窝点/专属件、舰船造型与族色 |
| **战术** | `tactic` | **决定射程带、期望交距、速度口径**（三件一起变）。缺省 = orbit |
| **射程带** | 引擎 `TACTIC_RANGE` × `foeRangeGrowMul`（**目前无逐卡覆写**） | brawl 2200 / orbit 4600 / kite 9200（×成长、封顶 15 km）。**是否"够得着玩家期望 3220 m"由它决定** |
| **期望交距** | 引擎 `tacticDesireFactor`（brawl 0.2 / orbit 0.55 / kite 0.85，**无逐卡覆写**） | 敌人想站在自己射程带的哪个位置 |
| **敌速** | `foeSpeedMps`（逐卡，26 张全显式） | 比率 = 敌战斗机动 ÷ 基准 165.2 m/s；护栏 brawl 1.05~1.55 / orbit 0.90~1.25 / kite 0.60~0.85 |
| **编队** | `escorts` / `waves` | 僚机摊薄份额 → 影响单发；波次决定总血与"无喘息" |
| **总血** | `foeHpOverride` | 逐卡；影响时长。⚠ 对 brawl 卡**不影响承伤**（够不着），对 orbit/kite 也主要影响时长 |
| **总 DPS / 单发** | 威胁 → 0.8 → 装填 4s → 命中补偿 → 逐卡口 | 逐卡口：`foeShotDmg`（直写单发）／`foeDmgMul`（伤害倍率） |
| **命中** | `foeHitRate`（覆写）/ `balance.foeHitRate 0.85` | 只对动能/爆炸；**能量 = 光束必中**（100%） |
| **构成** | `dmgMix` | 主 8 : 副 2；纯系只写一系。**副系决定"玩家堆哪一系抗"** |
| **衰减** | `foeFalloff`（覆写）/ `balance.foeFalloff 0.3` | 动能/爆炸 = 命中衰减；**能量 = 威力衰减（值越大衰减越轻）** |
| **个性口** | `foeDmgMul` / `foeHitRate` / `foeShotDmg` / `foeFalloff` / `blindDmgMul` | 逐卡特例 |

## 三条实测规律（调之前值得知道）

1. **brawl 卡的承伤由"速度差 × 推进器"决定，与血量无关** —— 中位玩家带 MK2 推进器时，威胁 40~80 的 9 张近战卡残血一律 100%。要让它们真打人，要么**再提敌速**（但玩家速度跨度 2.4 倍，见敌速重标 §3.2），要么**给玩家侧加限制**（如推进器冷却期更长）。
2. **orbit/kite 卡的承伤由"接近期长度 × 接近期火力"决定，与血量也几乎无关** —— 13 km 接近段挨的那一段就是全部伤害。
3. **星髓虫群 72 的 `foeDmgMul` 是死旋钮**（0.3~1.0 扫描对参考行零影响）——它已按您裁决移除。
