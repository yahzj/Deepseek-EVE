## 五、老档与页面锁口径

1. **老档（v25 及更早）**：读档时一次性把 13 条判为已完成（只写"已完成"，**不发任何奖励**）；
   13 封情报信由触发器在下一拍补送（按 id 幂等）。
2. **序章进度**：只认 `0`（正处序章演出）与 `99`（已完成）；老档的 -1 / 0.5 / 1..8 一律读成 99。
3. **页面锁定因此只对新档生效**（老档入口照旧）。
4. 旧线性教程（七步通讯 · 顶部引导条 · 光圈 · 收尾演出 · 跳过教程）与通讯「自带动作」机制整件退场。
5. **真档实证**（`npm run save:migrate`，只读）：`docs/test-saves/` 的 80 份各代存档（v18 → v25）**全部通过**——
   读得进来、`step` 落 0 或 99、13 条判过、资产逐字不变、页面解锁不倒退。
