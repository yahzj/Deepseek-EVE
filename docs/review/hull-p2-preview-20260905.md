# 承伤持久化 P2：数值与甲抗/盾抗流派平衡预览（2026-09-05，供船长拍板）

> 本文只做**预览与建议**，不做数值落盘；船长确认后回写 balance 并跑 P3 全量验收。

## 一、P0 落地的默认初值（现状）

| 参数 | 现值 | 位置 |
|---|---|---|
| 护盾战中回充 | 2%/s（满盾比例） | balance.battle.shieldRegenPerSec |
| 回充停止条件 | 甲与结构均归零后停充（防“盾皮僵持”） | combat.stepBattle |
| 结构（=耐久）伤 | 战斗中结构被打多少扣多少，跨场保留，归零弃船 | persistFleetHullDamage |
| 装甲残余 | armorPct 0~1，跨场保留 | 同上 |
| 港内维修 | 结构缺失 + 0.5×装甲缺失 × 船容 × 单价（技能折扣沿用） | shipyard.repairCostIsk |
| 修理套件 | 引擎逻辑就绪（结构/装甲同量恢复至阈值 0.5），**内容组件待修理系统专案** | repairWithKits |

## 二、磨损模型的行为特征（P0 引擎实测/模拟口径）

- 胜利连刷现在会产生**装甲/结构磨损**：低威胁目标打到盾即止（磨损≈0），高威胁/高穿目标才吃结构伤 → 天然把“高收益高磨损”绑在一起，符合收敛方向；
- 模拟观测（v22 引擎 60d all）：通关 0.07d（v21 为 0.05~0.06d），无引擎异常；磨损主要通过港内维修支出体现，farm 速率小幅回落；
- 失败惩罚（原扣耐久 15~30% + 维修费）在持久模型下语义强化：失败=当场再压结构 + 场上伤照留，弃船风险随磨损累积上升。

## 三、甲抗 vs 盾抗流派雏形（本轮只定方向，数值下批）

| 流派 | 特征 | 经济/战术含义 |
|---|---|---|
| 盾抗线 | 中高盾池 + 回充续航，甲/结构薄 | 连战省维修费，但怕高穿/爆发；适合“远行不常回港” |
| 甲抗线 | 高装甲池 + 抗性缺口收窄 | 单场更能抗，但受损就要回港付费（甲+结构都贵）→ 适合作战-保养节奏 |

- 钩子已具备：护盾操作学（+盾容量）、船体加固/重装舰操作（+甲结构）、护盾/装甲调谐学（缺口收窄）；
- **P2 建议落点（待确认）**：
  1. 回充维持 2%/s 初值（若连战强度过高可调 1.5%）；
  2. 维修费权重维持结构 1.0 + 装甲 0.5（若甲抗线过弱，装甲权重降到 0.35 并在甲板类装备上找补）；
  3. 暂不加“胜利额外磨损”参数——现有穿透伤已形成自然磨损；如模拟 P3 后磨损仍不足以打断顶配永动，再上“连续出战疲劳/同目标衰减”二选一（旋钮备而不用）。

## 四、待船长拍板项（本次预览不落数值）

1. 三组参数维持或微调（回充速率 / 维修装甲权重 / 是否加胜利附加磨损）；

3. 若确认方向 = “维持 P0 初值 + 流派只定方向”，P3 跑完直接收尾，数值细调并入修理系统专案一起做。
