# 术语词典（Glossary）

> **仓库级术语权威**（约定见 `docs/development-conventions.md` 第十一章）。
> 用途：跨会话沟通 / 写文档 / 写注释前查词，避免压缩上下文后名词漂移。
> 维护：新系统定稿词由经办人当天登记（定义/公式/出处/状态）；与 `docs/design/` 冲突以本词典为准并回头修订。

| 地图级别 | **2026-09-10 船长定**：每张窝点卡标 `AnomalyDef.lairLevel`（1/2/3）= 该地图的**档位上限**——**1 级只出外围、2 级到核心、3 级全档**（硬封顶，不是加权），故**族内越低级的图出现高档位赏金的概率越低**（1 级图永远出不了核心/深层）。发档 = 在该卡 `[1..级别]` 内**均匀随机**、逐卡独立掷、**无三档保底**。级别**只按族内相对强度**（奖金为主、威胁为辅），**不与区划绑定**（A 族 6 张全在中安，若按区划封顶则海盗永远出不了深层）。契约：每张候选卡必须显式标级（缺省 3 只是"漏标不误伤"），且**每个敌族至少一张 3 级**（船长定） | AnomalyDef.lairLevel；lairs.lairLevelOf / lairTiersOf；sideTasks.rollLairTierFor；content-check「窝点级别契约」；tests/bounty-tasks.test.ts |

| 赏金倍率 | **2026-09-10 船长定（2/4/8）**：三档窝点奖金 = 主题悬赏奖金 ×**2 / 4 / 8**——**只管钱、不管难度**：威胁/波次/僚机仍走档位威胁系数 1.3/1.6/2.0，三档奖金差距拉成 2/4/8 倍（一档也明确高于常驻悬赏原值）。酬金仍 = 窝点奖金 ×档位比例 0.5/0.75/1.0 | LAIR_REWARD_MUL；lairBaseRewardIsk |

| 敌对派系活跃 | **2026-09-10 船长定**：每天选**一个中安/低安星系**（已探索、有正经悬赏卡），在任务中心「赏金任务」页**置顶**一条；**额外一席**（当天 1 条派系 + 5 席常规 = 6 条），该星系从常规席位抽签池里**剔除**（避免同星系两条）。**只作用于该星系的常驻悬赏**（与赏金任务的窝点无关）：当天它的全部悬赏**奖金 +10%、敌人威胁 +10%**，战斗胜利后**按概率掉稀有残骸**（进该星系残骸场、打捞必得）。**不因打赢而下板** → 当天可反复刷；逐日重选 | state.sideTasks.faction；lairs.FACTION_BOUNTY_REWARD_MUL / FACTION_BOUNTY_THREAT_MUL / FACTION_RARE_DROP_CHANCE |
