# 术语词典

> 只收现行名称、定义和实现入口，不保存调参读数、事故过程、逐问逐答或发布沿革。新术语确认后登记，存疑核对当前代码和船长裁定。
> 数值由当前数据与导出函数决定，本页不维护第二份参数表。历史原文已封存；没有船长明确查阅要求，禁止阅读、检索或自动载入旧记录及Git历史。

## 一、领域与流程

| 术语 | 当前含义与入口 |
|---|---|
| 船长 | 用户本人，游戏设计、数值与发布的最终裁定者；汇报固定开头见开发约定 |
| 一号、二号、三号、零号 | 并行会话代号，工作树和权限以`AGENTS.md`为准，不由旧任务分工推定 |
| 确认闸门（原四步闸门） | 按风险分档：默认直接实现；仅新大功能、存档结构、数值体系、跨域、玩家公告、范围模糊等后果大或不可逆改动才确认，且一轮问完（集中提问≤3问、中文设计总结、显式确认、实现登记） |
| 主树、附属树 | 同仓Git工作树；主树main保存已合入结果，附属树隔离在途工作 |
| `.wiki` 知识库 | 仓库根目录`.wiki`的Obsidian库：设计、数值、UI/UX与架构的沉淀结论及书目蒸馏；检索分层与引用规则见`AGENTS.md` §5.4，入口`index.md`与`_meta/taxonomy.md` |
| 真档、门槛档 | 真档是个人真实进度；门槛档为可复现生成器合成的测试条件，不能混用 |
| 当前存档结构 | 只接受v31，继续清洗当前字段与修复资产；编号迁移和历史补偿不再执行 |
| 随档字段 | 写入后还需通过读档白名单保留的状态；写入点与`normalizeState`一起维护 |
| 铁人模式、存档代次、救援档 | 以落盘代次限制回退的存档纪律；代次账本与普通重置分开，规则读`ironman`相关实现 |
| 高安、中安、低安 | 安全等级分别为`security ≥ 0.5`、`0 < security < 0.5`、`security ≤ 0`；具体机制仍读各自门槛 |
| 主控、驾驶船 | 玩家当前直接控制的舰船与其活动；不等同全部舰队 |
| AI副船 | 消耗AI核心名额的自动作业舰，与工业共用启用上限；不要由名称推定支持自动远征 |
| 主控活动、活动门禁 | 主控互斥工作及切换前检查；以`activityGate`和活动注册为单点 |
| 到港接续待办 | `pendingStationActivity`绑定一艘主控舰的待启动指令，真正返航到港后重验再启动，不预扣材料 |
| 返航换驾驶 | 成功换船取消原舰接续待办，保留原舰返航与货物；新舰不继承返航，目标舰仍须满足接管条件 |
| 悬赏、常驻悬赏 | `AnomalyDef`战斗目标，由声望等门槛解锁；区别于限时赏金任务 |
| 首胜 | `completedBounties`中的完成标记；奖励与后续资格读实际消费点 |
| 远征 | 出击交战与善后返航状态机，实现在`core/src/expedition/` |
| 巡回讨伐、重复清剿 | 返航、冷却及主控空闲后继续出击的循环；亲自工业也占主控，AI工业不占 |
| 掩护巡逻、低安暴露 | 主控驻留野外与相应遇袭判据，读`encounters`及地点逻辑 |
| 扫描探索 | 独立深空扫描艇探测任务，不占主控活动；完成点亮星系并收尾 |
| 时效任务板 | 周期刷新且有存活时间的资源、快递或赏金任务，不能混用各板周期 |
| 快递接单 | 接受运输合同；普通与限时快递的期限和结算读对应任务定义 |
| 敌人窝点 | 多波战斗目标，威胁、掉落和编成由当前卡及派生规则决定 |
| 敌对派系活跃 | 星系当期敌对活动及相关候选、掉落规则，读当前活跃定义 |
| 周末入侵、外围、核心条、贡献奖、旗舰战 | 入侵玩法的区域推进、共享进度和奖励概念，实现在`core/src/invasion/`；入侵旗舰是职务，不是T5舰体分类名 |
| 判据回钉 | `threatJudged`用于指定威胁判据来源，不能与实际编成血量、火力混为一项 |
| 限时倍率表 | `tuning`内带有效时间的配置，过期不应作为永久基准 |

## 二、战斗与敌方

| 术语 | 当前含义与入口 |
|---|---|
| 指挥成本、指挥容量 | 船型固定占用点与玩家可同时指挥的点数预算，不是每场消耗品；规则归`combat/command/rules.ts`，船型成本归静态舰船表。船长2026-10-30确认实施，待验收 |
| 战斗编队、出勤快照 | 前者为港内保存的参战意向，后者为本次实际随行及返航的实例名单；意向不锁舰，出发逐舰预检并锁到返港，归`combat/command/`。船长2026-10-30确认实施，待验收 |
| 威胁等级、参考段火力 | 用于敌群派生或定价的标尺，不等于实际持续输出；以`foePower`及卡片工厂为准 |
| 虚拟装配、敌舰配置表 | 敌舰舰级、挂载和属性来源；按`foeShips`、`foeMounts`及真实工厂装配 |
| 舰级路径、编成、编成条目 | 卡片选择舰级及单位数量的规则；混编指多个规格或角色共同出场 |
| 轻装、精锐、子分类 | 敌舰规格或舰船角色修饰，与质量级别分别表达 |
| A海盗、B武装拾荒者、C异形、D守墓、E巨构、G鱿鱼亡军、H章鱼人 | 势力族标识；各族现行编成和挂载读内容目录，F制式巡逻为禁用旧称 |
| 血型随卡走 | 卡片`split`可覆写三层容量分配，不另改共用舰级 |
| 敌方挂载件 | `mounts`定义的敌舰机制组件；名称、效果与触发由挂载单点提供 |
| 纸面单发、名义火力、实收输出 | 分别是规格伤害、未计命中等因素的火力、实际扣除目标血量；不得互当收益结论 |
| 承伤三层 | 护盾、装甲、结构；结构是正式名称，耐久不是第四层 |
| 敌舰层抗 | 护盾、装甲、结构各层独立抗性，不能只用总抗性替代 |
| 动能、爆破、能量 | 三系伤害；武器类型和弹药类型分别取真实规格，克制读`typeLayerMult` |
| 远端衰减、命中公式 | 距离影响威力与命中的计算，由战斗数学单点决定，回避与命中不能凭文案相加 |
| 近盲带 | 靠近武器的近距区间；玩家舰载武器开火与伤害分别读`playerWeaponInRange`和`playerBlindDamageMul`，无人机与近防例外按实际实现 |
| 期望交距、目标距离、主武器 | 战术期望距离与玩家保存的距离设置；主武器识别读当前有效武器，不按固定槽猜测 |
| 开火列、无法交战 | 单位开火位置及提前脱战判据，读当前战斗状态，不用演出位置替代引擎位置 |
| 敌编队接近速度、敌冲锋 | 编队运动与逐单位冲锋状态；界面速度应读运行规格 |
| 推进器周期点火 | 主动推进收益按点火、冷却及捕获网等有效状态变化，不等同常驻基础速度 |
| 非推进器速度加成 | 生体脉搏加速器、几丁质骨架层等非推进器装备的速度收益持续生效，增压加速腔保留渐增；不随推进器冷却或停机消失，仍与当前有效速度件同池折权，捕获网整体减速照旧 |
| 胜率、带伤预警、连续作战保险 | 当前配置下的评估与出击防护；胜率是样本评估，不能冒充必胜承诺 |
| 齐射保护 | 玩家实际承伤的窗口与逐舰限制，单点为`combat/damage.ts`，读档和混伤也须走同一路径 |
| 护盾被动回充、护盾充能装置、护盾投送力场 | 被动恢复、周期本舰充能、对队友的力场支援；力场旧称护盾充能力场装置，2026-11-01船长确认更名，二号已实现待验收合入。当前比例与扣盾费用读`combatMath`及`combatRepair`，不使用旧恢复基准换算 |
| 修理组件、船体维修装置 | 维修消耗物与维修装置；战斗脉冲和战后维修各按实际消费入口 |
| 后勤舰 | 船体特性使维修脉冲作用于队友的舰种；目标与排除条件由实现决定 |
| 损伤管制装置 | `mod-dc-*`危机防护装置，触发、持续与保底账本不能由UI重复实现 |
| 苏生协议、陵寝重构协议、守墓镀层装甲 | 守墓危机恢复与容量相关机制；玩家和敌方规格按各自挂载读取，共享规则见`gravekeeperGear` |
| 酸液爆虫、酸液破盾腔 | 入侵自毁单位与其专属护盾伤害挂载，`foe-mount-c-acid-shield`只影响对应爆发护盾段 |
| 哺育工虫、背巢巨兽、巢母巨兽 | 入侵支援、机群载体与旗舰单位；腐蚀、补机、复活和加速账本见`alienCombat` |
| 颚钳无人机、颚钳虫群 | 玩家动能无人机与敌方机型，名称与来源分开；参数读取各自静态源 |
| 酸蚀弹射器、增压加速腔 | 降低目标装甲/结构抗性的炮台，以及随战斗时长蓄压的速度辅助件；有效值读`alienEquipment` |
| 叠光支援信标 | `foe-mount-corona-overlay-beacon`，中枢按周期在本波编成空位补叠光级，不额外扩编 |
| 受击增程 | 敌舰或敌机的射程增长机制，按对应挂载和触发状态计算 |
| 敌方混伤 | `dmgMix`定义的伤害类型分配，不能只按首种伤害展示或结算 |
| 入场窗口、单波增援、波次转场 | 演出与战斗推进边界；机制存在不等于当前开关已启用 |
| 伤害飘字、MISS | 战斗事件的实收伤害与未命中展示，同拍同目标按规则合并；取`BattleFx`而非另估伤害 |
| 伤害类型配色 | 动能金、爆破橙、能量青，徽标、弹道、射程弧与飘字读同源语义色 |

## 三、装备、舰船与技能

| 术语 | 当前含义与入口 |
|---|---|
| CPU、协处理器、CPU剩余 | 装配预算、扩容装备及预算减占用；单点`ships/fitting`，显示不得掩盖超载 |
| 高槽、中槽、低槽、舰船插件 | 装备归属与物理槽概念；插件独立于三类常规槽，筛选读统一分类 |
| 位数组 | 按位置保存的槽位布局，清洗不能把空位挤掉改变装配位置 |
| 舰船仓库、我的舰队 | 已拥有舰船实例及其管理入口，区别于市场舰种定义 |
| 装配方案、沉船快照 | 保存配置参考的方案与损失记录；套用仍需核实当前库存、预算和槽位 |
| 支援件 | 分战斗支援、辅助支援和修理装置，范围与叠加读实际效果类型 |
| 多装递减、多件不叠加、同类叠加多来源收益递减 | 分别对应折权、取单件与跨来源收益规则，不能互换用语 |
| 火力加成、武器类型加成、无人机专属加成 | `powerBonus`等不同作用域的收益；页面读实际接线，不把玩家武器和机群倍率混用 |
| 锁定装置、集火、收敛 | 目标选择和命中相关效果；由战斗单点提供，不在界面另写规则 |
| 侦察机、战斗机、强击机、轰炸机 | 四型无人机定位；体积、命中、射程、CPU与生存取当前机型和技能 |
| 无人机舱、机群火力占比、总火力锚点 | 机群容量与敌群火力拆分概念，分别读装配、`droneFireShare`和`firepowerAnchor` |
| 无人机出击加速器 | 缩短首次入场队列等待的高槽件；不同来源乘区与复活队列由`droneLaunch`统一处理 |
| 激光校准仪 | 改善玩家激光远端威力保留的低槽件，实际值由`laserFalloffOf`计算 |
| 近防炮、防空 | 近防武器及其对机群效果；逐门记账，命中、闪避和防空倍率按实际战斗消费 |
| 警戒机、蜂群机、备用机库 | 敌方机群与后备补机来源，备用量不算当前在场火力 |
| 短距离跃迁装置 | `mod-lair-blink-r`现名，中槽战斗支援；受击朝期望交距跃迁，不视作推进器，多件选取读实际规则 |
| 隐秘行动装置、跃迁计算机 | 高槽隐身支援与低槽跃迁支援，启停和叠加读对应装配效果 |
| 袭击者插件、护盾镀膜插件、护盾蓄能插件、空间压缩插件、廉价打印插件 | 海盗、异形、守墓、巨构、亡军的五族船插；定义存在不表示已开放获取，不自动加入普通船插兑换 |
| 船体特性、舰船间接属性 | 舰体定义驱动的被动及间接影响，图鉴与战斗取同源数据 |
| 护卫舰T1、驱逐舰T2、巡洋舰T3、主力舰T4、泰坦T5 | 当前质量级别分类，敌我共用；「旗舰」仅可用于入侵指挥职务或具体正式名称 |
| 工业、武装、重装、航运 | 舰船角色，与T级和电子、后勤、侦察等子分类分别表达 |
| 鲸王、座头鲸 | 前者偏短途采集，后者偏远星系大舱运输；具体效率按当前装配现算 |
| 磷虾级、沙鳗级、独角鲸级 | 正式采矿舰名，旧沙猫、掘地、先驱名称不作为当前称呼 |
| 技能科技树、技能书、真前置 | 技能节点展示、解锁凭证和真实学习条件；连线必须来自实际前置 |
| 训练许可、工作量、rank | 学习成本与训练时间/进度单位；进度投影由训练单点处理 |
| 通用、家族、专属技能 | 跨产线、单族及指定机器/配方的作用域，不能因同页展示就继承别族加成 |

## 四、工业、经济与打捞

| 术语 | 当前含义与入口 |
|---|---|
| 信用点 | 游戏货币中文单位，英文`credit/credits`，内部字段仍为`isk` |
| 原矿、原材料 | 采集原始物与精炼后材料的正式分类，不能都叫矿物 |
| 组装机、造船厂、实验室 | 多料到一物的生产族；仓库整批扣料、退料账与循环见开发约定十七 |
| 精炼炉、回收炉、拆解台 | 原料或残骸到多种产物的处理入口，按每批实际扣料与产物结算 |
| 工业工位、AI核心调度、工业扩容 | 亲自或AI驱动生产的工作名额，核心上限与机器位数分开计算 |
| 停机善后 | 退当前批实际材料、一次性图纸及名额，失去当前进度；走原始投料账不估算退款 |
| 产线节拍学、产出倍率 | 工期与批产是不同读数，必须读本产线真正消费的技能和导出单点 |
| 零件体系 | 配方中按当前目录分层的材料，基础与高级零件的蓝图要求分别读取 |
| 常驻、稀有、奇货、黑市 | 市场渠道；渠道不等于物品自身数字稀有度，黑市独立候选与日界 |
| 数字稀有度、R标签 | 物品自身档位，唯一表`RARITY_TIER`；无记录不强塞R1，不决定渠道归属 |
| 限额慢补货 | 常驻商品独立可售额度，周期补回、满额不囤积进度；与价格池、买入流量和限购分别记账 |
| 虚空晶、虚空母矿 | 前者按当前限额供给配置出售，后者保持只收不卖；不能沿用旧统一禁售结论 |
| 市场价格权威、基准价、成交价 | 静态基准与实时行情不同；商品引用按refId关联，不按key猜舰船id |
| 站内吸收、吸收额、收购档位、冲击动量 | 订单池与成交量对行情的作用；当前公式读市场导出，不从旧结论推收益 |
| 巡游抢单、价格小史 | 特殊成交路径与行情采样记录，不是第二套定价源 |
| 挂买单预扣 | `PlayerOrder.escrowIsk`托管余额，撤单退款与市场收入累计分开 |
| 蓝图价格、舰船价格三口径 | 书价、制造成本与市场锚价等不同概念，定价函数及登记例外是权威 |
| 长途运输 | 带时间、距离、安全收益及遇袭处理的贸易活动，预估和结算调用同源规则 |
| 残骸密度、基础密度、保底点、击杀注入、漂移 | 打捞候选生成及随时间变化概念，以当前打捞环境为准 |
| 打捞器、捞取体积、残骸记账 | 打捞能力、单次可处理量与已捞状态；满仓返港和自动循环读真实状态机 |
| 回收、拆解、回收档位 | 残骸或货柜转换产物的操作；常、险、危等档位不等于商品稀有度 |
| 彩头、特色掉落、稀有残骸 | 基础产出外的奖励与独立候选，保底、额外池和特色池分开计算 |
| 蓝图碎片、集齐阈值 | 集齐后获得图纸的碎片进度，重复规避按当前目录和账本 |
| wreckThreat | 回收结算采用的冻结威胁口径，不由战后新属性回算 |
| 拆解序位 | 按存档种子与拆解计数确定结果的账本，避免预览或其他随机行为扰动拆解 |
| 黑匣、异形旗舰黑匣 | 独立`blackbox`物品分类；入侵奖励与制造用途按当前定义，仓库和市场不归货物杂项 |

## 五、探索、建设与任务

| 术语 | 当前含义与入口 |
|---|---|
| 信号空间、信号谜质 | 当前旧探索玩法的正式玩家名称；代码兼容标识仍可保留wormhole，不据此推定新玩法已开放 |

| 星球地块、危险度、宜居度 | 地表建设单元、机械开发代价与生活条件；不是星系安全等级 |

| 完成时间 | 游戏时间与外部传入墙钟分别记录，core不直接取当前时间；未知旧时间不伪造 |

## 六、界面术语

| 术语 | 当前含义与入口 |
|---|---|
| 一级页、二级窗口 | 导航直系页面与其内功能容器；一级不滚，内容在内窗完整可达 |
| 旋转逻辑空间 | 手机竖屏横向布局的逻辑尺寸，覆盖层与媒体查询须使用同轴坐标 |
| 主题、皮肤、跟随系统 | 当前界面配色与系统偏好设置；颜色读取语义token，不能据主题复制规则 |
| 命名色、语义色阶、组件token | 色板分层，值由统一样式源维护，不在页面另抄硬编码 |
| 富卡、提示归属 | 统一悬停详情与触发元素，同元素单机制、内层优先、统一延迟 |
| 视口懒挂载 | 大列表按可见范围挂载展示，不改变内容目录和业务状态 |
| 星图显示模式 | 星系名称、安全等级和敌对派系的互斥显示选择 |
| 族徽角标 | 势力专属识别标记，判据和可访问名称读`labelsText`单点 |
| 物品/市场细分、蓝图二次分类 | 各入口复用同一分类函数，不能各页自造互斥口径 |
| 音效语义 id | 声音系统的稳定事件名（如`invasion-alarm`）：调用点、素材文件名、音效台共用一份清单（`SFX_CUES`），一经使用不改名 |
| 内置音效、本机覆盖 | 内置音效随构建发布（`assets/sfx/`）；本机覆盖是音效台导入的未入库音效，只存在本机，优先于内置但不随发布 |
| 音效台 | 设置内仅本机调试可见的音效管理面板（2026-11-04 调试批扩为居中大窗）：页签「素材清单 / 场景预演 / 实时触发 / 入库」+ 底部工具条，可收起为悬浮条、调试模式顶栏另有「♪ 声音」入口；试听、导入/替换、清除、导出与一键入库 |
| 音效入库包 | 音效台把本机覆盖打包成的 zip：含 `manifest.json` 与 `assets` 路径映射；仓库根 `npm run audio:install` 校验后写入内置素材目录，未入库的本机覆盖不随发布 |
| 场景音乐、环境音 | 按游玩场景切换的 BGM 与环境底噪；场景优先级与映射读 `scene.ts`，素材缺省即静音 |
| 音高随机、音分 | 战斗重复音每次播放的微小变调幅度；单位是音分（1 半音 = 100 音分，1 八度 = 1200 音分），默认 ±100 音分 |
| 场景预演 | 音效台调试页签：把音频强制切到某个场景的 BGM/环境底噪并列出相关事件，只切声音、不改存档与画面；「恢复真实场景」回到当前游玩场景 |
| 实时触发日志 | 音效台调试页签：滚动记录最近真实播放的语义 id（试听不记），供边看画面边锚定声音 |
| 一键入库 | 桌面开发版音效台把本机覆盖写入仓库内置素材目录（主进程调用 `audio:install`）；成功后自动清除已入库的本机覆盖，网页版仍走导出 + 命令；刷新页面后生效 |
