> 状态：已确认（船长 2026-09-08 逐轮拍板：①只升不砍；②同时看净收益率与周转收益率；
> ③精炼无技能净率抬到 ≈20%、满技在原数值上下调约 20%；④组装机收益率下限 ≈20%）。
> 前置：二号已完成体检工具（tools/manufacture-econ.ts）、组装机卡净 ≈ISK/h 展示（A 项）、

## 一、口径

- **工位**：手动位或 1 枚 AI 核心 = 1 工位；每线/每炉占 1 工位（AI 扩容工位只增并行数，
  不改单线口径——单线收益表即为"单位工位收益表"）。
- **两把尺**：①净收益率 =（卖站净得 − 材料成本）/ 材料成本（无技能手动口径）；
  ②周转视角 = 净/h ÷ 材料投入/h（同一比，直观化"转化速度"）。
- 下限：无技能净率 **≈20%**（精炼与组装机统一；高收益行不设上限——稀缺工位/长周期/
  吸收流自约束）。

## 二、精炼炉（balance.ts + 技能/文案）

- 基础产出倍率 100% → **120%**：无技能净率由 ≈0 抬到 ≈+20%（perOre 取整 ±2pp）。
- 技能本身每级加成在原值上下调约 20%（就近取整）：精炼学 +8%→**+6%**、高级回收处理
  +4%→**+3%**，满级倍率 160%→**165%**。
- 组装机技能同口径下调（就近取整）：工业理论 −5%→**−4%**、批量生产学 −4%→**−3%**（制造时间）；
  材料学 −2%→**−1.5%**、组件标准化 −1%→**−0.8%**（材料消耗）；产线节拍学（周期）不变。
- 玩家可见：技能描述、工业页产出倍率行、手册「精炼」条、README/头注同步；
  content-check 护栏 1.2 倍 [1.15, 1.35]（低批量 floor 步长允高，玄晶等）。
- 核心测试：industry.test/v10.test/skills-effects.test 数值断言随新参数更新。

## 六、2026-09-10 补锚（船长：「接下来对组装机生产的物品贩卖进行平衡」→「上调所需材料」）

**问题**：同日"MK2/MK3 装备价对齐同级武器价"上调了 46 件成品价，**材料配方未跟着走** ⇒
这些件的「料 ÷ 现货价」从 ~42% 掉到 **3.0~18.3%**，制造毛利率从 ~120% 飙到 **446~2625%**
（极端例 `bp-armor-plate-3`：一个工位变现 222 万 ISK/h；`bp-hullrep-1` 442 万/h），
远超采矿（掘洞满配 26~626 万/h）与赏金（深层卡 126.9 万/h）——而"高收益行不设上限"的三个理由
（稀缺工位 / 长周期 / 吸收流自约束）在这些行上都不成立（周期 900~2900s、吸收额不卡）。

**锚**：仓库既有同族锚 = **料 ≈ 现货价 × 45%**（MK1 全线 / 民用 / 弹药 / 修理组件实测 44.8~51%，
是 2026-09-08 按"卖站净率 ≥20%"定出来的）。**不是新设的锚**，是把价动过的件补回同族线。

**改动**：`blueprints.ts` **46 张非武器蓝图**（护盾四件 / 装甲四件 / 矢量推进器 / 无人机三件 /
采集·货舱·打捞·陀螺·索敌·射速·锁定·维修·稳定器 的 MK2·MK3）按 **保持配方内各矿物比例**放大用量
（取整：用量 ≥200 → 50 的倍数，否则 10 的倍数）⇒ 料/价落回 **44.8~45.4%**。

**未动**：武器族（32.5~42%，属其族内一致带）、MK1/民用/弹药/修理组件（已在锚线上）、
**舰船蓝图（料/价 22~35%、毛利 354%——本次不在范围内，工具已用 ⚠ 标出，待船长定夺）**、
所有价格、`buildSeconds`、技能。

**效果**：制造毛利率区间 **78%~2625%（34 倍）→ 78%~≈123%**。示例（变现口径，无技）：
`bp-armor-plate-3` **222 万 → 73.5 万 ISK/h**（料/价 4.5% → 45%、毛利 2098% → 122%）；
`bp-hullrep-1` **442 万 → 188 万 ISK/h**（料/价 17.8% → 44.9%、毛利 463% → 123%——
周期只 180s，单位时间收入仍偏高，但**毛利率已与同族一致**，属"短周期件"特征而非失衡）。

**连带**：这些线的矿物需求涨 3~15 倍 ⇒ 精炼炉成为新瓶颈（一条 MK3 装甲线的料 ≈ 2.3 台满技能炉供料），
"挖矿 → 精炼 → 制造"的多环节闭环才真正立起来；矿物池（同日按产能扩容后）供给充足
（三钛池每小时可买 ≈109 万件 ≫ 单线需求 ≈20.7 万件）。

**工具**：`manufacture:econ` 每行新增「料/价 %」列（<40% 打 ⚠，用于日后改价/改配方时复跑核对）。
临时 codemod（数值由数据自推、非手抄）与探针用完即删。

**验证**：typecheck ×4 + core **798/798** + content:check + desktop build 全绿；
`manufacture:econ` 复跑确认 46 张落回锚线、⚠ 只剩 3 张武器件（+ 舰船）；`liquidity:audit` 复核矿物池覆盖达标。
