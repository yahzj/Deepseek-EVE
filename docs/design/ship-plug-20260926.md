## 现行插件与方案规则

- 普通插件允许重复，每件扣一件库存、占一普通插件格，沿原公式叠加；T1~T5的5/4/3/2/1格、不拆换、带插件船不能入仓/挂售的限制不变。CPU插件保持80，不执行80→120提案。
- 增加中槽的插件每舰最多一件，增加低槽的插件另最多一件，两者可并存，按加槽字段判类型而非名字。旧重复配置保留最先安装件，其余完整免费退装备库；缩槽挤出的装备及超量机体沿原兼容口返还，不收费、不折黑匣、不毁物品。实际在途作业/战斗不改配置，到安全结束点幂等整理；整船回收也不重新装回违规重复扩槽。历史沉船与装配参考不是实际安装，不凭它们返库存。
- 战损与普通插件同区展示但数据仍分离，不占普通安装格、不能安装/卸下/交易/制造，普通维修不清除。我的舰队隐藏普通插件名/数/槽计与富卡，只留战损警告和真实装后属性；装配页和沉船记录仍可看普通插件。
- 沉船记录按原船型可保存高/中/低逐位和无人机到现有方案，普通插件仅参考，不自动安装；战损不进方案。每船型10套、同名覆盖须确认，缺船型拒绝，未知模块编号保留；原船不存在或残骸过期不影响有完整记录的保存。富卡显示当前目录基础属性，不虚构损毁时技能值。
- 黑匣当前族对应与价值见`weekend-invasion.md`及市场文档，不把后文早期8000万当当前价。普通残骸插件逐件换匣、主动拆船插件退库、整船成功回收保留普通插件是不同路径，分别按真实入口结算。

## 二、性质与槽位

- **就是装备**（同一套 `ModuleDef`），只是**不可拆、不可替换**；
- **插件槽绑船型**：**T1=5 · T2=4 · T3=3 · T4=2 · T5=1**；只有 T1~T5 有，无档船（采矿/货舰）**无插件槽**；
- **不可拆的落法**：装配页插件槽**无卸下按钮**；装了插件 ⇒ **不许进舰船仓库、不许挂市场卖**；
  **唯一失去途径 = 船被打沉**（现状：船沉时装配件一并遗失、不回装备库）。

## 三、产线 · 声望 · 市场 · 打捞

- **图纸**：**找章鱼人用声望兑换**；声望来自**击败入侵后的贡献占比**，单场 **0~15 点**；旧门槛数值**一律不动**；
- **生产**：组装机造，**每件消耗黑匣 ×1**；组装机门类筛选**新增「舰船插件」一档**；
- **市场**：插件与图纸**当前不可见**，但**市场卡照做并备注**（`unreleased` ＋ 备注），日后要开只删标记；
- **打捞**：自己残骸里的插件**按数量直接回收成黑匣**；与"其余件逐件掷骰"**两本账互不干扰**。

## 四、口径明细（船长裁决）

| 问题 | 裁决 |
| --- | --- |
| 被攻击概率增加 | **增加被选中的权重**（不是"更容易被打中"） |
| 被攻击概率减少 | **减少被选中的权重**（**不是闪避加算**） |
| CPU 增加 | **单纯增加 CPU 预算**（不是占用 CPU 作为代价） |
| 多件递减 | **不吃**——不可拆的固定件，装 5 件就是 5 件全额 |
| 固定值分档 | **不分档**，全船同一套固定值（已知后果：T1 收益远大于 T5，船长接受） |

## 五、不做 / 边界

- **不做**：闪避插件（船长改判）· 插件的拆卸与替换 · 插件上市 · 无档船的插件槽；
- **不动**：现有高/中/低槽位布局与槽位契约 · 旧声望门槛数值 · 黑匣现有掉落（旗舰击毁必掉 ×1）；
- **唯一碰存档结构的地方**：两条 +1 槽会把某类槽位顶到 **8 格**，而清洗器现为 `slice(0, 7)` ⇒ 同步抬上限。
