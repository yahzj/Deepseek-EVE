## 一、诊断：一个「族」字被当成三个互不相干的意思用

| # | 玩家看到的写法 | 代码里真正的含义 | 玩家有没有被告知？ |
| --- | --- | --- | --- |
| **A** | 「**武器族**加成」「**本族**武器单发 +12%（装**别族**武器无加成）」「**同族**里能装得最多的一档」「与**武器族**专精乘算」 | `ShipDef.weaponFamilyBonus` 的键 = **伤害类型**（kinetic / explosive / plasma） | ❌ **从没定义过**——玩家在界面上只见过「动能 / 爆破 / 能量」「动能炮 / 导弹架 / 激光」 |
| **B** | 「**采矿舰族**专精驾驶」「**航运族**舰船」「**矿族**的产量顶点」「**武装舰族**的量产主力」「**机库族**」「**巨构族**」 | `ShipRole`（industrial / armed / armored / hauler）等**自己舰船的类别/套系** | ❌ **从没定义过**——界面上这套叫「**采矿舰 / 武装舰 / 装甲舰 / 货运舰**」（舰队筛选第二行） |
| **C** | 「**敌族**」「**族徽**」「**五族**专属装备」「整趟都是**这一族**」 | 敌方**势力**（海盗 / 武装拾荒者 / 异形生物 / 守墓古舰 / 泰坦巨构 / 鱿烬亡军） | ✅ **有**——这是玩家已熟悉的说法（公告与洞内界面都用它） |

⇒ **误导的根因 = A、B 两类把"族"当内部键名直接印给玩家**，而"族"在玩家侧已经被 C 类占用了。修法 = **把 A/B 两类的"族"字去掉**（正字为"类型 / 舰种类别"），**C 类保留**（那是游戏设定词，不是开发字眼）。
