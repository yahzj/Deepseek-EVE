## 一、船长原话（照抄）

> 「**鹦鹉螺的槽位改成3/4/4，电子舰新增特性，削减敌人15%的武器射程，可以乘法叠加，与敌人的射程增加效果
> 做加法处理。（比如10000m射程，我方一艘电子舰，对方拥有射程+50%，那么对方实际射程为13500.）
> 射程最短只能削弱到3000m（不足3000m的无法被削弱）。**」

三问三答（船长 2026-09-18 定案，全取甲）：

| 问 | 裁定 |
|---|---|
| 多艘叠加 | **甲**：削减率**先乘法合成** `r = 1 − Π(1 − vᵢ)`，**再与敌方增程相加**：净倍率 = `1 + 敌方加成 − r` |
| 作用面 | **甲**：**敌方全部武器**——舰体武器（炮台/导弹/激光，走 `foeGunMaxRangeOf`）**＋ 机群放飞射程**（走 `foeDroneRangeOf`） |
| 鹦鹉螺槽位与契约冲突 | **甲**：给 `sh-nautilus` 一条**白名单豁免**（官方武装舰「高槽 ≥ 低槽+1」那条弱断言），其余官方舰照旧受约束 |

## 二、现状（读码取证）

- **电子舰** = 子分类 `subClass === '电子舰'`，全仓**刚好两艘**（`sh-wh-a-frigate` 掠袭电子舰 · `sh-wh-d-frigate` 哨戒电子舰）；
  既有特性 = CPU +100（2026-09-16，**子分类硬判**那次是特例）。
- **船体特性**的现行纪律 = **数据字段驱动**（2026-09-16 起：「后勤舰」`repairPulseTargetsFleet`、「侦察舰」
  `stealthCpuMul` / `stealthIgnoresPropulsion`）⇒ 本次照此，新增 `ShipDef.foeRangeDebuffPct`。
- **敌方射程只有两处算法**（各自的注释都写明"单一真相源，开火判定与界面标签共用"）：
  ① `combat.foeGunMaxRangeOf(b, unit, w)`（舰体武器，受击增程 `foeGunRangeMulOf` 在此合成）；
  ② `combat.foeDroneRangeOf(b, w)`（敌方机群，吃 `battle.foeDroneRangeBuff`，E 族 ×4）。
  ⇒ 本次削减压在这两处，**开火门 / 距离衰减 / 战斗界面射程标签自动跟随**，不新增第三份算法。
- **鹦鹉螺** `sh-nautilus` 现 `slots = { high: 4, mid: 4, low: 3 }`（**11 槽**，`OFFICIAL_SLOT_ALIGNED` 名单内 ⇒
  必须恰好等于 T3 默认线 11）；改 3/4/4 **总数仍 11** ✓，但会撞
  `content-check.ts:1394`「**官方武装舰 高槽 ≥ 低槽 + 1**」（3 < 4+1）⇒ 按船长裁定加白名单豁免。

## 三、口径（本次落码）

1. **削减率合成**：编队内每艘带 `foeRangeDebuffPct`（电子舰 = 0.15）的船贡献一个因子 ⇒
   `r = 1 − Π(1 − vᵢ)`（1 艘 15% · 2 艘 27.75% · 3 艘 38.6%…）。
2. **与敌方增程做加法**：`净倍率 = 增程倍率 − r = 1 + 敌方加成(%) − r`。
   船长例子：基础 10000、敌方 +50%、我方 1 艘 ⇒ 10000 × (1.5 − 0.15) = **13500** ✓。
3. **地板**：`基础射程 < 3000m ⇒ 完全不削`（只吃它自己的增程）；否则结果**下限 3000m**（`FOE_RANGE_DEBUFF_FLOOR_M`）。
   `净倍率` 先夹到 ≥ 0（防负数射程）。
4. **只动最远射程**，近界（近盲带）不动 —— 与既有「受击增程」口径（船长选乙）保持一致。
5. **落点**：战斗建档与**每拍**都把 `battle.meFoeRangeDebuff` 按当前编队重算（运行态、不随档 ⇒
   读档/中途换编队都不会陈旧）；两处射程函数读它。
6. **界面**：信息/装配页「船体特性」栏加一条（字段驱动，与侦察舰/后勤舰同栏同源）。
7. **鹦鹉螺**：`slots` 3/4/4（总数仍 11）；`content-check` 的官方武装舰弱断言加 `sh-nautilus` 豁免（写明理由）。

## 四、不做 / 边界

- 不动我方武器射程、不动敌方近界、不动敌方伤害/命中/装填；
- 不动既有「受击增程」的**触发条件**（D 族仍按"射程外命中"触发、E 族机群仍按"被打中一次"触发）；
- 不给电子舰加别的效果（本次只有这一条特性）；不改电子舰的数值/槽位/价格。
