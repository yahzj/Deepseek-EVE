# V12a 设计：星图 v2 定稿（20 星系 × 27 航线 + 布局编辑器）

> 状态：**已确认**（用户 2026-09-04 确认：布局以船长在编辑器内排版为准，含一处通路调整；
> 编辑器使命完成后从玩家界面隐藏，保留为开发工具）。
> 影响包：`packages/data/src/universe.ts`（内容数据，无存档结构变更）。

## 一、背景

星图从 8 星系扩到 20 星系（由近及远 3 段主干 + 中段 2~3 分叉），悬赏目标扩到 16 个、
采矿带 17 条全部挂星系（galaxyId）。为让"图上位置"可调整，桌面端内置了**星图布局编辑器**。

## 二、布局编辑器（开发工具）

- 入口：星图下方「✎ 布局编辑」（默认隐藏）。
- **启用开关**：DevTools 执行 `localStorage.setItem('whale-idle:dev-layout','1')` 后刷新页面；
  关闭即从界面移除入口（代码保留，可随时再开）。
- 能力：
  - 拖拽星系圆点（坐标四舍五入存本地覆盖 `whale-idle:starmap-layout`）；
  - **通路交叉实时检测**：编辑中交叉的航线画红线 + 交叉点标记；非编辑态按钮显示「有通路交叉」角标；
  - **自动整理**：确定性模拟退火最小化交叉数（锚定当前位置 + 位移惩罚 + 节点最小间距），
    同一输入可复现；实测默认代码布局 26 处交叉 → 2 处，耗时约 100~200ms；
  - **撤销整理**：回退到最近一次自动整理前；
  - **保存并复制 JSON**：把 20 个星系坐标导出到剪贴板，回传给开发者合入默认布局；
  - **重置默认**：清除本地覆盖。
- 交叉判定与几何助手全部实现于 `apps/desktop/src/renderer/src/panels/Expedition.tsx`。

## 三、默认布局定稿（2026-09-04 合入）

- 20 星系坐标 = 船长编辑器导出 JSON（见 `universe.ts`，含母港 45,54 起手位）；
- **通路调整（船长指定）**：原「星尘荒原 → 暗星坟场」改为「**星尘荒原 → 红环航道**」；
- 几何复核：剩余 1 处交叉（碎晶带–烬火星区 × 星髓迷宫–奥罗荒环）——**船长确认无视，保留原样**；
- 校验：`npm exec tsx tools/content-validate.ts` 全绿（坐标画布内、hub 可达全部星系、
  边引用存在、节点间距 ≥52px 无名称重叠）。

## 四、后续改布局的流程

1. 启用 dev 开关 → 编辑器拖拽/自动整理；
2. 点「保存并复制 JSON」，把 JSON 发开发者；
3. 开发者合入 `universe.ts` 坐标（如需通路增删也一并说明），跑 content-validate 后交付。
