## 一、关闭铁人模式的警告弹窗

- **落点**：`panels/SaveManager.tsx`。原先「关闭铁人模式」是**按钮变红 + 再点一次**那套两段确认
  （提示只写在按钮 `title` 里）⇒ 现改为**点一次即弹警告弹窗**，真关在弹窗里点「确认关闭」。
- **弹窗结构**：与站内其它确认弹窗同一套（`.app-modal-mask` / `.app-modal` / `.app-modal-head` /
  `.app-modal-body`，对齐 `WormholeScan` 的"放弃确认"写法）—— 点遮罩或「✕ 关闭」都等于放弃。
- **文案两条**（新 id）：`ui.Ironman.040`「关闭后无法再次开启铁人模式。」＋
  `ui.Ironman.041`「铁人福利同时失效；代次与已获得的徽章保留。」

## 二、未选择旧档的模式选择弹窗

- **新增件**：`panels/ModeChoice.tsx`；由 `App.tsx` 在 `onboarding.step !== 0`（＝**进游戏之后**）时挂载。
- **判据（唯一）**：`engine.modeChoiceNeeded()` → core `ironmanModeChosen(state)`
  ＝ 曾开过铁人（`ironman.sinceWallMs` 有值）**或**已选过普通（`state.modeChosen`）。
- **补的是谁**：① 铁人模式上线（2026-09-23）之前就存在的老档 ② 序章点了「跳过」的档 ③ 中途导入的档
  —— 这三类人**从来没被问过**（原先只有新档序章问一次）。三者在存档里原本**形态完全一样**，
  所以这次必须新增一个标记字段（见下）。
- **强制二选一**：遮罩无 `onClick`、无关闭键 ⇒ 只能点两张卡之一。
- **选铁人失败不静默放行**（如该档已关闭过铁人）：把引擎给的错误显示在框内，玩家可改选普通。

### 存档面：新增 `state.modeChosen?: boolean`

- **为什么必须有**：存档里原本区分不出「选过普通」「序章跳过」「老档」——三者都没有 `ironman` 字段
  ⇒ 不新增标记，弹窗会对已经选过的人反复弹。
- **口径**：**只在 true 时落键**、可选字段、**不升存档版本**（零迁移；老档快照往返逐字不变）。
- **谁写它**：**只有"选普通"那一刻**（core `markModeChosenAsStandard`）。
  选铁人**不写**——`ironman.sinceWallMs` 本身就是记录，`ironmanEver` 判得出来。
- **落笔两处**（约定 §二 规则）：写入点 `engine.chooseStandardMode()` ＋
  `save.ts` 的 `normalizeState` 白名单。
  ⚠ 漏了白名单那行 ⇒ **每次读档都重弹模式选择框**（与 `salvagerGift` 那次同类事故）。
- **序章那两张卡也跟着落账**：`PrologueScreen.chooseStandard()` 现在会先调 `engine.chooseStandardMode()`
  再走起名/收尾 ⇒ 新档在序章选过普通之后，进游戏不会再被问一次。
