# 支援呼叫装置 · 守墓王座舰（陵墓王庭）（2026-09-19）

**状态：进行中**（船长验收 + 合入 main 后走归档三步：并入 roadmap/词典 → 删本文件 → 重跑 `docs:index`）

## 一、船长原话（照抄）

- 「**战斗开始20秒后，增援2艘幽灵舰。如果对方在自己最远射程之外时，增援2艘静滞卫舰。**」
- 「因为延迟到场，所以需要一定补偿。**卡计算的实际威胁要*1.1**」
- 逐项确认：**补偿口径 = 甲**（照字面乘在**威胁**上）· **「支援呼叫装置」挂舰级** · 二选一在**20 秒那一刻判一次**
  · **原地入场** · **打死在场者即胜**（未到场的不计）· **开战提示 + 到场提示 + 卡面写明**

## 二、机制（落点）

| 项 | 口径 |
|---|---|
| 装置 | 「支援呼叫装置」`foe-mount-support-call`（**一件一类效果**：`supportCall { delaySec: 20, threatMul: 1.1 }`） |
| 挂载位 | **舰级** `foe-d-throne`（守墓王座舰；只服务本卡、不外借 ⇒ 洞外零影响） |
| 呼叫者 | 挂该件的单位（= 王座舰），且必须在**开战即在**的编成里（体检会拦"自己带 `enterAt`"）；**被击毁即不再呼叫** |
| 判定 | 战斗时钟 ≥ `delaySec`（20 秒）**判一次**：`b.distanceM ≤ 呼叫者当时有效炮台最远射程` ⇒ `inside` 支；否则 `outside` 支 |
| 两支 | 由卡面条目声明（`enterAt` ＋ `enterBranch`）：`inside` = 幽灵舰 ×2、`outside` = 静滞卫舰 ×2；**判完锁死**（另一支本场不再出现） |
| 锁存 | **不占存档字段**——由"哪一支已入场"反推（含尸体）⇒ 读档续战天然可续；判定点 = 战斗时钟 ≥ 20 秒后的第一拍 |
| 入场 | **原地入场**（`foeReinforceReopenFrac = 0`）＋ 入场演出与哑火窗口（沿用既有 `seedUnit`/`enteredAtMs`） |
| 判胜 | **打死在场者即胜**（未到场的增援不参与判胜）⇒ 20 秒内秒掉王座舰，援军不来、战斗立即结束 |
| 提示 | 开战推「敌方呼叫增援：20 秒后抵达」；到场推「敌方增援抵达：幽灵舰 ×2 / 静滞卫舰 ×2」（画面顶部提示位，与"受击增程"同处） |
| 总开关 | `foeReinforceEnabled: false → **true**`；旧「增援机制未启用契约」改写成「**支援呼叫装置契约**」 |

## 三、数值（甲案）

**份额**（占本卡总量）：王座舰 **68% 血 / 72% 火力**（开战即在）；任一支援军 **32% 血 / 28% 火力**（20 秒后）。

**卡面条目倍率**（本卡 5 单位 ⇒ 多舰补偿 `2N/(N+1)` = ×5/3，按引擎惯例折进倍率）：

| 条目 | hpMul | dmgMul | 设计单发 |
|---|---|---|---|
| 守墓王座舰 ×1 | 0.68 | 0.43 | 181 |
| 幽灵舰 ×2（inside） | 0.68 | 0.44 | 35 |
| 静滞卫舰 ×2（outside） | 0.25 | 0.19 | 39 |

- 两支账面相等：血 **587.52 / 585**（+0.4%）· 火力 **17.5 / 17.7 DPS**（+1.3%）——体检守恒契约 ≤3%。
- ⚠ 静滞卫舰装填 4,400ms（比幽灵舰慢）⇒ 单发取 **39** 才是"火力相等"（草案写 36 是"单发相等"，实际偏弱 9%）。
- 血/火力比 `r = 29.30`（改动前的单舰卡 29.21，+0.3%）⇒ **层的血/火力切分也不变**。

**派生记账（关键）**：互斥的两支**只按较重的一支**计入"自然总量"（`wormholeSkippedBranch`，血与火力两侧同源）。
否则没到场的那支也白占预算 ⇒ 本卡比同层同档弱约 24%，破「同层同档血×火力恒等」红线。
实测：`wormholeNaturalHp(卡) = 1838.72`，改动前的单舰卡 = 1840（**+0.07%** ⇒ 红线守住）。

**延迟补偿（口径甲）**：本卡派生威胁 = `round(层威胁 × 1.1)`（层 1 = 50 · 层 4 = 66），**显示与预算同源**；
该链上 `血/火力 = √(T·r) / √(T/r)`、`T ∝ 预算²` ⇒ 血与火力各 **×约 1.16**（实测 1.163；八层一致 1.158~1.166）。

## 四、边界与影响面

- **洞外零影响**：只有这一张隐藏卡用该装置；开关打开后其余卡**一张都没写** `enterAt` ⇒ 逐字零行为变化。
- **存档零迁移**：不新增任何存档字段（到场/分支都由 `battle.units` 的 tag 反推）。
- **近防炮/冲锋的威胁门槛（≥60）不受影响**：本卡只在层 4+ 出现，层 4 起威胁本就 ≥60（已核）。
- 面板「本层威胁」仍读**层**的值（×2 显示口径），不体现本卡的 ×1.1 —— 那是"层"的读数，不是"卡"的读数。
- 体检另动一处：**卡面主体判定排除支援分支条目**（`enterBranch`）——否则幽灵舰/静滞卫舰的族内 8:2
  会撞王座舰的 6:4 白名单（混伤白名单契约与舰级契约两处）。
- **多舰补偿 `2N/(N+1)`**：洞内派生会把总量归一 ⇒ 不产生叠加（全局复核仍挂着，船长未定）。
