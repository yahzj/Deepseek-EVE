## 三、复现命令（改值后重跑即更新文档）

```bash
npx tsx tools/wh-family-review.ts --write    # 按族总览（装备全字段 + 舰船特色与加成）
npx tsx tools/wh-ships-review.ts --write     # 舰船审查表（逐艘数值 + 同档对照 + 越界标注）
npx tsx tools/wh-weapon-dps.ts               # 武器输出对比（虫洞武器 vs 制式 MK3）
npx tsx tools/wh-ship-tune.ts                # ⚠ 只对**未调过的基线**运行（检测到 subClass 即拒绝，防二次叠加）
```

**四连**（本批每次提交均绿）：`npm run typecheck`（4 包）· `npm run test -w @whale/core`（**1232 用例**）·
`npm run content:check` · `npm run build`。

## 六、已知取舍（留档，避免被当成 bug）

1. **掠袭破片炮主段 DPS 只有 MK3 的 0.85**，靠**副段**拉到 ×1.28——副段在层克制下有波动（打装甲型更高）。
2. **孢子导弹巢单体 DPS 仍低于 MK3**（×0.69 → 命中补到 0.6 后略升）；它的价值在"全体攻击 + 13.5 km 覆盖"。
3. **陵卫连装炮每发吃 2 弹药** ⇒ 按弹药计的续航与 MK3 持平，账面 DPS ×2.05 不等于续航也翻倍。
4. **编队接近速度 = 全队存活舰 `combatSpeed` 的平均**（`combat.ts:3871`）⇒ 单舰速度惩罚会让**全队买单**（D 组的速度惩罚已因此移除）。
5. **锁定范围 / 信号半径 = 纯展示**（全引擎零消费）；**扫描分辨率**只进悬赏冷却（经济向）。给舰船做"强增"前必须先确认字段有消费点。
