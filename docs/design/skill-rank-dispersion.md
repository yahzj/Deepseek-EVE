# 技能 rank 分散化：相似效果错开级别（已确认 2026-09-08）

> 状态：**已确认并落地**。船长观察：多个相同 rank 的技能效果相同/相似（同乘区双修线与
> 跨域同型技能），希望类似效果尽量分散在不同级别。确认口径（三轮澄清）：
> ① 处理范围 = 同效成对（拆半双修线）与跨域同型技能；② 保留双技能结构，只改 rank，
> 不动数值/接线/文案；③ **表 1（同值成对）用上调错开；表 2（同乘区异值补强对）放弃上调、
> 改为下调错开**；无市场/战斗域的额外偏好（早期草案含"市场/战斗整体上调"，2026-09-08 撤销）。
> 训练总时长不守恒；rank 为目录字段，存档零迁移（已学等级原样）。

## 机制背景
单级时长 = 档底(60s/60s/155s/696s) × rank × 2^(级−1)：
r1 → Lv5 ≈1.4h；r2 ≈2.9h；r3 ≈11.2h；r4 ≈67h。
