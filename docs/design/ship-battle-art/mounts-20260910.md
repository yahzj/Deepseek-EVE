## 一、背景与决策

船长需求：尾焰的数量和位置都要和引擎喷口对齐；开火点挂在符合炮口的位置。
此前资产表（SHIP_ART 25 玩家舰 / FOE_ART 7 敌族，240×110 画布）只转录了图形，
引擎口/炮口均未落数据——尾焰是"一焰通吃"单点固定，开火点走舰艏前缘单锚（NOSE_MAIN/ESC）。

已确认决策（2026-09-10）：
1. **范围**：玩家 25 舰 + 敌族 7 型全部转录挂点；
2. **无原生炮**（矿舰/货舰/炮塔朝上类）：muzzles 留空，渲染回退舰艏前缘锚点；
3. **焰形**：每喷口同尺寸尾焰（不按数量缩放）；
4. **弹道与闪光**：都从真实炮口出（同源自洽）。

## 二、数据与口径

新文件 `apps/desktop/src/renderer/src/ui/shipMounts.ts`：
- `engines`：每枚喷口"口沿"（开口左缘中点，画布本地坐标）；尾焰菱形右尖恰好抵住该点向左喷。
- `muzzles`：每门原生炮管口端 / 导弹箱发射口前端中点；多炮口在战斗中逐发轮换。
- `mountsOf(shipId, foeKey)`：取挂点；未收录返回 undefined（调用方各自回退）。

## 三、渲染接线

1. **ShipSprite**：`engine=true` 时按 engines 逐口挂焰（`<g translate>` 隔离，避免 CSS 脉冲
   transform 覆盖）；焰形右尖距喷口口沿留 **5 画布单位空隙**（`EXHAUST_GAP`，2026-09-10 船长：
   完全贴口不美观）；无挂点数据回退旧单焰；engines 空（C 异形）不画焰。
2. **战斗（BattleScreen + battleViewCore）**：开火事件按发射者挂点取 muzzle（多炮口逐发轮换，
   计数按 'me'/敌方 tag 分键），弹道起点与炮口闪光同源 = 画布偏移 × (显示宽/240)；
   无炮/无数据 → 回退 NOSE_MAIN/NOSE_ESC 舰艏前缘（既有逻辑原样保留）。
3. **舰船状态窗（ShipStatusWin）**：交火火光改为舰形同画布（240×110 viewBox，叠于舰层上）内
   按 muzzles 逐口双相位闪烁；空表回退舰艏前缘单点 (215,55)。

已知取舍：
- 射程弧/枪口尺仍锚舰艏中心线（视觉校准件，不动）；
- 舰艏炮口超过画布右缘 240 的舰（大白鲨 242/锤头鲨 246 炮管本就被画布裁剪）火光右半亦随裁剪，
  与既有炮管观感一致；
- 敌我"背向拉开时照常开火"的既有画面语义（弹道方向不随翻转）未改，只换起点位置。
