# 敌列阵形「斜向菱形」（2026-09-12 船长定；状态：**已确认并实现**）

> 船长原话链：**「我想让敌舰排成 2X2 的菱形样式。」** →（三读法里）**「斜向菱形，第二排向右偏移」** →
> **「我看了下 是丙」** →（竖向两条路里）**「丙② 第一排不动 / 第二排下移 78」** → 「确认开工」。
> **取代** 2026-09-11 的「错列雁阵（前排＝首舰/头目档原位、其余上抬 54）」口径——那份口径**作废**，
> 见 `battle-formation-20260911.md` 顶部横幅。

## 一、阵形规则（数值精确）

- **按视觉行序交替分两排**：第 1/3/5… 艘 = **第一排**（原位）；第 2/4/6… 艘 = **第二排**；
- **同排内按列从左到右**；列宽 = 该列最宽舰，列间距 = `ROW_GAP`(4px)；
- **第二排右移半个列间距**（`shift = round((列宽₀ + 4) / 2)` ＝ 170 舰宽时 **87px**）、
  **下移一个舰高**（`drop = round(max(舰高))` ＝ 78px）；
- **第一排严格原位**：`y = TOP + rowH − 舰高/2`（＝改动前的行底 132.2，逐像素不变）；
  第二排 `y = TOP + 2×rowH − 舰高/2`；
- **单舰编成只有一排 ⇒ 逐像素不变**（教学卡/坟场/穹顶/碎晶…）。

## 二、两条硬约束（决定了数值只能这么取）

1. **舰体是实心的**：两排水平错开 < 一舰宽（170）时，必须**竖向拉开 ≥ 一舰高**，否则两排舰体互相压住
   （验算：右移 87 + 竖向仅 54 ⇒ 横向重叠 83px、竖向重叠 24px，会实打实叠住）；
2. **上方只有 `LAY.TOP`(54px) 留白**（2026-09-10 给无人机上凸弧留的）⇒ 第二排**不能往上抬 78**（会溢出泳道被裁）
   ⇒ **往下**排；好处是第一排完全不动（船长 2026-09-11 明确不喜欢"前排被顶下去"）。

## 五、已知取舍

1. **编队向下多占一个舰高**（第二排落在第一排下方）：窄窗口（泳道 `min-height: 260`）下第二排的血条可能被裁
   ——与本改动前的"后排上抬"相比，占高从"向上 54"变成"向下 78"；若船长觉得太靠下，可改"两排各偏 ±39"（居中版）。
2. **收拢时可能换排**：敌舰被击毁、尸骸演完收拢时，幸存舰按**视觉行序**重排 ⇒ 可能从第一排换到第二排
   （与既有"整批尸骸演完一起收拢"同源，是同一次重排）。若要"幸存舰不换排"，可改成按 tag 序号定机位（一格留空）。
3. **第二排没有浮空舰名**（其上方是第一排舰体）⇒ 舰名与「◈ 锁定」标记在该舰**血条标签**里（第一排照旧浮空）。
4. **多波增援**：按行序交替分排（第 n 波无特殊对待）＝船长此前选的「不分波」；若日后要"增援整排再降一层"，需另立口径。
5. 第一排仍是"底边对齐"（同排内较矮的舰沉底）——与改动前一致。
