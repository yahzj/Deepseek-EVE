## 实施闭环

1. 统一配置与查询：每型舰船静态成本、容量、声望解锁、最多12舰和旧机制回滚开关；所有入口与界面读同一导出，不把指挥成本写成每场货币消耗。
2. 参战名单：意向名单与出勤快照分离，出发前逐舰预检，参战实例在战斗和返航期间均锁定；不静默缩编、替船或临时从基地召僚舰。
3. 战斗接线：普通远征/赏金/入侵清缴、实际随行舰的遭遇、信号空间手动/自动和入侵旗舰统一预检；旧在途按快照完成，旧4舰分支由独立开关回归验证。已停用的AI远征不恢复。
4. 逐舰收尾：弹药与修理组件、无人机损失、装甲/结构写回、沉船/残骸、主控更换、存活舰返航/卸货、冷却与循环均按出勤名单核算；目标奖金、声望和首胜每场一次，不乘舰数。
5. 敌舰同时上限：初始波、增援、复活、召唤均须服从12舰在场上限；超过上限的舰作为待入场队列保留，不直接裁掉敌人、火力预算、奖励或波次。敌无人机不是舰船，不混进12艘舰体计数。
6. 界面与性能：新大编队布局保留舰型视觉区分和完整逐舰血量/详情，紧凑矩阵与战术距离共用锚点；不靠截断或整屏缩小藏船。昂贵舰体与事件层隔离，隐藏窗口停画；实际测4对4、12对12及机群压力。
7. 验证：专项、类型、内容、本地化、架构、布局、构建、存档往返/穷尽、回滚用例、原生几何与帧率。集中全量回归时点沿仓库现行要求，公告先准备待审稿，不擅自写入发布表。
