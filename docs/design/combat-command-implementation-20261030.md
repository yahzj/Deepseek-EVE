## 已确认范围

- 正常路径的玩家战斗统一采用指挥成本；信号空间和入侵旗舰不再正常运行独立4舰规则，但旧机制必须保留为可测的回滚路径。
- 新编队最多12艘，同时满足指挥容量；12是数量上限，不自动把已定容量125提高到能带12艘重舰。
- 战斗画面承载敌我各最多12艘舰船，并实测性能；不把只测Node引擎当作窗口不卡顿的结论。
- 本需求实际涉及战斗、远征/遭遇、舰船/技能、信号空间及持久化；这些是本次功能必需的连带范围，不以此授权其他系统重构。

## 实施闭环

1. 统一配置与查询：每型舰船静态成本、容量、声望解锁、最多12舰和旧机制回滚开关；所有入口与界面读同一导出，不把指挥成本写成每场货币消耗。
2. 参战名单：意向名单与出勤快照分离，出发前逐舰预检，参战实例在战斗和返航期间均锁定；不静默缩编、替船或临时从基地召僚舰。
3. 战斗接线：普通远征/赏金/入侵清缴、实际随行舰的遭遇、信号空间手动/自动和入侵旗舰统一预检；旧在途按快照完成，旧4舰分支由独立开关回归验证。已停用的AI远征不恢复。
4. 逐舰收尾：弹药与修理组件、无人机损失、装甲/结构写回、沉船/残骸、主控更换、存活舰返航/卸货、冷却与循环均按出勤名单核算；目标奖金、声望和首胜每场一次，不乘舰数。
5. 敌舰同时上限：初始波、增援、复活、召唤均须服从12舰在场上限；超过上限的舰作为待入场队列保留，不直接裁掉敌人、火力预算、奖励或波次。敌无人机不是舰船，不混进12艘舰体计数。
6. 界面与性能：新大编队布局保留舰型视觉区分和完整逐舰血量/详情，紧凑矩阵与战术距离共用锚点；不靠截断或整屏缩小藏船。昂贵舰体与事件层隔离，隐藏窗口停画；实际测4对4、12对12及机群压力。
7. 验证：专项、类型、内容、本地化、架构、布局、构建、存档往返/穷尽、回滚用例、原生几何与帧率。集中全量回归时点沿仓库现行要求，公告先准备待审稿，不擅自写入发布表。

## 待定细节

逐船首轮表有33种报价、1种战斗泰坦待定，另12种作业/运输船待定；构件鱼雷、机群与低速重装报价仍有已测风险。本次统一预算不得让这些舰型因缺字段免费参战，也不靠改舰船血量/火力来迁就成本；具体实施表需在本批定稿。

单舰是否始终允许驾驶已有重舰、累计声望账本、首条指挥技能能否提前训练、普通遭遇的随行来源，以及自动撤退触发后整队还是逐舰返回，需要在实施总结中明确，不利用「所有战斗」把未出勤舰瞬移进场。

信号空间既有质量、舰级禁入、回合与科技门槛是否仍与新预算并用，不能把保留回滚路径误解为删除所有其他玩法约束。默认建议不因本次数量改造删除非舰数规则。

## 改造前基线

正式工具`npx tsx tools/battle-twelve-baseline.ts`从合法初始状态独立合成，用正式MK2装配入口和战斗引擎，测1/4/12舰对等敌舰、无机群/有机群、3个确定种子，共18种压力组合。每例推进30秒战斗、300个100毫秒步；仅用夹具增加双方容量维持压力，不改生产定义，不走生产预算门槛，12巡洋是压力场景，不冒称合法125点编队。

输出`tools/_ui-artifacts/battle-twelve-20261030/before.json`：

- 12对12无机群每步95分位约0.53至0.59毫秒；有机群约0.75至0.78毫秒，三次最大值约1.09至3.89毫秒。它是Node引擎读数，不含React、DOM、布局、绘制、GPU及真实IPC成本。
- 现有布局函数按12巡洋计算，在1600×900有8艘我舰越界，1280×720有9艘越界；390×844有11艘我舰和6艘敌舰越界。不能只放开编队数量而沿用旧布局。
- 基线脚本严格类型检查通过，需显式带桌面`env.d.ts`声明；首次未带时产生了宿主类型缺失，不是修改生产声明解决。
- 最终验收还须在生产构建的独立隐藏Electron窗口里测帧耗时分布、长任务、内存、节点/特效数量、进退场及最小化/重开，不从上述结果宣称不卡顿。

UI技能定向检索中，`compact collection selection feedback`命中的集合换行规则适合准备名单：所有选中项可达，不固定单行裁掉。触觉和AI反馈两条不适用。React性能检索的昂贵组件隔离、SVG外层动画及窄依赖可用于本次实现；技能不代替真实性能测量或船长观感验收。
