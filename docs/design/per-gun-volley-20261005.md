# 逐炮命中与敌方炮数

> 状态：已实现并本地合入，待验收（三号 · verify · 2026-10-05）
> 船长原话：「我希望修改为每门炮单独计算，并给敌人添加炮的数量，让敌人不再是只有一发攻击」；「总伤害保持不变，并根据敌人势力设定添加炮数量……你可以先修改完炮数后给出你的优化方案」。
> 范围：战斗域的武器组逐炮结算、敌舰炮数登记、必要视图/工具/测试接线；不改命中闪避公式、不提高敌方总火力，不改小船血量或插件。本批完成后才提出小船优化方案。
> 待裁决：小船优化只作方案，尚无数值或公式实施授权。全流程游玩实测继续挂起。

## 实施口径

- 我方保留现有同型武器合并条目和装填/弹药账，开火时按count门各掷命中、各结算伤害。光束仍必中，无人机每架独立，不再合并一组伤害只掷一次。
- 敌舰新增gunCount，保留旧shotDmg为武器组每次齐射总伤；按炮数分摊伤害，整数余数均匀分配，Σ守恒。敌方炮数与原burst三连发是不同轴，每一连发都是一组齐射，装填/间隔/整轮总伤不改。
- 一组射击优先同一目标，目标被击沉后剩余炮重新选活目标；原集火/随机选靶模式保持。逐炮FX记录命中/MISS与实收伤害；按原步长同拍射击，80%齐射保险仍按整拍共用账，不能逐炮绕过。
- 保留旧聚合shotDmg/shotsByType和count的展示及DPS语义，不将敌群旧火力又乘gunCount；预估与威胁仍读守恒总量。混伤比例与无人机火力拆分不变。
- 光束、近防、多目标、连发、自加速、闪现禁火、受击阵列、护盾/免死、编队、存读档均纳入回归。标称总伤守恒不保证实际胜率完全相同，跨层克制/死亡换靶/触发粒度与随机消费随逐炮改变，必须报告实测差异。
