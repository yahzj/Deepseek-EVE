# B1 安全等级玩法化：低安遭遇 / 伏击（状态：已确认，实现中）

> 来源：roadmap B1。2026-09-04 两轮问答确认口径（Q1 混合形态 / Q2 三档结果池 /
> Q3 主控与 AI 都遇 / Q4 击退给少量缴获 + 区域停留船承担 / Q5 区域一次·停留船优先 /
> Q6 邀约 60 秒 / Q7 首次进入低安提示 + 手册「航行须知」分区）。

## 定稿口径

- **形态（Q1）**：离线（含大步离线结算）只走文字结算；玩家在线时命中遭遇有概率升级为
  「伏击待决」邀约——点「迎战」进入 V12 实时战斗（自动打完，横幅可观察），点「快速脱离」
  立即按文字三档结算；**60 秒（游戏时间）未响应自动按文字结算**（在线挂机与离线行为一致，
  超时判定用 gameMs，离线大步长天然瞬间超时，无需“是否在线”标志）。
- **结果（Q2 甲三档池 + Q4 缴获）**：按承担船火力与遭遇强度对比掷档：
  击退（胜面大：小概率仍受损）→ 少量 ISK 缴获；受损（耐久 −5%~15%，底 clamp 5% 且显著告警，
  绝不弃船）；被抢（小概率：丢至多 30% 船上货物，无货则丢少量钱包 ISK）。
- **触发面（Q3）**：主控（低安矿带采矿 / 低安星系胜利停留 / 低安悬赏远征途中）与 AI 副船
  （低安矿带采矿）都按暴露窗口掷骰；高安（sec ≥ +0.5）不掷。
- **承担规则（Q5 甲）**：同星系内我方在场船（停留船优先于作业船）承担事件，区域事件一次、
  事件后该星系进入 5 分钟区冷却（不叠加挨打）；无停留船时归触发作业船。
- **首次提示与手册（Q7）**：首次进入低安星系（经过/作业/停留）弹一次醒目提示并写日志；
  手册新增「航行须知」分区（低安规则 + 既有重要玩法口径摘要留档，后续新机制持续入档）。

## 数值骨架（初稿，实测后回调）
- 掷骰窗口 150s；窗口命中率 ≈ clamp01(0.01 + 0.05 × max(0, −sec))（sec=−1 → ~6%）。
- 遭遇强度 = 承担船火力 × 随机 0.75~1.35（低安越深略强）；文字三档与胜负均按火力对比推演。
- 战斗缴获 ISK = f(威胁)（与悬赏同量级小头）；受损上限单次 15%。
