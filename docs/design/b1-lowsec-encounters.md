## 定稿口径

- **形态（Q1）**：离线（含大步离线结算）只走文字结算；玩家在线时命中遭遇有概率升级为
  「伏击待决」邀约——点「迎战」进入 V12 实时战斗（自动打完，横幅可观察），点「快速脱离」
  立即按文字三档结算；**60 秒（游戏时间）未响应自动按文字结算**（在线挂机与离线行为一致，
  超时判定用 gameMs，离线大步长天然瞬间超时，无需“是否在线”标志）。
- **结果（Q2 甲三档池 + Q4 缴获）**：按承担船火力与遭遇强度对比掷档：
  击退（胜面大：小概率仍受损）→ 少量 ISK 缴获；受损（**2026-09-11 起：按敌人火力折算、装甲先吃**，
  见下节）；被抢（小概率：丢至多 30% 船上货物，无货则丢少量钱包 ISK）。
- **⚠ 2026-09-11 船长改口径（玩家反馈"副船遇袭耐久大幅下降后不会自动维修"）——以下取代旧条款**：
  1. **受损档旧口径作废**：旧文「耐久 −5%~15%，底 clamp 5%」不再使用（与敌群强度无关，且直接扣结构、
     装甲分文不动，与既有日志"被咬下一块装甲"不符——真 BUG）。现行 = **一口伤害 HP = 敌群火力 ×
     `encounter.hitFirepowerSec`（0.3 秒）**，敌群火力 = 威胁 × `battle.foeDpsPerThreat`（0.8）；
     施加时**先扣装甲、吸完再进结构**（层满值口径 = `hullLayerCaps`，与维修/修理组件同尺）；
     **结构底线 5% 保留**（绝不弃船）。标定：威胁 20 一口 4.8 HP / 威胁 48 一口 11.5 HP / 威胁 88 一口 21.1 HP。
  2. **结构低于 50% → 撤退**（`encounter.retreatHullFrac`）：遭遇了结时（击退/受损/被抢/应战胜负，全部判定）
     被袭船立刻收手返港**待命**——主控停下低安作业（采矿/打捞/扫描）并即时返航最近已建成站，
     副船中止 AI 任务召回（核心归还核心库）；**不自动维修、不自动再派**（回港后由玩家决定；
     副船结构 <50% 本就不能再派任务）。
  3. **迎战也有连续作战保险**：`fightEncounter` 给遭遇战写 `hullEscapeFrac = 0.5`（此前只有悬赏巡回场次有），
     本场结构损失过半即自动脱离——轻损退出、**无缴获、无额外扣损**（战斗内实际承伤照留），
     随后走同一条撤退口径，不会把船打到弃船。
  4. 撤退保险三项（`hullEscapeFrac` / `autoEscaped` / `escapeReason`）自 2026-09-11 起**随档保留**
     （此前 `cleanBattle` 未收录：战中重载保险凭空失效）。
- **触发面（Q3 + 2026-09-06 收敛）**：暴露只属"停留/就地作业"——主控（低安矿带**采掘中** /
  打捞**作业中** / 扫描**窗口** / 野外驻留＝掩护巡逻）与 AI 副船（采矿采掘中 / 打捞作业中 /
  掩护巡逻驻留）按暴露掷骰；**移动（航行/返航/转场途中）不暴露**——远征途中与各返航段不再掷
  （交火中也不暴露）；**只有低安掷**——2026-09-12 船长两条裁定（「将伏击掷骰阈值降低为0」＋「0也算低安」）：
  **低安 = sec ≤ 0（含 0）**，中安（0 < sec < 0.5）与高安一律不掷（判据 = `balance.encounter.lowSecMax`）。
- **承担规则（Q5 甲）**：同星系内我方在场船（停留船优先于作业船）承担事件，区域事件一次、
  事件后该星系进入 5 分钟区冷却（不叠加挨打）；无停留船时归触发作业船。
- **首次提示与手册（Q7）**：首次进入低安星系（经过/作业/停留）弹一次醒目提示并写日志；
  手册新增「航行须知」分区（低安规则 + 既有重要玩法口径摘要留档，后续新机制持续入档）。

## 数值骨架（2026-09-09 重锚后，实测后回调）
- 遇袭节奏（事件到点判定）：到点遇袭率 = **低安内**按安全等级线性——sec=0 → **5%** 基线、
  每降 1.0 → **+15%**（sec=−1.0 → **20%**；概率硬上限 `min(0.9)`）；扫描 ×1.5；
  5 分钟入场缓冲 + 5 分钟区域冷却；事件时机被遭遇占用即不再出随机事件。
  ⚠ 2026-09-12 归一：曲线零点 = **低安上限**（`lowSecMax`，现值 0）。**此前误取闸门值 0.5**，
  低安整体偏高 7.5 个百分点（−1.0 处实为 27.5%）——见文末「阈值改动」小节。
- 伏击敌群 = 事发星系可见悬赏敌群随机抽取（威胁 = 该卡威胁；无池不伏击）。
- 缴获 = 伏击敌群悬赏赏金 × **50%**（lootFracOfBounty；文字击退与全歼同额；不计首胜/声望）；
  胜利两路径向事发星系注入残骸密度 威胁 ×0.4。~~受损上限单次 15%（耐久底 clamp 5%）~~ ⇒
  **2026-09-11 改为：一口 = 敌群火力 × 0.3 秒、装甲先吃、结构底 clamp 5%（见上节第 1 条）。**

## ⚠ 更新（2026-09-04 v2：船长追加缓冲与时机占用）

- **到达缓冲**：每次进入低安"作业/驻留地点"后 **5 分钟安全期**（balance.encounter.entryBufferMs），
  期间绝不遇袭；在场连续计时（lowSecPresence 运行时维护，随在场状态增删）；扫描例外（即暴露、无缓冲）。
- **占用随机事件时机（触发融合）**：遭遇不再独立按窗口掷骰——改为随机事件每次到点时先判低安：
  我方有船在低安且已过缓冲（及区域冷却）→ 按星系安全度遇袭（sec=0 → 5%、sec=−1 → 20%，参数化）；
  命中 = 本次事件时机被遭遇占用（本段不再出随机事件）；未中 = 随机事件照常。**中安与高安 / 无暴露不变**
  （2026-09-12 起低安 = sec ≤ 0，见文末「阈值改动」小节）。
- 触发链：advanceEncounterWatch（在场维护+遭遇推进）先于 advanceEvents（到点调用 rollLowSecAmbush）。

## ⚠ 阈值改动（2026-09-12 船长两条裁定：「将伏击掷骰阈值降低为0」＋「0也算低安」）

- **口径**：**低安 = sec ≤ 0（含 0）**，只有低安掷伏击；中安（0 < sec < 0.5）与高安一律不掷。
  落码 = `EncounterBalance.highSecSafe: 0.5` → **`lowSecMax: 0`**（判据由 `sec >= 阈值 return`
  改 **`sec > 阈值 return`**，故 0 归低安）；`securityZoneOf` 的中安边界同步由 `v >= 0` 改 `v > 0`
  （中安 = 开区间 `(0, 0.5)`）；通讯 `lowSec` 触发器与体检死触发器守卫**都读同一个值**
  （此前各写死一份 `0`——负向验证时才暴露，已改单点）。
- **概率曲线归位（顺手修掉一处真漂移）**：公式 `p = 0.05 + 0.15 × min(1.5, max(0, 闸门值 − sec))`
  过去把闸门值 0.5 当零风险参考点 ⇒ 实际 sec=0 → 12.5%、−1.0 → **27.5%**，与本文件写的定义
  （sec=0 → 5%、sec=−1 → 20%）**差 7.5 个百分点**；零点改 0 之后曲线回到定义。
- **受影响星系（全 20 个）**：**会掷 12 个** —— 烬火星区 0.0 / 回音荒区 0.0 → 5%、奥罗荒环 −0.2 → 8%、
  星髓迷宫 −0.5 / 天底静区 −0.5 → 12.5%、裂谷深带 −0.6 → 14%、深渊之门 −0.7 / 蜃影星系 −0.7 → 15.5%、
  星噬之口 −0.9 / 虚海边缘 −0.9 → 18.5%、暗星坟场 −1.0 / 穹顶墓园 −1.0 → 20%；
  **不再掷 4 个（中安）** —— 红环航道 0.1 / 碎晶带 0.2 / 灰霾带 0.4 / 灯塔长廊 0.4。
- **连带**：日板抽地点的分区把 **烬火星区与回音荒区（均 0.0）由中安池移入低安池**
