## 三、与交接卡 / 设计稿的差异与更正

1. **期望交距机制**：本树已按船长裁决②**改用 d2 的全局机制**（`UnitSpec.foeRangeBand` 只由舰级路径写、`foeDesiredRange` 取自身射程带），
   verify 侧的 `desireRangeM` / `foeDesireRangeM` 字段与「期望射程契约」**已整段删除**（取数时清理，避免"一个标量三条优先级"）。
2. **A0/A2/A3 对 C 族判别力低**：四张卡射程带上限 2552~2713 **都低于 A0 的玩家站位 3220m** ⇒ 敌人 0 开火。
   这不是本批引入的（audit §一 已定性"参考行对短射程敌人系统性偏袒玩家"，B 族教学卡同理），但**判 C 族必须用 A1**——
   已在设计稿 §9.4/9.8 写明，并新增 `--std6` 探索行补 ③⑤/裸船。
3. **星髓失去光束必中**：裁定⑤"立掷命中档 + 主系统一为等离子"的直接后果，实测让它**更难**（A1 仍反杀），本批**未补偿**；
   若认为 T72 不该同时失去必中，单卡加 `energyForm: 'beam'` 即可（一行，但会与"全族掷命中"口径分叉）。
4. **单位名与卡名重合两处**（星髓虫群 / 深渊之门卫队）：舰级路径的单位名 = 舰级名（A/B 族无此情况），语义可接受，留待第二批定名。
5. **工具新增 `--std6`**：探索行**不属于**船长采纳的 A0~A3 四行口径，`--std` 输出一字未变；本批首次使用。
