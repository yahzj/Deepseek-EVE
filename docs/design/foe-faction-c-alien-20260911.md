## 四、引擎能力盘点（"群袭 / 自愈 / 厚甲 / 多波"能实现到什么程度）

| 设定想要的 | 引擎支持？ | 依据 |
|---|---|---|
| **多单位群袭**（一群小虫） | ✅ 支持 | 舰级路径 `FoeShipSlot.count`（同型多艘）+ 多舰补偿 `2N/(N+1)`（N=4 → ×1.6，正是为"数量弥补"设计的） |
| **头目 + 虫群**（大虫带小虫） | ✅ 支持 | 同 A 族：两条编成条目 + `hpMul` 分配血量；`elite: true` 给"精锐"前缀 |
| **分波次涌入**（巢穴一波波爬出来） | ✅ 支持 | `AnomalyDef.waves`（噬口已在用 2 波）；多波与"单波次内增援"不同，后者按裁决**未启用** |
| **厚甲 / 自愈**（生体件） | ✅ 支持 | 专属三件的 `armorHpBonus` / `repairFree`（无消耗自愈，同型多件按 EVE 曲线收敛）已实装 |
| **必中喷吐 vs 贴脸撕咬的分态** | ✅ 支持 | 舰级 `dmgMix`（能量 = 光束必中）+ 条目 `tactic` 覆写（同一条船可配多种打法） |
| **生物巨兽（比巡洋更大）** | ⚠ 需裁 | 舰种表有 **4 战列舰 / 5 旗舰** 两档，但 A 族已以"海盗不配战列"为由放弃；C 族要不要用由船长定 |
| **纯能量卡的远端收束** | ✅ 已有先例 | 深渊之门 `foeShotDmg` 直写 + `foeFalloff 0.1`（远端威力 ×0.10）——**全游戏首张"奖励堆能量抗"的卡** |

## 八、落码清单（第一步 · 待船长最终确认后开工）

**A. 引擎（C 族唯一需要新能力的族）**
1. **武器形态覆写**（对应裁定 5）：在 `FoeShipDef` / `FoeShipSlot` 加一个形态字段（建议名 `energyForm?: 'beam' | 'spit'`，或通用的 `weaponKind?: 'beam' | 'fixed'`）⇒ 建档时据此决定 `kind`，并让 `hitRate` 对能量同样生效（`kind === 'beam'` 时仍恒 1）。落点：`createFoeSpecsFromShips`、胜率预估（`isBeam` 分支）、战斗结算的 beam 分支各一处；**默认不写 = 现状（零行为变化）**。
2. **族级速度口径**：`content:check` 敌速口径契约加 **C 族带 1.30~2.10×**，并加"**同档实速必须高于 A 族**"的横向断言（A 现行 391/374/325/374 作为对照值）。

**B. 数据**
3. **新增 4 个 C 族舰级**（照 A/B 写法），档位与速度按 §七 裁定 2/3：
   | 舰级 | 舰种档 | 倍率 | 实速 | 服务卡 |
   |---|---|---|---|---|
   | 裂谷畸变体 | T3 巡洋 | 1.62 | **418** | 裂谷畸变体猎杀令 58 |
   | 星髓虫群 | T3 巡洋 | 1.65 | **426** | 星髓虫群 72 |
   | 噬口（巨兽） | **T4 战列** | 1.60 | **328** | 噬口猎杀令 80（"巨兽慢而硬"例外） |
   | 深渊之门卫队 | T2 驱逐 | 1.35 | **398** | 深渊之门卫队 45（改 brawl 后的新形态） |
4. **四张卡迁入舰级路径**：
   - 裂谷 / 噬口：**主系改等离子**（8 : 爆炸 2）+ 能量掷命中形态；命中沿用 0.95（改为"命中随距离衰减"口径）；
   - 星髓：等离子 8:2 不变，套用掷命中形态；
   - **深渊之门：整套重标**（裁定 1）——初值（六组实测后微调）：血 540 → **≈700**、单发 45 → **≈56**、命中 **0.90**、射程 **1~2,600**、远端衰减 **0.5**（改为命中衰减口径）、速度 234 → **398**、战术 kite → **brawl**。
   - 除上述有意改动外，其余字段**逐字保持**（先做零变化基线再改，两步分开验收）。
5. **专属三件只复核读数不改件**（生体件在新口径下的自愈/抗性读数写进报告）。

**C. 契约**
6. 「敌方混伤契约」：纯能量卡的收束旋钮由"必须给 `foeFalloff`"放宽为"**衰减或命中任给其一**"（对应新的掷命中形态）。
7. 「舰级契约」追加 **C 族允许 T4、但必须显式登记为"巨兽"用途**（`elite` 或注释口径，防日后随手给杂鱼挂 T4）。
8. 复核「窝点级别契约」（C 族四张全候选，L1/L2/L3/L3 不变）与「增援机制未启用契约」（C 族不带 `enterAt`）。

**D. 验证（缺一不可）**
9. 四连 + **零变化基线**（逐单位建档值比对，有意差异列表）+ **六组装配复核**（照 `foe-baseline-audit-20260911.md`，含裸船行；必须输出**敌方开火次数**）。
10. **重点看两处**：① 深渊之门改 brawl 后（威胁 45）是否落进"贴脸沙包"（六组里参考行 / 近战行读数）② 噬口降到 328 m/s 后是否**变容易**（原本 426）——若明显变简单，报告船长、由船长定是否补血/补单发。
11. 文案：C 族相关玩家可见文案与「异形」措辞核对（**本批无改名项**）。

### 9.2 引擎：能量·掷命中档（裁定⑤）

- `energyForm?: 'beam' | 'spit'` 落在 `FoeShipDef` 与 `FoeShipSlot`（**条目覆写 > 舰级 > 缺省 `'beam'`**）。
- 建档处（`createFoeSpecsFromShips`）：`isBeam = 主系 === 'plasma' && energyForm === 'beam'`
  ⇒ `kind = isBeam ? 'beam' : 'fixed'`、`hitRate = isBeam ? 1 : (条目 ?? 舰级)`。
- **只作用于能量主系**：动能/爆炸主系本来就 `fixed`（掷命中），本字段对它们无影响（有用例锁定）。
- 下游**零改动**：胜率预估与实时结算都读 `w.kind`（`isBeam = w.kind === 'beam'`）、层位克制读 `fixedType` ⇒
  `'spit'` 自动获得"掷命中 + 命中随距离衰减 + 吃回避"，而克制**仍按等离子行**（对盾 ×1.25 / 对甲 ×1 / 结构 ×1）。
- **默认不写 = 现状**：A/B 族七条舰级一字未动、读数不变（9.4 表可对账）。

1. **虫群规模 6~12 只/卡**（比海盗的 3~4 单位大一个量级），**逐卡单独定**（规模随威胁递进）。

4. **头目血量占比不套 A 族 60% 口径**（逐卡自定；噬口取 **≈40%**，让虫群占多数）。
