## 四、引擎能力盘点（"群袭 / 自愈 / 厚甲 / 多波"能实现到什么程度）

| 设定想要的 | 引擎支持？ | 依据 |
|---|---|---|
| **多单位群袭**（一群小虫） | ✅ 支持 | 舰级路径 `FoeShipSlot.count`（同型多艘）+ 多舰补偿 `2N/(N+1)`（N=4 → ×1.6，正是为"数量弥补"设计的） |
| **头目 + 虫群**（大虫带小虫） | ✅ 支持 | 同 A 族：两条编成条目 + `hpMul` 分配血量；`elite: true` 给"精锐"前缀 |
| **分波次涌入**（巢穴一波波爬出来） | ✅ 支持 | `AnomalyDef.waves`（噬口已在用 2 波）；多波与"单波次内增援"不同，后者按裁决**未启用** |
| **厚甲 / 自愈**（生体件） | ✅ 支持 | 专属三件的 `armorHpBonus` / `repairFree`（无消耗自愈，同型多件按 EVE 曲线收敛）已实装 |
| **必中喷吐 vs 贴脸撕咬的分态** | ✅ 支持 | 舰级 `dmgMix`（能量 = 光束必中）+ 条目 `tactic` 覆写（同一条船可配多种打法） |
| **生物巨兽（比巡洋更大）** | ⚠ 需裁 | 舰种表有 **4 战列舰 / 5 旗舰** 两档，但 A 族已以"海盗不配战列"为由放弃；C 族要不要用由船长定 |
| **纯能量卡的远端收束** | ✅ 已有先例 | 深渊之门 `foeShotDmg` 直写 + `foeFalloff 0.1`（远端威力 ×0.10）——**全游戏首张"奖励堆能量抗"的卡** |

## 五、待裁清单（集中提问 · 请逐条批）

| # | 问题 | 选项 |
|---|---|---|
| **1** | **C 族定位（强度段）** | (a) **中高段"墙族"**：威胁 45~80，接在 A 族中段之后当第一道硬墙；(b) **中段**：整体下压到 40~60，把 80 让给别人；(c) 保持现状跨度（45~80，族内自带梯度） |
| **2** | **战术性格** | (a) **统一 brawl**（"贴脸撕咬"）——最贴设定，但 45 那张要动；(b) **双态**：族内允许"近噬 + 远喷"两种（brawl ×3 + kite ×1 现状）；(c) 统一 **orbit**（中距缠斗） |
| **3** | **深渊之门 硬冲突**（现 kite + 13.3 km 光束 + 纯能量 + 全游戏最强远程） | (a) 保留它、把 C 族改为**双态族**（"远喷型"是族内正当变体）；(b) **改 brawl**（最贴设定，但要重标血/射程，且可能落进"贴脸沙包"陷阱）；(c) 改 **orbit**（中距封锁折中）；(d) **移出 C 族**（换族/换皮） |
| **4** | **速度口径** | (a) **偏快**（生物冲刺，1.0~1.5×，与 A 同向）；(b) **偏慢**（厚甲慢速，0.75~1.0×，与 B 同向，治"贴不到脸"）；(c) 保持现状（0.85~1.55×，逐卡定） |
| **5** | **舰种档** | (a) 只到 **3 巡洋舰**（与 A 一致，不配战列）；(b) 允许 **4 战列舰**（"生物巨兽"，噬口 80 / 星髓 72 用）；(c) 允许 **5 旗舰**（更极端） |
| **6** | **编成形态（群袭）** | (a) **统一"虫群"**：每卡多单位（如 N=3~4，小虫 ×N + 可选大虫头目）；(b) **分级**：低威胁群袭、高威胁单体巨兽（噬口 = 单体精英）；(c) 保持现状（僚机 0~2 逐卡定） |
| **7** | **混伤签名** | (a) **统一主系 = 等离子**（"酸液"，C 族签名），副系爆炸；(b) 保持"生物多样性"（裂谷/噬口动能主、星髓等离子主）；(c) 全部改纯系 + 用远端衰减/命中收束（风险高） |
| **8** | **专属三件是否随新口径复核** | (a) 复核读数但**不改件**（三件已逐件过审）；(b) 允许按新编成重标三件 |
| **9** | **窝点级别（L1/L2/L3/L3）** | (a) 保持现状（深渊之门 L1 / 裂谷 L2 / 星髓 L3 / 噬口 L3）；(b) 随强度重排 |
