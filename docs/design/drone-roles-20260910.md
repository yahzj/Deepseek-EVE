## 一、船长定位口径（原文要点）

| 机型 | 船长定位 |
| --- | --- |
| 侦察型（蜂鸟） | **闪避率最高** |
| 战斗型（赤鸢） | **属性平均** |
| 攻坚型（猎鹰） | **血量厚、攻击高、闪避很低** |
| 哨戒型（雷鸥） | **远程狙击，血量和侦察机差不多** |
| 适用范围 | 之后新增无人机须参考本定位；**现有无人机也要调整** |

## 二、定位契约（四档落点，供现有与未来机型共用）

| 档位 | 闪避 | 三层总血 | 单发（以侦察为 1×） | 射程 | 命中 | 抗性 | 体积 / CPU |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 侦察机 | **0.42~0.55（最高）** | 15~25（最脆） | **1~1.4×** | 2000~2800 | 75% 不衰减 | 无 | 5 m³ / 4 |
| 战斗机 | **0.20~0.30（居中）** | 35~50（居中） | **1.8~2.4×** | 2800~3200 | 75% 不衰减 | 全层小幅 | 10 m³ / 7 |
| 攻坚机 | **0.08~0.14（最低）** | **90~120（最厚）** | **3.4~4.6×** | 3300~3800 | 75% 不衰减 | 装甲向 | 20 m³ / 11 |
| 哨戒机 | 0.15~0.22（次低） | 18~30（≈侦察） | **6~7.5×（最高）** | 4500~6000 | 110%（保留衰减） | 护盾小幅 | 40 m³ / 16 |

> 契约的**可执行版本**在 `packages/data/src/droneRoles.ts`（`DRONE_ROLE_SPECS` + 逐机/阶梯校验函数），
> 由 `npm run content:check`（新增「无人机四型定位」行 + 逐机与阶梯断言）与
> `packages/core/tests/drone-roles.test.ts`（7 项）双重守卫——**新增无人机越档即被拦下**。

> 单发档基准 = 蜂鸟 3 → 3 / 6 / 12 / 20；现有四型**恰好已符合**这条火力梯子，
> 说明"攻击高"在现有数据里已经成立（攻坚单发是战斗机的 2 倍，每 CPU 伤害 1.09 为侦察/战斗/攻坚
> 三型最高——哨戒 1.25 更高，对应"狙击"）。**因此本次调整集中在生存包，不动火力与射程命中口径。**

## 四、方案中由二号填的未指定项（船长已接受）

1. **哨戒机闪避未指定**：定位只说"远程狙击 + 血量≈侦察机"。填 **0.18（次低）**——
   理由：狙击平台靠距离活命，若再给高闪避则"脆"这一代价被抵消。
2. **战斗机血量"平均"的锚点**：赤鸢 34 → **40**（四型中位），使"平均"在整个阶梯上成立。

## 五、影响面（必须知情）

1. **这些数值目前没有任何战斗效果**——`DroneDefense`（盾/甲/结构/抗性/闪避）只被物品详情/图鉴/
   手册显示，战斗引擎不读；玩家可见文案也明写"不消耗、不被击落"。所以：
   - 本次调整**不改变任何胜率、不改变校准矩阵**（`battle:calibrate` / `battle:drone-vs-gun` 输出不会动）；
   - 调整的可见效果 = 物品详情/图鉴/手册的「生存（契约）」「回避」两行数字变化。
2. **要让"血厚/闪避"真正成立，需要实装"无人机可被击落"**（敌方点防/随机击落 → 机群随战斗递减，
   攻坚靠血厚、侦察靠闪避活下来）。这是战斗引擎级改动（含 UI 表现与平衡复核），建议单独立项。
3. **C6 平衡不受影响**：上一轮的"无人机流 vs 炮流"结论（有效 DPS@2km 105% 等）基于火力与命中，
   与生存包无关，故无需复跑。
4. **测试存档与既有档无迁移**：`defense` 不进存档（存档只记 droneLoad 数量），零迁移。

## 八、无人机舰专属加成（2026-09-10 船长拍板，已确认并实施）

**背景**：无人机舰的 `powerBonus`（火力加成）与同档炮舰齐平（王鲭 0.6 = 长尾鲨级），
但该字段**只乘入炮台与基础舰炮**，对主力武器（机群）完全无效——等于把母舰往"当炮舰用"推。
船长口径：**削弱无人机舰的火力加成，改为和其它巡洋舰同款的专属加成**。

**已实施**：

| 舰船 | powerBonus | 新增 `droneDmgBonus` |
| --- | --- | --- |
| 王鲭级无人机母舰（T3） | 0.6 → **0.3** | **+12%**（与其它巡洋舰族加成同档） |
| 梭鱼级无人机护卫（T2） | 0.45 → **0.25** | **+8%**（T2 档） |

- 机制：`combat.ts` 无人机单发 = 机型基数 ×2 ×(1+Σ战术导控) ×**(1+船体 droneDmgBonus)** ×(1+5%×无人机作战学)，三者乘算；
- 字段只给无人机舰（其它舰船不挂）；测试 `tests/drone-ship-bonus.test.ts`（3 项）钉住字段、乘算链与"只喂无人机"。

**实测（`drone-vs-gun` 复跑，满技能 5 种子）**：

| 口径 | 改前 | 改后 |
| --- | --- | --- |
| 王鲭·无人机 D3 名义 / 有效@2km | 220 / 184 | **245 / 206**（+12%） |
| 王鲭·炮流 4×MK3 名义 / 有效 | 183 / 175 | **149 / 143**（−19%） |
| 王鲭·炮流实战（噬口/坟场/穹顶交火） | 76s / 68s / 104s | **89s / 78s / 120s** |
| 梭鱼·无人机 D2b 名义 | 132 | **142**（+8%） |
| 梭鱼·炮流 3×MK3 名义 | 126 | **109**（−13%） |
| 近防炮战损（穹顶 96，默认档） | 2.2 架 | **1.4 架**（机群更强 → 交火更短） |

净效果：**无人机舰的无人机路线变强、炮舰路线变弱**——与"它就是无人机平台"的定位一致。
