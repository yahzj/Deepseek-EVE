### 0.3 血型改 0.5：**卡片 `hpMul` 一律不动**（✅ 已落码，实测核对过）

**结论（把原先"再乘 1.176"的想法作废）**：护盾每场满值重建、装甲/结构跨场持久 ⇒ 血型从 0.34/0.33/0.33
改成 **0.5/0.25/0.25** 本身就让**等效耐久涨 17.6%**；若再把 `hpMul` 也乘 1.176，等于把血量调回原样
⇒ **难度白涨 17.6%**。⇒ **`hpMul` / `dmgMul` 一个都不动**，等效耐久自然维持旧值。

**实测对照（`activeFoeSpecsOf` 探针 · 原始血量点数）**：

| 卡 / 波 | 改前 | 改后 | 等效耐久（改后 ×1.176） |
|---|---|---|---|
| `ink-harass` w0 | 89 | **89** | ≈105（≈ 改前的 104） |
| `ink-raid` w0 / w1 | 61 / 117 | **61 / 87** | ≈72 / ≈102（≈ 改前的 72 / 104） |
| `ink-main` w0 / w1 | 61 / 202 | **61 / 176** | ≈72 / ≈207（≈ 改前的 72 / 203） |
| `ink-flagship` w0/w1/w2/w3 | 103/159/116/159 | **103/127/116/149** | ≈121/149/136/175（≈ 改前的 126/154/142/183） |

⇒ **强度基本守恒**（±5%），差值是逐单位取整 + 鱼雷舰"高攻低血"改单发带来的。

**鱼雷舰单发 60→90 的连带**：`dmgMul` 也**不动** ⇒ 该舰每发实收从 8 涨到 11（更痛），
这是船长要的"攻击更高"的**落地体现**；四卡逐波单发合计从 24/39/27/31 涨到 **33/49/39/35**。

  捕获网归属加 `foe-h-ink-corvette`、"洞外不许挂冲锋件"加 H 族豁免（H 的件写在**舰级**上，四张卡全带）。

#### 干扰压制 · 船长三例（照抄，口径就按这三条钉死）

1. 「**敌方1艘干扰，我方1艘电子，最终结果是我方射程-0.35，敌方不变**」
2. 「**敌方1艘干扰，我方2艘电子，最终结果是我方射程-0.2，敌方不变**」
3. 「**敌方1艘干扰，我方1艘电子，我方有射程增加60%效果，最终结果是我方射程-0.35+0.6=+0.25，敌方不变**」

| 项 | 口径（引擎实现） | 例① | 例② | 例③ |
|---|---|---|---|---|
| 敌方干扰合成 | `r_e = 1 − Π(1 − vᵢ)`（每艘 0.5） | 0.50 | 0.50 | 0.50 |
| 我方电子舰合成 | `r_p = 1 − Π(1 − vᵢ)`（每艘 0.15，与既有那条**同一份** `meFoeRangeDebuff`） | 0.15 | 0.2775 | 0.15 |
| **净削减** | `net = max(0, r_e − r_p)`——**"相互抵消"就是这一减** | **0.35** | **0.2225** | 0.35 |
| **我方射程倍率** | `1 + 我方射程加成 − net` | **0.65** | 0.7775 | **1.25** |
| **敌方射程** | **完全不受影响**（干扰只压我方，不动 `foeGunMaxRangeOf` 那条链） | 不变 | 不变 | 不变 |

- ⚠ **例②的 0.2 是船长口述的举例错误**（船长 2026-09-24 当场更正：「**例②是我举例错误**」）⇒
  引擎按**乘法合成**算：电子舰每艘 15% ⇒ 2 艘 = 27.75%（不是 30%），净 = 0.50 − 0.2775 = **0.2225**
  （倍率 ×0.7775）。这处差值是"例②本身不成立"，不是引擎偏差。
- ⚠ **例③的加法口径**：武器上的 `maxRangeM` 已经乘过 `(1+0.6)`（谜质/模块那条加法链）⇒
  引擎按 `(1+bonus−net)/(1+bonus)` 反解施加系数（每件武器**各按自己的加成**算），
  1.6 × 0.78125 = **1.25** = `1 + 0.6 − 0.35` ✓。⚠ 已删除首版的"我方倍率 ×0.50"旧读法
  （那是把"-35%"错读成"只由敌方 50% 决定"）与半成品的 `foeRangeNetDebuffOf`。

**落点**（与视图同源，不新增第三份射程算法）：
`buildMyUnitSpecs`（单船/多舰两条路径，开战首拍 + 每拍重建）· `battleArcsFor`（视图锚舰）·
`meJammerNetOf` / `meRangeMulOf` / `applyMeJammerDebuff`（每件武器按自己的射程加成反解）。

**用例**：`packages/core/tests/ink-tide-20260924.test.ts` 17 例——三例逐条（①×0.65 · ②0.2225/×0.7775 ·
③×1.25）＋"敌方不变"＋裸武器落点＋**端到端**（真打 `ink-main`：视图射程弧第 0 波 = 基础、
干扰舰那一波 = 基础×0.65，且敌方武器的有效射程仍只被我方电子舰那条老机制压）。
