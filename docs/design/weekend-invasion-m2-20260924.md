**⚠ 落码中两处实测修正（留档，别照旧文重开）**：
1. **契约里的"比率"是对基准船（长尾鲨级）的比值，不是 `speedRatio`** —— 墨潮旗舰首版按 `speedRatio 1.6`
   （248 m/s）标定，实测比率只有 0.85×（越下限）；重算后取 **2.0（310 m/s，比率 ≈1.06×）**。
   同族其余四条也据此重标（1.10 / 1.05 / 1.05 / 1.05）。
2. **入侵卡的"地区"必须显式写** `region: 'wh'` —— 否则按"id 前缀 + 星系安全等级"会推成高安，
   残骸组契约与 `content-check` 的组统计一起错位（工具当时直接崩在 `tally` 取空）。
