## 一、背景与路线

船长拍板（2026-09-04，集中问答两轮 + 补充说明）：
- 伤害三系 ↔ 武器形态一一对应，方便统一：**质量炮（动能）· 导弹（爆炸）· 激光（能量）**；
- 现行"同 MK 三系同参、只换弹种"的炮 = **临时填充数据**，将按形态逐个替换；
- **本轮 = V18B-1：导弹架**（从导弹开始设计）；质量炮/激光 = V18B-2 后续批
  （船长补充：动能炮届时**不一定改名**——形态差异优先于命名，V18B-2 再定）；
- 导弹机制 = **逐发消耗简化版**（船长选乙：与炮弹同管线消耗，无弹匣概念）。

## 二、导弹架设计（mod-missile-1/2/3）

| 项 | 定案 |
|---|---|
| 家族 | ModuleSlot 新增 **missile**（徽标「导弹架」；高槽 rack；与炮/矿/无人机件共位） |
| 伤害 | **explosive（爆炸）系**——不新增伤害系（抗性/克制表/支援件全兼容） |
| 弹药 | 逐发消耗 explosive 键；原"高爆弹"（ammo-explosive-l，id 不变）更名 **「爆破导弹」** |
| 弹道 | **无视近盲**（minRange = 0，贴身可发射） |
| 命中 | **追踪制**：falloff = 1 → 距离衰减恒 1，命中率只看 武器命中 × 攻防修正 − 回避 |
| 节奏 | 单发高伤 + 装填偏慢（远程爆破轰炸定位，与动能速射错开） |
| 渠道 | 市场专供（无蓝图；沿用原高爆炮价位） |

## 四、引擎接入

- combat：武器收集扩为 turret + missile 双族（同 id ×N 齐射合并照旧、per-gun 弹型管线
  复用）；`playerAmmoType`（出发主弹装载）扩族；远征文案"已装配武器"判定扩族；
  **AI 副船同源自动生效**（同一 createPlayerSpec）；
- 命中：falloff=1 → distFactor 恒 1、minRange=0 → 无近盲，公式零改动（数据驱动）；
- 伤害稳定器（V18.1 爆炸系款）按 explosive 键自动加成导弹单发（与动能炮同池逻辑）；
- UI：SLOT_LABELS/Glyphs/色调、moduleShortEffect/moduleInfoLines（弹头/射程带/弹道特性/
  追踪命中/装填）、装配页与手册自动；
- content-check：missile 家族白名单 + 断言（damageType=explosive、minRange=0、falloff=1、
  武器参数全套、无工业 bonus）。
