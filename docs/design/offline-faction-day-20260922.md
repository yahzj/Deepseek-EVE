# 离线跨天时「敌对派系活跃」按哪一天算（船长之问 · 已查明，附读数）· 2026-09-22

- 状态：待裁决（现状已实测查明；第五节有一个可选改动等船长定 · 本行随裁决更新）
- 经办：二号（工作树 `H:\大鲸鱼\Deepseek-EVE-d2`）· **本文只记录读数，未改任何代码**
- 判定工具：临时探针（跑完已删；结论与读数记在本文第三节）

## 一、船长原话（照抄）

> 「假设玩家挂机活跃敌人星系后离线，第二天再上线，那么会计算前一天刷了多少活跃敌人吗？还是说刷了多少敌人只在上线时计算此时刷了多少敌人（因为换天了，活跃敌人的星系换了）」

## 二、结论（先说结果）

1. **游戏里没有"刷了多少敌人"这本账**：派系活跃**不是逐拍刷怪**，而是**每天本地 0 点整板替换的一张日板卡**（选一个已探索的中安/低安星系）。该星系当天的**常驻悬赏**吃 **奖金 ×1.1 / 威胁 ×1.1**，胜利后按 30% + 保底 10 次掷**稀有残骸**。没有任何"离线给你补 N 个敌人"的结算。
2. **离线期间真的会打**——但只有**「重复清剿」开着**才会：离线按 30 秒分片推进，每片边界按在线同款条件自动再出发（`simulation.ts`），所以离线一夜确实有战果。
3. **这些战果按"上线日那一版"判**（不是昨天那版）：离线推进把整段窗口的 `nowWallMs` 统一设成**离线末刻**，日板旋转就发生在窗口的**第一片**里 ⇒ 那之后的每一次再出发，看的都是**今天**（上线日）抽中的星系。
4. **唯一的例外 = 离线前就已经在打的那一场**：它吃不吃加成是**出发那一刻锁定的**（`exp.factionActive` 随远征落档）⇒ 昨晚出发、跨夜打完的那一场**照样吃昨天的加成**（实测钱包正是 1,000,000 × 1.1）。

## 三、实测读数（合成场景，唯一变量 = 日板是否在离线窗口里换）

| 场景 | 离线窗口 | 离线前那版活跃 | 上线后那版活跃 | 读数 |
| --- | --- | --- | --- | --- |
| A 不跨天 | 今天 00:10:00 → 00:10:35 | 目标星系 | 目标星系（不换板） | 再出发那场 `factionActive = **true**` |
| B 跨天 | 9/21 23:59:50 → 9/22 00:00:25 | 目标星系 | 另抽（本场景抽不出 ⇒ 无） | 再出发那场 `factionActive = **false**` |
| C 跨天但今天又是它 | 同上 | 目标星系 | 目标星系 | `factionActive = **true**` |
| D 昨天出发、跨夜打完 | 同上 | 目标星系 | 另抽（无） | 钱包 **+1,100,000**（= 1,000,000 × 1.1）· 稀有残骸空手计数 +1 ⇒ **保住昨天的加成** |
| E1 长窗口跨天 | 9/21 20:00 → 9/22 00:00:25 | 目标星系 | 另抽（无） | 战报 56 条 · 该星系稀有残骸存量 **0** |
| E2 长窗口不换板 | 同上 | 目标星系 | 目标星系 | 战报 51 条 · 该星系稀有残骸存量 **30** |

**E1 vs E2 是这次最关键的一条**：稀有残骸**只有"派系活跃那场胜利"才会掷骰**（`expedition.ts` 的 `factionActive` 分支）。
E1 整段窗口 0 件 ⇒ **连 0 点之前那几个小时（20:00–24:00）的场次也一场都没吃到昨天的加成** ——
因为整段离线的 `nowWallMs` 都是"离线末刻"，第一片就把日板推到了**上线日**那一版。

## 四、机制出处（要改就改这几处）

| 环节 | 位置 | 现行口径 |
| --- | --- | --- |
| 日板旋转 | `core/sideTasks.ts` `advanceBountyBoard` | 按 `nowWallMs` 对齐本地 0 点；跨日（含离线一夜/多日）**整板清空重刷**，跨多日**只补最后一道界** |
| 派系选星 | 同文件 `spawnFactionActivity` / `factionPoolOf` | 每天选 1 个已探索中安/低安星系（排除已建成副站的），并把该星系从当日 5 席抽签池剔除 |
| 加成锁 | `core/expedition.ts` `startExpedition` | 出发那一刻写 `exp.factionActive`，本场带着它打完（战中/跨天都不变） |
| 离线推进 | `core/simulation.ts` `simulateOffline` | 整段窗口**只用同一个 `nowWallMs`**（= 离线末刻）；重复清剿按 30 秒分片，片边界再出发 |
| 结算上限 | 同文件 | 基础 **8 小时**（离线作业管理学每级 +20% · 无人值守调度学每级 +40% ⇒ 双满级 32 小时），超出部分不结算 |

## 五、可选改动（等船长裁）

**问题**：离线窗口若跨过 0 点，"0 点之前那几个小时"也被按**上线日**那版判 ⇒ 玩家昨晚实际在打的活跃星系，那几小时的战果**吃不到它本该吃的加成**（对玩家不利，且与"当天可反复刷"的口径不一致）。

| 方案 | 做法 | 代价 |
| --- | --- | --- |
| **甲（推荐，改动小）** | 离线分片按**日界**切段：0 点之前那段用**旧日界**的 `nowWallMs`（照吃昨天的活跃），0 点之后那段用新日界 | `simulateOffline` 里多一层"按 dayStart 切段"的循环；每段各自传 `nowWallMs`。口径与"日板一天一版"一致，只是把两版各用在各自那段时间上 |
| 乙 | 不动（现状 = 整段按上线日判） | 离线跨夜对"昨天的活跃星系"等于没有加成；好处是结算只有一版、逻辑最简 |
| 丙 | 只把"离线前那一场"扩成"离线前那条活跃星系整夜都算"（即离线期间锁定离线前那版） | 与"0 点换板"的日板口径冲突（板已经换了，加成却还按旧的），不建议 |

**不做**：任何"离线补敌人数量"的结算（现在没有这本账，也不建议加——它会把"挂机收益"从"清剿效率"变成"在线时长补贴"）。

## 六、顺带确认的既有口径（不是本问的一部分，但相关）

- 昨天没打完的**当日 5 席赏金**：跨日整板作废，**无惩罚**（船长 2026-09-10 定）；
- 已经打进星系的**稀有残骸存量留在那里**（打捞必得），不随换天消失；
- **常驻悬赏**（派系活跃作用的那类）不是日板席位，卡一直在，只是"当天吃不吃 ×1.1"随日板变。
