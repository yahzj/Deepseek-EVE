## 一、船长原话（照抄）

> 「假设玩家挂机活跃敌人星系后离线，第二天再上线，那么会计算前一天刷了多少活跃敌人吗？还是说刷了多少敌人只在上线时计算此时刷了多少敌人（因为换天了，活跃敌人的星系换了）」

## 二、结论（先说结果）

1. **游戏里没有"刷了多少敌人"这本账**：派系活跃**不是逐拍刷怪**，而是**每天本地 0 点整板替换的一张日板卡**（选一个已探索的中安/低安星系）。该星系当天的**常驻悬赏**吃 **奖金 ×1.1 / 威胁 ×1.1**，胜利后按 30% + 保底 10 次掷**稀有残骸**。没有任何"离线给你补 N 个敌人"的结算。
2. **离线期间真的会打**——但只有**「重复清剿」开着**才会：离线按 30 秒分片推进，每片边界按在线同款条件自动再出发（`simulation.ts`），所以离线一夜确实有战果。
3. **这些战果按"上线日那一版"判**（不是昨天那版）：离线推进把整段窗口的 `nowWallMs` 统一设成**离线末刻**，日板旋转就发生在窗口的**第一片**里 ⇒ 那之后的每一次再出发，看的都是**今天**（上线日）抽中的星系。
4. **唯一的例外 = 离线前就已经在打的那一场**：它吃不吃加成是**出发那一刻锁定的**（`exp.factionActive` 随远征落档）⇒ 昨晚出发、跨夜打完的那一场**照样吃昨天的加成**（实测钱包正是 1,000,000 × 1.1）。

## 五、三案与船长裁决

**问题**：离线窗口若跨过 0 点，"0 点之前那几个小时"也被按**上线日**那版判 ⇒ 玩家昨晚实际在打的活跃星系，那几小时的战果**吃不到它本该吃的加成**（对玩家不利，且与"当天可反复刷"的口径不一致）。

| 方案 | 做法 | 结果 |
| --- | --- | --- |
| **甲** | 离线**分片那条路**上让墙钟**跟着片走**（0 点前的片用旧日界、0 点后的片用新日界） | ✅ **船长选此案，已实现** |
| 乙 | 不动（整段按上线日判） | 未采纳 |
| 丙 | 离线期间锁定旧版活跃 | 未采纳（与"0 点换板"冲突） |

**不做**：任何"离线补敌人数量"的结算（现在没有这本账，也不建议加——它会把"挂机收益"从"清剿效率"变成"在线时长补贴"）。

## 六、实现（改了哪些文件）

| 文件 | 改动 |
| --- | --- |
| `packages/core/src/simulation.ts` | 分片推进那一段：新增 `let wallMs = lastSavedWallMs`，每片 `wallMs += step` 后传 `{ ...advOpts, nowWallMs: wallMs }` ⇒ **每片用它自己走到的那一刻**判日板。**分片本身一个字没动**（片长/片数/每片一次 `advanceGame` 全不变，末片墙钟仍 = 离线末刻 ⇒ `state.wallMs` 落值与改前一致）。头注与函数内长注释写明口径与"为什么不切大推进那条路" |
| `packages/core/tests/offline-loop.test.ts` | 新增一条 describe（3 例）：① 离线前那版活跃 = 目标星系 ⇒ 0 点前那 3 小时的战果照吃加成；② 对照（两版都不是它）⇒ 一场都不吃；③ 上线日那版 = 目标星系 ⇒ 0 点后那 2 小时吃的是**今天**这版 |

**为什么只改分片那条路**（这是本次设计的关键边界）：只有**重复清剿开着**时离线才会再出发——`advanceAutoLoopBounty` 全仓只有两个调用点（在线心跳 `apps/desktop/.../engine.ts`、离线分片 `simulation.ts`）；没开清剿的离线是"一次大推进"，期间不会开新战斗，而离线前已在打的那一场早在出发那刻就锁定了加成（第三节 D 已实测）。顺带量到的两条读数也支持这个边界：

| 离线 8 小时（跨 0 点） | 20 分钟资源/快递板刷新次数（seq 增量 ÷ 每刷 4 条） |
| --- | --- |
| 没开重复清剿（大推进） | **1 次**（正是船长 2026-09-05 定的"仅末窗执行"） |
| 开了重复清剿（30 秒分片） | **24 次**（既有行为，本次**不动**） |

⇒ 若改成"所有路径都切段"，大推进那条会从 1 次变 2~3 次，把"仅末窗执行"这条老口径顺带改掉。**故不切它**，并在注释里写明"将来若那条路也能在离线中再出发，这里要一起改"。

## 八、顺带确认的既有口径（不是本问的一部分，但相关）

- 昨天没打完的**当日 5 席赏金**：跨日整板作废，**无惩罚**（船长 2026-09-10 定）；
- 已经打进星系的**稀有残骸存量留在那里**（打捞必得），不随换天消失；
- **常驻悬赏**（派系活跃作用的那类）不是日板席位，卡一直在，只是"当天吃不吃 ×1.1"随日板变；
- 离线超过一天（上限 16/24/32 小时时才可能）：中间那些天也各按自己那版判 ⇒ 上线日那版的抽签结果可能与"只补末界"的旧行为不同（修好相位的必然结果，如实登记）。
