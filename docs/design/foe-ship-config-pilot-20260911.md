### 1.2 更严重的一层：**低安的伏击遭遇里也没有海盗**

- `encounters.ts:56` 原文：「伏击者来自**事发星系可见的悬赏敌群**池（hidden 遭遇模板不算）」。
- 低安十一张卡的族系 = **C 异形 4**（深渊之门45 / 裂谷58 / 星髓72 / 噬口80）· **D 守墓 3**（坟场88 / 虚海88 / 穹顶96）· **E 巨构 2**（泰坦60 / 奥罗62）· **G 流亡 2**（烬火42 / 天底66）。
  ⇒ 在低安被伏击，来打你的是**异形 / 古舰 / 巨构 / 流亡者**，**没有海盗**。
- 四张 `enc-pirate-*`（说明写着"低安遭遇模板"）**已退役**：`encounters.ts:9` 原文「旧 hidden 四档模板**退役**，仅作旧档遗留遭遇的战斗兜底」；且它们的 `galaxyId` 全指向 `galaxy-hub`（**sec=1 高安**），只是占位。

### 1.3 星图派系也是空白的

`Expedition.tsx:796-801`：「敌对派系归属——**由该星系的悬赏卡推导**」（`foeFamilyOf(a.id)`）。
⇒ 低安十个星系在星图上**永远不会显示"海盗"标签**。

### 1.4 ⭐ 杠杆：一张低安海盗卡点亮三条通道

因为「伏击者取自该星系可见悬赏敌群」+「星图派系由悬赏卡推导」，
**只要在低安放一张 A 族悬赏卡**，就同时得到：
**① 低安可接的海盗悬赏 ② 低安伏击遭遇里出现海盗 ③ 星图上该星系显示"海盗"派系标签**。

## 四、交换位置：能选哪一对（两条硬约束）

### 约束一：A 族六张里，**只有一张的威胁段进得了低安**

低安现有威胁段 = 42 / 45 / 58 / 60 / 62 / 66 / 72 / 80 / 88 / 88 / 96（**最低 42**）；
A 族六张 = 12 / 20 / 22 / 28 / 34 / **48**。
⇒ **只有「蜃影导航劫持令 48」够得着低安**。其余五张（12~34）挪进低安会低于门槛 8~30 分，
等于把整个低安入口拉低。

### 约束二：低安十一张里，**只有一张没有与星系名绑定**

低安十一张卡，**十张把所在星系的主题词直接写进了卡名**：

| 低安卡 | 所在星系 | 名绑定 |
|---|---|---|
| 坟场守墓人 88 | 暗星**坟场** | ✅ 坟场 |
| 深渊之门卫队 45 | **深渊之门** | ✅ 逐字同 |
| 奥罗武装残骸群 62 | **奥罗**荒环 | ✅ 奥罗 |
| 星髓虫群 72 | **星髓**迷宫 | ✅ 星髓 |
| 烬火围攻战 42 | **烬火**星区 | ✅ 烬火 |
| 天底静区封锁 66 | **天底静区** | ✅ 逐字同 |
| 噬口猎杀令 80 | 星**噬口**（星噬之口） | ✅ 噬口 |
| 虚海守望者 88 | **虚海**边缘 | ✅ 虚海 |
| 穹顶守卫 96 | **穹顶**墓园 | ✅ 穹顶 |
| 裂谷畸变体猎杀令 58 | **裂谷**深带 | ✅ 裂谷 |
| **泰坦残骸勘探 60** | 深渊之门 | ❌ **无绑定** ← 唯一可动 |

（附注：星系名与卡名**并非引擎规则必须一致**——`红环航道` 的两张卡是「赤潮劫掠舰队」「幽灵舰信号」，
都不含"红环"。绑定是**低安十一个星系各自建立的一一对应**，不是硬约束。）
⇒ 挪走那十张中的任何一张，都会留下一个"**名字指向已不存在的卡**"的星系（星系名不会跟着改）。

### 结论：**只有一对能同时满足两条约束**

> ## 「蜃影导航劫持令」48（中安·蜃影星系） ⇄ 「泰坦残骸勘探」60（低安·深渊之门）

| 项 | 结果 |
|---|---|
| 低安获得海盗 | ✅ **深渊之门（sec −0.7）** → 悬赏 / 伏击遭遇 / 星图派系**三条通道同时点亮** |
| 名绑定 | ✅ **不破**——深渊之门仍保留同名的「深渊之门卫队 45」 |
| 设定贴合 | ✅ 「**导航劫持**」出现在低安的星门要地，比在中安更合理（低安正是劫掠者猎杀航路之处） |
| ⚠ 代价 | **威胁段错位**：蜃影星系 48→60（中安顶段抬高 12 分），深渊之门 60→48 |

### 备选（若您更看重威胁段守恒）

**「蜃影导航劫持令」48 ⇄ 「深渊之门卫队」45**（只差 3 分，几乎同段）。
代价：**深渊之门卫队是 C 异形、且逐字绑定"深渊之门"**，换到蜃影星系后**必须改名**，
否则"深渊之门卫队"驻在蜃影星系不符合设定。改名属玩家可见文案变更。

### 随交换需一并核对（我查完列给您，不擅自改）

交换会连带影响该星系的**伏击遭遇强度**与**残骸打捞池**（`wreckPoolOf` 按星系取卡）；
另需核对两张卡的 `standingReq`（低安门槛通常更高）与报酬是否需要对齐。
