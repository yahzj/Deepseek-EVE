### 6.2 口径统一（船长 2026-09-17「照做」）

**三层克制唯一源 = `typeLayerMult`**（`combat.ts:294`）：动能 盾 ×1.5 / 甲 ×0.75 / 结构 ×1；高爆 甲 ×1.5 / 盾 ×0.75 / 结构 ×1；能量 盾 ×1.25 / 甲 · 结构 ×1。
统一写法 = **只列非 ×1 的层**：`对护盾 ×1.5、对装甲 ×0.75`。

查出并修掉的**真值错**：
- 轻型炮台 MK1·动能型 `打盾 1.5 倍伤害（打甲减半）` ⇒ ×0.75 ≠「减半」；
- 轻型导弹架 MK1 `（打甲 1.5 倍、打盾减半）` ⇒ 同上；
- 装甲镀层 MK1·高爆型 `高爆对装甲是双倍伤害` ⇒ 真值 ×1.5；
- 蓝图侧 3 条弹药图纸只写单层 ⇒ 补齐另一层（`content:check`「弹药克制声明」按 `typeLayerMult` 自动对账，`tools/content-check.ts:559`）。

**系名统一**（权威 = `DAMAGE_TYPE_LABELS`：动能 / 高爆 / 能量）：甲壳棱镜层 `动能 / 爆破 / 等离子一视同仁` ⇒ `动能 / 高爆 / 能量一视同仁`。

**叠加口径固定三词**：`多装递减`（EVE 曲线：命中 / 闪避 / 跃迁 / 锁定）· `多件不叠加`（取最重一件：陵寝装甲层速度代价）· `同类叠加，多来源收益递减`（技能↔件）。跃迁计算机的本体说明与蓝图说明统一成同一句。
