## 六、设计系统定稿（本仓口径 · 只写"我们怎么用"）

### 6.1 密度（采纳技能拨盘 8/10）

### 6.1.1 间距刻度（**2026-09-25 船长裁决：贴真实值**）
实测（`_len-survey.ts`）本仓真实间距是 **2px 基数的手工刻度**（`8×149 · 6×144 · 10×76 · 2×69 · 4×54`），
不是 4px 基数。阶段②原定的 `4/8/12/16/24` 只命中 **37%**，故按船长裁决改为**贴真实值的全值刻度**：

`sp-1:1` · `sp-2:2` · `sp-3:3` · `sp-4:4` · `sp-5:5` · `sp-6:6` · `sp-7:7` · `sp-8:8` · `sp-9:9`
· `sp-10:10` · `sp-11:11` · `sp-12:12` · `sp-13:13` · `sp-14:14` · `sp-15:15` · `sp-16:16`
· `sp-18:18` · `sp-20:20` · `sp-22:22` · `sp-24:24` · `sp-26:26` · `sp-28:28` · `sp-32:32` · `sp-44:44` · `sp-999:999`（胶囊圆角）

**命名即值**（`sp-7` 就是 7px），杜绝阶段②那种"名字与实际值对不上"（原 `sp-2` = 8px）。
值域取到 44px 是因为 `padding`/`border-radius` 的真实值里 **7px×29 · 9px×15 · 18px×14 · 11px×8 · 22px×4**
这些是正经高频值（不是 gap 里只出现一次的零散值）⇒ **补刻度、不硬掰到邻档**，仍是零漂移。

**负向偏移不入刻度**（有意决定）：`margin: -13px 0 0 -13px` 这类是**定位偏移**（重叠 / 贴边让位），
语义与"间距节奏"不同，建负刻度会让人误当成间距档来用；实测只出现在少数定位处，保持原值书写。

**四族已全量落地**（阶段④首轮）：`gap` / `margin` 两族 502 处；第二轮 `padding` / `border-radius` 两族 514 处。
合计 **1016 处**，硬编码 px 从 **572 → 3**，`var(--wui-sp-*)` 用例 **0 → 1325**。
剩下 3 处＝刻度外的 1 个 `34px`/`19px` 与 `margin: auto` 居中（后两类本就不该 token 化）。

### 6.2 字号字阶（**2026-09-25 船长裁决：刻度贴着真实值改 · 零观感漂移**）
`11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 15 / 17 / 19 / 21 px` → 收成 **18 档**：

| token | 值 | token | 值 | token | 值 |
| --- | --- | --- | --- | --- | --- |
| `--wui-fs-2xs` | 9px | `--wui-fs-sm` | 12.5px | `--wui-fs-xl` | 17px |
| `--wui-fs-2xsb` | 10px | `--wui-fs-base` | 13px | `--wui-fs-2xl` | 18px |
| `--wui-fs-2xsc` | 10.5px | `--wui-fs-baseb` | 13.5px | `--wui-fs-3xl` | 19px |
| `--wui-fs-xs` | 11px | `--wui-fs-md` | 14px | `--wui-fs-4xl` | 20px |
| `--wui-fs-xsb` | 11.5px | `--wui-fs-mdb` | 14.5px | `--wui-fs-5xl` | 36px |
| `--wui-fs-s` | 12px | `--wui-fs-lg` | 15px | | |
| | | `--wui-fs-lgb` | 16px | | |

**为什么不是阶段②原定的 6 档**：实测（`_scale-options.ts`）原刻度 `11.5/12.5/13.5/14.5/17/19` 只命中真实值 **8%**，
照它迁移要动 156 条 0.5px、16 条 1px = 全站字号重排。改为贴真实值的 18 档后命中 **92%**，
**每条替换前后像素完全相同 ⇒ 零观感漂移**，而 token 单点的目的（一处改全站）完整达成。

**硬约束：`calc()` 里的字号必须保持精确数值**。本仓有两处既有机制依赖最终字号：
- `calc(var(--ui-fs, 1) * Npx)`（32 处）= **设置→字体大小**的缩放倍率。token 代进去后 N 必须**分毫不变**，否则缩放基准被改、与玩家设置叠加出偏差；
- `--app-head-fs: 13px`（styles.css:88）= 标题缩放的**单一常量**（全站标题走它）⇒ 它本身就是合格的单点，**优先改它、不逐处改标题字号**。

**字体族不动**（系统雅黑栈 + Cascadia Mono），不用 Fira 系。
