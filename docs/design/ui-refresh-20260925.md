## 六、设计系统定稿（本仓口径 · 只写"我们怎么用"）

### 6.1 密度（采纳技能拨盘 8/10）
- **行高节奏**：紧凑行 28px · 常规行 32px · 分组块内边距 8/12px · 分组块间距 8px；
- **一级页仍不滚**（2026-09-08 船长红线不变）：密度提升靠"分组 + 徽标列"，不靠缩字。

### 6.2 字号字阶（现状取整为档，不新造字体）
`11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 15 / 17 / 19 / 21 px` → 收成 **7 档**：
`--wui-fs-xs 11.5 · sm 12.5 · base 13.5 · md 14.5 · lg 17 · xl 19 · mono`（等宽仍走 `--wui-mono`）。
**字体族不动**（系统雅黑栈 + Cascadia Mono），不用 Fira 系。

### 6.3 动效（本次新增单点）
| token | 值 | 用途 |
| --- | --- | --- |
| `--wui-dur-1` | 120ms | 悬停/按压反馈 |
| `--wui-dur-2` | 200ms | 状态切换 |
| `--wui-dur-3` | 320ms | 面板/弹窗进出 |
| `--wui-dur-loop` | 1200ms | **无限循环**动画的基准周期（各动画按倍率派生） |
| `--wui-ease-out` | `cubic-bezier(.2,.7,.3,1)` | 进场 |
| `--wui-ease-in-out` | `ease-in-out` | 循环/呼吸 |

### 6.4 无障碍硬线
- **`prefers-reduced-motion: reduce` 必须覆盖全部 51 条无限动画**：统一改 `animation: none` 或 `animation-duration: 1ms`（保留终态），并在契约里加一条体检；
- 正文对比度 ≥4.5:1、识别色 ≥4.5:1（已有 `ui:theme-check` 守着，不放松）；
- 键盘焦点可见（`:focus-visible` 描边用 `--wui-accent`）。
