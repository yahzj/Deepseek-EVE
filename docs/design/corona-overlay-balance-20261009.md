## 数值口径

- 叠光级敌舰：叠光装置的全部伤害乘区由 `0.3` 改为 `0.5`，实际按每发统一乘区生效。
- 叠光激光炮：沿用正常 MK3 激光炮 `dmgMult = 4.2`，玩家单发取 `4.2 × 0.5 = 2.1`，相对旧 `1.26` 为约66.7%上调；射程由7000米下调至6000米。
- 叠光激光炮的 `overlayDrive = { stepMs: 300, floorMs: 600 }` 不变；叠光级敌舰挂件的装填加速和闪现推进不变。
