# T2 技能队列改造（状态：已确认）

> 来源：船长测试反馈单 T2（roadmap 置顶，批次 A 主体）。2026-09-04 经四步闸门确认后实现。
> 关联：`docs/roadmap.md` T1–T11 清单、`docs/architecture.md` 里程碑表。

## 需求原句（逐字）

- a) 暂停当前训练且保留进度；
- b) 同一技能可多次入队（目标逐级递增，连锁学习）；
- c) 取消靠前队列后后续自动顺延（去重校验随之调整）；
- d) 技能说明中"实际效果"文字做高亮/换色区分；
- e) 显示该技能各级训练时间；入队后改显下一级队列时间。

## 已确认的设计决策

1. **"暂停"实现口径 = 取消并保留本级进度**：不做暂停状态位。
   取消队首训练时，把"本级已练毫秒"暂存（`skills.savedProgress`，键=技能 id）；
   之后重新把该技能排为队首占位（练的正是暂存所属那一级）时自动续接并清掉暂存。
   → 存读兼容字段（completedBounties v15.1 先例）：normalize 补默认，**不 bump 版本号**。
2. **连锁入队**：同一技能可多次入队，但目标等级必须逐级 +1——
   下一个可排目标 = 已学等级 + 1 + 队列中同技能条数；跳级与重复目标都按此拒绝（提示语说明"需先排 LvN"）。
3. **取消顺延**：移除第 i 条后，排在它**后面**的同技能条目全部顺延一级（填补被取消的那级空位）；
   其它技能条目不受影响（各自只数自己的同技能链）。
4. **队首进度去向**：取消队首且进度 > 0 时——
   - 有顺延后继（顺延后目标 == 被取消条目的目标，即接替同一级）→ 进度转交后继，队列继续自动练到该级完成；
   - 无后继 → 存入 savedProgress（见 1）；
   - 零进度 → 仅顺延，无转移。
   清空队列 = 队首同规则（只暂存，因为后续条目一并被清掉）。
5. **说明高亮**：`@whale/data` 技能表 description 内"实际效果数值段"用 `⟦…⟧` 括起
   （如 `⟦4%⟧`、`⟦1 艘⟧`；同一句可多段：会计学/贸易谈判学）。界面渲染为金色高亮并去掉符号；
   悬浮提示 / 手册等纯文本场合 strip 掉符号。无数字效果的技能不加标记。
6. **时长展示**：技能行空闲 → 训练按钮下方显示本级时长；已排队/训练中 → 追加按钮指向
   "下一队列级"并显示该级时长；排队等待估算 = 队首剩余 + 前置各条单级时长；
   技能行悬浮提示列出 1~5 级各级时长（公式 rank × 2^(Lv−1) × 60s，不变）。

## 边界与兜底

- **旧档跳级条目**（旧规则允许直接排 Lv3，无中间条目）：引擎照旧一路练到底（原有多级推进分支即兜底），
  不迁移、不阻塞、不丢档；顺延/承接对这类非连续链尽力而为（目标不衔接时改走 savedProgress）。
- **续接附着与位置无关**：即使新条目排在别的技能后面（非队首），暂存进度也先附着到该条目上，
  等它成为队首时才消耗——不会因为中间插了别的技能而丢进度。
- 目标 <= 已学等级时拒绝并顺手清掉该技能已无意义的暂存值。
- savedProgress normalize：只收正数毫秒、整数、封顶一天（正常单级最长约 1 小时，留足余量）。

## 涉及文件

- `packages/core/src/state.ts`：SkillsState + `savedProgress` 字段与初始值；
- `packages/core/src/save.ts`：normalize 容错读取（无版本迁移）；
- `packages/core/src/engine.ts`：`enqueueSkill`（连锁校验+续接附着）/ `removeQueueAt`（顺延+承接+暂存）/
  `clearSkillQueue`（保留队首进度）/ `skillQueueStatus`（pending 带真实队列下标 queueIndex 与单级时长 levelMs）；
- `packages/data/src/skills.ts`：6 条效果描述包 `⟦…⟧`（导航学/跃迁引擎操控/加速控制理论/人工智能专家/会计学/贸易谈判学）+ 表头标记约定；
- UI：`SkillsPage.tsx`（队列头取消、按 queueIndex 移除、连锁追加、时长、`⟦⟧` 金色高亮、续接提示）、
  `ActivityBar.tsx`（移除训练提示改文案）、`Handbook.tsx`+新增 `ui/skillText.ts`（纯文本 strip）、styles.css；
- 测试：`engine.test.ts` 适配连锁规则，新增 `packages/core/tests/t2.test.ts`（9 例）。
