# T3 货仓归属与副船查看（状态：已确认）

> 来源：船长测试反馈单 T3（roadmap 置顶，批次 A）。2026-09-04 确认设计后实现。
> 关联：`docs/roadmap.md` T1–T11 清单、`docs/architecture.md` 里程碑表。

## 需求与确认口径

- 原句：货仓页显示当前舱属哪艘船；可切换查看副船货仓。
- 船长确认（推流问答）：**1甲** 本批只做"切换查看"，副船货仓只读（不做装卸/出售，那属结构级另立项）；
  **2甲** 作业中的船（采矿/远征/AI 在外）仍可切换查看，标注"作业中"；**3甲** 页面动作
  （市价卖出 / 全部卸入仓库）始终只作用于"当前驾驶的船"。

## 设计

### core（只读扩展；不改任何写函数签名、不动存档、无版本号）
1. `inventory.ts` 新增按船查询，现有"当前船"函数改为薄委托（行为零变化）：
   - `cargoOfShip(state, shipId)`：任一舰队船货仓内容（缺船/条目缺失按空）；
   - `cargoUsedM3Of(state, ctx, shipId)`、`cargoCapacityM3Of(state, ctx, shipId)`：
     体积与容量按**该船自己**的舰船定义 + **该船**货舱槽装备加成（与驾驶船同公式）。
2. `activity.ts` 新增 `shipBusyLabel(state, ctx, shipId): string | null`——船忙态的**唯一判定源**：
   - 驾驶船：采矿（采掘中/采矿·出航中/采矿·返航中）、扫描探索中、远征（·出航/·交火/·返航）；
   - 副船：AI 任务各阶段（AI 采矿中/·出航/·返航；AI 远征·去程/·交火/·返航）；
   - 制造与技能训练不绑船，不算忙；空闲/未知船返回 null。

### UI（CargoPage）
- 面板顶部"查看"船选择条：舰队每艘船一枚 chip = 船名 +（驾驶中）标记 + 出勤徽标（红字忙态），
  点击切换查看目标；默认 = 驾驶船；**驾驶船变更自动跟随**；选中船已不存在（卖/弃船）自动回驾驶船；
- 容量占用条与分组货单全部跟随所选船（组标题标注 驾驶船 / 查看中）；
- 动作隔离：所选 = 驾驶船 → 卖出/卸货按钮照旧；所选 ≠ 驾驶船 → 按钮不渲染，行尾"只读查看"灰字，
  顶部备注"只读查看：装卸与出售仅对当前驾驶船可用"+ 该船忙态/闲置说明。

## 边界与容错
- 数据表缺 def 的船：容量显示 —（core 返回 0），货仓照读，不崩；
- 不存在的 shipId：货仓空、容量 0、忙态 null；
- 空货仓分组提示随查看对象措辞（副船矿石空：`「船名」的货仓里没有矿石。`）；
- AI 副船与驾驶船互斥由引擎既有规则保证，忙态按 shipId 直接命中，无附加锁定。
