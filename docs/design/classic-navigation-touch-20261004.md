# 旧版导航单指拖动

> 状态：已确认，已实现，自测通过，待合入验收（三号 · verify · 2026-10-04）
> 船长：「然后添加一个允许玩家通过手指拖动上下滑动导航栏的功能（旧版）」。

- 只在旧版手机导航内部列表绑定单指拖动；底部开关、新版、鼠标与网页版尺寸排列不变。
- 读取根旋转缩放矩阵，将物理手指位移映射到列表纵轴；普通横屏用Y，旋转竖屏自然映射到X。
- 8物理像素纵轴阈值，轻点切页不拦截；拖动捕获指针，限制scrollTop在合法范围，结束阻断误触点击，下一次按下恢复轻点。
- 双指不继续拖动，保留pinch-zoom；取消和卸载释放捕获、监听与短时点击保护。
- 实现为导航UI域，参照虫洞已有指针捕获/拖动防误点与Tooltip坐标换算；不动存档、玩家文案及其他手机样式。
- 计划：纯函数事件夹具覆盖方向、缩放、阈值、多指、边界、清理；真实生成CSS的无头Edge夹具实发触摸，升级旧版旋转从记录失败到必须成功断言。
- 本地验证后合入，待验收不推送；个人档不读取。

## 验证结果

- 新增7条事件回归（旋转/普通方向、缩放、物理阈值、鼠标不接管、取消/清理、多指、点击保护及外壳仅旧版手机接线）；连同旧版侧栏/视口26条专项通过。
- 真实CSS及真实触摸函数在独立无头Edge外壳夹具执行：横屏滚动64px、旋转竖屏91px，拖动后导航点击计数0，下一次轻点计数1。旧版旋转触摸由上一批记录为0，升级为必须大于0的硬断言后通过，不再以程序scrollTop替代手势成功。
- 两套计算尺寸与网页版仍一致，旧版展开外宽189px，新版左列150px；底部开关不绑定拖动，旧版折叠时同一列表继续可拖。
- 全量330文件3889用例、四包typecheck、ui:rot-check、ui:layout-css:check、arch:guard及桌面/网页构建通过。正常提交仍跑内容与本地化闸门，不跳过检查。
- 测试目标是合成事件和浏览器真实触摸夹具，不是个人存档或完整游戏真机观感。无惯性滚动新增；手指移动时直接跟随，轻点保留。设备原生双指缩放与pointercancel已留通道。
