# 编队预设交战距离

状态：实现与专项自测完成；船长已指示收尾、合并并推送，执行合入验证中；本批不部署或发布桌面版。

船长原话：「是否应该给不同编队一个预设距离？用于替换之前的按敌卡预设的距离？」；已确认编队距离替换敌卡自动记忆的方案。

- 预设保存主控、成员顺序和可选默认期望距离；自动档沿用现有距离计算。套用预设同时应用距离，同一批舰船的不同预设互不覆盖。
- 战中拖动、战术和战前确认仅改本场；明确保存到出发预设才修改长期默认。快照绑定预设及实际名单，不能保存到不匹配的临时队伍或已经更改名单的预设。
- 当前编队距离单独管理，保存新编队或覆盖预设时一并保存；没有设置的旧预设默认自动，不从旧敌卡或星系记录推测迁移。
- 开战入口和预估改读编队距离；自动探索显式自动距离不读写玩家偏好。旧敌卡数据保留兼容，不再读写；旧在途战斗保留自己的当前距离。
- 换装备或改成员后不静默修改默认米数；配置变化提醒使用编队的射程证据，与敌卡无关。新旧存档字段走白名单、坏字段丢弃，不升级结构版本。
- 前一批返航切换预设修复保留；不改战斗数值、随机源、实际开战距离、敌方机动，不发布桌面版。

依据：`.wiki/projects/pitfall-combat-fleet.md`与`.wiki/concepts/save-architecture.md`（confidence: extracted）的宿主一致取值、出发快照与清洗白名单原则。Serena与知识库专用工具未提供，使用定向读取。UI技能查询`save confirmation feedback --domain ux`匹配保存后的明确反馈，沿用现有数字输入与保存图标。

验证：实施后覆盖预设切换、同船不同预设、旧记录隔离、各战斗宿主、确认后配置重验、战中显式保存、自动探索隔离及存档往返。仅使用合成场景，不读取个人真档。

## 实现与验证

- 功能域为编队作战距离；沿用已有预设操作、射程确认事务和战斗宿主解析。涉及战斗、远征、舰船预设与存档接线，依据本次已确认的替换方案；不调整战斗数值或其他玩法。
- 默认米数和最大射程证据分别保存；战中拖条、战术与战前确认不覆盖长期默认。临时默认保存会解除当前预设绑定，预设本身不变。
- 远征出发快照锁定距离、名单与来源，途中改默认不影响到达开战；删除仍被战斗引用的预设后，新预设不复用该编号。
- 预估快照映射舰船实例编号，缓存包含有效编队距离；固定默认只采该距离，自动档保留三点采样。旧敌卡与胜利距离不参与选距。
- 19份受影响专项共299条通过；最终核心边界另复跑84条通过。包含前批返航切换修复；未运行完整core回归，留待集中验收。
- T2六项检查、`l10n:params`、`save:roundtrip-audit --synthetic-only`通过；网页版生产构建通过，未执行Windows桌面打包。
- 文案新增`core.fleetRange.001～002`与`ui.fleetRange.001～018`，中文落地、英文延期；旧滑条自动记忆文案保留原ID/英文但停止调用。

## 独立验收档

运行`npx tsx tools/make-fleet-presets-save.ts`可重建全新合成状态，工具拒绝覆盖已有文件。当前输出`docs/test-saves/test-save-fleet-presets-20261118-115940.json`，包含三舰近距1800米、同船三舰远距7000米及双舰自动三套预设，当前套用近距。

加载前先在游戏内备份当前进度，再在设置中导入测试档。到舰船页展开编队预设，检查近距/远距切换、自动/手动保存及重载；出战后拖动距离不应改预设，明确保存应写回出发预设。测试结束导回自己的备份。工具不读取个人档。

浏览器取证使用`node tools/fleet-presets-browser-check.cjs`，优先验证最新`web/dist`；自有无头Chrome与合成档，覆盖classic/modern和1366×768、390×844。预设操作四组与战斗保存四组均通过，底栏文字及控件无越界；主动压窄按钮能检出文字溢出。既有按钮高光伪元素会让scrollWidth多2像素，按钮按实际文字边界检查，其他容器保留滚动宽度检查。结果不等同船长观感验收。
