## 6. 纪律速记（本轮踩过的坑）

- **中文盘写入**：一律 .NET 显式 UTF-8（`WriteAllText` + `UTF8Encoding($false)`），**行尾 CRLF**；
  合并/批量写文档后三查：BOM/行尾与改前一致 · 全仓往返解码乱码 0 · 与两侧父提交比「父提交有的行还在」。
- **`git add` 显式路径**；多行 commit 信息用 `git commit -F <tempfile>`（PowerShell 里 `-m` 多行会炸）；取历史版本 = `git checkout <rev> -- <path>`（不经变量中转）。
- **PowerShell 陷阱**（本轮反复命中，照抄即可避）：`[System.IO.File]::ReadAllText` 相对路径按**进程 CWD** 解析（不是 `Set-Location` 的位置）⇒ 一律给绝对路径 ·
  多行 here-string 做 `.Replace` 会撞 CRLF（用单行锚点）· 把 `@( @(a,b) )` 传给函数会**被展平**而静默无操作 · 反引号 `\t`/`\n` 在 JSON 串里会被吞（用 `[char]9`）·
  `Get-Content` 在控制台会把中文弄花（看文件用 read/grep 工具）。
- **临时探针一律 `_` 前缀**，收尾二选一（转正式入库 / 删除）；读数日志落 `tools/_ui-artifacts/*.log`（gitignore 区，船长随时可看尾）。
- **后台任务**每 2 分钟无新输出主动查一次（读日志尾 / 进程在不在）；收尾用 `job_kill`，**绝不对浏览器进程下手**。
