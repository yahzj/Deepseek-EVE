# 物品与舰船筛选归类统一

> **状态：已确认，实施中**（三号 · verify · 2026-10-04）
> 船长原话：「玩家反应，标签筛选混乱，我之前已经统一过一次了，但是依旧不太好用，同时还有个BUG，物品页的仓库内，二级筛选标签失效了，我希望你能对各个模块使用的标签进行统一归类：将所有物品舰船划分，最好能囊括在2个标签内，并且玩家查看时不会出现一个细分标签内太多不同东西的情况，并新增一个其他类别：其他用于临时放置新增的没有分类的物品。」
> 后续确认：「物品和舰船除了市场外好像没有其他地方会同时出现了，单独占用一级合适吗？」→「好的」。
> 范围：统一市场、物品页仓库、货仓、物品/装备/舰船图鉴、舰队与舰船仓库使用的筛选层级；修复物品页仓库二级筛选实际不生效的问题。
> 不做：不改物品、装备、舰船的 id、名称、数值、配方、掉落、存档字段或玩法；不改蓝图生产判据，只保持其产物维度。
> 跨域依据：船长确认了市场、物品、舰船、图鉴之间的统一筛选口径；共享单点 `ui/itemSubs.ts` 作为分类表与判定入口。

## 已确认口径

- 市场同时出现多种资产：一级保留「全部 / 物品 / 舰船」两大域；物品域二级为货物、装备、消耗品、货柜、残骸、黑匣、蓝图、AI 核心、其他；舰船域二级为采矿舰、货运舰、武装舰、装甲舰、其他。
- 物品页仓库、货仓、物品图鉴不再显示只有领域意义的「物品」一级，直接使用物品分类；装备的槽位与功能作为后续细分维度。
- 舰队、舰船仓库、舰船图鉴、造船厂、虫洞编队不再显示只有领域意义的「舰船」一级，直接使用舰船类别；舰船级别保持独立筛选维度。
- 蓝图和组装机沿用产物分类，不强行套入物品/舰船领域。
- 每个领域增加「其他」兜底；只有实际存在未登记或无法识别的条目时显示，未知条目不得从筛选结果消失。
- 各页面按实际内容隐藏空筛选项；切换父级后，子筛选回落到「全部」，避免旧键残留。

## 根因与实现

- 物品页普通物品的列表模式与网格模式只按物品 `kind` 渲染，未调用已有的 `dimHit()`；装备库调用了该判定，所以出现“标签变化、内容不变”。两种视图统一调用 `itemBucketPasses` + `itemSubPasses`。
- `ui/itemSubs.ts` 新增市场领域表、物品领域表和未知类兜底判定；市场页面使用领域→二级分类，其他物品页面使用物品分类表。
- 旧槽位与功能表保留为细分维度，兼容蓝图、装备图鉴和工业页的既有产物判据；不把高/中/低槽和功能族混进同一个一级标签。

## 验收与边界

- 验收重点：市场一级只出现领域；市场选择物品/舰船后只出现对应二级；物品页仓库列表/网格二级筛选一致；新未知条目能落入其他；空子类不显示；中英文标签取词一致。
- 验证：筛选单元/静态接线回归、四包类型、核心测试、`content:check`、`l10n:check`、`l10n:params`、`ui:rot-check`、`arch:guard`。
