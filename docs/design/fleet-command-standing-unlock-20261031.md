# 编队技能分类与20声望解锁通讯

> 状态：实现、专项回归与隔离桌面冒烟完成，待船长验收。二号，`d2/workspace`，2026-10-31。

## 船长原话与确认

「将编队相关的技能的技能分类放入舰船大类中，同时将战舰操作也放入舰船大类中。当玩家20声望后弹出一个通讯，告诉玩家解锁了编队相关的内容和技能，跳转为跳转到编队的技能学习页面」

确认覆盖既有技能分类裁定「武装舰操作、装甲舰操作归战斗」。获准后，两个技能书整体移入“舰船”大类，其他战斗技能分类保持不变。

通讯文案经船长确认，消息数据引用经批准的本地化 ID：

- 主题：多舰编队权限已开放
- 正文：飞行员，协会确认你的累计声望已达到20，多舰编队权限现已开放。
- 正文：编队指挥技能已列入舰船训练科目，可前往查看并安排训练。
- 跳转：前往舰船技能，直接落点为技能页“舰船 → 编队指挥”技能书

## 改动

- `b-warship`、`b-command` 两本技能书及其全部技能组改为“舰船”。
- 保留技能 ID、书名、rank、训练效果、真前置与技能树坐标；战斗中的武器、命中、弹药、无人机等书仍归“战斗”。
- 编队门槛 `20` 从 command config 经 `COMMAND_STANDING_REQUIRED` 导出，指挥预算判断、通讯触发和内容门槛契约共用同一值。
- 新增 `msg-fleet-command-unlock`：累计协会声望达 20 后一次性投递并弹窗；通讯的主题、正文和跳转提示登记为本地化 ID，数据消息表引用这些 ID。与其他新消息同拍满足时，此信在目录内优先投递，保留全局每拍只弹一封的既有规则及已入队弹窗。
- 通讯跳转扩展可选的 `skillBranch`；弹窗与收件箱共用出口，直接定位“舰船 / 编队指挥”，清空搜索和状态筛选并收起原技能详情。旧的仅定位大类请求仍兼容。该字段仅属于静态数据和界面请求，不写游戏存档。
- 未获英文准备授权；四个通讯 ID 以 `enDeferred: true` 登记并排入待本地化表，英文界面按共享规则回退显示批准的中文，不加空白或伪译。
