## 架构（两条取舍，为免上千处改动）

- **内容层**（`packages/data`）：新增**按 id 索引的英文覆盖表** `data/src/l10n/en/*.ts`（`{ name, description }`）＋
  `localizeDef / localizeCtx(ctx, locale)`；`buildSimContext(locale?)` 增可选参数。
  **`locale === 'zh'` 时原样返回** ⇒ 现有工具 / 测试 / 模拟逐字不变。英文只覆盖 `name/description`，id 与数值一字不动。
- **界面层**（renderer `i18n/`）：`L10nProvider` + `useL10n()`；词典**以中文源串为 key**（必要时 `#上下文` 后缀消歧），
  `t('装配')` **缺 key 自动回退中文** ⇒ 可分批翻、永不白屏，并可由工具列出未译清单。
  `fmtNum / fmtIsk / fmtM3` 走当前 locale（替换 353 处硬编码 `toLocaleString('zh-CN')`）。
- **字体**：`[data-locale="en"]` 切 Latin 优先栈（`Segoe UI / Inter / system-ui` → CJK 兜底），中文侧一字不动。
- **校验工具**：新增 `npm run l10n:check` —— ① 英文表 id 集合 = 中文表（缺失 / 孤儿都红）② UI 词典无死 key ＋
  列出未译可见串（报告）③ 英文串禁残留 CJK（白名单除外）④ 占位符 / 单位一致性。
  `content:check` 的**禁用词契约按语言分叉**（中文侧仍禁 EVE/ISK/NPC；英文侧另立清单）。
