# 扩槽插件同类型限装与免费退回

> **状态：已实现、自测通过，待船长验收；本地合入收尾中，未推送**（零号 · `dsh/system-search-20261007` · 2026-10-08）
> **船长原话**：「增加槽位的舰船插件限制为只能使用一个，如果玩家已经安装多个，免费帮玩家拆卸。」
> **最新澄清**：「是同类型的增加槽位的插件只能用一个」。
> **范围**：中槽扩展插件、低槽扩展插件各自最多一件；同类型多余件完整退装备库，减少的槽位上的装备完整返还。普通重复插件、战损、历史沉船记录和装配方案参考不改；不提供通用插件拆卸入口。
> **待裁决**：无；以最新澄清为准，两类可以同时安装。不推送，不操作个人档；公告仅备审。

## 已明确行为

- 每艘船增加中槽的插件限一件，增加低槽的插件另限一件，两者不互斥；其它插件仍可按现有槽位重复安装。
- 旧配置保留同类型最先安装的一件，其余完整返还装备库，不扣信用点、不折黑匣、不销毁。
- 清理后真实槽位按剩余插件重算，超出位置的模块退库，其余位置和伤比例保留；不自动重新分配装备或收费维修。
- 启动和导入沿现有装备修复入口执行；重复刷新不会再返还。历史记录和方案不是实际已装件，不凭它们返还库存。
- 在途队伍应避免中途清空装备计时／供给；在合法结束点整理，载入时也能继续完成后整理。沉船整船回收不得重新装回同类型重复扩槽插件。

## 参照与边界

主域舰船与装配，沿`installPlug`、`repairDeprecatedModules`、旧插件归位及溢出退库机制。存档不新增字段、不升版本，不改个人档。必要战损整船恢复接线属于插件存量兼容，不调整回收概率、装备保全率、残骸或历史快照。当前实现位于零号隔离树，不触碰零号根目录另一批数据编辑器工作。

## 实现与验证

- 限装由 `plugs.ts` 的类型判据和门禁提供，安装命令与装配候选共用。按实际加槽字段判类型，不按型号名称，另一种扩槽和普通重复件仍可安装。
- 旧配置沿装备载入修复入口整理，引擎心跳补齐解锁后的整理。采矿、打捞、运输、交付、返航、远征、遭遇战、AI 作业、洞内编队均避免中途改配置；真整船回收接线也不能重建重复扩槽配置。
- 专项新增 13 项：类型互斥与并存、拒绝不扣库、免费退回、缩槽与机体守恒、幂等、真实存读、忙态保护、真实停采返航到港、旧误装归位、历史方案与沉船保留、整船打捞、实际候选表达式和双语日志。旧扩槽、重复插件与负面叠加测试改为合法新配置或明确历史夹具，不降低守恒及原数值断言。
- 全量核心：402 个文件、5304 项通过、8 项原有跳过。四包类型、内容、旋转、109 条架构单点登记、本地化表与 218 处内联日志对照通过。
- 存档往返：105 份可迁移档成功，第二轮丢键和类型变化均为 0；历史 v17 档一份低于当前 v24 迁移下限，维持现有拒绝，不扩大支持范围。
- 桌面和网页构建通过。隐藏 Electron 使用隔离新档完成旧界面中文桌面与新界面英文竖屏回归，验证普通插件重复安装、沉船卡牌、方案保存和真实保存重载；不用个人档，读数不是船长观感验收结论。

## 公告备审

玩家每艘舰船最多安装一件中槽扩展插件和一件低槽扩展插件，两者可以同时使用。已有同类型重复插件免费退回装备库，减少的槽位上的装备一并退回；其它插件仍可按现有规则重复安装。
