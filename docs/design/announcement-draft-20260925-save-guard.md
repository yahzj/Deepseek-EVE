- **date**：`2026-09-25`
- **tag**：`系统`
- **bullets**（5 条）：

1. 网页版可以把存档绑定到本机的一个文件：在「设置 → 存储状态」里点「绑定本地存档文件」，选好位置后，游戏每次保存都会同时写进这个文件；浏览器数据被清理时，从这个文件即可继续进度。
2. 绑定之后浏览器里仍会保留一份，两份取较新的继续；浏览器重启后若显示「需点一次『重新连接』」，点一下即可恢复。
3. 浏览器不允许本页保存进度时（例如隐私窗口），游戏会当场提示，不再安静地丢进度；关闭或切走页面之前，游戏也会再保存一次。
4. 旧存档一时读不出来时，游戏会暂停写入并提示，避免旧档被覆盖；玩家确认后可在设置里放行写入。
5. 「设置 → 存储状态」新增一行状态显示：存档在哪里、当前能不能写、是否已获浏览器持久保存，以及绑定的本地存档文件名。使用 Safari 的玩家无法把存档写到本地文件，建议改用 Chrome 或 Edge 打开本页，或把本页「添加到程序坞」，并定期「导出存档」。
