# 守墓入侵蓄能、复活与基础属性调整

> 状态：已确认，实施中。船长回复「确定」。二号，d2/workspace，2026-10-16；基线f8470a57。

## 船长原话

「永陵每次叠加的伤害加成改为0.3（顺便检查下永陵蓄能是加法还是乘法，如果是加法，将伤害加成改为0.4），给予永陵级每隔60秒复活所有友方的挂载件（参考其他旗舰）。本次入侵的敌舰有30%的护盾动能抗性。并将本次入侵所有敌舰基础速度平均提高20%。」

## 核对结论

- `gravekeeperCombat.foeCapacitorMultiplierOf`按指数乘算，当前每层伤害乘1.15、装填乘1.1；不是加法。依船长条件，本轮伤害应改为每层乘1.3，n层为1.3的n次方，不使用加法0.4。
- 墨潮旗舰复活挂载复用`resolveFoeRevive`，只复活当前波已阵亡且空槽的友舰，满血以支援单位入场；不跨波、不超编、召唤者死亡停止。永陵当前末波友军为王座舰一艘、静滞卫舰两艘。
- 本轮四卡均复用部分旧D舰。速度与护盾抗性必须限定守墓入侵派生卡，不能直接修改共享长舰、静滞与王座舰定义而影响旧悬赏/虫洞。

## 拟议实施方案

1. 蓄能每层伤害改为乘1.3，间隔每层乘1.1不变；首次空盾、本场永久、全部武器独立计数、八炮一组每轮记一次、无玩法叠层上限等现行规则不变。射程仍提高50%，不混入本轮未要求的期望距离改动。
2. 新增永陵专用挂载，拟名「陵寝重构协议」。参照现有旗舰复活入口，自永陵本波入场起每60秒复活本波全部已阵亡友舰；当前配置最多三艘，满血、相同原配置，使用既有支援入场窗口并真实参战。活着的不治疗或复制，复活后再次阵亡可在后续周期再补；无尸体跳过不积攒次数，永陵死亡停止。不同意跨波复活前不扩大到之前三波。
3. 四张守墓入侵卡中的全部敌舰护盾动能抗性设为30%，仅这一伤害类型和血层；装甲/结构现有抗性与其他护盾抗性不变。复活舰继承本卡配置；不影响玩家装备、普通D悬赏/信号空间/虫洞。
4. 四卡每个敌舰编成条目的基础速度乘1.2，在现有舰种基准×舰级速度倍率×条目速度倍率后统一取整。不是只提高整队显示读数，不改敏捷、全局机动公式、推进器或玩家速度。复活舰同样继承加速。
5. 原血量、共享旗舰血池30万、编成/波次数、固定主炮伤害、射程、近盲、装填基础值、期望距离、卡面威胁标签及掉落不顺带调整。重跑实际属性/威胁/战斗读数；若既有标签契约与新增复活要求冲突，报告实际偏差，不自行通过额外放大火力追标签。
