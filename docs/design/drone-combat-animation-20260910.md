# 无人机战斗动画 + 损毁系统（2026-09-10 船长逐轮拍板，状态：已确认）

> 三号 经办。本文记录全部已确认口径（含后续损毁系统），实现分两批交付：
> **第一批 = 动画演出**（本轮）；**第二批 = 损毁系统骨架**（紧随其后）。

## 一、背景

玩家反馈："战斗动画与普通武器同质化"。根因（读码确认）：
- `WeaponSpec.kind` 只有 `gun/beam/fixed`，**无人机与「基础舰炮」同为 `fixed`**，引擎层分不出；
- `BattleFx` 只带弹型（kinetic/explosive/plasma）+ 命中，**不带武器来源** → 表现层只能按弹型画弹道；
- 战斗画面只画主舰与敌舰，**画面上看不到任何无人机**。

## 二、已确认口径（逐条）

### 机型与演出
1. 四型：`drone-scout` 蜂鸟 / `drone-assault` 赤鸢 / `drone-heavy` 猎鹰 → **放飞-回巢**；
   `drone-sentry` 雷鸥哨戒 → **常驻伴飞（母舰下方）**，多架只显 1 架动画。
2. 放飞触发 = 该型首次开火；**该型 ≥1.2s 无开火 → 回巢**（收舱时仅机库口微光）。
3. 演出制式（2026-09-10 船长二次定，两套都保留、常量切换）：
   - **出击制 `sortie`（默认）**：无人机自母舰放出 → **飞到敌舰侧的攻击阵位开火** → 无开火 1.2s 后原路返航；
   - 机群制 `formation`（保留）：无人机在母舰上侧编队巡飞，弹道自编队位起飞。
   切换点 = `ui/droneArt.tsx` 的 `DRONE_STYLE`（两套 CSS keyframes 均在）。
4. 每型显示上限 **6 架** + `×N` 徽标；混装各型各自编队；战败（母舰被毁）**不回收**，随机体消失。

### 弹道与表现层
4. 颜色**按弹型**（动能金 / 高爆橙 / 能量青，与炮台同一读图语言）；**机型决定弹点形制与密度**
   （蜂鸟最密最小 / 赤鸢中等 / 猎鹰大而沉 / 哨戒远程小束点；猎鹰与雷鸥同为能量型，靠形制区分）。
5. 弹道起点 = **该型机体当前位置**（不参与母舰炮口轮换；炮口轮换只留给炮台/激光/导弹）。
6. 同型同帧多架开火 → **合并为一波**（每波 ≤3 条蜂群点，密度体现数量）。
7. 命中特效**小型化**（与炮台大 puff 区分）。
8. 顺带修：射程弧列表把无人机逐架条目**合并为「机型 ×N」一条**（冷却条同步），不再 16 条刷屏。
9. 视觉纪律：机体与弹点全部 **SVG 线稿**（禁止 CSS 拼形状；动作走 CSS 动画 + 类切换）。

### 多单位接口（为副本机制预留）
10. 机群渲染器按**单位**设计（unitTag + 锚点 + 显示宽 + 机型表）；当前只喂主舰 `player`。
    未来副本机制的多船舰队战斗**只需把友军单位加进列表**，引擎无需再改（`fx.tag` 已标识单位）。
11. **敌方机群预留**：`foeSpec.drones` 结构 + 机群层按单位渲染；敌族数据/敌近防炮留待后续排期。
12. 状态窗（左侧导航）、装配页本轮**不做**机群预览（同一渲染器后续可复用）。

### 损毁系统（第二批交付）
13. 无人机 = **舰载子单位**（挂 `单位.drones[]`，三层血量 / 存活 / 装填相位），**不进主目标池** →
    现有全部武器与锁定装置（集火）**按构造**看不到无人机（"现有武器不攻击、不锁定"零改动成立）。
14. **近防炮预留**：`WeaponSpec.canHitDrones` 标记 + 短射程；开火时带标记武器**优先筛机群**，
    无无人机则打舰（先机后舰）。本轮只落字段与筛选分支，用测试用假近防炮驱动；真装备数据待上线。
15. 血量口径 = **物品现有 `defense` 三层**（蜂鸟 6/3/10、赤鸢 10/6/18、猎鹰 20/12/34、雷鸥 30/20/55）
    + 回避率，兑现 V11 契约。
16. 损毁演出：该架停火（机群减 1）+ 小型爆炸/坠落 SVG；新增 fx 事件 `droneDown`；战报统计
    「无人机损失 N 架」。
17. 战后结算：**损毁数从舰上机巢（droneLoad）扣除**——永久损失，需回港重新装载；日志提示。
18. 平衡影响：当前**零**（无武器可打无人机）；待近防炮与敌方机群上线后再出校准矩阵。

## 三、不做清单
无人机不单位化进主目标池、不参与伤害分摊、不改炮台/激光/导弹弹道与炮口轮换、不动物理数值、
本轮不做敌方机群与近防炮装备数据、状态窗/装配页不做机群预览。

## 三·补 2026-09-10 船长目测反馈后的修正（第一批内）
- **无人机弹道不显示（已修）**：根因 = 普通弹条靠 `scaleX(.05→1)` 曳光，弹条被压到 7px 后等于不可见；
  现改为**沿弹道飞行的曳光点**（`.app-bts-bolt-dot` + `app-bts-drone-fly`，`--fly` = 行程 px），
  与机型形制无关地保证可见性；引擎侧同时加了"实战开火事件确实带 src/artId"的回归（4 条）。
- **放飞动画改为出击制（新方案，旧方案保留）**：见上 §二.3 —— 放出 → 飞至敌侧攻击阵位开火 → 返航。

## 四、验收点（战斗目测）
- 四型单装：蜂鸟/赤鸢/猎鹰 放飞-回巢节拍、哨戒常驻下方（多架只 1 架）；
- 混装：各型独立编队、弹点形制可辨、颜色仍按弹型；
- 未进射程不放飞；停止开火 1.2s 回巢；战败不回收；
- 射程弧列表显示「机型 ×N」一条；命中特效小型化。
