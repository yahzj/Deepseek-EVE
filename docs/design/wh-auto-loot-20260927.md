# 虫洞自动探索：产出种类不对（货柜只有安全柜 ＋ 不给谜质）— 工作文档

- **状态**：已交付（2026-09-27 · 一号 · 主树 `main`）
- **来源**：船长转述玩家反馈（同一次报障的**两条症状**）。

## 船长原话（照抄）

> 虫洞自动探索有些不对，玩家带出的全是势力的安全货柜，没有其他货柜
>
> 甲
>
> 而且自动探索不给谜质

（两条症状同批处理；"甲" = 货柜那条选定的修法，见下。）

## 根因

### ① 货柜：种类**写死**成单一类型

`packages/core/src/wormholeAuto.ts` 的发货处只发 `wormholeRelicBoxIdOf(family)`
（本族**遗迹安全货柜**）——**一件图纸货柜都没有**：

```ts
// ④ 遗迹安全货柜：模拟器在遗迹格命中几次就给几件（同样按小数部分掷一次取整）
const boxBase = Math.floor(descend.relicBoxes)
const boxN = boxBase + (rng() < descend.relicBoxes - boxBase ? 1 : 0)
for (let i = 0; i < boxN; i++) gains.push({ itemId: wormholeRelicBoxIdOf(family), units: 1 })
```

而**手动路径早已演进**（`wormholeSalvage.wormholeRollRelicBox`）：

```
层 1 恒不出 → 命中率 wormholeRelicChanceOf(depth) → 贵重品货柜占比 wormholeRelicValuablesShareOf(depth)
→ 其余在 wormholeRelicBoxPoolOf(ctx, depth, family) 里等权抽
池 = 贵重品货柜 ＋ 本族安全货柜 ＋ 本层有资格的图纸货柜档（浅档恒在 · 中 ≥5 · 深 ≥7）＋ 军用备货柜
```

⇒ 自动探索这条线没跟上，还停在"只有安全货柜"的旧口径。

### ② 谜质：谜质格**根本不在模拟器的目标白名单里**

`packages/core/src/wormholeAutoSim.ts` 的"值得去的格"白名单只有
`vein / graveyard / ruins / ship` —— **`matter`（谜质格）不在内** ⇒ 模拟器整趟都不去谜质格，
谜质恒为 0。（手动：每个谜质格取回 1 台谜质储存器，撤离成功折 1 枚虫洞谜质。）

⚠ **与 2026-09-27 我给自动探索接的 `blankShareFactor` 无关**：那个参数只喂**建盘**
（`wormholeMakeGrid(..., blankShareFactor)` = 空白地点占比），不参与货柜种类抽取，也不参与目标选择。

## 修法

### ① 货柜 —— 船长选定**甲：与手动同一条池**

⚠ 关键约束：`wormholeRollRelicBox` 是**格级**函数（依赖 `run.grid` 与 `cell`），
**自动探索没有盘面**（只有模拟器的 `relicBoxes` 件数）⇒ 不能直接调用它。
**做法：把"命中之后是哪一种货柜"抽成单点纯函数，两边共用**（符合仓库的单点纪律）：

1. **`wormholeSalvage` 新增** `wormholeRollRelicBoxKind(rng, ctx, depth, family)` —— 种类抽取单点。
2. **`wormholeRollRelicBox` 改为调用它** —— ⚠ **等价重构**：随机数消耗顺序逐字保持
   （两次 `rng()` 的顺序与次数不变）⇒ 手动路径行为**一字不变**。
3. **`wormholeAuto` 发货处逐件调用它**，层取 `descend.depthReached`（真正下到的层）。

### ② 谜质线 —— 船长对两问均取推荐项

**第一问「谜质线怎么补」= 甲：与手动同口径。** 手动每格取回 1 台谜质储存器、**撤离成功折 1 枚**
虫洞谜质（`wormholeBattle.deliverExtraction`）；自动线没有 `run`、没有本趟货仓
⇒ 只能按"撤离成功"那一步折算：**1 台 = 1 枚**，直接进仓库。台数随其他产出一并打 8 折，
小数部分掷一次取整（与稀有残骸 / 货柜同一套写法）。

**第二问「去不去抢谜质」= E：与遗迹同档（rank 2，按远近竞争）。** 依据是实测：

| 方案 | 虫洞谜质 | 稀有残骸（五族） | 安全货柜 | 母矿 |
|---|---|---|---|---|
| 基线（无谜质线） | **0** | 20.4 / 18.9 / 18.2 / 17.6 / 15.6 | 贵重 1.58 · 图纸 0.47 · 军用 0.45 | 150.4 |
| 只挂 rank 0（与矿脉同档） | 0.24（48/200 趟） | 与基线**逐字相同** | 逐字相同 | 逐字相同 |
| **E：与遗迹同档（选定）** | **1.91（194/200 趟）** | −13%~−22% | 1.36 · 0.39 · 0.39 | 155.1 |
| 最优先（rank 3） | 2.48（200/200 趟） | **−45%** | 1.09 · 0.28 · 0.29 | 155.1 |

- 只挂 rank 0 实测 **76% 的趟仍拿不到谜质** ⇒ 玩家大概率还会报"不给谜质"；
- 给 rank 3 会把遗迹整条挤掉（稀有残骸 −45%、货柜 −四成），代价过重；
- 同档 = 两者按远近竞争，**遗迹那条"不能被纯最近优先饿死"的既定意图原样保住**。

⚠ 加入谜质线**必然**挤掉其他线（回合预算固定 45，手动玩家同样要选先去哪）——
这是取舍，不是缺陷；上表的 −13%~−22% 就是这个取舍的量。

## 读数（真实结算路径 · 200 趟 · 4× sh-thresher · AI 专家 6 级）

修复后 200 趟的各类产出（÷趟数）：

```
母矿 155.07 · 普通残骸 四族各 38~45 m³ · 稀有残骸 五族各 11.7~15.9
虫洞谜质 1.91（194/200 趟）· 贵重品柜 1.36 · 军用柜 0.39 · 浅档图纸柜 0.39 · 各族安全柜 0.03~0.09
出 AI 核心 26/200 趟（= 13%，与「层 1 起 10% + 每层 15%」口径相符）
```

- **货柜修复确认生效**：四类都出（贵重品 / 浅档图纸 / 军用 / 本族安全柜），
  对照修复前"**全是**本族安全货柜"。
- 谜质 **1.91 枚/趟**（研究材料，行价 70 万/枚）；对照条目 ① 的"≈0.23 件/趟"是**货柜**那条线的旧基线，
  不是谜质的。
