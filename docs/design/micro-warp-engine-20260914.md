# 微型跃迁引擎（中槽短爆发推进 · **2026-09-14 船长定 · 已确认 · 已落码**）

> 状态：**口径已确认**（四步闸门：集中提问 → 设计总结 → 船长逐条裁定 → 落码）。
> 新增内容 = 中槽 `propulsion` 三档 **微型跃迁引擎**（`mod-mwd-1/2/3`，点火 10 秒 / 冷却 60 秒）。
> 相关旧稿：`thruster-charge-20260910.md`（推进器周期爆发的原始设计）、`price-ladder-20260913.md`（价格阶梯）。

## 一、船长原话（照抄）

1. 「**添加新装备，中槽，微信跃迁引擎：提供远超推进器的加速度，但是只持续10秒，冷却依旧60秒。**」
2. 四步闸门答复：「**微型跃迁引擎，+80%（×0.80）／+150%（×0.75）／+250%（×0.6），周期方案按你算。
   件数/档位/价格/渠道：按你推荐来。**」
   - 「微信」按笔误处理 ⇒ 定名 **微型跃迁引擎**（EVE 里这一件的本名就是 Microwarpdrive）；
   - 三组「加成（点火期命中代价）」= **三档**（MK1/MK2/MK3），与三档矢量推进器同构；
   - 「周期方案按你算」= 采用经办人推荐的**逐单位周期**（见 §三）；
   - 「件数/档位/价格/渠道」= 按经办人推荐（单列一条线 · MK1/MK2 稀有 + MK3 奇货 · 市场可买可挂卖 · 各配一张图纸）。

## 三、⚠ 周期口径改判（旧条款**作废/改写**，不留两套）

**旧口径（船长 2026-09-10/09-11 定，已作废的部分）**：
- 「推进器周期 = 点火 60 秒 / 冷却 60 秒，**开场即点火**」（`thruster-charge-20260910.md`）；
- 「秒数**唯一出处 = `balance.battle.thrusterBoostMs/thrusterCooldownMs`**，界面一律经 core
  `thrusterCycleText()` 取值，**不许写死 60**」＋「周期由**战斗时钟**推导（`thrusterPhase`），
  引擎与战斗界面**同源**」——含义是**全队共用一条时间线**（`docs/glossary.md` 的「推进器周期点火」条、
  roadmap 2026-09-11 一号批）。

**新口径（2026-09-14 船长裁定「周期方案按你算」）**：
1. **周期逐单位**：`combat.thrusterPhase(battle, bal, cycle?)` 多收一个可选的周期参数；
   每个单位的周期 = `unitThrusterCycle(spec, bal)`（spec 没写覆盖 ⇒ 回落到 `balance.battle` 的全局值）。
2. **件自带覆盖**：`ModuleDef.thrusterBoostMs / thrusterCooldownMs`（`types.ts`）——**不写 = 用全局**
   （三档矢量推进器就是这样，一个字节都没改）；写了 = 该单位改用这套窗口（微型跃迁引擎 = 10 s / 60 s）。
3. **一船多件取点火最短的那件**（同长再取冷却更短者）——`createPlayerSpec` 的 `propCycle` 单点。
4. **界面读数 = 我方首舰（主控/距离锚）的周期**：战斗界面底部「推进器」冷却格、
   `battleArcsFor.thrusterCycle`、装配页「机动速度」行、换装卡/装备库/手册短行（`thrusterCycleText`）、
   模块信息卡后缀（`propTailOf`）全部**按件/按船取值**；全局值仍是「没写覆盖」时的回落值。
5. **旧条款怎么改**：词典该条改写为「**全局默认 60/60 + 件可覆盖 + 逐单位判定**」，
   「唯一出处」的说法改为「**秒数的唯一出处 = `balance.battle` 或该件的两个字段**，
   界面一律经 `thrusterCycleText/FullText` 取值，不写死秒数」（见 `docs/glossary.md` 同条）。

**影响面（如实登记）**：
- **混编队读数会变**：改前"整队平均机动 × **主控那一件**的倍率（全队同时点火）"；改后"**逐舰**各按自己的
  点火状态提速后再平均"⇒ 队里只有一部分船装微型跃迁引擎时，前 10 秒的整队均速低于旧口径（旧口径会让
  没装的船也吃到主控的爆发）。单船路径与"全队同款推进器"的编队**逐字不变**。
- 战斗界面那一条冷却格**只有一条**：显示**我方首舰**的周期（与「推进器点火中 +N%」同一个单位）。

## 五、边界与取舍（已确认）

- **占空比**：微型跃迁引擎 10 / 70 ≈ **14%**（矢量推进器 60 / 120 = 50%）⇒ **峰值高、均速低**：
  它是"抢位 / 脱离 / 开场压制"的爆发件，长期风筝仍归矢量推进器。三档峰值 +80/+150/+250%
  全部高于同档矢量（+30/+60/+100%），代价是点火期命中 ×0.80/×0.75/×0.60（矢量是 ×0.95/×0.88/×0.80）。
- **多装**：与矢量推进器同槽族、**允许复数安装**（V18.1 口径：无同类唯一约束），速度加成走 EVE 曲线收敛，
  周期取点火最短的那件。
- **不进专用校准行**：`battle:calibrate` 的标准行（A0~A3）不装推进器 ⇒ 本批不动既有标定读数；
  要评估"装与不装"的差距，用 `thruster-charge.test.ts` 里那条静止敌观测。
