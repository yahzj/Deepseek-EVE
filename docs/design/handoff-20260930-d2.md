## §5 亲历的坑（照抄避雷）

1. **推送 GitHub 要绕 DNS**（沿用 2026-09-27 卡）：`github.com` 解析到不通的 IP，可用写法
   `git -c http.curloptResolve=github.com:443:140.82.114.3 -c http.version=HTTP/1.1 push origin main`（IP 轮换再试，别写进全局配置）。
2. **批量替换文案别扫 `docs/`**：本轮第一遍全仓替换把 74 份文档 ＋ 5 份测试存档一起改了（含 SVG 样例与封存卷），已 `git checkout -- docs/` 整体回滚。玩家可见文案只动 `packages/` `apps/` `tools/`；`docs/` 留到归档。
3. **PowerShell 函数里的 `Write-Output` 会被 `$x = Fn ...` 吞进返回值**：本轮 `docs/glossary.md` 因此混进 7 行 `  ✓ [...]` 杂散行（已删）。要在函数里打印进度，别用 `Write-Output`（或改写成不经变量捕获）。
4. **中文提交信息一律用 .NET 写盘**：`git show HEAD:file > out.txt` 经 PowerShell 重定向是 **UTF-16LE**，`git commit -F` 会报 `a NUL byte in commit log message not allowed`；正确做法 = `[System.IO.File]::WriteAllText($env:TEMP + '\_cm.txt', $msg, (New-Object System.Text.UTF8Encoding($false)))`。
5. **`git add -A` 会把临时提交信息文件也提交**：信息文件写到 `$env:TEMP`，别放在仓库里（本轮 `tools/_cm-rename.txt` 被提交后已 `--amend` 摘掉）。
6. **预提交钩子的「⚠️ 需裁决」名单**：`packages/core/src/balance.ts` · `tools/docs-seal.ts` · `save.ts` / `test-saves` / `ironman` ⇒ 命中**必须先报船长**，按批复用 `--no-verify` 并在提交信息里记账（本会话两次：`c6198f36` 归档、`734ccf52` balance 注释）。
7. **合并 main 的固定冲突只有生成件 `docs/INDEX.md`**：`git checkout --ours docs/INDEX.md` → `npm run docs:index` → `git add` → 提交合并。（`git merge-tree --write-tree --name-only main HEAD` 可先预判冲突。）
8. **加/删工作文档后跑 `npm run docs:index`**：INDEX 记文件大小与状态（本会话实测 379 → 380 份 · 726 → 727 行）。
9. **写文本文件一律 CRLF ＋ UTF-8 无 BOM**：`write` 工具产 LF，写完用 .NET 归一；每次批量写盘后做三自检（BOM / 裸 LF / 往返解码）。
10. **改玩家可见文案要记账**：`⟪文案调整 YYYY-MM-DD⟫` 记号 ＋ 本批工作文档台账（日期 · 落点 · 改动 · 依据船长原话），漏了等于没做。
