## 一、首批范围与交付顺序

建议首批目标为「3×3站体 → 五类起步设施 → 首批人口复苏与运输 → 基础培训/派工 → 人类采矿、精炼 → 第一项科研」，形成可操作、可保存、可离线推进的正常流程，分批交付：

| 批次 | 可验收成果 |
|---|---|
| A：可建造的小站 | 真实交料运输、开工锁料、施工/暂停/取消、主体接网与3×3地块；随后建设发电、生命维持、服务中心。 |

| C：生产与科研 | 人类采矿/精炼、共享物料流、暂停恢复与人类/AI交接、首项科研。 |

每批先提供模块状态、快照、独立界面与验证，完成后集中接入，不先改动正式游戏。A批预览中的库存、到货和回收是测试宿主输入，不代表真实运输已接入；不在模块另写航路或生产公式。首次扩站施工、设施升级、舰员养成、外派、袭击/设施损伤、维修与人口永久损失暂不进入首批。
