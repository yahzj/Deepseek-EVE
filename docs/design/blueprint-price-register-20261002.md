## 4. 逐条理由（可查证 · 不猜）

**A 类四条**：

- **`bp-shieldchg-2` / `-3`**：两件由 **2026-09-14** 提交 `b3ff74c9`（「护盾回充改判按当前盾比例 ＋ 新装备护盾充能装置三档」· 二号）一次性引入 ⇒ 书价按**当时的自定值**落（MK2 走 ×2.0、MK3 走 ×2.5），**没走 2026-09-11 的档位系数口径**（该口径只对当时既有的 91 张做过全量对齐）。
- **`bp-shieldfield-2` / `-3`**：两件由 **2026-09-21** 提交 `b221cefe` 引入，船长当日原话给了**装备**均价「**平均价格分别是 400W 和 2000W**」＋「**都只有一次性蓝图**。一次性蓝图在稀有」⇒ `blueprints.ts` 行内注释自己写明「**书价 = 产物价**（一次性图既有口径）」，实现即 400 万 / 2000 万。⚠ 体检的「专属一次性图纸」豁免分支（书价 = 产物价不套系数）只认**只收不卖**那一类，这两张是**可买**的稀有一次性图 ⇒ 走了系数比对、因此报 ⚠。

**B 类七条**：

- 七张都是**高级零件线**，而这条线自己的定价口径是「**产物价 = 材料成本 ×1.50**」——证据在 `packages/data/src/items.ts` 各行注释里逐条写着（例：`part-fire-control` 那行 `baseSellPriceIsk: 1_670, // 材料 1_110（协处理器芯 700 ＋ 电路基板 2×95 ＋ 同位聚晶 4×55）×1.50`）⇒ **料/价 恒 ≈ 66.7%**。
- 体检那条「同族锚 45%、带宽 30%~60%」来自 2026-09-11 那批**装备/物品**蓝图的对齐口径，**与高级零件线不是同一把尺** ⇒ 属口径不适用，不是漂移。
