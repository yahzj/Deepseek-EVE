## 二、引擎侧的一处真缺陷（顺手修掉，船长那句"卖单"点到的）

`market.seedCommonBook` 原实现**无条件**铺 NPC 卖单（池商品 `flow×0.8` 一笔、单件平价品两笔）
⇒ **只收不卖的商品也会在货架上挂着"买不了"的卖单**：实测 `box-relic-a`（洞内货柜，早已
`playerBuyable: false`）开盘就有 **2 件卖单**，点买入被 `buyAtMarket` 的 `not-buyable` 拦下。
现按 `playerBuyable` 收口（与 `slowSupplyDraw` / 供应阶梯两处既有门同一把尺）：

- **只收不卖 ⇒ 一笔 NPC 卖单都不铺**（虚空母矿 / 虚空晶 / 洞内货柜 / 残骸收购卡…全部生效）；
- **收购侧（`npcBuy`）不受影响** —— "只收不卖"就是"我收，但我不卖给你"。

读法：三处门合起来 = ①开盘簿不铺 ②常规窗口抽取跳过（`slowSupplyDraw`）③供应阶梯不出售
（`market.ts:751`）；再加上 2026-09-14 修掉的「市场奇货事件不再强刷只收不卖货」，**NPC 侧没有任何
渠道能给出这两样的卖单**。

## 三、经济读数（真引擎，改前 → 改后）

| 口径 | 改前 | 改后 |
|---|---|---|
| 每单位母矿「卖原矿」现金（NPC 收购） | 780 | **780**（价格不动） |
| 每单位母矿「炼成三件套再卖」现金 | **1,016** | **566** |
| 每单位母矿产出**市值**（base 价口径） | 1,016.25 | **566.25** |
| 结论 | 炼更赚（+30%） | **炼不如卖**（−27%） |

- **"炼不如卖"是"产量减半"的直接后果**（船长要的正是虚空晶更稀缺）：洞内 24 张专属蓝图 +
> 皇带鱼级都以虚空晶为主料，产出减半 ⇒ 同样一条蓝图的挖矿量翻倍。
- 只收不卖之后，原文那条"买入精炼不赚"的**防套利论证退休**（买不到矿/晶，这条路已封死）；
  价格比值不再有套利风险，故按船长"价格不动"保留原价。
- 若日后想让"炼"始终比"卖"略赚，唯一旋钮 = 下调母矿收购倍率（`demandMultiplier` 0.6 → ≈0.42）
  或上调虚空晶价（会连带重标所有以虚空晶计价的内容）—— **本批未动**。

## 五、玩家侧挂卖：**船长裁定「保持现状」**（2026-09-14）

`playerBuyable: false` 在引擎里**同时挡掉"玩家挂买单"**（`placeBuyOrder`）。
「市场不会出现卖单」这句实现为 **NPC 侧一笔都不铺**；而**玩家侧挂卖照旧**——依据是 2026-09-14
既有定案「**维持所有物品允许玩家挂卖**」（三号那批"专属内容补市场行"）：

- 当时我把这个岔口摆给船长（"连玩家挂的卖单也不出现"会与上面那条既有定案相冲）⇒
  **船长 2026-09-14 裁定：「保持现状」** ⇒ 本批**不动** `playerSellable`，玩家仍可挂卖虚空晶/母矿的卖单，
  别人也能买走（求购单仍不可挂）。
- 也就是说：「市场不会出现卖单」的落地边界 = **NPC 侧零卖单**（开盘簿 / 窗口抽取 / 供应阶梯 / 奇货事件
  四道门全封），**玩家之间照常**。日后若要连玩家侧也禁，改动 = 给这两条加 `playerSellable: false` +
  同步体检「挂卖可达契约①」与词典（**需船长重新点头**，因为那会推翻上面那条既有定案）。
