复原负向验证时我图快，用 PowerShell 正则把 `cpu: 165,` 批量改回 `cpu: 265,`，**结果误伤了「虎鲨级」（`sh-tigershark`——它也是 165、下一行同样是 `droneBayM3`）**。**在 diff 逐行核对时抓到**（`--numstat` 从 8/2 变成 9/3），已逐行改回并三重复验（全仓 `cpu: 265` 只剩两艘电子舰 · diff 回到 8/2 · 虎鲨 = 165）。
⇒ 复述仓库既有血泪条：**批量/正则替换必须"改完立刻 `git diff` 复核命中集合"**，尤其同值相邻字段；逐处精确替换（`edit` 工具）的风险显著更低。
