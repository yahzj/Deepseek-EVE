## 关键技术口径

- **窗口内 `vw` 问题**：战斗屏内层有 `clamp(420px, 52vw, 780px)`（标尺 / 底栏）与 `padding: 6px 4vw`——全屏时 `vw` 即窗口宽，窗口化后必须改为按窗口算。**只覆盖这四处**，且在 `.app-winbox` 作用域内，不动全局规则。
- **窄窗横滑**：战斗屏的手机段口径（`@media (max-width: 640px)`）改为**按容器**生效（`.app-winbox` 窄时舞台横滑、底栏适配宽度），因为窗口宽度与视口宽度无关。
- **z 序**：窗口 110（低于详情窗 120 / 140 与悬浮说明 1000，高于浮动还原标 90 与公告 88）。
- **弹窗与最小化**：照抄战斗窗口既有机制（`xxxOpen` state + 活动上升沿自动弹出一次 + 手动最小化后不再自动弹回）。
