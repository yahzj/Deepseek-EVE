# M0 设计文档：技能训练队列 + 时间系统 + 存档

## 目标

用最小可玩闭环验证整套架构：**把技能加入队列 → 挂机（在线或离线）→ 技能升级 →
日志可读 → 存档可靠**。M0 不做经济、战斗、星图。

## 数值规则

### 训练时长公式（core/src/training.ts）

```
单级时长(level) = 基础时长(默认 60 秒，可被技能表覆盖) × rank × 2^(level-1)
训练到目标总时长 = Σ 各级单级时长
```

示例（rank=1，基础 60 秒）：

| 目标 | 各级耗时 | 累计 |
|---|---|---|
| Lv1 | 1 分钟 | 1 分钟 |
| Lv2 | 2 分钟 | 3 分钟 |
| Lv3 | 4 分钟 | 7 分钟 |
| Lv4 | 8 分钟 | 15 分钟 |
| Lv5 | 16 分钟 | 31 分钟 |

技能上限 **5 级**；rank 越大练得越慢（数值表见 `packages/data/src/skills.ts`）。

### 队列规则

- 队列严格先到先练：队首训练中，其余排队，练完自动出队继续下一个。
- 可随时从任意位置移除；移除队首 = 放弃当前这级已练的进度。
- 同一技能"相同目标等级"不允许重复入队；目标必须高于当前等级。
- 队列项进度只记"当前这一级"，升一级清零重计（实现简单且不易出 bug）。

### 离线结算（core/src/simulation.ts）

- 只结算一次（读档时）：`结算时长 = min(离开时长, 8 小时)`。
- 超上限部分直接放弃，并在日志里写明"超出上限的 X 未结算"。
- 时钟回拨 → 不结算不报错。
- 游戏内时间 `gameMs` 单调累计（只被推进，从不回退）。

## 存档格式 v1

```jsonc
{
  "format": "whale-idle-save",   // 格式标识（防误读别人的档）
  "version": 1,                  // 结构版本号
  "savedAtWallMs": 123456,       // 最近保存墙钟时间（离线时长基准）
  "state": {
    "version": 1,
    "gameMs": 0,                 // 游戏内累计毫秒
    "savedAtWallMs": 0,
    "logCap": 300,               // 日志上限
    "character": { "name": "深空学徒", "startedAtWallMs": 0 },
    "rng": { "seed": 0, "count": 0 },
    "skills": { "trained": {}, "queue": [] }, // queue 项 {skillId, targetLevel, progressMs}
    "logs": []                   // 环形日志 [{id, atGameMs, kind, text}]
  }
}
```

### 迁移约定

- 结构一变：`version + 1`，并在 `save.ts` 的 MIGRATIONS 表补 `(旧版 → 新版)` 函数。
- 迁移只处理"结构变了的部分"；缺字段由 normalizeState 补默认值。
- 每个迁移必须有对应单元测试（示例：v0 草图 → v1 已有测试）。
- 读取失败三层报错：PARSE（非 JSON）/ FORMAT（非本游戏档）/ VERSION（版本不兼容）。

## 日志

- 类型：`system`（紫）`info`（白）`queue`（青）`levelup`（金）`warn`（红）。
- 上限 300 条环形裁剪；界面显示最近 200 条、最新在前。

## 界面（M0）

- 顶栏：游戏名 / 飞行员名 / 在线时长 / 保存 / 重置档案。
- 左栏：技能目录（按组折叠不展开，直接展示；每行 = 名称、Lv x/5、难度、
  说明、按钮"训练到下一级"或状态标签）。
- 右栏上：训练队列（队首大进度条 + 剩余时间；排队项可移除；底部队列总时长 + 清空）。
- 右栏下：事件日志。
- 全部中文文案；无图片资源（纯 CSS/文字）。

## 验收清单

- [ ] 新建档：默认飞行员"深空学徒"，日志有欢迎语
- [ ] 点"训练到 Lv2"：技能行变训练中、日志出现"开始训练"
- [ ] 60 秒后升 Lv1、日志金色"提升至 Lv1"；再 120 秒升 Lv2 完成出队
- [ ] 排队 2 个技能：第一个完成自动开始第二个
- [ ] 移除/清空队列行为正确、日志有记录
- [ ] 关闭游戏 >1 分钟后重开：日志出现"离线归来…结算完成"，进度已补
- [ ] 手动保存提示"存档已写入本地"
- [ ] 重置档案需确认，之后是新档

## 测试覆盖（自动）

- 时长公式边界（rank、baseMs、越界目标、总时长求和）
- 队列推进（逐秒小步长 / 巨量离线一步推、升级富余时间不浪费、非法指令拒绝）
- 离线切分与结算（上限截断、超长训练需求、时钟回拨）
- 存档（往返一致、v0→v1 迁移、三类坏档报错、字段容错）

## 非目标（明确不做）

- 不提供舰船/物品/货币；采矿、精炼、制造、星图、战斗、声望全部 M1+。
- 不做多人/云存档（架构已预留）。
- 不追求即时战斗演出——战斗走"时段结算"文字战报路线（M3 设计时定细节）。
