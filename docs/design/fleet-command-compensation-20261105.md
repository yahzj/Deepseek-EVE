# 旧存档编队协同指挥补偿

状态：船长明确指定，三号在verify实施；未提交、未合入、未推送。船长2026-11-05已批准公告写入游戏，修订稿及补偿说明已落地验证树。

## 授权与范围

船长原话：“新增一个存档补偿机制，旧存档玩家根据累计声望按档位给予编队协同指挥的等级，档位累计声望分别是40/60/80/100，分别给予1～4级编队协同指挥”。

- 功能域：编队指挥旧档补偿。参照既有`normalizeTrainingProgress`的一次性标记及存档清洗入口，不新建通用迁移系统。
- 新增规则只适用于当前可读取的v31存档；不恢复已退役的低版本读取或历史补偿。用户本次明确指令是新补偿的批准依据。
- 在`combat/command/compensation.ts`单独承载补偿，`state.ts`仅增加可选类型和新档标记，`save.ts`仅接入清洗字段与单次调用，不扩展大文件职责。
- 不改技能效果、rank、前置、训练许可价格、树坐标、声望账本或存档结构版本；不额外赠送编队指挥基础等其他技能。

## 结算规则

| 首次载入时累计协会声望 | 编队协同指挥最低等级 |
|---|---:|
| 小于40 | 不补发 |
| 40至59 | 1 |
| 60至79 | 2 |
| 80至99 | 3 |
| 100及以上 | 4 |

- 缺少`skills.commandCompensationVersion`的旧档在载入清洗后判定一次，随后记录版本1；未达40也记已处理，后续声望上涨不追加补偿。
- 新建存档直接记录版本1，不参与补偿。既有已处理存档重复导入、本地恢复或云档载入不重复发放；重新载入未处理原始旧档仍计算同一最低等级，不叠加。
- 累计声望复用`standingOf`，不使用可支配余额。缺少累计账本时沿既有清洗回填规则，不引入声望下限。
- 已有等级只保留或提高到最低等级，不降级、不按等级累加；已练到1级以上沿现有许可规则视为已有训练许可，不另扣费。
- 只有实际提高等级时才清理该技能已覆盖的训练目标与暂存进度；更高训练目标保留，低等级进度不转用于高等级。其他技能、队列顺序及进度不动；等级未提高时该技能原进度也不动。
- 不读取、覆写玩家真档，不新增补偿日志、领取按钮或提示；补偿说明随本次获批公告落地。
