## 一、范围与不做的

**做**：外壳（app shell）三件事——
1. 导航从**左侧 168px 竖栏**改为**底部横栏**（大图标 + 图标下方配字）；
2. **出港**（= 星图页，带 `is-featured`）放**正中间**，带**不一样的按钮边框**；
3. **活动栏**从「横跨整宽 · 最高 230px」改为**左侧竖列**（船长令：这样 AI 作业能同时显示多个）。

**不做**：页面内部的布局（左右侧栏宽度、卡片排布一律不动）；文案；数值。

## 三、方案（船长选定＝草图变体丁）

```
┌──────────────────────────────────────────────┐
│ 顶栏（品牌 · 信用点 · 铁人 · 设置）            │
├────────┬─────────────────────────────────────┤
│ 活动栏 │ 页面内容（星图 + 详情栏）             │
│ 左列   │                                      │
│ ~150px │                                      │
├────────┴─────────────────────────────────────┤
│ 物品 装配 舰船 工业 │ 出港 │ 市场 技能 任务 成就 │ 设置 │
└──────────────────────────────────────────────┘
```

**账**：左导航 168px → 底栏（0 宽）；活动栏加回左侧约 150px ⇒ **横向净省约 18px**（不是重点）；
**重点是纵向**：活动栏可用高度 **230px → 约 690px**，同时可见作业行 **约 7 → 20+**
——这正是船长要的「AI 作业也能同时显示多个」。

## 四、已知要一并处理的点（不藏）

1. `.app-activitybar-scan`（固定 `width: 200px`）与 `.app-activitybar-tuning`（`width: max-content`）在 150px 窄列会**溢出** ⇒ 改成纵向窄卡（标签一行、进度一行）；
2. `.app-nav-item.is-featured` 现有 `width: 100%` + `aspect-ratio: 1/1` 是**为竖栏写的**，横排底栏里要改；
3. `.app-root.is-mobile-rot .app-nav-side` 两条规则（旋转模式的让位口径）需随形态改写；
4. 一级页**不滚**红线（约定第六章）：底栏占约 96px 后，内容仍需完整装下 ⇒ 落地后要核验**不出现整页滚动条**。
