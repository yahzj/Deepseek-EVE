## 现行外壳与操作边界

- classic左导航/流内日志与modern底导航/左活动列共存，出港保持特征入口。手机导航按后续裁定恢复各自网页版规则，不再使用已撤回的手机压窄/小字号；整体旋转、1200逻辑宽、内容适配与日志抽屉保留。modern桌面日志原浮层覆盖右区不作为黑市/战斗宽度BUG。
- 旧导航可收为最左图标，名称提示/切页保持，手机桌面偏好独立。唯一开关在底部正常占位区，和上方内滚列表为兄弟，按钮按真实滚动条留宽对齐；剩余高度用尺寸容器预算，先收留白再内滚，舰船预览/底部不压扁、不硬裁。日志先原宽淡出再释放空间，恢复滚动/筛选/焦点。
- 手机日志默认关闭、独立状态不污染桌面，遮罩/Escape关闭、焦点返回/Tab循环。旧手机导航单指拖动逆旋转缩放矩阵映射物理轴，8物理像素阈值、防拖后误切页、下次轻点恢复；双指退出列表拖动保留捏合，不接管鼠标/modern/底开关，取消/卸载清理。
- 视口按物理方向判，捏合冻结尺寸，软键盘缩高不误退旋转，地址栏滞回不变；输入至少16 CSS像素、功能标签横滑、标题操作可换行/内滚，正文二级滚动、整页不滚。弹层固定头/操作和限高正文，方案/无人机保持各自原整窗内滚，不一概强裁。
- 主控状态窗低安遭遇优先于作业，副船交火不误显示主控；活动门禁/停止/退料/返航政策不变，不因缺动画窗口新增玩法。四类作业最小化/还原/切导航保持，入侵显示见入侵文档。
- 筛选共用`ui/itemSubs.ts`：市场一级全部/物品/舰船，物品二级货物/装备/消耗品/货柜/残骸/黑匣/蓝图/核心/其他，舰船采矿/货运/武装/装甲/其他；单资产页直接用自身类别，槽位/功能/档位是附加条件。父类变化清失效子条件、隐藏空类、未知落其他；仓库两视图二级同源，工业/蓝图按产物，不承诺每查询只需两按钮。

## 一、范围与不做的

**做**：外壳（app shell）三件事——
1. 导航从**左侧 168px 竖栏**改为**底部横栏**（大图标 + 图标下方配字）；
2. **出港**（= 星图页，带 `is-featured`）放**正中间**，带**不一样的按钮边框**；
3. **活动栏**从「横跨整宽 · 最高 230px」改为**左侧竖列**（船长令：这样 AI 作业能同时显示多个）。

**不做**：页面内部的布局（左右侧栏宽度、卡片排布一律不动）；文案；数值。

## 三、方案（船长选定＝草图变体丁）

```
┌──────────────────────────────────────────────┐
│ 顶栏（品牌 · 信用点 · 铁人 · 设置）            │
├────────┬─────────────────────────────────────┤
│ 活动栏 │ 页面内容（星图 + 详情栏）             │
│ 左列   │                                      │
│ ~150px │                                      │
├────────┴─────────────────────────────────────┤
│ 物品 装配 舰船 工业 │ 出港 │ 市场 技能 任务 成就 │ 设置 │
└──────────────────────────────────────────────┘
```

**账**：左导航 168px → 底栏（0 宽）；活动栏加回左侧约 150px ⇒ **横向净省约 18px**（不是重点）；
**重点是纵向**：活动栏可用高度 **230px → 约 690px**，同时可见作业行 **约 7 → 20+**
——这正是船长要的「AI 作业也能同时显示多个」。

## 四、已知要一并处理的点（不藏）

1. `.app-activitybar-scan`（固定 `width: 200px`）与 `.app-activitybar-tuning`（`width: max-content`）在 150px 窄列会**溢出** ⇒ 改成纵向窄卡（标签一行、进度一行）；
2. `.app-nav-item.is-featured` 现有 `width: 100%` + `aspect-ratio: 1/1` 是**为竖栏写的**，横排底栏里要改；
3. `.app-root.is-mobile-rot .app-nav-side` 两条规则（旋转模式的让位口径）需随形态改写；
4. 一级页**不滚**红线（约定第六章）：底栏占约 96px 后，内容仍需完整装下 ⇒ 落地后要核验**不出现整页滚动条**。
