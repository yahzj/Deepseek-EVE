## 一、核心结论（修正先前判断）

1. **MK3 不是任何威胁的胜负关键**：满配（4~5 高槽 + MK2 + 盾抗/索敌/陀螺/稳定支援件）无技能即可 100%
   打穿 T58~96；MK3 的贡献只是击杀快 ~10~30%。「没 MK3 打不过 T58」的说法错误（源于无支援的裸参考装矩阵），特此更正。
2. **真正的决定性维度 = 高槽门数 × 支援件 × 船体 EHP/抗性**，不是炮的 MK 档位。现有敌血曲线按
   「3×MK3 无支援参考装」标定（>40 段 ref 12.8），而玩家真实可及顶配（4×MK2 ≈ 14.9、5×MK2 ≈ 18.7 的
   火力单位 + 生存件）已系统性超过参考火力 → **当前曲线对满配武装船全线失压，终局形同虚设**。
3. 推论：**仅移动 MK3/顶船解锁位置拉不长曲线**——装备闸门拦不住"4×MK2 一路首胜到穹顶"的推进
   （声望推进不依赖火力）。要让每档装备有存在感，必须先让威胁对「该阶段可及顶配」产生真实梯度。
4. 附带发现：`battleWinPreview`（解析模型 + logit 扩散）显著低估实战胜率（大白鲨 5×MK2 无技能实测穹顶
   100%，preview 却只有 ~87% 量级）——影响 AI 门槛与最终验证闸（85% 线），建议一并校准。

## 二、目标形态

- 真实节奏下装备主线顶配日从 ≈d1.7 拉长到 **d12~18**；
- 每阶段（声望段）存在"该段顶配 ≈ 90~98% 可胜、低一档 ≈ 30~60%"的真实梯度；单场击杀 30~90s 递增；
- 解锁闸门同时承担战力与叙事：**顶级舰船 = sec<0 深处（末期段）**；**MK3 家族 = 末期前一两个星系**；
- 挖矿/工业收入曲线不动（作为无门槛兜底，维持现在的时间账）。

## 三、方案构成

### P1 · 威胁曲线重标（前置，不可省）
- 按「分阶段玩家真实可及配装」重建敌血/敌火力：
  阶段配装锚（由 `battle-calibrate` 扩展装配行给出实测基线）：
  - A 隼枭×3 MK1（声望0-1）→ B 虎鲨×4 MK2（声望2-4）→ C 灰鲭鲨×4 MK2+支援满（声望5-8）
    → D 灰鲭鲨×4 MK2 全技能（声望9-10）→ E 大白鲨×5 MK3+支援满/全技能（声望11+）。
- **技能口径（船长 2026-09-06 定）**：技能 = 玩家独立于装备的「局外成长」；已定「满配才能通关」，
  敌人设计对技能**宽容**——技能负责同档提速/减负，不作为过墙钥匙（装备才是闸门内容）。
  校准矩阵与目标一律跑 **三档技能**：`无技能 / 中位技能（同一批战斗·操控技能统一 Lv3）/ 全技能 5`
  （battle:calibrate 已并入 MID_SKILLS 档位）。
- 目标标定表（每档威胁给定该段配装的目标胜率与击杀秒区间，按三档技能分别验收）：
  - 该段顶配 × 中位技能：**85~98%**，单场 30~90s（主验收行）；
  - 该段顶配 × 无技能：≥ **70%**（宽容底线：满配不至于因技能没练而被卡死）；
  - 该段顶配 × 全技能：≥95% 且击杀再提速（技能收益 = 时间/容错，非通关）；
  - 低一档配装 × 全技能：**≤60%**（装备仍是主闸门，技能不许越级碾压下一段太多）；
  - 每个阶段行同时记录 **战后残血%**（磨损代理）——连战续航维度为待建模项
    （P0 承伤持久化 + 港内维修/修理组件已在引擎，校准口径待补"连续 N 场"模拟，见待办）。
- 重标杠杆：`foeHpCurve` 参考火力段表/幂指、`foeDpsPerThreat`、`foeHitRate`/装填/层抗缺口微调；
  优先只动 HP/火力两轴，不动机制；
- 产线验证：`battle:calibrate`（阶段装配行 × 三技能档 × 残血% 格子）+ `bounty:econ`（各档可刷性）
  + real 节奏 sim（topGearDay/MK3 首装日；连战续航并入 farm 段实测）。
- **T45/48 两档 kite 墙**随重标按 C 段目标重新落点（不再单独手调）。

### P2 · 装备解锁闸门（船长 2026-09-06 定稿：硬拦常驻 + 暗市单可绕过）
- **双通道语义**（新闸门商品，如 MK3 家族）：
  - **常驻通道（硬拦）**：声望（或指定 req 条件）不足 → 买入/挂收购单被拦（沿用现有
    `goodLockedReason`），卡片显示「需声望 X」作**指引**；
  - **暗市通道（可绕过）**：锁定期间市场按**原稀有度窗口命中 ×0.01** 概率刷出订单，
    订单价 = 基准 **×4**（溢价 300%→定稿 4 倍价）；这类**暗市单可绕过声望拦截直接买入**
    （早拿 = 蹲稀有 × 高代价；正常拿 = 等声望达标走常驻原价原频率）；
  - **解锁（声望达标）后**：恢复原稀有度刷单与正常定价，**不转为常驻商品**；
- 现有 `standingReq` 船（大白鲨=声望 7、玄武=声望 9）：**维持现状硬拦，不加暗市通道**（船长定）；
- 实现要点（执行计划细化）：
  - `MarketGoodDef` 增可选 `req`（保留 `standingReq` 兼容）；
  - NPC 订单结构加兼容字段标记**暗市单**（锁定期 spawn 时写入）；买入撮合按单判断：
    普通单仍受 standing 拦截、暗市单放行；
  - `refreshGoodOrders`：locked 时窗口命中率 ×0.01；暗市单定价 ×4（买卖两侧同规则）；
  - UI：锁定商品可见，「需声望 X」提示保留（指引）；暗市单到货有视觉/文案标识（玩家向）；
  - 测试：暗市命中率、×4 定价、绕过拦截可买、常驻通道仍拦、解锁后恢复原节奏；
  - 存档零结构变化。
