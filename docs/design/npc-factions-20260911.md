# NPC 势力档案（协会侧）· 设定与口径（2026-09-11 船长定）

> **状态：已确认**（船长 2026-09-11 定世界观六条 + 通讯 v2 全部裁定；第 7 条为经办人自查补充，已随设计总结获确认）。
> 经办：一号。数据落点：`packages/data/src/commsFactions.ts`；契约落点：`tools/content-check.ts`「通讯消息契约」。
> 相关：`docs/design/comms-20260911.md`（通讯系统）、`docs/glossary.md` 七之二（术语）。

## 1. 一句话

协会是**章鱼人**的官方行业组织；章鱼人**不追问船里是谁**——他们把玩家当一条**普通承包舰船**，
称玩家为「**飞行员**」（职务称呼，与物种无关）。玩家**就是那条船**（舰船 AI），不是坐在船里的人。

## 2. 叙述铁律（7 条，全部做成契约）

| # | 铁律 | 落地方式 |
|---|---|---|
| 1 | **官方势力 = 章鱼人**（无更正式族名；协会对外自称「协会」） | `CommsFactionDef.species` 恒为 `'章鱼人'`，契约逐势力强制（防设定漂移） |
| 2 | 章鱼人**不追问船里是谁**：把玩家当普通承包舰船，不做特殊对待 | NPC 消息与剧本台词扫描「AI / 智能 / 旧时代 / 人类」；**豁免既有系统官方名**（`AI 核心`、`人工智能专家`）——那是玩法术语，不是对玩家身份的指涉 |
| 3 | **其他 NPC（打捞队工会等）也是章鱼人**，同族不同行会 | 打捞队工会 `species` 同为「章鱼人」、`alignment = 民间` |
| 4 | 玩家保留被称「**飞行员**」（协会职务称呼，与物种无关）；自定义名 = **呼号** | 既有 3 处文案**不动**（本批只改 2 处见 §5） |
| 5 | **人类早已离开/消失在深空**：协会不谈、也帮不上 | 「人类」入扫描清单；贯穿任务「寻找人类」保持"完成方法未知"，协会侧不给答案 |
| 6 | **敌族关系留白**：F 族制式巡逻与协会的关系，不在协会侧文档里定 | 协会侧文档一句「见敌族设定文档」，不编 |
| 7 | **玩家就是那条船**：文案禁用「你的舰船」这类主体分离说法（经办人自查补充） | 「你的舰船」入扫描清单；同批扫全仓**命中 2 处**（见 §5） |
| 8 | **两套认知口径**（2026-09-11 船长补定：「**外部认知中，我们是飞行员；但是内部系统中，我们知道自己是舰载 AI**」）：**对外**（章鱼人 NPC）玩家是「飞行员」，他们不追问船里是谁；**对内**（船自己的系统，如信息库）玩家**知道自己就是舰载 AI**，系统来源的来信可以直说这件事 | 契约**按发件方分级**：NPC 来源不豁免「舰载 AI / 船载 AI / 舰船 AI」（写了就报错）；**船内系统来源（`alignment: '系统'`）额外豁免**这三类自我认知表述。**负向验证**：把「本舰是旧时代舰载AI」分别塞进协会来信与信息库来信 → 前者如实报错、后者放行 |

## 6. 与既有系统的接口（边界）

- 通讯消息**只给提示 + 跳转**（裁决③）：不在通讯页接取/推进/交付任何任务；
- 剧情与通话**同处一个收件箱**：T9 建站剧本镜像进通讯页（裁决②），本批给 4 份剧本挂靠 `dshi · 基建部`；
- **势力不入档**：势力档案是静态数据，界面按当前数据表解析（存档零迁移）；
- **解析失败降级不崩**：势力/部门 id 写错时，收件箱显示原文 id、立场小片不出现，日志照常写。

## 8. 命名与维护规则

1. **新增势力/部门必须同步三处**：`data/commsFactions.ts`（数据）+ `docs/glossary.md` 七之二（词典）+ 契约（自动生效于新条目）；
2. **势力 id 稳定、不复用**；部门 id 在势力内唯一；
3. **颜色与图标复用既有语汇**：`tone` 取既有 `NAV_TONES`/`ICO_TONES` 同族色，`glyph` 必须是既有 SVG 线稿图标名（契约校验图标名存在）；
4. **每个势力至少被引用一次**（消息或剧本），杜绝"空档案"；
5. 部门 `kinds` 必须是势力 `kinds` 的子集（两级白名单）；
6. 新增玩家可见文案一律过世界观铁律扫描（§2 第 2、7 条）。

## 9. 验收口径（本批已跑）

- `content:check`「通讯消息契约」读数：`7 条消息 + 4 份剧本；势力档案 2 个（协会 8 部门 / 打捞队工会 1 部门），发件方引用与内容类型白名单全通过`；
- **契约负向验证 5/5**（物种改人类 / 部门白名单去掉「提示」/ 部门 id 不存在 / 文案「智能 AI」/ 文案「你的舰船」→ 逐条如实报错）；
- core 用例 6 例覆盖发件方解析与全部降级路径；
- 实机（无头 Chrome）核对发件人写法、立场/内容类型小片、通栏「前往」与不滚口径。
