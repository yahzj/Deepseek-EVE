# 船体维修装置（中槽自动修复装甲/结构）——设计定稿

- 状态：**已确认**（船长 2026-09-09；四步闸门走完："请确认" → "确认"）
- 经办：一号（大鲸鱼深空工业 · main）
- 关联：P0 承伤持久化（修理组件体系，2026-09-05）、V18.1 支援件槽族、市场维修组件池

## 一、设计目标与玩家文案口径

战斗中装甲/结构被打穿是常态；本装置给战斗中的持续回复能力：
- 中槽支援件（`slot: 'support'`、`rack: 'mid'`——与索敌/陀螺同级），全自动，无需操作；
- **AI 副船同样生效**（引擎统一走 `startBattleFor`/`advanceBattleFor`，无主控专属路径）；
- 消耗型：每脉冲（5 秒）消耗 1 枚对应修理组件——**民用级吃民用修理组件，MK1/MK2 吃军用修理组件**；
- 组件耗尽 → 该台自动停机（日志一次），不再修复；**修不过敌方火力**（数值上每跳修复量远低于敌方 dps，仅延寿不无敌）；
- 只修装甲与结构两层；**护盾不修**（护盾靠回充；装置描述明确"装甲/结构"）。

## 三、修复语义（引擎）

1. **额度转移**：每台每脉冲两层通道各 X；某层已满（或该层补满）后，该层剩余额度转投另一层；
   单跳修复上限 = 装甲额度 + 结构额度；两层皆满 = 痊愈空转：**计脉冲但不扣组件**。
2. **修复上限 = 出场满值口径**（`createPlayerSpec` 重建值，与连续作战保险同源）——入场残余（P0 装甲/耐久百分比）可以战斗中修回满血。
3. **预载与退还（与弹药预载同哲学）**：
   - `startBattleFor` 开战装载：货舱优先、仓库兜底；每台预载上限 = ⌈整场最长战斗时间（`bal.maxBattleMs`）/ 5 秒⌉ + 1 枚（多波演出窗口冻结战斗时钟，+1 防边界不足）；
   - 战斗全程不可补给（远征深空语义）；战斗结束/撤退/遭遇战结算/AI 结算四处调用 `refundRepairKits` 把未用组件退回**仓库**（幂等）；
   - 库存不足 → 装置照常装配但开战即停机（`stopped`），开战日志明示缺料。
4. **调度**：`BattleState.repair`（可选，零迁移）持 units 快照（开战写入，离线续算不依赖当前装配）+ kits 账本 + `nextPulseAtMs` + 脉冲/消耗计数；`advanceBattleFor` 每拍推进后补齐到期脉冲；结束/撤退/自动撤退后不再补跳。
5. **多件叠加**：同类/异档可多装（V18.1 无唯一约束），每台独立修复与扣组件——修复量叠加、组件消耗成倍（CPU 与中槽位是自然约束）；信息卡"叠加方式"沿用 flat（可多装·全额叠加）标签。
6. **预估口径**：稳态预览（analytic）不含修复（保守——不加装即高估修复收益）；胜率 MC 与校准工具走同一引擎自动含修复（评估快照组件给足 = "组件充足"同弹药哲学，`estimateBountyWinOn` 每局补足）；损耗统计钳制 [0,1]（修复可超开局残余，UI 不显示负损耗）。

## 四、界面

- **装配/悬停信息卡**（moduleInfoLines support 分支）：`自动维修` 行 = 每 5 秒修复量（层满转投）+ `运转消耗` 行 = 每跳组件 ×1（组件名中文）；
- **战斗页**（BattleScreen legends 行，弹药旁）：`维修装置运转中 · 组件 ×N` 徽标（绿点随脉冲呼吸）；组件耗尽 → `维修装置停机` 暗红点停跳；tooltip 说明修复/消耗语义；
- **日志**：开战"维修装置待命…每 5 秒自动修复"（缺料则"没有民用/军用修理组件"警示）；耗尽"组件耗尽自动停机"（一次）；
- 血条回升肉眼可见（战斗页三层血条）；组件余量以预载账本计（货舱/仓库被移走的部分在战斗徽标中呈现为"组件 ×N"）。

## 七、已知取舍

- 稳态胜率预览不含修复（保守）；MC/校准同引擎含修复；
- 战斗中无手动开关（装置运转与否由组件决定，设计如此：想省组件就卸装置）；
- 组件装载走"货舱（当前驾驶船）优先 + 仓库兜底"，与弹药装载完全同源（AI 副船远征同样吃主仓组件——弹药既有语义，保持一致）。
