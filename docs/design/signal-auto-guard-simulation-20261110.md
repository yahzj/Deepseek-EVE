# 自动探索守卫实战推演

状态：实现、专项、T2检查、存档往返及双布局网页派队验证完成；船长于2026-11-10明确要求「进行合并推送然后部署」，正在执行网页版发布。二号，`d2/workspace`，2026-11-10。

船长原话：「现在问题是 这个自动判定率太低，不如原本的实际作战，建议回调为实际战斗模拟」。

## 实施边界

- 公开信号自动探索的新任务，用正式守卫战建档与逐步推进取胜负，替换解析战斗比1.15门槛。
- 仍用当前探索回合、普通作业额度与奖励抽取规则；失败不跳层，不恢复旧随机地图模拟。
- 各层作为出发舰队的独立守卫资格检验，使用该族该层守卫、实际装配、已装载无人机、出发伤势、技能科技和已有补给。不虚构弹药或维修件。
- 在完整隔离状态内使用独立种子运行；不向真实状态提交模拟的库存、维修、战损、图鉴、日志、射程记忆或随机数变化。不跨层累计模拟损耗，最终仍使用当前自动探索损伤规则与不丢船边界。
- 每层只运行一场，默认自动交战距离，不搜索最优距离、不运行多轮取优。模拟胜利且回合足够才下潜；超时、失败或无法开战均不通过。
- 新估算快照版本为2，保存守卫结果和交战时长；已有版本1及无估算快照的旧在途任务不重算。在线/离线、存读档保持冻结奖励且只发一次。
- 网页派队在自建Worker中推演；期间按钮禁用并显示等待图标，关闭准备窗、取消主控交接、换队或换档取消计算。返回结果时复核原存档、内容上下文、主控/接任对象、信号和能力/有效补给输入，再走正式派队入口；不把副本游戏状态覆盖回真实状态。失败或超时不耗信号，不回退主线程重算。
- 逐层报告数据随新规则更新；详情UI尚未实施，见`signal-auto-report-detail-20261109.md`。未改主控探索、实验自动队、公告或桌面发行配置。本次依船长明确指令合并、推送并部署网页版，桌面发行继续暂停。
