## 2. 现场读数（动手前 · 两条导入路径逐项对照）

同一个 `engine.importSaveFromFile()`，**存档页有交代、新游戏页漏了同一手**：

| 情形 | 存档页 `SaveManager.tsx` | 新游戏页 `ModeChoice.tsx`（改前） |
|---|---|---|
| 关掉文件选择器 / 选择器没弹出来 | ✅ 浮层 `ui.SaveManager.031` | ❌ `if (r.canceled) return` ⇒ **界面一个字都不说** |
| 导入成功 | ✅ 浮层 ＋ 关窗 | ⚠ `setOk('已从所选文件导入存档…')`，但**同拍 `notify()` 让本框自动卸载**（导入的档已选过模式）⇒ **成功提示玩家看不到** |
| 导入失败 | ✅ 浮层 | ✅ 框内红字（能看到） |

另核一条：`importSaveFromFile` **不会刷新页面**（热替换内存档 ＋ 落盘 ＋ `notify()`）⇒ 不是"页面重载"的错觉。

| ⑥ **手机 Firefox 加固 C** | `game/storage.ts` | 看门狗窗口内补一条**状态轮询**（只读 `document.hidden`，**不碰 `hasFocus()`**——后者在开发工具/窗口失焦时会误标"已离开前台"，反而废掉"没弹出来"的兜底） | 有的内核改了可见性却不派发 `visibilitychange` |
