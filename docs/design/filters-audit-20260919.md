## 四、可统一的候选（等你裁，本文件不预设结论）

1. **文案**：把二级「全部」统一成一处口径（候选：`全部子类` 全套，或按维度命名 `全部槽类 / 全部类别 / 全部级别`）。
2. **键**：`SUB_ALL` 一个常量走全家（把精炼炉的空串与舰队的 `'all'` 收编）。
3. **出现/重置规则**：二选一——「级联 + 换上级即重置」或「全常显 + 各维独立」。
4. **选项来源**：把 `FLEET_FILTER_TABS` / `STORE_OWN_TABS` / `FURNACE_TABS` / `WRECK_SUBS` / `MANU_TABS` / `BP_MAIN` 收进 `ui/itemSubs.ts` 单点表（与既有的 9 张表并列）。
5. **动态性**：是否把「只列真有内容的档」这条（书架已按此改）推广到其余页面；还是统一改成"静态全列 + 空态文案说明"。
6. **补筛选**：任务中心是否补**级别筛选**（资源/快递已分 L1~L5）；货仓是否补分类筛选（与仓库对齐）。
7. **搜索与筛选**：统一为「与」（把技能页那条互斥改掉）或统一为「互斥」。

1. **第 0 遍 · 戊**：一次裁清六条基线（不改码，只出规范）——规范定了，后面每遍都只是"套用"。

每一遍 = 一次完整交付：落码 → 四道闸门 → 汇报 → 船长实机验收 → 与该遍规范条目一起推送。
