## 1. 船长原话（照抄）

> 「技能加速页面，因为之后还会获得 3 倍和 4 倍的加速剂，所以抬头需要在使用了加速剂才会出现，
> 下方的持有的加速道具内也要说明不同的加速剂的效果」

## 2. 现场（动手前核实）

- 「技能加速页面」= 技能页的子窗口（`pages/SkillsTreePage.tsx` 的 `SkillBoostBlock`，
  子页签 `ui.boost.001`「技能加速」）。
- **抬头** = 那条 `.app-boost-now` 状态条：⚡图标 ＋「技能加速 ×2」＋「未生效」/「剩余 …」
  ＋ 一句效果说明 ＋ **「自动续用」开关**。倍率取自 `SYNAPTIC_ACCELERANT_MUL` 反算（不写死 ×2），
  但**那条常驻** ⇒ 只有一剂时"×2"恰好对，将来有多剂时"抬头挂着一个固定倍率"就会读错。
- **下方清单**只有一行：图标 ＋ 名称 ＋「持有 ×N」＋「使用」——**没有任何效果说明**。
- 表里目前**只有一剂**：`synaptic-accelerant`（`items.ts`，24 小时 ×0.5 · 不可叠用）；×3 / ×4 未进数据。
- **同族先例**：活动栏那枚加速读数本来就是"**生效才出现**"
  （`ActivityBarClassic.tsx`：`synapticAccelerantRemainMs() > 0 ? … : null`）⇒ 抬头条件化与它同口径。
- **连带**：`core.consumables.syncBoostRenew`（自动续用）在"剩余 0"时同样会补一剂 ⇒ 开关若跟着抬头
  一起收，玩家在没生效时就够不到它。这一处请船长定（见下）。

## 3. 船长四答（2026-10-02，集中提问一次问完）

| 问 | 取 | 说明 |
|---|---|---|
| 自动续用开关放哪 | **乙：跟着抬头一起收** | 没生效就看不到开关；用法变成"先手动用一枚 ⇒ 抬头出现 ⇒ 这时才开得了自动续用" |
| 行内效果说明取哪份文案 | **乙：直接渲染该道具的物品说明全文** | 与物品页/货仓页同源，中英自动跟随 |
| 本轮要不要连 core 泛化成多剂 | **甲：不泛化** | 只做「抬头条件化 ＋ 行内效果说明」，留好加行的位置；core 的「按道具使用/倍率/续用」与存档字段等 ×3/×4 那批再一起改 |
| 物品说明漏了技能页这一处 | **甲：一并补成三处** | 中英各改一处 |

⚠ 乙案没有卡死态（已核 `syncBoostRenew`）：开关开着时它会在"剩余不足以练完当前这一级"之前就补上，
`remainMs` 不会掉到 0；真没料了由它自己关掉开关并写 `core.consumable.015`。
