# V13 设计：星图探索系统（迷雾 · 点亮 · 扫描探索）

> 状态：**已确认**（用户 2026-09-04 确认：两层迷雾模型 A；点亮 = 到达点亮 + **扫描探索**主动指令
> （扫描期间随机事件触发进度额外增加 + 新设「探索发现」专属事件池）；
> 迷雾同时封锁行动；悬赏情报标记例外显示；规避机动等战斗向技能不引入）。
> 影响包：core（state/save v13→v14、explore.ts、mining/expedition/ai 接入、events.ts）、
> desktop（星图迷雾渲染、MapPage 锁定展示）。存档结构 **v12 → v13（→ v14 续扫补充，见文末）**。

## 一、迷雾模型（用户确认：两层 + 半段虚化提示）

```
[已探索] hub ──实线── [已探索] kor      （两端已亮：实线 + ′ 分钟数）
     │ 暗色实线（不显示分钟数）
  (○) 「未知信号」剪影                  （已探索星系的一跳邻居：半透明虚线圆点，名称/内容隐藏）
     ╌╌╌ 半段虚化虚线（画到 50% 渐隐）   （剪影连向更远处的提示：这边还有路）
```

- 可见性由存档 `exploredGalaxies`（存"已探索"集，初始 = 母港）+ 图实时推导：
  - 已探索：完整显示（名称/描述/内容）；
  - 剪影 frontier = 未探索且邻接已探索的星系；
  - 更深处不渲染。
- 布局编辑器（dev 工具）与 dev 模式显示全图，不受迷雾影响。

## 二、点亮途径（用户确认：到达点亮 + 扫描探索）

1. **到达点亮**：任何船实际抵达目标星系（远征去程结束进入交火 = 到港；主控/AI 矿船
   出航结束开始采掘）→ 点亮该星系；在途作业（读档/迁移恢复）由 `ensureTransitExplored`
   运行时兜底自动点亮。
2. **扫描探索（startScan，主动指令）**：对象 = 剪影星系；
   - 校验：星系存在、未探索、是剪影（在已知航线边缘）、无进行中主控作业（采矿/远征/扫描互斥）；
   - 作业 = 前往（单程按跃迁实际耗时）+ **就地深空扫描 10 分钟**（SCAN_WINDOW_MS）+ 返航；
     完成回港 → 点亮并写日志（总耗时出发时锁定，warp 快船更快）；
   - 免费（时间与事件节奏即代价）。

## 三、扫描期间的随机事件（用户指定）

- **触发进度额外增加**：扫描作业进行期间，随机事件倒计时按 `balance.events.exploreBoost`（默认 1.0 =
  ×2 速度）提前；实现于 `advanceEvents`（先播种、后加速、while 触发，顺序修正避免把 0 当未播种）；
- **探索发现池**：扫描期间事件到点 → `fireOneEvent` 强制从新池 `EXPLORE_EVENTS`（12 条中文风味，
  含小额 ISK 奖励；导出供测试/文档）抽取；非扫描期该池不参与（四类常规池不受影响）。

## 四、行动封锁（用户确认：迷雾同时封锁行动）

- 目标星系未点亮（且非母港）→ `出发远征` / `开采该星系矿带` / AI 同款派发一律拒绝
  （`actionBlockReason` 统一提示「尚未探索——先对星图上的未知信号执行扫描探索」）；
- 母港星系（含本地矿带）不受限 → 新手基础采矿不断；
- **悬赏情报例外**：列表照常可见；星图剪影节点显示 ⚔N 数量徽标（协会共享情报，帮助决定扫描优先级）；
  矿带内容标记跟随迷雾；矿带列表可见但锁定并提示「所在星系未探索」；
- `expeditionFeasibility` 增加探索检查（UI 出发按钮禁用文案 = "星系未探索"）。

## 附：V14 补充（2026-09-04 确认：扫描探索可终止，进度保存续扫）

- **问题**：扫描作业一旦开始只能等完成（最长 30+ 分钟），玩家无法中断。
- **语义（用户确认：续扫式）**：终止时保存"**就地扫描窗口**已完成毫秒"（航程段不折算）；
  下次对该星系扫描只补扫剩余窗口（往返航程照常）。进度随档保存，离线不丢。
- 存档：`scanProgress: Record<galaxyId, ms>`（v14；上限 = SCAN_WINDOW_MS，normalize 收敛）——
  `MIGRATIONS[13]`（v13→v14 补空表）+ 往返保存测试；
- 规则（explore.ts `stopScan`）：
  - 去程途中终止：无窗口进度新增（若此前有存档进度保留）；
  - 就地扫描中终止：`scanProgress[gid] += (elapsed − 单程)`，作业结束（船立即回港模型）；
  - 返航段终止（窗口已满）：直接结算点亮（与自然完成同一路径，清进度）；
  - 再次 `startScan` 该星系：总时长 = 往返 ×2 + 剩余窗口，日志注明「续扫」；
  - 扫描完成（自然或终止结算）一律清除该星系进度记录；
- UI：扫描进度条标题行右侧「终止探索」按钮（warn 样式）+ toast；按钮 title 说明进度保留。
