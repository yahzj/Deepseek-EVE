## 根因（⚠ 含一次"我第一版改错了"的留痕）

1. **第一版判断错了**：我先按 `if (w.allFoes === true && hit && !droneHit)` 里那个 `&& hit` 去改，
   以为它就是闸门。**改完用例立刻红**（第 434 拍仍只有 1 条），引擎诊断显示那两拍连插在块前的
   日志都没执行 ⇒ 才看清真结构：**整段"全体攻击"原先写在上面那个 `if (hit) { … }` 里面**
   （那一层的 `hit` 就是主目标那一发的命中判定）⇒ 主目标没中时整段跟着被跳过。
   **原条件里那个 `&& hit` 是多余的第二道锁，去掉它不改变任何行为。**
2. **真闸门 = 外层 `if (hit)`**：`hit === false` ⇒ 副目标**连掷都不掷**，画面只剩主目标那一条弹道。

## 取证读数（3 艘敌舰 · 28 轮齐射 · 同种子前后对照）

| 读数 | 修前 | 修后 |
| --- | --- | --- |
| 铺开轮（3 条弹道） | 10 | 28 |
| **单发轮（1 条弹道）** | **18（64%）** | **0** |
| 每轮期望命中目标数 | 0.679 | **1.071**（= 命中率 × 3） |

- 64% 恰等于 `1 − 主目标命中率(0.357)` ⇒ 单发轮的成因就是"主目标没中"。
- 同种子逐拍对照（诊断探针实测）：`t=433` 修前 `me导弹=1 [w0-foe-1:-]`、修后
  `me导弹=3 [foe-0:H, w0-foe-2:H, w0-foe-1:-]` —— 主目标仍未命中，但两艘副目标照常命中并掉血。
- 输出倍数 **×1.58**（3 敌、命中率 0.357 的口径）。

**为什么判定为缺陷而不是设计**（三份口径里两份都是"每目标独立"）：
① 落码记录（2026-09-13）只写「**逐目标独立掷命中** + 各吃各自层克制」，从没提过这道闸；
② **胜率预估器**（`combat.steadyPreview` 的 `allFoesMul = foes.length`）一直按"每轮打全部敌舰"算
⇒ 与实战差 1.58×（预估偏高）；③ 船长 2026-09-13 原话就是「对所有敌方同时攻击」。

## 修法

- `packages/core/src/combat.ts`：把「全体攻击」整段**移出 `if (hit) { … }`**（条件简化为
  `if (w.allFoes === true && !droneHit)`），并就地写明这次改判与由来。
- **句式一字未动**：逐目标各自掷命中（`oHitChance` 用**那一艘自己的回避**）、各吃各自的层克制与抗性、
  副目标不吃锁定加深（基数用 `dmg`）、受击增程等触发点照旧逐舰触发、打机群（`droneHit` 非空）仍不铺开。

## 影响面 / 不做

- **只此一件武器带 `allFoes`**（`mod-wh-c-missile`）⇒ 只有装了它的场次读数变化。
- 单发 / 装填 / 射程 / 命中 / 弹药一字未动 ⇒ **单体标称 DPS 锚（`wh-weapon-dps` 的 ×0.69）不受影响**
  （只有 1 艘敌舰时本就没有副目标，这一段本就不做事）。
- 不动 `steadyPreview`（它本来就是"每目标独立"的口径，本次是让**实战**与它对齐）。
- 不重标单发：船长未要求补锚（若日后觉得偏强，锚点入口 = 单发 `dmgMult` 或命中 0.6）。
