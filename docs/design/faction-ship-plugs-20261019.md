- 原有「每个信号空间势力至少三种」目标没有被这五件取消；这五件各作为一项指定设计，其余各两种仍待商讨。下文原15种仅为未批准备选，不自动与这五件一同实施。
- 沿用官方名「隐秘行动装置」记录机制；袭击者只解除推进器互斥，不凭空授予隐秘行动、不延长时间，开火和超时现形不变。侦察舰已自带该豁免，不再重复获得收益。
- 旧规则三层容量插件使用固定值。护盾镀膜的新提案属于按最终护盾值进行战斗转换的特殊规则，不能在未获明确确认前视为已修改旧规则；通用固定容量船插保持原样。
- 护盾镀膜按转换前最终值取数一次，不将转入装甲再乘一遍技能、装备或插件的装甲容量倍率。例：最终盾1000、甲600，满状态进入战斗可转为盾0、甲1100；半装甲及跨场的当前值仍待裁定。
- 护盾蓄能建议作用于完整被动恢复公式而非仅当前护盾比例项；现行是当前护盾1.2%/秒与满盾0.6%/秒下限取大，提案对应1.8%与0.9%。护盾为0时仍不被动恢复；与镀膜同装时不凭空生成护盾。
- 被动恢复维护备注：最终被动恢复量 = 基础被动恢复量 ×（1 + 同类加成系数之和）。护盾蓄能的0.5仅记一次；未来若增加另一个20%来源，合计乘1.7，不是1.5×1.2。不得给未来同类增益另开乘区，也不据此修改主动充能、力场等其他恢复机制。
- 廉价打印的明确解释：无人机仍可被击落，击落后照常停火；不增加战中复位能力，也不把本舰效果扩散到其他舰。需保留运行中的击落/复位记账以免死机继续攻击或重复返还，玩家战后永久损失为0，不靠额外从仓库补机实现“返还”。
- 廉价打印整件只结算一次：重复安装不继续缩短启动间隔或储备甲板补机周期，不将机群三层血量连续减半，也不将伤害连续乘0.75，不增加返还数量。
- 廉价打印的血量/伤害建议在本舰机群完成已有技能和装备加成后分别乘0.5/0.75，三层分别取最终整数，不改单件无人机物品表；启动减免与既有启动来源独立乘0.75，不改变攻击装填。伤害独立乘0.75已明确，其他计算顺序仍待确认。
- 储备甲板周期减免作用于本舰已装的各件储备甲板，插件效果只应用一次；无储备甲板时不会凭空获得战中补机。原有多甲板按需启动、逐件补机队列及备用机预算机制不因“周期缩短”一项自动取消，战后免损与补机货源守恒仍在完整总结中定案。
- 空间压缩须同步本舰货仓、无人机装载上限、实际出击与CPU预算读数；不能只改战斗或界面。减少CPU的安装动作要先检查是否超载，避免不可拆船插把已有合法配置直接变成超载配置。
- 空间压缩同型叠加：固定值按件累加，n件无人机舱增加80n立方米、CPU预算减少50n、最大速度减少20n米/秒；货仓加成建议沿既有同区加算为25%n，而非逐件乘1.25，最终区间仍随完整总结确认。
- 通用槽数、不可拆换、残骸及整船回收原则暂不改；是否给这五件设置限装、获取与制造均须明确裁定，不沿用上一轮助手建议当作批准。

### 集中待确认

1. 前三件“不叠加”建议整件只生效一次，袭击者速度代价也只扣一次；廉价打印已明确不叠加，空间压缩已明确可叠加。是否需要给不叠加者另设每舰限装一件，以及空间压缩的货仓加成区间，仍待确认。
2. 护盾镀膜是否同时增加开场当前装甲与装甲上限？转换部分是像护盾一样每场重建，还是并入装甲残余跨场保留？前者必须单独结算转换层，不能误治愈原装甲损伤。
3. 廉价打印的“启动时间减25%”建议只影响首批出击，战中复位沿原间隔；若母舰沉没，建议仍按原沉船规则处理本舰载机，不向仓库额外返还。两点均待船长确认。
4. 这五件暂不预设图纸永久性、掉落入口/概率、料单/工时或公告；剩余各两种可在效果边界确定后继续讨论。

## 建议共通方向

- 势力只决定来源与技术风格，不先限制为本族船体才能安装；安装仍遵守既有货舰能力限制。
- 首批不增加套装效果、不改变插件格数、不开放卸下或替换，不改现有12种通用船插。
- 除上述船长已指定的四种不叠加船插外，其余候选同型重复规则尚待确认。固定值加算；百分比字段按其属性的既有公式合成，避免用一句全额叠加掩盖算法差异。缩短间隔、CPU减免和酸蚀等在下一轮逐项写清重复5件的结果与原有下限，未定前不承诺零间隔/零CPU/无穷酸蚀。
- 获取建议为对应势力信号空间战利品提供图纸、组装机制造，不直接投放成品；图纸是否永久及掉落入口/权重待定。采用既有主题材料加通用黑匣的方向，不默认新增五族黑匣或新货币。
- 现有玩家残骸插件按数量折黑匣的规则保留，不因势力插件新增一种按来源保留的回收账；整船回收/主动拆船仍各走原规则。
- 涉及插件/装配、战斗建档、工业制造、信号空间掉落与势力图鉴；此处仅列设计触及面，实施前需获得这份跨域范围确认。
