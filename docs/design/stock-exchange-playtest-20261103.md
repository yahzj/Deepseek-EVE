# 证券交易所 · 可玩性算法验证（P0：建造前筛参数）

> 状态：设计并实施中　｜　日期：2026-11-03
> 船长指令：「先验证可玩性吧，用算法可以测验吗？」
> 结论口径：**算法能测结构，不能测乐趣**。它负责筛掉「必死局 / 必印钞 / 无决策」的参数，剩下的手感必须真人玩。

---

## 一、能测什么、不能测什么

| 能测（结构性问题） | 不能测（必须真人） |
|---|---|
| 不同杠杆/波动/费率下，玩家的存活率与破产时间 | 爆仓那一刻心里爽不爽 |
| 策略之间有没有「技巧空间」（差异显著 = 有得玩） | 画面/音效/节奏的临场感 |
| 是否存在必赚策略（= 印钞机，经济崩） | 长期留存与社交传播 |
| 是否存在必亏结构（= 劝退，没人玩） | 「故事感」与炫耀欲 |
| 决策密度够不够（多久有一次值得做的决定） | 个人偏好（有人爱长线有人爱梭哈） |

## 二、可玩性代理指标（指标化「好玩」）

| 指标 | 定义 | 目标区间（初版） |
|---|---|---|
| **存活率** | 30 游戏日后账户未破产的比例 | 30%~70%：太高=没风险，太低=劝退 |
| **盈利面** | 最终盈利的玩家比例 | 20%~45%：接近抛硬币但可被技巧改善 |
| **策略区分度** | 最好策略与最差策略的期望收益差 | 显著 > 费率成本 ⇒ 有技巧空间 |
| **爆仓节奏** | 首次爆仓发生的游戏时间中位数 | ≥30 分钟：太短=瞬间死 |
| **近失率** | 爆仓前最后一次距强平 <5% 的比例 | ≥40%：制造「差一点」 |
| **决策密度** | 每分钟出现「值得做决定」的事件次数 | 0.2~1.5 次/分钟：挂机与盯盘都能接受 |
| **波动刺激度** | 每分钟保证金盈亏波动的 90 分位 | 不为 0 且不持续爆表 |
| **印钞检测** | 所有策略中是否存在稳定正期望 | **零容忍**：有则参数作废 |

## 三、实验矩阵

- 策略（7 种）：随机梭哈 20x / 动量追涨 10x / 网格 3x / 定投长线 1x / 50x 高频 / 价值锚点 / 模板组合（定投+移动止盈）
- 杠杆上限：10x / 20x / 50x
- 日波动：中盘 4% / 小盘 8% / 妖股 15%
- 费率：低（买 0.05%/卖 0.1%）/ 基准（0.1%/0.2%）/ 高（0.2%/0.4%）
- 每组合 500 次蒙特卡洛，每次 30 游戏日，1 秒 tick

## 四、模拟模型（与设计稿一致）

- 价格：对数随机游走 + Student-t(ν=5) 肥尾 + EWMA 波动聚集 + 均值回归锚点 + 泊松事件冲击
- 逐仓：`IM=1/L`、`MM=0.6×IM`、多空强平价按设计稿公式
- 强平：分片吃单，滑点按盘口深度估计；不允许负余额（穿仓记欠款）
- 成本：佣金+印花税按名义收；杠杆利息与资金费按小时
- 玩家资金：1000 万启动（原型值），不做入金/出金
- 随机源：可复现种子；同种子同结果

## 五、判定规则（绿灯/黄灯/红灯）

- 🟢 绿灯：存活率、盈利面、策略区分度、印钞检测全部达标 ⇒ 参数可进原型
- 🟡 黄灯：1~2 项越界 ⇒ 调参重跑（优先调杠杆上限与费率）
- 🔴 红灯：印钞检测命中，或 50x 存活期中位数 <10 分钟，或盈利面 <10%（劝退）⇒ 该参数组合作废

## 六、输出

- 每个组合一行：存活率 / 盈利面 / 期望收益 / 爆仓时间中位数 / 近失率 / 决策密度
- 附「策略区分度」热力表：策略 × 参数
- 结论：推荐参数（杠杆上限、费率、波动档、事件间隔），以及红灯组合
- 脚本可复现，输出写入 `docs/design/stock-exchange-playtest-20261103.md` 的报告节

## 七、复现

- 脚本：`tools/_exchange-playtest.ts`（临时探针；验证后决定是否转正式入库）
- 运行：`npx tsx tools/_exchange-playtest.ts`
- 该仿真**不依赖**原型 UI，与 `features/exchange/mock/` 的规则同口径；参数漂移时以本文件与设计稿为准。

## 八、实测结果（2026-11-03，种子 20261103，哈希 06a63825）

### 8.1 90x 与档位费率（30 日 × 500 次，日波动 8%，四策略统一 90x）

| 指标 | 90x（tiered） | 50x（tiered） |
|---|---|---|
| 首次爆仓中位 | **29 分钟** | 54 分钟 |
| 破产（资金归零）中位 | 16.0 小时 | 19.1 小时 |
| 30 日存活率 | 0.0% | 0.0% |
| 一轮往返费用 | **保证金 5.4%** | 保证金 7.5% |
| 平费口径下 | 保证金 **27%**（判红，玩家输给手续费） | — |

**结论**：90x 是「分钟级梭哈档」，不是线性更难的一档；**档位降费是 90x 可玩的前提**（tiered 的单轮成本低于 50x，因为高杠杆档费率更低）。船长「最高 90x、让他们梭哈」在数学上成立，但前提是费率随档下调。

### 8.2 印钞红灯：锚点漂移无效

- 尝试「锚点漂移 + 自适应回归阻尼」：k 从 8 扫到 800、锚点日漂移 σ 从 1% 扫到 8%，**全部仍判印钞**（k=800 仍 +116%，C 组 30 日期望 +2730.7%、盈利面 100%、t=22）。
- **根因不是锚点可见**，是量化模板「+62.5% 止盈 / −17.5% 止损」的赔率结构在吃残余均值回归。
- **修法**：改模板（止盈 +15%~20%、持有 ≤2 日）或加持仓成本；**不能拿锚点漂移当修复**。

### 8.3 3x 网格在 8% 波动下必亏

- A/B/C 三组：−93.8% / −94.2% / −78.6%，远低于 −50% 劝退线。
- **结论**：8% 波动下删掉 3x 网格模板；网格只保留「日波动 ≤4% + 1x」。

### 8.4 决策密度仍不达标

- 实测 0.000~0.076 次/分（目标 0.2~1.5/分）。
- 提高事件频率不改善（杠杆玩家死更快）；事件均值建议 **15 分钟**（活跃度），但**决策密度指标口径要改**：「可操作事件/高频 1 分钟决策」而不是「行情变动」。

### 8.5 复现与一致性

- 同种子两次 RUN1/RUN2 均为 `06a63825`（MATCH）；旧口径价值锚点 +868.1%/99.8% 与旧 50x/8% 13.0%/1.3 时均 MATCH（回归对照有效）。
- 总耗时 68.5s（<180s）。
