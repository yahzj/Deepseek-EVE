# 蓝图获取速率调整（碎片门槛下调 · 市场蓝图书权重 5% · 蓝图单寿命 6 小时）

> 状态：**已确认**（船长 2026-09-10 拍板）。经办：大鲸鱼一号。
> 触发：船长复核「残骸与市场两条蓝图获取路线」后要求调整出率；先答复「D2 那批专属装备无蓝图、不上市场」，
> 随即定下本批两处系数 + 两处边界。

## 一、决策链（船长逐轮拍板）

1. **残骸侧：只降集齐门槛，概率不动**——`FRAGMENT_RECIPES.need` MK2 100 → **25**、MK3 1000 → **250**；
   `RECYCLE_CHANCE.fragT2/fragT3`（0.00045 / 0.0007 每 m³）保持不变。
2. **市场侧：蓝图书权重 50% → 5%**（`balance.market.blueprintWeight = 0.05`）。
3. **边界一（船长二次确认）：5% 也影响奇货渠道**——稀有抽取与奇货掷骰共用同一个权重。
4. **边界二（船长选丙案）：蓝图单寿命延长到 6 小时**（`balance.market.blueprintLifeMs`），
   与奇货同为 6 小时；普通稀有单仍 36 分钟。
5. 旋钮范围（船长定）：出率 + 集齐门槛；**书价、声望门槛、暗市闸不动**；收购侧（玩家回卖）不动。

## 二、改动清单

| 位置 | 改动 |

| `packages/core/src/balance.ts` + `types.ts` | 新增 `market.blueprintWeight`（0.05）与 `market.blueprintLifeMs`（6h） |
| `packages/core/src/market.ts` | 新增 `blueprintWeight(def, ctx)`；三处硬编码 `0.5` 改读配置（稀有抽取两处 + 奇货掷骰一处）；`orderLifeMsOf` 对"稀有渠道蓝图书"返回 6 小时 |
| `packages/core/src/index.ts` | 导出 `fragmentPoolOf` |
| `apps/desktop/.../ui/wreckFlavor.tsx` | 星图/工业页残骸卡的碎片提示改按 `tier` 判威胁门槛（不再用片数反推档位） |
| `apps/desktop/.../pages/MarketPage.tsx` | 稀有订单页提示补「蓝图书 6 小时」（tooltip 与页脚各一处） |

| `tools/market-rarity-sim.ts` | 新增 `--bp-weight` 对照参数、蓝图占比与按行间隔输出（吸收原临时探针 `_bp-rate.ts`，探针已删） |

### 为什么必须加 `tier` 字段（本次唯一的连带重构）

改动前，引擎用「片数 == 100 / == 1000」判断配方属于 MK2 还是 MK3 档（`salvage.ts` 两处池拆分、
`wreckFlavor.tsx` 的威胁门槛、`tools/salvage-econ.ts` 两处）。**只改 need 会把两个池一起打成空数组**
（碎片一片都不出）。故档位改为显式字段，所有判据改读 `tier`。

## 三、数值结果（工具实测）

### 残骸侧（`npx tsx tools/salvage-econ.ts`）

| 口径 | 改前 | 改后 |
|---|---|---|
| MK2 整档（一趟凑齐 3 张书） | 666,667 m³ = 炉时 463h / 370h | **166,667 m³ = 116h / 93h** |
| MK3 整档 | 4,285,714 m³ = 炉时 2,976h / 2,381h | **1,071,429 m³ = 744h / 595h** |
| 相对"买齐三张书"的等价工时 | 约 28 倍慢 | **约 7 倍慢** |

### 市场侧（`npx tsx tools/market-rarity-sim.ts --windows 2880`）

| 指标 | 改前（权重 0.5） | 改后（权重 0.05） |
|---|---|---|
| 蓝图占稀有供给 | 25.2% | **3.2%** |
| 大众档蓝图单行间隔 | ≈1.5h | **≈11.7h**（中位 8.0h） |
| 高阶档蓝图单行间隔 | ≈6.0h | **≈40.9h**（中位 28.7h） |
| 六张碎片路线对应书 | 1.5~6.9h | 10.1h / 12.3h / 44.5h（MK2）· 36.8h / 41.2h / 36.9h（MK3） |
| 蓝图单寿命 | 36 分钟 | **6 小时**（有货时间占比：大众档 ≈51%、高阶档 ≈13%） |
| 稀有渠道每窗张数 | 14.70 | 14.62（**不变**：蓝图让出的份额全部回到现货装备） |

奇货渠道（舰船蓝图 14 张 + 弹药 MK2 蓝图 3 张）同样 ×0.05：单行命中期望
`0.008 × 现货抢购学 × 0.05 = 每窗 0.04%` → 单行 ≈ **417h（17.4 天）**；
17 行合计 ≈ **0.98 张/天**（无技能）——造船线从"随时能买到"变为"要蹲、要攒"。

## 四、已知取舍与待办

- **常驻（common）蓝图书渠道未动**：民用级/MK1 蓝图走常驻掷骰（`0.425/窗`，2026-09-09 定），
  本次 5% 只作用于稀有与奇货两个渠道。船长如需一并收口，另开一条。
- **旧公告文案与实际不符**：`packages/data/src/announcements.ts` 有两处「集 100/1000 片」「集 1000 片」
  （2026-09-09 蓝图公告）。改动门槛后该表述过期，玩家会照旧文操作。**修订公告需船长逐条批准**，
  未批准前保持原文（登记为已知偏差）。
- **`tools/salvage-econ.ts` 的彩头 EV 口径失真**：该行把碎片按"蓝图市价 ÷ 片数"折算成 ISK/h，
  门槛降到 25/250 后折算值涨 4 倍（约 2.96 万 → 10.3 万 ISK/h），超过「彩头 EV ≤ 保底 10%」的旧护栏。
  碎片不可出售、该值是"收藏折算"而非产出，故未改口径；如船长要，可改为"碎片只记进度、不计 EV"。
- **高级箱（稀有残骸）继续封存**（船长 2026-09-10 定，本批未动）；窝点专属装备的
  「来源唯一契约」（无蓝图、无市场卡、无碎片配方、不进常规池）由 `content:check` 守住。
