# 返航时换驾驶限制回退

> 状态：已实现，本地专项自测完成，待船长验收；不推送（二号，d2/workspace，2026-10-14）。基线`29fb5a5f`。

## 船长原话

「进行回滚，允许返航时切换其他船只」。针对此前回报的停止采矿/打捞后的独立返航，以及站内作业排队返航不能换驾驶。

## 范围与边界

- 只回退当前驾驶舰在`shipReturns`独立返航时禁止切换到其他可用舰船的新增限制，不回滚整批血量、恢复、基础炮、近盲、停靠或返航接续实现。
- 换驾驶交接的只读预检释放旧船返航限制，真实账本、已走时间和货物不变；新驾驶船使用港内位置，旧船继续航程、到港才卸货。
- 当前船返航不是停靠：仍不能装卸、出售船上货物、站内维修或配置。目标舰本身正在返航、战斗、探索等仍不可接管；换港transit及其他原活动锁定不扩大放行。
- 成功换驾驶取消旧站内待办，失败不改待办、货物或返航。切站内活动后尚未走第一拍的占位返航，必须在旧船归属下兑现真实腿长、清交接标记，防止下一拍给新驾驶船建立错误返航。
- 域：舰船与装配（core换驾驶、既有页面同源预检及回归）；同类参照`changeShipBlockReason`、`retireMiningShip`/`retireSalvageShip`、`advanceShipReturns`。不新增随档字段、文案或UI布局，不处理个人档。
