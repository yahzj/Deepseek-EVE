## 三、概述（About This Game）

### 3.1 完整版（推荐；1148 字符，可直接粘贴）

```
【信息库检索重启：1/7】

你在这条船的核心里醒来。上一次运行是什么时候，记录里没有答案。

人类早已离开这片星海；如今的航道由章鱼人的行会经营——协会签发悬赏、打捞队收购残骸，
而定居点之间的每一吨矿石、每一件装备，都要有人运。
他们把你当作一名飞行员。只有船自己的系统知道，你就是这条船。

第一件事很朴素：把还在运转的采掘激光架到矿带上，让账户里重新有进项。
之后的一切，都从这个循环里长出来。

—— 采出来，炼干净，造成型，卖出去，再拿钱去换更硬的火力。

【采掘与精炼】
矿带覆盖矿石、气体与冰矿，采掘激光按设定自动循环作业，遇上富矿脉还有额外收获。
精炼炉支持多工位排产：主控号位由你亲自指定，闲置的 AI 核心顶上其余炉位，
矿石按批次在炉里转化，产物直接入库。

【制造与工业】
装备与舰船都能按蓝图自造。组装机可以循环制造，蓝图一次投入、长期复用；
AI 工位随技能扩容，把"造什么、造多少、卖给谁"交给一条能自己跑的产线。

【舰船与装配】
武装、重装、航运、采矿四个族系，从护卫舰到旗舰分档；六个装配槽、上百件装备，
动力、火力、防御、工业与无人机各有取舍。

【星图与远征】
一张连成网络的星图：有的星门要声望才能进，有的星系可以建前哨站；
悬赏任务、敌人窝点，以及每天轮换的「敌对派系活跃」。
窝点打下来会带回稀有残骸——解体后能得到那一族的专属装备，没有图纸，也不在市场上出售。

【实时战斗】
战斗是真正在打的：护盾、装甲、结构三层承伤，动能、高爆、能量三系互相克制，
接战距离会改变命中与伤害；不同的敌群打法不同——贴身缠斗、绕圈消耗、放风筝、保持距离。
无人机分侦察、攻坚、重载、哨戒四型，出击会被敌方近防炮打掉，战后按技能回收机体，
没回收的就要回港补。多波次增援、锁定阵列、战中自修的维修装置，都会改变一场仗该怎么打。

【市场与贸易】
市场由 NPC 订单簿与站内库存池组成：货多压价、断货涨价，
稀有度分层的稀有订单与奇货渠道另有门槛。跑长途的行情有波动，
什么时候出货、走哪条线，是能算的。

【自动作业】
采矿、打捞、巡逻等作业线可以交给 AI 副船；它们与站内工业共享同一套 AI 核心启用上限。
把重复劳动交出去，是这款游戏里最实在的一次升级。

【通讯与剧情】
协会的航行管制、基建部、测绘处、工业部、冶炼组、训练处、财务处与航线安全会主动发消息过来：
航线警告、产能提醒、建站通话，全部留档在通讯页，随时回看。

【怎么挂】
离线期间照常产出；采掘、精炼、制造、副船作业与重复清剿都会自己推进；
每次操作与定时自动存档，不用怕丢进度。重复清剿遇上损失过半会自动停下提醒，不会闷头送船。

单机、无需联网——随时关掉窗口，回来时进度在等你。
```

### 3.2 主要特色（Steam「特色」栏，7 条；235 字符）

```
· 放置也讲深度：离线照常产出，但每一次升级都来自技能、装配与产线的真实选择
· 一条能自己跑的工业链：矿带 → 精炼炉 → 蓝图制造 → 市场出货
· 打真的仗：护盾/装甲/结构三层承伤，动能/高爆/能量三系克制，多波增援与战损回收
· 四型无人机与 AI 副船：把重复劳动交出去，再决定什么值得你亲自做
· 会涨会跌的市场：订单簿与库存池，跑长途是有行情的
· 星图上有故事：窝点与稀有残骸、协会各部门的来信与建站通话
· 单机、无需联网，随时关掉窗口、回来接着养船
```
