## 一、背景与目标

三族基础弹（动能弹/爆破导弹/能量弹药）是唯一弹档，无玩家选择、无升级空间。
本次新增每族 **MK2 高级弹**（纯数值上级，克制表同基础），并引入**出战前选档**：
装配页按弹族选择本船用弹档位，开战预载按档消耗；战斗中不换弹。
连打（巡回自动再出发/离线补算）与手动战斗同源装载——**玩家配置什么档，连打就消耗什么档**；
玩家未配置（默认基础弹）则消耗基础弹。

## 三、机制

1. **档位存储**：`FleetShipState.ammoPref?: Partial<Record<DamageType, string>>`
   （值 = 弹 itemId，如 `ammo-kinetic-2`；缺省 = 基础弹）。旧档无键 → 基础弹，零迁移。
   随船记录（换船各自独立）。
2. **装配页选档**：按弹族（动能炮/导弹架/激光炮 → 各自弹种）行内下拉「基础弹 / <弹> MK2」，
   持久化写入当前驾驶船 `ammoPref`。
3. **开战装载**（`startBattleFor` 预载段）：目标弹 id = 配置档；**该档库存不足 → 整族回退
   基础弹 + 开战日志提示**（不卡远征）；实装弹 id 记入 `BattleState.ammoIds?`（零迁移，
   缺省 = 基础弹语义）。
4. **伤害接入**：单发基数 = 战斗快照所载弹档的 `dmg`（`createPlayerSpec` 按配置档取弹药卡）；
   回退发生时按基础/配置 dmg 比**修正已建快照单发**（真战与库存一致）；MC/稳态预估走
   `createPlayerSpec` 同源 = 按配置档满库存口径（与校准假想一致）。
5. **退还**：按 `battle.ammoIds` 实装弹 id 原样退回仓库（不再写死基础 id）。
6. **连打/离线/AI 触发战斗**：全部经同一装载入口 → 自动消耗当前配置档弹药（船长口径）；
   AI 副船当前无战斗任务，不涉及；playthrough-sim 无选档行为，走默认基础弹（记录在案）。

## 五、测试与校准

- 回归：配置 MK2 装载与消耗退还 / MK2 缺货回退基础 + 伤害修正 / 退还按实装 id /
  旧档无 pref 默认基础零迁移 / MK2 单发比基础高（8:6、9:7、12:9）。
- 校准：S4/T3 巡洋行加「+MK2 弹」变体复跑，确认 E 段失衡与否后留档。

## 六、已知取舍

- 纯数值上级 = 基础弹在玩家预算充足后逐步退役（与装备 MK 纵向升级同构）；
- 价格与伤害脱钩（×7.5~10 单价、+29~33% 伤害）→ MK2 弹定位**攻坚/提速消耗品**
  （缩短战斗时长、减磨损、E 段更稳），日常经济性低于基础弹——按船长拍板价格执行；
- 「选档」仅出战前，战斗中不可换（无换弹交互）。
