**缺陷读数（哨戒型 · 僚舰携带）**：


玩家看到的画面：僚舰的哨戒机只在悬停、**从不攻击**（主控上方凭空出现曳光条）。

### 2.3 根因（两处，同一个病）

`BattleScreen.tsx` 的弹道层里，**常驻型（`model.resident`）无人机的开火起点用的是 `layFx`（主控布局）**，
而不是"发射舰自己的锚"：

```ts
} else {
  from = droneHomeStation(dm, n % …, layFx)   // ← 僚舰的哨戒机也走这里 ⇒ 起点塌回主控
}
```

同一批还有一处对称缺陷：**我方无人机被点防击落时的坠落/爆炸点**，其"自家机库口"同样写的是
`layDown.me`（主控锚）⇒ 僚舰的机体被击落时会朝**主控**方向滑、并在主控旁炸。
