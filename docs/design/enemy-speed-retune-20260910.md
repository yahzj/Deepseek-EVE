## 0. 一句话

**按"速度中位线的船只"做基准后，重标的形状是"低段近战卡大提速、高段近战卡略降"**——
因为实测发现：**现状的低段近战卡全都比玩家慢 18~38 m/s（这才是"贴脸怪不贴脸"的真正根因），

## 1. 基准怎么定（船长：「参考按照速度中位线的船只」）

**基准船** = 船池（25 艘）按 `maxSpeedMps` 排序取**中位** →
**长尾鲨级导弹巡洋舰**（船速 **272** / 敏捷 **0.54**）。

它的**战斗机动** = 272 × 0.6 × (1+(0.54−0.5)×2×0.15) = **165.2 m/s**（无技能、不装推进器）。
⇒ **本提案所有"比率"的分母都是 165.2 m/s。**

工具里这条基准是**运行时自己算的**（`[...SHIPS].sort(...)[中位]`），船池变了基准跟着变，不会写死。

**换算**：`敌速(存储值) = 比率 × 165.2 ÷ 0.564`（敌方敏捷固定 0.3 → 战斗机动 = 存储值 ×0.6×0.94）。

## 6. 近战卡血量重标（口径待裁，上一版扫描结论仍然有效）

近战卡从"打不到"变成"打得到"，当年按"零承伤"定的 `foeHpOverride` 必须跟着下调。
上一版扫描（`--brawlmul` ×0.85 / 0.7 / 0.55）的结论：**×0.7 是"能过但紧"一档、
×0.55 又变回白刷、满技能档对血量完全不敏感** ⇒ 需逐卡定值，不能用全局倍率。
**D(T) 与 `foeDpsPerThreat`(0.8) 本身不动**（按您 Q5 的"保留两段式"）。
**本轮矩阵里近战卡的血量未改**（预演只改速度），所以 §4 的翻转里有相当一部分正是血量该补的地方。
**请定目标残血带**（我建议"中位参考行打完剩 30~60%"），我再出逐卡血量表。
