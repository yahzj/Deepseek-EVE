# 市场页参考图改造（2026-09-05 船长提供参考图）

## 需求
船长给出市场参考图（盘口风格：左侧热门交易列表 + 详情区[24h 中位价/涨跌/价格折线/持有量] + 买卖盘深度 + 底部交易面板[买入/卖出/单价/数量]），要求市场页参考改造。

## 现状与复用
- **价格历史已在引擎**（无需本次新增/存档变更）：`state.market.priceHistory`（每 30 分钟采样一次，保留最近 24 窗口），导出 API：
  - `marketHistory(state, goodKey)` → 价格数组；`marketTrend(state, goodKey)` → 1/0/-1（涨/平/跌）；
  - 盘口 `state.market.npcBuy / npcSell`；当前报价 `marketQuote`；持有量 `naturalHoldings`（含 escrow 侧按自然库存）。
- 交易沿用既有引擎：`buyGoodAt`（市价买入吃单）、`sellHoldingAt(key, qty?)`（市价卖出/部分卖）、`placeBuyOrderAt / placeSellOrderAt`（挂单）。

## 已实现（提交 f00a22b、c37f9c9）
- 商品行新增「📈 详情」按钮；点击展开**市场详情卡**；外部聚焦（舰船页/物品页"查看市场"跳转）自动选中并展开。
- 详情卡：
  - 价格折线（SVG，市场历史），标注高价/低价；样本 <2 显示"采样中"占位；
  - 摘要行：持有量、24h 中位价、涨跌▲▼、当前收购/供应价、站内库存池；
  - 买卖盘深度两栏：**按价格档聚合成交量**（同价合并为一行，2026-09-05 船长发现同价多行后修正），取前 8 档，柱宽∝该档挂量（买盘青绿/卖盘琥珀）；
  - 交易面板：买入/卖出 tab（自动回填单价/数量）、数量/单价输入、`市价买入`/`市价卖出`（数量可选）+ `挂买单`/`挂卖单`。
- 新样式：`app-mkt-detail / app-mkt-detail-* / app-mkt-chart / app-mkt-depth / app-mkt-book / app-mkt-trade-*`。

## 与参考图的差异 / 待办
- 已改为参考图的**常驻双栏**布局（船长 2026-09-05 继续调整布局）：左栏 = 全局搜索 + 常驻/稀有标签 + 商品列表；右栏 = 市场详情大盘（常驻显示，无选中时显示引导空态）。列表保持"有货冒泡/稀有寿命/手动挂单"等全部能力；详情卡保留价格折线/买卖盘深度/交易面板。新样式：`app-mkt-split / app-mkt-left / app-mkt-right`（`app-mkt-detail` 在右栏内改纵向堆叠）。
- 折线/摘要基于引擎历史采样（游戏内时间推进积累；新档/离线初期样本较少属正常）。
- 弹药自造（另任务）与本改造无关。

## 复核/注意
- 属 UI 信息展示改造，无战斗数值改动；价格历史字段为既有兼容字段（无存档版本变更）。
