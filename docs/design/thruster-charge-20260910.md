# 推进器周期爆发 + 高威胁近战敌突进（2026-09-10 · 状态：**已确认并实现**）

> 船长裁决（原文，分两轮）：
> ①「给予近距离敌人突进加速的能力，当进入射程2秒后，突击能力消失，之后需要10秒冷却才能再次启动突进。
>    同时修改推进器效果，推进器效果为每隔一段时间赋予玩家速度增加，持续一段时间后进入冷却。
>    同时战斗场景中，屏幕下方会显示推进器冷却时间。」
> ②「敌方突进的冷却时间延长至20秒。且只出现在高威胁的敌人身上。我方推进器持续时间改为60秒，冷却也为60秒。开场就启动。」
> ③「按建议」= 门槛威胁 ≥60、爆发幅度 MK1+40%/MK2+80%/MK3+130%、突进倍率 ×2.0、且**同时限定近战型**。
>
> 触发来源：2026-09-10 战斗复核 §9（短射程近战敌"够不着"——推进器把玩家机动抬到远超敌方锚定值，
> 距离拔河后停在敌射程之外）。详见 `docs/design/mixed-damage-review-20260910.md` §9。

---

## 1. 要解决的问题（一句话）

**推进器常驻加成让玩家全程快于近战敌**（机动 = 船速 ×0.6 × 敏捷修正；推进器直接乘船速），
距离拔河里玩家赢 → 停在**自己期望距离 3220 m**（主武器射程中点），而近战敌射程上限只有 **2655 m**
→ **差 542 m，永远够不着**（S2 中位对全部 brawl 2.2~2.8 km 敌卡残血一律 112%＝一点没挨打）。

两处改动配套：**推进器改为周期爆发**（平时变慢 → 近战敌有机会贴上来）＋**高威胁近战敌会突进**（够不着时主动冲）。

## 2. 确认口径（全部为船长原话/裁决）

### 2.1 我方推进器：周期爆发

| 项 | 值 |
|---|---|
| 周期 | **持续 60 秒 → 冷却 60 秒**（120 秒一轮） |
| 启动 | **开场即启动**（战斗时钟 t=0 进入爆发；即"冲刺进场"） |
| 常驻加成 | **取消**（冷却期无任何推进器加成，回到基础船速） |
| 爆发幅度 | **MK1 +40% / MK2 +80% / MK3 +130%**（原常驻 +30/60/100%） |
| 多件 | 仍按 **EVE 曲线收敛**（`curveMult`） |
| 技能 | 矢量机动操作（+5%/级）作用在**基础战斗机动速度**上（不变） |
| 影响面 | 只作用于**战斗机动速度**（弃船率/跃迁充能只看船体 agility，模块不碰） |
| 存档 | **周期由战斗时钟推导**（`lastTickGameMs - startedAtGameMs`）→ **不新增任何存档字段**，战中重载不丢 |

### 2.2 高威胁近战敌：突进（⚙ **已实现，暂未实装**）

> **船长 2026-09-10 追加：「敌人突进暂时先取消实装，仅实现功能。」**
> → 机制、状态机、参数、UI 标记**全部就位**，但由总开关 `balance.foeChargeEnabled`（**默认 false**）
> 控制：关闭时**没有任何敌人具备突进资格**，任何战斗都不触发。**启用只改这一个开关。**
> 用例 `tests/thruster-charge.test.ts` 同时覆盖"开关开 = 完整循环"与"开关关 = 完全不触发"两条。

| 项 | 值 |
|---|---|
| 适用范围 | **威胁 ≥ 60 且 战术 = 近战（brawl）**——门槛与既有「点防起始威胁 60」同口径 |
| 触发 | 当前**够不着**（距离在其武器射程之外）且**冷却已过** |
| 效果 | **临时加速：机动 ×2.0**（仍走距离拔河公式，非"无视拔河"） |
| 结束 | **进入自己武器射程后再维持 2 秒** → 突进结束 |
| 冷却 | **20 秒** |
| 总时长上限 | 无（它就是为了进射程；未进射程则持续突进，冷却不启动） |
| 存档 | 3 个 `BattleState` 可选字段（零迁移）；**不进 `cleanBattle` 白名单**（与既有 `hullEscapeFrac` 同待遇：战中重载会重置突进循环） |

### 2.3 界面

- **战斗界面底部**「装填冷却」行**新增一格「推进器」**：复刻同级 `.app-bts-reload*` 结构
  （色点 + 名称 + 冷却条 + 倒计时/就绪秒数），**常驻显示**；爆发中显示「推进中」。
- 敌方**突进中**给出显式标记（便于实测观察）。
- 星空视差速率继续由**驾驶船当前实际战斗速度**驱动 → 爆发期星空跑得更快（同一信号，非新机制）。

## 4. 验证口径与实测结果

1. **推进器档位对照**（`tools/mixed-damage-review.ts` **F 段**，9 种子、中位技能、同一艘灰鲭鲨换中槽）：

| 目标 | 无推进器 | MK1 | MK2 | MK3 |
|---|---|---|---|---|
| 星髓虫群 72（近战 2.65km，短战） | 41s · 敌开火 **1 次** | 46s · **0 次** | 48s · **0 次** | 51s · **0 次** |
| 泰坦残骸勘探 60（近战 2.6km，短战） | 40s · 0 次 | 42s · 0 次 | 44s · 0 次 | 47s · 0 次 |
| **坟场守墓人 88（近战 2.8km，长战 111~134s）** | 111s · **25 次** | 124s · **4 次** | 130s · **6 次** | 134s · **6 次** |
| 深渊之门卫队 45（狙击 13.3km·对照） | 66s · 29 次 | 46s · 20 次 | 39s · 16 次 | 34s · 13 次 |

（本表为**失稳代价改为随点火窗口生效之后**的复跑值；改口径前 MK3 坟场为 148s / 11 次。）

**读法**：
- **长战有效**：坟场守墓人跨过了 60 秒点火期 → 冷却段玩家变慢、敌人追上并开火（无推进器 25 次 → 有推进器 6~11 次，
  即"推进器已不能像旧口径那样全程免疫"，但仍显著优于无推进器）；
- **短战未变**：星髓/泰坦这类 40~51 秒就打完的卡，**整场都落在点火期内** → 仍然够不着（0~1 次）。
  这正是**敌突进机制存在的理由**（而它现在按船长指示未实装）——两件事要分开看：
  **推进器周期化治的是"长战的尾巴"，短战免疫要靠敌突进或其它手段。**
- **对照卡**：能被够着的狙击敌（深渊之门）面前，推进器档位越高越安全（开火 29→13 次、残血 30%→69%）。

2. **同源自检**：本次只改**机动速度**（距离步进），未动命中/伤害/射程/装填——对照表里能观察到的变化
   全部通过"敌开火次数/时长"体现，单发数值无变化 ✓。
3. **复跑**：`battle:calibrate` 全矩阵 + P1 复跑表（`power-ladder-rework.md` §七）——**T3/S4 等无推进器的装配行
   逐字未变**（证明作用面干净）；**S1（推进器 MK1）/S2（MK2）两行只有小幅时长漂移（±10~15s）**，
   **胜负判定一格未变**（S2 虚海/穹顶仍 0%、S1 赤潮仍 100%）。
4. **测试档**：`etier` 档**无需重生**——存档只存状态，推进器是代码；该档的装配与技能口径未变。
5. 回归：typecheck ×4 + core **794/794** + content:check + desktop build。

## 5. 已知取舍（写清，不藏）

- **冷却期无任何推进器加成**：平均机动低于旧常驻（如 MK2 旧全程 342 m/s → 新前 60 秒 385、之后 214，
  120 秒均值约 300）→ **长战（>60 秒，如 E 段 76~155 秒）的尾巴明显更吃紧**，这是本次机制的直接代价。
- **短战（<60 秒）仍免疫**：40~50 秒打完的卡整场落在点火期内 → 短射程敌依旧够不着（实测 0~1 次开火）。
  **治"短战够不着"要靠敌突进**（现已实现但按船长指示未实装），或后续另议别的机制。
- **失稳代价随点火窗口走**（2026-09-10 船长追加「行」）：`hitPenalty`（MK1/2/3 = 命中 ×0.95/0.88/0.80）
  **只在点火期生效**——冷却期不失稳（`stepBattle` 用 `meAtk` 把 `hitMul` 置 1）。
  模块描述、装配界面「点火代价」行、手册、词典均已同步为"点火期"口径。
- **门槛只给 brawl**：长射程敌（噬口/虚海/穹顶，orbit）**不吃突进**——它们本来就能打到玩家，给了只会更难而治不了病。
- `cleanBattle` 未收录突进字段 → **战中重载会重置突进循环**（同现有 `hullEscapeFrac` 待遇）。
