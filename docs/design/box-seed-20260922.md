## 一、口径（最终）
- **种子 = `hash(存档种子, 第 N 次货柜拆解)`**，`N` = **全局货柜拆解计数**（四种货柜混算，存存档，老档缺省 0）。
- **拆解不再消费 `state.rng`**（防刷的关键：开箱前去干别的都不影响结果）。
- 读档重开 ⇒ `N` 回到同一值 ⇒ 结果相同（**刷不了**）；**先开哪一箱由玩家决定 ⇒ 顺序可微调**（船长要的）。
- 一箱多件（军用 1~3 件 / 贵重品 10~20 件）由**同一条子流**派生 ⇒ 整箱固定。
- 范围：**只这四种货柜**（安全货柜 `box-relic-*` / 图纸货柜 `box-bp-*` / 贵重品 / 军用备货柜）；回收炉等其它开箱**一律不动**。
