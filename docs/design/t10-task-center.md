# T10 统一任务系统与任务中心（状态：已确认）

> 来源：船长测试反馈单 T10（roadmap 置顶，批次 B·讨论）。经船长调整**先于 T9 实施**
> （建站任务将作为任务系统的任务族落地）。2026-09-04 问答确认后实现。
> 关联：`docs/roadmap.md` T1–T11 清单、`docs/architecture.md` 里程碑表、`docs/design/t8-galaxy-stay.md`。

## 需求与确认口径

- 原句：添加统一任务界面，并分析是否归纳进星图页。
- 问答确认：Q1甲 首任务族 = **悬赏**（22 张收纳为"悬赏族"，机制全保留），框架留族扩展位
  （建站类 / 引导类随后续内容加入）；Q2甲 **归纳进星图页**——"悬赏情报"标签升级为
  「任务中心」，按任务族分组展示，星图 ⚔ 徽标与星系详情仍是地理入口；
  Q3甲 **视图层任务目录 + 状态读取现有系统**（不建引擎级任务队列；悬赏行为零风险；
  需要持久进度的新族（建站）到时补轻量进度字段）；Q4 **排序选项**：距离 / 星系 /
  奖励 / 声望 / 默认——默认 = **可接取冒泡在前**（可接取 = 声望满足且星系已探索），
  其后按名称；各排序次级一律按名称收尾（同值稳定）；选择存 localStorage。

## 实现（纯 renderer，core 零改动）

- 星图页标签「悬赏情报」→「任务中心」（图标 ⚔ 保留）；
- `BountyPanel` → `TaskPanel`：标题「任务中心」+ 家族说明行
  （"任务族：悬赏（22）。建站/引导族将随内容加入同一框架——任务卡格式已统一"）+ 排序行
  （5 个选项的 select，存 `whale-idle:task-sort`）+ 悬赏族卡片列表（原 AnomalyCard 全套
  机制：声望/探索锁、冷却倒计时、连续出击开关、去程/交火/停留文案）；
- 距离排序以**当前位置（T8 origin：野外停留点或空间站）**为起点的最短标称分钟为键，
  无航路排最后；奖励/声望收益降序。
