## 实现边界

- `packages/data/src/market/playerGoods.ts` 保留 22 件插件、20 张势力图纸、5 种加密柜，共 47 条玩家交易定义；已有15条静态条目仍以 JSON 为参数源，内容检查强制与派生公式一致。
- 移出12张非势力插件永久蓝图；保留其学习、制造和声望兑换。旧存档中尚未成交的挂单在市场初始化时退回实际托管图纸或预扣资金，重复初始化不会重复返还；新挂单与转发均拒绝。
- `playerBuyable`、`playerSellable` 继续表示 NPC 供货、收购资格，不作为玩家交易禁令。47条均关闭 NPC 双向买卖和黑市供货，不改变声望商店兑换资格。
- 势力插件永久及一次性蓝图均为100,000,000；成品按原始配方材料的`baseSellPriceIsk × count`合计乘10，按每件产出折算，不含蓝图书价、不取技能或替代黑匣折扣。当前22件料价均为11,174,500，成品基价111,745,000。
- 加密柜共用实际开柜奖池与张数范围：1～3张均匀抽取、平均2张；插件/武器/舰船三类等权，类内等权，允许重复。基价为整柜图纸总价值期望×30%，仅最终信用点向上取整。A/C/D/E/G分别为21,164,234 / 21,095,687 / 21,959,260 / 21,386,820 / 21,415,210。
- 参考基价不生成NPC行情采样或噪声，不扰动既有商品随机序列；玩家挂价仍须为正安全整数，已有本地卖单上限与后台1000倍价格过滤现在正常适用于这些条目。
- 外来订单沿用既有 5 倍稀缺规则：卖单接收买方付最终报价，原卖方按原挂价结算；稀缺买单接收卖方按 `floor(P / 5)` 收款。税费、预算、回执去重和购买声望门槛保留。
- 图鉴及蓝图书架的现有市场跳转按玩家流通资格开放；不改布局、不显示订单来源、不强制联网、不改变导入导出或普通/铁人模式。
- 后台严格共享市场不新增商品或货源，只更新隔离 relay 目录。没有数据表迁移，不打开生产数据库。
