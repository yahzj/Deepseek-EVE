# 技能训练许可（学习技能要有成本）— 工作文档

- **状态**：进行中（2026-09-27 开工 · 一号 · 主树 `main`）
- **主题**：给「学习技能」加一道付费门槛 —— 高 rank 技能要先买**训练许可**才能排训练。

## 船长原话（照抄）

**第一轮（需求）**：
> 我想让学习技能有成本，当玩家想要升级某个技能时，需要先购买技能书（不用实际购买，出现一个按钮，显示该技能的技能书多少钱，点之后直接付钱学会）。购买了技能书后，这个技能就可以随意从LV1升级到LV5。技能书从RANK3到RANK5，价格分别为5万，20万，100万。rank1~2的技能不用技能书，初始便可以直接升级训练。

**第二轮（改判）**：
> 选甲，不过我想了下，还是rank4~rank6需要钱吧，价格分别为50万，200万，1000万

**第三轮（裁定）**：
> rank6是预留的。不用改名。按照现有名称维持。其他没问题

## 已确认决策（船长三轮拍定）

| # | 点 | 裁定 |
|---|---|---|
| 1 | 买书买到什么 | **甲案**：只解锁**训练资格**，0→1 照样排队练、时长照旧（**不**直达 Lv1）⇒ 训练时长体系完整保留，且不会顺带跳过「前置 ≥ Lv1」链 |
| 2 | 收费档位 | **rank4 = 500,000（50 万）· rank5 = 2,000,000（200 万）· rank6 = 10,000,000（1000 万）ISK**；**rank6 是预留档**（本作数据表现最高 rank5，将来新增 rank6 技能时按表自动生效，不用再改代码） |
| 3 | 免费档 | **rank1~3 免许可**，初始即可直接训练 |
| 4 | 命名 | **分支名不动**（`SKILL_BRANCHES` 那 23 本继续叫「技能书」）⇒ 新道具不能同名，定名「**训练许可**」（en: Training License）。⚠ 仅 l10n 两行字，随时可换词 |
| 5 | 买许可要不要前置 | **不要求** —— 花钱就能买；买了也仍要等前置练完才能入队 |
| 6 | 老档 | 已经练过（等级 ≥1）的收费档技能**视同已购**，零迁移键、不回收已练等级 |
| 7 | 队列已排的 | **不回溯踢出**，只校验新入队 |
| 8 | 付款确认 | 50 万 / 200 万都是大钱 ⇒ **二次确认**（与现有付费操作同款样式） |
| 9 | 是否做成物品 | **不做真物品**：纯解锁状态位，不掉落、不上市场、不进仓库 |

## 范围 / 不做

**做**：core 新增定价表与判据、`buySkillBook` 动作、`enqueueSkill` 新增第 7 道校验；状态加 `skills.books`（老档零迁移）；界面挂购买按钮（详情窗 + 列表页）；中英文案走 id 制；用例与全闸门。

**不做**：不改分支命名；不做物品/掉落/市场；不动价格（船长定）；不改训练时长公式；不改前置机制（许可与前置是**两道独立门槛**）。
