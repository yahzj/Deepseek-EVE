# 事件日志重新分类（2026-09-26）

状态：**已实现 · 待船长验收**

## 船长原话（照抄）

1. 「**现在发送给事件日志的信息十分混乱，大量信息都放进了'信息'里，而且缺少'战斗'的分类**」
2. 「**对事件日志重新分类，你详细列出每一类要显示哪些来源的消息**」
3. 「**1，合并，2可以，3单独算。以及 事件日志上方的筛选，玩家点击哪一个筛选就只显示该筛选的内容。**」
   ⇒ ①「队列」并入「升级」 ② 战报从警告挪进战斗（可以） ③ 打捞**单独一类** ④ 筛选改**单选**

|---|---|---|

**核心问题**：「战斗」这条线被劈成 `info` + `warn` + `trade` 三半；而「信息」成了工业/航行/通讯/任务的混合兜底。

## 二、分流三条判定口径（新增）

1. **域优先**：一条消息先按"它属于哪条玩法线"归类，而不是按"它看起来重不重要"。
2. **战报一律归战斗**：胜 / 败 / 撤退 / 弃船 / 回合耗尽 —— 顺序与结果都在「战斗」里连成一条线。
3. **警告 = 跨域严重度**：只留「异常 / 需要玩家行动」的消息（组件不足、结构濒危、货仓放不下、作业停止、记录缺失），**不再承担"战败"这类域内信息**。
