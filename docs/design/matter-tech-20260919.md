## 三、机制口径

### 1. 货币与入口
- 花费 = **虫洞谜质 + 信用点**；**不耗时**（点即生效）。
- 谜质行价 **70,000 → 700,000**：`data/items.ts` 的 `baseSellPriceIsk`、`data/marketCatalog.ts` 行价；
  连带 = 结算单 `essenceIsk` 参考估值、`wormholeSalvage.ts` 注释、`wormhole-battle.test.ts` 的 `2×70_000` 断言、
  洞内经济读数（跑前后 A/B）。
- 入口：星图 · 出港 → **「扫描虫洞」页拆两个子页**：「虫洞探索」（现有内容：扫描进度 / 库存虫洞 / 返回虫洞）
  + 「谜质科技」（新树）。谜质科技子页 = 顶部资源条（谜质 / 信用点）+ 分层树（节点小卡：名 / 等级点 / 下一级费用），
  **固定尺寸不滚**；点节点开**二级窗**看详情与研究按钮（二次确认）。样式复刻同类卡片、SVG 线稿、`Tooltip.tsx`。

### 2. 打捞/采集「效率 → 额外堆」（新机制）
- 效率 = **Σ（每台打捞器/采集器的档位基础效率）＋ 对应科技加成**（吊臂 / 钻头 +20%/级）。
- 档位基础效率：**民用 0% · MK1 20% · MK2 40% · MK3 60% · 异星原型 80%**
  （⚠ 打捞器**只有 MK1/MK2/MK3** 三档 ⇒ 20/40/60；采集器五档齐全）。
- 每次动作：`额外堆 = floor(效率) + (掷中 frac(效率) ? 1 : 0)`，受"剩余堆数"限制；**回合仍 1/次动作**
  （`WORMHOLE_TURN_PER_WORK = 1` 不动）。
- ⚠ **效率 > 0 才掷骰** ⇒ 只带"民用采集器（0%）"且未点科技的编队**不消费随机数**（零行为变化）；
  MK1 以上或点了科技 ⇒ 开始额外捞（新行为，读数会变；随机数流会移动，如实报告）。
- 装置「打捞起重机 / 采集钻机（+1 台）」**保持原样**（与效率是两根轴）。

### 3. 回合（改口径）
- `WORMHOLE_TURN_BASE`：**100 → 80**（`WORMHOLE_TURN_MASS_COEF = 0.53` 不动）。
- 时序锚定器 = **永久**「最大回合数 +10/级」；与**本趟**的装置「时序核心 +10/台」**分开相加**：
  `回合预算 = floor(80 × (1 − 质量比 × 0.53)) + 10 × 锚定器等级 + 10 × 时序核心台数`。
- 连带实测（写读数）：4×T3 `53 → 42`、空载 `100 → 80`；满级锚定器 +100。

### 4. 扫描虫洞间隔
- 谐振信号滤波阵列 −5%/级、5 级（满级 −25%）；与现有链**乘算**
  （`wormholeScan.ts`：12 小时 × 三技能乘算 × 星际奇遇学）⇒ 满级再 ×0.75。

### 5. 洞内战斗倍速（**解挂**挂起卡 `battle-speed-20260919.md`）
- 时间压缩矩阵：**1 级 ×2 · 2 级 ×4**；**只作用于洞内战斗**。
- **只在前台心跳生效**（离线 / 后台结算一律 1×）。**演出照原速**（入场动画 / 击杀慢镜 / 波次转场），
  只把"**动画没结束不开火**"的保护窗口按倍速**等比放大**。
- 控件 = **战斗窗口顶部中间、距离条上方**（×1 / ×2 / ×4；默认只显示已解锁档）。
- 实现 = 给战斗一条独立倍速时间轴：`战斗目标时刻 = battle.startedAtGameMs + (state.gameMs − battle.startedAtGameMs) × 倍速`
  （1× 时逐字等价）；并把挂起卡列出的**三处混用真实墙钟**改成倍速口径
  （入场动画时刻 / 波次转场等待 `state.gameMs < battle.waveClearAt` / 提示条 `atMs` 的读取口径）。

### 6. 封顶
- 三线点满也远低于现有封顶（回避 +3% · 敌命中 −3% · 三层抗性各 +0.15 · 威胁 −9% vs 封顶 +0.25 / −0.25 / 0.9 / 0.5 倍）
