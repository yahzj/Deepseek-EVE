## 一、船长原话（照抄，逐轮）

> 初始每个任务数量提高到4，每个建成的空间站让任务数量+2。并且任务将划分级别，级别越高的任务收购的数量/所需的货仓容量越多。同样奖励也越高。快递的货采用和长途运输一样的虚拟货物，只有占用体积属性。快递任务有2种区分，普通快递和限时快递，限时快递对玩家舰船的跃迁速度有要求，通常以快运货舰为准，高级的限时快递基准线为快运货舰+跃迁计算器的标准。间隔改为30分钟一次，接取的快递任务不会被刷掉。资源任务的市场联动涨价（只有涨价部分）会在任务完成后移除。

> 任务刷新周期回滚到20分钟。限时快递的速度应该按照剑鱼的标准来。分为3个档位，分别是剑鱼，剑鱼+MK2，剑鱼+MK3,剑鱼+MK3*2。

> 需要确保L5限时快递玩家能够达到条件完成。且L1~L4任务至少要各出现。资源任务的奖励系数下调，L1~L5分别为1.1/1.15/1.2/1.25/1.3

## 二、落码口径

| 项 | 口径 | 落点 |
|---|---|---|
| 条数 | 资源/快递各 **4** 起，**每建成一座副站两类各 +2** | `SIDE_TASK_BASE_COUNT` / `SIDE_TASK_COUNT_PER_STATION` / `taskCountsFor` |
| 刷新周期 | **20 分钟**（回滚后维持现状，与市场补给同源） | `boardPeriodMs`（未改） |
| 级别 | **L1~L5**；量倍率 1 / 1.7 / 3 / 5 / 8；**L1~L4 每轮必各出现**，剩余席位按"越高越可能"权重掷（10/15/20/25/30） | `SIDE_TASK_LEVEL_SCALE` / `rollLevels` |
| 资源需量 | **玩家 1 小时产能 × 1 × 级别倍率**（船长 2026-09-18：「移除 0.25 倍率，改为 1 倍」⇒ L1 = 1 小时产量、L5 = 8 小时产量）——产能锚：矿石 6 线满产 18,000/小时；矿物 ×无门槛矿带最优精炼产率；NPC 直供品按池量 1% | `hourlySupplyOf` / `rollResourceNeed` / `RESOURCE_NEED_HOUR_FRACTION` |
| 资源奖励 | need × 刷出收购价 × **1.1 / 1.15 / 1.2 / 1.25 / 1.3**，仍**强制低于供应价**（红线未改） | `RESOURCE_TASK_LEVEL_MARGIN` / `resourceRewardIskFor` |
| 快递货物 | **虚拟货物**：不再绑商品、不扣仓库物品；出发时真实货物卸入仓库、按体积占舱，到站释放 | `volumeM3` / `startCourierDelivery` |
| 快递体积 | **非限时**按级别等比：**L1 1,000 ⇒ L5 20,000 m³**（1,000 / 2,100 / 4,500 / 9,500 / 20,000）；**限时 = 非限时的一半**（船长 2026-09-18：「L5非限时的快递体积提高到2万立方，L1提高到1000，其他等比上调，限时快递体积为非限时的一半」） | `COURIER_TASK_LEVEL_VOLUME` / `COURIER_TIMED_VOLUME_RATIO` / `courierVolumeFor(level, timed)` |
| 快递运费 | **与体积解耦**（船长：「在维持运费的前提下，提高占用的体积数」）：运费 = 级别基准（180,000 / 459,000 / 1,170,000 / 2,850,000 / 6,480,000 ISK）× 航程系数（**标称分钟 ÷ 10，下限 0.5、无上限**） | `COURIER_TASK_LEVEL_FREIGHT_ISK` / `courierRewardIskFor` |
| 限时快递 | **每单独立掷「普通 / 限时」（限时概率 50%）**；限时门槛 4 档（船长选丙）：**L2 6.20 · L3 7.44 · L4 8.37 · L5 10.92 AU/s**（L1 掷成限时时取最低档 6.20）；限时体积减半 | `COURIER_TIMED_CHANCE` / `COURIER_TIMED_WARP_REQ` / `courierWarpReqOf` |
| 时限 | = 该档基准配置跑完本段航程的时长 ×1.05 宽限（出发时锁定 `deadlineAtGameMs`） | `TIMED_COURIER_GRACE` |
| 超时 | **甲案**：无报酬、任务作废（日志写明） | `settleCourierDelivery` |
| 接单 | 快递可「接单」⇒ 进 `sideTasks.accepted`，**跨整板刷新保留**（上限 4 单）；出发不再受 20 分钟到期限制；可放弃 | `acceptCourierTask` / `abandonAcceptedCourierTask` |
| 市场联动 | 削供应比例 **0.45 → 0.25**；**同一商品每轮只被抽一次**；**资源任务完成时回退涨价部分**（shock −0.05，钳 ≥0） | `SPAWN_SUPPLY_CUT` / `SPAWN_SHOCK_STEP` / `refundSpawnShock` |
| 存档 | `SideTask` 新增可选字段（level / volumeM3 / timed / warpReqAus / timeLimitMs）＋ `sideTasks.accepted`；**空表不写键、老档零迁移**；清洗器同步放宽快递"必须有商品"的校验 | `state.ts` / `save.ts` |

## 三、L5 可达性（船长要求，已实测）

剑鱼级：低槽 3 · 中槽 2 · 高槽 2 · CPU 175 · 基础跃迁 6.20 AU/s；跃迁计算机 MK3 = 低槽件、CPU 40 ⇒
**两件占 2 槽 80 CPU** ⇒ 引擎实装读数 6.20 → 8.37（1 件）→ **10.92 AU/s（2 件）** = L5 门槛 ✓。
来源：MK3 模块市场行价 944 万/件、蓝图 2,832 万，且可自造（900 秒）。另：飞鱼级 + 2×MK3 = 13.03 AU/s 也能过 L5。
