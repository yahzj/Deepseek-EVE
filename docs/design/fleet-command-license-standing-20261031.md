## 授权与范围

船长原话：「多舰船编队后，敌我强度发生很明显的变化，我觉得几个编队相关的技能都要添加购买训练许可的声望前提，分别需要20/40/60声望，T4的编队协同指挥技能下调至T3」。许可定价询问后船长回复「按你推荐来」。

落实为基础T2：20累计协会声望、5万信用点；协同T3：40累计协会声望、20万信用点；统合T5：60累计协会声望、200万信用点。声望仅为购买门槛、不扣除。前置仍分别要求上一技能Lv3，每级容量5/7/8不变。

功能域为技能许可与训练，沿用现有`skills/license.ts`、许可账本和详情/列表按钮。不改战斗数值、舰船成本、编队上限或其他低阶技能许可规则。

## 实施边界

- 显式许可定价覆盖rank免许可规则，避免基础T2、协同T3无需购买便能训练。
- 购买命令与详情/列表共享声望预检；复用既有声望不足模板，不新增玩家可见句子或修改技能说明。
- 保留已购许可及已练技能的既有豁免，不追收、不删除等级、不清掉已在途队列。
- 协同降阶按现有训练公式减少工作量；不主动重写已有暂存工作量，不额外退款。
- 技能定义字段属于静态数据，不新增随档字段；现有许可保存与读档路径不变。
- 英文不新增翻译，界面复用既有中英文声望模板；新规则不写入说明正文，门槛按静态字段同源显示。

## 验证计划
