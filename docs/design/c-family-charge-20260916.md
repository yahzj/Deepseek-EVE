## 一、船长原话（照抄）

1. 「**C族全部添加冲锋，按照级别分别为1.5/2/2.5/3/4**」
2. 四问后确认（本会话）：**按"舰种档"读**，不是"五条舰级依次"——
   ⇒ **T1 1.5 · T2 2 · T3 2.5 · T4 3 · T5 4**；**噬口巨兽维持 3**（与 2026-09-14「大虫子的冲锋倍率改为 3」逐字一致）。
3. 「**孢群异虫速度削减到300**」——与 2026-09-11 族格裁定②「C 族速度比 A 海盗还快（同档实速须高于 A 族；
   倍率带 1.30~2.10）」**冲突**，按约定 §5.2 摆出冲突后船长选**甲案**：**开显式例外**，速度按 300。

**起因**（同日稍早）：船长问「孢群异虫是否有冲锋？」——查实**没有**（族内唯一不具冲锋资格的舰级），
引出第 1 条族格裁定；查证过程见 `combat.updateFoeCharge` 的 2026-09-16 注记与
`docs/test-saves/README.md`（同一批「洞内被 C 族贴上拉不开距离」报障的戊案结论）。

## 二、范围 / 不做

**做**：C 族五条舰级**一律具冲锋资格**；倍率**只由舰种档决定**（新增契约基准表 + 体检 + 用例）；
**孢群异虫速度 400 → 300**（新增「允许慢」白名单 + 体检契约例外 + 反查）。
**不做**：不动其余四条舰级的速度（`speedRatio` 与族格提速带一律不改）· 不动冲锋的**触发/解除口径**
（触发 = 够不着 或 距离 > 期望交距 + 1,000；解除 = 自身炮台命中我方 或 压到期望交距，冷却 10 秒）·
不动全局总开关 `foeChargeEnabled`（仍 false，只影响"老路"）· 不动其他四族 · 不动"C 比 A 快"这条族格本身
（只给孢群异虫**逐条例外**）。

## 四、影响面

- **洞内三卡**（冲锋期编队均速）：浅「星髓游猎群」597 → **796**；中「孢群兵潮」532 → **781**
  （孢群单人 750、成虫 796；基础均速 399 → **365**）；深「噬口深巢」~740 → **828**。
  ⇒ 浅/深两卡的贴脸压力明显上升，中层卡因母舰减速**基础速度下降**（它成了卡里最慢的一条，"母舰在后、成虫在前"）。
- **洞外悬赏线**：只有「星髓虫群」（末波 星髓成虫 ×3）受影响（冲锋 1.5→2）；噬口猎杀令 / 裂谷畸变体 /
  深渊之门卫队用 **T1 幼虫或 T4 巨兽 ⇒ 零变化**。孢群异虫只在洞内三卡出场（`anomalies.ts` 无引用）。
- **契约面**：C 族「敌速口径契约」新增**逐条例外 + 反查**（白名单里的舰必须确实低于族格要求，
  否则红）；新增「C 族冲锋契约」（全族具资格 + 倍率等于按档表）。
- **老路耦合解除**：改前"若把总开关打开，层 2 守卫以上的孢群异虫会被老路放行吃全局 ×3"这条隐患，
  现由**舰级显式 opt-in（2.5）**取代 ⇒ 开关开不开都按按档表走。
