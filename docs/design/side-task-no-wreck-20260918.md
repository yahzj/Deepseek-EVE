# 资源 / 快递任务排除残骸（2026-09-18 船长指令）

状态：**已实现 · 待船长实机验收**（验收后按 §8 归档：roadmap 一条 + 删本稿）
范围：时效任务板（`sideTasks.ts`）的候选池——**资源任务与快递任务都不再要求交付残骸**
不做：残骸的市场行与回收/拆解链路（照旧可卖、可入炉）；碎片 / 遗迹货柜 / 虚空母矿等其他物品

## 一、船长原话（照抄）

> 在资源和快递任务中，将所有残骸排除。

## 二、改了什么

- **落点（单点）**：`packages/core/src/sideTasks.ts` 的 `sideTaskCandidateGoods()`——资源任务与快递任务
  **共用这一个候选池**（`refreshBoard` 里两族都从它抽 2 条），所以在池口排除即可覆盖两族。
- **判据**：`ctx.items.get(def.refId)?.kind === 'wreck'`——**普通残骸与稀有残骸同属这一类**，
  走数据、不看 id 前缀（`wreck-*` / `wreck-rare-*` 都命中）。
- **位置**：放在"仓库已有该货即放行"那条快速路径**之前**——否则玩家仓库里躺着残骸时又会被放回候选池。
- **注释同步**：候选池尾部那句"弹药/修理组件/无人机/残骸/碎片等恒可刷"里的**残骸已删**，
  并写明本裁定与判据位置（防日后有人把残骸加回来）。

## 三、读数（真实数据 · 临时探针实测后已删）

- 市场目录 460 个商品，其中**残骸类 23 个**（`wreck-<悬赏卡 id>`，`poolTarget = 30,000`、**只收不卖**）。
- 改前：这 23 个都进候选池（残骸无矿带依赖 ⇒ 走"恒可刷"那条）。
- 改后：候选池 15 个、**残骸 0 个**；**把残骸塞进仓库再算，仍为 0**（快速路径已挡住）。
- 稀有残骸物品 37 个**本就没有市场行**（不进池）；判据同样覆盖它们（日后若加市场行也不会漏）。

## 四、为什么该排除（背景）

残骸**只收不卖**（`WRECK_BUY_GOODS.playerBuyable = false`）：资源任务/快递任务要求交付残骸时，
玩家**无法从市场买到**，只能靠打捞凑量（`need` 由 `poolTarget` 掷出，量级数百 m³）⇒ 任务容易变成死路。
本次按船长令把残骸整体移出这两族任务的候选池。
