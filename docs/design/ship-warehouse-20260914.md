# 舰船仓库（2026-09-14 · 状态：已确认）

> 船长原话（照抄，全部裁定来源）：
> 「**接下来实现舰船出售，建议先将舰队页面中的舰船市场换成舰船仓库，所有组装机生产的舰船都放进舰船仓库内，
> 并允许堆叠数量。舰船仓库内添加筛选：全部/已拥有/未拥有。以及和我的舰队页面相同的类别，级别筛选。
> 玩家可以从舰船仓库中将船转移到我的舰队内。而我的舰队内的无装配满耐久的舰船也可以转移到舰船仓库。
> 之后移除我的舰队内舰船的出售按钮。**」
> ＋（用途补充）「**舰船仓库是用于方便市场出售舰船的**」。
>
> 集中提问五问的裁定（均为船长选定）：**①范围 = 甲**（连出售一起做）· **②「已拥有/未拥有」= 乙**
> （只看仓库库存）· **③未拥有的船型行 = 甲**（仍全部列出、保留「去市场查看 / 下单」）·
> **④入仓边界 = 甲**（有自定义名先弹确认清名；已锁定拦入仓）· **⑤市场买入的船 = 甲**（一律进舰队，
> 只有组装机产出进仓库）。

## 一、存储模型

- 新存档字段 **`state.shipStore`**：`船型 id → 艘数`，**纯计数**。`CURRENT_STATE_VERSION` **不升**
  （可选字段、缺省空 ⇒ **零迁移**；`save.ts` 只收正整数，0/负数/小数/非数值丢弃或取整）。
- 仓里的船一律是**全新船**：满耐久（结构 ＋ 装甲都是 100%）· 无装配 · 货仓空 · 无自定义名。
  ⇒ 这四条同时是**入仓门槛**（见 §三），保证"堆叠"这件事有意义（同型每一艘都逐字段相同）。
- 读口径单点（`shipyard.ts`）：`shipStoredCount`（仓库数）· `shipOwnedCount`（仓库 ＋ 在役舰队）·
  `shipStorable`（入仓逐档拒因）。

## 二、产出与流向

| 来源 | 落点（2026-09-14 起） |
|---|---|
| **组装机**造出一艘舰船 | **舰船仓库 +1**（原先直接进机库；日志改为「已入舰船仓库（现有 N 艘）」） |
| **市场买入**（现货 / 挂单成交） | **仍在役舰队（机库）**——挂单成交可能是二手船（耐久 <1 或带自定义名），进不了计数仓库 |
| 洞内 / 打捞等其它来源 | 不变（进机库） |

⚠ 行为变化（题中之义）：造完的船**不会自动出现在舰队里** ⇒ 要驾驶或派 AI 必须先在舰船页「舰船仓库」
点「转入舰队」。AI 副船池只认在役舰队。

## 三、两个方向的门槛

**舰队 → 仓库（`storeShip`）**：非当前驾驶 · 无 AI 任务 · 非换驾驶善后返航中 · 未锁定 ·
不受进洞 / 自动探索锁（`shipLockedReason`）· 货仓空 · 无装配 · **满耐久**；
**有自定义名** ⇒ 引擎返回 `named: true`，界面弹确认「入仓将清除自定义名"X"」（可取消先去改名），
确认后带 `{ clearName: true }` 重发 ⇒ **名字不会被静默丢掉**。

**仓库 → 舰队（`unstoreShip`）**：仓里该型 ≥ 1 艘即**即时、免费**，`addShipToFleet` 生成全新实例
（新 uid、满耐久、无装配、无名）。**舰队不设上限**（维持现状）。

## 四、出售（仓库是出售入口）

- 界面：舰船页「舰船仓库」每行「**出售 1 艘**」→ 二次确认弹层（沿用原舰队「市价出售」确认块的样式）。
- 引擎单点 `sellStoredShipAtMarket(state, ctx, defId)`：扣仓 1 艘 → 挂限价卖单 → **立即撮合一轮**。
  1. **有人收购 ⇒ 即时成交**，`total` = 税后净入账（贸易税照收、挂单免费）；
  2. **无人收购 ⇒ 留在簿上**（限价卖单），**撤单退回舰船仓库**——托管记录
     `escrowShips[id].from = 'store'`（缺省 = `'fleet'`，老档零迁移）；
  3. 定价沿用原口径：当前收购价；无收购单时按均衡收购价 ×0.98。
- **「我的舰队」内的出售按钮整块退场**：舰船页不再有「市价出售」与其确认弹层，`sellBlockers` 预检、
  `engine.sellShipAt` 包装一并删除；core 的 `sellShipAtMarket` / `shipSellable` / `placeShipSellOrder`
  **保留**（有既有用例覆盖；老档 escrow 撤单要退回机库；后续可复用），注释注明"自本批起无界面入口"。

## 五、界面

- 舰船页第三档 **「舰船市场」→「舰船仓库」**（`ShipTab` 键 `'shop' → 'store'`，图标取物品仓库那只箱子）。
  购买入口不丢：买卖本就在市场页，行内保留「去市场查看 / 下单」。
- 列表 = **有市场行的船型**（沿用原舰船市场列表）＋ **仓库里已有的任何船型**（洞内定制船这类不上市场的
  船在仓里也看得见、能提取）。
- 搜索栏进标题行（计数「匹配 N / 共 M 型 · 仓内 K 艘」），工具条三维筛选（复刻「我的舰队」样式）：
  1. **拥有**：全部 / 已拥有 / 未拥有 —— 按船长裁定**只看仓库库存**（在役舰队有同型、仓库空 ⇒ 仍算"未拥有"；
     卡片上另有「舰队 ×M」参考读数，不是筛选判据）；
  2. **类别**（`SHIP_SUBS`）· 3. **级别**（`SHIP_TIER_SUBS`）—— 与「我的舰队」同一张单点表。
- 卡片：船名 + 子分类/角色徽标 + 稀有度 · 货舱/循环/动力 · 描述 · 底行「仓库 ×N」/「舰队 ×M」/
  现货价/声望锁 · 按钮「转入舰队」「出售 1 艘」「去市场查看 / 下单」（前两个在 N = 0 时置灰）。
- 「我的舰队」卡片：新增「**移入舰船仓库**」（不满足条件置灰，悬停写明 core 给的拒因）；
  「已锁定」提示与锁定按钮话术改为**防误移入仓库**（锁定语义随出售按钮退场而转向）。

## 六、连带同步

- 市场页舰船行「自己的库存」= **舰船仓库 ＋ 在役舰队**（悬停口径说明同步）；
  市场页对舰船的"不能卖"提示改指「舰船仓库」。
- ⚠ 老档：已托管的舰队船撤单仍退回机库（`from` 缺省）✓；`shipStore` 缺省 = 空仓 ✓。

## 八、已知取舍

1. 仓库是纯计数 ⇒ 二手船（耐久 <1）进不来；带名字的船要经确认清名（船长选定「甲」）。
2. 「已拥有」只看仓库（船长选定「乙」）——筛选语义是"仓库里有没有货"，空态与徽标文案据此写。
3. 出售为**系统按收购价估价**；"自己填价挂卖单"是后续可选扩展（市场详情页已有挂单面板可复用）。
4. 舰队无上限；仓库亦无上限。
