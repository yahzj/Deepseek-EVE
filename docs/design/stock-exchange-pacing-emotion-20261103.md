## 结论先行

1. **现在的设计踩中两个反面教材**：1 秒刷新 + 高杠杆 = 书里的「持续高压 → 感官麻木 → 疲劳退出」；纯挂机长线 = 「扁平挂机 → 三分钟困意」。要波浪，但**不靠限制玩家**造波浪——市场不关门，用事件密度与可配置提醒帮玩家自己形成张弛。
2. **市场不设限制，节奏由玩家自选**（船长 2026-11-03 裁定：「允许玩家联机，也允许玩家张弛，自己选。没必要做限制，可以做提醒」）。市场保持 **7×24 连续开盘**；系统只提供**可配置的提醒与软引导**（盯盘时长、隔夜风险、强平预警、自设每日亏损上限），不强制休市、不锁功能、不限制交易时段。张弛由玩家用条件单/止盈止损/量化机器人自己外包。
3. **失败必须比胜利设计得更认真**：死前征兆、Near Miss（差一点就活下来）、归因复盘、极速重试、复仇清单。爆仓不是终点，是下一波的蓄力。
4. **赌博感来自「自愿承担风险」，不是「被动不可抗力」**：黑天鹅之前必须给信号（盘口异动/内幕电报/大单踪迹），否则玩家只会觉得被系统骗。
5. **打击感要分级**：成交/盈利用轻反馈，强平/穿仓/逼空用重反馈（Hitstop + Trauma 震屏 + 数字弹跳），并且严格限频——**警报疲劳是赌博前端的头号杀手**。

## 一、诊断：为什么现在的设计不好玩

| 书里的错误模式 | 我们当前设计 | 后果 |
|---|---|---|
| 持续高压（A 型） | 1 秒 tick 无休、50x 杠杆随时可开 | 玩家神经紧绷 → 烦躁 → 关掉；且 50x 在 8% 日波动下平均 15 分钟爆仓（前期仿真结论） |
| 扁平挂机（B 型） | 长线只靠分红/缓慢持有 | 打开像看任务管理器，三分钟困意 |
| 失败无归因 | 爆仓只显示「已强平」 | 玩家不知道错在哪，只觉得被系统收割 |
| 附件节奏断裂 | 结算/动画不可跳过、切页卡顿 | 心流 3 秒内腰斩 |
| 无差别刺激 | 所有事件都弹红闪 | 警报疲劳，真警告被无视 |

**结论**：我们之前设计了「机制」（撮合/杠杆/事件），但没设计「情绪曲线」。这份稿子补的就是情绪工程。

## 二、节奏由玩家自选：市场不关门，只给提醒

### 2.1 市场：7×24 连续（船长 2026-11-03 裁定）

- 撮合与行情按真实墙钟**连续运行**，不设开收盘、不设休市、不锁交易时段、不限制杠杆可用时间。
- 1 秒 tick 常态；「盯盘 / 挂机」只是玩家的观看与通知偏好，**不是功能开关**（同一界面、同一套功能，符合「不要区别界面」）。
- 不再有「隔夜跳空」概念——市场连续，价格本来就一直在动；离线风险交给「离线保护」开关与提醒。

### 2.2 张弛靠玩家自选，系统只做「可配置提醒」

| 提醒 | 触发条件（初值） | 玩家可配置 |
|---|---|---|
| 盯盘时长提醒 | 连续停留交易所页且有操作累计 45 / 90 分钟 | 可关、可改阈值 |
| 高频操作提醒 | 10 分钟内下单 > 60 次 | 可关 |
| 高杠杆提示 | 下单杠杆 ≥ 10x（≥20x 二次确认） | 不可关（风险告知底线） |
| 离线持仓提示 | 开启离线保护时提示当前仓位风险 | 保护档位可配 |
| 强平预警 | 距强平 30% / 15% / 5% 三级 | 阈值可调 |
| 自设每日亏损上限 | 玩家自己填 | 触及后**只提醒、不强制**；「自我冷静锁」由玩家自己选择开启 |
| 事件订阅 | 财经快讯 / 板块异动 | 可全部关闭 |

- **红线**：禁止以「为你好」为由关闭市场、限制时段、锁住功能。系统只提供信息与提醒，决策权在玩家。
- 「持续高潮」不靠关门解决，靠**默认值、风险告知、失败体验设计**解决（见第四、五节）。

### 2.3 情绪波浪：由事件自然形成，不由系统强制

- 事件仍用泊松间隔（15~45 分钟）制造自然波峰；玩家可订阅/静音。
- 事件调度器保留软约束：同一标的连续事件不超过 2 波，避免疲劳——这是**事件节流**，不是市场关门。
- 宏观节拍保留（日分红、周财报、赛季排行），给长线玩家沉淀感。

## 三、情绪波浪发生器（每个完整波浪 20~40 分钟）

```
蓄压(10-15m) ──▶ 爆发(3-5m) ──▶ 释怀(3-5m) ──▶ 沉淀(10-15m) ──▶ 下一波
```

| 阶段 | 可观测信号（给玩家的「前兆」） | 系统动作 |
|---|---|---|
| 蓄压 | 盘口变薄、大单踪迹、内幕电报、波动率抬升、新闻预告 | 事件进入「酝酿」状态，AI 机构开始建仓 |
| 爆发 | 事件落地、价格突破、强平连锁、全服播报 | 波动率 ×2~3、封顶熔断、逼空阶段机启动 |
| 释怀 | 事件结束、盈亏入账、战报生成 | 结算动画（可跳过）、收益入账音效 |
| 沉淀 | 复盘面板、持仓整理、下注计划 | 安静期、条件单/量化布置 |

- **事件间隔用泊松分布（15~45 分钟）**，不要固定周期——书里明确说固定周期会被玩家摸清节奏而失去惊喜。
- **事件节流**（不是市场关门）：同一标的连续事件不超过 2 波；整体事件密度玩家可静音——「连续高潮等于没有高潮」要靠事件调度解决，不靠强制休市。

## 四、失败的艺术（对赌博系统最关键的一节）

| 设计点 | 具体做法 |
|---|---|
| **死前征兆** | 距强平 30% / 15% / 5% 三级预警，配递进音效与持仓行描边；**禁止无预警秒爆** |
| **Near Miss** | 爆仓后显示「你差 0.8% 就活下来了」；强平前 3 秒给「决断窗口」：追加保证金 or 主动认赔（画面上只留这两个按钮） |
| **归因复盘** | 战报明确写致命原因：「20x 杠杆 + 事件冲击 −3.2% + 滑点 0.4%」，并给一条可执行建议 |
| **极速重试** | 「按上次仓位重开」≤5 秒；首笔复仇单免手续费（复仇券） |
| **蔡格尼克效应** | 爆仓记录进「复仇清单」，下次登录首页可见，制造未完成情结 |
| **失败合理性红线** | 任何「跳空/插针」必须可归因到可观测事件；不允许系统暗改价格收割 |

> 吉泽秀雄：**「游戏失败的瞬间，是玩家距离放弃游戏最近的时刻。」** 赌博系统尤其如此——爆仓体验设计得不好，玩家不是再试一次，而是卸载。

## 五、打击感与反馈分级（《236 技巧》工程参数映射）

| 事件 | 反馈 | 参数（初值） |
|---|---|---|
| 下单/撤单成功 | 按钮微缩放 + 轻音效 | 1.0→0.95→1.0，80ms 回弹 |
| 成交（普通） | 数字弹跳 + 音效 | 1.0→1.3→1.1，150ms；**150ms 合并窗口**防数字雪崩 |
| 大额成交 / 逼空 / 里程碑 | Hitstop + 白闪 | 停顿 60~120ms，白闪 2 帧 |
| 强平（普通） | 持仓行红闪 + 低频音 | 不震屏 |
| 强平（穿仓/大额） | Trauma 震屏 + 红黑暗角脉冲 | `Trauma²` 衰减，Decay 1.2/s，上限 0.6 |
| 收盘结算 | 级联面板（普通→稀有→成就） | 可长按 0.5s 跳过 |
| 预警 | 分级（黄/橙/红），禁止全屏闪烁 | 只有「红色临界」允许屏幕边缘脉冲 |

- **输入缓冲**：玩家在动画/结算期间的操作，保留 150ms 预输入队列，不吞键。
- **数字合并**：同一标的 150ms 内的连续成交合并成一个跃动数字，避免刷屏。

## 六、控制感与风险设计（Schell 透镜 47/51）

- **主动风险**：杠杆档、止损、事件下注、持仓过夜，全部是玩家显式选择；不做自动加杠杆。
- **被动不可抗力红线**：黑天鹅必须有前兆信号；没有信号的暴跌只能来自玩家自己的持仓决策。
- **有意义的选择**：不存在绝对最优策略——不同标的波动率/流动性/杠杆上限/事件敏感度形成真实取舍。
- **控制感**：强平前决断窗口、可随时撤单、可设止损、可一键降杠杆（离线保护）。
- **间接控制**：用快讯、盘口异动、大单踪迹引导注意力，而不是弹窗逼玩家看。

## 七、兴趣曲线钩子（前 30 秒 → 7 日）

| 时点 | 钩子 | 目的 |
|---|---|---|
| 前 30 秒 | 行情跳动 + 一键小额试单（首单免手续费） | 立刻体验到「我在交易」 |
| 前 5 分钟 | 第一次明显盈亏（约 ±20% 保证金） | 情绪峰值 |
| 前 1 小时 | 第一次事件行情 + 第一个量化机器人上岗 | 建立「能挂机」的预期 |
| 首日 | 第一次收盘结算仪式 + 第一次分红 | 仪式感与归属 |
| 7 日 | 第一次逼空周期 + 第一次股东身份 | 长期目标 |

## 八、附件节奏与 UI 约束

- 所有交互反馈 <100ms；结算/动画**必须可跳过**（点击任意处或长按 0.5s）。
- 快讯走马灯**不常驻滚动**，按事件节奏弹出；玩家可切「整备视图」（暗色 + 慢 BGM + 复盘面板）——这是视图选择，不是强制。
- 货币/涨跌颜色必须符合直觉映射（红涨绿跌或可配置），颜色只走 gain/loss 主题单点。
- 市场连续运行、没有开收盘；但每日结算/分红必须有明确的视觉与音效提示，避免玩家漏看。

---

## 九、情绪安全阀（伦理与留存）

- 连续在线 N 小时给一次「休息提醒」（不强制退出）。
- 玩家可自设「每日最大亏损」：触及后**只提醒并建议停手**；「自我冷静锁」是可选开关，由玩家自愿开启（开了才强制）。
- **不做欺骗性设计**：不伪造成交、不暗改价格、不制造虚假稀缺；所有概率与费率明示。
- 赌博感来自「自愿的高风险」，不是「被系统算计」。

## 十一、对既有设计的改动清单（待批准后实现）

### 后端（whale-server 独立仓库）

- **不新增 market session 状态机**：撮合按真实墙钟 7×24 连续运行（维持 D7），股市不设开收盘、不锁时段。
- 事件调度器：泊松间隔（15~45 分钟）+ 同标的连续事件 ≤2 波的节流。
- 强平预警分级事件推送（WS 新消息类型）。
- 复盘数据：每笔强平记录归因字段（杠杆/事件/滑点）。
- 通知订阅：玩家可配置事件推送开关；静音即服务端不推。

### 前端

- **提醒中心**：盯盘时长 / 高频操作 / 强平预警 / 每日亏损自设，全部可配置、可关闭（高杠杆风险告知除外）。
- 每日结算与分红的仪式化面板（可跳过）。
- 反馈分级与数字合并（按第五节参数）。
- 复仇清单、复盘战报。
- 「整备视图」可选（暗色/慢节奏/复盘），是视图偏好，不是强制模式。

### 需要船长裁定的取舍

1. **复仇券 / 首单保护**：给不给？会不会太「手游化」？
2. **提醒密度**：盯盘提醒 45 分钟起，会不会太烦？
3. **每日亏损上限**：默认只提醒；「自我冷静锁」是否作为可选开关提供？
4. **事件节流**：同标的连续事件 ≤2 波，是否合适？

## 十二、怎么验证「好玩」

1. **情绪曲线摸底**：用原型连续玩 30 分钟，每分钟给自己情绪打 1~5 分，看是「波浪」还是「单调衰减」。
2. **爆仓体验测试**：故意 20x 爆仓 3 次，检查是否想立刻重开（Near Miss 是否生效），还是想关游戏。
3. **提醒干扰度**：连续玩 60 分钟，统计提醒弹了几次、烦不烦；提醒必须像「副驾提示」，不能像「家长说教」。
4. **自选强度验证**：同一天分别用「短线梭哈」和「挂机托管」两种强度各玩 15 分钟，确认两种模式都能获得正反馈，而不是逼玩家二选一。
5. **A/B 参数**：事件间隔 15 vs 45 分钟、强平预警阈值 15% vs 30%，各玩 10 分钟对比。
