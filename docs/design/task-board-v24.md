## 定位
任务中心（出港页）除「重要任务」外的一类**随机板任务**：每 20 分钟与市场常驻补给同源整板刷新
2 条，寿命 = 整轮，过期不补。分两类：

| | 资源任务 | 快递任务 |
|---|---|---|
| 语义 | 协会限时收购（仓库交付即结） | 向已建成副站定向投送 |
| 解锁 | 随板（候选池门槛见下） | 任一副空间站**建成**后 |
| 交付 | 仓库足量点「完成」，扣货入账下板 | 「出发投送」：仓库锁货 → 航程计时 → 到站自动结算 |
| 报酬 | 刷出时收购价 × `RESOURCE_TASK_MARGIN`(1.04) 整百，**强制 < 需量×供应价** | 收购价 × `COURIER_TASK_MARGIN`(1.30)（运费补贴型），同样市价买入必亏 |
| 货仓 | 只认仓库（不认船上货仓） | 出发即从仓库锁定扣出（在途挂账 deliver，整板刷新不清） |

## 关键机制（口径，均已拍板）
- **刷新**：与市场 `orderLifeMs.common`（20 分钟）同源；离线大步长只在末窗结算一次，防 480 次冲击；
- **候选池门槛**：矿石/气/冰 = 任一产出矿带星系已探索；矿物反查精炼源；NPC 直供品恒刷；仓库已见恒放行；
- **防套利**：need = 池量比例取整；报酬锚定刷出时价且强制低于供应价——市价买入交付必亏；
- **市场联动**：刷出时 npcSell 减 30% 尾扣 + pool.q 同扣 + shock+0.05（≤0.4）制造涨价，防买来秒交；
- **快递投送**：目标 = 刷出时绑定的已建成副站（stationId/galaxyId 兼容字段，无版本号）；出发后
  按「当前位置 → 目标站」真实航程 `arriveAtGameMs` 到站自动结算（停靠目标站、入账、下板、清挂账）；
  在途互斥（采矿/远征/扫描/打捞/掩护巡逻/换港返航拒发）；途中不可取消、召回即达（无在途残留）；
- **快递机制复核（2026-09-08 船长拍板：保持现状）**：船长问"移动不耗时后快递是否不合理"——口径：
  免费的是**去程就位**（掩护巡逻/换港返航/任务出击即时）；返程类移动仍计时（自动返航/失利返航/
  巡回讨伐返程 = 2×单程，采矿打捞满仓返航亦然）。快递 = 唯一「定向跨站直达」的航程动作，
  等待期互斥与"船在跑"一致；报酬 ×1.30 保留。**不改代码**，仅登记本口径。
