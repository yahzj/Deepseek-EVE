## 一、现状与本次要修的硬伤

**取形链路（改前）**：`ShipSprite.tsx:95`

```
shipId ? SHIP_ART[shipId] : foeKey ? FOE_ART[foeKey] : undefined
```

两个问题：

1. **敌舰一带 shipId，族形分支就永远走不到**——三元表达式把两条路互斥了，`foeKey` 形同虚设。
   （与本批"入侵窗口不见了"同源：都被一条不显眼的短路掩盖。）
2. **敌舰取形只到族**：`FOE_ART` 的键是族字母 `A~H`——A 族 5 条卡画的是同一张图，
   C 族 5 条（幼虫/成虫/孢群/噬口）也都一样。族内无差异 ⇒ 船长要的"按敌舰不同做出区分"没有承载点。

**取形链路（改后）**：由**逐舰**到**逐族**三级回退，任一级命中即用，都不命中才落 role 剪影。

```
① FOE_SHIP_ART[shipId]   ← 本次新增的 30 张逐舰形（本批主体）
② FOE_ART[foeKey]        ← 族形，保留为兜底（旧内容表/异常档/未录形）
③ role 线描剪影（140×64，仓库既有回退，不动）
```

`SHIP_ART[shipId]`（玩家舰 25 艘）优先级不变，仍在敌舰逐舰形之前判。

**挂点同理**：`shipMounts.mountsOf()` 改前只查 `SHIP_MOUNTS[shipId]` → `FOE_MOUNTS[族字母]`；
敌舰有 shipId 就查不到逐舰挂点 ⇒ 尾焰/炮口位置只能吃族级值（或落 undefined 回退旧单焰）。
本批新增 `FOE_SHIP_MOUNTS`（逐舰），插在族级之前。

## 二、画布口径（与既有敌舰资产一致，不新立口径）

| 项 | 口径 |
| --- | --- |
| 画布 | `240 × 110`，viewBox `0 0 240 110` |
| 朝向 | 舰艏朝**右**；翻转由渲染层整体镜像（`ShipSprite` 的 `scaleX(-1)`） |
| 船体纵带 | 落在 `y36 ~ y96` 内（与 A/B/D/E/G 既有形同带）；高耸件（塔/桅）允许上探，**塔尖留 4px** |
| 主轮廓 | 无类元素，继承 `currentColor`，线宽由渲染层的 `strokeWidth=2.2` 给 |
| 面板线 | `.shipart-panel`（虚线/细线，浊色） |
| 族色点缀 | `.shipart-acc`（描边）/ `.shipart-accf`（实心点）；色值走 `ui/tones.ts` 随主题 |
| 发光件 | `.shipart-volt-g` / `.shipart-volt-i`（资产内固定族色，不随主题）；本批只用于尾焰口/机库门 |
| 尾焰 | 渲染层按 `engines` 挂点自动画（口沿左缘中点），**资产内不画焰** |

### 4.1 写形时必须守的三条（踩过的坑，写在这里省得下一个人再踩）

| 坑 | 症状 | 口径 |
| --- | --- | --- |
| **船体画成细横条** | 全族 5 条一眼是"压扁的胶囊/横条"，没有舰体 | 船体纵带务必 `y36~96`（高 ≥ 50），别只在舰桥高度画一条窄带 |
| **内部横竖线画成网格** | 船体读成"格子铁笼"而不是船 | 别在一条 path 里交叉画纵横面板线；改成**分区块**（各块自带闭合轮廓）或只画纵向舱壁 |
| **异形族出现直角** | C 族读成机械舰，与"生物体"设定相抵 | C 族轮廓一律走 Q 曲线 + `pod()` 胶囊；不用直边多边形 |
