## 一、船长原话（照抄）

1. 「**⑤ D 族移动到武装舰，吃武装舰技能**」
2. 「**先完成D族转移，然后一并按照如下调整：武装舰T1~T5获得单发伤害加成，分别是15/20/25/35/50.
   允许出现上下浮动。如果是无人机船，则改为同等数值的无人机伤害加成。移除每条船的50动能抗性
   （如果某条船没有这条属性就告诉我）／装甲舰T~T5获得装甲的动能和能量抗性加成，分别为
   30/30/35/35/35。移除之前获得的单发伤害加成。（这里所有的移除都不会影响舰船子类型和种族给予的
   额外属性。）完成后，将每条船的加成和全部抗性列出给我审查**」
3. （前序，④）「**抗性也进行调整，不要单纯互换（不用护盾了，所以不要给护盾任何抗性，只给装甲抗性）**」
   ＋ 追问后选**甲案**：E 三艘的**壳层等离子抗 0.25 保留**。

## 四、实现判读（**列明供审查，若与你的意思不同说一声我改**）

1. **「高槽 ≥ 低槽 + 1」契约收窄为官方船**：D 族三艘的槽位是 2026-09-13 按**子分类**定的
   （电子舰 2/3/3 · 指挥舰 2/4/4 · 陵寝 4/4/4），要满足那条弱断言就得推翻那套设计 ⇒ 收窄为官方船，
   三艘的实际布局改用例逐一钉住。**若你要的是"改槽位"（甲案），说一声我按 8/10/12 总数重排。**
2. **「无人机船」= 梭鱼级无人机护卫 + 王鲭级无人机母舰**（主力输出是机群的两艘）。其余带
   `droneDmgBonus` 的船（鹦鹉螺 +10% · 幽影 +6% · 亡军后勤 +10% · 亡军鱼雷 +14% · 陵卫指挥 +8%）
   是**子分类给的**，按你「不影响子类型给予的属性」保留，同时按新口径拿 `powerBonus`。
3. **装甲舰原有的甲层高爆 0.5 保留**（甲壳线 / C 族），叠在新的动能/能量 30~35% 之上 ⇒
   甲壳线现在是"甲层三系都抗"。**若你要的是"甲层只留动能+能量"，说一声我删掉高爆那一条。**
4. **D 族原有抗性全保留**（盾/甲/壳 0.25 + 甲层高爆 0.5）：它们不是"50 动能抗"，也不属装甲舰移除范围。
5. **装机加成被吞掉的两处**（旧值写在 `powerBonus` 里，本轮被阶梯值/移除覆盖）：
   **构件鱼雷舰** 2026-09-14「鱼雷舰强化 +25 点」（0.50 ⇒ 0）· **亡军鱼雷舰** 同日「+20 点」（0.82 ⇒ 0.25）。
   要保留这两笔强化的话，得给它们单列一条字段或按浮动上抬。
6. **本轮未用"上下浮动"**：全部取阶梯精确值（你要的是先审查）。要把某些船浮回（如巨齿鲨 / 邓氏鱼 /
   亡军鱼雷舰这类原先高加成的），给个方向我按 ±5% 内调。
