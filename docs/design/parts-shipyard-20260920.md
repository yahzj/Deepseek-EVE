### 九·一 追加裁定 4（2026-09-20 船长：「只动筛选的选项，不动其他卡片」）

- **卡片侧一行未动**：组装机卡列表仍由 `items`（静态蓝图目录）经「搜索 × 学会 × 门类 × 子类 × 图纸」过滤，本轮只把门类判定提成 `inTab()` 的**等价重写**；
  市场 `filteredAll`、造船厂 `visible`、精炼炉网格、仓库列表**均未改动**。实测（探针 `tools/_filter-check.ts`，用后即删）：
  组装机共 **149** 张卡 —— 装备 124 · **零件 14（基础 7 张"无需图纸"卡 + 高级 7 张，全部在列）** · 消耗品 11；市场 9 个类型里**被隐藏的档一律是商品数为 0 的档**（高槽 55 条商品 ⇒ 只隐「护盾/装甲/推进器/协处理器」；蓝图 198 条 ⇒ 一档不隐，含「零件蓝图」7 条）。
- **补一处会被误读的措辞**：组装机的「图纸」行在"只剩全部"时才整行隐藏——而任何一张卡非一次性即永久 ⇒
  只要选了子类且该子类有卡，两个档必有一个命中、该行**实际恒显**；零件门类下消失的只有**「一次性蓝图」这一个档**（船长点名的那条）。
- **顺带补上"选中的档消失 ⇒ 回落全部"**（与蓝图书架 2026-09-19 同口径，避免出现**看不见的筛选**把卡片全清空）：

## 十、追加裁定 6（2026-09-20 船长：提高专属的零件占比）

船长原话：「**调整专属舰船和装备使用零件的比例，需要提高。**」→ 集中提问后的四答 + 两条自定义口径：

| 问题 | 裁定 |
|---|---|
| 口径 | **材料价值占比** |
| 目标 | 专属**提高到 75% 的零件价值占比**（允许删除部分原材料） |
| 总价 | **等值替换**（配方总价分文不变） |
| 构成 | **基础件打底 + 高级件点睛** |
| 范围 | 「非专属的不需要使用高级零件。**将 T4 的舰船也纳入调整范围内**」；「**专属装备和舰船需要使用约 30% 价值的稀有零件**」；追问后补：**皇带鱼也提（只用基础件）**；「**按本场出发快照补**」式的口径问法在此为「按价值占比」 |
| 「稀有零件」= | 现有的 **7 种高级零件**（不新开档、不改稀有度） |
| 30% 的分母 | **占配方材料总价值**的 30%（⇒ 基础件 45%、矿物 25%） |
