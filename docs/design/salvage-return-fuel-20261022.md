## 复现与根因

- `advanceSalvageOp` 的满仓自动返航已调用 `beginJumpFuelLeg` 并把倍率存入 `salvaging.fuelMul`，引擎计时使用倍率；但 `activity.ts` 的打捞活动栏返航进度和剩余时间没有传倍率，显示慢十倍。
- 星图页 `MapPage.tsx` 的 `salvageProgressOf` 也直接使用未缩放的满载航程，遗漏货仓占比及燃料倍率；此处为源码核查，不冒称界面手操验收。
- 手动停止走 `armReturnLeg`，切舰/切活动走 `retireSalvageShip`；这些独立返航账本按未加速时长计时，且不扣燃料。
- 已点火返航途中停止会重置进度并丢失倍率，换船则保留已走毫秒但丢失倍率。
- 打捞自动循环卸货后原倍率字段可能残留，若直接拿它判断新一趟是否点火会误把下一趟当成已点火。
