# 射程确认原因与距离滑条

> 状态：已确认，已实现，待船长验收（二号 · d2/workspace · 2026-10-23）
> 船长原话：「之前做的‘重复出击’中，‘再次入场时射程增加或缩短，都会先要求确认’弹出的窗口只要求玩家填写期望距离，并未告知为什么会有这个弹窗，需要用红字提醒玩家，出击舰船/舰队与上次舰队不符合，包括射程变动，只写了一个射程太过含糊，并且给玩家一个战斗同款的横向滑动条让玩家快速选择距离。」「同射程但换了出击舰船，不要弹确认」「确认」

## 已确认设计

- 战斗确认仍然只由同一卡的最大射程相对上次变化触发；舰队变化单独发生时不弹窗。
- 按卡保存最近一次成功参战的舰船 ID 名单。名单变化只用于解释射程变化；比较舰船名单、不比较编队顺序，不把换装本身纳入舰队差异。
- 射程变化时红字分别说明可确认的差异：有旧名单且名单变化时说明本次参战舰队不同；同时显示最大射程旧值与新值。旧存档无名单时不猜测舰队差异。
- 期望距离保留数字输入，并增加与战斗画面同方向的水平滑条：左侧为远端，右侧为贴近；两种输入实时同步，范围为本次战斗的最小距离至允许上限。
- 不改战斗距离计算、射程确认触发规则、其他战斗流程与存档版本；不推送。

## 范围与参照

- 功能域：战斗（core 与桌面界面）。核心参照 `battleRangeMemory.ts` 现有按卡快照、清洗和待确认事务；界面参照 `BattleScreen.tsx` 的 `.app-bts-*` 距离轴和现有模态框。
- 同射程换舰仍直接入场并更新该卡最近成功参战舰船名单；后续射程变化以这份最近名单作提示比较。
- UI 指南已检索 UX Focus States：模态框内控件保留可见键盘焦点。颜色外仍以明确文本区分差异。
