## 2. 查证结论（一号 · 一次性探针（`tools/_probe-bugs-*.mts`，落地后已按纪律删除）实测）

| 报障 | 查证结果 |
|---|---|
| 入侵战期望距离不保存 | **普通遭遇战（入侵伏击）里 `setBattleDesire` 被直接拒**（`core.expedition.001`「当前不在交火中」）——因为宿主判据只认**旗舰战**；旗舰战与远征两条路本来通（`desire-memory-20260928` 用例钉着）。**另**：拖距离条**不落盘**（2026-09-13 性能修，全靠 60 秒自动存盘）⇒ 拖完立刻关游戏就丢 |
| 自动续用不是开关 | 行为上确是开关（点一下开/关），但**观感**是普通小按钮（`.app-btn is-small` ＋ `is-on`），全仓无现成「开关」控件（无 `role="switch"`） |
| 开启即烧一枚、无视剩余 | **属实**：续用触发时把窗口**重置**为完整 24 小时（`skillBoostUntilMs = gameMs + MS`）⇒ 剩余时间被丢掉（探针 ③：剩 2 分钟 → 补后 24 小时） |
| 离线不续用 | **core 复现不出**：离线 8 小时实测补用（库存 3→2、汇总句「自动续用突触加速剂 ×1」），读档后离线同样补用；本批按「累加」修完再复测一次并把结论写回本文件 |

## 3. 本批改动（船长已批口径）

**A. 期望距离（远征/战斗域）**
1. `packages/core/src/expedition.ts` · `setBattleDesire`：宿主判据由「只认旗舰战」放宽为「**遭遇槽里任意正在打的遭遇战**」⇒ 普通入侵伏击里拖距离条不再被拒；偏好仍写**本场所在星系**（`enc.galaxyId`）。
2. `apps/desktop/src/renderer/src/game/engine.ts` ＋ `panels/BattleScreen.tsx`：**松手/战术按钮那一次提交落盘**（拖动中的节流提交仍不落盘，保性能）⇒ 拖完立刻关游戏不再丢。

**B. 技能加速自动续用（工业/技能域）**
3. `packages/core/src/consumables.ts` · `syncBoostRenew`：补的那一枚**累加**在剩余之上（`max(now, 现有到期) + 24h`），不再丢掉剩余时间；「剩余不足以练完当前这一级才补」的无缝判据不变。
4. `apps/desktop/src/renderer/src/pages/SkillsTreePage.tsx` ＋ `packages/data/src/l10n/table.ts`：按钮文案随状态显示「自动续用：开／关」（新增 `ui.boost.010` / `ui.boost.011` 两条 id · zh＋en），沿用同族 `.app-btn`＋`is-on`，不新造控件。

## 4. 不做

- 不给普通遭遇战新做战斗画面（现状：伏击战由引擎后台推演）——本轮只让「能写就写、能记住就记住」。
