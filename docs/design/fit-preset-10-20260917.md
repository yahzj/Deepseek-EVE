## 一、船长原话（照抄）

> 「**舰船的装配方案数量上限拓展到10套，并且允许玩家查看装备方案内用了哪些装备。**」

两问两答（船长 2026-09-17 定案，全取甲）：

| 问 | 裁定 |
|---|---|
| 明细的形态 | **甲：行内展开**——每行多一个「明细」按钮，点开在本行下方展开、再点收起 |
| 明细的粒度 | **甲：逐位列（含空位）＋ 无人机**——「高 1 件名 · 高 2 空 …」＋「无人机 型号 ×N」 |

## 二、现状（读码取证）

- 上限单点 = `packages/core/src/fitPresets.ts` 的 **`FIT_PRESET_MAX = 3`**；`save.ts` 规范化按它**截断**；
  `saveFitPreset` 满套且无同名时拒绝（错误文案带套数）。
- 每行只显示**摘要**：`fitPresetBrief` =「装备 8 件（高 4 / 中 2 / 低 2）· 无人机 2 型 5 架」——
  **看不出装了哪几件**。
- 方案按**船型**（`defId`）归口；存三类槽位逐位件 id ＋ 无人机舱装载；**不含弹药档**。
- 界面 = 装配页「装配目标」栏右侧按钮（`N/3`）＋ 方案浮层（套用 / 重命名 / 删除）。

## 三、口径（本次落码）

1. **上限 3 → 10**：只动单点常量 `FIT_PRESET_MAX`（`save.ts` 截断、`saveFitPreset` 拒绝文案、界面 `N/M` 与
   tooltip 全部读它 ⇒ 不会漂）；**同名覆盖**照旧（满 10 套仍可覆盖同名，不必先删）。
2. **明细单点**：新增 `fitPresetDetailOf(preset, ctx, ship)`（core）⇒ 返回
   - `slots`：**按目标船槽位布局铺满**（高/中/低 逐位，**1 起**位次），空位 `id: null` / `name: '空'`；
   - `drones`：「机型 × 架」（未知机型标 `missing`）；
   - `overflow`：**超出本船槽位的方案位数**（套用时按 `Math.min` 忽略 ⇒ 如实报出）。
   **未知 / 已下架的件不隐藏**（`name` 回落成 id ＋ `missing: true`）——与套用时「逐条报未装」同一口径。
3. **界面**：方案行新增「明细 / 收起」按钮（行内展开，不看就不占空间）；明细块按 高 / 中 / 低 / 无人机 四行渲染，
   空位淡显、未知件染色提示；件名一律来自 core 单点（界面不自己拼）。
4. **浮层可滚**：`.app-fit-preset-list` 加 `max-height: 46vh; overflow-y: auto`（10 套 ＋ 展开明细会很高；
   二级浮层可滚，§6「一级页不滚」只约束导航直系页）。
5. **零迁移**：上限只放大 ⇒ 老档（≤3 套）逐字不变；`save.ts` 结构清洗规则不变（条数上限跟着常量走）。

## 四、不做 / 边界

- 不改「按船型归口」「先卸光再装」「尽力装 + 逐条提示」「方案不含弹药档」这些既有口径；
- 明细**只读**：不在明细里改件/换件（要改就套用后再改，或覆盖保存）；
- 不给明细加"每件悬停看效果"（船长两问里未选丙案）——需要时另立。
