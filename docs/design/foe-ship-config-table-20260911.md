> **船长提议原文（2026-09-11）**：「其实建议给敌人单独一套**敌舰的配置表**，敌舰属性按照配置表

## 一、诊断：现在"为什么会连带一起动"

现在敌人的一切属性都是**从"威胁"推导出来的**，没有"船"这一层：

| 属性 | 现在的来源 |
|---|---|
| 血量 | `foeHpOfThreat(威胁)`（威胁曲线反推），可被逐卡 `foeHpOverride` 覆盖 |
| 速度 | `参考船速 × 威胁基率(威胁) × 战术系数(tactic)`（`combat.ts:840-842`） |
| 伤害 | `威胁份额 × foeDpsPerThreat`（`:851`） |
| 命中/装填/衰减 | 全局常量 + 逐卡覆盖（`foeHitRate` / `foeReloadMs` / `foeFalloff`） |
| 血层分布 | `PROFILE_SPLIT[defProfile]`（3 档：盾/甲/平衡） |
| 抗性 | **`resists: {}` —— 敌人全系零抗性**（`combat.ts:879`） |
| 舰种名 | `FOE_CLASS[战术][血型]` —— **只有名字，没有属性**（`combat.ts:770`） |

**本会话已经真实发生过的连带事故**（都是这一层缺失造成的）：

1. **推进器一提档 → 全表标定作废**，最后只能回退推进器来恢复一致性。
2. **改 `tactic` 默认值 → 5 张卡静默变战术**（`烬火42/回音52/天底66/虚海88/穹顶96` 都没写 `tactic`，靠 `?? 'orbit'` 生效）。
3. **两张 kite 卡只能逐卡打补丁**（`foeDmgMul 0.27 / 0.30`），因为没有族级/舰级口径。
4. **敌速出现两种口径混用**：brawl/orbit 走 2026-09-10 固定锚定，kite 保留 2026-09-09 段参考船口径 —— 谁都看不出来，因为速度是"算出来的"而非"配出来的"。
5. **族系两处真相源**：数据侧 `anomaly.foeFamily` 与美术侧 `FOE_FAMILY[id]`（硬编码 22 行）**各写各的**，`演习场靶机` 在美术侧是 B、在数据侧为空。

⇒ 您指出的正是根因：**没有"船"这个实体，所以任何全局项一动就是全表联动。**

## 二、方案骨架

**新增 `packages/data/src/foe-ships.ts`：敌舰配置表。一行 = 一个舰级。**

| 字段组 | 内容 | 现在散落在哪 |
|---|---|---|
| 身份 | 舰级 id / 舰级名 / 族（A~G） | 名字在 `FOE_CLASS`；族在硬编码表 |
| 防御 | 总血基准 · 结构/装甲/护盾分布 · **三系抗性（新增）** | 威胁曲线 + `PROFILE_SPLIT`；抗性现在全零 |
| 机动 | 速度基准 · 灵活度 | `参考船速 × 威胁基率 × 战术系数` |
| 武器 | 单发 · 装填 · 命中 · 射程带 · 远端衰减 · 近盲带 · 伤害构成 | 威胁份额推导 + 全局常量 + 逐卡覆盖 |
| 战术 | 默认战术（brawl/orbit/kite） | 卡上 `tactic` |
| 词缀 | 轻装 / **精锐（头目档，现已预留）** | `FOE_LIGHT_WORD`；精锐档 `combat.ts:776-777` 预留未实装 |

**悬赏卡改为"引用舰级 + 修正"**：

```ts
// 示意：A 族某卡的"头目 + 一堆杂鱼"
ships: [
  { ship: 'foe-pirate-skiff', units: 3, hpMul: 0.5 },  // 杂鱼：快艇 ×3
  { ship: 'foe-pirate-boss',  units: 1, waves: [2] },  // 头目：自家舰级，后一波入场
]
```

⇒ **动一艘船（改 `foe-pirate-skiff`）只影响引用它的卡，且影响面一眼可见**——正是您要的效果。

**顺带解决我上一条报的引擎缺口**：上一轮我查出"**头目能和杂鱼一样疼，但没法更疼**"（同卡所有单位共用一套武器，`combat.ts:894-911` 读卡级字段）。若一张卡能混编**两个舰级**，头目直接引用一个"自带更高单发/更好命中"的舰级即可 —— **不必去动战斗结算核心的伤害链**。

## 三、必须先定的取舍（根问题）：**威胁还当不当家？**

| 方案 | 说明 | 得 | 失 |
|---|---|---|---|
| **甲 · 舰级给绝对值** | 舰级表写死血量/速度/单发；威胁降为展示与排序 | 彻底解耦；头目能自带更强武器 | **现有"威胁=战力"的难度体系要重建**，26 张卡 + 全套标定作废 |
| **乙 · 舰级给系数** | 舰级表给"相对基准的倍率"，威胁仍是总闸 | 保留现有难度曲线，改动小 | **船与船仍会随威胁联动——您要解决的问题只解一半** |
| **丙 · 混合（我推荐）** | 舰级给**绝对值**；卡上用 `hpMul`/分段微调；威胁降级为"展示 / 报酬 / 解锁"口径，另立一条**战力校验**（content:check 按舰级表反算实际战力，与卡面威胁比对，偏差超阈值报错） | 解耦 + 难度仍可控（用校验替代隐式推导） | 需新写一条校验契约 + 一次全量重标 |
