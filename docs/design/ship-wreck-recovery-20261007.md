# 玩家舰船整船回收与战损插件

> **状态：已实现并本地合入，待船长观感验收/发布**（零号 · `dsh/ship-wreck-recovery-20261007` · 2026-10-07，基线`d233f761`，功能提交`1bc1ef19`）
> 船长原话：「我想实现类似《远行星号》中类似的沉船打捞系统，在玩家舰船被摧毁后，打捞有概率能够回收受损严重的玩家舰船。如果成功回收，则装备成功回收的概率提高到80%。回收的舰船有概率添加一个损坏插件，损坏插件会随机降低舰船的某一方面属性。并且需要新增配套的’工程‘技能：增加舰船打捞回收成功率的2个上下级技能，效果分别为rank4下级技能每级提高5%/rank5上级技能每级提高4%。算法采用加算，基础概率由你定。还要增加一个rank4下级技能的后续rank5技能，增加舰船成功回收时，装备的回收概率，每级4%，满级后成功大佬舰船装备回收率100%。」船长确认本方案。

## 范围

- 正常星系主控与AI舰船残骸：整船回收、装备保全、战损插件、工程技能、存档与读数。
- 虫洞/信号空间不生成玩家舰船残骸，货舱、弹药不返还；无人机按原有独立回收率判定，不吃装备保全技能。
- 战损插件不占普通插件槽、不参与装配方案、不制造、不交易；普通维修不清除。
- 新残骸每件普通装备只判定一次；旧残骸缺少判定标记时沿用原有逐轮尝试，避免历史存档静默丢件。

## 已确认口径

| 项目 | 口径 |
|---|---|
| 基础整船回收率 | 25% |
| 舰体回收技能 | Rank4「舰体打捞工程学」+5个百分点/级；Rank5「高级舰体打捞工程学」+4个百分点/级；加算 |
| 整船回收上限 | 90%（为技能与既有插件预留空间） |
| 回收船状态 | 结构20%、装甲20%；回母港舰队，不自动成为主控 |
| 装备保全率 | 基础80%；Rank5「装备保全工程学」+4个百分点/级，满级100% |
| 装备判定 | 普通模块逐件一次；未保全永久损失；无人机沿用无人机独立回收规则 |
| 战损插件 | 整船回收成功后50%概率添加；最多3个；同类不重复；不占普通插件槽 |
| 战损效果 | 护盾/装甲/结构/速度/货舱/武器与无人机射程六类之一，单项-15% |

## 公告备审

1. 玩家可通过打捞回收正常星系中被摧毁的舰船，回收舰船保留部分装备并拖回母港。
2. 工程新增舰体打捞与装备保全技能，逐级提高整船回收率及成功回收后的装备保全率。
3. 回收舰船可能带有战损插件，降低一项舰船属性；常规维修不会清除战损。
4. 玩家可在舰船、装配及沉船记录中查看战损详情；新残骸的普通装备仅判定一次保全。
