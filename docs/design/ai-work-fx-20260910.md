# AI 工作动画（AI 指挥中心「执行中」按工作内容差分）（2026-09-10，状态：**已确认口径并实现，待验收**）

> 需求原文（船长）：在 AI 指挥中心给每个 AI 显示一个简单的工作动画（按工作内容差分），顺便考虑下是否会大幅消耗性能。
> 确认口径（船长 2026-09-10 三项选择，均取推荐）：**范围 = 仅「执行中」列表每行**；**粒度 = 6 类工作各一套**；
> **风格 = SVG 线稿小场景**（与舰船资产同语言，见约定第九章）。
> 实现：`apps/desktop/src/renderer/src/ui/aiWorkFx.tsx`（唯一实现）+ `ShipPage.tsx` 接线 + `styles.css` 动画层。

## 二、每类画面（56×36 画布，细描边 1.6 / currentColor / viewBox）

- **采矿**：舰影 + 采掘激光脉动打向右侧矿点，3 粒矿石碎屑错相位回流货舱；
- **打捞**：舰影 + 扇形牵引光束呼吸（低透明填充）+ 激光主线脉动 + 2 片残骸被吸回；
- **掩护巡逻**：舰影小幅左右巡航（带尾焰）+ 两道扫描弧呼吸 + 远端敌情三角闪烁；
- **精炼炉**：炉体（含进料口） + 炉内两道火焰绕底边缩放脉动 + 火星上升；
- **回收炉**：同一炉体形象 + 残骸碎块从上方落入炉口 + 底部产出料闪动；
- **组装制造**：组装台 + 机械臂绕根部摆动 + 台面工件脉动 + 装配火花闪。

配色沿用 `NAV_TONES` 同族语汇：采矿 #b5e35f / 打捞 #6fe3f0 / 掩护巡逻 #ffc46b / 精炼炉 #42d9b0 /

## 三、性能口径（船长问"是否会大幅消耗性能"）

结论：**不会大幅消耗性能**，依据如下（也是实现纪律，见约定第十四章）：

1. **量级**：行数量级 = AI 核心上限（「AI 核心操作学」每级 +1，常见 1~4 艘副船）+ 站内工业（1~3 条），个位数行；
2. **只动合成器属性**：每条动画只改 `transform` / `opacity`；不碰 `filter` / `box-shadow` / 宽高
   （第十四章第 5 条实测绘制尖峰 50~60ms 的正是那类动画）；本轮也未加 `will-change`（个位数元素无必要、白吃显存）；
3. **不加逐帧 JS**：不新建 rAF 循环，动画全交给 CSS，与引擎 10Hz tick 解耦（战斗画面那条 rAF 与本处无关）；
4. **重渲染面为零**：`AiWorkFx` 走 `memo`——引擎每 tick 触发整树重渲染（App 层订阅 force）时 props（kind 字符串）不变，
   整棵 SVG 子树跳过 diff；
5. **不留后台开销**：切走舰船页/AI 标签页即卸载（该 tab 条件渲染）；
6. **复核方式**：如需实测，`localStorage['whale-idle:debug']='1'` → 顶栏「⏱ 性能」取 adv/notify/commit/long/fps 前后快照；
   本轮的静态结论是"新增成本 ≈ 首次挂载 ~10 个 SVG 节点/行 + 动画期间合成器合成"，与战斗画面不在一个量级。
