## 一、船长原话（照抄）

> 进行修正，玩家扫描星系将不再占用玩家的主控活动（也不显示在主控活动里，而是在 AI 活动的图标右侧
> 显示一个进度条，当扫描完成后这个进度条依旧存在并高亮，直到玩家进入星图界面查看后才移除）。

## 二、修前是什么样（核过的现状）

「星系扫描」= 星图里对剪影星系点的「扫描探索」（`state.scanning`，就地扫 10 分钟基准 → 点亮 → 自动返航）：

- **货真价实占着主控**：开扫自身挡 11 项；**反向有 14 处** `if (state.scanning.active) return '扫描探索中：先终止扫描'`
  （采矿 / 打捞 / 远征 / 长途运输 / 快递 / 亲自开炉×2 / 亲自开线 / 掩护巡逻 / 返航空间站 / 建站交付 /
  换驾驶 / 进洞 / 扫描虫洞）；
- `shipBusyLabel` 报「扫描探索中」⇒ 换驾驶、派副船、进洞同一把尺挡住；界面另有「换驾驶会终止扫描」二次确认；
- **牵动舰船位置**：开扫清 `awayGalaxy`；窗口完成 → 自动返航段（单程）→ 自动停靠最近的已建成站 + 自动卸货；
- 事件侧挂三件事：扫描期间事件倒计时 ×2、强制走「探索发现」池（12 条专属事件）、
  把玩家算作"就地作业暴露"（低安埋伏概率提高；埋伏本身不中断扫描，真正会停扫的是
  "主控结构过低 / 修理组件耗尽"那条自动停手）。

## 三、定案口径（三条）

| # | 口径 | 含义 |
|---|---|---|
| **1A** | **双向放行** | 扫描期间玩家照常采矿 / 打捞 / 远征 / 长途运输 / 快递投送 / 掩护巡逻 / 亲自开炉·开线 / 进虫洞；反过来这些在跑时**也能派扫描艇**。唯一保留的互斥 = **一次只派一艘**（`state.scanning` 单槽；要换目标先召回，已扫进度按星系各自保留） |
| **2A** | **不牵动舰船** | 扫描艇是**无人艇**：不出发、不返航、不停靠、不卸货。**自动返航段取消**（它原先只在日志里存在、不挡任何操作）；`awayGalaxy` / `dockedSite` / `transit` / 货仓全程不动 |
| **3甲** | **不再暴露** | 扫描**退出"就地作业暴露"清单**（无人艇不在场、没得打）⇒ 不会因扫描挨打、也不会再被"结构过低"自动停手连带停扫。**「探索发现」事件池与事件倒计时加速照旧保留**（口径 = 扫描艇把前方的信号传了回来；12 条专属事件一条不删） |

### 界面（船长原话直落）

- 「玩家活动」列表**不再出**「扫描探索」行（`activityOverview` 不再生成 `kind: 'scan'`）；
  事件栏头部 **AI 两枚徽标（副船 / 工业）右侧**新增**扫描条**（`app-activitybar-scan`，定宽 200px、
  名称省略号，防头部跳动）：进行中 = 星系名 + 进度 + 百分比；点击 = 跳「星图」页。
- **完成后扫描条依旧存在并金色高亮**（满格 + 「✓ 已完成」），**直到玩家进「星图」界面查看**才移除：
  完成时置 `scanning.awaitingView = true` + 记 `lastGalaxyId`；玩家**进/切到「星图」页的「星图」标签**
  （`App.tsx` 的 `useEffect`）或**点一下扫描条**即调 `acknowledgeScanView` 收起（幂等，收第二次返回 false 不落档）。
  ⚠ **完成时人已经停在星图页** ⇒ 那一拍不触发（依赖只有 `[page, mapTab]`），高亮留着，等他离开再回来或点一下才收
  ——免得"新点亮的星系还没看见，条就没了"。
- **终止入口搬家**：活动栏那个「终止扫描」按钮随行一起消失 ⇒ 搬到**星图页那条扫描读数**里
  （`Expedition.tsx`，口径 = 「召回扫描艇」，已扫部分保留）；`ShipPage` 的"换驾驶会终止扫描"二次确认**删除**
  （扫描已经不影响换船）。

## 四、存档（零迁移）

- 新增两个**可选**字段：`scanning.awaitingView?: boolean`、`scanning.lastGalaxyId?: string | null`
  （`createInitialState` 里给初值，`save.ts` 归一）⇒ 老档无字段也能读。
- **老档"自动返航段"一次性收口**：老档若正处在 `returning === true`，其窗口完成时**星系早已点亮**
  （`finishScan` 先落地）⇒ 读档直接按"已收尾"处理（`active=false`、时间字段清零、`returning=false`），
  **情报不丢、舰船位置不动**（收口前那套"到港停靠 + 自动卸货"作废），并补亮 `awaitingView` 让玩家看一眼。
- `returning` 字段保留（运行期恒 false）——读档时老档返航段与其混不到一起。

## 五、连带改动与"不动的部分"

- **进洞门槛少一档**：「扫描星系」从主控活动全表**出表**（十档 → 九档，`glossary.md` 八之七已改）；
  两个方向都放行：扫描在跑照样能进洞、进洞后照样能派扫描艇、别的活动在跑也能派。
- **不动**（明确保留）：`RETURN_LEG_MUL` 仍是悬赏/打捞/巡回讨伐的返航旋钮（只是星系扫描不再用它）；
  低安「扫得慢」（`SCAN_LOWSEC_PENALTY`）不变；续扫进度 `scanProgress` 语义不变；`scanProgress` 读档上限
  仍是 22 分钟；**「扫描虫洞」的一切口径不动**（仍占主控、仍暴露、仍"遇袭不中断"）。
- **⚠ 顺带发现的口径漂移（船长 2026-09-15 已裁定：不要动虫洞）**：2026-09-14 那条「**虫洞扫描与星图扫描
  遭遇期望一致**」（`encounters.ts` 用同一个 `kind: '扫描'` 档、含低安 ×1.5 系数）——星系扫描改无人化后
  **不再暴露**，于是这条"一致"事实上只剩虫洞扫描一边。**裁定 = 保持现状**：虫洞扫描照旧暴露、
  照旧「遇袭不中断」；两边不再强行对齐（本条件即口径记录）。
