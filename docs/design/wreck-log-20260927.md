## 一、行为

- **触发**：所有我方舰船损失都走 `shipyard.loseShip()`（远征 / AI 副船 / 虫洞内被击沉 / 虫洞内整队失联）⇒ 在那里追加一条。
- **每条存**：船名（含自定义名）· 船型 · 损失原因（结构化枚举）· 地点（星系 id；虫洞内记层数）· 时间 +
  **高/中/低槽装配** + **舰船插件** + **无人机舱**快照（顺序敏感：在 `delete state.fleet[shipId]` 之前抓）。
- **保留**：最多 30 条，新的在前，超出丢最旧。
- **残骸状态**：读残骸账派生 —— 残骸还在 ⇒ 「可打捞（剩余 X）」（48 游戏小时衰减）；被捞走（`markWreckRecovered`）⇒「已回收」；都没了 ⇒「已过期」；虫洞内损毁 ⇒「无残骸」。
- **入口**：通讯页顶部按既有 `.app-tasktabs` 族加「收件箱 / 沉船记录」切换；沉船记录左列清单、右列明细，只用既有 `.app-comms-*` 族类名。
- **不做**：不记货舱货物；不记拆解/卖船；不改残骸系统的衰减与回收规则。
