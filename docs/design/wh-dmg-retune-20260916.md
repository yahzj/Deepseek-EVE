## 二、最终口径（现行 = 甲案）

**洞内派生卡 = 按"威胁预算"反算血与火力**（`wormholeAnomalyOf`）：

```
ratio       = 卡的自然血 / 卡的自然火力        （卡面事实，不缩放）
budget      = foeHpOfThreat(层威胁) × 洞内强度系数 10 × 谜质威胁乘数
T（威胁预算）= budget² ÷ WORMHOLE_THREAT_REF_RATIO(25) × 档位威胁修正
血 = √(T·ratio)        火力 = √(T ÷ ratio)
```

- **同层同档"威胁量（血 × 火力）"恒定**：族的"厚甲 / 高火力"性格由**自然比**表达，不再由专用旋钮表达；
  实测极差 层1 浅档 ±1.4% · 层8 浅/中/深 ±4.5%（结构恒等；偏差来自**每门单发取整**与**舰体火力越线折扣**，非线性）。
- **档位修正改乘 T**（`WORMHOLE_TIER_THREAT_MUL` = 浅 1 / 中 **1.05** / 深 **1.1**）⇒ 血与火力**各 ×√档位**
  （旧口径是"只抬血 ×1.1 / ×1.2"）。
- **族系数全部撤除**：`WORMHOLE_FOE_DMG_MUL(0.7)` · `WORMHOLE_GRAVE_DMG_MUL(1.45)` · `WORMHOLE_GRAVE_HP_MUL(0.85)`
  **三个常量已删**；`WORMHOLE_TIER_HP_MUL` 改名 `WORMHOLE_TIER_THREAT_MUL`。
- **保险（新增 · 洞内洞外都生效 · 只对我方）**：`PLAYER_VOLLEY_DMG_CAP_SHARE = 0.8` +
  `cappedFoeDamage()` —— **同一拍内落在同一艘我方舰上的敌方伤害合计 ≤ 该舰满血（三层合计）× 80%**
  ⇒ 满血舰**永不可能被一次齐射带走**（至少留 20%）。只挂在"敌 → 我"三处结算点（敌机群 / 敌光束 / 敌炮台），
  我方打敌人一字不动；逐拍账本 `battle.meVolleyDmg`（每拍开头清空，`save.ts` 登记为**运行期字段**、不进档）。

**不动**：洞外任何数值 · 威胁曲线与面板威胁 ×2 · 谜质 · 错开首轮齐射（洞内各敌首发差 900ms）·
D 炮台受击增程的**距离门**（只有"这一发来自它射程之外"才解锁）· E 族机群受击增程 ×4。

## 三、改前 → 改后（实测 · 同一探针跑 HEAD 旧模块与现行模块）

`tools` 探针（临时）逐卡量：**层 8 深层节点**

| 族 | 卡 | 血 | 火力 | 血×火力 |
|---|---|---|---|---|
| A | `wh-pirate-warband` | 10,010 → **8,290**（−17%） | 404.3 → **473.5**（+17%） | 4,046,543 → 3,925,544 |
| C | `wh-alien-hive` | 10,010 → **10,063**（+1%） | 281.8 → **395.0**（+40%） | 2,820,318 → 3,974,813 |
| D | `wh-grave-throne` | 8,509 → **11,347**（+33%） | 445.0 → **352.8**（−21%） | 3,786,283 → 4,002,820 |
| E | `wh-titan-hulk` | 10,010 → **7,188**（−28%） | 581.6 → **596.6**（+3%） | **5,821,497 → 4,288,199** |
| G | `wh-exile-line` | 10,010 → **11,424**（+14%） | 227.1 → **356.0**（+57%） | 2,272,953 → 4,066,481 |

⇒ **改前"深层 E"独占 1.8× 的威胁预算（5.82M vs G 2.27M，2.56× 极差）；改后五族同层同档拉平（±4.5%）**。
这就是船长问的「为什么 D 组和 E 组的深层 DPS 这么高」的答案：旧公式里**火力 ∝ 自然火力 × 血缩放**，
自然火力高的族（E 581.6 / D 445.0）在深层被血量曲线**同倍放大**，于是"厚血族"叠出高火力。

**层 1 浅档**（船长看过的老读数，同探针复测）：A 3,490/114.0 → **3,230/150.5** · C 3,490/114.8 → **3,210/150.8** ·
D 2,967/93.5 → **5,129/95.0**（血 +73%）· E 3,490/196.0 → **2,451/196.3**（血 −30%、火力持平）·
G 3,490/162.0 → **2,690/176.3**。**E 的火力一动没动**（它的自然比恰好≈参考比 25 的等价值），
但它的**血少了 30%** ⇒ "薄皮高伤"从"靠旋钮"变成"靠卡面性格"。
