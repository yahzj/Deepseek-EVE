- 旧规则来源：2026-10-02裁定，原话「我希望的是100%后能够继续刷，但是掉落残骸数量需要减半作为惩罚」。当前`weekend-autoloop.test.ts`明确断言收复后循环目标保留；代码也会继续原星系。
- 新指令要求收复后切换，因此自动循环在原目标刷满后的行为要改变。推荐只修改自动循环：依次收复未完成的外围和核心，全部完成即停止。
- 手动主动出击仍可刷已收复星系，既有半量残骸及不给额外收复奖励保持。不删除已收复星系的入侵卡或修改全局可打判据。
- 不新增单星系刷取模式或第二个开关；若仍需自动刷已收复星系，须另行裁定，而非暗中扩大本次功能。

## 推荐实施规则

1. 开启时所选为未收复外围，则先打该处；其余外围按本场`peripheryIds`的既有顺序逐个处理，保持目标稳定，不另按距离/进度重排。
2. 所选目标已收复，或选中核心但还有外围未收复，则先选列表中第一个未收复外围。外围全部收复后选未收复核心，只打其普通入侵舰队。
3. 出发前复查当前目标实际进度，已满则切换，NPC或其他战斗完成的目标也自动跳过。切换不归零贡献、不改变事件编号、不消费尚未出发的抽签次数。
4. 正在战斗或返航时保留本趟目标及结算归属，不中断、不改绑远征。照常打完并返航卸货，空闲后再选择下一处，不添加瞬移或星系间直达路线。
5. 每场仍经过既有等待、真实抽卡冷却、装甲/结构、维修与货仓检查。冷却中等待；战败/撤退和补给不足等保持原安全处理，不靠换目标绕开停环条件。未探索、不可达或其他前置不满足时暂停并提示，不自动探索或忽略门槛。
6. 核心实际收复进度满后自动关闭循环，提示收复完成、旗舰需手动挑战。不调用旗舰准备、编队或开战入口，不将普通核心舰队等同于旗舰战。
7. 活动结束或更换场次不继续旧路线，也不自动开下一周/召唤的新入侵。旧档已开启的入侵循环按新规则续跑；沿用当前目标字段，不新增存档结构或开关。
8. 在线与离线同源选目标，按各自推进到的入侵时刻判NPC进度。实现时核对时钟传参，不能用上线末刻提前跳过离线片中的未收复目标。

## 追加：活动栏冷却进度

- 根因：`activity.ts`目前只根据`autoLoopAnomalyId`生成常驻悬赏循环行，没有根据`weekendEvent.autoLoopGalaxyId`生成入侵行。新旧活动栏已支持通用`percent`/`remainingMs`进度渲染，不是冷却条的CSS失效。
- 技能判断：`ui-ux-pro-max`的UX域`loading feedback progress`命中Feedback/Progress Indicators「Show progress for multi-step processes」及Feedback/Loading Indicators「preserve layout focus」「leave long waits unexplained」的反面提醒。支持补显示反馈，沿用同款稳定活动行，不额外弹窗或新增动效。
- 非战斗/返航的等待窗口显示「入侵重复出击」、当前目标星系、冷却进度条和剩余时间，进度方向与常驻悬赏相同。冷却读下一场真正抽到的卡，不读板面驻留卡；只读预览不消费抽签次数，显示和出发共用core结果。
- 等待其他主控作业时显示等待原因，不能用冷却条冒充该作业的结束进度。返航途中继续显示本趟返航条，不叠加第二条等待行；停止后续入侵循环不召回当前胜利返航。
- 收复后换目标，活动栏更新目标及新目标下一场真实冷却；不得把上一目标的条继续挂在新目标名下。核心全清或活动结束后移除循环行，不保留虚假的100%等待条。
- 停止按钮接入侵循环关闭入口，不能复用`bountyLoopAt(null)`只关常驻循环；点击行跳星图，不跳已不存在的页签。新旧界面同一视图结果，使用既有图标/进度条/剩余时长样式，中英文接线一致。

Title: Invasion Repeat Assault Changes

1. When players enable repeat assault, it switches targets as each system is reclaimed, clearing the periphery before the core.
2. Repeat assault stops once all peripheral and core systems are reclaimed. Players must challenge the flagship manually. Manual sorties remain available in reclaimed systems, with the existing half-wreck yield unchanged.
