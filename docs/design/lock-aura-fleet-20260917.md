## 三、口径（本次落码）

1. **全队取最高一份**：编队（主控 ＋ 僚舰）内任一舰装了 `lockDmgBonus` 件 ⇒ 取其中**最高的那一份**
   （先各自曲线收敛、再取最大），**全队每舰**的 `lockedDmgBonus` 都置为该值；
   **零份 ⇒ 一个字段都不写**（无阵列的编队逐字不变）。
2. **集火同批扩到全队**：因为是同一个字段驱动（`unit.lockedDmgBonus` 既管集火又管增伤），
   全队置上之后 **全队武器都集火「存活编队首位」**（主舰优先、击毁接力）。
3. **单舰场景不变**：全队 = 它自己 ⇒ 逐字等价（远征单人 / 遭遇战 / 虫洞单舰）。
4. **打敌机仍不吃**（保持现状口径）。
5. **零存档迁移**：纯运行时聚合，不改存档结构、不改任何件数值（8/12/20/30% 一个数不动）。

## 四、不做 / 边界

- 不改阵列三档与丧钟的**数值 / CPU / 价格 / 渠道**；不改敌方（敌舰没有锁定件）；
- 不改「集火 vs 随机」这套机制本身，只把它的作用域从"装阵列的那艘"扩到"全队"；
- 不改 `curveMult` 的多件收敛口径（同舰多件仍取曲线值）。

**用例里踩到的两个读数坑（已写进用例注释，防下次再踩）**：
1. **`stats.meDmg` 会"封顶到敌舰总血"**——敌舰被打死时，带/不带光环两跑的合计值**双双收敛到敌舰满血**
   （实测 1652 = 敌舰满血、逐字相同）⇒ 拿合计值判"增伤是否生效"会得到**假阴性**。改为
   **敌我血量都抬高 ＋ 只跑 15 秒（双方都活着）＋ 只比每发均值 `meDmg ÷ meHits`**。
2. **高血量夹具下双方走不进射程**（实测 15 秒 `meHits = 0`、每发均值 `NaN`）⇒ 用例里**逐拍把距离钉在 1,000 m**。

## 七、同批发现的一个真 BUG（与本改动无关，待船长定）

**指挥舰的「全舰单发伤害 +15%」（`ShipDef.fleetDamageBonusPct`）从未生效**——它只在
`startFleetBattleFor` 里乘进**开战那一刻**的规格（`spec.weapons[].shotDmg`），而战斗是
**逐拍重建规格**的（`buildMyUnitSpecs` → `createPlayerSpec`，后者不知道这个字段）⇒ 那些被乘过的值
**一拍都没用上**（开火读的是重建后的规格）。

**取证（真引擎 A/B · 同编队同种子，只差光环船那 15%；敌卡 threat 1200 双方都不死、比每发均值）**：
带光环 **每发 91.640 / 命中 25** · 无光环 **每发 91.640 / 命中 25** ⇒ **比值 1.000**（生效应 ≈1.15）。
⚠ **口径修正（本文件前一版结论作废）**：第一版探针拿 `stats.meDmg` **合计值**比，而合计值在敌舰被打死时
**收敛到敌舰总血**（1652 = 敌舰满血）⇒ 那次"逐字相同"是**假阴性**、不能当证据；本节的每发均值口径才是有效证据。

**修法（若船长要修）**：与本次锁定光环同一处纪律——把 `fleetDamageBonusPct` 的乘算挪进
`buildMyUnitSpecs`（每拍重建处），并补一条"光环每拍生效"的用例。**影响面**：指挥舰在编队里**变强**
（+15% 全队单发，此前为 0）⇒ 含指挥舰的编队战读数与胜率会变；敌舰无此字段、单舰场景无影响。
