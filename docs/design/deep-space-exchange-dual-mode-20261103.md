# 设计文档：深空证券交易所（DSSE）双模式 UI/UX 重构 (2026-11-03)

## 1. 状态与背景
- **状态**：开发中
- **船长原话**：「世界观与代入感推敲里的股票代码都要四位英文就好了，资金来源：方案 1是我们的真实目标，但是我们先做2，测试功能。极简模式下的债券理财就不做了。主要是目的是让玩家上这个股市赌桌上消耗游戏中期大量溢出的信用点（也就是游戏币）。我们先做UI，先吧UI和交互做好了，玩家才愿意来玩」
- **官方定名**：**深空证券交易所（Deep Space Stock Exchange，DSSE）**
- **业务战略目的**：作为游戏中期巨额溢出信用点（游戏币）的大水槽回收渠道，给玩家提供高刺激感、低决策门槛的星际金融博弈玩法。

---

## 2. 核心架构与功能规划

### 2.1 模式划分与切换机制
- **双模式一键切换**：
  - 默认模式：**极简投资大厅（Simple Mode）**
  - 高阶模式：**专业终端（HUD PRO）**
  - 切换入口：顶栏右侧科幻拨动按钮 `[ 极简看盘 ⚡ ] ⇄ [ 专业终端 ⤢ ]`；
  - 持久化：保存在 `localStorage['whale-idle:exch-view-mode']`（取值 `'simple' | 'pro'`），零延迟无刷新就地切换。

### 2.2 股票标的规范（统一 4 位英文字母代码）
- `SMHI`：星海重工联合体（军工防务巨头，高波动高弹性）
- `UGMC`：联星采矿集团（原材料与稀有矿垄断商，周期蓝筹）
- `OJLS`：欧吉跃迁物流（星门运输与供应链网络，稳健成长）
- `ABSI`：阿斯托利亚科研院（蓝图逆向与虫洞先驱科技，高风险超高收益）

### 2.3 极简模式（Simple Mode）具体布局与设计
1. **顶栏精简**：
   - 仅显示：深空证券交易所标题、模式切换开关、总资产（大字）、可用现金、浮动盈亏（红绿带 %）、一键重置账户；
   - 彻底隐藏保证金率、维持保证金、冻结款等冰冷指标。
2. **左栏（星际企业榜单 · 300px）**：
   - 卡片式股票列表：4位代码 + 公司名称 + 现价大字 + 今日涨跌幅 + Sparkline 迷你趋势线；
   - 持仓提示：若持有该公司股票，卡片右上角显示精致角标 `持仓 1,500股`；
   - **极简模式下不显示债券理财卡（BondCard）**，保持纯粹专注。
3. **右栏（公司主视区 & 极简现货交易舱 · 弹性自适应满宽）**：
   - **抬头区**：公司名、4位代码、现价（大号数字）、今日涨跌、24h 高低成交；
   - **平滑流光渐变走势图（SimpleChart）**：
     - 提供通俗的三大周期按钮：【分时】、【日走势】、【周线】；
     - 隐藏蜡烛影线与复杂指标，采用带半透明发光底色的平滑面积折线图，鼠标划过实时展示当时价格；
   - **傻瓜式现货买卖舱（SimpleTradePanel）**：
     - 买入模式：提供 `25%`、`50%`、`75%`、`全仓` 筹码按钮，自动换算“预计获得股数”，大按钮【立即市价买入】一键成交；
     - 卖出模式：展示持有股数，提供 `25%`、`半仓`、`一键全卖` 筹码按钮，自动换算“预计变现金额”，大按钮【立即市价卖出】；
     - 彻底隐藏 2~50x 杠杆、限价单、条件单与网格，防止新手意外爆仓。
   - **当前股票持仓看板（SimplePositionCard）**：
     - 紧贴买卖舱下方，若有持仓大字展现：持仓股数、持仓成本、浮动盈亏（+ISK 与 +%）；
     - 提供一枚快捷【一键清仓套现】大按钮。

### 2.4 专业模式（HUD PRO）
- 完整保留三栏布局：`StockList`、`Chart`（专业多周期蜡烛图）、`OrderBook`（五档盘口）、`TradeTape`（实时成交流水）、`TradePanel`（2~50x 多空逐仓杠杆与限价单）、`Positions`、`AutoTrade`（网格与定投）、`Records` 流水。
