## 二、本批（待验收）：筛选合并 ＋ 造船厂类别行

### ① 组装机与造船厂：「学会」行 → 「蓝图」行（两轴并一维）

- 原先两行：**「学会：全部/已学会/未学会」**＋ 第三行 **「图纸：全部/永久/一次性」**（第三行还只在选了子类后才出现）。
- 现合成**一行四档**（`BLUEPRINT_LEARN_TABS`，本批扩容）：全部 / 已学会 / 未学会 / **未学会的一次性图纸** /
  **已学会的一次性图纸**；**第三行「图纸」整行删除**（级联条件随之取消 ⇒ 少一行、少一次点击）。
- 判据 = 学会那一轴（`ownsBlueprint`）× 是不是一次性那一轴（`singleUse`）；键仍是 `BlueprintLearnKey`。
- 行名前缀沿用组装机第一行那条 `ui.Industry.136`（**id 不变、文案由「学会：」改「蓝图：」**，与技能改名同口径），
  两个面板共用一条，不另造同串条目。

### ② 造船厂：新增「类别」行（插在「子类」上一级）

- 行序变为 **第 1 行 蓝图 · 第 2 行 类别 · 第 3 行 子类**（舰船级别 T1~T5）。
- 类别键表 = `SHIP_SUBS`（全部 / 采矿舰 / 货运舰 / 武装舰 / 装甲舰），判据走**唯一入口 `shipRolePasses`**
  （= core `shipCategoryKeyOf`）⇒ 与**手册舰船图鉴 / 我的舰队 / 虫洞编队**同一把尺，同一型船在各页落同一档。
- 空档隐藏照 2026-09-20 「明显不存在的子类筛选隐藏」：类别行只列真有蓝图的档（`presentSubs`）。
- **两维互不重置**（2026-09-12 船长在舰队页定的口径）：类别与级别各自独立、与其它条件取「与」。
