## 核心摘要

- 目标流程：主体建站 → 建起步设施 → 复苏并转运人口 → 培训/派工 → 采矿、精炼和科研 → 再审升级与扩站总账。
- 自建初始站体5000万信用点只含3×3主体，不含基础发电、生命维持、服务中心等设施，也不含复苏、培训或舰船。
- 起步设施采用统一生命维持；其容量、电力，以及已确认的基础设施料单、施工时长见设施与成本主题稿。
- 人口、设备、材料各记一份：一人口同一时刻只做一项工作；共享仓库不等于免费产能或重复运输。
- 玩家站仍停留在设计阶段。已确认设计不代表允许实现；旧副站已有的实现也不代表玩家站已实现。

## 当前决定

| 主题 | 已确认摘要 | 边界 |
|---|---|---|
| 科研与设施 | 科研项目解锁设施/课程/扩站资格；统一生命维持承担起步人口容量。 | 完整研究目录、部分研究参数仍待审。 |
| 主体与成本 | 初始主体价值5000万；五类起步设施的料单/工期已确认。 | 主体工期、两项升级和首次扩站最终材料/工时待审。 |
| 复苏与转运 | 按单位预留人口容量；正常接收不新增独立电耗；异常时未接收人口安全安置。 | 已接收居民遭遇严重故障、战损/毁站与完整袭击系统另审。 |
| 维修 | 三项起步保障设施可用材料和时间修复到最近完成等级；维修不另耗站电、不需居民或工程师。 | 维修包材料和工时仍待确认；不含高级设施维修。 |
| 基础劳动力 | 采矿、精炼不需专门课程；施工需工程师、科研需研究员；一人口只执行一项工作。 | 更高级职业与经营系统另审。 |
| 人类生产 | 沿用同条件主控手动基准与现有配方/技能；按真实人口和设备并行，不叠加人类效率倍率。 | 缺料/缺电暂停恢复及人类/AI主动交接已确认；不改变现有AI代码。 |
