# 设置切换英文实机巡检

> **状态：实测完成，已确认存在遗漏，待修复**（三号 · verify · 2026-10-18）
> 船长原话：进行一次实机测试，在设置内切换至英文查看是否有遗漏。
> 范围/不做：真实本地App中文启动，通过设置点击English，核查两布局主要页面、子页签、说明与辅助标签，并比较英文重载；仅独立合成档、隐藏Electron。不读取个人档、不改主树、不合入或推送。
> 待裁决点：巡检发现的问题按报告交付，不以待译登记清零代替玩家界面全英文结论。

## 方法

- 正式复跑工具`node tools/l10n-en-native-check.cjs`，先`npm run build`。
- 工具加载本树真实主进程/renderer，随机回环服务与独立临时userData，中文启动后点击设置中的English，不用测试API代替语言操作。
- 合成舰长名为`Locale Test Pilot`，无玩家自定义舰名；仓库配测试物品，首任务完成、实验室解锁。扫描文本节点及title/data-tip/aria-label/placeholder；“中文”语言选择选项是允许保留的语言自称。
- 桌面1366×768，两主题；输出`tools/_ui-artifacts/l10n-en-native-20261018/`。初轮只列已展开页面，后续补子页与重载，不据此声称所有游戏状态均已覆盖。

## 初轮结论

- 设置切换能写入英文偏好，设置本身与动态取词区域进入英文，无运行异常，但多个模块加载时缓存的标签仍为中文。
- 成就81条卡名、部分工业残骸说明、无人机数量单位、稀有度辅助标签、设置背景名仍存在中文；需要与重载结果区分热切缓存及真实漏译。
- 之前“剩余中文全是内部字符串、全部本地化完成”的汇报不准确：静态延期表仅证明已登记翻译完整，不证明派生文案/模块级缓存/运行期参数都已本地化。本报告以实际App结果为准。

| 问题 | 实际例子 | 定位依据 |

| 装配伤害/抗性标签缓存中文 | 动能25%、高爆、能量、槽位说明 | `ui/shipInfo.tsx`的`DMG_LABEL`及装配页模块级取词 |
