## 二、口径定稿

### 模式与代次

| 项 | 口径 |
|---|---|
| 模式 | 普通档 / 铁人档。**新档可选**；**现有旧档允许一次性转换**；**只能关闭、不可再开启**（单向门） |
| 代次 | 存档头 `ironman.seq`（**普通档也记**，只显示不拦）＋ 存档之外账本 `%APPDATA%\whale-idle\ironman-ledger.json`（**主 + 影子双写**，读 max，原子写） |
| 递增 | **每次落盘 +1**（现状：每 15 秒自动存档 ＋ 每个动作后立即落盘） |
| 闸门 | 铁人档装载（导入 / 恢复）时 `T = max(当前档代次, 账本最高)`；`档.代次 < T` ⇒ **拒绝** |
| 救援 | **≥48 小时**（按档内 `savedAtWallMs` 计龄）的档可装载，**玩家自己在列表里挑**（更旧 = 损失更大）；救援**不受闸门限制**，但内部记一笔（**玩家侧不显示**，船长令） |
| 关闭铁人 | 代次**停止上升**、账本保留、**不可重开**；关闭期间回滚无法追溯（船长已知情接受） |
| 重置档案 | **不清账本**；新档代次从账本最高继续（否则"重置 + 导入旧档"是后门） |

## 三、边界与已知取舍（如实登记）

1. **不做自动备份**（船长令）⇒ 救援**依赖玩家自己手动备份**；从不备份的玩家没有救援档。
2. **换机导入**（新机器账本为空）会被接受一次（提示"本设备首次载入铁人档"）⇒ 单机方案天花板，公告只讲"铁人档不可回退"。
3. **账本可被删/改**仍可绕过（双写只提高门槛）⇒ 符合船长"提高成本、不彻底堵死"。
4. 关闭铁人是**单向门**；关闭后的回滚无法追溯。
5. 福利造成两种模式的数值分叉；**工具与读数默认普通档基线**（不传墙钟 ⇒ 1× 那套免疫照旧）。
