## 三、发现（不一致点）

1. **修理组件两线是收益悬崖**：无技净/h(变现) 19.9 万 / 62.8 万、满技 52 万 / 163 万，
   超参照锚（≈5~6 万/h）**3~30 倍**，也远超装备顶档（MK3 8.5 万）与弹药（3.4~4.6 万）。
   成因 = 短周期（30/40s，2026-09-06 船长缩至原 1/3：90→30s、120→40s）× 低材料成本
   × 净率 20%（2026-09-08 现货上调达标）。design 既有句「高收益行不设上限——稀缺工位/
   **长周期**/吸收流自约束」（manufacture-refine-worker-econ.md §一）——**长周期自约束在
   短周期行不成立**，修理组件等于低门槛印钞线。
2. **civ 装备档显著低于参照锚**：无技变现 8~12k/h（MK1 17~23k、MK2/MK3 51~85k、锚 ≈5~6 万）。
   若 civ = 练手/普及供应线可接受；若按工位机会成本则偏低（但 civ 装备廉价、材料门槛低）。
3. 弹药 3 线节奏与收益中低位（无技 3.4~4.6 万/h）——消耗品高频补给场景，量价结构合理，
   未见失衡。
4. 装备 MK2/MK3 落在锚带（无技变现 51~85k/h）：MK3 单件 5~7 时占工位久、依赖市场消化
   （吸收流自约束），与 design「高收益行自约束」意图一致，无异常。

## 四、校准建议（供船长选向，未实施）

- **A. 修理组件（两线）**——目标把单工位净/h 拉回 ≈5~10 万带，同时尽量保持玩家补给便利：
  - A1：批量放大 + 周期拉长同比例（如 civ 5个/30s → 25个/150s、mil 3个/40s → 15个/200s，
    或等价组合）——净/h 降至约 1/5，供应节奏略降但可接受；
  - A2：仅拉长周期（批量不变）——净/h 同步降但单批供应变慢（玩家等货）；
  - A3：回调 basePrice 至净率 ~10%（涉及 2026-09-08「只升不砍」历史拍板，需船长确认破例）。
- **B. civ 装备档**：维持现状（练手线）或批量 ×2 提收益，请船长定。
- **C. 弹药**：建议不动；可选「批量 120→240、周期 10→20s」降操作频率（收益不变）。
- 舰船 buildSeconds：另出表（本表不涉）。
