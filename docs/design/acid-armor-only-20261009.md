# 酸液减抗仅作用装甲

> **状态：已实现，自测通过，待合入与验收**（二号 · d2/workspace · 2026-10-09）
> 船长原话：「将酸液爆虫的抗性减少效果移除减少结构抗性部分，包括玩家侧的酸液投射器，也不减少结构抗性」「酸液投射器也修改为仅减少装甲抗性」；范围与文案总结后船长回复「确认」。
> 范围：爆虫与玩家酸蚀弹射器仅削减装甲抗性，同步现行说明及测试。参照现有 `applyAlienCorrosion` / `acidResistsOf`，只改减抗层位。战斗域，无跨模块。
> 不做：护盾减抗、伤害/破盾倍率/命中/射程/周期/叠层强度或期限调整、存档结构迁移、历史公告回改、英文准备、真档读写。
> 待裁决点：无；主树在途改动时不合入。

## 确认行为

- 爆虫每次爆发仍削减全队装甲三系抗性15个百分点，逐次叠加、可为负值、跨波保留，主动与死亡爆发去重不变。护盾与结构抗性保持基础值。
- 玩家酸蚀弹射器每次命中仍削减目标装甲三系抗性10个百分点，持续15秒，各层独立到期；其他层不变。
- 随档累计量及层期限保留，读档后按新规则作用装甲；既往已扣血不回算。
- 既有英文及历史公告不改，新敌方说明与战场提示另取待译ID。玩家现有待译说明及规格只改中文。
