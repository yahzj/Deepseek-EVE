## 实施策略

- 小屏触屏使用独立 `is-mobile-layout`；竖屏沿既有旋转，横屏不旋转，不用缩小整窗解决挤压。
- 日志默认关闭，展开/关闭状态不写桌面日志偏好；同一日志组件改为手机抽屉，背景关闭、Esc 与焦点返回，入口持续可达。
- classic 手机左导航改紧凑宽度，保持全部图标/名称与内部滚动；modern 底栏紧凑并保持出港居中。桌面外壳保持原样。
- 主区优先分配剩余宽高；活动栏有明确高度预算与内部滚动，不盖主区，也不停止后台活动。
- 手机弹层按局部逻辑空间限制，头部/按钮保留、正文内滚；重点实测装配候选、数量/交易确认、技能详情、虫洞与日志操作。
- 参照同域日志浮层/收起入口、`app-btn`、现有 `app-modal`、手机横滑图例和面板内滚，不新增设计体系、不新增玩家文案。
- 技能依据：ui-ux-pro-max ux 域 Focus Not Obscured / Sticky Navigation；支持常驻入口不遮控件与弹层关闭后焦点返回。颜色不作为唯一状态，真实触控验证不只 DOM click。
