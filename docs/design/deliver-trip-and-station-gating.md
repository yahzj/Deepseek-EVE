## A. 市场成交静默化（让利 / 巡游不告知玩家）

- **引擎**：站内吸收（settleStationTake）、卖出侧越线抢单（settleSnatchSell）、买入侧抢单
  （settleSnatchBuy）的成交日志统一为普通模板：
  - 卖侧 = `挂单成交：<名>×n，税后入账 … ISK（贸易税/声望加成同簿）`（舰船 = `挂单成交：二手舰船…`）；
  - 买侧 = `挂单买入成交：<名>×1（… ISK）`。
  - 不再出现「让利售出 / 站内收购 / 巡游采购 / 巡游供货」字样。
- **UI**：MarketPage 价格指引（卖/买两侧）删除吸收额 ×E、巡游概率、命中件数等披露文案，
  只保留普通撮合语义（挂价与收购价线/供应价线的相对关系 → 优先级/等待回补）。移除
  snatchSellFill 的 UI 引用（引擎导出保留，供测试用）。
- 机制本身（F×E 保底、越线概率、价格纪律、让利换清仓）**全部保留**，只是玩家可见层静默。
- 测试：market.test 断言语义全部改为「挂单成交/挂单买入成交」前缀统计 + 静默专项（日志零通道字样）。

## B. 建站交付航线（真实航程；自动交付；自动返航；可随时取消）

- **入口**：①星图该星系行动区（GalaxyActions）「建站交付 · 前往工地交付」行；②任务中心·建站
  任务卡（StationCard）不在现场时的同款按钮。同一引擎指令 startSiteDeliverTrip。
- **前置**：驾驶船空闲且停靠空间站（母港或已建成副站 = 协会基地网络）；工地未建成且所在星系已
  探明；仓库+货仓有可交付建材。野外/作业中/亲自开线/快递途中 → 明确拒绝文案。
- **行程**：ShipTransitState 增可选 `delivery: { siteId, phase } | null`（to-site / to-station；
  save 白名单透传、旧档回退 null）。出发 = 驶离泊位（awayGalaxy = 出发星系，航行中站内功能
  天然关闭）→ 真实航程 travelLegMs（debug 模式 1s）→ 到点：
  1. 野外停留工地星系；
  2. **自动交付**：接受名单循环扣缴（仓库+货仓），逐档推进，日志与现场交付同口径；
  3. 全部档位完成 → 就地停靠新落成副站；未建成 → 自动返航最近空间站（to-station 腿，若最近站
     与本星系同站则直接落位）；
  4. 建材不足/空跑 → 提示还差多少，照常返航（可备料后再一键出发）。
- **取消**：cancelSiteDeliverTrip —— 无惩罚，立即返航停靠最近已建成站（顶栏活动行「建站交付·
  前往工地/返航中」+「取消交付」按钮）。
- 手动「现场提交」保留（人在现场仍可补充）。
- 测试：t9 +8（前置校验 / 端到端自动交付并返航 / 建材足量一次建成就地停靠 / 途中取消与取消前置 /
  空跑照常返航 / …）。

## C. 市场蓝图「已学习 / 已获得」标识

- 蓝图行（GoodRow）与详情卡：`已学习`（learnedRecipes 命中，可无限自制）/ `已获得 ×N`
  （blueprintStock）chip；两者皆无 → 详情卡显示 `尚未获得`。新增 chip 色 is-learned / is-stock
  （同族样式）。

## D. 未建成副站彻底收口（船长改拍版）

- 原则：**完成全部档位（建成）前不视为任何站点**——不停靠、无泊位、无卸货、无维修/换驾驶、
  无任何站内功能；只有"工地现场"（野外停留，可现场交付建材）。
- stations.ts 两站档位 unlockDesc 改为施工推进文案，功能统一挂「建成」（并入基地网络，开放
  泊位/卸货/维修/补给/换驾驶及全部共享设施）。
- 停靠落点只认已建成站：onArriveAtGalaxy / noteStationSiteAt 改现场口径（去「首档解锁泊位」）；
- 引擎 advanceGame 逐 tick `reconcileDockSanity`：旧档残留的未建成/未知停靠纠正为工地星系野外
  停留（幂等、只记一次日志）；
- shipyard repairShip / changeShip 对未建成停靠一律拒办（含状态残留防御；建成后放行）。
