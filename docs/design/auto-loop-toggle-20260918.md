## 二、现状（读码坐实 · 动手前）

- 状态 = `state.autoLoopAnomalyId`（单个悬赏 id 或 null，落档）；核心 `setAutoLoopBounty(state, ctx, id \\| null)`
  **原先没有任何门**（纯开关 + 日志）。
- **悬赏卡上已有双向开关**（`重复清剿` ↔ `停止讨伐`），但禁用条件 `busyOther` 写的是
  `… || (远征在飞 && 环不是本目标)` ⇒ **"正在打这个目标但还没开环"被判成忙碌 ⇒ 进行中根本开不了**。
- **活动栏只有单向"关"**（交火行给「撤退」、返航行与等待行给「停止清剿」）——本次按船长裁定**不动**。

## 四、边界与不做

- **活动栏不动**；**忙碌判定沿用**（采矿/转场/待命/打捞/别的目标在飞 ⇒ 本卡开关仍禁用）。
- **自动停环六类原因全部保留**（战损过半 · 失利 · 目标不存在 · 耐久<50%无装置/无组件 · 货仓不足 · 出发被拒），其中两类现在**同时**挡住"立刻再开"。
- **关闭不受任何限制**。存档**只新增一个可选字段、零迁移**（老档缺省 ⇒ 该判定不生效）。
- 属玩法微调、不达"大更"标准 ⇒ 不发公告。
