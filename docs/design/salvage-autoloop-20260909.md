## 1. 主控(引擎 + UI)
- `SalvageOpState` 新增偏好字段 `autoCycle`(默认 **true**)/ `stopAfterTrip`(默认 false),
  跨趟持久(手动停止不重置,同采矿);旧档零迁移(`!== false` / `=== true` 读取,缺省 = 开);
- 引擎 `advanceSalvageOp`:满仓 → 返航(去程并入,按货仓占比缩放,不变)→ 到港整仓卸入仓库 →
  **autoCycle 且未勾 stopAfterTrip = 同星系直接续捞**(无出航相位,清本趟账);
  勾了 stopAfterTrip / 关闭自动循环 = 卸货后收工(日志区分两种收工原因);
- 满仓动作维持既有语义:一律自动返航卸货(不复制采矿"关循环满仓停野外"的边角行为,避免货损意外);
- UI:残骸打捞页加与采矿同款设置行(app-mining-settings 样式)——
  「自动循环(满舱返航卸入仓库 → 去程并入返航 → 自动再打捞)」+「本次返航卸货后停止」;
  互锁与采矿同款:循环开关作业中不可改;stopAfterTrip 仅作业中且循环开时可勾;
- 玩家可见文案同步:打捞页说明/按钮 tooltip/手册「打捞残骸」/引擎日志去「不自动续」口径。

## 2. AI 副船
- `advanceAiSalvage`:到港卸货后不再任务结束归还核心 → **同星系自动再出航(循环)**,直到玩家取消;
  离线结算按趟统计不变(每趟到港计一次);
- 指派日志与注释同步「自动循环,取消任务才结束」;与 AI 采矿(本就无限循环)对称。

## 3. 说明
- 打捞密度有保底(不干涸),循环无自然停点——停止手段 = 主控手动停止/勾 stopAfterTrip,AI 取消任务;
- 低安遇袭等暴露规则不变(每次作业内按既有遭遇逻辑处理,循环只重复既有单趟语义);
- 无存档迁移;无公告(待船长决定是否需要)。
