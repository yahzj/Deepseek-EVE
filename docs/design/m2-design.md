# M2 设计文档：蓝图制造链（装备）

## 目标

让矿物从"只能卖钱"升级为"制造原料"，形成完整成长螺旋：
**挖矿 → 精炼 → 制造装备 → 装配到船上挖得更快/装得更多 → 挖更多矿造更高级装备**。
同时落地架构预留的"限时批次作业"抽象（采矿是循环作业，制造是一次性计时作业）。

## 玩法规则

### 装备（data：modules.ts）

船有两个装备槽（随船生效，换船不丢失）：

| 槽位 | 效果 | 装备 |
|---|---|---|
| 采集器槽（miner） | 循环产量 ×(1+加成) | 强化采集器 MK1（+20%）、MK2（+50%） |
| 货舱槽（cargo） | 货舱容量 ×(1+加成) | 货舱扩展 MK1（+30%）、MK2（+80%） |

- 采集器 = 提升收入速率（在线离线都受益）；
- 货舱 = 提升"一趟能挖多久"，离线 8 小时上限下决定产出总量（挂机关键数值）。
- 同槽换装：旧件自动退回装备库；卸下也回装备库；装备库数量归零不能装配。

### 蓝图（data：blueprints.ts）

- 蓝图用 ISK **一次性购买、永久可造**（已购清单进存档）。
- 每次制造：**开工立即扣全部材料与制造费**，之后不可取消（但制造不会失败）。
- 耗时 = 蓝图基础秒数 × max(40%, 1 − 5% × 工业理论等级)，**开工时锁定**，
  制造中途升技能不影响本次完成时刻（有测试覆盖）。
- 同时只允许一个制造作业；到点自动完成，装备入库并写日志；离线照常完成。

### 数值一览

| 蓝图 | 产物 | 材料 | 耗时 | 制造费 | 蓝图价 |
|---|---|---|---|---|---|
| bp-miner-1 | 采集器 MK1 | 三钛 1200 + 类银 500 | 8 分 | 8k | 5k |
| bp-cargo-1 | 货舱 MK1 | 类银 800 + 类晶体 250 | 10 分 | 10k | 6k |
| bp-miner-2 | 采集器 MK2 | 三钛 4500 + 类银 1800 + 类晶体 600 | 50 分 | 60k | 35k |
| bp-cargo-2 | 货舱 MK2 | 类银 2200 + 类晶体 900 + 超噬 200 | 70 分 | 80k | 45k |

材料只消耗**矿物**（精炼学的意义闭环）；MK2 系列需要超噬矿 → 逼玩家去挖克洛基石/希莫非特矿带。

### 平衡意图

MK1 采集器（+20%）约 2 小时回本；MK2 系列是"鲸吞级 + 全套 MK2"之后的长期目标。
离线 8 小时 + 大货舱 = 满舱时长是玩家要不要升级货舱模块的核心决策。

```jsonc
{
  "version": 3,
  "moduleBay": { "mod-miner-1": 1 },        // 装备库：id -> 数量

  "manufacturing": { "active": false, "blueprintId": null, "finishAtGameMs": 0, "durationMs": 0 },
  ...v2 字段不变

```

## 验收清单（M2）

- [ ] 蓝图商店能买蓝图（钱不够禁用）；已购后卡片变"已拥有"且按钮变"开始制造"
- [ ] 材料不足时按钮禁用/提示缺哪些（含持有数量对比）
- [ ] 开工：材料与制造费立即扣除；进度条走动；制造中不可再开工
- [ ] 工业理论升到 3 级后新作业耗时 -15%；正在造的作业不受影响
- [ ] 到点自动完成：装备入库 + 日志；关游戏期间制造照常完成
- [ ] 装配台：装备库装备装上对应槽、显示加成；换装旧件退回；卸下回库
- [ ] 装配 MK1 采集器后每循环产量 +20%；货舱扩展后容量条变长
- [ ] v2 老档打开后：原有钱/矿/船保留，装备库空、可正常开造

## 非目标（明确不做）

- 不做批量制造与制造队列（单作业够用）；
- 蓝图不可抄写/研究（EVE 的 ME/TE 研究机制留作未来深度）；
- 装备不用于战斗（M3 会引入战斗装备体系时统一建模）。
