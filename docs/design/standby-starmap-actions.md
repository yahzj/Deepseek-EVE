## 机制

### 主控「前往星系待命」（goStandbyAt / advanceStandby / cancelStandby，location.ts）
- 舰船空闲（采矿/远征/扫描/返航/去程中均拒）时：从当前位置（站或野外）飞往**已探索**目标星系，
  时长按当前船跃迁/技能锁定；到点 `awayGalaxy = 目标星系` 野外停留（与远征胜利停留同一表达，
  B1 低安遭遇暴露自动生效）；目标星系须已探索且非当前停靠点；
- 去程在活动栏显示（「前往 X 待命 · 去程中」）可**召回**（recall-standby：立即回母港，无耗时，
  同远征召回口径）；去程中采矿/远征/扫描/返航/换船/维修全部拒绝；
- 到达后就是普通野外停留：可采矿/出击/返航空间站/再前往其它星系。
- 状态：`state.standby {active, galaxyId, finishAtGameMs, legMs}`（v17.1 兼容字段，normalize 幂等）。

### 副船「驻留待命」（assignAiStandby，ai.ts；AiTask 新 kind `standby`）
- 目标须已探索；占一个 AI 名额并消耗一枚核心（与采矿/远征一致管理：取消召回归还核心，
  不占 idle 名单、不可出售/再指派）；去程计时（按核心效率拉长）到点 phase='stand' 驻留；
- **驻留的副船 = 区域停留船**：低安星系中进入 B1 遭遇暴露，且按"停留船优先承担"参与判定；
- 活动栏显示「X · 驻留待命（留守/去程）」可取消；舰船页执行中列表同步展示。
- 存档：aiAssignments task kind=standby normalize 分支。

### 星图动作区（Expedition.tsx GalaxyActions，已探索星系侧栏）
- **⛳ 前往待命**（主控）：按钮按状态禁用并给出原因（已在目标/去程中/驾驶船作业中）；
- **副船待命**：空闲副船 + AI 核心选择 + 「派去待命」；
- **矿带**：该星系矿带行（产出简介）→ ⛏ 开采（采矿中禁换带提示；远征中两步确认转开采）；
- **悬赏**：该星系悬赏行（威胁/奖金/已首胜标记；只列声望达标、无冷却、非执行中的）→ 出击 /
  采矿中「转战出发」两步确认；扫描/返航/其它远征在飞时禁用并说明。
- 另：wrapper `anomalies` 现过滤 hidden 遭遇模板（不污染悬赏目录）。
