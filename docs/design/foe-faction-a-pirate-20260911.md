## 二、引擎能力盘点（"头目+杂鱼"能实现到什么程度）

> 结论：**数量与"头目血厚"支持**，**"头目打得疼"不支持**，**族级速度不支持**，**突进已实装但开关关着**。

| 您要的 | 引擎支持？ | 依据与细节 |
|---|---|---|
| **一堆杂鱼（数量多）** | ✅ **支持，无上限** | `waves[].units` = **同波小队数**（`combat.ts:917` 按 units 循环生成小队）。合计单位 = Σ units ×(1+僚机)。※ `escorts` 有 **硬封顶 2**（`combat.ts:825`），但那是"每小队僚机数"，**不影响小队数** |
| **数量多 → 每个更弱** | ✅ **自然成立** | `unitHp = 本波血 × uThreat/威胁`（:848）、`dps = uThreat × foeDpsPerThreat`（:851），其中 `uThreat = 威胁 ÷ (1+0.6×僚机)`（:829） |
| **头目血厚** | ✅ **支持** | `waves[].hpShare` 可给某波更大血量份额（`combat.ts:847`） |
| **头目打得疼** | ❌ **不支持** | 同一张卡的**所有单位共用同一套武器**（`combat.ts:894-911` 全部读**卡级** `anomaly.*`）；DPS 只跟"威胁份额"走，**与波次/小队无关**。⇒ 头目能更厚，**但和杂鱼一样疼** |
| **头目名号（"精锐"档）** | ⚠ **预留未实装** | `combat.ts:776-777` 注释原文：「规格词缀…**"精锐"档预留——若将来出现相对规格 >1 的头目单位**」。现在只有"轻装"档在用 |
| **全族速度快** | ❌ **无族级系数** | `foeSpeed = min(上限, 参考船速 × 威胁基率 × **战术级**系数)`（`combat.ts:840-842`）。**没有"族→速度"这一层** |
| **突袭（突进）** | ⚠ **已实装，总开关默认关** | `combat.ts:886-893`：`foeCanCharge` 资格 = **威胁 ≥ `foeChargeThreatFloor` 且 战术 = brawl**；受 `foeChargeEnabled` 总开关约束，**默认 false**（船长当日原话留档在注释里：「暂时先取消实装，仅实现功能」）。⇒ **要"海盗突袭"只差开这一个开关**（外加给 A 族卡 brawl 战术） |

## 三、调整方案草案

### 3.1 结构：每张 A 族卡 = 杂鱼波 + 头目波

```
waves: [
  { units: 3, hpShare: 0.15 },   // 杂鱼群：数量多、单个脆
  { units: 1, hpShare: 0.55 },   // 头目：血厚，最后登场
]
```
- **总血口径守恒**：实际总血 = `foeHpOverride` × Σ(units × hpShare)。
  上式 = 430 ×(3×0.15 + 1×0.55) = **430**，与现在持平 → **不破坏威胁曲线**。
- **头目血 = 杂鱼血的 3.7 倍**（0.55×430=237 对 0.15×430=65）✓ 兑现"头目强大"
- **顺带拿到战斗节奏**：先清一堆杂鱼、头目再入场（正好贴合"头目坐镇、杂鱼先上"）

### 3.2 样板卡演练：灰霾伏击团清剿令（现 28 kite / 430 血 / 1 僚机 / 0.69×）

| 项 | 现状 | 改后（示例） |
|---|---|---|
| 战术 | kite | **kite 保持**（"伏击"= 打了就跑，仍是混装族的一员） |
| 速度 | 201（0.69×，**慢于玩家**） | **≥1.15× 档**（按新口径精算后回写） |
| 编队 | 1 队 + 1 僚机 = 2 单位 | **杂鱼 3 队 + 头目 1 队 = 4 单位** |
| 总血 | 430 | 430（守恒） |
| 头目血 | 与杂鱼同规格 | **≈3.7 倍** |
| 头目伤害 | 同杂鱼 | ⚠ **引擎限制：仍同杂鱼**（除非加字段，见待拍板①） |

### 3.3 数值口径：把"装备差"做成族级，而不是逐卡打补丁

撤掉 `赤潮` 的 `foeDmgMul 0.27` 与 `蜃影` 的 `0.30`，改为**族级"装备差"系数**
（例：A 族全体伤害 ×0.85，统一挂在一个新字段上，全族一张表可查）。
⇒ 好处：族特色**可校验**（content:check 能查"A 族是否全体挂了该系数"），
也顺带补上我在商讨件漏洞③里说的"族特色没有可校验落点"。
