## 5. 踩过的坑（都是真实踩到的，照抄结论）

**合并与提交**
1. `docs/roadmap.md` 几乎每次合并都冲突：**保留两条**（本批在最上、对方条目原样），然后用 Node 脚本删 `<<<<<<< / ======= / >>>>>>>` 标记行——**别用 PowerShell 脚本改**（中文会坏）。
2. `git commit -m '...'` 的消息里**不能出现 `[ ]` 与 `'`**（PowerShell 会当通配/断引号）→ 长消息写进临时文件用 `git commit -F 文件`。
3. 跨分支真冲突实例：d2 已按船长裁决**退休 `foeDmgMul`**，而 main 侧两例测试仍用它 ⇒ 合并后必失败，正确修法是改成**单发直写 `foeShotDmg`**（不是恢复旧字段）。
4. `git merge --abort` 是你保持"工作树永远干净"的保险；发现取数时机不对就回滚，不要带着半成品往下走。

**探针（`npx tsx`）**
5. 探针是 CJS：**不能用顶层 `await`** → 写 `async function main()` + `void main()`。
6. 想渲染 `ui/*.tsx`（如属性面板文本）：先 `(globalThis as any).React = React` 再 `await import('react-dom/server')`，否则 `React is not defined`。
7. 有些导出名容易猜错：无人机参数表是 `DRONE_ROLE_SPECS`（不是 `DRONE_ROLES`）；核心包只导出**被显式 re-export** 的东西（需要就先在 `packages/core/src/index.ts` 补导出）。
8. 测装备属性/悬浮文本时，**别忘了 `crossFamilyLines` 是第二份渲染分支**（跨族搭车加成），文案要与主分支一起改——本会话就因为只改了一份踩过 `+$` 残留。

**体检与文案**
9. `content-check.ts` 的错误消息写在**模板字符串**里：**内部不能再嵌反引号**（会直接把文件语法打断）。
10. 玩家可见文案的搜索要用**字符串字面量**扫描（先剥注释），否则满仓开发注释会淹没结果；改文案后必做**产物核对**（在 `apps/desktop/out/renderer/assets/index-*.js` 里 grep 新串/旧串计数）。
11. 面板文案与引擎读数漂移是本项目的高发 bug（例：激光「威力衰减」面板自算 ×0.68、引擎实为 ×0.48）——**凡"显示值"能改成就地调用引擎函数，就改成调用**。

**文档与交付**
12. 文档-only 批次**不用跑测试**（船长 2026-09-11 明确），但要做 `git diff` 逐行核对 + 检索命令与结果。
13. 历史条目不回改：`docs/roadmap.md` 的老条目、`docs/design/*` 的取证行、`docs/review/*` 的快照都**保留原样**；要改现行描述就改现行文件，并在新条目里记明。
