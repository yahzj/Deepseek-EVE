# A 族全族贴脸：除劫掠狙击舰外，最小射程改为 1（2026-09-20）

> **状态：进行中**（已实现，待船长验收）
>
> **船长原话（照抄）**：「**将除劫掠狙击艇外的A族船，最小射程改为1.**」
> 集中提问后的回答：「**全动。**」（= ① 四张旧隐藏遭遇模板 `enc-pirate-1..4` 的射程覆写**一起改**；
> ② 附改前/改后读数）
>
> 范围：**只动 A 族（海盗）的近界（`rangeMinM`）**——舰级本体 + 卡面覆写；上限、单发、血量、速度、
> 战术、命中一律不动。**劫掠狙击舰（`foe-pirate-sniper`）及其为主体/杂鱼的卡全部豁免**（船长原话"除…外"）。

## 一、勘明的事实（改前）

A 族舰级共 **5 条**，全仓只在 `packages/data/src/foe-ships.ts` 定义一次：

| 舰级 | 战术 | 改前射程带 | 改前期望交距 | 改后 |
|---|---|---|---|---|
| 海盗快艇 `foe-pirate-skiff` | brawl | **1**~2600 | 521 | 不变（本来就是 1） |
| **劫掠护卫舰** `foe-pirate-corvette` | orbit | **326**~4275 | 2498 | **1**~4275 ⇒ 交距 2352（−146 m） |
| 劫掠狙击舰 `foe-pirate-sniper` | kite | 1255~9619 | 8364 | **豁免、一字不动** |
| 海盗头目舰 `foe-pirate-warlord` | brawl | **1**~2210 | 443 | 不变（本来就是 1） |
| **劫掠电子舰** `foe-pirate-raider` | orbit | **326**~4275 | 2498 | **1**~4275 ⇒ 交距 2352（−146 m） |

**期望交距口径**（`docs/glossary.md`「期望交距」条）：`min + tacticDesireFactor[战术] × (max − min)`，
`brawl 0.2 / orbit 0.55 / kite 0.85`（`balance.battle.tacticDesireFactor`）⇒ **近界参与带内插值**，
所以改近界同时把 orbit 的站位往前带了 146 m。

**机制上的真实效果**：近界 = 敌舰武器的**死区下沿** ⇒ 改后 A 族（除狙击舰）**贴到 1 m 也能开火**
（改前玩家钻进 326 m 以内，这两艘打不着）。

## 二、改了什么

| 文件 | 位置 | 改前 → 改后 |
|---|---|---|
| `packages/data/src/foe-ships.ts` | `FOE_SHIP_PIRATE_CORVETTE.rangeMinM` | `326` → **`1`** |
| 同上 | `FOE_SHIP_PIRATE_RAIDER.rangeMinM` | `326` → **`1`** |
| 同上 | 抬头 A 族表 + 两处"射程 −15%"推导注释 | 按新口径改写（**近界船长特批 1，上限仍 −15%**） |
| `packages/data/src/anomalies.ts` | `enc-pirate-1`（快艇）`rangeMinM` | `350` → **`1`** |
| 同上 | `enc-pirate-2`（护卫舰，主/僚两条）`rangeMinM` | `383` → **`1`**（两条都改） |

**不动**：
- **劫掠狙击舰**（1255~9619）与**以它为主体/杂鱼的三张卡**（`ano-redring-raiders` 赤潮劫掠舰队 ·
  `ano-haze-ambush` 灰霾伏击团清剿令 · `ano-mirage-hijackers` 蜃影导航劫持令）——它们的近界 = 狙击舰带
  ×变体倍率（`REDRING_RANGE_MUL` / `MIRAGE_RANGE_MUL`），是"除狙击舰外"的直接含义。
- `enc-pirate-3`（狙击舰主体）与 `enc-pirate-4`（头目舰主体）——**近界本来就是 1**。
- 所有上限（`rangeMaxM`）、`rangeMul` 变体倍率、单发/血量/速度/战术/命中/挂载件。

**⚠ 口径改写（§5.2 已向船长摆出后按其"全动"执行）**：2026-09-11 A 族数值批定的
「**A 族全族射程 −15%**」原先把近界也一起缩（`383 ×0.85 = 326`）⇒ 现改为
**「近界 = 船长 2026-09-20 特批 1（全族贴脸）· 上限仍按 −15%」**，旧推导只对上限生效。
没有测试/契约钉住过这两个近界值（`content:check` 的 A 族契约只管**速度**），故无契约冲突。

**⚠ 旧档兜底卡的守恒口径被本批打破（船长知情）**：`enc-pirate-1..4` 是**旧档隐藏遭遇模板**，
其射程覆写原为"迁移守恒（旧档兜底卡不许漂移）"冻结值 ⇒ 本批按船长令把其中**非狙击舰的两张**近界改成 1，
这两张卡的近界不再守恒（**上限、血量、单发、速度仍逐字守恒**）。四张卡都不在悬赏目录里。

## 三、回归守卫（`packages/core/tests/foe-ship-path.test.ts` 新增 1 例）

- A 族 5 条舰级：**除 `foe-pirate-sniper`（1255）外，`rangeMinM` 一律 == 1**；
- A 族卡面：**凡含狙击舰条目的卡整张豁免**；其余卡上写了 `rangeMinM` 的条目**一律 == 1**（含四张旧模板）。

## 四、读数（改前 / 改后 · 真引擎 A/B）

**解析面上改了什么**（`createFoeSpecs` 现算）：信标猎手悬赏（护卫舰）**武器近界 326 → 1**、
**期望交距 2498 → 2352 m**（−146）；`balance.battle.minDistanceM`（贴脸极限）= **200 m**
⇒ **旧口径下 200~326 m 是这两艘的绝对死区**（玩家若能压进这 126 m 的带子里，它们一炮不发）。

**对局面上有没有变化**（同一批种子、同一套配装，只切近界）：**没有**。

| 玩家档 | 战术 | 卡（威胁） | 改前 → 改后（胜率 / 中位耗时） |
|---|---|---|---|
| 中期 T2 大白鲨 · 5 导弹 MK1 · 无技能 | 贴脸 200m | 信标猎手悬赏 22 | 100% / 27s → **100% / 27s** |
| 同上 | 贴脸 200m | 伏击劫掠队 22 | 100% / 6s → **100% / 6s** |
| 同上 | 贴脸 200m | 海盗战团 45 | 0% / 25s → **0% / 25s** |
| 同上 | 中距（默认） | 海盗战团 45 | 0% / 33s → **0% / 33s** |
| 满配 王鲭 · D3 机群 · 满技能 | 贴脸 200m | 信标猎手悬赏 22 | 100% / 9s → **100% / 9s** |
| 同上 | 中距（默认） | 海盗战团 45 | 100% / 16s → **100% / 16s** |
| 贴脸快船 幼虫截击舰 432 m/s · 满技能 | 贴脸 200m | 信标猎手悬赏 22 | 100% / 104s → **100% / 104s** |
| 同上 | 中距（默认） | 海盗战团 45 | 100% / 126s → **100% / 126s** |

（表为节选；全表 = **3 档玩家 × 2 战术 × 3 张卡 × 5 种子 = 90 场/版本，逐格一致**。
自检：同一探针先打印"武器近界 326 → 1 · 期望交距 2498 → 2352"确认补丁生效，排除假阴性。）

**结论**：本改动**不改现有对局的胜负与耗时**——它兑现的是两件"设定与边界"：
① A 族（除狙击舰）**自 1 m 起即可开火**，死区取消；
② orbit 站位按期望交距**前压 146 m**。
⚠ 顺带实测到的一条事实：当前距离动力学下**玩家不容易把交距压进 200~326 m**（连 432 m/s 的贴脸快船档
也没压进去，交距由敌方期望距离主导）⇒ 死区在现版本更像"口径上的隐患"而非可稳定利用的打法。
