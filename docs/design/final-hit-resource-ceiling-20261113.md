# 抗性后实伤与最终资源产出向上取整

状态：三号 verify 已实现并完成专项检查；船长2026-11-14明确授权连同二号工作区合并推送，不部署。正在进行集成验收。

## 已确认口径

- 船长要求“抗性后的每次实际伤害也必须是整数”，玩家获得资源和物品也向上取整。
- 同一次命中的混伤、附伤及跨层扣血保留中间精度，完成后只对实际伤害总量取整一次；我方、敌方和无人机同规则。零伤害仍为零，旧档小数残血打空时受剩余血量限制。
- 最终离散产出在完整周期或独立奖励结算时向上取整；持续进度、概率、倍率、单件体积、容量上限不变，搬运已有资产不重新取整，不能超仓。
- 消耗、收费、退款、经济参数及持续恢复不属于本批；不新增玩法、状态机或存档版本。
- 功能域：战斗及资源产出；跨域修改已获本轮方案确认。沿用 `ceilFinalQuantity` 及现有结算单点，不在库存底层全局替换取整规则。

## 实现与结果

- 战斗：`applyDamageExact`保留层抗与混伤精度，`finalizeHitDamage`补整次命中的取整尾差，防止相减噪声重复加点；主副伤害在敌舰唯一入伤口合并，死亡与飘字共用结算结果。齐射限额不足1点的余额不放行小数伤害，损管仍保留至少1点结构。
- 资源：自动探索普通资源最终件数向上取整并以真实容量封顶；稀有奖励命中次数保留原概率，命中后的数量取整。墓场/遗迹新稀有堆数量取整；AI富矿加成后补齐主控已有的容量裁切。
- 采矿、精炼、实验室、制造及多数奖励已使用最终数量取整单点，本批不重复改写。预览与实际收货沿用原有同源函数/冻结快照，已有在途收益不重算。
- 最终合并专项35文件790项通过；T2六项技术检查、24小时经济体检、桌面构建和仅合成档的存档往返通过，往返差异0处。未进行集中验收阶段的整库回归，未读取个人档。
- 已知边界：旧档若存在小数库存或小数退款账，仍可能经过既有`addItem/addWare/removeWare`的取整逻辑；本批没有新增搬运取整，也未迁移旧资产，不能据本批宣称这些旧异常资产全面守恒。小数剩余血量打空时，实伤以剩余血量为限。
