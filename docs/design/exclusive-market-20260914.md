# 专属内容上市场（只收不卖）＋ 专属无人机一次性图纸（2026-09-14 · 状态：已确认）

> 船长原话（照抄，本批全部裁定的来源）：
> - 「**允许玩家挂卖，顺便检查下其他物品，维持所有物品允许玩家挂卖**」
> - 「**所有专属的东西，价格翻4倍**」（范围选定：**凡专属，含洞内 88 条**）
> - 「**无人机也出蓝图，专属无人机出一次性蓝图（专属无人机的一次性蓝图，每次制造50架）**」
> - 「记得备注**只收不卖**」
>
> 集中提问的其余裁定：**范围** = 凡无市场行的可获得内容**全补**（105 条）· **定价** = 材料价值反推
> （全表锚"料/价 45%"）· **稀有度与收购** = 奇货档（exotic）＋ NPC 照常收 · **露出** = 照常入市场页与手册图鉴 ·
> **无人机渠道** = 各自走原渠道 · **产出数量** = 仅无人机那 3 张 50 架/次 · **特例** = 沙猫级与邓氏鱼级**不补**。

## 一、口径

| 项 | 结论 |
|---|---|
| 补行数量 | **106 条**（原无市场行的 103 条 + 新增 3 张无人机一次性蓝图）⇒ 市场目录 354 → **460 行** |
| 行属性 | 一律 **`playerBuyable: false`（只收不卖）** · `rarity: 'exotic'`（奇货）· **不设声望门槛** |
| 玩家能做什么 | **挂卖**（自定价挂单，escrow 托货）· **市价卖给 NPC 收购单**（奇货 1%/窗 × 建站扩容）· 撤单退回原库存 |
| 市场不做什么 | **不出售现货** ⇒ 渠道与稀缺性不变（洞内遗迹打捞 / 窝点高级箱） |
| 价 | **基准 × 4**（专属口径）：① 有料单的 = `材料 ÷ 0.45`（全表锚）× 4；② 窝点专属件（无料单）= **同槽位最高档常规件** × 4；③ 专属无人机 = **自带货值 `baseSellPriceIsk`** × 4；④ **舰船图纸 = 舰价 × 0.5**（守 2026-09-14「一次性舰船蓝图」规则） |

**价表（实测区间）**：虫洞舰船 **230.6 万 ~ 1536 万**（中位 744 万）· 虫洞装备 **267 万 ~ 1200 万**（中位 645 万）·
图纸（含 3 张无人机图纸）**115 万 ~ 932 万**（中位 490 万）· 窝点专属装备 **766 万 ~ 1200 万** ·
专属无人机 **2.4 万 / 4.8 万 / 8.8 万** · 无人机图纸 **120 万 / 240 万 / 440 万**（= 产物价：无人机价 × 50）。

## 三、契约改动（体检常驻）

| 契约 | 改动 |
|---|---|
| 「**挂卖可达契约**」（新增） | ① 任何市场行不得 `playerSellable: false`；② 可获得内容必须有市场行，例外表只放 **沙猫级 / 邓氏鱼级**（逐条写理由）；③ **专属内容的市场行必须只收不卖** |
| 「来源唯一契约」 | 窝点专属件：原「**不得有市场卡**」→「不得有**可购买**的市场卡（只收不卖行允许）」；原「不得有蓝图」→ **允许一次性蓝图**（`singleUse` 必须为真）；池成员从"模块/物品"扩到**蓝图** |
| 「蓝图价格口径」 | 新增**专属一次性图纸**豁免档（31 张）：**书价 = 产物价**，不套档位系数、不比料/价带（掉落物没有"市场垄断加价"那一层；料/价恒 ≈11.25% 是 ×4 口径的数学必然） |
| 「窝点契约」 | 专属装备池成员允许**蓝图 id** |
| `rarityTier` 表 | 补 **106 键**（值 4 = 奇货层；契约"表键数 = 市场卡数"守） |

## 四、边界与取舍

1. **沙猫级（协会保底艇）与邓氏鱼级（无渠道壳体）有意不补**——前者防"卖光起步资产卡死新档"，
   后者没有任何获取渠道（补行等于给拿不到的东西标价）。
2. 无人机**货值** `baseSellPriceIsk` 同步 ×4（24,000 / 48,000 / 88,000）——它与市场行同值是全表惯例
   （制式 4 型上两者逐值相等），改价不同步会让 AI 收益估算 / 拆解估值 / 丢货排序读到旧值。
3. 舰船（15 艘虫洞定制船）的 `priceIsk` **仍为 0**（定制船口径：无市场行或只收不卖 ⇒ 必须 0）。
4. 「只收不卖」= 市场不出售现货；**NPC 照常收购** ⇒ 玩家挂卖之外还能市价出手（与 AI 核心贝塔/阿尔法同模式）。
5. **存档零迁移**（纯内容表 + 契约；`recAcc.blueprint` 为新增可选字段，老档缺省空）。
