# M4 设计文档：战斗装备 / 内容扩充 / 数值体检工具

## 目标

1. 补上战斗成长线（M3 预留）：**炮台槽 + 舰载炮台模块**，火力不再只吃炮术学；
2. 内容扩充：星图加深（+2 星系）、悬赏加高（威胁 75/90），并让声望带来直接经济回报；
3. 数值体检工具：模拟脚本自动对比三种新手策略的 24 小时产出，调数值不再靠猜。

## 玩法规则

### 炮台槽与火力公式（core）

- 舰船装备槽扩展为三个：采集器槽 / 货舱槽 / **炮台槽**（存档 v5，老档自动补空槽）。
- 新装备：舰载轻型炮台 MK1（火力 +25%）、舰载重型炮台 MK2（火力 +60%）。
- 火力公式：`火力 = (基础 10 + 炮术学 2/级) × (1 + 炮台加成)`；
  远征出发时锁定火力，悬赏卡预估胜率实时反映炮台加成。
- 新蓝图（延续 M2 制造链，矿物消耗口扩大）：

| 蓝图 | 材料 | 耗时 | 制造费 | 蓝图价 |
|---|---|---|---|---|
| bp-turret-1（MK1 炮台） | 三钛 2000 + 类晶体 500 | 20 分 | 2 万 | 1.2 万 |
| bp-turret-2（MK2 炮台） | 类晶体 1600 + 超噬 500 + 三钛 6000 | 100 分 | 15 万 | 9 万 |

### 内容扩充（data）

- 星系 +2：奥罗荒环、星髓迷宫（母港最短路约 15 / 10 分钟），航线 3 条新边；
- 悬赏 +3（声望阶梯延到 12 级）：奥罗武装残骸群（威胁 75，42 万 ISK）、
  星髓巢穴（威胁 90，65 万 ISK）；
- **声望贸易回馈**：深空工业协会声望每 1 点 → 空间站收购价 +1%（上限 +15%），
  声望 = 解锁门槛 + 直接收入加成。

### 数值体检工具（tools/balance-check.ts，`npm run balance`）

三种自动策略各挂机 24 小时（30 秒步长，真实引擎推进，忽略离线/远征）：
- A 原矿流：只练采矿技术，满舱卖原矿；
- B 精炼流：+精炼学 5 / 高级回收 5，精炼成矿物出售；
- C 装备流：B + 采矿护卫舰 5，并按路线自制 MK1 采集器 → MK1 货舱 → MK1 炮台 → MK2 采集器。

输出：24 小时末 ISK / 最终舰船 / 里程碑（买船、造装备时点）/ 每小时 ISK 曲线。
首次运行结果（M4 数值基线）：
- A ≈ 211 万 ISK（第 13 小时买鲸吞）；B ≈ 565 万；C ≈ 664 万；
- 结论：精炼流收入约为原矿流 2.7 倍（练精炼技能投入划算）；
  装备流再 +17%（前期慢，后期加速——投资回报成立）。
