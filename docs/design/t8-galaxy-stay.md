## 需求与确认口径（两轮问答 + 数值定稿）

- 原句：点击星系可直接"前往并停留"（悬赏完成后停留便于反复刷赏金）；重复刷同悬赏需冷却，
  间隔受舰船扫描属性影响。
- 定稿：
  - **Q1**：采矿返航目标 = 最近空间站（母港 ⊕ 未来 T9 副站，先立接口）；悬赏加**连续出击**；
    悬赏与扫描完成后**原地停留**；不设单星系驻地——船需要回空间站是为了**卸货/维修**（无远程入库）；
  - **Q2 甲**：重复冷却 = `10 秒 × (500 ÷ scanResMm)^0.5`（基础大幅缩减至 10 秒；≥1 秒；
    按当时出击船锁定）；
  - **Q3 甲**：只对同一悬赏生效，卡片显示倒计时；
  - **Q4**：B2 赏金衰减后置，按经济曲线再定；
  - **自动停环条件定稿**：耐久阈值 **0.5**；若货仓内有**修理组件类物品**（后续内容补充，
    seam = `ItemDef.repairRestore`），连续出击自动消耗修理组件（可连续多件）恢复耐久，仍不足才停；
    战败自动返航并停环；**连续出击开关落档**（重启自动恢复）。

## 位置模型（轻量，Q-C 甲）

- `awayGalaxy`：空闲野外停留（胜利/扫描完成后所在星系）；null = 在空间站（当前唯一 = 母港）。
- `transit`：显式"返航空间站"行程（野外 → 站；当前船跃迁/技能、出发锁定；到站清 awayGalaxy；
  活动栏倒计时、不可取消）。
- 一切作业出发地 = `awayGalaxy ?? 空间站星系`（origin 感知：远征/扫描去程、矿带初始出航均按
  当前位置计程）；作业进行中位置由作业自身表达；`mining.originGalaxy` 记录野外起步（首次到带清空，
  自动循环以空间站为基准）。
- 守卫：野外空闲不可换驾驶/维修驾驶船；`repairShip` 驾驶船在野外拒绝；CargoPage 装卸与出售
  在野外被 UI 拦截提示；`loseShip` 等不产生冲突。
- `stationGalaxyIds()` seam：当前 = [母港]；T9 副站建成后并入并改"最近空间站"解析。

## 悬赏与扫描行为

- 远征：去程(out，从当前位置) → 交火 → **胜利 = 结算 + 停留目标星系**（奖励/战利品/声望入账不变，
  冷却计时开始；目标=母港星系则直接回港语义）；**失利 = 自动返航**（既有惩罚机制不变，停环）。
  召回仍即时回港（沿用）。
- 扫描：作业 = 去程 + 就地窗口（**无自动返航段**）；窗口完成 → 点亮 + **停留**该星系；
  手动终止 → 窗口进度保留 + 自动返航空间站（去程即终止 = 从出发地折返，母港出发直接回港）。
- 悬赏卡：去程/交火时长分列 + "胜利后停留（可连击/返航）"；冷却倒计时 chip；出发按钮冷却中禁用。

## 连续出击（半自动 + 落档）

- 开关落档（`autoLoopAnomalyId`）；在线心跳（renderer tick 每秒）驱动 `advanceAutoLoopBounty`：
  忙/冷却 → 等待；**自动停环** = ① 货仓剩余 < 本单预期缴获体积（硬边界，无远程入库）
  ② 耐久 < 0.5 且修理组件耗尽 ③ 战败/数据异常/目标不可达；
  出发前耐久 < 0.5 先自动消耗货仓修理组件（可多件）——内容补条后自动生效。
