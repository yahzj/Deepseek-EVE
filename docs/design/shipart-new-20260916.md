## 三、落码

**① 形（`apps/desktop/src/renderer/src/ui/`）**
- 新文件 `shipArtWh.tsx`：虫洞族 15 艘，**按族分节**（A 掠袭 / C 巢群 / D 陵墓 / E 巨构 / G 亡军）；
- `shipArt.tsx`：鹦鹉螺 / 巨齿鲨 / 邓氏鱼 3 艘（归入既有掠食者武装族）+ **`...SHIP_ART_WH` 并表**。

**② 语言（沿用 `docs/design/ship-battle-art/README.md`，不自造）**
- 画布 **240×110**、**舰首朝右**、无类元素 = 主轮廓（currentColor 2.2）、`shipart-panel` 面板线（1px/40%）、
  `shipart-acc` 族色细线、`shipart-accf` 族色实心点；
- **族血统**（同 README §三 敌族分型表的造型关键词——这 15 艘本就是那五族的舰）：
  A 掠袭 = 粗短破旧 + 角旗天线 + 斜排劫掠炮 · C 巢群 = 有机曲线 + 发光裂隙 + 非对称肢节（**固定磷光绿**
  `shipart-volt-g`/`-fill-g`）· D 陵墓 = 残破古典舰体 + 长舰首 + **冷青磷光**（`shipart-volt-i`/`-fill-i`）·
  E 巨构 = 厚重装甲层 + 断裂截面 + 外露桁架 · G 亡军 = 蜂窝舱段 + 补丁帆 + 吊臂；
- **同族三档 = 体量阶梯**（护卫舰短、驱逐舰长、巡洋舰宽厚），轮廓族型一致、个体差异在舰桥/炮位/舱段；
- 另 3 艘按**个体特征**画：鹦鹉螺 = 分段螺旋装甲环 + 测绘桅杆天线阵 · 巨齿鲨 = 舰首巨齿獠牙 + 三联主炮 ·
  邓氏鱼 = 头部装甲盾板 + 四联舷炮 + 双联主炮。

**③ 挂点（`ui/shipMounts.ts`）**：18 艘逐条补 `engines`/`muzzles`，坐标**取自本批图形几何**
（喷口 = 舰尾开口左缘中点、炮口 = 炮管口端）；C 族有机舰 `engines: []`（无喷口 ⇒ 不画尾焰，与敌族 C 同款）、
哨戒电子舰 / 后勤舰 `muzzles: []`（无原生炮 ⇒ 回退舰艏锚）。**两表至此 43/43 齐备**。

**④ 防回潮哨（`tools/content-check.ts`）**：新增「**舰船图形契约**」——`ships.ts` 每一艘船必须在
**形表**与**挂点表**各有一条（静态读 UI 源码，与「图标覆盖契约」「市场类型契约」同款，不引 UI 依赖）；
缺哪边就点名报错并写明后果（回退兜底剪影 / 尾焰回落单焰）。

**⑤ 复用件（`tools/shipart-preview.ts` + `npm run art:ships`）**：把**全部 43 艘**的战斗图形渲染成
一张静态总览页（按舰种分节、★ 标本批），供船长目测或新人比对——起因是虫洞族舰在存档里不易凑齐、
逐艘进游戏看代价太高。做法 = 从源码文本抽 JSX 转 SVG（**与真源同源**，改形后重跑即同步）。

## 五、已知取舍（如实登记）

1. **体量阶梯不吃图形尺寸**：T1~T5 的显示大小由既有 `SIZE_BY_TIER` 机制控制（与形无关）；
   本批只保证同族三档的**轮廓体量有差异**（护卫舰画得短、巡洋舰画得宽厚），不做像素级等比；
2. **族色件用固定色**：C 族磷光绿 / D 族冷青是资产内固定色（与敌族形同款），
   主轮廓仍随 role 色（掠食者武装暖红 / 甲壳重装银灰）⇒ 与敌舰的区分继续靠"左右列 + 翻转"；
3. **预览页不是游戏画面**：不含战斗布局、尾焰、体量阶梯 ⇒ 只用于看形，不代替真机验收。
