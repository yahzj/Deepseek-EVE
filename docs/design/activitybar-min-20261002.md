## 1. 船长原话（照抄）

> 「给旧版界面的活动窗口添加个最小化的按钮，点击后活动窗口高度缩小，只显示标题（写着活动的那一行）」

## 2. 现状（动手前核实）

- 「旧版界面的活动窗口」= **`panels/ActivityBarClassic.tsx`**（该文件头注释原文就写着
  「这就是船长要的"旧版活动窗口"」）；新版是 `panels/ActivityBar.tsx`，由 `ui/AppShell.tsx`
  按版式二选一渲染（classic / modern）。
- 它是**左侧 150px 定宽竖列**（2026-09-25 船长令「将活动栏放到左侧，竖列显示」），
  `flex: 0 1 auto` ＋ `max-height: 100%` ＋ `overflow-y: auto` ⇒ 超出时列内滚动。
- 顶上那一行 `.app-activitybar-hd` 里，除标题「活动」（`ui.ActivityBar.025`）外**还挤着**
  两枚 AI 徽标（副船 ×N / 工业 ×N）与星系扫描进度条。
- 活动栏与日志侧栏的收起机制**无关**（`logCollapsed` 是日志那一侧的，两者不共用状态）。

## 3. 船长裁决（2026-10-02 四问四答）

| 问 | 取 |
|---|---|
| 最小化后顶上那行留什么 | **甲：整行保留**（「活动」＋ 两枚 AI 徽标 ＋ 扫描进度条），只把下面两组收起来 |
| 收起状态要不要记住 | **乙：不记** —— 每次进游戏都是展开的 |
| 按钮形态 | **甲：小图标按钮**（收起 ▾ / 展开 ▸），悬停写说明；**位置改到标题行最左侧**（船长补答） |

## 4. 逐条改动

1. `panels/ActivityBarClassic.tsx`：`useState` 一个 `collapsed`（**不落盘**，每次进游戏展开）；
   标题行**最左端**加一枚小图标按钮（▾ / ▸），点一下收起、再点展开。
2. `panels/ActivityBarClassic.tsx`：收起时只渲染标题行那一行 —— 下面两组（玩家活动 / 技能训练等）
   与其它块整块不渲染（与「作业按钮只在真能用的时候才出现」同一套做法：能不给就不给，界面不藏内容）。
3. `styles.css`：`.app-activitybar.is-collapsed` 的定高与内边距（收成一行高），
   以及那枚小按钮的样式（**优先复刻同级相似项**：照 `.app-activitybar-ai` 那族小图标按钮写）。
4. l10n：新增 2 条（`ui.ActivityBar.070` 收起、`071` 展开）—— 中文只进 `table.ts` 的 `zh` 列。
5. 生成件 `ui/layout-css/styles-{modern,classic}.css` 重跑（不手改）。

## 5. 范围 / 不做

- **只改旧版活动栏**；新版 `ActivityBar.tsx` 不动（船长明说"旧版界面"）。
- 不做"记不记得住"的持久化（船长取乙）。
- 不动 `.app-workspace` 的其它排布；收起后腾出的竖向空间自然留白（活动栏那一列变短，
  整行高度仍由主内容区决定 ⇒ 不会把主区挤动）。
