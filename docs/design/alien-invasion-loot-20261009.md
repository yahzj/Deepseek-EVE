| 基准价 | 4,800,000信用点 |

无技能、用基础爆破弹药时单发84，命中前名义DPS约9.23；同条件动能炮台MK3约10.47。本件用慢射击和高CPU换长射程与辅助破抗效果。以上仅为静态参考，最终强度须按真引擎专项复核。

酸蚀边界待确认：

- 每次命中指定的敌方舰船后，该舰装甲与结构的三系抗性各降低10个百分点；不按原抗性乘0.9。对护盾、敌方无人机无效。
- 每层15秒，同一目标上不同装备、不同友舰的命中直接叠加，无额外多件惩罚；每层独立记录到期时刻，不刷新旧层。
- 推荐本次命中的直接伤害先结算，随后新增酸蚀，后续伤害享受破抗效果；射失不附加。
- 多层允许把抗性降为负值，但遵守现有抗性下限-90%；不是额外新增层数上限。
- 必须从目标基线与当前有效层数重算，不能到期简单加回10个百分点，以免触底后恢复错误或长期数值漂移。
- 对存活目标跨波保留直到到期，新出现的敌人不继承；目标死亡或整场结束清除。读档、离线结算按同一游戏战斗时钟恢复和过期，不刷新持续时间。
- 爆炸层位克制保持现状；近盲带命中且造成减伤后的伤害仍触发酸蚀。不同型号炮台分组、同型号多件合并开火时，也须保留实际命中的逐件层数，不按整组合并成一层。

### 增压加速腔

建议内容ID `mod-alien-pressure-chamber`。

| 参数 | 数值 |
|---|---:|
| 槽位 / 类型 | 低槽 / 辅助 |
| CPU | 30 |
| 初始机动速度加成 | 5% |
| 满额机动速度加成 | 25% |
| 线性增长时间 | 60秒 |
| 基准价 | 2,800,000信用点 |

公式：`p(t) = 0.05 + 0.20 × min(1, max(0, t) / 60000)`，`t` 为整场战斗已推进的游戏毫秒。0/30/60秒分别为5%/15%/25%，之后维持25%。

- 只改变装备所属舰船的战斗机动速度，不影响跃迁、运输、采矿返航或全队速度。
- 同舰与推进器、其他速度加成装备共用速度递减池，按当时有效加成重新排序后折权加算；不为这件再开独立乘区，不重复计入初始5%。
- 同型第1/2/3件权重沿用现有曲线，约100%/87%/57%，无其他速度装备混装时满额三件合计约60.99%；不另设总速度上限。
- 整场计时跨波不重置，进入下一场重新从5%开始；暂停时不按墙上时间增长。读档和离线按同一游戏战斗时钟继续，不重置蓄压。
- 继承现有推进器周期的激活/冷却规则，不让动态加成改变装备之外的推进机制。实现时验证无重复相乘和每拍累计漂移。
