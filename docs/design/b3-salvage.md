## 一、定位与目标

EVE 式残骸打捞的文字挂机化：
1. **依附战斗系统**——先刷怪（产生残骸密度），再打捞（采矿式作业），最后回收（开箱式精炼）；
2. 高槽分配策略：打捞器是**无伤害高槽件**，与炮/矿枪/无人机件争位 → 战斗船与打捞船专职分工；
3. 挂机友好：AI 副船可打捞/回收（AI = 玩家分身，受核心效率惩罚 40/50/60/75%），不强制手动；
4. 补上物流组载体：残骸 = 大宗重货 → 货仓/运输/（拟扩展）压缩技术有真实用途。

## 二、残骸密度模型（星系级标量，已定稿 v4+）

- **基础密度 base = round(10 + 15×(1 − security))** ∈ [10,40]（新手 10 → 最危险 40），只随危险度；
- **保底线 = 5**（全图固定）：密度 ≤5 打捞不扣密度、进保底稳态（半效）；
- **击杀注入**：该星系远征胜利（主控/AI）Δ = **威胁 × 0.4**，无上限；
- **闲置漂移**（该星系无打捞进行中才结算）：>base 线性衰减回 base，**48h** 放完；<base 线性回升到 base，**4h** 回满；离线照算；
- **打捞扣减（放干守恒，防刷密度印钞）**：每轮（每台每周期）扣 = 当前超出保底线量的 **2%（1/50，N0=50 台·轮）**，指数式；超出量趋零时进位到保底线进保底稳态。同速率守恒参照：4×MK1（1440 台·轮/h）≈ 玩家 50 场/h ×威胁45 的注入，平衡点 ≈ 星系基础密度；
- **保底稳态**：密度 ≤5 → 不扣密度，单轮仍产 1 具（体积 ×0.5），可持续半效捞；
- 稀有残骸计数：每星系预留字段，本里程碑不实现（将来 = 高级开箱口子）。

## 三、打捞动作（作业形态，已定稿）

- **采矿式作业**：船抵达目标星系 → 自动持续打捞 → 满仓自动返港卸入仓库 → 任务结束（不自动续，手动再派）；占主控工作位（与采矿/扫描/精炼炉互斥守卫同采矿口径）；
- 主控与 AI 副船都支持（AI 任务型：吃副船名额 + 核心效率 40~75%）；
- 门槛：船上装打捞器即可；星系密度任意（含已到保底线的）；无战斗；
- **低安打捞 = B1 暴露**：往返/作业中掷遭遇骰（打捞船被抢 = 残骸货损，上限沿用 lowsec-survival）；
- **返航节奏平衡（与采矿对齐）**：打捞满载 m³/h = 同期采矿 m³/h × **1.2**（趟次稍多于采矿——残骸重、单趟价值略低但回炉价值略高，运输是选择不是惩罚）。

## 四、打捞器（高槽件，已定稿）

- 新族：高槽 rack、无伤害；名称/市场文案待装备定名步；
- 档位：MK1 / MK2 / MK3；**周期 10s / 8s / 6s**；**CPU 2 / 6 / 15**；
- 每台每轮结算一次捞取，升级 = 减周期不增产；多台叠加；
- **记账（乙案，2026-09-05 船长拍板）：残骸计数 = 体积**——入舱 m³ = 该型号单份体积
  （威胁 ×0.06）× max(0.5, 密度/10)（密度 5 = 半效保底、10 = ×1、更高更肥）；
- 获得渠道默认随 C2 体系：MK1 常驻现货，MK2/3 稀有市场 + 蓝图门槛（待装备数值步细化）。

## 五、残骸型号与回收开箱（已定稿）

- **型号按敌群注册**（悬赏卡/低安遭遇群，每卡/群一种）：默认基础体积 = **威胁 × 0.06 m³**（T12 ≈0.7、T45 ≈2.7、T96 ≈5.8；卡级可覆盖）；回收产出 ∝ 体积 × 型号系数（不成 1:1）；
- **回收 = 开箱**（精炼炉新增“残骸回收”批）：
  - **批 = 10 m³ / 25 秒**（劳动者 100% → 1440 m³/h，与 4×MK1 打捞量级同速；**残骸计数 = 体积，item unitM3 = 1**）；AI 核心按效率档；矿精炼炉同款循环/占位（尾批不足按实有）；
  - 每具产出 = **保底矿物**（确定性，按危险度池抽取）+ **彩头**（概率）；
- 彩头分层：① 基础常驻件直出（无蓝图门槛的 MK1 系民用件——不产其蓝图碎片）；② 低安（sec<0）残骸箱低概率 MK2；③ 蓝图碎片（MK2/3/异星等不直出的高级件，碎片集齐逆向解锁蓝图；**MK2 100 / MK3 1000 / 异星 10000 片**）；
- 市场蓝图出现率（除最低级蓝图）随本里程碑进一步调低（内容工作台表改动）。

## 六、经济锚（已定稿 + 校验行待模拟）

- **保底收入锚**：打捞+回收全链保底 ISK/h = 同效率下采矿环（采→精炼→卖）的 **×1.1**（“略高”：残骸需战斗前置，采矿随时可挖）；彩头 EV ≤ 保底 **10%**；
- 采矿参照 X（平衡检查中段口径 ≈ 50,000 ISK/h，随实现期精确化，线性缩放）；
- 矿物池三档（按星系基础密度）：
  | 池 | base | 构成（权重） |
  |---|---|---|
  | 常 | 10~19 | 三钛 65 / 类银 30 / 类晶体 5 |
  | 险 | 20~29 | 类银 45 / 类晶体 35 / 超噬 12 / 同位 8 |
  | 危 | 30~40 | 类晶体 30 / 超噬 25 / 同位 30 / 星髓 13 / 冥铁 2 |
- 单方价值 U 为最终旋钮：`U = 目标保底额 ÷ (每时捞取总体积)`，实现时按三条校验行对齐（4×MK1 参照 / 手动 100% / AI α 75% / 4×MK3 极限）；
- 不排斥纯 AI 流（AI=分身 + 效率惩罚天然拉低）。
