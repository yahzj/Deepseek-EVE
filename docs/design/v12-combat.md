> 现行入口：本节为2026-10-09归档后的战斗规则摘要；后文V12原设计保留沿革，不以旧步长、单船边界或未完成标记覆盖当前代码。多波规则另见`wave-battles-20260909.md`，入侵族机制见`weekend-invasion.md`及`corona-balance-20261003.md`。

## 现行战斗与验证入口

- 共用内部步长10毫秒、补算上限40万步；齐射承伤保险仍按独立100毫秒窗口归组，低速航程按实际步长缩放。界面心跳与60秒自动保存不因内部步长变短而改变。
- 同型武器组共用装填和弹药账，每门炮独立判命中、结算伤害和演出；敌舰`gunCount`分摊原组总伤，不把旧`shotDmg`再乘炮数。整数余数守恒，光束仍必中、无人机逐架独立。击沉目标后剩余炮重新选活目标，近防、多目标和三连发沿同一结算入口。炮数以敌舰源参数为准，不维护第二份全表。
- 新开战的所有玩家攻击条目先完成各自最终装填，含基础炮、舰载武器、近防与无人机；敌方首波和其他装置周期不改。旧在途不补首轮延迟；换波保留余额的最新修复见多波文档§七，不反算已经同步的历史相位。
- 每舰无人机独立首次出击队列，相邻基础等待500毫秒，哨戒也排队。先完成原初始装填，实际可攻击时逐架释放，不积攒到同拍放整群；已放飞架次后续按攻击周期，复活机重新排队尾。掠袭机库每件将首次等待乘0.8，下限10毫秒，不缩短攻击周期；旧档缺首次标记按已放飞续战。机群存活数与已出击数分开显示。
- 演出消费绑定具体战斗对象及序号代次，换场或读档对象更换清掉瞬时视觉账本；不重播超过现实200毫秒的陈旧事件。事件环至少48条、保留最近现实2秒跨子步事件、硬上限512，读档保留来源、机型、目标及机制标记；演出缓存不改变伤害。
- 玩家跃迁规避装置被敌舰舰炮命中才触发，朝自己的期望交距移动，最多2000米、冷却16秒；已到目标或无法移动不耗冷却，MISS不触发。敌方12秒不改，位移仍在既有三段等待处兑现，排队与对侧禁火保持。
- 捕获网每个战斗片恢复未减速的规格，再施加当前有效网一次，避免长步重复乘算；断开后恢复。双向连线按真实施放舰/目标tag定位，僚舰投网同样显示束缚与详情；不调巢母基础240m/s，手册只显示基础m/s，不显示倍率后缀。有效挂载取条目覆盖，否则继承舰级；手册空覆盖不偷偷补默认件。
- R族族格只影响敌方期望距离，不替换开场距离，也不改写玩家期望；按实际入侵星系记忆偏好的修复见`weekend-invasion.md`。开场距离专项仍有历史夹具补充建议，保留`r-open-distance-20261002.md`，不因当前实现已合入而宣称该测试缺口已补齐。
- 顶部使用紧凑旧式装填条：武器射程、装填和状态进入下拉武器列表，同舰同型号合并数量，不同舰/档/弹系/周期/射程不强并；无人机按本舰机型聚合。外部真实周期装置自动换行，读秒随进度条；被动件不造周期，缺弹/缺料/损失/沉船不伪装就绪。列表支持悬停移入、固定点击、触屏、键盘及Escape，限高内滚，不撑高战场。
- 装备负面由`equipmentPenaltiesOf`等核心单点合成，正向收益不变；随同件收益边际递减的负面使用同一排序权重，全额族权重1。装填与主动周期增加逐件相乘，速度/命中/射程乘保留比例，抗性按有效百分点相减，固定减速相加，安全下限沿原规则。巨构协处理器CPU+90不改，每件装填代价8%；影响基础炮、武器、无人机及维修/盾充/力场/网/储备甲板，叠光步长和下限同乘，不改连发发间隔、首次出击队列、推进器、隐身、采集和被动回盾。旧账当前截止不清零，后续从基础周期重算。
- 护盾充能力场每路只恢复其他存活队友，实际恢复至少一舰才扣施放者最大护盾10%，不随目标数重复扣、不溢出扣甲壳；不足不发动、无缺盾目标不扣，失败照样进入下一周期。恢复量仍按施放者最大护盾及原衰减比例，目标按自身容量封顶；同型一路、不同型独立，中槽自回盾不变。
- 敌方近防续战时若调度缺失，按当前波判据威胁和已有机群池补建，不重建机体血量；低威胁/明确禁用不强开。共用反击许可在5秒窗内没有任何实际尝试时保留，至少一舰选到目标尝试后消费，MISS也算；仍为当拍就绪舰各一次，不给未就绪舰逐艘积攒。哨戒近距暴露、伤害/命中/抗性不改，不承诺每场必掉机。

## 一、总架构（统一引擎，无第二口径）

- 远征 = 两阶段：`out`（去程航行，沿用固定时长机制）→ 到港自动进入 `battle`（持久状态机推进）
  → 战斗结束自动 `back`（返航）→ 到家结算战报
- 战斗 = **确定性事件步进**：不逐帧，按下个决定性事件切段（装填完成开火 / 距离穿越射程边界 /
  单位击破 / 编队全灭）；在线每秒小步、离线一次性大步长——同一 `advanceBattle(dt)` 代码路径
- 在线可"观战/介入"（P2 小剧场：距离条/双方血条/事件流 + 手动拖距离条）；介入只是改状态里的
  期望距离（落档，离线沿用）——不产生第二套结算
- 预估胜率 / AI ≥80% 门槛 = 同一引擎的"自动战术期望推演"（确定性），与结算同源

## 二、编队单位模型（NvN 预埋）

- 战斗双方 = 单位列表；单位数据包 = 三层血量/层抗 × 武器 × 机动（速度/机动/信号）× AI 控制器
- v1：我方 = 玩家主控船 1 单位（无人机并入主船武器组，不单独成单位、不损毁）；
  > **⚠ 此项已作废**：无人机现为**独立单位、会被敌方近防炮击落并永久损失**（2026-09-10 船长定，
  > 见 `docs/design/drone-losses-20260910.md`；`combat.ts` 的 `pdThreatFloor` / `settleDroneLosses`）。
  敌方 = 目标主体 1 单位 + 僚机 0~2（escorts，每架 threat×0.5 独立单位）
- 目标选择（v1）：每单位攻击"射程内最近的可开火敌单位"，同距按单位序集火
- 敌方单位由 `threat` 运行时换算生成（见六）——AnomalyDef 只加叙事字段

## 三、命中与伤害公式（每次开火）

```
开火条件    weapon.minRangeM ≤ 距离 ≤ weapon.maxRangeM（过近/过远不开火；
            **敌方例外（2026-09-05）：近盲带内不停火、伤害 ×blindDmgMul**，见文首更新）
距离衰减    distFactor：minRange 端 = 1.0 → 线性降至 maxRange 端 = weapon.falloff
命中加成    effHitBonus = attacker.hitBonus（**信号半径/扫描分辨率不参与公式**，2026-09 船长拍板）
单发命中    hit = clamp(hitMin, hitMax, (weapon.hitRate + 攻方 effHitBonus − 守方 effEvasion) × distFactor)
            ⚠ **2026-09-15 船长改判**（原话「改为从初始命中中扣」）：回避**先扣、余量再乘距离衰减**；
            旧口径 `(基础 + 加成) × distFactor − 回避`（回避 = 不随距离缩水的固定点数）**作废**。
            df = 1（贴到近端）时新旧完全等价；越远回避越被衰减稀释。
            打机群（`droneHitChance`）把 distFactor 固定为 1 ⇒ 该路零变化。
单发伤害    dmg = ammo.dmg × weapon.dmgMult × (1 + 0.05×炮术等级) × (1 + ship.powerBonus)
伤害结算    类型 × 层位克制系数 × (1 − 层抗)，逐层消费（盾→甲→结构）；结构归零单位击破
```

## 四、武器 / 弹药 / 无人机 / CPU 规则

- ModuleDef 炮台家族新增：`maxRangeM / minRangeM / hitRate / falloff / reloadMs / dmgMult`
- 炮术学：改为每级 **+5% 单发伤害**（skill 文案同步）
- 弹药：每次开火（不论命中）消耗 1 发；弹型选择 = 开火时取剩余数量最多的型（平局按
  kin→exp→pla）→ 混装配弹自然形成伤害类型混合；单型打空则该型停火
- 出发预载：按 `ammoTimeCapMs × 射速 × ammoMargin` 从货仓→仓库装载弹药快照；结束剩余退回
- 无人机：出发自动装载（仓库/货仓），受 `droneBayM3` 与 CPU 余量约束（dmg/cpu 贪心选配），
  参战并入主船伤害类型权重；v1 不损毁
- `ammoPerEngagement` 退役语义（预载替代），字段保留展示

## 五、距离动力学与战术

- 开战距离 = max(双方全部武器 maxRange)×openRangeFactor + openRangePadM
- 每 tick 双方朝各自期望距离移动；距离变化率 = 速度代数和
  （战斗机动速度 = maxSpeed × speedFactor ×(1±agilitySpeedBonus)），clamp [minDistanceM, 开战距离]
- 玩家战术（出发卡选择 + 战斗中可改）：贴脸/中距/风筝/自动（默认中距）；手动 = 拖距离条覆盖
- 敌方 tactic：`brawl`（贴脸近战）/ `orbit`（中距绕圈）/ `kite`（拉远吊打）；
  期望距离 = 战术基准射程 × tacticDesireFactor（基准 = 双方 maxRange 较大者）；速度快方主导收敛

## 六、敌方单位换算（运行时，初值校准）

- AnomalyDef 增：`tactic`（默认 orbit）/ `defProfile`（默认 balanced，血型比例 盾型 50/25/25、
  甲型 20/55/25、均衡 33/33/33）/ `escorts`（0~2）/ `dmgMix`（默认均分）/ `foeSpeedMps?` /
  `blindDmgMul?`（近盲带伤害比例，缺省 0.3）
- 主体总血 = C4 时长预期曲线 `foeHpOfThreat(T)` = 参考段火力 foeRefFire(段) × D(T)
  （D = 5+85×((T−6)/90)^1.6）；血量按威胁份额分给主体/僚机（每架 escorts×0.6 份额）
- 敌方武器由 tactic 定型（brawl 贴脸近程 / orbit 中距环绕 / kite 远程高最小射程），
  C4-#3 起走"虚拟装配模板"：射程 = 战术带 ×(1+侧重系数×(T−10)/90) 封顶 15km；
  速度 = 参考船速段 × m_base(T) × tactic 系数（brawl 1.28 / orbit 1.0 / kite 0.72）封顶；
  总火力 ≈ threat × foeDpsPerThreat（0.8）
- 现有 10 目标按叙事补字段（深渊之门卫队 shield+kite、坟场守墓人 armor+brawl、
  星髓巢穴 armor+brawl+僚机×2 = 首个 1v3 等）

## 七、胜负与结算

- 胜 = 敌编队全灭（奖励/战利品/声望/情报彩蛋沿用）；败 = 我方结构归零
  （扣耐久 0.15~0.3、弃船骰、维修费=期望奖励×50% 沿用）
- 战斗超时（maxBattleMs）按双方剩余血量比判胜
  > **⚠ 此项已作废**：现行口径 = **超时一律判负、并按撤退处理**（`combat.ts` 明文"旧口径已作废"；
  > 船长 2026-09-10 裁决，见 `docs/design/timeout-defeat-20260910.md`）。
- 战报升级：交战时长、开火/命中统计、弹药消耗、双方各层残余
