# 默认期望交距：中段 → 射程带高位（星图 0.8 · 洞内维持 0.5）

- **状态**：已确认（船长 2026-09-15 裁定：「解释清楚了，是期望距离的问题。」＋ 选定「默认期望抬到射程带高位」，
  并追加「**虫洞维持中段**」）
- **起因**：船长转玩家报障「**进行赏金任务时，敌我的初始距离非常近，对远程武器不利**」，
  并给了截图（我方 = 基础舰炮 + 巡航导弹架 MK3×4 · 敌方 = 3× 守墓长舰 1,062~7,391 m = **虚海守望者**，
  即任务中心那批赏金任务里的窝点卡）。

## 一、排查（先把事实钉准）

截图里那句「**期望 8,140 m**」正好 = 巡航导弹架 MK3（1,400~14,880）的**射程带中点** ⇒ 默认档没被"按星系记忆"带偏，
问题就在**默认档本身**。真引擎实测（同卡同装配同种子）：

| 时刻 | 实际交距 | 说明 |
|---|---|---|
| **t=0（进战斗那一刻）** | **16,368 m** | `battleOpenM` = 双方所有武器最远射程（我方 14,880）×1.0 + 缓冲 max(100, 10%) ⇒ **开局不近**，双方都够不着 |
| t=5s / 10s / 20s | 14,888 / 13,408 / 10,448 | 双方相向接近 |
| **t=30s 起** | **8,127 m** | 停在我方期望中距 8,140 ⇒ 对 14,880 的武器只用到 **射程的 55%** |

⇒ 玩家的观感来自**稳态**：进战斗约半分钟后，交距必然收拢到"射程带中点"。远程武器玩家要的远端位置，
默认档从来不给——必须**在战斗里**手动拖距离条或点「风筝」，而且拖过之后会**按星系永久记住**。

## 二、口径（现行）

`desiredRangeFor(me, tactic, bal, midPos = bal.desireBandWormhole)`
= 期望交距在**主武器有效射程带**内的位置（0 = 最小射程 · 0.5 = 中点 · 1 = 最大射程）：

| 档 | 位置 | 谁用 |
|---|---|---|
| 贴脸 `assault` | 主武器最小射程 ×0.6 | 三按钮（不变） |
| **中距 `mid`** | **星图 = 0.8**（`desireBandStarMap`）· **洞内 = 0.5**（`desireBandWormhole`） | 见下表 |
| 风筝 `kite` | 主武器最大射程 ×0.95 | 三按钮（不变） |

**同一单点的 7 个使用方**（逐条登记，避免漏改）：

1. 星图战斗默认期望（`startBattleFor`：`desirePrefOf(...) ?? 默认档`）——赏金任务/远征/遭遇走这条；
2. 星图编队战（`startFleetBattleFor` 非虫洞支）；
3. 战斗界面「中距」按钮（`battleTacticDesire`，按"当前是否在洞内交火"分档）；
4. AI 副船（`desireM === null` 强制默认档）；
5. **预估胜率**的稳态距离近似（`steadyDistance(..., midPos)`，按卡 id `wh-*` 判洞内）；
6. 出发前/战斗中切战术的同一出口；
7. 工具读数（`foe-hp-table` 等按 mid 的模型）。

**明确不动的**：开战距离公式（`openRangeFactor` 1.0 + 缓冲 10%）、贴脸/风筝两档、按星系记忆机制、
敌方期望交距口径（`foeDesiredRange`）、洞内"进去就得挨打"那条（近战怪开局距离仍用中段）。

## 三、读数（真引擎 A/B，同卡同装配同种子）

| 配置 | 旧中点档 | 新默认档 |
|---|---|---|
| 虚海守望者 L2 · 4×巡航导弹架 MK3（T3） | 稳态 **8,127 m** · 我开火/敌血曲线与新版**逐点相同** · 我方全程 100%/100% | 稳态 **12,171 m** · 同上 · 离敌方射程上限 7,391 m 从 **736 m** 拉到 **4,783 m** |
| 虚海守望者 L2 · 4×激光 MK3（T3，光束必中 + 远端衰减） | t≈20s **进入敌方射程** ⇒ 交火 20 秒「遭重创」⇒ **远征失利且弃船**（长尾鲨级已损毁，货仓与装备一并遗失） | 全程停在敌方射程外 ⇒ **100%/100% 零伤害**（我方在 8,387 m 仍打得到，只是吃衰减） |

⇒ 对"我方射程远于敌方"的配置，这一档改动是**实质性的生存转折**（不是小余量）：
它把「射程优势」真正兑现成了「打得到、挨不着」。

## 四、已知取舍与气味（如实登记）

1. **纯炮台/光束流**：站位变远 ⇒ 命中随距离下降、光束还吃远端衰减 ⇒ **自己输出变低**；
   长盘磨不动时会撞"打满上限判负"（引擎既有口径）。对**追踪导弹**类无此代价（命中不随距离衰减）。
2. **射程优势被放大**：我方射程远于敌方且我方更快时，可以稳定站在敌方射程外白嫖
   （敌方有冲锋的单位仍会扑上来；D 族这类"不 brawl"的族不会）——这是"打远程怪就该用远程武器"的
   设计意图，但它确实让**高威胁远程卡**更容易被无伤刷。若日后觉得过，可调的旋钮：
   ①把 0.8 降到 0.7；②给"敌方期望更近"时留一点内推权重；③对最远端的白嫖加一条"敌方增援/转场回拉"。
3. **洞内不受影响**（船长裁定）：`desireBandWormhole` 保持 0.5，2026-09-13「进去就得挨打」不变。
4. **界面口径同步**：胜率预估的稳态距离同源分档 ⇒ 不会出现"界面按中点估、实战站远端"的错位；
   但历史读数（改前的校准表/预估）不可直接与改后对比。
