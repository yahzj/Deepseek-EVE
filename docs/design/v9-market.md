## 一、目录与稀有度

- 两栏：
  - **常驻供应（common）**：矿石/矿物走"库存池"模型；单件平价品（MK1 装备、低级蓝图、
    掘洞级、基础 AI 核心 25k）随刷随买。
  - **稀有订单**：rare（MK2 装备、MK2 蓝图、造船蓝图、鲸吞级、开拓级）低频出现；
    exotic 限定奇货（鲸王级、鲸王蓝图、伽马/贝塔/阿尔法核心）同栏展示、极低概率 + 天价。
- 订单寿命：常驻 20 分钟 / 稀有 9 分钟 / 限定 6 小时（`balance.market.orderLifeMs`）。
  ⚠️ P2 抽取节拍制（2026-09-06 船长定，详见 `power-ladder-rework.md`）：**rare NPC 订单寿命 ×4**
  （9 → 36 分钟，买卖两侧同规则，`RARE_LIFE_MUL`）；**限定奇货 4 分钟 → 6 小时**；
  rare/奇货供给改为**每 10 分钟抽取节拍**（`RARE_DRAW_PERIOD_MS`）：rare 每窗抽
  N = 8%~15% × 已解锁件数（加权有放回，同窗可重复抽中同一类型；闸内权重 0.04，命中即 ×4 价暗市单）；
  奇货每抽取窗每件独立 0.8%（×现货抢购学）掷骰、全窗命中 >2 张随机抽选保留（`EXOTIC_CAP_PER_DRAW`）。
- 价格锚点：单件商品 basePrice = 旧商店/蓝图价（供应价 = 平价 ×1，收购价 = demandMultiplier，
  防套利）；池商品 basePrice = 旧空间站收购价（均衡价），收购平价、供应微溢 6%（保价差）。

## 二、价格机制（池商品核心玩法）

- 均衡价 L = basePrice × 库存压力 × (1 + 冲击动量) × (1 + 慢速噪声)。
- 库存压力：q > poolTarget 淤积 → 收购压价（倾销砸价）；q 接近 0 → 供应断货、价格走高；
  池以 30 分钟半程向目标回归（模拟站内吸收/补给）。
- 冲击动量（隐藏数值）：单窗口净成交量超过参考量 ×2（参考量 = 每窗口稳态流量的一半）
  触发一次 **±10%** 偏移（2026-09-11 船长三裁：5% → 8% → **10%**），**可叠加、无上限**（已按用户确认）；以 6 分钟半程衰减。
  - **砸得越狠 → 来收货的买家越多**（2026-09-11 船长：原话「我想表达的意思是。砸得越狠越卖来买的人越多」，
    裁定「**每层提高 8% 买单数量**」「**所有商品都适用**」）：**每层未衰减惩罚把 NPC 收购单（买单）挂单量 +8%**
    （层数 = `|shock| ÷ 每层幅度`，**不取整**、随衰减平滑回落；**只在砸盘方向生效**——玩家买入推高价格时不动买单量）。
    单点 = `market.dumpBuyVolumeMul()`，池商品收购阶梯 / 单件平价品 / 稀有 / 奇货 / 开局铺簿共用；
    每层系数 = `balance.market.dumpBuyVolumePerLayer`。
  - **砸盘时挂卖单量同步削减**（2026-09-11 船长：「**砸盘时，挂卖单的量进行同步削减**」）：**每层未衰减惩罚把
    NPC 供应单量 −8%**（下限 10%，只在砸盘方向），单点 `market.dumpSellVolumeMul()`，只作用于池商品供应阶梯
    （单件/稀有/奇货的供应单恒 1 张）。与买单放大对称：砸得越狠 → 接货的越多、出货的越少。
  - **收购量不再乘库存压力**（2026-09-11 船长：「**移除压力项**」→ 追问后定「**甲：只从收购量里移除**」）：
    池商品收购阶梯量 = `flow × 阶梯系数 × 补偿倍率`（**不含 `pClamped`**）；**价格仍保留压力项**（淤积压价 /
    缺货涨价照旧）。价格钳制下限同日由 **0.2× 下调到 0.1×**（让 10%/层的惩罚真跌得下去）。
    实测（40 窗连续倾销 ore-veldspar）：温和倾销 价格 **0.167×**、收购量 **×1.64**、供应量 **×0.43**；
    巨量倾销（池量 2.07× 目标）价格同 **0.167×**、收购量 **×1.56**、供应量 **×0.66** —— **深砸不再把买家压少**。
- 慢速噪声（2026-09-05 船长感知"常驻行情太稳定"后新增）：每个商品一个独立的、缓慢随机游走并
  向 0 均值回归的偏移，半程 4 小时、每窗增量半幅 ≈4%（稳态约 ±15%），钳制在 ±40%。
  即使玩家完全不交易，价格也会温和起伏、有真实曲线；玩家交易造成的压力/冲击仍在其上叠加。
- 输出价钳制在 basePrice 的 10% ~ 500% 之间（2026-09-11 船长：下限 20% → 10%）（仅防归零/溢出，不是叠加上限）。
- 价格小史（趋势图）：每窗口记录当前均衡价 L（含噪声/压力/冲击）。不用 bestBuy——它是"20 窗
  移动最大值"，旧高单会在下行时压制、掩盖噪声波动（便宜货整数取整后易钉死）；记 L 更能即时反映趋势。
- 池商品买卖价差：收购 ≈L / 供应 ≈L+max(1, 6%)（整数价差保底 1 ISK，避免低价商品
  取整后买卖同价）。

## 三、订单簿与内部消化

- NPC 簿：npcBuy（收购单，玩家卖出的对手盘）/ npcSell（供应单，玩家买入的对手盘）；
  单 = {价, 量, 到期时刻}，每 60 秒窗口（tickMs）补单/过期/撮合，离线大推进同样适用。
- 池商品按**价格阶梯**铺簿（2026-09-05 船长：不要全部挤在一个价——富凡晶石此前只有单一价位）：
  每窗口推 3 档——收购阶梯最佳档在均衡价 L、越深越便宜（低档量更大/墙）；供应阶梯最低档 ≈L×1.06、
  越深越贵。档位步进 = `max(1, round(价×4%))`，低价商品取整后也至少差 1 ISK，形成层次分明的盘口。
- 池量/流量按"越低级越大"放大（2026-09-05 船长：低级矿石/矿物是海量消耗品）：
  最低级矿物（三钛/焦晶岩/类银）池与流量放大约 10~15 倍（三钛池 24 万→30 万、流量 800→1 万；稀有矿保持小），
  使市场批量与池量配得上"海量"，且单批供应 ≥ 新手一趟矿船的结晶产出。放大只增数量/流动性，不变价格机制。
- 玩家市价卖出 = 立即按价从高到低吃穿收购簿；**吃穿后的剩余自动按边际价转限价卖单**
  （货已锁定 escrow，不浪费）。
- 玩家市价买入 = 立即按价从低到高吃穿供应簿；簿吃穿后提示可稍等补给或挂限价买单。
- 挂单：买入不预扣（成交时才扣钱、货直接入对应库存）；卖出先锁货（escrow）。
  撤单：物品退回物品仓库 / 装备退回装备库 / 蓝图退回蓝图书架 / 舰船退回机库（保留耐久）。
- **内部消化**：NPC 新订单与簿上对侧订单"撞价"（新收购价 > 最低供应价等）时不瞬时成交，
  进消化队列，按 digestPerWindow=15%/窗口 随时间推进消化——大冲突订单消化得慢（不瞬消）。
- 订单成交即时把货/钱入账并写"trade"日志；成交完毕的挂单自动清理。

## 十、贸易税与市场技能（2026-09-03 用户确认：销售税 5%、不收挂单费、双技能合计减税 80%）

- **税制**：只设单一「贸易税（销售税）」。玩家每一笔**卖出成交**（市价卖出、限价卖单成交、
  市价/挂单卖船成交）按成交金额征税 5%，入账时自动扣除；买方、挂单/自动转挂单动作一律免费
  （参考 EVE 销售税；**取消经纪人费/挂单费**——用户拍板）。
- 到账 = 毛额（声望加成计入）− round(毛额×税率)；日志写"税后入账 X ISK（贸易税 Y ISK）"。
- **减免技能**（数据驱动，新增「贸易」组，rank 2）：
  - 会计学 `accounting`：每级 −8% 贸易税；
  - 贸易谈判学 `trade-negotiation`：每级 −8% 贸易税（用户建议改名，替代"经纪关系学"）；
  - 减免**线性相加**：税率 = 5% × (1 − 8%×(会计学级+贸易谈判学级))；双满 → 1%（合计减免 80%）。
- 配置在 `balance.market`：salesTaxRate / taxSkillAId / taxSkillBId / taxCutPerLevel（**不进存档**，
  无版本迁移）；结算点：settleSell 与 sellAtMarket（含卖船路径，统一税后净入账语义）。
- 平衡影响（24h 体检税后）：A≈1.0M / B≈3.0M / C≈3.1M ISK（税约 -5~9%，温和的 ISK 回收阀）。
- UI：市场页顶部显示当前税率与技能减免（会计学/贸易谈判学等级实时折算）。
