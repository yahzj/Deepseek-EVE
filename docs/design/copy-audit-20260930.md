## 二、`whale-copy` 规程要点（本仓文案的作业依据）

1. **六个落点各自的语域**（物品/模块/舰船说明 · 技能说明 · 日志 · 公告 · 通讯与对白 · 界面提示与悬停）：

   点一件事留钩子；公告是**第三人称「玩家」**、3~5 条。
2. **铁律**：id 制（先取 id 再写文案，中文只出现在 `table.ts` 的 `zh` 列）· 中英双语 ·
   说明只写规格、括号只放规格 · 玩家向内容禁开发语 · 数值 `⟦⟧` 三处登记 · 改文案加
   `⟪文案调整⟫` 标记 + 工作文档台账。
3. **落笔四条手艺**：先列信息清单再写句 · 一句一件事 · 主语与动作有着落 · 读完出声。
4. **审校五步**：抽语料 → 定优先级（A 通讯 → B 公告 → C 说明文本 → D 界面长句）→ 逐条判
   **保留／微改／重写** → 出审校表（问题归类 + 通则）→ 船长批准后批量落地并跑闸门。
5. **反例库**：把 2026-09-30 我那份被驳回的通讯稿当负面样本写进去了（复制感／说明书嘴／堆五条机制／
