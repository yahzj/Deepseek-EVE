## 二、谜质 → 「虫洞谜质」

| 项 | 值 | 说明 |
|---|---|---|
| id / 名 / 种类 | `mat-wh-essence` · **虫洞谜质** · `matter` | 与 24 台谜质装置同类目（图鉴归类一致） |
| 介绍 | 「虫洞内存在的奇幻物资，具备研究价值。」 | **只做设定语言**：不承诺任何研究玩法（避免"说了做不到"） |
| 体积 / 单价 | 0.5 m³ · **70,000 信用点/枚** | 市场行 `demandMultiplier: 1.0` ⇒ **NPC 收购 = 70,000**（与专属物品行同口径） |
| 交易 | **只收不卖**（`playerBuyable: false`） | 与虚空母矿/虚空晶/专属物品同一档 |
| 换算 | **1 台谜质 = 1 枚** | 按"本趟已取回（在货仓 / 临时空间）的台数"计 |
| 触发时机 | **只在撤离成功时转换** | **全损不转**（随货仓一起丢，沿用既有全损口径）；**没捡的不补发** |
| 增益 | **保留原样**（取回即生效、离洞失效） | 本批只新增"结束时转成物品"，不动 24 台装置的效果体系 |
| 收益量级 | 一趟 3~8 台 ⇒ **21 万 ~ 56 万**信用点 | 与洞内层收益同量级（"目前纯粹作为虫洞的金钱收益"） |

## 七、落码记录（批 B · 2026-09-15）

**① 谜质折算**（改的是 2026-09-14 的旧口径「随趟消失、不进仓库」）：
`deliverExtraction` 里按**件**数装置（形状件一件一格，含临时空间里那批）折成 `mat-wh-essence`：
1 台 = 1 枚、只收不卖、**只有撤离成功才折**（全损走"随趟丢"那条路 ⇒ 一枚都没有）；
装置给的增益本趟照旧生效（折算是结算动作，不改趟内任何账目）；装置本身仍**不进仓库、不进拆解池**。
结算单新增「虫洞谜质」格（枚数 + 按行价参考估值，**不计入到手合计**，与 AI 核心同口径）。
24 张谜质装置说明统一补尾注「（撤离成功则析出虫洞谜质）」。

**② 贵重品货柜**：拆解 ⇒ **一叠奢侈品 10~20 件**（三档 `lux-1/2/3` 等权；`units` 就是这一叠的件数，
交付走 `wormholeDeliverRelics` 新增的可选 `unitsOf` 覆盖，其余调用零改动）。定价 **50 万**（= 期望 84 万 ×0.6）。

**③ 残骸堆货柜**：`wormholeSalvageAt` 每收走一堆掷一次 **0.75%**、**一次打捞最多 1 个**；
四类货柜**类等权**（各 1/4）再类内等权（安全货柜按本格敌卡的族）；**不分层**（层 1 也出深档）。
只在 `graveyard` 生效（遗迹另有专属掉落，不叠加）；掷骰走**独立盐值的流**
（`runSeed*89 + depth*811 + (q*29+r*43)*19 + 剩堆数*7 + 23`）⇒ 不消费既有随机数，旧读数逐字不变。
落点走与遗迹货柜同一套「收货阶梯」（货仓 → 临时空间 → 散落该格），结果多报一个 `boxes` 字段。

**④ 军用备货柜**：拆解 ⇒ **1~3 件随机 MK3 装备**（逐件独立等权，可重样）；
池 = **按 id 后缀 `-3` 派生**（与体检 `isMk3` 同一把尺）**含武器**、**排除** `-wh-` 与 `mod-lair-*` 与 `unreleased`（30 件）。
一箱多件走 `WormholeUnboxDraw.extra` + `unitsOf`（模块按"清单里出现几次"各入装备库一次）。
定价 **280 万**（= MK3 池均 235.5 万 × 期望 2 件 ×0.6；**原估值 700 万高于拆解期望，已按同一条 ×0.6 规则下调**）。

**⑤ 安全货柜价 ×1.5 的连带**：物品卡与市场行**两处一起**提到 3,232,500 / 3,352,500 / 6,112,500 / 4,927,500 / 4,815,000
（原口径"收购价 = 内容期望 ×0.6"随之变成 **×0.9**：仍低于拆解期望、哲学不破，只是"开箱 vs 卖箱"的差距收窄）。
