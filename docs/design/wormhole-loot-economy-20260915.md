## 二、谜质 → 「虫洞谜质」

| 项 | 值 | 说明 |
|---|---|---|
| id / 名 / 种类 | `mat-wh-essence` · **虫洞谜质** · `matter` | 与 24 台谜质装置同类目（图鉴归类一致） |
| 介绍 | 「虫洞内存在的奇幻物资，具备研究价值。」 | **只做设定语言**：不承诺任何研究玩法（避免"说了做不到"） |
| 体积 / 单价 | 0.5 m³ · **70,000 信用点/枚** | 市场行 `demandMultiplier: 1.0` ⇒ **NPC 收购 = 70,000**（与专属物品行同口径） |
| 交易 | **只收不卖**（`playerBuyable: false`） | 与虚空母矿/虚空晶/专属物品同一档 |
| 换算 | **1 台谜质 = 1 枚** | 按"本趟已取回（在货仓 / 临时空间）的台数"计 |
| 触发时机 | **只在撤离成功时转换** | **全损不转**（随货仓一起丢，沿用既有全损口径）；**没捡的不补发** |
| 增益 | **保留原样**（取回即生效、离洞失效） | 本批只新增"结束时转成物品"，不动 24 台装置的效果体系 |
| 收益量级 | 一趟 3~8 台 ⇒ **21 万 ~ 56 万**信用点 | 与洞内层收益同量级（"目前纯粹作为虫洞的金钱收益"） |

## 三、货柜家族（4 类）

| 货柜 | 体积 / 格 | 价格（basePrice） | 市场 | 拆解产出 |
|---|---|---|---|---|
| **安全货柜**（五族 · 现有） | **3000 m³ / 3×2 = 6 格**（原 2000 / 2×2 = 4 格） | 原价 **×1.5**（口径仍 = 内容期望市值 ×0.6） | 只收不卖 | 原样（族专属装备 / 图纸 / 矿物） |
| **图纸货柜**（层档 · 现有） | 1000 m³ / 2 格（**不变**） | 不变 | 只收不卖 | 原样（一次性舰船图纸等） |
| **贵重品货柜**（新） | **1000 m³ / 2 格** | **500,000** | 只收不卖 | **奢侈品 ×10~20 件**（随机） |
| **军用备货柜**（新） | **2000 m³ / 2×2 = 4 格** | = 内容期望市值 ×0.6（按 MK3 装备池期望反算） | 只收不卖 | **MK3 装备 ×1~3 件**（含武器、**排除专属**） |

## 五、连带与边界（如实登记）

1. **MK3 武器多一条渠道**：现在只有"穹顶守卫直出 + 碎片集齐 250 片"，本批起军用备货柜也能拆出（**船长已裁定含武器**）——设计稿与词典登记该渠道。
2. **安全货柜改规格的三处连带**：① 体检契约里「2000 m³ = 4 格」的断言改写为 3000 / 3×2；② `wormholeHold` 形状表新增 3×2 形状；③ **老档读档即按新体积算** ⇒ 可能出现"原本装得下、读档即超载"，**不特殊宽限**（既有超载链：禁装货 + 可丢 / 可装船）。
3. **价格口径**：新物品与货柜一律走"市场行 basePrice = 内容期望市值 ×0.6"（既有惯例）；只收不卖的四类货柜与谜质的 `demandMultiplier` 取 **1.0**（与专属物品行同口径）。
4. **旧口径作废**：安全货柜「2000 m³ = 4 格」作废（本稿为准）。
5. **表现层**：新物品与两个新货柜需**新 SVG 线稿**（谜质晶格 / 贵重箱 / 军备箱），与既有货柜图标同语言；画完交船长审观感。
6. **公告**：属大更新 ⇒ 另出**公告待审稿**（过审前不写入 `announcements.ts`）。
