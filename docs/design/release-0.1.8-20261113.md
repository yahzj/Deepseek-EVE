# 0.1.8 网页版发布

状态：待合并推送与网页版部署。经办：二号，`Deepseek-EVE-d2`，`d2/workspace`；2026-11-13。

船长原话：「合并，仍然会推送并部署，推进小版本」。本批客户端显示版本由`0.1.7`推进到`0.1.8`；版本来自`apps/desktop/package.json`，同步工作区锁文件元数据。网页发布，桌面版继续暂停。

## 发布范围

- 修理无人机改为只在交战距离不超过`2500`米时进入敌方近防炮目标池；修理机不再因攻击型无人机的反击令牌越过距离限制。
- 修理无人机基础间隔由`10`秒调整为`20`秒，装甲与结构基础修理量各由`10`提高到`20`；维修技能、后勤输出和受修舰各层容量加成按维修装置同源口径计算。
- 增加真实修理事件驱动的放飞、抵达受修友舰、修理脉冲、返航动画；不产生攻击弹道、伤害音效或重复结算。
- 修复损伤管制装置在小数结构血量下偶发漏触发的问题，并补齐实际攻击、组件来源、逐舰和战中读档回归。

## 验证与发布边界

- 相关专项与回归通过：修理无人机、近防炮、逐舰维修、死亡舰不复活、损伤管制及相关战斗路径共`643`项定向测试通过。
- T2 六项检查通过：类型、内容、本地化、UI、架构和范围检查全部通过；网页构建通过。
- 发布使用`Publish (Manual)`的`target=web`，`source_ref`锁定合并后的完整提交SHA，`tag_name`为空；Windows构建与发布跳过，不创建或移动标签，不操作后端或Steam。
- 公告未写入游戏，桌面版不构建、不打包、不发布；浏览器观感验收仍由船长确认。
