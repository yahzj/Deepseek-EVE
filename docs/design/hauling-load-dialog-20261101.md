## 授权与范围

船长原话：「长途运输的体积选择应该放在玩家点击开始运输后弹出让玩家输入，卡片也需要修改，删除重复内容，显示最大货仓的收益和每单位体积货物的收益，在弹出窗口内显示玩家输入的承运体积能有多少收益以及一个相对模糊的威胁系数。」随后确认完整方案。

## 行为

- 卡片按当前出勤舰队全部可用空间，列最大承运量、满载单程收益、单位体积每单程费率及独立金色满载时薪；删除主控船名、往返重复报酬和精确风险读数。
- 开始按钮只弹窗；输入默认满载，25/50/75/满载快捷选择。实时毛收益与时薪区间；空、零、非整数、超量均不可确认。确认才调用正式运输入口，取消无写入。
- 在途使用冻结出勤名单调整下一趟货量，保留本趟装载和计酬快照；折返不开放调整。到站停运与中断确认不变。
- 威胁为沿途低安目标威胁/当地普通海盗基准的最大值，向下取整形成整数宽档；任一危险地区缺基准显示未知，全安全无威胁。只做预览，不抽配置、不消耗随机数、不将护航降频误当减伤。
- 单位费率保留小数，不按1m³小订单向上取整；实际计酬仍走原正式公式。时薪按精确航程毫秒计算，未扣补给、战损和遇袭延误。
