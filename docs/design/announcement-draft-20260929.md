## 三、建议新发（5 条）

### A · 拆船回收（**新系统**，建议排第一）

- **id**：`ann-ship-scrap-20260929` · **date**：2026-09-29 · **tag**：系统
- **title**：新功能：舰船拆解回收

**要点（4 条）**

1. 「舰船插件」区域新增「拆解回收」按钮：确认后把这艘舰船化成材料，回收量为该舰船造料单的 **50%**，每种材料**向下取整**。
2. 回收前有**两次确认**，第二次会列出这艘船能回收到的每种材料与数量，并写明**蓝图书不会返还**。
3. 回收时船上**高/中/低槽装备、舰船插件、随船无人机**一并进装备库，**货舱货物**进物品仓库。
4. 正在驾驶的舰船、AI 执勤中、在途或正在虫洞作业的舰船不能回收。

**为什么该发**：新玩法入口（玩家不知道入口在插件区就永远找不到）。

### B · 无人机体系更新

- **id**：`ann-drone-line-20260929` · **date**：2026-09-29 · **tag**：系统
- **title**：无人机体系更新：两件新装备与射程重排

**要点（4 条）**

1. 新高槽装备「**无人机储备甲板**」MK1 / MK2 / MK3：有无人机被摧毁时开始运转周期，周期结束后从货舱补充**同型**机一架并重新加入战斗；周期分别为 **15 秒 / 10 秒 / 6 秒**。
2. 新中槽装备「**无人机护盾投射仪**」MK2 / MK3：我方放飞机群的**护盾层 +70% / +100%**（只作用于护盾层，多件相加）。
3. **槽位与舱容调整**：无人机甲板扩展等扩舱件改到**低槽**；掠袭机库的无人机舱容 **30 → 40 m³**；两艘势力巡洋舰的无人机专用槽由中槽改为低槽。
4. **射程重排**：哨戒 **6,500 / 7,500 m** ＞ 侦察 **6,000 m** ＞ 战斗 **5,000 m** ＞ 攻坚 **4,000 m**。

### C · 采矿 / 精炼 / 回收调平（**2026-09-29 船长令：暂不发布** —— 稿留此处，等你点头）

- **id**：`ann-econ-rebalance-20260929` · **date**：2026-09-29 · **tag**：数值
- **title**：采矿、精炼与回收调平

**要点（4 条 · 待发布前复核用词：本仓「矿石 / 矿物」是陈旧术语，要改成「原矿 / 原材料」）**

1. **矿石按体积结算**：不同矿石的单位体积不同，采矿量与货舱占位都按体积算；精炼产出同步上调。
2. **精炼炉节奏重标**：各矿石之间"单位时间收益"的差距收窄，选矿不必只盯一种。
3. **残骸回收保底按 1:2:3 拉开**：低档残骸的保底提高，混档回收不再被高档拖低。
4. **两艘船升档**：开拓级升为 T3、座头鲸升为 T4，各多一个非高槽槽位；开拓级的市价与图纸价格同步上调。

### D · 技能树扩充

- **id**：`ann-skill-mining-20260929` · **date**：2026-09-29 · **tag**：内容
- **title**：技能树扩充：新增矿业大类与高阶技能

**要点（4 条）**

1. 技能树新增「**矿业**」大类：采矿与采矿舰相关技能从工业类独立出来，导航更清楚。

### E · 入侵活动规则调整

- **id**：`ann-weekend-rules-20260929` · **date**：2026-09-29 · **tag**：系统
- **title**：入侵活动规则调整

**要点（4 条）**

1. **旗舰黑匣改为「亲手击沉必得」**：不再看爆率，玩家在旗舰战里打沉母舰即可获得黑匣 ×1。
2. **贡献占比改为按输出计**：BOSS 输出占**六成**、清缴进度占**四成**——实战打得越多，占比越高。
3. **入侵期间悬赏照常发放**：星系被占不再让悬赏延后。
4. **低安遇袭不再抢走信用点**：只对货舱下手。
