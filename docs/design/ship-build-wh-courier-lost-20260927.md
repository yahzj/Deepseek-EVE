**答一：会返还** ✓ —— 蓝图回到书架（0→1）、名额标记摘除、线摘掉；材料同批退回（前文第一节的探针已验同一条实现）。

**答二：能切出来跑快递** ✓ —— 闸门那条"人在虫洞里"的拦截条件是
`state.wormhole.run != null && run.attending === true`（`activityGate.ts:172`）：**只看"人在不在洞里"**。

[探针] ③切出来后闸门 = null （放行 ⇒ 可以跑快递）

⚠ **但"战斗中"一律拒**（`activityGate.ts:166`：`run.battle != null` ⇒ "这一场打完才能切换主控活动"）

## 七、由此得到的改进建议（等船长裁）

建议给 `logAutoHalt`（或 `haltActivityForSwitch` 的 manufacturing 分支）补一句**退回读数**，形如

⚠ 只改**告知**，不动"进度丢弃"这个既定口径（船长 2026-09-21 答 2）。
