# 报障取证：谜质格会不会给「图纸货柜」（2026-09-16）

**状态：已结案（玩家当场澄清是看错）** · 经办：一号 · 工作文档（归档后删除，结论并入 `docs/roadmap.md`）

## 一、船长原话（照抄）

1. 报障转述：「**有玩家反应，从谜质中获得了图纸货柜**」
2. 追问后船长补：「**好像是谜质的虫洞地点**」
3. 结案：「**玩家澄清，是看错了**」

## 二、结论（先行）

**不是 bug：现行代码里「虫洞谜质格」发不出任何 `box-*`**——它只发 `mat-*` 谜质装置。
`box-bp-*`（图纸货柜）的**正规来源只有两条**，都与谜质格格不相干：

| 来源 | 口径 | 出处 |
| --- | --- | --- |
| **遗迹首次打捞** | 层 2 起 **70%** 命中，命中后按**全货柜池 10 种**抽（贵重品柜 50% + 其余 9 种各 ≈5.6%，含三档图纸柜） | `wormholeSalvage.wormholeRollRelicBox` / `wormholeRelicBoxPoolOf` |
| **残骸堆打捞**（墓场） | 每收走一堆掷 **0.75%**、单次上限 1 个，四类货柜类等权（图纸柜三档为一类） | `wormholeSalvage.wormholeRollSalvageBox` / `wormholeSalvageBoxClassesOf` |

## 三、取证（走真 API + 入库差分）

一次性探针（`tools/_probe-matter-box.ts`，跑完即删）：逐种子 × 层 1~5 造盘，把玩家瞬移到每一格上，
依次调 core 的四条真实入口，并对「仓库 / 货仓形状件 / 临时空间 / 背包 / 蓝图书架 / AI 核心账」做**快照差分**，
看这一动作**真发了什么**；同一套差分同时打在遗迹格上作**阳性对照**。

- **谜质格 420 格（40 种子 × 层 1~5）**：`wormholeActivateAt` **420/420 成功**，发出条目**全部是 `mat-*`**
  （23 台装置全覆盖，与 `WORMHOLE_MATTER_DRAW_POOL` 的 23 台一一对上）；仓库/背包/书架上**一件别的都没有**。
- 谜质格上另外三条入口 **420/420 全被拒**、不扣回合、不发东西：
  「这个地点没有可打捞的残骸。」/「这个地点没有可采集的矿脉。」/「这里没有可拾取的东西。」
- **阳性对照（遗迹格 423 格）**：同一套差分抓到 **10 种 `box-*`** —— `box-valuables` 134 · `box-relic-g/d/c/e/a`
  28/24/24/19/13 · `box-bp-deep/mid/shallow` 17/13/12 · `box-military` 15（另 AI 核心 52 枚）。
  ⇒ 对照证明"差分能抓出货柜"，所以"谜质格没抓到"是**结论**，不是工具瞎。

## 四、代码单点核查（为什么结构上也不可能）

1. **谜质格的动作只有一条**：`wormholeActivateAt` 的谜质分支取 `wormholeMatterDeviceAt(种子, 层, 格)`，
   即从 `WORMHOLE_MATTER_DRAW_POOL`（23 台 `mat-*`，已排除退役的撤离掩护器）里定死一台 ⇒ **档位与货柜池无交集**。
2. **打捞/采集/拾取都按"地点"分流**：`wormholeEnsureSalvagePiles`（只 `graveyard`/`ruins`）·
   `wormholeSalvageAt`（只 `graveyard`/`ruins`）· `wormholeCollectOreAt`（只 `vein`）·
   `wormholeTakePileAt`（网格层只允许形状件，而谜质格不铺堆）⇒ 谜质格上**没有能掷货柜的入口**。
3. **会往格上铺东西的写入点共 6 处**（`wormholeEnsureSalvagePiles` / `wormholeEnsureVeinPiles` /
   打捞与遗迹首捞的「散落该格」两条 / `wormholeGrantShipSpoils` 战果散落 / 采集），
   前五处都写"当前格"且以地点为闸 ⇒ 战果散落只发生在**战斗格**，而谜质格开不了战。
4. **玩家可见文案本来就说清了来源**：谜质格取回是「🕳 取回谜质：〈装置名〉（〈效果〉）」；
   遗迹出货是「🕳 遗迹深处发现〈货柜名〉」；残骸堆出货是「🕳 残骸堆里翻出〈货柜名〉」——三句各自带来源。

## 五、落码（本批唯一的改动）

- `packages/core/tests/wormhole-matter.test.ts` 新增 **⑦b「谜质格只发谜质装置」**（常驻护栏）：
  ① 谜质格上打捞/采集/拾取三条入口全被拒、不扣回合、不动仓库；
  ② 图纸货柜的正规来源（遗迹掉落池）作对照断言；
  ③ **12 种子 × 层 1~5** 扫遍谜质格：激活发到手的只能是 `wormholeMatterDeviceOf` 认得的那台，
  且货仓/临时空间/背包里**绝不出现 `box-*`**；`granted > 10` 防"护栏空转"（实测 **99** 次成功取回）。
- 临时探针按工具纪律删除（读数为本文与 roadmap 条目）。
- **玩家可见文案零改动**、数值零改动、存档零改动。
