## 四、族哈希真 BUG（船长确认修）

**旧实现**：`Math.abs((s × 1103515245 + 12345) % WORMHOLE_FAMILY_ORDER.length)`。

**成因**：模数是族数 **5**，而 `1103515245 = 5 × 220703049`、`12345 = 5 × 2469` **两项都能被 5 整除**
⇒ `s × 1103515245 + 12345 ≡ 0 (mod 5)` 对**任何** s 成立 ⇒ 下标恒 0 ⇒ 恒 A 族。
根因是这对 LCG 常数（Numerical Recipes 那对）本是配 `% 2^31` 用的，拿来配 `% 5` 时
"乘数/加数与模数不互质"，结果塌成常数。

**影响面（量化）**：

| 种子范围 | 旧哈希行为 |
|---|---|
| 乘积不溢出 2^53（种子 ≲ 8.16M，占真实扫描区间 1..2e9 的 **0.41%**） | **必然 A 族**（实测种 1..20000 → 100% A） |
| 乘积溢出 2^53（其余 99.6%） | 靠**浮点舍入**凑出伪随机，但分布**偏斜**：A 13.0% / C 18.8% / **D 31.9%** / E 23.6% / **G 12.7%** |

⇒ 「等概率五分之一」从来没实现：小种子恒 A、大种子靠溢出凑（D 是 G 的 2.5 倍）。

**修法**：splitmix 风格 **32 位混合**（全程 `Math.imul`/异或 ⇒ 无浮点参与、跨引擎确定）再取模。
修后实测分布 ≈ **A 19.9 / C 19.9 / D 20.0 / E 20.1 / G 20.0**（种 1..2e9 等距抽样 20 万）。
**新旧存档里已有的洞不变**（族随 `run.family` 落档）；只有"现算"的入口（新扫描的洞 / 老档缺字段 / 调试）变。
回归用例：`tests/wormhole-archetype.test.ts` 新增「小种子也必须摇出五族」（旧实现必然塌成 A 的那一段）。

顺带核过：另三处同类常量（`wormhole.ts:665/1231`、`wormholeFoes.ts:281`）模数是 **2147483647（素数）**，
与 5 互质 ⇒ 不存在这一类塌陷（但它们吃浮点溢出精度，属另一档隐患，本次不动、只登记）。

## 八、海盗速度甲案（船长 2026-09-16「检查了海盗的平均速度好像有些太慢」）

**读数（同层可比，战斗机动 m/s / 相对基准船 165.2）**：A 浅 190（1.15×）· A 中 200（1.21×）· A 深 218（1.32×）
｜C 浅 224（1.36×）· C 中 206 · C 深 205｜G 浅 201 · 中 175 · 深 121｜D 浅 183 · 中 102 · 深 69｜E 三卡 20（族格：巨构不讲机动、`speedRatio 0`、靠机群作战）。

**查出的真不一致**：`wh-pirate-scout` / `wh-pirate-hunt` 的**劫掠护卫舰**被卡面条目 `speedMul 0.9` 压到
**337 m/s < 本档基准 340** ⇒ 违反船长 2026-09-11「A 族速度都快…每档都必须高于基准」。**逃过体检的原因**：
A 族那条契约原判据是 `def.hidden !== true`，而**洞内三张卡恰好都标了 hidden** ⇒ 整族洞内卡从未被这条规则检查。

**甲案落值**：① 两张卡的护卫舰去掉 `speedMul`（实速 337 → **374 = 1.28×**）；② 契约豁免收窄为
「只豁免迁移守恒反算的 `enc-pirate-*` 旧模板」（按 id 前缀认）⇒ 洞内 A 族卡从此受同一口径约束（体检读数由 15 条升到 **17 条**）。

**不动**：C 族（船长 2026-09-11 明文「**C 族速度比 A 海盗还快**」⇒ 海盗不是最快族是既定口径，不是 bug）· D 族"越往里越慢"· E 族 0 倍率（族格）· 旧模板 `enc-pirate-*`。

用例：`tests/wh-foe-mounts-battle.test.ts` +1 例（洞内 A 族每条编目实速 > 本档基准 + 逐条点名 374）。
