## 背景与问题
1. 玩家反馈：建成副空间站后本应"像母港一样用"，但市场/出售/精炼/回收/组装等只有回母港可用
   （旧稿 T9「母港独有：市场/制造台」与"建成副站提供卸货/维修/补给/换驾驶"的档位文案不完整，
   且"补给"实际挂市场 → 承诺落空）；
2. 悬赏/扫描"任务完成即返航"（2026-09-06）固定回母港，与"移动免费的是去程就位、返程类仍计时"
   的体系不一致；建成副站后玩家希望活动结束停到离现场最近的站；
3. 本地悬赏（落点 = 目标星系）0 航程转身 → 与本地矿工 3 分钟循环返航成本脱节，可无限白刷。

## 确认决策
| # | 决策 | 细节 |
|---|---|---|
| D1 | **已建成副站 = 母港镜像** | 市场买卖（出售放行）、精炼炉、残骸回收、逆向研究、组装机制造、维修、卸货、换驾驶全部可用；**设施与仓库全局共享，副站只是入口**（无独立库存/市场/炉位；零存档迁移） |
| D2 | 镜像只限**已建成**站 | 修建中工地/野外不开放（档位节奏保留）；工地现场交付语义照旧（见 t9 交付修复） |
| D3 | **所有自动返航选最近已建成站** | 悬赏胜利/失利/撤退、扫描完成：返航基准 = 目标星系最近已建成站（无 = 母港），到港停靠该站（dockedSite 落点、日志带站名）；采矿/打捞/AI 本即最近站口径；**手动召回（远征/掩护巡逻）仍回母港（例外）** |
| D4 | **本地悬赏返港段 120s** | 落点 = 目标星系（母港本地/建成站本地）时胜利结算后固定返港 2 分钟（`LOCAL_RETURN_MS` = `balance.mining.localLegMs`，对齐矿工本地满载单程），期间不可召回（同胜利返航语义） |
| D5 | 演习场奖励重锚 | `ano-training` 1,000 → **3,600 ISK**（按"交火 2min + 返港 2min"≈900/min 的费率带取整百；玩家公告不提及对齐口径） |
| D6 | 展示动态化 | 悬赏卡「胜利返航约 X 分钟（不可召回）」与「估算奖励/小时」按最近站实时计算；本地悬赏显示"返港约 2 分钟" |

## 参数与口径备忘
- 本地返港段 120s = `balance.mining.localLegMs`；异星系返航 = 2×单程(目标↔落点)，航路不可达时兜底 `outMs×2`；
- 判断"已建成"统一用 `siteProgress.stage >= tiers.length`（与并网判定同源）；
- 本地矿工参考节奏：本地一趟循环 180s（返航 120s + 空船去程 60s 并入）；隔壁星系单程 ≈3.5~3.9 分钟（按船速）；
- 船队善后返航（换驾驶旧船自动返港）只交割仓库、不设停靠点，不随 D3 变化（无影响面）。

## 已知取舍 / 后续可调
- 建成站所在星系的悬赏、以及靠近建成站的深区悬赏，返航路程会缩短（建站红利）；若后续发现"建站改变深区节奏"过度，可只对奖励/小时展示与白刷防护保留母港口径（另议）；
- 手动召回回母港为船长确认的例外；如需召回也去最近站，另行拍板。
