## 二、口径定稿（两件）

### 机制一 · 垂暮级（T4 `foe-r-corona-dusk`）——「待机护盾阵列 / Standby Shield Array」

| 项 | 口径 |
|---|---|
| 条件 | 该舰的闪现**不在冷却中**（`now >= foeBlinks[tag]`；**从未闪过也算可用** ⇒ 开场即生效） |
| 🔴 **判据的时点** | **按拍开头取快照**（**船长 2026-10-03 裁定**：「**同一拍整次齐射都算**」）——本拍开始时闪现没在冷却 ⇒ **本拍之内的整次齐射全算生效**（哪怕触发闪现的那一发就在本拍里）；下一拍才失效。落点 = `combat.foeStandbyReadyOf` ＋ `stepBattle` 开头的 `snapshotFoeStandby`（`BattleState.foeStandbyTick`） |
| 效果 | **护盾层**对**全部伤害类型**（动能 / 爆破 / 能量）获得 **50% 抗性** ⇒ 落在该层的伤害 ×0.5 |
| 作用层 | **只护盾层**（装甲 / 结构照常） |
| 与闪现共用冷却 | 闪完那 **5 秒**里没有这层抗性（机制的一部分） |
| 数值 | **50% 写死在件上**（与「闪烁过载」的 `hullCostPct: 0.05` 同款），**不另开旋钮** |

### 机制二 · 入侵旗舰（T5 `foe-r-corona-nexus`）——「聚焦阵列 / Focus Array」

| 项 | 口径 |
|---|---|
| 效果 | **它自己武器**的**远端衰减系数**（`falloff`，现 **0.2**）随开战时间**线性爬升到 1.0 = 无衰减** |
| 曲线 | `f(t) = min(1, 0.2 + 0.8 × t ÷ 120s)`（第 60 秒 = 0.6） |
| 计时 | 🔴 **随波重置**（**船长 2026-10-02 改判**）：**每波从头爬**，第 2 波回到 0.2 再爬 |
| 范围 | 只影响**它自己**的武器（不 buff 僚舰） |
| 数值 | **120 秒写死在件上** |

**🔴 机制一的实战读数（两版对照 · 供船长校准）**：出荷配置（闪现 ＋ 待机护盾阵列）下，垂暮级的盾层
累计掉幅（关回充、同随机序列）：

| 判据 | 裸对照 | 只挂件（无闪现） | 出荷（闪现＋件） | 这层抗性实际挡掉 |
|---|---|---|---|---|
| 旧：实时查冷却（落码初版） | 528 | 264 | **490（92.9%）** | 约 **7%** |
| ✅ 新：**每拍开头快照**（**船长 2026-10-03 裁定「同一拍整次齐射都算」**） | 528 | 264 | **336（63.7%）** | 约 **36%** |

旧版为什么几乎挡不住：闪现是**挨打触发**的，而同一发里"伤害结算在前、盖冷却在后" ⇒ 实时查冷却时，
同一拍只有**触发那一发**吃得到抗性，随后同拍的其余发全被刚盖上的冷却挡掉。船长第一句原话
「**触发的那次齐射**受到的伤害减半」⇒ 判据改成**每拍开头的一瞬**（`foeStandbyReadyOf` ＋
`stepBattle` 开头的 `snapshotFoeStandby`），本拍整次齐射同命（用例 ⑪ 钉住）。

**另两处如实登记**：
- **连发的净 DPS**：船长口径「每发 −70%」= 一轮 ×0.9；另因一轮多占 200ms 相位
  （三发 100ms 间隔的占位）⇒ 长期 DPS ≈ **×0.87**（读数来自 ⑩ 的轮周期 5.30s）。
- **连发节拍要减一拍**：本仓开火环"冷却减到 0 的那一拍不开火、下一拍才开火"⇒ 直接写 `gapMs` 实得
  **200ms**；已按 `max(0, gapMs − dtMs)` 补正为**真正的 100ms**（⑩ 已钉住）。

## 六、机制三 · 入侵旗舰的**武器侧面改判**（船长 2026-10-02 追加 · ✅ **已落码**）

> **船长原话（照抄）**：「**入侵旗舰的武器伤害降低60%，但是每次开火是三次间隔100ms的射击，目标选择随机。**」

| 项 | 照字面的读法（⚠ 见"歧义"） |
|---|---|
| 伤害 | **每发**伤害 ×**0.3**（原单发的 30%）—— 船长 2026-10-02 **二次改判**：「**再调低一些，改为每发 −70%**」 |
| 连发 | 原本"一门一次"改成 **三连发，间隔 100 ms** |
| 选靶 | **每一发独立随机选靶**（与既有 `foeTargeting: 'random'` 同口径） |
| 与机制二的关系 | 与「聚焦阵列」的远端衰减爬升**相乘**（衰减按当拍值算） |

✅ **船长 2026-10-02 裁定：甲**（「伤害降低 N%」= **每发** ×(1−N)，不是「一轮总伤」）⇒
**先定 −60%（每发 ×0.4）**，**同日二次改判为 −70% ⇒ 每发 ×0.3** ⇒
**一轮三连总伤 = 原单发 × 0.9**。

**落点**：旗舰武器条目（`foe-ships.ts` 的 `FOE_R_CORONA_NEXUS`：`shotDmg` / `reloadMs` / `burst`）＋
`combat.ts` 敌方开火段（三连发排期与逐发随机选靶；`BattleState.foeBurstFired` 记本轮已发数）。
✅ **2026-10-03 已落码**：`shotDmg 519 → 156`、`burst: { shots: 3, gapMs: 100 }`；
「目标选择随机」由本卡既有的 `foeTargeting: 'random'` 兑现（**每发各调一次 `pickTarget()`**）。
