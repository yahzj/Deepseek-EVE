## 一、船长原话（照抄）

> 「**虫洞前往下一层修改为必须在下一层入口才可以前往**」

四问四答（船长 2026-09-18 定案，全取推荐）：

| 问 | 裁定 |
|---|---|
| 严格度 | **只认「此刻站在入口格」**（离开就得走回来）——与守卫战同一把尺 |
| 按钮表现 | **站不在入口就不显示**「继续深入」（按钮出现 = 可以下去了，与"作业按钮只在真能用时出现"一致） |
| 判据层次 | **核心 `wormholeDescend` ＋ 界面**都加（老档线性层无网格 ⇒ 不受影响） |
| 入口标记 | **踩到入口格即标在地图上**（与"扫到出口格 / 踩到漂浮信标"同一收口） |

## 二、现状（读码坐实 · 动手前）

- **守卫战本来就要求站在入口**：`wormholeBattle.ts` boss 分支 `if (!here || !isExitCell(grid, grid.pos))
  return { ok: false, error: '层末守卫守在下一层入口：先找到并抵达入口。' }`。
- **「深入」原先没有任何位置要求**：`wormholeDescend`（`wormhole.ts`）只查 战斗中 / 待结算节点 /
  `bossCleared < depth` / `turnsLeft <= 0`；界面按钮只由 `bossDone` 决定 ⇒ 清完守卫后走开到任何地方都能下潜。
- **踩到入口原先不会把它标出**：`markExitKnown` 只在"扫到出口格"（`wormhole.ts`）与"踩到漂浮信标"时调用。

## 三、落码

| # | 文件 | 改动 |
|---|---|---|
| 1 | `packages/core/src/wormhole.ts` `wormholeDescend()` | 新增位置门槛：`if (run.grid && !isExitCell(run.grid, run.grid.pos)) return { ok:false, error:'没站在下一层入口：先走到入口（下潜点）再深入。' }`。**判据排在回合耗尽之后**（回合见底时"只能撤离"是更决定性的状态）；**无网格的老档线性层跳过** |

## 四、边界与不做

- 不改：守卫战口径（已要求站入口）· 撤离（不需要位置）· 回合/超载/战斗中的既有门槛 · 虫洞收益与威胁数值（零数值改动）。
- 老档**线性层**（`grid === undefined`）没有"入口格"概念 ⇒ **照旧放行**（兼容边界，有用例钉住）。
- 属玩法微调、不达"大更"标准 ⇒ 不发公告（船长若要，另出待审稿）。
