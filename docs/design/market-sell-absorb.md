## 一、背景

- 玩家反馈组装机"性价比极低甚至亏钱 + 额外制造费" → 船长先拍板取消每次制造费（已完成）。
- 卖通道此前讨论"放大收购吸收量（推荐）"，船长补充设计原则：**吸收量同样与价格挂钩**。
- 无池单件没有"自身流量"参照的问题，由本机制一并解决（保底吸收 + 折价放大替代伪流量阶梯）。

## 二、机制（船长确认口径）

**每窗总吸收保底 = 基础吸收额 F × 折价倍率 E**，吃簿优先、站内补差、绝不叠加：

- 每 60s 窗：卖单先照旧吃 npc 收购簿（价 ≥ 挂价的簿单，成交价按簿价计）；
- 当窗吃簿量 < F×E → 差额计入该单"补差结余"（小数跨窗结转）；
- 结余整数部分由站内以**挂单价**直接收购（日志"让利售出"，税/声望加成/池入账与簿成交同口径）；
- 吃簿量 ≥ F×E 的窗口只走簿面，不额外站内收购（**不叠加**，平价常态与现状长期持平）；
- 只对挂价 ≤ 现行买盘价的卖单生效：高于买盘价 = 等更高簿价，站内不接、不累计额度。

**公式**（基准买盘价 b = buyPrice(def, L)：池商品 = L、单件 = demandMultiplier×L，随行就市）：

- 折价深度 d = (b − p) / b（p = 挂单价；p ≥ b 时 d = 0 → E = 1 保底）
- 折价倍率 E = min(absorbMaxMul, 1 + absorbPerPoint × d×100)
  - 参数：absorbPerPoint = **0.4**（每让利 1 个百分点提速 +40%）、absorbMaxMul = **5**（封顶）
  - 折 1% → ×1.4、折 5% → ×3、折 10% → ×5 封顶；更深的让利不再提速（理性止步 10% 档）

**基础吸收额 F（件/窗）**（船长确认；per-good 可用 `absorbQtyPerWindow` 覆写）：

| 商品类 | F | 备注 |
|---|---|---|
| 池商品（矿/冰/气/矿粉/弹药等） | supplyFlow（缺省 poolTarget/120） | ≈ 现状自然吞吐量级 |
| common 无池单件（装备/蓝图/船/核心等） | 1 | 保底每窗 1 件（确定性替代 NPC 85% 概率刷新） |
| rare | 0.3 | 船长选字面口径（≈ 现状期望的 10 倍；吸收价仍是折价收购线，让利倾销由冲击压价自稳） |
| 奇货 | 0.1 | 同上 |

## 三、行为与叙事

- **平价挂卖（p ≈ b）**：每窗保底吸收 ≈ F×E = F，吃簿优先——与取消制造费前长期期望基本持平
  （单件从"赌 0.85 概率"变确定性 1 件/窗，体验更顺）；
- **让利挂卖**：压价即提速，折 5% ×3、折 10% ×5——急出货挂低价，不急挂平价慢慢走；
- **市价大单自动受益**：吃穿簿后剩余自动按边际价（≈ 簿深档 ≈ −8%）挂限价单，天然带 ~×4 提速，
  玩家无需学新操作；手动挂单可精确选档；
- 站内收购同样计入净卖出量（netVol）→ 大额让利抛售会触发负冲击压价，市场自稳（砸价越狠跌得越快，
  直到新均衡），不会无限套利；
- 高于买盘价挂卖：无保底无提速，维持现状等更高簿价。
