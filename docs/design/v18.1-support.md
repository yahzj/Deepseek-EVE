## 一、背景与船长拍板

V18A 上线"同类唯一"（抗性/容量同系、推进器全船各 1 件）后，船长指示：
1. **添加 EVE 式叠乘收敛，但不用"同类唯一"限制**——进一步拍板（问答两轮）：
   - Q2 自定义：**所有装备取消同类唯一**，速度、命中、闪避和抗性拥有叠乘惩罚；
   - Q3 自定义：**减算类项目用缺口复合**（例：两件 +20% 闪避 = 1−(1−0.2)² = 36%）；
     **非减算的系数用 EVE 标准曲线**（第 n 件权重 e^−((n−1)/2.67)² ≈ 100/87/57/28/11%）；
     追问澄清：**伤害与射速不走 EVE 曲线**（命中、速度才走）；未特别点名的同类型装备
     加成一律**加算**（线性求和，避免指数爆炸）；
   - 新增装备：部分提升 **射速 / 闪避 / 命中 / 指定类型伤害** 的中槽与低槽件。
2. 防混乱 UX（船长选甲案）：机制保留在引擎，UI 只呈现**两种标签**——
   「可多装 · 全额叠加」（线性件）与「多装递减」（收敛件）；装配预览直接给最终数值，
   公式不进玩家文案。

## 二、合成机制总表（core/equipment 收敛 API）

| 组 | 成员 | 多件合成 |
|---|---|---|
| **缺口复合**（gap） | 抗性（盾/甲各系）、闪避 | `1 − (1−base)·Π(1−xᵢ)`（`gapCombine`；抗性沿用 mergeResist 链天然收敛） |
| **EVE 曲线**（curve） | 命中（索敌阵列）、速度（推进器多件） | `stackWeight(n)=e^−((n−1)/2.67)²`；`curveMult = Π(1+pᵢ·wᵢ)`（按件效果从强到弱排位） |
| **加算**（flat） | 伤害稳定器%（三系）、射速装填缩短、容量%（盾扩/甲厚）、货舱扩展、无人机导控（现状 1+Σ） | `Σ pᵢ` 线性 |
| **实体线性** | 炮台 ×N、矿枪 ×N、无人机挂架 ×N | 数量即收益（V18A 已定，不动） |

- 装配层（equipment.fitModule）**删除同类唯一校验**：任何件可复数安装；
  防超模 = 收敛 + **CPU 全位合计**（档位 5/15/40）双约束。
- **推进器特例**（船长校对通过）：多件推进器速度加成 EVE 曲线；**开火失稳代价只取
  最重（削减最大）一件**（不连乘——连乘会变相恢复"只装一件"）。
- 旧档无需迁移（唯一键此前阻止了多装，无历史超限档）。

## 三、新装备：支援件 18 件（support 家族 × MK1/2/3）

家族判别：效果字段（types.ModuleDef V18.1 段）——
`damageTypeBonusPct`（按系）/ `reloadCutPct` / `hitBonusPct` / `evasionGapPct`。

| 族（id 前缀） | 槽 | 效果 MK1/MK2/MK3 | CPU | 叠加标签 |
|---|---|---|---|---|
| 动能/高爆/等离子稳定器 `mod-stab-{kin,exp,pla}-N` | 低 | 对应系**炮台**单发伤害 +6/10/15% | 5/15/40 | 全额叠加 |
| 射速计算机 `mod-rof-N` | 低 | 炮台装填 −5/8/12%（reload ÷ (1+Σ)） | 5/15/40 | 全额叠加 |
| 索敌阵列 `mod-track-N` | 中 | 炮台命中整体 ×(1+8/12/16%)，EVE 曲线 | 5/15/40 | 多装递减 |
| 姿态陀螺 `mod-gyro-N` | 中 | 被命中缺口削减 10/15/20%，缺口复合 | 5/15/40 | 多装递减 |

- 伤害件**只加成对应系炮台**（不影响无人机——无人机归战术导控）；三系独立（动能件
  不影响高爆炮）。
- 数量：装备 54 → 72；市场卡 121 → 139（MK1 常驻、MK2/3 稀有；价格按 C2 锚）。
- **数值全部为暂定初值，进 C4 校准轮复核。**

## 四、战斗接入点（combat.createPlayerSpec，AI 副船同源）

- 伤害稳定器：该系 gun 条目单发 `perShot ×(1+Σ 系加成)`；
- 射速计算机：gun 条目 `reloadMs ÷ (1+Σ)`（下限 100ms）；
- 索敌阵列：gun 条目新增 `eqHitMul = curveMult(命中件)`——在 hitChance 中与推进器失稳
  分开乘（`raw × eqHitMul × hitMul`），只作用于炮台；
- 姿态陀螺：`evasion = gapCombine(闪避件, 船体基础回避)`（全船）；
- 推进器多件：`speedMps = 船体 × curveMult(推进速度件)`；`hitMul = 1 − 最重失稳`。

## 五、防混乱 UX（船长选甲案）

- 全 UI 两种标签（moduleShortEffect 尾注 / 悬浮叠加方式行 / 手册一致）：
  - 线性件：「可多装 · 全额叠加」；
  - 收敛件：「多装递减」（curve 悬浮写明 ≈87%/57% 曲线；gap 写明缺口复合）。
- FitPage 合成预览行：回避率 / 开火命中修正（失稳 × 索敌）/ 机动速度（含加力）——
  均为装后最终值；
- FitPage 空位候选下拉：收敛件已装同类时标注「同类第 N+1 件：按 X% 生效 / 只削剩余缺口」；
- 删除「同类唯一」叙事（FitPage/悬浮/门槛档文案全部更新）。
