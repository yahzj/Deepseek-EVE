# V12b 设计：星图航行跃迁（warp × 航行加速技能族）

> 状态：**已确认**（用户 2026-09-04 确认：反比式换算、基准 3.0 AU/s；
> 技能范围 = 导航学 + 跃迁引擎操控 + **加速控制理论**（新增），三者趋同统一；
> 规避机动理论不引入（战斗向）；装配推进器本轮不参与）。
> 影响包：core（travel.ts + mining/expedition/ai 接入）、data（skills.ts 文案）。
> 无存档结构变更（船 warpSpeedAus 字段 V10.5b 已有、技能等级本来在档）→ 不升版本号。

## 一、规则

```
实际航程耗时 = 标称分钟 × 60_000 × 航行因子
航行因子     = (warpRefAus / warpEff)
             × ∏ (1 − cutPerLevel × 技能等级)     // 三技能各一乘区
warpEff      = 当前/指定船 warpSpeedAus（数据 2.8~3.9；缺失 = warpRefAus 不缩放；clamp [0.5, 12]）
航行因子下限  = minFactor（0.35）：组合再强航程也至少保留 35% 时间
```

默认值（`core/src/balance.ts` → `balance.travel`）：
`warpRefAus: 3.0`、`minFactor: 0.35`、`cutPerLevel: 0.04`、
`skillIds: ['navigation','warp-drive-operation','acceleration-control']`。

**统一换算入口**（`core/src/travel.ts`，经 `@whale/core` 唯一出口导出）：
`warpSpeedAus` / `travelTimeFactor` / `travelLegMs`（毫秒，round）/ `travelMinutesEff`（展示，round 分钟）。

## 二、应用点与边界（全部经统一入口）

| 场景 | 接入 | 说明 |
|---|---|---|
| 采矿周转 | `oneLegMs` 航程段 | 4 分钟带内周转基础**不缩放**（shipId 参数化，AI 副船按自身船速） |
| 远征 | `startExpedition` outMs 锁定、返航同值 | 出发时按当时船+技能锁定，途中升级不影响本次 |
| AI 采矿/远征 | `advanceAiMining` 腿、`assignAiExpedition` outMs | 按副船自身 warp 换算后 ÷AI 效率 |
| 星图 UI | 选中星系"距母港单程"、悬赏卡航程 | 显示实际分钟；边上的标称 ′ 分钟保留（图论权重） |
| 路径规划 | 不参与 | Dijkstra 仍用静态 `travelMinutes`（只影响"走完要多久"） |

## 三、航行加速技能族（趋同统一）

EVE 检索结论（来源：[EVE 中文 wiki·技能/导航学](https://eve.huijiwiki.com/wiki/%E6%8A%80%E8%83%BD/%E5%AF%BC%E8%88%AA%E5%AD%A6)、
[EVE Academy magic-14](https://www.eveonline.com/zh/eve-academy/magic-14)、[eve-search](https://eve-search.com/thread/564561-0)）：

- **导航学**（已有，rank 1）：原 EVE 效果 = 亚光速航速 +5%/级 → 本游戏激活为航行加速。
- **跃迁引擎操控**（已有，rank 2）：原 EVE 效果 = 跃迁启动电容 −10%/级；游戏无电容/准备机制，
  船长裁定**归类同性质**（航行加速）。
- **加速控制理论**（新增，rank 2）：原 EVE 效果 = 加速度提升；船长裁定**趋同统一**（航行加速）。
- **规避机动理论**：战斗机动域（agility），**不引入**（船长裁定）。
- 文案统一句式：`航行加速：每级缩短星图航行时间 4%（同类技能乘算叠加）。`（前置一句 EVE 风味说明）
- 幅度：每级 −4%，乘算叠加。满配示例（3.9 AU/s 顶级船 + 三技能 5 级）≈ ×0.39（省 61% 航程时间）。

## 四、数值示例（单程 6 分钟标称）

| 场景 | 航行因子 | 实际单程 |
|---|---|---|
| 无 warp 数据船（测试/缺省） | 1.0 | 6 分钟（旧行为不变） |
| 初始船 沙猫级 3.5 | ×0.857 | 5.1 分钟（快 14%） |
| 慢船 2.8 | ×1.07 | 6.4 分钟（慢 7%） |
| 3.5 + 导航 5 | ×0.686 | 4.1 分钟 |
| 3.9 + 三技能满 | ×0.394 | 2.4 分钟 |
| 任意 + 极端数据 | 下限 ×0.35 | 下限保护 |

## 五、后期预留：跳跃系统（旗舰系，未实施）

船长指示（2026-09-04）：EVE 旗舰跳跃系三技能——**跳跃引擎操控 / 跳跃燃料节约 / 跳跃通道发生学**——
作为**后期玩家快速移动手段**：消耗特定资源、瞬间到达目的地（星图直达）。
本版本**不引入**技能与资源，仅备案意图：
- 机制轮廓：消耗"跳跃燃料"类资源，从母港/跳跃通道点瞬间抵达目标星系（跳过航行时间）；
- 定位在"后期"（对标 EVE 旗舰/跳跃通道），届时再走确认流程定资源种类、冷却/限制与三技能效果；
- 命名注意：普通航行技能族用"跃迁/航行"词，未来跳跃系用"**跳跃**"词族避免混淆
  （跃迁引擎操控 = 普通航行加速；跳跃引擎操控 = 后期瞬间移动，名字已天然区分）。
