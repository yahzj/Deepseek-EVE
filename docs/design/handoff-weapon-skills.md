## 二、引擎技能触点现状（战斗侧）

**唯一已接线的战斗技能 = `gunnery`（炮术学，rank 1，战斗组）**：
- 乘区 = `dmgScale = (1 + battle.gunneryDmgPerLevel×Lv) × (1+船 powerBonus)`，每级 +5%
  （balance.ts battle 段 `gunnerySkillId`/`gunneryDmgPerLevel` = 0.05）；
- 覆盖面：**gun（动能炮/导弹架）与激光（beam）条目单发 + 基础舰炮**（createPlayerSpec 构建期
  乘入）；**不含无人机条目**（无人机只吃战术导控装置）。
- 技能训练时长：基础 60s×2^(级−1)×rank（见 skills.ts 头注释）。

战斗相关隐藏占位（engine HIDDEN_SKILL_IDS 禁训隐藏，等战斗数值开放）：
- 工程组：`shield-operation`（护盾操作学）、`energy-management`（能量管理学）、
  `hull-upgrades`（船体加固理论）——文案仍是"以后生效"，随防御侧技能填充开放。

**尚未开放技能乘区的战斗参数点**（如需技能化，谁接谁做请在提案里写明，避免双改）：
命中加成、装填/射速、射程带、回避、无人机伤害/放飞 CPU、激光威力衰减斜率、导弹
近盲距离、按族伤害（动能/爆炸/能量分家而非 gunnery 全包）等均无技能消费字段——
接线点在 combat.ts createPlayerSpec / 战斗循环，属**战斗数值域（二号）**：建议一号出
技能提案（名称/组/rank/⟦数值⟧文案草稿）→ 船长确认 → 触点由二号（或一号并行按约定文件
划分）接入并补测试。

## 三、给一号的填充建议骨架（草案方向，数值一律待船长确认）

1. **武器族技能化方向**（呼应"按伤害类型设计武器"）：每形态一族主技能
   （如 质量炮操作 / 导弹发射学 / 激光炮学——命名自由，勿与临时动能炮捆绑），
   族技能乘区建议与 gunnery 并列新乘区（乘性叠加）或拆分替代——**数值模型由二号出
   方案再定，一号先出结构与文案**；
2. 文案红线：**不再用"炮台/炮弹/高爆弹/等离子弹"等旧称谓**——弹药 = 动能弹 /
   爆破导弹 / 能量弹药；武器 = 炮台（动能）/ 导弹架 / 激光炮；"导弹无视近盲"表述已
   作废（现为近盲安全射距）；激光 = 必中 + 威力衰减（幅度减半）；
3. 技能描述须写真实效果 + ⟦数值⟧ 标记（规范见 skills.ts 头注释），数值改动需同步
   balance 常量与 description（既有规则）；
4. 无人机与防御侧（盾/甲/结构隐藏技能）属于同一填充批次可选范围；
5. 已接线 gunnery 文案"舰炮战斗训练：实时战斗单发伤害 +5%"仍准确（覆盖三形态），
   可保留或随族技能化后收敛为通用/覆盖族——改动前经船长确认。
