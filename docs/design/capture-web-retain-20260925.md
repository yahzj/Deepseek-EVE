## 船长原话（照抄）

> 「**装备劫掠捕获网的船攻击时，如果命中已经被捕获的船时，并不会触发，而是保留直到攻击了没有被捕获的船**。」

## 取证（先查真相，再改）

**① 场景是常态，不是边角**：捕获网挂在两处 ——
A 族「劫掠电子舰」（每场 1 艘，写在深层战团条目上）＋ **H 族「墨潮突击舰」的舰级**
（2026-09-24 船长令「墨潮突击舰添加 A 族洞内电子舰同款网子和冲锋」）。
引用后者的卡是 **多艘同时上场**：`ink-harass` 骚扰舰队 **×4** / 袭击舰队 ×2 / 另有 ×3、×4 两张
（`packages/data/src/wormholeFoes.ts`）⇒ **一队里 2~4 张网同场**。

**② 现行行为不是"保留"，是"静默作废"**（真引擎实测 · 真实入侵卡 `ink-harass` ＋ 我方只 1 艘船）：

| 读数 | 改前 |
| --- | --- |
| 记「网已发放」的敌舰（`foeWebFired`） | **4 艘**（四艘都记了） |
| 实际被钉住的目标（`meWebDebuffs`） | 1 个 |
| 蓝线（张网）事件 | **1 条** |

⇒ 根因 = `fireFoeCaptureWeb` **无条件先记 `foeWebFired` 再判"目标已被钉住"**：
第 2 艘起的第一发打到同一目标时，本函数早早 return —— **不推特效、不写日志、此后整场不再发放**。
`git log -S` 显示这个顺序**自 2026-09-16 落码起就没变过** ⇒ 船长记的"保留"是要的口径，代码从没做到。

## 改动

- `packages/core/src/combat.ts` 的 `fireFoeCaptureWeb`：**把 `foeWebFired` 记账挪到"目标已被钉住"那道
  判断之后** ⇒ 只有**真正钉住一个未被捕获的目标**时才算发放；打空（目标已被别的网钉住）时本舰的网
  **留着**，下一次开火再试。三条口径一并写进函数头注（整场只发一次 / 多艘不叠加 / **打空不算用掉**）。
- `packages/core/src/state.ts` 的 `foeWebFired` 字段注释同步（点明"打空不算用掉"）。
- 调用点注释同步（判定在函数内部，调用点只判"本舰还没发过"）。
- **句式与效果一字未动**：四层效果（机动 ×0.1 / 关推进器 / 闪避归零 / 射程 −500m）、不看命中、
  击杀发动者即解除、不叠加 —— 全部照旧。
