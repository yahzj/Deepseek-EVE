## 一、排版问题诊断与顶尖 UI 方案

1. **左侧活动栏字符竖排折断问题（船长 11-02 追修）**：
   - **病因**：在 150px 窄列内，旧版 `.app-activitybar-item` 默认 `flex-direction: row` 且内部 flex 容器发生恶性挤压，导致技能名「导航学」、说明「训练至 Lv1 (当前 Lv0)」、时间与「移除」按钮被压缩为多列 1~2 字符宽的垂直折行，字符像竹简一样竖立。
   - **横向化重构（字体不缩小、尽力横着放）**：
     - **行 1（头部两端对齐）**：左侧 `[图标 + 技能名]` 横向靠左对齐，右侧 `[微型移除/停止按键]` 横向靠右对齐。技能名字号保持 `--wui-fs-sm`（12.5px）加粗，与右侧按键互不挤占。
     - **行 2（说明独占满宽）**：`训练至 Lv1 (当前 Lv0)` 独占整整一行（100% 满宽横向展开），`white-space: nowrap;` 绝不折断成竖排。
     - **行 3（满宽科技进度条）**：独占整整一行，科技发光轨道。
     - **行 4（进度与时间独占满宽）**：`12% · 剩 1分45秒` 独占整整一行横向展示，不再被右侧按钮挤压撕裂。
     - **视觉成果**：彻底告别竖排挤压，四行信息流全为清晰横排，字形饱满且字体完全不缩小。

1. **左侧活动栏「计时中」幽灵标题问题**：
   - 当无正在扫描星系且突触加速剂未激活时，仍固定渲染「计时中」标题，而下方空空如也，导致视觉上下一组「技能训练」像是「计时中」的子项。
   - **落地**：增加 `{scanBar || boostRemainMs > 0 ? (...) : null}` 条件包裹，无计时项时不渲染空标题。

2. **左侧活动栏项目碰运气折行问题**：
   - 原先在 150px 窄列内，标题、副信息、进度条、时间全部挤在同一个 `flex-wrap: wrap` 容器里，导致技能训练卡片被强行切碎成 5 行。
   - **落地**：重构为分层垂直信息流：
     - 行 1（头部）：图标 + 标题（单行防溢出，ellipsis 截字带原生 title 提示）
     - 行 2（说明）：全宽副信息行（微型高阶字阶，整洁平滑）
     - 行 3（进度）：全宽独立进度条（100% 满宽，深空高科技轨道光效）
     - 行 4（底栏）：左右对齐元数据（左侧百分比与剩余时间，右侧紧凑微型操作按键，不占大面积红块）

3. **左侧待机状态排版碎片化问题**：
   - 原文案为横向布局长句，窄列下破折号和标点断裂严重。
   - **落地**：新增待机微面板组件（`ActivityBarIdle`），智能解析为状态呼吸点 + 主状态词 + 操作引导短语，并支持快捷点击跳转对应功能区（玩家活动跳星图、技能跳技能页、AI跳AI指挥中心）。

4. **底部导航栏普通项字号过小问题**：
   - `.app-nav-side .app-nav-item` 原字号仅为 `--wui-fs-2xsc`（9.5px），阅读极为吃力，与中间「出港」12.5px（700字重）脱节。
   - **落地**：字号提升至 `--wui-fs-sm`（12.5px），字重设为 500，居中饱满，清晰舒适，完全容纳在 78px 定宽内。
