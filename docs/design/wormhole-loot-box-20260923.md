| 路径 | 改前 | 改后 | 常量 |

| **战果（虫洞敌人掉落）** 出货柜 | 0.75% / 场 | **5% / 场** | 新增 `WORMHOLE_LOOT_BOX_CHANCE = 0.05` |

**过程留痕（两次裁定）**：这两处原本**共用一个常量**（战果那条是同日早先按船长「和残骸格一样（0.75%）」借用的）。

不变项：**每次最多 1 个**（`WORMHOLE_SALVAGE_BOX_MAX`）· 四类货柜**类等权**（族安全货柜 / 图纸货柜按层过滤 / 贵重品货柜 / 军用备货柜）· 落点仍走遗迹货柜那套收货阶梯（货仓 → 临时空间 → 散落该格）· 掷骰仍是**独立盐值**（不消费既有掷骰序列，旧读数不受扰动）。

**量级提示（如实登记）**：0.75% → 5% 是**约 6.7 倍**；货柜属大件战利品（贵重品货柜口径价 ≈ 382.8 万 ISK，安全/图纸货柜另有自己的池）
