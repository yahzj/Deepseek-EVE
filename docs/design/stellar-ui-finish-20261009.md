## 范围

星系探索表现域，沿用现有星图、详情和固定任务/生产区。修复星系/地表样式使用未定义主题变量、危险确认的背景与键盘边界，以及地表返回焦点；保留地图会话视口和选择。地表只修现有标题字号，不重做开发界面，不改核心规则、数值、存档或旧宇宙星图。

写实PNG/GIF素材路线仍待明确批准：现行规约要求SVG线稿，不能把继续已确认布局收尾解释为位图例外或运行PixelPlanets授权。本轮不运行外部程序、不装依赖、不生成英文或接入远程资产。

## 技能与参照

`ui-ux-pro-max`的ux域检索「focus not obscured modal confirmation」命中Focus Not Obscured与Focus States：被覆盖的背景控件不能获得焦点，确认内控件需可见焦点。支持按现有确认模式修边界；不借此替换布局或建立新提示层。参照现有星图44px工具条、确认框和全仓`--wui-bg-panel`/`--wui-bg-deep`/`--wui-fs-lg`变量。React依现有hooks、refs和清理模式；不增加持续动效。
