改为 `96 * 3_600_000`（**周五 20:00 ~ 周二 20:00**）。

该常量是"窗口"的**唯一出处**，因此四处判定一起跟着走（无需第二处改动）：

| 读它的地方 | 含义 |
| --- | --- |
| `weekendWindowOpen` | 窗口内才存在入侵（`ensureWeekendEvent` 的开局闸） |
| `weekendTick` ④ | 正常模式窗口到点 ⇒ 结束本场（`T0+96h`） |
| `ensureWeekendEvent` | 「一个窗口只开一场」：上一场开始至今不足 96h ⇒ 不开新场 |
| `weekendWindowMsOf` | 活动总时长读数（调试档 = 本值 ÷ 60） |
| 首场特例失效时刻 | `nowWallMs >= 首场 + 96h` |

**直接效果**（船长要的应该是这个）：NPC 保底不变（外围 `T0+48h` 满 · 核心再 24h ⇒ `T0+72h` 满）
⇒ **旗舰的可打时间由 2 小时变成 24 小时**；章鱼那 24h 削血窗口也正好落在窗口之内。
