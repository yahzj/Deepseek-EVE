原话（照抄）：「**对手册中的各个图鉴添加筛选，如果有子分类的，主筛选选择之后出现子分类筛选。物品界面的仓库也添加筛选**」

| 问 | 船长选的 |
|---|---|
| 物品图鉴 / 技能速查没有现成第二层，怎么办 | **只做一级**（有子分类的装备 / 舰船 / 蓝图才有二级） |
| 仓库筛选怎么分 | **大类 + 装备二级**（选「装备」时出现槽类） |
| 二级行什么时候出现 | **选了主类才出现**（组装机现行口径；「我的舰队」的「两行常显」不适用于本批） |
| 筛选状态要不要记住 | **每次打开重置**（不落盘） |

## 二、主 / 子维度表（实现口径）

| 页签 | 一级（主筛选） | 二级（子筛选，选了主类才出现） |
|---|---|---|
| 物品图鉴 | 物品大类（原矿 / 原材料 / 气体 / 冰矿 / 弹药 / 无人机 / 残骸 / 货柜 / 蓝图碎片 / 修理组件，即 core `ITEM_KIND_ORDER`） | 无（无天然第二层） |
| 装备图鉴 | 槽类（高槽 / 中槽 / 低槽装备，`RACK_SUBS`） | 功能九组（`MODULE_SUBS`）＋「其它」 |
| 舰船图鉴 | 角色（采矿舰 / 货运舰 / 武装舰 / 重装舰，`SHIP_SUBS`） | 级别 T1~T5（`SHIP_TIER_SUBS`） |
| 蓝图图鉴 | 门类（装备蓝图 / 舰船蓝图 / 消耗品蓝图） | 装备→槽类（高/中/低）· 舰船→T1~T5 · 消耗品→无 |

| 物品页·仓库 | 物品各大类 ＋ 「装备」 | 只对「装备」：槽类（高/中/低，`RACK_SUBS`） |

**判据同源**：筛选判定与各页**分组键逐条对齐**（装备按 `rackOf`、舰船按 `role` / `tier`、蓝图按 `shipId` / `itemId` / 产物槽类），避免"筛出来的条目和分组标题不一致"。

## 三、行为口径

1. **与搜索取「与」**：搜索词 ＋ 一级 ＋ 二级三者同时生效；命中计数在任一生效时显示「匹配 N」。
2. **分节照旧**：内容区仍按原小组分节渲染（现有小节标题与"空组隐藏"不变），筛选只决定"哪些小节在"。
3. **级联归零**：换一级＝二级回「全部子类」；换页/关手册＝两级都回「全部」（不落盘，与市场页「切类型即回全部子类」同哲学）。
4. **左侧导航计数不含筛选**：导航栏仍是"条目数 / 搜索命中数"（筛选是当前页的临时收窄，不改变目录规模）。
5. **仓库三处细节**：① 选了某个物品大类时，**装备库整块不渲染**；② 槽类二级**只作用于装备库**；③ 「矿石 / 矿物空面板常驻」这条教学性规则在**搜索或筛选生效时不再常驻**（空块隐藏）。
6. **一级页不滚红线**：仓库的筛选行并入**固定工具条**（复用 `.app-fleet-toolbar` / `.app-fleet-row` / `.app-fleet-scroll` 一套），标题行与筛选行冻结、内容区照旧内滚；**「货仓」tab 本批未动**。
7. **样式零新增**：胶囊与行结构全部复用组装机 / 舰队那套类名（`app-task-tabs` ＋ `app-fleet-tabs` ＋ `app-tasktab`），只为手册新增一条容器内边距（`.app-hand-filters`）。
