# V17/V17.1 设计：装备参数结构化（EVE 式"参数进公式"· 定稿）

> **V18.1 更新（2026-09-04 船长拍板）**：本文档"抗性/容量件拆族、同槽二选一"的
> **唯一性约束已被取消**（含推进器）——全部件可多装，收敛靠叠加机制（缺口复合 /
> EVE 曲线 / 加算，见 docs/design/v18.1-support.md）。参数进公式的分族模型本身不变。

> 状态：**V17.1 定稿已实现**（船长逐项审核后定稿：抗性/容量拆族、纯抗保守档、
> 推进器常驻命中代价、CPU 成倍档位；core 268+ tests 全绿）。
> 背景：V12 战斗引擎早已落地，但装备停留在 V10.5 占位契约（抗性绝对加算、推进器
> 引擎完全不消费、炮台旧 bonus 百分比残留）。船长方向（多轮确认）：
> **装备不再是单纯的百分比加成**——参数进公式的具体环节、装配有取舍与资源约束。
>
> 决策记录：
> 1. 抗性形态 = 同代次分系专精（动能/高爆/能量 × MK1-3），EVE 式乘缺合成（拍板）；
> 2. 反馈修正 = 增强器应为**纯抗性**而非"容量+缺口"混装（船长："以为是抗性装备，
>    结果居然削减抗性增量容量"）→ 抗性件/容量件**拆族**、同槽二选一；
> 3. 补充 = 单纯提高护盾/装甲容量的容量件也要（护盾扩展器 / 装甲增厚板）；
> 4. CPU = 随档位成倍（低级 5 / 中级 15 / 高级 40，civ 3、炮台加码）——拉开船级差距；
> 5. 推进器 = 加力推进（速度进战斗）＋ **常驻命中代价**（船长指定：使用推进器时
>    削减武器命中率；低档轻微 / 高档重：×0.95 / ×0.88 / ×0.80）；
> 6. 槽制 = **V18 立项**：EVE 式高/中/低槽（船体布局制；炮尺寸已随 V18 口径取消移除，
>    纯数量布局）作独立里程碑，V17 参数与之正交（详见 §七与 docs/roadmap.md C3）。

## 一、装备结构（42 件，V17.1 定稿）

| 家族 | 槽 | 形态 | 件数 |
|---|---|---|---|
| 采集器 / 货舱扩展 | miner / cargo | 工业加成（产量 / 容量百分比，非战斗） | 5 + 5 |
| 炮台 | turret | 完整武器卡（配弹/射程带/命中/装填/伤害倍率） | 5 |
| **护盾增强器** | shield | **纯抗性**：动能/高爆/能量 × MK1-3（乘缺） | 9 |
| **护盾扩展器** | shield | **纯容量**：MK1-3（与增强器同槽二选一） | 3 |
| **装甲镀层** | armor | **纯抗性**：动能/高爆/能量 × MK1-3（乘缺） | 9 |
| **装甲增厚板** | armor | **纯容量**：MK1-3（与镀层同槽二选一） | 3 |
| 矢量推进器 | propulsion | 加力推进（速度 + 命中代价） | 3 |

数据字段（types.ts ModuleDef）：
- 抗性件：`shieldResistAdd / armorResistAdd: DamageResists`（单键专精）；
- 容量件：`shieldHpBonus / armorHpBonus`（抗性件不再携带）；
- 推进器：`speedBonusPct`（速度）+ `hitPenalty`（命中削减量，缺省 0）；
- 炮台：V11 武器卡全套；工业件：`bonus`（仅工业槽语义）。

## 二、抗性合成：EVE 式"乘入未抗部分"（V17.1 纯抗数值 = 保守档）

```
实际抗性 = 1 − (1 − 船体基础抗) × (1 − 模块值)，每系独立，上限 0.9
```

| 件 | MK1 | MK2 | MK3 |
|---|---|---|---|
| 护盾增强器（各系同值） | +20%（25% 基船 → 40%） | +35%（→ 51%） | +50%（→ 63%） |
| 装甲镀层（各系同值） | +25%（25% 基船 → 44%） | +40%（→ 55%） | +55%（→ 66%） |

- 船体基础抗越高边际收益越低（0.5 基 + MK3 盾件 → 75% 封顶前仍显著）；无基础船面板 = 模块值。
- 引擎：combat.mergeResist（导出，测试/UI 同源）；实时结算与胜率预估（battleWinPreview /
  aiWinPreview）共用 createPlayerSpec——装配变化自动进预估，无第二套数值。
- 克制在前、抗性在后：动能打盾 ×1.5 先乘，再 ×(1−抗)。

## 三、容量件与同槽取舍

- 护盾扩展器：盾容 +15 / +35 / +60%（MK1-3）；装甲增厚板：甲容 +20 / +45 / +80%。
- 与抗性件占用**同一个槽位、只能装一件**：要克制某系伤害（对敌主伤换抗）还是
  硬吃一切（堆容量），出发前在装配台二选一——EVE"配装取舍"的最小落地。
- content-check 断言拆族互斥（容量与抗性不可同件）。

## 四、CPU 装配资源（V17.1 定稿：成倍档位 = 船级差距的隐藏分）

| 档位 | 民用 | MK1（低级） | MK2（中级） | MK3（高级） | 异星原型 |
|---|---|---|---|---|---|
| 工业 / 战斗件 | 3 | **5** | **15** | **40** | 60 |
| 炮台 | 6 | 10 | 28 | 52 | 70 |

- fitModule 六槽合计 ≤ 船体 cpu，超载拒绝并提示差额；与无人机放飞共用（CPU 占用满 =
  战斗无余量放无人机——取舍而非错误）；
- 沙猫（CPU 60）= 低级全套上限；MK3 顶配（240+，含炮台）只有 220+ CPU 的顶级船能接近
  满配 → 高级船不只是数值高，还能"带得动"高级装备（装配台 CPU 行有档位说明）。

## 五、矢量推进器 = 加力推进（常驻代价，V17.1 定稿）

| | MK1 | MK2 | MK3 |
|---|---|---|---|
| 战斗速度 | +15% | +30% | +50% |
| 命中代价 | ×0.95 | ×0.88 | ×0.80 |
| CPU | 5 | 15 | 40 |

- 速度乘入 UnitSpec.speedMps → combatSpeed（距离操纵：贴近/拉开/脱离敌网）；
- `hitPenalty` 乘入 hitChance（attacker.hitMul，缺省 1）——**我方全部武器命中**整体缩放，
  实时结算与胜率预估同源；敌方单位不受影响（无 hitMul）；
- 弃船逃生 / 跃迁充能仍随船体 agility（模块不碰船体间接属性）。

## 六、展示口径 / 存档 / 校验

- UI：抗性一律正向表述（"动能抗 +20%（乘入制…25% 基础船 → 40%）"）；
  **装配台显示"装后合成"**：血量（含容量件）与三层最终抗性（与战斗引擎同源
  createPlayerSpec），不需要玩家心算；推进器行明示速度与命中代价；CPU 行带档位说明。
- 悬赏卡"敌主伤 动能/高爆/能量"（foeMainDamageType 与编队同源）——换装决策入口情报。
- calcPower（火力指数）不再乘装备百分比（展示口径 = 基础+炮术+船型；装备战力走
  battleWinPreview）。
- 存档：旧 id（mod-shield-1/2/3、mod-armor-1/2/3 通用全系件）载入时由
  repairDeprecatedModules 原位迁移为动能款、装备库计数并入（GameEngine.start 离线结算前
  执行，幂等）。V17 早期混装件未发布过正式版本，无需迁移。
- 校验：typecheck（4 包）/ core tests / content:check（拆族互斥、值域、CPU>0 整、
  市场交叉引用）/ desktop+web build。
