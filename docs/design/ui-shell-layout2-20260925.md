## 三、教训（本批已踩，写下来避免再犯）
1. **改完结构必须量"每段的实际占用"**——只顾"活动栏在左"而没量"主窗口还剩多少"，
   导致主窗口被挤到 218px（船长反馈"主窗口不存在"）；
2. **`width:100%` + padding 必须配 `box-sizing: border-box`**（本仓 header/workspace 早有此注释，加底栏时漏抄）；
3. **每项要求单独验收**：改完对着船长原话逐条核，别"整体感觉对了"就交。
