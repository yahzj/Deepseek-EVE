# 挂单瞬间吃簿：与现有簿面对冲的挂单立即成交（状态：已确认，2026-09-10 船长拍板；一号实现）

> 船长 2026-09-10 反馈：「当玩家挂单购买时，并不对市面上已有的卖单进行核对，导致玩家可以挂出和卖单价格一样的买单。」
> 船长决定：① 挂价与簿面冲撞时**立即吃单、剩余继续挂单**（标准限价单语义）；
> ② **买卖两侧对称**一起修。core 行为修复 + renderer 回执文案；存档与数值口径零改动。

## 1. 根因

- 撮合只在**每 60 秒的市场窗口**跑一次（`balance.market.tickMs = 60_000`：`processWindow → matchPlayerOrders`）；
  **挂单这个动作本身完全不核对簿面**。
- 而「挂单买」表单的价格**默认预填当前最佳供应价**（`MarketPage`：`quote.sell ?? askLineOf(...)`）——
  也就是盘口里那一笔卖单的价格。玩家点一下即挂出与在售**卖单同价**的买单，且不会成交。
- 到下一个窗口时 NPC 供应阶梯已**带 ±2% 抖动重铺**，挂价常常低于新卖价 → 这单长期挂着，
  只能靠"越线抢单"的每窗掷骰（`snatchBuyChance=0.2`）碰运气。窗口撮合的价格规则本身没问题
  （买单吃「卖价 ≤ 挂价」、**同价算成交**，`npc.price > order.price` 才跳过）。

## 2. 修复（`packages/core/src/market.ts`）

- 抽出 `eatBook(state, ctx, order)`：确定性吃现有簿面，与窗口撮合**共用同一批结算函数**
  （`settleBuy` / `settleSell` → 钱货、贸易税、声望加成、库存池、日志完全同源）：
  - 卖单：吃「收购价 ≥ 挂价」的收购单（同价算成交），按挂价入账（既有口径不变）；
  - 买单：吃「供应价 ≤ 挂价」的供应单（同价算成交），按**簿面供应价**付费（玩家不亏）；
  - 目录外的下架商品不撮合（沿用 2026-09-09 防御：防走 `depositGood` 空目录分支）。
- 新增 `crossOnPlacement(...)`：挂单瞬间调 `eatBook`；**全部成交的单直接移出挂单表**
  （不再出现在「我的挂单」，也不必等窗口清理），部分成交的剩余量继续挂着等后续窗口。
- 接入四条挂单路径：`placeBuyOrder` / `placeSellOrder` / `listSellHolding`（UI 卖单入口）/ `placeShipSellOrder`（整船二手挂单）。
- **不动**：60 秒窗撮合照旧；越线抢单（买单低于供应价线 / 卖单高于收购价线）仍是**每窗掷骰**，
  挂单瞬间**不额外掷骰**（不改变既有手感与随机数消耗序列）；站内让利吸收、`windowFilled` 配额结算、
  贸易税与限价上限等口径一律不变（即时吃单写入的 `windowFilled` 会在下个窗口开头归零，不挤占吸收配额）。

## 3. 回执（renderer）

- 游戏日志与界面回执都写明即时成交结果：`已挂买单：…（挂在簿上，等对手单成交）` /
  `买单已即时成交：…×N @ P ISK` / `买单已即时成交 k 件，余 m 件挂单 @ P ISK`（卖单同构）。
- `engine.placeBuyOrderAt` 改为返回 `{ orderId, want, filled, resting }`；`placeSellOrderAt` 透传
  core 结果里的 `filled / resting`；`MarketPage.doPlace` 用新文案（保留奇货低价挂单的既有提醒）。

## 4. 验证

- 新增 `tests/market-cross.test.ts`（8 例）：同价买单即成交且钱货两清、高于卖价按簿面价付费、
  买多吃少（剩余挂单）、多档按低到高吃、不冲撞不吃簿、卖单侧同价即成交（含 5% 税与托管释放）、
  卖价低于收购单按挂价拿钱、卖单不冲撞留在托管与挂单表。
- 既有两个测试按新语义更新（原断言"挂单等到窗口才成交"）：贸易税用例改为
  「不冲撞的挂单免费 + 压线挂单挂出即成交扣税」；商品下架用例改用"不吃簿的低价残留单"
  构造旧档场景（防御语义不变）。
- 真实目录探针（临时 `_` 前缀脚本，已删）：物品/装备/蓝图/核心四类真商品同价买单均即时成交，
  付款 = 簿面价 × 成交量，单件商品余量正确留挂单；低价买单不成交留在挂单表；卖单侧压线即成交含税。
- `npm run typecheck` 四包全绿；`npm run test -w @whale/core` **649 passed**（65 文件）；
  `npm run build -w @whale/desktop` 绿。推送闸门：只本地 commit，未推送 origin。

## 5. 已知取舍（供船长复核）

- 买单即时吃单按**簿面价**付费（≤ 玩家挂价）：比"按自己挂价成交"更省，符合限价单语义；
  卖单仍按**自己的挂价**入账（既有口径，未改动）——两侧价格口径的这处不对称是历史设计，
  若希望卖单也按簿面更高的收购价入账，需另行拍板（涉及收益口径，本次未动）。
- 挂单瞬间不掷越线抢单骰：低于供应价线的买单仍按每 60 秒窗口 20% 概率等到货；如希望"挂单即掷"，另行拍板。
