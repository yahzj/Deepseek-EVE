# 战损插件并入现有插件展示区

> **状态：实现与自测完成，待本地合入及船长验收**（零号 · `dsh/system-search-20261007` · 2026-10-07）
> **船长原话**：「首先是关于之前的打捞沉船机制，测试后发现，负面插件应该合入现有的插件槽，并列展示，单独列出过于突兀。」
> **范围**：舰船、装配、沉船记录的战损卡格与普通插件同区并列；不修改回收概率、战损强度、制造或普通维修规则。
> **待裁决点**：无；船长「确认」采用同区展示、不占普通安装名额，存档与回收数值不变。

## 一、现场核对与规则冲突

- `ShipDamageMods.tsx`当前绘制独立标题及逐条展开详情，分别挂在舰船卡、装配区和沉船记录底部。
- 普通插件在`FitPage.tsx`的`PlugSlots`内按船型槽数绘制`.app-fit-slot-icon`卡格；沉船记录在`WreckFitPanel.tsx`有独立普通插件网格。
- 原确认`docs/design/ship-wreck-recovery-20261007.md`明确「战损插件不占普通插件槽」，最多3个、同类不重复。普通舰船插件槽数按T1~T5分别5／4／3／2／1；槽已满的回收船仍会携带普通插件及新增战损。
- 船长新提议「合入现有插件槽」若指真正占用槽数，与旧规则冲突。后果是T5船一格可能已有普通插件，回收再增加战损就超额；需要另定挤出普通插件、超槽保留、限制新增战损等行为。仅展示合并则不存在这些玩法和存档改变。

## 二、推荐方案

1. 取消独立战损标题和纵向列表，在同一个「舰船插件」区域内按现有大小绘制：普通插件／空安装槽在前，战损卡格紧随其后，多项自动换行，不另起浮动卡区。
2. 战损卡格有现有插件图标、名称、实际负面效果和文字标记。警告描边只是辅助，颜色不是唯一识别手段。
3. 数量仍清楚区分：普通安装数／容量不把战损算进去，战损数量另作同一标题栏内短读数，避免显示成超额装配。没有普通插件槽的舰船也必须能显示战损，不能随普通槽区早退而消失。
4. 桌面悬停和点击、手机点击均可读取同一富详情。卡格固定尺寸，不在网格内展开高度变化；详情走现有富卡或弹层。
5. 舰船卡移除孤立战损段，转为同一插件摘要区；沉船记录把战损移到普通插件网格，不再挂在无人机之后。仅有战损、仅有普通插件或两者都有时都有清楚空态。
6. 普通插件安装、重复安装、拆船回收、方案保存行为保留。战损仍不能安装／卸下／交易，不生成回收黑匣，不进入装配方案，也不在普通维修时清除。
7. 存档继续保持`plugs`和`damagePlugs`分离，展示统一读取，不把战损写成普通装备编号，避免既有清洗、插件回收和属性算法误算。

## 三、界面判断

支持统一到现有插件卡格，理由是本仓同类功能沿用既有组件，当前单独列表与插件网格有视觉结构差异；这是现场代码与仓库规约判断。

`ui-ux-pro-max`的ux域检索「consistency familiar components」未命中；重试「consistent design patterns」得到字体层级、移动优先和一致帮助条目，没有直接证明战损应放入插件槽。因此不把检索包装成该布局的专门依据。触摸相关检索明确要求目标尺寸与间距，实施时复用固定卡格并确保点击详情。

风险护栏：不要把显示格数量当安装槽数；不要因正负卡格并列影响普通插件重复计数；旧档和已回收船不得静默丢任何插件；键盘与触屏都能查看负面属性。

## 四、实施与验证

经确认后单独在零号实现展示批次，功能域为舰船装配，必要沉船记录展示属原回收域接线。复用现有插件格、悬停层、富卡与沉船装备卡，不修改核心回收经济和随机序列。

测试覆盖普通槽已满＋3战损、普通槽为0＋战损、只有战损、重复普通插件、三界面一致、方案／拆船／回收数量不变、存档往返、桌面和手机短高度无挤压及详情可达。若船长要求占用安装名额，先补已满槽兼容规则，再实施核心变更。

## 五、实施结果

- `ShipDamageMods.tsx`改为固定卡格＋同源悬停／点击富详情，补焦点、Escape、触屏和正确关闭图标；`FitPage.tsx`、`ShipPage.tsx`、`WreckFitPanel.tsx`三处同区并列，局部样式在`styles-ship-damage.css`。
- 只调整展示，不改`plugs`／`damagePlugs`存档、回收、强度、维修、方案或槽位上限。普通插件重复数与满槽仍照旧，零普通槽仍能显示战损。
- 新专项10项通过；核心全量5133通过、8项既有跳过。原生工具三界面点击详情，旧／新、中／英、桌面／手机仿真8组全部通过；新版桌面先收起已有浮层日志再验证右侧卡格，不改变日志设计。
- 与星系批次在同一隔离树交付，两个功能域独立记录。主树未跟踪导出与个人档未触碰，不推送；观感验收留给船长。
