# 敌方挂载件「条目级」口径收敛 · A 族冲锋件与劫掠电子舰（2026-09-19）

**状态：进行中**（船长验收 + 合入 main 后走归档三步：并入 roadmap/词典 → 删本文件 → 重跑 `docs:index`）

## 一、船长原话（照抄）

- 「我还发现，A族似乎只给了电子舰一艘船冲锋挂载件？」（核查后答复：三条舰级本就是**条目级**挂载，
  只有劫掠电子舰把两件写在舰级上——见下）
- 「**海盗电子舰的冲锋也移除，只在洞内单独挂载**」

## 二、范围（本次只做这一件事）

1. **劫掠电子舰 `foe-pirate-raider` 舰级挂载清空**：冲锋件与捕获网**一并**写到深层卡「海盗战团」
   （`wh-pirate-warband`）的**条目**上。
   - ⚠ 引擎取有效挂载是 **`slot.mounts ?? ship.mounts`（替换语义、不是叠加）**——
     只搬冲锋件会**顶掉捕获网**（电子舰当场失去捕获网）⇒ 两件必须一起搬。
   - **行为零变化**：该舰级只被「海盗战团」使用 ⇒ 搬运后洞内读数逐字相同
     （`foeMountNames` 顺序也保持 `['劫掠冲锋推进器','劫掠捕获网']`）。
2. **体检契约随之收口**（`tools/content-check.ts` ⑤g）：
   - ③ 的理由改写：原判据「电子舰的舰级挂冲锋件 ⇒ 它进洞外卡就会跟着冲」随搬运失效；
   - **新增一条**：凡引用「劫掠电子舰」的卡，其条目必须挂捕获网件（原先靠舰级自带，现在必须显式声明）。
3. **用例同步**：`thruster-charge.test.ts` 的"舰级例外专条"改成"洞内族之外，任何舰级一律不带冲锋件"；
   `foe-capture-web.test.ts` 的舰级挂载断言改指战团条目（`:76` 那条端到端读数用作"搬完仍在"的证据）。

## 三、不做（等船长另定）

- **不改挂载解析语义**：「条目 ?? 舰级」仍是**替换**。若将来要让捕获网跟着**舰级**走
  （例如电子舰日后进别的卡也自动带网），需要把解析改成"叠加"——那是引擎口径改动，先不动。
