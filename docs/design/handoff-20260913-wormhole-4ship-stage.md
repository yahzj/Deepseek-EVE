## 2. 验收口径（**船长验收要看的，逐条给读数**）

1. 洞内战斗开打后，泳道内**同时可见我方 4 条舰影**（不是只在顶部条里）；
2. 每条舰影**各自带舰名 + 三层血条**（复用战场同一支 `HpTri`，别自造第二种血条样式）；
3. **主控**那条带「主控」徽标（沿用编队条的 `.app-bts-fleet-lead` 语义/样式）；
4. 沉没的舰：**位置保留**、转「已沉没」灰态（**不许从布局里抽走**——抽走会让其余舰影跳动）；
5. **洞外（远征 / 遭遇 / 教学）单船路径观感零变化**（`myUnits.length === 1` 时与改前逐像素一致）；
6. **入场动画照旧生效**（你上次那版「舰船从屏幕外减速飞入」）：4 舰各自错峰飞入、落点 = 它们的战斗位置，
   动画**只走 transform/opacity**，不改任何坐标；
7. 窗口尺寸变化不溢出（泳道 `overflow: hidden`；容器定高，防跳动）。
