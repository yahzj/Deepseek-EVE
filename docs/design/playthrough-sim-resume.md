### 现在的精确卡点（下一步照这个做）

**层深 2 → 3 上不去，缺的是"过第 2 层的余量"**（第六批已把第 2 层到达从 40% 抬到 **61%**）：

- 清掉第 2 层守卫约吃 **36%** 血 ⇒ `61% − 36% ≈ 25% < 撤退线 45%`
  ⇒ 下一拍 `wantExtract`（<45%）命中 ⇒ **撤离，仍然拿不到第 3 层**。
- 也就是**还差约 20 个百分点**。三个可用方向（按性价比）：
  ① **抬升过第 2 层的血量**：确认 `fillRack` 铺的是高档件、把 `repairWhFleet` 的节流从"每天一次"
     放宽到"每次进洞前一次"（现在 0% 甲的船要等到第二天才修，中间那些趟只能靠选船闸挡掉）；
  ② **降低单场战斗的掉血**：更多无人机 / 更高档护盾装甲 / 更高 DPS；
  ③ **改撤退口径**：撤退线是 45%（`wormholeHpFrac() < 0.45`），与进洞门同源。
     若允许"残血也下潜一层、下去立刻撤"（层深入账 + 撤离都不需要打赢），
     则只要**清掉本层守卫时还没死**就够了 —— 这是**最低成本**的一条，但要把
     "下潜后立刻撤"做成明确分支（现在是"清守卫 → 下潜 → 下一拍撤"，中间那拍会被 <45% 截住）。

**下一步（按优先级）**：
1. **【最高杠杆，未做】放宽撤退线 / 让"清完守卫就必下潜"优先于血量检查**（上面第 ③ 条）：

2. **`repairWhFleet` 节流放宽**：改成"每趟进洞前一次"（用 `whStats.entries` 变化做键，而不是按天）。
3. **确认 `fillRack` 铺的是高档件**（`mod-shield-ext-3` / `mod-armor-plate-3`），不是 MK1。
4. **无人机选型复核**：当前按"单发伤害降序"（三档每 m³ 伤害都是 0.6，够用）。

- ⚠ **这个模拟的经济是紧平衡的**：任何"多花钱换战力"的改动都会拖垮「10 亿」那条目标
  （第五轮两例：维修装置 ⇒ 现金 −34%；MK2 弹药 ⇒ 现金掉到 4.5 万）。**三条目标要同时达成**，
