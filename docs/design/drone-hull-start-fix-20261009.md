## 核对与修正范围

之前工作稿把船体启动加成收窄为巨构无人机作战舰，当前船长明确为所有无人机舰，以此修正。目录中无人机主力舰共四艘：梭鱼级无人机护卫、王鲭级无人机母舰、机库无人机作战舰、巨构无人机作战舰。补前三艘`droneLaunchCutPct = 0.3`，巨构现有值保留。仅有无人机舱或附带机群加成的侦察/指挥/后勤/鱼雷舰不按无人机主力舰扩展，不改其定位。

使用现有船体数据字段与引擎/特性显示单点，不改共享算法。四艘首次启动间隔500→350ms，一件MK3加速器后350×0.6=210ms；旧机库乘区、多件递减、10ms底限、攻击装填与战损补位规则保持。不改变舰船价格、槽位、CPU、无人机舱或伤害。

旧工作稿`drone-launch-laser-calibration-20261009.md`的“仅巨构”记述为此前误收窄，以本轮船长设定和当前数据为准；工作期不回改历史过程稿。
