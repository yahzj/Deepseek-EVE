# 文档精简与封存（roadmap / glossary）—— 工作文档

> **状态：进行中**（三号 · verify40 · 2026-09-15）——第一期（roadmap 封存 + 索引基建）已落地；
> **第二期（glossary 逐词条瘦身）待船长就"裁法"点头**，见 §六。

## 一、船长原话（照抄）

1. 「**清理没有用的截图png，然后开始整理文档并制作一个文档的索引目录。设定新规则，工作流没有进行收尾归档事，不允许直接修改旧文档。应该新建一个该工作的临时文档记录工作相关。等到归档时，再合入旧文档。**」
2. 「**roadmap/glossary 也要进行精简，删除过时内容，或者将过时内容移入另外一个文档并封存。**」

## 二、范围与不做

**做**：① 无用截图/垃圾清理；② `docs/INDEX.md` 文档索引 + 生成器；③ **roadmap 精简与封存**；④ **glossary 过时内容封存**；⑤ 封存区规则与索引接线。
**不做**（本期）：**①** 不改任何**现行口径**（术语含义、数值、契约）；**②** 不重写封存卷内的文字（冻结件）；**③** 不动 `docs/test-saves/` 的测试档；**④** 不碰玩家存档结构与任何游戏数值。

## 三、判据（什么算"过时"，机械可核）

| 对象 | 判据 | 处置 |
|---|---|---|
| roadmap 批次条目 | 在**滚动窗口（最新 20 条）之外** ⇒ 已被后来条目取代/已成历史 | **原文封存**进 `docs/archive/roadmap-YYYY-MM-DD.md`（按条目日期分卷） |
| roadmap 待办项 | 标 `[✓]` = 已办结 | 原文移入 `roadmap-todo-done-20260915.md`，roadmap 留一行核对结论 |
| roadmap 旧「读法」注 | 描述的是**改版前的文件结构** | 移入同一卷（新结构说明写在文件头） |
| glossary 词条 | 词条名自带 **已废弃/已作废** | 原文移入 `glossary-retired-20260915.md`，词典原位留一行「已废弃 + 现行叫法 + 指针」 |
| glossary 词条内**沿革句** | 句中出现 旧口径/此前/原为/已改/不再/作废 之类标记 | **第二期待裁定**：可外移量实测仅 **约 31 KB**（99 词条），见 §五 |

**为什么不直接删**：这些是**决策审计链**（船长原话照抄 / 逐问逐答 / 负向验证 / 读数）。"删除"会丢取证；封存只是把它挪出常读路径，**检索入口仍在**（卷索引 + `docs/INDEX.md` + `git log -S`）。

## 五、glossary 的实测结论（重要）

- 全表 **330 行词条 / 294 KB**；其中 **97 行超过 600 字**、合计 176 KB（占 60%）——**大头不是"过时"，是"写得太厚"**。
- 按"过时"判据（沿革句）实测：**只有约 31 KB 可外移**（99 个词条里各含 1~5 句沿革），其余 **~260 KB 是现行口径本体**（含船长原话照抄）。
- ⇒ **只按"删过时"办，glossary 最多瘦 10%**。要显著变薄，只能改**写法**：把「船长原话照抄 / 逐问逐答」从词条里挪进封存卷，词条只留「口径一句话 + 出处日期 + 关键数值」。
  这是**改权威文档的编辑判断**（词典是术语权威、也是压缩后恢复上下文的第一入口），**等船长裁法再动手**。

## 六、第二期待裁定（三选一）

- **甲 · 只删过时（保守）**：99 个词条里的沿革句外移，词典 294 → ~263 KB；不动现行口径写法。
- **乙 · 口径瘦身（推荐）**：词条 = 现行口径（≤ 约 200 字）+ 出处日期 + 关键数值；原话/逐问逐答/推演进 `docs/archive/glossary-detail-*.md`（按章分卷）。预计 294 → **110~130 KB**，但**要逐条改 330 个词条**，按章分批（先三、装备/制造/经济 73 KB），每批跑完闸门再进下一批。

## 八、已知取舍（如实登记）

1. **滚动窗口 = 20 条**：roadmap 顶部只留最近 20 条批次条目，更早的要点开卷。窗口可调（`--window=N`），但调大就会回到膨胀老路。
2. **封存卷体量不均**：09-14 一卷 391 KB（当天 122 条），最细的 09-06 只有 1 条 2 KB；按日分卷是为了"哪天的事看哪卷"。
3. **`## 变更记录（本文件）` 段头被取消**：该段只是"更早批次放在文件下方"的旧结构，条目已按日进卷。
4. **旧版「读法」注不再现行**：它描述的旧结构（顶部块 + 置顶 + 变更记录）已被新结构取代，原文进了 `roadmap-todo-done-20260915.md`。
5. **`docs/design/archive/` 与 `docs/archive/` 分工**：前者是**设计稿**的归档（既有 40 份）；后者是**日志/词典等历史件**的封存区（新建）。两者都不受"禁止改旧文档"约束以外的新规矩。
