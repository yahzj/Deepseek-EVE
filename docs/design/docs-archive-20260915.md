## 三、判据（什么算"过时"，机械可核）

| 对象 | 判据 | 处置 |
|---|---|---|
| roadmap 批次条目 | 在**滚动窗口（最新 20 条）之外** ⇒ 已被后来条目取代/已成历史 | **原文封存**进 `docs/archive/roadmap-YYYY-MM-DD.md`（按条目日期分卷） |
| roadmap 待办项 | 标 `[✓]` = 已办结 | 原文移入 `roadmap-todo-done-20260915.md`，roadmap 留一行核对结论 |
| roadmap 旧「读法」注 | 描述的是**改版前的文件结构** | 移入同一卷（新结构说明写在文件头） |
| glossary 词条 | 词条名自带 **已废弃/已作废** | 原文移入 `glossary-retired-20260915.md`，词典原位留一行「已废弃 + 现行叫法 + 指针」 |
| glossary 词条内**沿革句** | 句中出现 旧口径/此前/原为/已改/不再/作废 之类标记 | **第二期待裁定**：可外移量实测仅 **约 31 KB**（99 词条），见 §五 |

**为什么不直接删**：这些是**决策审计链**（船长原话照抄 / 逐问逐答 / 负向验证 / 读数）。"删除"会丢取证；封存只是把它挪出常读路径，**检索入口仍在**（卷索引 + `docs/INDEX.md` + `git log -S`）。
