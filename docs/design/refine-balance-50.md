# 精炼配平 50% 持平 + 工业页净收益口径（设计定稿与实现记录）

> 状态：**已确认并实现**（2026-09-08 船长确认；本地提交标注「待验收/待发布」，随推送闸门发布）。
> 触发：船长反馈「精炼炉收益不正确，好像并未扣除材料成本」——查证引擎结算每批已实扣料，
> 问题只在工业页精炼卡的 ≈ISK/h 估算按矿物毛产值计算、未扣被炼资源的价值（原料本可卖）。

## 一、规则改弦（替代旧锚）

- **旧锚**（items.ts 头注 / v10-content.md / m1-design.md 历史记录）：精炼配方按
  「100% 收率价值 ≈ 收购价 ×1.15~1.35」配平 → 无技能（50%）精炼必然亏损，
  是「卖原矿 vs 练技能精炼」的刻意决策点。
- **新锚（2026-09-08 船长定稿）**：全部 14 条精炼配方（7 矿石 + 4 气体 + 3 冰矿）按
  「50% 收率（无技能）时每批产值 ≈ 每批耗料价值（双方按站内收价 baseSellPriceIsk，
  不随市场）」配平——零技能不吃亏不虚高；精炼学每级 +8pp 收率线性转赚，满技能（95%）
  净收益 ≈ +82%~+110% 耗料值（≈ 原料售价 ×1.9，与公告「满级约 ×1.75~1.8」精神同源）。
- 收率公式、批量/周期、矿物与资源价格、蓝图材料数一律不动；perOre 取整粒度允许
  50% 实际净率落在微正 +0.4%~+4.6%（小批量 floor 步长所致，无法精确归零）。

## 三、UI 估算口径（工业页精炼卡）

- 精炼资源卡（矿石/气体/冰矿）≈ISK/h 改为**净口径**：
  `净 ≈ (Σ floor(批×perOre×当前收率)×矿物收价 − 批×原料收价) × 3_600_000 ÷ 周期`；
  主值显示净收益并标「（净）」；负值用警示色（`app-belt-econ-val.is-neg`，--wui-red）并附
  「净亏：直接卖原料更划算」；tooltip 注明构成（毛产值 ≈X ISK/h 一并给出）、不随市场、未计成交税。
- 残骸回收卡不变：残骸不可出售、无耗料可扣，保底 ≈ISK/h 本就是净口径。
- 组装机（制造）：**本批零改动**——组装机收益相关调整由大鲸鱼二号在 d2 另行处理
  （2026-09-08 船长分工），本设计不覆盖。
