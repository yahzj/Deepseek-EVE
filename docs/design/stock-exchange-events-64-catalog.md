## 三、组合规则

- 事件 ID：`EV-<象拼音>-<code>-<强度>`；
- 标题：`[<象名>·<强度词>] <剧本标题>：<公司名>（<代码>）<方向标签>`；
- 正文：`<剧本正文><强度追加句>`；
- `tone`：太阳/少阴 = good，少阳/太阴 = bad；`xiang` 字段记录四象；`intensity` 1~4；
- 影响回合：强度 1→1、2→2、3→2、4→3；小盘 OJLS/ABSI 冲击 ×1.5。

## 四、抽样（确定性）

- 每回合 25% 触发；触发后依次抽：象（25/25/25/25）→ 标的（按流通权重）→ 强度（40/30/20/10）；
- 种子持久化；同种子可复现。
