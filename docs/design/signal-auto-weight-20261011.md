# 信号空间自动探索超重编队修复

> **状态：已实现，自测中，待验收**（二号 · d2/workspace · 2026-10-11）
> 玩家原话：「玩家自动安排探索信号空间时，可以分配超过重量限制的小队，这是BUG」。
> 范围：自动探索默认编队与启动命令复用 `wormholeAdmission` 的质量门禁；补自动队伍、超重手动队伍与质量上限边界测试。不改船质量、探索收益、AI核心、舰数上限、真实存档或手动进洞规则。
> 待裁决点：无；用户已要求修复。

## 根因

- `wormholeAutoCandidates` 过去只按武装度、耐久和船型档位挑最多4艘，没有累计调用 `wormholeAdmission`。
- `wormholeAutoBlockReason` 过去只检查虫洞库存、舰数、单舰忙碌和AI核心，手动传入的自动探索队伍可以绕过总质量上限。

## 修复口径

- 默认自动安排逐艘累加候选队伍的等效质量，超过现有 `WORMHOLE_TOTAL_MASS_CAP` 的候选不入选；后续较轻候选仍可补足队伍。
- 自动探索启动命令层再次调用 `wormholeAdmission`，超重队伍复用现有质量拒因；质量恰好等于上限仍可通过。
- 质量公式、档位禁入、舰数上限、AI核心、忙碌状态和界面候选排序保持原口径。

- `wormhole-auto.test.ts` 与 `wormhole-admission.test.ts`：28项通过。
- 四包类型检查通过；内容与架构检查待提交钩子完成。
