## 〇、每一步都成立的口径

| 机制 | 口径 |
|---|---|
| **顺序解锁（顺序段）** | 前 **11 条**（「第一次扫描」…「第一次指派 AI 副船」）**一次只出一条**；判定**也只判当前那一条** ⇒ 不显示的任务不会提前完成 |
| **末段并列批** | 第 11 条完成 ⇒ 「**寻找人类**」（**置顶**）＋「第一次长途运输」＋「第一次虫洞」**一起显示**；两条「第一次」**判定互不阻塞**（同拍可判过多条） |
| **完成那一刻的日志** | 有奖励的条目记一行「◆ 任务奖励已发放：…。」（**13 条现在全都有奖励** ⇒ 都会有这行） |
| **导航提醒** | 显示组一变 ⇒ 导航「任务中心」亮 **+1** 徽标（悬停写新那组标题）；**进任务中心即灭**。记账存"显示组签名"（顺序段 = 单条 id，末段 = `first-haul\|first-wormhole`；老档零迁移） |
| **成就徽章** | 任务徽章（卡名 = 任务标题）＋ 链徽章（`见习××`）**同拍到手**，但**纯展示：不写日志、不发通讯** |
| **通讯送达** | 送达条件 = 该条已完成（`trigger: firstTask`）；**完成的下一拍**进收件箱并**默认弹窗**（`kind: 提示`；同一拍只弹第一封，其余只进收件箱） |
| **任务卡结构** | 页头「◆ 第一次 · N/13 已完成 ·（1 条时）一次只出一条：做完这条，下一条才出现／（多条时）剩下的可以按任意顺序做」＋ 卡：`◆ 标题` ＋ 右上角「前往×× ›」 ＋ 正文（= `detail`）＋ 奖励行「奖励 ◆ …」＋ 底行「完成即发情报」 |
| **里程碑（次数链）** | 每条「第一次」对应一条链，完成才上「里程碑任务」页；链升级只**记账**，奖金到该页点「领奖」才进钱包 |

## 一、逐步清点（队列序 = 玩家实际顺序）

### 第 1 步 · 第一次扫描（`first-scan`）｜实测 ≈0.6 分钟（含序章收尾）

- **任务文本**：正文——「星图上只剩剪影的位置＝未解读的未知信号。派一艘深空扫描艇就地扫描，窗口走完即点亮该星系：航线、矿带、悬赏与残骸情报一并解锁。母港只需十来秒，其余星系越危险扫得越久。」
- **玩家做什么**：任务中心 →「前往星图 ›」→ 对未解读信号点「扫描」。母港窗口 10 秒。
- **判据**：已点亮且存在于内容表的星系 ≥ 1。
- **完成那一刻**：奖励**采集器 MK1 ×1**（进装备库）· 日志「◆ 任务奖励已发放：采集器 MK1 ×1。」· **星图四项解锁**（矿带开采 / 常驻悬赏 / 残骸打捞 / 长途运输）· 链「宇宙探索家」上里程碑页（按**点亮星系**计数，共 **5 档**：L1 = 5 个 → L5 = 全图 20 个）· 徽章 `ach-first-scan`。
- **通讯**：主题「**档案补全 · 星图扫描**」（发件：舰载信息库 · 检索重启）
  1. 星图上那些只剩剪影的位置，是尚未解读的未知信号；派深空扫描艇跑一趟就能点亮它。
  2. 点亮之后，那处星系的矿带、航道与驻留势力才会进入可作业清单。
  3. 随信附一台采集器 MK1——装上它，采掘效率更高。
  - 「前往」提示：「去星图看看点亮了哪些地方」→ 星图

### 第 2 步 · 第一次采集原矿（`first-mine`）｜实测 ≈4.0 分钟（4 趟矿）

- **任务文本**：正文——「先到「舰船」页把驾驶换成采矿艇（沙猫级），再到矿带派出采矿：采掘、返航、卸货自动跑完。原矿可以按市价卖出，也可以送进精炼炉炼成原材料——那是绝大多数蓝图的用料。」
- **玩家做什么**：「前往矿带开采 ›」→ 先换乘采矿艇 → 派出采矿（自动循环，满仓返航卸货）。
- **判据**：累计采到原矿 > 0（`firstStats.mineUnits`）。
- **完成那一刻**：奖励**打捞器 MK1 ×1**（装备库）＋**橄榄岩 ×100**（仓库）· 日志「◆ 任务奖励已发放：打捞器 MK1 ×1、橄榄岩 ×100。」· **工业页解锁**（跟着下一条"轮到"一起开）· 链「深空采掘者」（按**原矿单位**累计，共 10 档：L1 = 1,000）· 徽章 `ach-first-mine`。
- **通讯**：主题「**档案补全 · 采矿与精炼**」
  1. 矿带产出原矿；精炼炉把原矿炼成原材料，原材料才是绝大多数蓝图的用料。
  2. 随信附一台打捞器 MK1——装上即可用于打捞作业。
  3. 另附 100 单位橄榄岩：精炼炉每批要 100 单位，这批料够开第一炉。
  - 「前往」提示：「去工业页看看精炼炉与组装机」→ 工业页

### 第 3 步 · 第一次操作精炼炉（`first-refine`）｜实测 ≈0.5 分钟/批

- **任务文本**：正文——「精炼炉按批运转：原料够一批就能起炉，料尽自动停炉，装满则按批续烧。精炼学每级 +6% 产出、高级回收处理每级 +3%，两条练满可到 165%。」
- **玩家做什么**：「前往精炼炉 ›」→ 选原料起炉（每批 100 单位；主控亲自看炉占一台）。
- **判据**：精炼出料批数 ≥ 1（残骸回收炉**不**计入）。
- **完成那一刻**：奖励**动能弹药生产线蓝图 ×1**（进蓝图库存）· 日志「◆ 任务奖励已发放：动能弹药生产线蓝图 ×1。」· 链「精炼师」（按**出料批数**，L1 = 10 批）· 徽章 `ach-first-refine`。
- **通讯**：主题「**档案补全 · 精炼炉**」

  2. 「精炼学」每级 +6% 产出、「高级回收处理」每级 +3%，两条练满可到 165%。
  3. 随信附一份「动能弹药生产线」蓝图——材料是钛钢合金，正好由原矿炼出。

### 第 4 步 · 第一次完成悬赏（`first-bounty`）｜实测 ≈0.5 分钟（与第 5 步同一段）

- **任务文本**：正文——「常驻悬赏按威胁分档：档位越高敌人越厚、火力越重，报酬与协会声望也越高。声望是协会渠道的通行证，市场门槛与虫洞扫描都看它。」
- **玩家做什么**：「前往常驻悬赏 ›」→ 接一档常驻悬赏并打赢（教学场「演习场驱逐令」有本舰主控加成；**声望只在每张卡的首胜给**）。
- **判据**：讨伐胜利场数 ≥ 1。
- **完成那一刻**：奖励**鲣鱼级护卫舰 ×1**（直接进机库，同型自动编号 #2）· 日志「◆ 任务奖励已发放：鲣鱼级护卫舰 ×1。」· 链「赏金猎人」（按**胜场**，L1 = 1 场）· 徽章 `ach-first-bounty`。
- **为什么排在这一位**（**2026-09-20 第三道令**：悬赏与打捞对调）：先打一场**拿钱**（实测这把进账 3,600 信用点）

- **通讯**：主题「**档案补全 · 悬赏讨伐**」
  1. 悬赏按威胁分档：威胁越高，敌舰越厚、火力越重，报酬与声望也越高。
  2. 声望是协会渠道的通行证——市场声望门槛、虫洞扫描解锁都看它。
  3. 随信附一艘鲣鱼级护卫舰——编入舰队或改作副船都行。
  - 「前往」提示：「星图里的常驻悬赏可以接着打」→ 星图

  1. 护盾脱战后自行回满；装甲与结构的损伤会跨场保留，需要修理组件或港内工位处理。
