## 已确认政策

- 保存、恢复、备份共用 FIFO 队列，文本在入队前固定；失败回到调用者，不阻断后续请求。
- 桌面文件使用唯一临时名；临时文件属于当前请求，失败清理，不清理他人的文件。
- 铁人账本自身的读改写串行。主档成功回执等待账本处理；账本失败保留既有降级政策，诊断可见，不回滚主档。
- `backupNow()` 保存失败或挂起时停止；成功时备份的是这次保存的确切文本，不受中间自动保存影响，也不把旧文本再覆盖回主档。
- 保留公开保存 API；备份桥只增加兼容的可选快照参数，不改存档字段、铁人奖励、救援门槛或导出代次政策。

## 模块与参照

- 功能域：保存域，无跨游戏模块。参照现有 `storage.ts` 双端桥、`ironmanLedger.ts` 可注入目录、tmp＋rename 原子覆盖与备份时间戳命名。
- 同域没有现成 FIFO 事务件，提取轻量队列供桌面、账本、网页复用；文件原子写件只在主进程使用，不引入运行期循环。
- 不改玩家文案，保存失败复用 `ui.engine.027`；账本降级只写开发诊断。
