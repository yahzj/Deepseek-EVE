# 敌方混伤（2026-09-10 · 状态：已确认并实现）

> 船长指令：「给所有赏金任务的敌人添加额外攻击的副伤害类型，让其攻击造成混伤（主类型占大部分），
> 并需要在任务中告知玩家」→ 同日追定：「还是将常驻悬赏的伤害比例也进行修改，但是比例约为 8：2」。

## 1. 结论（一句话）

敌人不再只打"主系"一种伤害：**常驻悬赏 / 低安遇袭 = 主 80% + 副 20%**、**窝点（赏金任务）= 主 60% + 副 40%**，
各系各自吃自己的层位克制与层抗；**敌总伤不变**；**教学卡保持纯系**；卡面把构成直接告诉玩家。

## 2. 现状与改动（为什么这是一次"让白写字段生效"的改动）

`AnomalyDef.dmgMix` 早就存在（如 `{ explosive: 2 }`），但引擎只用它取**最高权重的那一系**
（`pickTopType` → 敌武器的 `fixedType`），玩家实际只挨一种伤害，卡面也只显示「敌主伤 ⬤」。
本次把它变成**真正的伤害构成**：

| 层 | 改动 |
|---|---|
| 数据 | 25 张敌军卡写明两系 `dmgMix`（主 8 : 副 2）；**教学卡（演习场讨伐令）不写** = 保持纯系 |
| 语义 | `dmgMix` 的**正权重键 = 参战系**（≥2 系即混伤）；**旧口径"没写的系缺省权重 1"作废**——那条会让只写一系的卡悄悄变成三系混伤 |
| 窝点派生 | `lairAnomalyOf` 给派生卡写 **{ 主系 6 : 副系 4 }**（比常驻更"混"：窝点本就是更硬的特色敌人），**主系不许变** |
| 副系 | 按**敌族签名序列**取第一个 ≠ 主系的系（`FOE_SUB_DMG`）：A 海盗 动能→爆炸→等离子 / C 异形 爆炸→等离子→动能 / D 守墓 等离子→动能→爆炸 / E 巨构 等离子→爆炸→动能 / G 流亡 爆炸→动能→等离子（无族卡按 A 序兜底） |
| 引擎 | ①`createFoeSpecs` 出多系单发（复用我方炮台的 `shotsByType`）；②实时结算 `applyFoeShot` 按构成**逐系** `applyDamage`；③**胜率预估**按份额加权（否则"卡面写混伤、预估按纯系算"会骗人） |
| 契约 | `content:check` 新增「敌方混伤契约」：非教学卡必须两系且**主 8 : 副 2**、副系须等于族签名值、窝点派生须**同主系 + 6:4** |
| 告知 | 三处卡片显示位（常驻悬赏卡 / 派系活跃卡 / **赏金任务卡**）由「敌主伤 ⬤」改为「**敌火力 ⬤动能 60% · ⬤爆炸 40%**」，悬停说明补"只堆主系抗会被副系穿透" |

## 3. 口径与取舍（船长裁决）

| 议题 | 裁决 |
|---|---|
| 配比 | 常驻悬赏 / 低安遇袭 **8 : 2**；窝点 **6 : 4** |
| 范围 | 全部常驻悬赏 + 4 张低安遇袭隐藏模板；**教学卡除外**（不给新手第一场上混伤） |
| 平衡 | **敌总伤不变**——只改构成，不改 DPS |
| 副系分配 | 按族签名表（撞主系则顺延），见上表 |

### 已知副作用（写进档，便于日后校准）

- **"堆单系抗"变弱**：以前把主系抗堆满即可近乎免疫，现在副系会绕开主抗。极端例：对动能抗 90% 的目标，
  纯动能每 100 点只能打进去很少，混伤（动能 60 + 爆炸 40）能打进去明显更多——这是设计目的，
  但也是"玩家堆抗收益下降"的直接来源。
- **武器形态不变**：主系是能量仍是**光束必中**，混伤只改伤害构成；命中、近盲折扣、距离衰减一律按主系口径。
  也就是说"等离子主系 + 动能副系"的敌人依然必中，只是伤害里有 20~40% 走动能克制。
- **预估与实战同源**：卡面显示的胜率预估已改用加权克制，卡面构成 = 实际构成（此项有回归测试守）。
- 取整口径：逐系分摊、**最后一条吃余数**，Σ 永远等于总单发；单发极小时副系会取整成 0 → 并入主系一条（不产生 0 伤害条目）。
