## 二、机制根因（已定位到具体代码，不是工具缺陷）

1. **射程互斥（悬赏那侧的墙）**
   剩余 3 张卡里两张是 `kite`（放风筝）战术，引擎的敌方期望距离是
   **「跟随我方最大射程」**：`combat.ts:2568`
   ```ts
   if (tactic === 'kite') return Math.max(bal.minDistanceM + 1, Math.round(mainMax * 0.95))
   ```
   我方若只装**动能炮塔 MK3（射程 7,350 m）**，敌编队就停在约 **10,102 m** ⇒
   引擎写出 `⚔ 无法交战（…）：一炮未发……已脱离交火并返航`（脱战不写胜负，所以
   报告里"出征 N 次、零结局行"）。要够得着必须上**导弹 MK3（14,880 m）**或激光 MK3（10,500 m）。

2. **火力互斥（虫洞那侧的墙）**
   虫洞层末守卫是**硬拼伤害**的场景，而远射武器（导弹）的"伤害/秒/槽"低于动能炮塔
   （实测值：炮塔 MK3 **1.745** ＞ 激光 MK3 1.05 ＞ 导弹 MK3 0.915）
   ⇒ 换上远射武器后**虫洞立刻从 6/6 掉到 2/6**。

3. **两个目标共用同一批船**
   虫洞编队上限 `WORMHOLE_MAX_SHIPS = 4`（`core/wormhole.ts:72`），
   而本模拟能稳定养出的满配战斗舰就是 **4 艘 T3**（更高档 T4 玄武级 90M/艘，
   且一次性蓝图声望门槛 25）⇒ **没有余力再养一支"远射专用队"**。
   工具层凡尝试"临时换装 / 临时换驾"（方案 C/D/E），都会打乱**主控的采矿-卖出节奏**，
   把「10 亿」那条一起拖垮（实测现金从 135 亿掉到 3,100~6,260 万）。

## 三、我的判断

- **不是引擎 bug**（我此前一度怀疑，已更正）：`kite` 跟随射程是**已登记的战术口径**
  （`combat.ts` 注释里写明 brawl/orbit/kite 三档期望距离的推导），行为自洽。
- **也不是工具缺陷**：五种方案已穷尽"单主控 + 4 舰"这一空间的常见解法。
- **是配平问题**：`kite` 卡要求"长射程"，虫洞深层要求"高 DPS"，
  而玩家在同一批船上**二选一**；只要编队上限是 4 艘，两条目标就抢同一批船。
