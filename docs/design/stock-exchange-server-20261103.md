# 证券交易所（服务端真股市）设计方案

> 状态：**待裁决（未写功能代码）**
> 日期：2026-11-03
> 船长原话（本次）：「我想为这个游戏项目增加一个股市系统，现在从头开始设计」「有前后端，服务器上的真实的股市系统，但是是实时的赌博乐园」「真股市 = 持续撮合 + 完整订单类型 + 杠杆强平 + 实时推送，赌博感 = 高杠杆 + 大波动 + 做空逼空 + 事件驱动」「毕竟是挂机游戏，长线买也可以的。做短线翘大杠杆也可以，但是不要区别界面，这些功能要统一在一个界面上，可以让玩家自动设置量化交易（简单版不用太拟真）」「股市也是游戏经济数值里的一环」
> 取代关系：本文取代 `docs/design/stock-market-system-20261103.md` 中「路径 A：纯本地高拟真模拟器」的推荐项（该稿未提交、未动手写代码）。旧稿保留作「单机本地模拟盘」备选，是否归档待船长裁定。

## 一、结论先行

1. **可行，且基建比预期完整得多**：`apps/server` 已上线可跑，已有设备码账号、云存档、双分录哈希链账本、**冻结式订单簿市场**、WebSocket 通道、SQLite 持久化、限流。缺的是 `exchange` 业务域、实时行情推送、以及**客户端尚未接入服务器**（P2 待做）。
2. **路线反转**：知识库白皮书与旧设计稿都假设「纯本地确定性演算」，本次按船长要求改为**服务端权威撮合 + 实时推送**。股市持仓与现金放在服务端，**本地存档 v31 结构不变**（只多一条券商绑定/偏好设置，可存服务端）。
3. **「真股市」必须承认一半是机器人**：小圈子同时在线人数撑不起十只股票的深度，做市商/散户/机构订单必须进同一本订单簿。玩家看到的是一个连续盘口，而不是「和 NPC 议价」。
4. **经济上必须是净销毁口**：税、佣金、资金费、借券费全部销毁；**分红只能来自回收池，不能凭空印钞**，否则股市会成为继悬赏之后的第二个通胀源。
5. **分期可独立上线**：P0 就能玩「真撮合 + 实时行情 + 长线持股」，P1 加杠杆做空，P2 加生态事件逼空，P3 加量化。

## 三、核心架构裁定（推荐方案）

### D1 权威模型：服务端权威证券账户

- 服务端持有：券商现金、冻结、持仓、保证金、借券、强平记录。
- 本地存档**不存持仓明细**，只存「已绑定券商 + 显示偏好」（也可全部存服务端）。
- 好处：杠杆强平天然权威、改档改不出股市资产、存档不受股市膨胀、**v31 不变**。
- 代价：单机/断网玩家没有股市（见 D4）。

### D2 资金闸门：入金 / 出金 + 配额制

- **入金**（本地 ISK → 券商现金）：客户端调用 `POST /api/exchange/deposit`，扣本地存档 ISK、服务端加钱包，**按配额限速 + 手续费 + 审计**。配额沿用现有产出闸门思路（因为混合权威下服务器无法验证本地余额）。
- **出金**（券商现金 → 本地 ISK）：扣服务端钱包、客户端加存档 ISK；出金免配额但**收更高的费**并设 T+N 冷却。
- **拒绝方案**：服务器全权威钱包（会把整个游戏经济搬上服务器，超出本批范围）。
- 幂等键防止重复入金；账本每笔可回溯。

### D3 市场结构：玩家订单 + AI 生态订单进同一本簿

- 真实 CLOB（价格优先/时间优先），玩家与 AI 都是簿上的订单，**不区分标记**。
- AI 三类：做市商（托底深度与价差）、动量散户（放大波动）、价值机构（围绕锚点平抑）。
- 目的：① 小圈子也有连续盘口；② 玩家大单能真实冲击价格；③ 逼空有对手盘。

### D4 单机 / 联机：**建议仅联机**（待裁决）

- 推荐：股市只对「已连接服务器」开放；单机模式该页显示「需连接星海网络」。
- 备选：单机也跑一套本地模拟盘（同规则、core 内实现）——**成本翻倍**，且两套引擎长期会漂移。
- 推荐理由：船长要的是「服务器上真实的股市」，本地模拟无法满足「玩家行为互相影响」。

### D5 时间：一律服务端墙钟

- 撮合、资金费、分红、强平全用服务器时间；本地存档的离线结算时钟不参与股市。
- 防改系统时间刷股市收益。

### D6 客户端通道：桌面走主进程代理，网页走同源反代（推荐）

| 方案 | 做法 | 取舍 |
|---|---|---|
| **A（推荐）桌面主进程代理** | preload 增加 `exchange.request / exchange.subscribe`，主进程持 HTTP/WS 连接，渲染层走 IPC | CSP 保持收紧，令牌不落渲染层；代价是 IPC 与 WS 事件转发要写一层 |
| B 放宽 CSP | `connect-src` 加服务器域 | 桌面端服务器地址玩家可自定义 ⇒ 静态 CSP 无法枚举，只能放成 `http: https: ws:`，等同放弃 CSP |
| C 服务端同源反代 | 网页版由 Caddy 把游戏页与 API 同域 | 网页版最干净，但需域名 + HTTPS（转正式才具备） |

> P0 建议：桌面走 A，网页版先只读或后续按 C 接；两条路共用同一份 TS 客户端协议层。

### D7 股市时钟与离线结算**解耦**（本批新增裁定）

- 股市按**真实墙钟 7×24 连续运行**；本地存档的离线结算上限（8h / 双技能 32h）**不作用于股市**。
- 玩家离线期间：行情照走、挂单照成交、强平照发生；上线以服务端状态为准。
- 理由：真股市不能停摆，否则长线玩家可借「离线不结算」规避爆仓风险，等于给杠杆开后门。
- 代价：离线 30h 的玩家，本地游戏只推进 8h，但股市推进 30h——这个差异必须在界面上说清（「你离线期间市场走了 30 小时」）。

## 四、系统设计

### 4.1 标的与板块（船长 2026-11-03 指定，共 4 家）

| 板块 | 企业代码 | 企业全称 | 核心特色与联动事件 |
|---|---|---|---|
| 军工重工 | SMHI | 西斯玛特造船重工 | 战舰与重型装配制造。星系战事活跃、海盗清剿与入侵战催化上涨。 |
| 采矿能源 | UGMC | 泛星系联合矿业公会 | 原矿勘探与深空采掘。受全星系矿石流通量与开采产出影响。 |
| 航运物流 | OJLS | 猎户座跃迁物流 | 星际干线运输。受贸易航路安全度与快递任务活跃度影响。 |
| 前沿科技 | ABSI | 晨曦仿生智能体 | AI 核心研发与自动驾驶控制。受探针制造与高端蓝图需求提振。 |

- 每只股票：总股本 / 流通盘 / 内在价值锚（anchor）/ 波动率档 / 可杠杆上限 / 是否可做空。
- 市值分层：小盘 15 亿 / 中盘 120 亿 / 大盘 1,000 亿（按玩家财富 6.36 亿锚定，见数值表）。
- 四家公司的联动事件直接读游戏实体统计（击杀/入侵、矿物产出、快递任务、虫洞与蓝图），不做纯随机事件。

### 4.2 订单类型（按优先级分批）

| 批次 | 订单类型 | 说明 |
|---|---|---|
| P0 | 限价 GTC | 挂单等成交，可撤 |
| P0 | 市价（转 IOC，剩余撤销） | 带最大滑点保护，防吃穿 |
| P1 | 止损市价 / 止损限价 | 服务端条件单，触发后转市价/限价 |
| P1 | 止盈限价 | 同上 |
| P2 | 条件单（价格 / 涨跌幅 / 均线触发） | 量化基础 |
| P2 | 冰山单 | 拆单隐藏真实体量 |
| P3 | Post-Only / IOC / FOK | 给量化策略用，防止吃单滑点 |
| P3 | 跟踪止损 | 移动止盈 |

### 4.3 撮合与盘口

- 内存订单簿 + SQLite 只追加成交流水；价格用整数分（`FixedPrice`，避免浮点漂移）。
- 撮合循环：服务端每 500ms 一次（10 只标的成本可忽略）；下单立即尝试撮合当拍。
- 盘口五档 + 最近成交 + 1s/1m K 线（K 线由成交聚合，落 SQLite，保留 30 天）。
- 涨跌保护：**不设硬涨跌停**（要赌博感），设**波动率熔断**：单 5 分钟 ±20% 触发 3 分钟冷静期（只允许限价单）。参数待定。

### 4.4 杠杆 / 保证金 / 强平 / 借券 / 资金费（船长已裁决：最高 90x、双仓位模式、允许负余额）

**杠杆档**：2x / 5x / 10x / 20x / 50x / **90x**。
- 按标的流动性分级给上限：高流动 90x / 中 50x / 低 20x（船长 2026-11-03：「最高可以开 90 倍杠杆，让他们梭哈，给玩家梭哈的权限」）。
- **仓位模式（船长 2026-11-03 裁决：双模式自选）**：默认**逐仓**；玩家可主动切「**全仓**」——所有持仓共用账户权益，强平 = 权益归零并记欠款，真梭哈可以归零。切换时 UI 必须明确警示。
- **90x 的数学**：`IM=1/90≈1.11%`、`MM≈0.67%`，多头强平距离 ≈ **0.447%**；在日波动 8% 的标的上，随机行走平均 **约 4~5 分钟**就会触碰（无漂移下 `E[T]=(b/σ)²`）。这不是系统刁难，是杠杆本身的物理。
- **费率档位（船长 2026-11-03 裁决：降常规档，让钱多留在玩家与人格之间）**：`L≤20x` 买 **0.05%** / 卖 **0.10%**；`20x<L≤50x` 买 0.03% / 卖 0.06%；`L>50x` 买 0.02% / 卖 0.04%。一轮往返占保证金：20x ≈ 3.0%、50x ≈ 4.5%、90x ≈ 5.4%。
- **标记价防插针**：90x 下 0.45% 波动即强平，强平必须用 **5~10 秒中位价** 判定，不能按单笔成交价——否则一次盘口插针就能把玩家打穿，那才是「系统扣钱」。
- **拉盘砸盘算玩法（船长 2026-11-03 裁决）**：允许玩家坐庄，但必须付出冲击成本与暴露风险；AI 人格会反制，交易所对极端波动提高保证金/限制开空，**但不清零**。
- **单账户名义敞口上限** = `min(该标的流通市值 × 10%, 流动性池可承接量, 盘口深度可承接量)`；超限时**不拒绝杠杆档**，而是显示「盘口深度不足，本次最多可开 X」——梭哈可以，但市场没那么多对手盘时只能成交能成交的部分。

**保证金**：
- 初始保证金 `IM = 1 / 杠杆`（2x→50%、5x→20%、10x→10%、20x→5%、50x→2%）。
- 维持保证金 `MM = 0.6 × IM`（50x→1.2%）。
- 强平价：多头 `P_liq = P_e × (1 − 1/L) / (1 − MM)`；空头对称。
- 强平执行：每拍**分片**吃对手盘 ≤1 档的 30%，逐步平仓，不一次性市价砸盘（防连锁崩盘）。

**允许负余额（船长裁决）⇒ 必须配债务与清算设计**：
1. 强平后 `equity < 0` 的部分记「**欠款**」，现金与持仓归零。
2. 回收顺序：分红 → 出金 → 入金 → 新仓盈利；欠款未清期间**禁止提现与开新仓**。
3. **破产清算**（玩家主动申请）：欠款清零，代价 = 信用等级下降 + 禁入市场 N 游戏日 + 记入档案。
4. **保险基金兜底上限**：穿仓由保险基金吸收；基金低于阈值时**自动提高全市场最低保证金并限制开新仓**（负反馈，防系统性穿仓击穿系统）。

**系统性风险约束（50x 的关键，本方案的核心闸门）**：
- 杠杆资金对手方是 AI 做市商与借券池，二者资本有限：`流动性池利用率 > 80%` 时资金费率上浮、限制开新仓。
- **系统绝不凭空补足穿仓亏损**：基金不足只能降杠杆 / 停开仓，不能印钞。
- 每标的每账户都有持仓与敞口上限，逼空螺旋也有硬顶（见 4.5 P4 监管介入）。

**离线保护开关（船长已裁决：接受离线强平 + 提供保护）**：
- 开关三种档：`不保护（默认，最真实）/ 自动降杠杆 / 自动止损+冻结新开仓`。
- 玩家离线超过 N 小时前触发保护动作，并推送一条服务端通知；保护动作写审计。

**做空**：系统借券池（P1），P3 再开玩家出借；借券费按日计息。
**资金费**：多空之间定期结算，一部分销毁；这是高杠杆的主要持有成本。

### 4.5 逼空阶段机（借鉴 StockSim 五阶段）

| 阶段 | 触发条件（初值） | 表现 |
|---|---|---|
| P1 囤积 | 借券/流通盘 > 20% | 盘口变薄，价格缓慢抬升 |
| P2 诱多 | 价格上涨 + 空头浮亏 | 动量散户跟风买入 |
| P3 回补螺旋 | 空头保证金率触及预警 | 空头强制回补 → 价格再涨 |
| P4 监管介入 | 5 分钟涨幅 > 25% | 提高保证金/限制开新空 |
| P5 崩溃回归 | 空头清空或资金耗尽 | 价格回归锚点，接盘者套牢 |

- 确定性关键：所有触发都用服务端状态与计数器判定，不用裸随机。

### 4.6 事件驱动（挂现有游戏实体）

| 事件 | 触发 | 影响 |
|---|---|---|
| 异形入侵 | 全服入侵次数/日 | 军工 ↑，物流 ↓ |
| 矿带发现 / 倾销 | 全服矿物产出波动 | 矿业 ↑ / ↓ |
| 虫洞发现 | 虫洞事件数 | 科研 ↑，运费 ↑ |
| 海盗猖獗 | 低安遇袭统计 | 物流 ↓，军工 ↑ |
| 公司财报 | 每游戏日结算 | 全板块按经营指标重估 |
| 个体事故 / 收购 | 随机 + 条件 | 单股剧烈波动 |

- 事件由服务端全服统计驱动；客户端只收到 `eventId` + 数字，**文案走客户端 l10n 表**（满足独立部署 + 中文先行纪律）。

### 4.7 AI 交易者生态

| 代理 | 行为 | 作用 |

### 4.8 分红与股东权益

- **分红池**（关键经济设计）：`分红池 = 当期交易税 + 佣金 × 比例 + 公司经营指标挂钩的有限额度`。**不允许凭空印钞**。
- 持股按比例分派，服务端每日结算，离线累加。
- 股东特权（P2 再议）：持股 1%/5%/10% 的交易税减免、产线提速、内部配额；**属跨域，需单独批准**。

### 4.9 量化交易（简单版）

- 策略模板（不是脚本）：定投 DCA、网格、移动止盈、止损、追涨/追跌、事件套利。
- 条件维度只用三种：价格阈值 / 涨跌幅 / 均线交叉（MA5/MA20）。
- 服务端定时评估（每拍或每 5s），下单走同一订单簿；每账号策略数上限、每分钟动作上限。
- 全部集成在同一个交易界面（不另开页面）。

### 4.10 经济闭环（费率初值，待校准）

| 项 | 初值 | 归属 |
|---|---|---|
| 买入佣金 | 0.10% | 系统销毁 |
| 卖出印花税 | 0.20% | 系统销毁 |
| 入金手续费 | 0.5% | 系统销毁 |
| 出金手续费 | 1.0% + 下一游戏日到账 | 系统销毁 |
| 杠杆利息（按日） | 0.02% ~ 0.05%，按流动性池利用率浮动（>80% 上浮） | 一部分进保险基金 |
| 借券费（按日） | 0.02% ~ 0.10% | 借出方（P1 为系统） |
| 资金费（8 小时） | 0.01% 基准，上限 0.1% | 多空互转 + 部分销毁 |
| 强平罚金 | 强平额 0.5% | 保险基金 |
| **分红池** | 当期（佣金 + 印花税 + 资金费）× 30%~50% | 回流给股东，**不额外印钞** |

> 校准注意：50x 杠杆下一轮完整买卖的名义税 ≈ 0.3% × 50 = **保证金的 15%**，高频交易天然自带重税，这是「抑制刷单 + 提供销毁口」的双重设计。税率若按经济代理建议提到 0.5%~2%，50x 下会变成保证金的 50%~200%，等于禁止短线——**不建议**，维持 0.1%/0.2%。

- 净销毁目标：玩家群体总资产在股市内**长期净流出**（税+费），分红只返还其中一部分。
- 20x 杠杆下，一次完整进出 ≈ 名义价值 0.15% × 20 = 保证金 3% —— 高频交易自带重税，天然抑制刷单。

### 6.1 交互规格（把「不区别界面」落到控件级）

**右栏 = 唯一的下单面板**，自上而下：

| 区块 | 控件 | 说明 |
|---|---|---|
| 模式分段控件 | `现货 / 杠杆多 / 杠杆空` | 只改保证金语义，**不切页面、不改布局**；切换时下方预览同步刷新 |
| 价格 | 数值框 + 「盘口价」快捷 | 点击盘口任一档位自动填入并高亮 |
| 数量 | 数值框 + `25% / 50% / MAX` 快捷 | 现货按可用现金算，杠杆档按保证金算 |
| 杠杆滑杆 | 仅杠杆档显示 | 档位按标的允许范围灰显不可用项，并标注理由 |
| 预览 | 保证金 / 名义价值 / 手续费 / **强平价 / 距强平 %** | 强平价随价格与杠杆实时重算；距离 < 15% 变警示色 |
| 保护 | 止盈 / 止损（可选） | 勾选后服务端条件单，与主单同一事务提交 |
| 提交 | `确认下单` | 杠杆档 ≥10x 时二次确认，确认框内再显示一次强平价 |
| 持仓 / 委托 | Tabs 切换 | 持仓行内直接「平仓 / 调整保证金 / 设止盈止损」 |
| 自动交易 | 折叠区 | 策略卡片列表 + 「新建策略」；见下 |

**自动交易（同一右栏、同一套控件）**：

- 策略卡片：`定投 DCA / 网格 / 移动止盈 / 止损 / 追涨 / 事件套利`。
- 新建策略表单只有两段：**条件**（价格阈值 / 涨跌幅 / 均线交叉）+ **动作**（买入 / 卖出 / 平仓，带数量与杠杆）。
- 策略执行走与手动下单**同一条服务端下单链路**，因此在委托列表里和手动单混排显示，用一个小角标区分来源。
- 每账号策略数、每分钟动作数有上限；触发动作写审计流水。

**状态与防错**：未绑定券商 → 引导连接服务器；已绑定未入金 → 引导入金；强平预警 → 页面顶部常驻警示条 + 持仓行红色描边；不可下单原因必须显式写出（杠杆档不允许 / 标的不可做空 / 额度不足），不做灰化无提示。

**长线玩家路径**：现货买入 → 持仓面板显示「累计分红 / 年化收益率 / 持股比例」→ 策略区提供「定投」模板。所有数字与短线玩家同屏，不另开「投资页」。

### 6.2 下单表单的防错规格（映射《表单设计体验》）

交易所下单面板是**高风险表单**（一次误输可能直接爆仓），按书中「理解→检索→裁量→录入」四阶段逐条落地：

| 准则 | 落地规则 |
|---|---|
| 单列垂直流 | 下单面板**单列自上而下**，不做两列并排；标签在控件上方，**禁止用占位符冒充标签** |
| 控件选型 | 模式（3 项）与杠杆档（5 项）用**分段控件**，不用下拉菜单；选项 < 5 一律不用下拉 |
| 前馈计算 | 保证金 / 名义价值 / 手续费 / 强平价 / 距强平**随输入实时重算**，不等提交才报错 |
| 数值三元联动 | 数量 = 步进器 + 滑块 + 数字框 + `25%/50%/MAX` 快捷；杠杆 = 分段控件 + 滑杆，双向同步 |
| 行内校验 | 失焦即校验；错误写在字段下方，说明「错在哪 + 怎么改」，不弹全局红条 |
| 主按钮不置灰 | 不可下单时**不禁用按钮**，点击后显式说明原因（额度不足 / 标的不可做空 / 杠杆档不允许），避免灰按钮死胡同 |
| 裁量阶段消疑 | 强平价旁直接写「价格跌到 X 即强制平仓，距现价 Y%」，不要求玩家自己算 |
| 敏感度校验 | 数量或杠杆超敞口上限时给**可点击的建议值**（「按上限最多可开 N 股」），不只报错 |
| 防手滑 | ≥10x 二次确认，确认框内再显示一次强平价与最大亏损；同一单 2 秒内幂等去重 |

## 附录 A：撮合与价格引擎实现要点（撮合参考子代理取证，服务端可直接照搬）

### A.1 订单簿骨架

- 定点价 `p`（×100 分）；`seq` 单调号即唯一时间优先级（**禁止 `Date.now`**）；买入档降序、卖出档升序；档内 FIFO。
- 档位上限 10 档（超出当市价），订单索引 `Map<id, Order>` 撤单 O(1)。
- 撮合伪代码：

```
submit(o): o.seq = ++seq
  opp = o.side==buy ? asks : bids
  while o.qty>0 && 交叉(o.p, opp.top.p):
    m = opp.top.q[0]; f = min(o.qty, m.qty)
    成交(m.p, f)            // 成交价恒取 maker 价
    o.qty -= f; m.qty -= f; opp.top.total -= f
    if m.qty==0 { 出队; index.delete }
    if opp.top.total==0 删档
  if o.qty>0 && 允许挂单: 插入 else 撤销余量   // 市价单 = 限价±∞ + 剩余全撤
```

- 订单类型取舍：**必须** 限价 GTC / 市价 / 停价（触发池独立，每拍按 high-low 判触发）；**低成本可得** IOC（加 `tif` 即可）、Post-Only；**建议砍** 冰山、FOK、集合竞价（玩法重复、单机/小圈子无隐藏意图需求）。
- 停价池不进主簿，每拍判触发 → 转市价；这是「防离线爆仓」的关键组件。

### A.2 价格演进（对数空间 + 肥尾 + 波动聚集）

```
x = ln(P / A)                       // A = 内在价值锚点
Δx = (μ − σ²/2)·Δt + σ·√Δt·Z − θ·x·Δt + ΣJ + λ_f·(Q/V_ref)
P = A · e^x，x 钳制在 ±ln5
```

| 参数 | 初值 | 说明 |
|---|---|---|
| σ/步（60s） | 0.5% 蓝筹 / 0.9% 常规 / 1.6% 军工科研 | 需实测 |
| μ/步 | 0 ~ +0.03% | 板块异质 |
| θ（均值回归） | 0.002 ~ 0.01，默认 0.0045 | 半衰期 ≈154 步 |
| Z 分布 | Student-t ν≈5（肥尾） | 比正态更有赌博感 |
| 波动聚集 | EWMA：`σ²_t = λσ²_{t−1} + (1−λ)r²_{t−1}`，λ=0.94 | 替代 GARCH(1,1) |
| 事件冲击 J | ±3% ~ ±25% | 见 4.6 |
| 资金流冲击 λ_f | 0.5 ~ 2.0，或 √律 `k√(Q/V)`，k≈0.1~0.5 | 玩家大单影响 |
| σ 自适应 | ≤4σ_base；事件后 ×2~3，5~10 步回落 | 防失控 |
| 硬边界 | 0.2A 地板 / 5A 天花板 + 锚点引力 | 防归零与无限泡沫 |

> 两个已知坑：① 参考资料里 `σ=0.02/2.5s` 直接折算到 60s 必失控；② 现市场 `noiseStep=0.04`、`shockPerTrigger=0.1` 是**物资本位**参数，照抄会与现货同质化。RNG 必须每标的每步无条件消费一次，否则读档时序漂移（`advance.ts` 已有同类教训）。

### A.3 杠杆与强平公式（逐仓）

| 项 | 公式 / 取值 |
|---|---|
| 初始保证金率 IM | 2x→50% / 3x→33% / 5x→20%（按此规律推 10x→10%、20x→5%） |
| 维持保证金率 MM | `MM = 0.6 × IM` |
| 多头强平价 | `P_liq = P_e × (1 − 1/L) / (1 − MM)` |
| 空头强平价 | `P_liq = P_e × (1 + 1/L) / (1 + MM)` |
| 强平判据 | `equity ≤ MM × 名义价值` |
| 强平执行 | 每拍吃对手盘 ≤1 档的 30% 分片平仓；`equity ≤ 0` 交保险基金 |

> 三份金融参考资料均**未覆盖保证金公式**，上式为按逐仓定义自行推导，需实现后用确定性用例验证。

### A.4 逼空五阶段（确定性化）

| 阶段 | 触发（初值） | 表现 |
|---|---|---|
| 潜伏 | 空头持仓 SI > 80% 流通 | 盘口变薄 |
| 点火 | 价格 > 1.15 A 且 si < 0.8 | 动量散户跟风 |
| 轧空 | 空头 equity < MM | 强制回补 min(持仓 30%, 对手 1 档) |
| 顶部 | 空头资金耗尽 | 「capital 耗尽即退场」是可控关键 |
| 崩溃 | 无新买盘 | −85% 回归 |

- **步序必须钉死**：撮合 → 强平 → AI 下单 → 价格演进。步序错了螺旋就出不来。
- 流动性真空：做市商必须设**库存上限 / 撤单阈值**，否则永远轧不起来。
- 催化剂用**时间表**驱动，不用随机，否则读档后阶段漂移。

### A.5 AI 参数（初值，需实测）

| 代理 | 规则 | 参数 |
|---|---|---|
| 做市商 | `mid ± (spread/2 + γσ²qT)` 含库存偏移（A-S 简化） | spread 0.2~0.5%；每档 = 流通 0.05~0.2%；库存 ±1% |
| 动量散户 | 5 步收益 > +2% 买；亏 8~15% 止损 | 单笔 = 池 2%；池 = 流通 5~10%；情绪周期 20~40 步 |
| 价值机构 | P < 0.8A 买、P > 1.3A 卖 | 单笔 3~10× 散户；冷却 20 步；池 20~30% |

- 防薅：库存反向恶化时**报价偏移**、资金耗尽停挂；成交恒取 maker 价；同 step 按 seq 排序。
