1. 玩家可从对应势力加密货柜中获得战损管理、纳米生物质、蓄能、无人机指挥、坚固结构五种插件的一次性制造图纸，使用任意黑匣按原料单制造。
2. 战损管理插件可减轻战损惩罚，并按不同战损类型提高结构动能与能量抗性；纳米生物质插件以部分装甲容量换取持续装甲修复。
3. 蓄能插件提高动能武器与激光的单发伤害，同时延长攻击间隔、减轻远端衰减；无人机指挥插件可向友舰分享无人机伤害加成，并增加本舰被选为目标的倾向。
4. 坚固结构插件提高结构容量，装有该插件的沉船整船回收成功时保留旧战损，不再新增战损。同种新增插件多件安装只生效一件。
5. 敌我舰船护盾自然回复统一采用当前护盾比例与满盾下限，空盾后不再自行恢复；危机超载协议与生体甲壳板的伤害、无人机周期及修复量同步调整。
