## 二、根因（代码位置）

`packages/core/src/expedition.ts:683-685`：

```ts
// V18B-1：武器形态分家——炮台（turret）与导弹架（missile）都算"已装武器"
const hasTurret =
  familyModules(state, ctx, shipId, 'turret').length > 0 || familyModules(state, ctx, shipId, 'missile').length > 0
```

⇒ **判据只认 `turret` 与 `missile`**，漏了：
- **`laser`（激光炮 = 能量系）** —— V18B-2 把"能量炮台 ＋ 异星原型"归位成激光炮之后，
  游戏里**能量系武器全是 `laser`**（`V17_MODULE_MIGRATIONS` 里 `mod-turret-pla-* → mod-laser-*` 可证）；
- **无人机线 `drone-rack` / `drone-tac`**。

注释自陈"**V18B-1**：炮台与导弹架都算" ⇒ 写这行时只覆盖到 V18B-1，**V18B-2 落码后没跟着同步**。

**同仓另有一份正确口径**（对照）：`packages/core/src/weekendLaunch.ts:71` 的
`WEAPON_SLOTS = { turret, missile, laser, drone-rack, drone-tac }`（**5 个**）——
即"同一件事、两处判据、口径不同"，`expedition.ts` 这处是漏的那种。
（`combat.ts:1513-1515` 与 `:2106-2108` 的武器汇总都是 `turret + missile + laser` **三系齐全** ✓ 也印证 laser 属于武器。）

## 三、玩家可见现象为什么长这样 ＋ 影响面

- 那句日志由 `hasTurret` 直接分支：`hasTurret ? （有弹药⇒"预载弹药 N 发" / 没弹药⇒"警告：未携带弹药…"） : "未装配武器：仅基础舰炮还击。"`
  ⇒ 玩家装的是**激光炮/无人机**时，`hasTurret === false` ⇒ 打印"未装配武器" ⇒ 与他装配页看到的事实相反。
- **⚠ 影响面：纯日志文案错，战斗计算不受影响** —— 战斗侧的武器汇总是 `turret + missile + laser` 三系齐全
  （`combat.ts`），激光照常开火、照常吃弹药。⇒ 玩家被**误导**（以为武器没生效），但战力没损失。
- 同类现象还会出现在**常驻悬赏 / 窝点赏金 / 入侵悬赏**（都走同一条远征抵达链）—— 玩家报的"打入侵悬赏"属于其中一种。
