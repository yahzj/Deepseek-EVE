## 实施边界

同类参照为已迁移的工业与技能域，三层均使用功能域目录和旧路径具名兼容出口。

- core `market/`：常量、门槛、定价与税、日志/显示名、NPC簿底层、供给与开盘、报价/价格史、库存出入、结算、撮合、订单、即时交易、舰船交易及自然库存交易。函数正文不动，私有跨文件依赖仅在域内导出，公开旧API集合保持。
- 周期推进仍按原序清过期、库存回归/噪声、消化、供给、撮合、站内吸收、价格史与冲击；撮合与即时交易不相互反引，税、声望、收入与托管核销仍走原函数。
- data `market/`：570条源码绑定原键序压缩空白到单独bindings，原目录按RAW、残骸、追加、插件顺序组合；渠道闸门和残骸派生单列。JSON与稀有度填充、黑市资格、未上线过滤不变。
- renderer `features/market/`：商品行、列、价格图、详情、我的挂单、筛选/排序/读数辅助与页面；按原函数边界提取，不新拆状态，不改变Hook、key、ResizeObserver、窄屏浮层和订单草稿生命周期。
- 参数导入清单与数据编辑器绑定位置同步，不扩展工具的权限/安全模型；源文件测试改读真实声明，保留断言。
- 新实现每份至多800行。App/index/state/save等未审大文件不动，必要小调用点直引实现。一次性脚本核验后删除。
