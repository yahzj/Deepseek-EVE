### 2.3 超空间折跃燃料（`jump-fuel` · kind = 新增档 `consumable`）

- **计量**：1 单位燃料 = **1 秒「原返航时长」**（原返航 = 不含燃料时的返航时长，含货仓占比缩放）。
- **消耗**：返航腿**开始时扣一次**（`ceil(原返航秒)` 单位）；燃料不足 ⇒ 本趟不加速、不扣。
- **效果**：该趟返航**速度 ×10**（时长 ÷10）。
- **开关**：采矿 / 打捞 / 悬赏与远征 / 探索扫描 / AI 副船作业（`state.jumpFuel`，**默认全关**）。
- **不吃**：手动撤退（本来就即时）· 战斗中不生效 · 没打开开关的活动。
- **本地母港卡照吃**（船长令）。
