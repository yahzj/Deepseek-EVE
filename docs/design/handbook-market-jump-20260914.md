# 手册 · 图鉴详情加「↖ 查看市场」（2026-09-14）

> **状态**：✅ **已确认**（船长 2026-09-14「按你推荐来」＋「可以」）｜✅ **已落码**（本地提交，待验收）
> **船长原话（照抄）**：「**玩家查看图鉴内的道具时，添加一个跳转市场的按钮。**」
> **落点**：`panels/Handbook.tsx` · `ui/marketJump.ts`（新）· `App.tsx` · `styles.css` · `tools/content-check.ts`

## 一、行为

点那枚按钮 = **关掉手册 → 切到市场页 → 一次性聚焦该商品**：市场页会把搜索词设为该商品、选中它并
展开**行情详情**（价格 / 挂单 / 买入）。**只跳转、不下单**——与 2026-09-14 船长在组装机那条定的口径
一致（「跳转到市场对应的订单详细，而不是直接市场价下订单」）。

复用 App 里现成的 `onGotoMarket(goodKey)` 入口（舰船页 / 物品页 / 货舱页 / 工业页都在用，
**全仓一处口径**；聚焦带 `seq` 递增 ⇒ 连着点同一件也会重新聚焦）。
**必须同时关手册**：手册是覆盖层，不关就会盖在刚切过去的市场页上面，聚焦也看不见。

## 二、范围与形态（四条推荐口径）

| 决策 | 取法 |
|---|---|
| 覆盖范围 | **物品 / 装备 / 舰船 / 蓝图**四个图鉴的详情浮层；技能速查与说明类页签**不给**（不涉市场） |
| 位置与文案 | 详情浮层**头部右侧** · `app-btn is-small` ·「**↖ 查看市场**」· 悬停「前往市场查看该物品的订单（价格/挂单/买入）」 |
| 无市场行 | **不渲染按钮**（照物品页口径；不是置灰） |
| 蓝图跳哪边 | 跳**这张蓝图自己**的订单详情（买书 / 自己挂买单），与组装机口径一致 |

## 三、映射与单一实现

- 图鉴四类的主键就是各自目录的 id ⇒ 直接问 core 的 `marketGoodOf(ctx, kind, refId)`
  （与物品页 / 货舱页 / 组装机**同一个查询口**）：`items→'item'` · `modules→'module'` ·
  `ships→'ship'` · `blueprints→'blueprint'`。
- 映射单点放在**新建的 `apps/desktop/src/renderer/src/ui/marketJump.ts`**（`handMarketKeyOf`），
  而不是写在 `Handbook.tsx` 里：**体检要跨层调它**，而 `Handbook.tsx` import 了 `@whale/ui`
  → `packages/ui/src/index.css`，node 侧 `tsx` 加载即 `SyntaxError: Unexpected token ':'`（实测）。
  新模块**只依赖 `@whale/core`**（与 `ui/shipInfo.tsx` 那条既有跨层契约同款，两头都能安全 import）。

## 四、常驻护栏：体检新增「图鉴市场跳转契约」

`tools/content-check.ts` 跨层 import `handMarketKeyOf`，把**四类图鉴目录逐个走一遍**（与手册同一套
可见目录口径：物品走 `visibleItemDefs`、装备/舰船/蓝图走 `itemReleased` 过滤后的目录）：

- 判据 = 每个条目都要能命中一行，**放行四类**（前两类是"市场页本来就看不到它"，不是漏行）：
  ① 能命中；② 市场行**被 `unreleased` 闸掉**（施工期市行，`buildMarketGoodsCatalog` 会过滤）——
  谜质装置 24 + AI 核心 3；③ 物品 kind = `wreck` / `fragment`（残骸唯一变现 = 回收炉开箱、
  隐藏卡残骸没有收购卡、碎片不进市场）；④ 名单例外：`sandcat`（协会保底艇）/
  `sh-dunkleosteus`（无渠道壳体），理由同「挂卖可达契约」的 `NO_ROW_OK`。
- **反向判据**：玩法速览 / 航行须知 / 技能速查三个页签**恒不命中**（防"给说明页也挂上按钮"）。
- 为什么值得常驻：映射错位（改图鉴主键语义、改某族的 market kind）不会报错，只会让
  **整类图鉴的按钮静默消失**——玩家看不见"少了个按钮"，只有这条契约会点名。

**实测读数**：四类图鉴 **505 个条目** ⇒ 可跳 **439** · 市行被 `unreleased` 闸掉 **27** ·
残骸/碎片无市场卡 **37** · 名单例外 **2**。

## 六、边界与不做

- 网格卡上**不放**第二枚按钮（卡片小会挤）；市场页聚焦逻辑本身未动。
- **技能速查**没有市场行、**说明类**页签不涉市场 ⇒ 都不给按钮。
- 只收不卖的条目（洞内专属 106 行 / 残骸收购卡）**正常可跳**——跳过去看到"只收不卖"是预期信息。
- **未上线内容**本来就不进图鉴（`unreleased` 闸）⇒ 与其市场行一同隐身，两边口径一致。
- 零存档影响、零数值改动。
