## 二、战斗伤害飘字（已落完）

**数据侧（core）**：`BattleFx` 新增**可选** `dmg?: number`（`packages/core/src/state.ts`，纯展示、零迁移），
口径 = **`applyDamage().dealt` 实收**（盾→甲→结构真扣掉的血量，已吃层克制与层抗；含本发附伤段），
写入点：

| 开火支 | 写入值 |
|---|---|
| 我方每发（主目标） | 主段 + 附伤段 `dealt` 之和（`selfDealt`） |
| 我方「全体攻击」的每艘副目标 | 该舰自己的主段 + 附伤段之和（`oDealt`，逐舰各一个数字） |
| 敌方机群 / 敌方炮台 / 敌方光束 | 该发前后**被打那艘我方舰**三层血量之和的差 |

- **未命中 / 无伤事件（捕获网连线、机群击落演出）不写该字段** ⇒ 表现层不出数字（不会飘「-0」）。
- 齐射协调仪的**溢火结转**不计在本发头上（落在另一艘敌舰身上，已有画面提示）。
- `save.ts` 的 `cleanFx` 白名单收录该字段（坏值/缺省一律不写）⇒ 战中重载后仍在环里的事件照旧带数字。
- 只读已算出的结算结果：**不多消费一个随机数、不改任何数值**（`tests/battle-fx-dmg.test.ts` 用同种子
  双跑逐值对账锁住这条）。

**渲染侧（apps/desktop）**：`panels/BattleScreen.tsx` 飘字层——落点 = 这一发的**目标点**（与弹道同一套几何）·
同一拍按目标 tag 累加成一个数字 · 数字吃 `DMG_COLOR[type]`、MISS 用 `--wui-dim`（灰，不新造色）·
生命期 `POPUP_LIFE = 900` 走**战斗时钟** `now`（倍速跟着快、暂停即冻结）· 叠在弹道之上且 `pointer-events:none`。
文案 id：`ui.BattleScreen.107`（zh/en 同为 `MISS`，船长指定显示 MISS）。

**落码时顺手修掉的一个洞**：首版对 `hit: true` 但无伤的事件（捕获网连线、机群击落）会飘出「**-0**」⇒
现在**零伤且非未命中就不落飘字**（真未命中才飘 MISS）。
