## 1. 船长原话（照抄）

> 「入侵的收复进度100%后，外围和核心星系仍然可以继续刷入侵敌人。但是残骸掉落减半，也没有其他啊奖励。」

澄清追问后：

> 「我希望的是 **100% 后能够继续刷，但是掉落残骸数量需要减半作为惩罚**」

（⇒ 前一条是**规格**不是抱怨：「也没有其他奖励」= 惩罚就是惩罚，**不用再补奖励**。）

## 2. 现状读数（临时探针 `tools/_probe-postreclaim.mts`，收尾删）

全部夺回（每处进度 100%）后，**除旗舰战外全部门都关着**：

| 入口 | 改前 | 出处 |
|---|---|---|
| 星图/详细页「击退入侵舰队」行 | 关（板面回落该星系原卡） | 渲染层 `invadedHere` 自判 `progress < 1` |
| 主动出击抽签 `weekendAssaultDrawOf` | `null` | `weekendOccupiedLiveAt` 要求进度 < 1 |
| 遇袭抽签 / 遇袭概率 | `null` / `0.0%` | 同上 ＋ `p = 60%×(1−进度)` |
| 「重复出击」 | 自动停（"该星系已被夺回"） | `advanceAutoLoopInvasion` |
| **旗舰（母舰）战** | **仍开着** | 只要求"核心条满 ＋ 未落定局"，与夺回无关 |

⇒ 于是"100% 之后还能打的"只剩旗舰战，而它走**遭遇**结算 ⇒ 残骸按 `WRECK_ENCOUNTER_INJECT_FRAC = 0.5`
（"遇袭半量"）＋ 入侵遭遇赏金恒 0。这就是原话里"掉落减半、也没有其他奖励"的来源。

## 3. 船长三答（2026-10-02 · 全取推荐案）

| 问 | 取 |
|---|---|
| 遇袭概率公式 `60%×(1−进度)` 动不动 | **甲：不动** ⇒ 100% 的星系遇袭概率恒 0（"继续刷"= 玩家**主动**去刷） |
| 100% 的星系仍显示为被占（红光 ＋ 满格进度条） | **甲：可以** |
| 加一句「已夺回 ⇒ 只给半量残骸」的说明 | **甲：加**（稿子随本批一起递审） |

## 4. 逐条改动（方案即确认稿）

1. **判据改名改义**：`weekendOccupiedLiveAt` → **`weekendZoneLiveAt`**
   （＝「活动未结束 且 该星系是本次入侵的核心/外围」，**删掉"进度必须 < 1"那一句**）；
   core 与渲染层全部调用点同步 ⇒ 夺回后「击退入侵舰队」行、板面换卡与置顶、遇袭破例、主动出击、
   重复出击**照旧开着**（观感即第 3 节第 2 答：红光 ＋ 满格进度条一直挂到活动结束）。
2. **残骸减半（本轮唯一的新数值口径）**：新增单点 **`weekendWreckPenaltyFracOf(state, galaxyId, nowWallMs)`**
   —— 该星系**已夺回**（进度 ≥ 1）⇒ `0.5`，否则 `1.0`；出征注入那一行按它取 `frac`
   （遇袭本来就是 0.5、旗舰战也是 0.5 ⇒ 100% 后三种入口**一律半量**）。
3. **不给其他奖励（保持不动 ＋ 堵一个漏）**：已核 ① 进度台账 `clamp01`（满档不再涨 ⇒ 结算无额外进度收入）
   ② 入侵卡赏金 0 ③ 夺回奖一次性 ④ 声望只首胜。
   **要改的是**：`weekendBattle` 现在把「核心满 ⇒ 去核心打」判成**旗舰战** ⇒ 入口一放开会把"继续刷核心"
   错发成旗舰掉落（稀有残骸 ×3）⇒ 改成**只有"遭遇槽挂着旗舰卡"那一场算旗舰战**，其余算普通入侵舰队
   （该判据只对 **BOSS 族**（H/R）改；A/C/G 的老口径逐字保留，避免动到未上线族）。
4. **文案**：新增一条说明（悬停），只给"已夺回"的星系看：**该星系已夺回 ⇒ 继续打只给半量残骸、进度不再增长**。
5. **用例**：订正 5 处旧口径断言（重复出击"夺回即停" · 夺回后板面回落原卡 · hint 已夺回不算 …）
   ＋ 新增用例（夺回后仍可出击 · 重复出击不停 · 残骸半量 · 台账不涨 · 板面仍换入侵卡）。

## 5. 边界（不动）

- 活动结束（96h / 结算）后一切关闭照旧；夺回奖励、进度收入、贡献四档奖的结算口径不变。
- 遇袭概率公式不动（见第 3 节第 1 答）。
- R 族（二号在途）走同一套；本批不碰其数据与文案。
