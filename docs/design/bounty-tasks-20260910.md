# 赏金任务 · 敌人窝点（2026-09-10 船长定稿）

> 状态：**已确认（结构）/ 数值待定**——结构、界面与掉落链路已按船长口径实现并通过验证；
> 文件顶部集中了一批**可调常量**（威胁系数、波次占比、僚机增量、酬金比例、稀有残骸件数、
> 高级箱命中率与矿物量、六件专属装备数值），等船长定数后只改常量。

## 0. 一句话

星图的「战斗悬赏」改名 **常驻悬赏**；任务中心新增第四个子页 **赏金任务**——限时派发的**临时战斗任务**，
目标是被按档位强化过的**敌人窝点**；打赢 → 窝点奖金 + 任务酬金入账，并在该星系留下**稀有残骸**
（打捞必得），回站精炼炉当**高级箱**开，可开出该敌族的**专属装备**。

| 项 | 结论 |

## 2. 周期与规则（船长口径）

- **独立日板（2026-09-10 船长定）**：24 小时一轮、**每天本地 0 点整板替换**，按**现实墙钟**对齐
  （`nowWallMs` 由心跳传入：在线 = `Date.now()`，离线 = 离线末刻），与资源/快递的 20 分钟板完全独立
  （两套倒计时各自计时；跨日只补最后一道界，中间那些天的板早已作废）。
  落档字段 `sideTasks.bountyWindow` = 上一次刷出的日界（本地 0 点墙钟毫秒，0 = 未开板；老档缺省 0，
  首次拿到有效墙钟即开板）。
- **抽地点（日板席位）**：按安全等级分区抽，**高安不派发**（排除后按候选数比例分：**中安 2 席 + 低安 3 席**
  = 每天 5 个地点）；各区**独立抽**、抽不满就少发（不跨区补位）；同日不重复星系；
  赏金任务不触碰市场（无刷单影响）。
- **发档位**：三档**随机发放**，但**保证每天每个档位至少一张**——5 席 = 三档各 1 + 余下 2 席随机；
  恰好 3 席 = 外围/核心/深层各 1；2 席 = 两个不同档位；1 席 = 随机一档。
  档位与"抽到哪个地点"解耦（地点只决定在哪打，不决定多深）。
- **声望门槛 = 接取条件（2026-09-10 同日修订）**：主题悬赏的声望门槛不再过滤候选，
  声望不够的窝点**照样在板上出现**（卡面同时展示门槛与当前协会声望，未达标时整卡压暗 + 锁形徽标），
  但「出发」被拒（提示 `需声望 N（当前 M）`）——声望达标后即可接（当日剩余时间内随时可接）。
  **旧规则「窝点档位上限由声望决定」已退役**：档位由日板发放，不再随声望封顶。
- 过期即作废，**无惩罚**；档位、酬金、窝点名在**刷出时锁定**（面板剩余时间与资源/快递同源）。
- 必须**亲自出击**（AI 不能代劳）；与采矿互斥时走既有「转战」两步确认。
- 出击校验（顺序）：目标数据 → 舰队可用 → **协会声望 ≥ 卡面门槛** → 星系已探索 → 重复冷却 → 扫描/返港互斥；
  另有窝点专属校验：非窝点目标（无核心词/隐藏/**B 族**）拒绝。

## 3. 档位（日板发放）

| 档 | 威胁系数 | 僚机 | 波次（威胁大头后置） | **赏金倍率** | 酬金比例 | 稀有残骸 |
|---|---|---|---|---|---|---|
| 一档 外围 | ×1.3 | +0 | 沿用主题悬赏原波次 | **×2** | ×0.5 | ×1 件 |
| 二档 核心 | ×1.6 | +1（上限 2） | 双波 0.35 / 0.65 | **×4** | ×0.75 | ×2 件 |
| 三档 深层 | ×2.0 | +1（上限 2） | 三波 0.2 / 0.3 / 0.5 | **×8** | ×1.0 | ×3 件 |

- **赏金倍率 2/4/8（2026-09-10 船长定）**：窝点奖金 = 主题悬赏奖金 ×2/×4/×8 —— **只管钱、不管难度**，
  威胁/波次/僚机仍走档位威胁系数 1.3/1.6/2.0；酬金 = 窝点奖金 ×档位比例（跟强度递增）。
- 战报、奖金、残骸投放、失利维修费一律按**本场实际目标卡**（强化后）计，避免"打了窝点按主题悬赏报账"；
  卡片展示公式 = 结算公式 = `窝点奖金 × 赏金猎手学系数`（展示=到账口径，见词典）。

## 4. 战利品链路

1. **打赢窝点** → 该星系残骸场按敌群记账留下**稀有残骸 ×档位件数**（1/2/3 件，单件 30 m³）。
   - 稀有残骸只在**窝点**产出；常驻悬赏不产出。
   - 任务已过期也照常投放（打都打了，战利品不能吞）；任务仍在板上则同时结算酬金并下板。
   - 打输 / 撤退：任务留在板上可再来，**不投放**（窝点档位随本场作废）。
2. **打捞** → 该星系有存量时，打捞每轮**必捞一件**稀有残骸（捞完为止，之后回常规残骸池）。
3. **开箱** → 回站精炼炉「残骸回收」按**高级箱**处理：常规保底照有，**另必给**额外掉落：
   ①先掷该敌群**专属装备**（按回收档位命中率）→ ②未命中则给该敌群**主题追加件** → ③无论命中与否，
   再附一批**高阶矿物**（数量按档位）。每件稀有残骸只结算一次（由回收首批触发）。
