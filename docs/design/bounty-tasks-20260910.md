# 赏金任务 · 敌人窝点（2026-09-10 船长定稿）

> 状态：**已确认（结构）/ 数值待定**——结构、界面与掉落链路已按船长口径实现并通过验证；
> 文件顶部集中了一批**可调常量**（威胁系数、波次占比、僚机增量、酬金比例、稀有残骸件数、
> 高级箱命中率与矿物量、六件专属装备数值），等船长定数后只改常量。

## 0. 一句话

星图的「战斗悬赏」改名 **常驻悬赏**；任务中心新增第四个子页 **赏金任务**——限时派发的**临时战斗任务**，
目标是被按档位强化过的**敌人窝点**；打赢 → 窝点奖金 + 任务酬金入账，并在该星系留下**稀有残骸**
（打捞必得），回站精炼炉当**高级箱**开，可开出该敌族的**专属装备**。

## 2. 周期与规则（船长口径）

- **独立日板（2026-09-10 船长定）**：24 小时一轮、**每天本地 0 点整板替换**，按**现实墙钟**对齐
  （`nowWallMs` 由心跳传入：在线 = `Date.now()`，离线 = 离线末刻），与资源/快递的 20 分钟板完全独立
  （两套倒计时各自计时；跨日只补最后一道界，中间那些天的板早已作废）。
  落档字段 `sideTasks.bountyWindow` = 上一次刷出的日界（本地 0 点墙钟毫秒，0 = 未开板；老档缺省 0，
  首次拿到有效墙钟即开板）。
- **抽地点（日板席位）**：按安全等级分区抽，**高安不派发**（排除后按候选数比例分：**中安 2 席 + 低安 3 席**
  = 每天 5 个地点）；各区**独立抽**、抽不满就少发（不跨区补位）；同日不重复星系（同星系多张卡取级别最高的一张，
  见 §3.1）；赏金任务不触碰市场（无刷单影响）。
- **发档位**：由该地点的**地图级别封顶**（见 §3.1）——1 级图只出外围、2 级图到核心、3 级图全档；
  逐卡独立掷、**无三档保底**（旧规则"每天三档各至少一张 + 档位与地点解耦"已于 2026-09-10 船长定下退役）。

### 2.1 敌对派系活跃（同日追加：日板置顶的额外一条）

- **选点**：每天从**已探索的中安/低安**星系里随机选一个（该星系要有正经悬赏卡：非隐藏、有核心词、奖金 > 0）。
  选中后该星系**从常规 5 席的抽签池里剔除**（避免同星系两条）→ 当天共 **1 条派系 + 5 席常规 = 6 条**。
- **加成范围**：**只作用于该星系的常驻悬赏**（与赏金任务的窝点无关）——当天它的**全部**可见悬赏
  **奖金 ×1.1、威胁 ×1.1**。威胁不是纯数字：它驱动敌舰**血量/火力/速度/射程**（血量 = 段火力 ×D(威胁)，
  D 为 5s→90s 的击杀秒数刻度、指数 1.6；速度基数 0.80→0.95）；因为中安/低安卡的威胁都 ≥20，
  +10% 不会踩到敌血曲线的段界（16 / 40 两条），只是平滑变硬。
- **战利品**：胜利后**按概率**掉稀有残骸 ×1（进该星系残骸场，打捞必得 —— 与窝点同一条链路）。
  **不因打赢而下板** → 当天可反复刷（这也是概率要按"日均刷取次数"审数的原因，见 §7）。
- **界面**：赏金任务页最上方一条琥珀描边卡（`is-faction`），显示星系/安全等级/威胁（原值 → +10%）/
  奖金（原值 → +10%）/胜率/掉落概率；常驻悬赏页对当日该星系的悬赏卡挂「派系活跃」徽标，
  且威胁、奖金、胜率、估算收益全部按**加成后**显示（展示=到账）。
- **声望门槛 = 接取条件（2026-09-10 同日修订）**：主题悬赏的声望门槛不再过滤候选，
  声望不够的窝点**照样在板上出现**（卡面同时展示门槛与当前协会声望，未达标时整卡压暗 + 锁形徽标），
  但「出发」被拒（提示 `需声望 N（当前 M）`）——声望达标后即可接（当日剩余时间内随时可接）。
  **旧规则「窝点档位上限由声望决定」已退役**：档位由日板发放，不再随声望封顶。
- 过期即作废，**无惩罚**；档位、酬金、窝点名在**刷出时锁定**（面板剩余时间与资源/快递同源）。
- 必须**亲自出击**（AI 不能代劳）；与采矿互斥时走既有「转战」两步确认。
- 出击校验（顺序）：目标数据 → 舰队可用 → **协会声望 ≥ 卡面门槛** → 星系已探索 → 重复冷却 → 扫描/返港互斥；
  另有窝点专属校验：非窝点目标（无核心词/隐藏/**B 族**）拒绝。

### 3.1 档位怎么发：地图级别封顶（2026-09-10 船长定，替代旧"随机 + 三档保底"）

船长口径：**同族存在多张地图时，越低级的图出现高档位赏金的概率越低**。落地规则：

- 每张窝点卡标一个 **`AnomalyDef.lairLevel`**（1/2/3）= 该地图的**档位上限**：
  **1 级只出外围、2 级到核心、3 级全档**，故 1 级图永远出不了核心/深层；
- 发档 = 在该卡 `[1..lairLevel]` 内**均匀随机**（硬封顶，不是加权），**逐卡独立掷**；
- **旧"每天三档各至少一张"的保底取消**、旧的"抽完再洗牌让档位与地点解耦"也取消
  （本改动正是要建立"地点级别 → 档位上限"的关联）；
- 级别**只按族内相对强度**（奖金为主、威胁为辅），**不与区划绑定**：A 族 6 张全在中安，
  若按区划封顶则海盗永远出不了深层；
- 契约（`content-check` 窝点级别契约）：每张候选卡必须**显式标级**（缺省 3 只是"漏标不误伤"），
  且**每个敌族至少一张 3 级**（船长 2026-09-10 定）；另对"同族内级别更高而奖金更低"出提示。

## 4. 战利品链路

1. **打赢窝点** → 该星系残骸场按敌群记账留下**稀有残骸 ×档位件数**（1/2/3 件，单件 30 m³）。
   - 稀有残骸只在**窝点**产出；常驻悬赏不产出。
   - 任务已过期也照常投放（打都打了，战利品不能吞）；任务仍在板上则同时结算酬金并下板。
   - 打输 / 撤退：任务留在板上可再来，**不投放**（窝点档位随本场作废）。
2. **打捞** → 该星系有存量时，打捞每轮**必捞一件**稀有残骸（捞完为止，之后回常规残骸池）。
3. **开箱** → 回站精炼炉「残骸回收」按**高级箱**处理：常规保底照有，**另必给**额外掉落：
   ①先掷该敌群**专属装备**（按回收档位命中率）→ ②未命中则给该敌群**主题追加件** → ③无论命中与否，
   再附一批**高阶矿物**（数量按档位）。**一炉一箱**（船长 2026-09-10 定：按炉结算、不按件累积——
   该台炉处理它的第一批时结算一次，故把多件稀有残骸丢进同一台炉只开一箱；逐件开就是一炉一箱）。

   **开放状态**：稀有残骸**已解禁**（船长 2026-09-10：二号五族专属装备齐备后开放）。此前封存期的
   "协会回收炉暂不受理" 实现与全部玩家可见文案已同步清掉（核心拒绝分支、工业页卡片过滤、
   战报/任务日志、星图打捞卡悬停、物品描述）。

   **经济对照（`tools/_rarebox-econ.ts` 真实引擎实测；数值方向待船长定）**：

   | 指标 | 实测 |
   |---|---|
   | 日供给（全清日板） | 外围 2.36 席×1 + 核心 1.93 席×2 + 深层 0.72 席×3 = **8.4 件/天**；＋ 敌对派系活跃 ≈1.4 件/天 → **≈9.8 件/天** |
   | 每箱专属命中 | 外围 25% / 核心 40% / 深层 55%（未命中必给一件主题件） |

**D 族基准（2026-09-10 船长定：「D 族是最强敌族，装备可对标异星档、可略强」）**：
D 族三件整体比同槽位制式 MK3 高半档，代价走 CPU（42/62/52）与**机动速度 −25%**——
装齐三件的守墓舰 = 打不动、追不上（守墓者本来也不追人）。

**E 族基准（2026-09-10 船长定：「略高于 MK3」；三件已逐件过审）**：巨构残骸炮从早期占位件
（1.9/5200ms = 只有 MK3 的 21% 输出）重定为**十秒一发的重锤**——船长指定装填拉到 10 秒并
**保住名义 DPS（= MK3 的 109.5%）**，故单发抬到 19.1；代价是**远端衰减 0.1**（越远越打不中，
射程带尽头几近失的）与基础命中 0.70（低于 MK3 的 0.78），CPU 反降到 **22**（结构简单）。
另两件补齐 E 族的"巨构"性格：**深层机库**（无人机舱 +95 m³ / CPU 50，全游戏最大机库）与
**巨构骨架**（**结构层容量 +60%** —— 引擎新能力 `hullHpBonus`，接上此前唯一没有容量模块的一层；
＋甲容 +30% / CPU 50）。三层总血对照（灰鲭鲨 裸 366）：装甲增厚板 MK3 435.6 ＜ **巨构骨架 455.1** ＜
陵寝装甲层 461.7 —— **E 略高于 MK3、仍低于 D**。
与 D 族守墓者长炮分工：**D = 12 km 必中点名炮**（单发 2.24 倍、总输出 MK3 的 90%），
**E = 9.6 km 爆炸换血锤**（单发 3.72 倍、总输出 MK3 的 109.5%、但命中与射程都不如 D）。

**G 族「烬火流亡」设定（2026-09-10 船长确认：照既有料确立）**：G 族是**被协会长期封锁、
打散后残存下来的流亡舰队**——三处活动星区各有其证据：**烬火星区**（围攻战事常年不断、
协会悬赏民间火力增援）、**回音荒区**（残舰群不断"复活"，被判定为残余自动化程序作祟 →
暗示他们握着**残余自动化产线**）、**天底**（"死胡同，也是流亡舰队最后的据点"，协会长年封锁）。
外形语言 = **蜂窝舱段 + 补丁帆**、集群感；族色 = **聚落紫 `#cd9fdd`**；窝点三档称呼 =
**残兵头目 / 聚落营地 / 藏匿地**（围攻 → 聚落 → 藏匿的生存姿态）。
他们靠**拼装废件**维持战力，主力手段 = **蜂群式无人机**（专属件「流亡蜂无人机」即"流亡者从残舰机库里
拼出来的侦查无人机"——他们连无人机都是自己攒的）。

**G 族基准（2026-09-10 船长定：三件全走无人机线 → G 族 = 无人机专族）**：
①**流亡蜂无人机**（专属侦察机，一次 ×10 架，见 §3 表）＋ ②导控（+45% / CPU 32）＋ ③中继（+65% / CPU 34）——
两个模块加起来只花 **66 点 CPU**（梭鱼级 320 里的一小部分），一套就把无人机流的
"**打得够重、够得着、还得起消耗**"补齐。数值口径 = **上限低于 D/E**（D 最强、E 略高于 MK3），
立身之本是**每点 CPU 更划算的拼装件**与**消耗得起**：导控每点 CPU 出 1.41 个点（MK3 是 0.89）、
中继每点出 1.91 个点（MK3 是 1.74）；无人机单发 6 却只占 5 点 CPU（战斗机赤鸢同单发要 7 点）。

**G 族第一件的改造（2026-09-10 船长：原「流亡蜂群巢」机库模块 → 专属无人机"物品"）**：
设计稿 `docs/design/g-exile-bee-drone-20260910.md`（状态：已确认）。要点：
①专属池从"只装模块"扩成**可混装模块与物品**（模块进装备库、无人机进物品仓库，一次 `RARE_BOX_DRONE_UNITS` = 10 架）；
②持有判定对无人机 = **物品仓库 + 各船机舱架数**（`equipment.ownedItemCount`）——手上还有就不重复掉，
**打光之后重新进池**（等于"再刷一次就能补回来"）；
③四型定位契约扩展：**锚点机型显式化**（`DRONE_ROLE_ANCHORS`）+ 专属强化型**豁免区间校验**（仍守硬边界），
阶梯只比锚点 → "专属强化型 + 制式型"同类共存合法，**四型定位本身不变**；
④回收明细账新增"无人机 N 架"（`recAcc.drone`）。

**「机动代价」（速度代价）机制（2026-09-10 新增）**：装甲容量件可带 `speedPenaltyPct`
（值域 (0, 0.9]），战斗速度 `speedMps` 乘 `1 − 该值`；**多件不叠加、只取最重一件**
（与推进器失稳 `hitPenalty` 同口径：重甲不会叠成静止）；只影响接敌/拉开距离的距离机动，
不改命中。仅影响战斗内速度，不涉跃迁与工厂循环。


**掉落规则（2026-09-10 船长定，乙案）**：**同族集齐前不重复**——开箱掷中专属装备时，
若该族池里还有玩家**当前未持有**的件（装备库 + 已装配位），就只从"未持有"里抽；
三件都到手后恢复均匀随机（允许重复）。判定不引入永久收集记录，零存档迁移。

**无消耗自愈的叠加（2026-09-10 船长定）**：同型多件的修复量按 **EVE 曲线收敛**
（权重 100%/87%/57%/28%/11%），不吃组件故必须收敛；抗性仍走既有**缺口复合**。

无蓝图、不上市场、不入常规掉落池；**B 族（武装拾荒者）随窝点取消**（原「拾荒者拆解臂」已撤下），
**F 族（制式巡逻）留空**（无窝点成员）。
