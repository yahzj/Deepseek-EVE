# 赏金任务 · 敌人窝点（2026-09-10 船长定稿）

> 状态：**已确认（结构）/ 数值待定**——结构、界面与掉落链路已按船长口径实现并通过验证；
> 文件顶部集中了一批**可调常量**（威胁系数、波次占比、僚机增量、酬金比例、稀有残骸件数、
> 高级箱命中率与矿物量、六件专属装备数值），等船长定数后只改常量。

## 0. 一句话

星图的「战斗悬赏」改名 **常驻悬赏**；任务中心新增第四个子页 **赏金任务**——限时派发的**临时战斗任务**，
目标是被按档位强化过的**敌人窝点**；打赢 → 窝点奖金 + 任务酬金入账，并在该星系留下**稀有残骸**
（打捞必得），回站精炼炉当**高级箱**开，可开出该敌族的**专属装备**。

## 1. 命名与位置

| 项 | 结论 |
|---|---|
| 常驻悬赏 | 原「战斗悬赏」全量改名（星图标签、面板标题、教程、重要任务、教程日志、聚光灯文本）。含义 = 星图上一直在、随时可打的 22 张悬赏卡 |
| 赏金任务 | 任务中心第四个页签（重要 / 资源 / 快递 / **赏金**），与资源/快递共用 20 分钟整点板 |
| 敌人窝点 | 赏金任务的目标本体：由该星系主题悬赏**派生**的高难加强卡；不入常驻悬赏列表、不入星图 |
| 三档称呼 | 按**敌族**定制，全部为"地点/头目"语义（船长词表定稿，见 §3），**不写"主城/本部"** 这类会把整族一锅端的说法 |

## 2. 周期与规则（船长口径）

- 与市场「补给刷新」同源：`orderLifeMs.common` = 20 分钟一轮，**整板替换**；每轮 **2 张**（候选不足按实际数）。
- 候选 = 已探索星系里「可作窝点（有核心词、非隐藏、奖金 > 0）且主题悬赏声望门槛 ≤ 当前声望」的卡；
  **同轮不重复星系**；赏金任务不触碰市场（无刷单影响）。
- 过期即作废，**无惩罚**；已刷出的档位、酬金、窝点名在**刷出时锁定**（面板剩余时间与资源/快递同源）。
- 必须**亲自出击**（AI 不能代劳）；与采矿互斥时走既有「转战」两步确认。
- 出击校验：非窝点目标拒绝；档位不得高于当前声望允许的上限（`startExpedition(..., { lairTier })`）。

## 3. 档位（声望决定上限）

| 档 | 声望 | 威胁系数 | 僚机 | 波次（威胁大头后置） | 酬金比例 | 稀有残骸 |
|---|---|---|---|---|---|---|
| 一档 外围 | 0~5 | ×1.3 | +0 | 沿用主题悬赏原波次 | ×0.5 | ×1 件 |
| 二档 核心 | 6~10 | ×1.6 | +1（上限 2） | 双波 0.35 / 0.65 | ×0.75 | ×2 件 |
| 三档 深层 | 11+ | ×2.0 | +1（上限 2） | 三波 0.2 / 0.3 / 0.5 | ×1.0 | ×3 件 |

- 窝点奖金 = 主题悬赏奖金 × 档位威胁系数（沿用既有浮动与技能系数）；**酬金跟强度走**（= 窝点奖金 × 比例）。
- 战报、奖金、残骸投放、失利维修费一律按**本场实际目标卡**（强化后）计，避免"打了窝点按主题悬赏报账"。

## 4. 战利品链路

1. **打赢窝点** → 该星系残骸场按敌群记账留下**稀有残骸 ×档位件数**（1/2/3 件，单件 30 m³）。
   - 稀有残骸只在**窝点**产出；常驻悬赏不产出。
   - 任务已过期也照常投放（打都打了，战利品不能吞）；任务仍在板上则同时结算酬金并下板。
   - 打输 / 撤退：任务留在板上可再来，**不投放**（窝点档位随本场作废）。
2. **打捞** → 该星系有存量时，打捞每轮**必捞一件**稀有残骸（捞完为止，之后回常规残骸池）。
3. **开箱** → 回站精炼炉「残骸回收」按**高级箱**处理：常规保底照有，**另必给**额外掉落：
   ①先掷该敌群**专属装备**（按回收档位命中率）→ ②未命中则给该敌群**主题追加件** → ③无论命中与否，
   再附一批**高阶矿物**（数量按档位）。每件稀有残骸只结算一次（由回收首批触发）。

## 5. 界面

- **任务中心 · 赏金任务**：卡片与资源/快递卡同族（`app-station-card`），含窝点名 + 档位徽标、
  目标星系、威胁（对比主题悬赏）、波数、窝点奖金、任务酬金、剩余时间、出发按钮（采矿中两步确认）。
- **星图 · 残骸打捞**：星系卡在「残骸密度」行末尾显示金色徽标 `稀有残骸 ×N`，悬浮显示按敌群的明细
  与开箱说明。
- **工业页 · 残骸回收卡**：稀有残骸卡名后带 `高级箱` 金色徽标，说明行点明"保底之外必定再给"。
- **上交战 / 远征状态**：目标名、威胁、胜率估算一律按强化后的窝点卡（`ExpeditionView.lairTier`）。
