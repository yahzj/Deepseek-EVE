# M1 设计文档：采矿 / 精炼 / 物品栏 / 钱包

## 目标

打通第二个玩法支柱——**资源生产经济闭环**：派船挖矿 → 矿石入舱 →
精炼成矿物或直接出售 → 换 ISK → 买更大的船 / 练更高技能 → 挖得更快。
同时让 M0 训练的技能（采矿技术、采矿护卫舰、精炼学、高级回收）真正生效。

## 玩法规则

### 采矿作业（core/src/mining.ts）

- 模型：**循环作业**。选一条矿带开始开采后，矿船按"循环时长"节奏反复采集；
  每完成一个循环，若货舱放得下整循环的产量则入舱，放不下则**货舱已满自动停采**。
- 在线：引擎每秒把流逝时间喂给作业；离线：读档时一次推进大段时间（同一套循环逻辑）。
- 单循环参数（技能加成后）：
  ```
  循环时长 = 船基础循环秒 × max(60%, 1 − 3% × 采矿护卫舰等级)
  循环产量 = floor(船基础产量 × (1 + 6% × 采矿技术等级))
  ```
  加成技能 id 与系数都在平衡配置（balance.ts），改技能 id/系数不动引擎。
- 富矿脉：每循环 1% 概率触发，该循环产量翻倍，写日志；判定走种子随机（可复现）。
- 日志克制：只在 开始/停止/货舱满/富矿脉 时写，日常采集不刷屏。

### 矿带与物品（data：belts.ts / items.ts）

| 矿带 | 矿石 | 收购价(ISK/单位) | 精炼配方(100%收率) |
|---|---|---|---|
| 丰饶之环 | 富凡晶石 | 12 | 三钛×2、类银×0.6 |
| 灼烧裂隙 | 灼烧岩 | 18 | 类银×1.6、类晶体×0.5 |
| 深空晶体带 | 克洛基石 | 30 | 类晶体×1.2、超噬×0.15 |
| 红环危机带 | 希莫非特 | 55 | 超噬×0.45、三钛×1.5 |

矿物：三钛合金 8 / 类银超金属 12 / 类晶体胶体 20 / 超噬矿 90（ISK/单位，0.01 m³/单位）。
矿石 1 m³/单位。**精炼的意义：价值密度提升 + 体积骤减**（100 m³ 矿石 → 约 2 m³ 矿物）。

### 精炼（core/src/industry.ts）

```
收率 = min(95%, 50% + 8% × 精炼学等级 + 4% × 高级回收等级)
产物单位 = floor(矿石数 × 配方系数 × 收率)     // 每行配方独立折算
```

低技能（50%）时精炼价值 < 直接卖原矿 → **两种流派**：懒人卖矿攒船 /
练精炼学后再炼矿卖（单单位价值约高 1.9 倍）。故意的数值决策点。

### 市场与买船

- 卖出：任何物品按牌价全量卖给空间站（ISK 直接入钱包）。
- 舰船线（data：ships.ts）：

| 船 | 货舱 | 循环 | 产量/循环 | 价格 | 约效率(对沙猫) |
|---|---|---|---|---|---|
| 沙猫级 | 800 m³ | 12 秒 | 10 | 初始自带 | 1× |
| 掘洞级 | 1800 m³ | 11 秒 | 18 | 12 万 | ~2× |
| 鲸吞级 | 4500 m³ | 10 秒 | 34 | 90 万 | ~3.6× |

- 初始资金 10,000 ISK；新手船约 33 分钟挖满一趟（≈9,600 ISK/趟）。

### 离线结算（v2 版）

- 结算上限仍 8 小时；采矿若在进行，按循环批量结算（货舱满则停在离线期间）。
- 摘要日志格式：`离线结算完成：推进 X；离线采集 富凡晶石×800，期间发生 N 条事件。`
- 事件计数 = 结算期间实际新增日志数（不得为负——曾出现 -1 的 bug，已修并有回归测试）。

## 验收清单（M1）

- [ ] 选矿带 → 开始开采 → 货舱数字每秒增长，循环进度条走动
- [ ] 货舱满自动停止并警告；手动停止记录"本趟采得 X 单位"
- [ ] 精炼 100 单位富凡晶石：0 级精炼学得 100 三钛+25 类银；5 级得 180+45
- [ ] 矿物体积 0.01 m³/单位，精炼后货舱腾出大量空间
- [ ] 卖原矿/卖矿物 ISK 即时入账；顶栏余额变化
- [ ] 12 万 ISK 能买掘洞级并立刻生效（货舱/循环/产量变大）
- [ ] 采矿技术升到 2 级后产量即时 +12%（无需重开矿）
- [ ] 关闭游戏 20 分钟：回来日志有"离线采集 …×N"，货舱多了矿
- [ ] v1 老档（M0 存档）打开后正常游玩，钱包 1 万、沙猫级、原技能保留

## 测试覆盖（自动，50 项含 M0）

- 采矿：开始/停止/非法指令、循环结算精确性（半循环进度）、两种技能加成、
  货舱满自动停、富矿脉随机消耗计数、技能中途升级即时生效、引擎不硬编码技能 id
- 经济：收率公式边界（0/5 级/上限 95%）、精炼产物折算、矿物与空仓拒绝、
  卖出入账、买船（钱不够/成功/重复/免费船拒绝）
- 迁移：v0→v2 全链、v1→v2 无损、坏档三类报错、字段容错
- 离线：采矿摘要文本、事件计数不为负（回归）、时钟回拨

## 非目标（明确不做）

- 不做海盗/危险（矿带无威胁）——留给 M3 远征；
- 不做市场价波动与玩家交易——在线化阶段再说；
- 矿物暂不能用于制造（M2 蓝图链接入）。
