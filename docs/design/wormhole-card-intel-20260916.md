## 二、落码（改了什么）

- **core 单点**（`packages/core/src/wormholeFoes.ts`）：
  - `WORMHOLE_FAMILY_ETHNIC`：族称（**海盗 / 异形 / 守墓 / 巨构 / 亡军**）；
  - `DAMAGE_TYPE_LABELS`：伤害中文名（**动能 / 高爆 / 能量**，与战斗界面 `DMG_LABEL` 同一套叫法）；
  - `WORMHOLE_TIER_LABELS`：三档中文名（浅层 / 中层 / 深层）；
  - **`wormholeFamilyIntel(family, ctx)`**：返回族称 + **浅层卡名** + **主系一句话** + **三档「卡名 + 火力构成」**
    （构成取 `foeDamageComposition` ⇒ 与战斗结算、胜率预估同源）。主系规则：单系 ⇒「纯高爆」·
    头名 ≥ 75% ⇒「动能为主」· 否则 ⇒「动能 / 高爆并重」。
- **engine**（`game/engine.ts`）：`wormholeFamilyIntel(family)`——与 `wormholeFamilyName` 同一把尺，
  **必须走 `ctx.anomalies` 全表**（五张洞内卡都 `hidden`，用过滤后的目录会漏出内部 id，2026-09-14 踩过）。
- **渲染层**：
  - 新增 `ui/wormholeIntel.ts`（**扫描页与准备页共用**）：`wormholeIntelLine`（卡片那一句）· `wormholeIntelTip`（悬停多行）；
  - `panels/WormholeScan.tsx`：卡片**新增第三行**「敌：劫掠支队（A 族 · 海盗）· 动能为主」，
    悬停换成完整口径（三档构成 + 内容原型说明）。`.app-inv-main` 是纵向 flex ⇒ 自然换行、**零样式改动**；
  - `panels/Wormhole.tsx` 准备页：横幅说明上方加同一行（只有"这一处是哪一处"已知时才显示，
    即从库存进来、`stockId`/`autoStockId` 有值；从星图入口直接开面板则不显示——**不猜、不编**）。
- **不改**：任何数值/概率/存档字段；卡片按钮与布局骨架；悬赏卡那套；**不给"建议抗性"**（船长明确不要）。
