1. 「高安路线的收益率是0.5，中安是0.75，低安是1，这样如何？」

## 二、长途运输报酬：安全档收益率 + 距离指数

**公式**：单段报酬 = 货仓 × `HAUL_RATE_PER_M3_MIN`(0.6) × **锚定标称分钟**(10) ×
( **有效距离** ÷ **锚定有效距离**(7.75) )^**1.5** × 本趟行情倍率(5~10)。

- **有效距离** = 沿引擎选定的最短路**逐跳**累加「该跳分钟 × 该跳系数」；
  **每跳系数 = 该跳两端里「安全等级较低（更危险）」那一端的系数**（高安 0.5 / 中安 0.75 / 低安 1；
  档位判定走 `securityZoneOf` 单点，低安 = sec ≤ 0 含 0）。
- **等价写法**：旧式「货仓 × 0.6 × 本段标称分钟 × 形状因子 G」其中 G = (D/D锚)^p × (标称锚/标称)
  ⇒ **标称分钟被锚定常数吸收**，**单段总报酬只取决有效距离**（航程时间不进报酬）。
- **航程时间一字未动**（仍标称 ×15）；**存档零迁移**（全部静态推导）。
- **锚定航线 = 母港 ⇄ 烬火前哨站**（标称 10′、有效距离 7.75 = 3×0.5 + 3×0.75 + 4×1.0）。

**读数（皇带鱼级旗舰货舰 36,000 m³ · 行情均值 ×7.5 · 面板不显示档位与系数——船长定）**

| 航线 | 有效距离 | 有效距离/标称 | 时薪（改前 → 改后） | 变化 |
|---|---|---|---|---|
| 母港 ⇄ 烬火前哨站 | 7.75 | 0.775 | 648,000 → **648,000** | **锚，逐字不变** |
| 母港 ⇄ 红环前哨站 | 4.5 | 0.643 | 648,000 → **409,600** | **−37%** |
| 红环前哨站 ⇄ 烬火前哨站 | 3.0 | 1.000 | 648,000 → **520,200** | −20% |

**超可加（1+1<2）**：把母港⇄烬火拆成「母港⇄红环 ＋ 红环⇄烬火」两段跑，只值整段的
**68%**（拆两段的和 ÷ 整段 = (4.5^1.5 + 3^1.5) / 7.75^1.5）；线性旧口径下是 **97%**（几乎不亏，
且低安短线是全表最赚）——这正是要改掉的形态。

## 三、遇袭后自动维修（先修后判）

**收场顺序**（击退 / 受损 / 被抢 / 自动脱离 / 应战胜负**五路共用** `settleEncounterTail`）：

1. **先修**：装甲**或**结构 < 50% ⇒ 就地用**修理组件**补到两者 ≥ `encounter.repairTargetFrac`(0.6)
   或**组件耗尽**（与重复清剿同口径的触发线/目标值）；两项都 ≥50% ⇒ 一枚不动。
   - **来源**：**货舱优先 → 仓库兜底**（船长「用组件，包括仓库组件」；与战斗预载同序）；
     **取件序**：民用 → 军用 → 其它带回复值的组件（与手动使用同口径）。
2. **再判返港**：**组件耗尽** 或 **补完后结构仍 < 50%**（`encounter.retreatHullFrac`）⇒ 收手返港待命
   （主控：停低安作业 + 即时返航最近已建成站；副船：中止 AI 任务召回）。**不自动再派**（不变）。

**⚠ 旧口径作废**：2026-09-11 的「**不自动维修**」与「结构 <50% **一律**撤退」两条由船长 2026-09-12 改判
⇒ 现在**只要组件够，被伏击的船不再自动撤退**（修好继续干活），返港降级为"修不动 / 修不好"时的保命档。

**覆盖主控 + AI 副船**（`repairWithKitsFor` 逐船单点）；副船既有的「本场失利且耐久 ≤30% → 回港花 ISK 修满」
**保留为兜底**。**重复清剿的自动修补口径一字未改**（只读货舱、不碰仓库）。

## 四、连带确认：长途运输途中会遇袭（保留，只改文案）

实测（真引擎）：`hauling.setLeg` 每段把 `awayGalaxy` 记为**出发星系**，而 `encounters.collectExposures`
的排除清单只排了采矿/远征/打捞/扫描 ⇒ **出发港在低安（烬火星区 sec 0.0）的运输航段**会被计为
「出发星系的驻留暴露」并掷伏击（5 游戏日实测 8 条遭遇、装甲掉到 94%；对照「停在烬火港里不跑运输」= 0 条）。

船长裁定**保留该行为**（「打算让长途运输会遇袭」）⇒ 只改玩家可见文案，**不动暴露面**：
手册「什么会遇袭」、手册「打捞残骸」、通讯 `msg-lowsec-rules`、首次入低安运行时提示四处已同步
（「航行途中不会」→ 明确「**长途运输途中同样会**」；移动段不暴露仍是通则）。
