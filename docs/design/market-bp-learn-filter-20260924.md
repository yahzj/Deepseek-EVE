# 工作文档 · 市场「蓝图」二级筛选：加入「未学会」（2026-09-24 · 三号）

> **状态：进行中**（已落码并过闸门，待船长验收观感）
> **船长原话（照抄）**：「**市场蓝图筛选的子筛选里，加入一个未学习蓝图的子筛选。**」

## 一、做了什么

- **市场页**：类型选「蓝图」后的**二级下拉**在原九档（高/中/低槽装备蓝图 · T1~T5 舰船蓝图 · 消耗品蓝图 · 零件蓝图）
  之后，新增**两档**：**已学会** · **未学会**（复用组装机那一行 `BLUEPRINT_LEARN_TABS` 的**同一套键与同一套文案 id** `ui.itemSubs.031/032`
  ⇒ 中英双语现成，不新造词条）。
- **船长只点名「未学会」一档，为什么补了「已学会」**：与组装机那一行**对称**（那边是"全部 / 已学会 / 未学会"），
  且筛完未学会的人下一个动作通常就是回看"我学过哪些"。**若只要一档，说一句我删掉「已学会」**（一处删除，零连带）。

## 二、判定口径（与组装机同一把尺）

`subPasses(ctx, good, 'blueprint', sub, state)`（`ui/itemSubs.ts`，市场与组装机共用的判定入口）：

| 档 | 判据 |
| --- | --- |
| **已学会** | `ownsBlueprint(state, refId)`（core 单点，读 `state.learnedRecipes`） |
| **未学会** | **永久图纸**且尚未学会 ⇒ `!ownsBlueprint && !singleUse` |

⚠ **一次性图纸不进「未学会」**：它按定义「不上市场、不能学、只能造一次」（`BlueprintDef.singleUse`），
放进去就是一张**永远学不会**的清单（组装机那边也是这么排除的：`!it.learnless && !ownsBlueprint(...)`）。

## 三、两个实现取舍（防后人重踩）

1. **另起一张市场专用表 `MARKET_BLUEPRINT_SUBS`，没有直接往 `BLUEPRINT_SUBS` 里加**：
   后者**同时是手册「蓝图图鉴」的分组顺序表**（`Handbook.orderOf('blueprints')`），而 `groupCells` 对
   "顺序表里有、但没卡片"的键**会原样留下一组** ⇒ 直接加会让图鉴多出两个空组标题。现市场读新表、图鉴照旧读原表。
2. **「学没学会」两档在下拉里常显**（不走"本档没商品就隐藏"那条既有尺）：它按**玩家存档**实时判定、不是内容分类，
   否则"一张都还没学会"的玩家看不到「已学会」这一档。
   另：下拉选中后的结果栏标题改走 `subText(...)`（原先直接读 `label`，英文界面下会漏中文）。

## 四、实测读数（一次性探针，**用完即删**）

真内容目录 ＋ 真引擎（`buildSimContext('zh')` ＋ `createInitialState()`），调**市场同一个判定入口**：

- 市场蓝图行 **200** 条 = 永久 **167** ＋ 一次性 **33**；
- 「**未学会**」命中 **167** 条（**正好等于永久图纸数** ⇒ 33 张一次性一张都没漏进来）；「**已学会**」命中 **0** 条（新档未学任何蓝图）；
- **反向验证**：拿一张永久图纸（`bp-pd-e`）——学之前 `未学会=true / 已学会=false`，`learnedRecipes` 里推入后
  `未学会=false / 已学会=true`，与 `ownsBlueprint` 复核一致；
- **边界**：一次性图纸两档都不命中；不传 `state`（老调用方）两档恒不命中（宁可不筛也不猜）；
- **既有档零漂移**（同一次跑）：高 47 · 中 37 · 低 42 · 消耗品 11 · 零件 7。
