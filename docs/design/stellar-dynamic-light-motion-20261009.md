# 星系天体动态光照与运动

> 状态：单星岩质/海洋试作已实现并自检，待船长审查，一号main，2026-10-09。
> 船长反馈：「图片光照来源不是恒星，而是固定左上角，这似乎是硬伤，可能不能使用固定png，而且行星不会自转和公转」。
> 批准：船长答「可以」，确认先做单星岩质/海洋动态试作，展示速度按本方案；先交审，不自动扩展全部类型或推送。

## 事实与责任

当前PixelPlanets导出固定光源坐标0.25/0.25、冻结时间0.17，PNG保存了已着色结果。星图的恒星照明只作用于场景，不能重算PNG本体的昼夜面；表面与公转均静止。上一方案明确首轮静态，但面向恒星的光照一致性没有解决，此为实现限制，不以静态审批回避反馈。

原生shader暴露light_origin/time/rotation，光源用于表面着色，time用于纹理推进。直接旋转整张PNG会把烘焙阴影/星环轴一起旋转，不等同表面自转；GIF或单维自转精灵图也仍有固定光源。预导出每类多光向×多旋转相位会增加资源和跳帧，且难表现双星，不作为推荐路径。

## 推荐方案

二维WebGL实时天体着色，移植已核验且保留MIT许可的PixelPlanets算法，分离球面法线、地表/云层纹理、自转相位与光源方向；不写第二套探索规则、不引入Godot运行依赖、不调用外部服务。以像素球体呈现，不转成三维场景，不引入Three.js或新的大渲染框架。需要明确批准将星系天体图形例外扩至实时二维shader；未批准前不改当前渲染。

- 单星：光线由当前显示的恒星与行星位置计算，亮面朝向恒星，自转只推进表面/云层，昼夜方向不随自转一起旋转。
- 双星：两颗恒星各有光向，叠加明暗与色温；现有数据没有真实恒星光度/质量，不伪装精确天文辐射，用公开类型的有限示意权重并登记规则。
- 黑洞：本体不当太阳，若表现吸积盘照明只作克制示意；流浪星系用弱环境光，不凭空增加中心光源。所有类型均保留可辨夜侧。
- 自转：建议本体一圈约40秒，云层允许与地表不同速度；星环轴不随地表旋转。七类公开类型各自复用相应算法、固定种子与已审颜色，地图和详情共用光照/相位。
- 公转：建议内圈约180秒、外圈约480秒，按公开轨道顺序平滑过渡，不假称真实天文周期。以原坐标角度作初相位，原轨道半径和存档坐标不改，双星围绕现有轨道中心，流浪天体不伪造围绕恒星的公转。
- 运动只是表现，不改游戏工期、航路、探索随机序列、危险/宜居或资源。会话内时间连续，暂停/后台/关闭期间不推进，不按离线游戏时间补转，不新增存档字段。
- 地表进入/返回和切换星系保留相位会话；同一个天体的画面位置、选中环、状态标记、标签、悬停与命中读取同一显示坐标。按下/拖动/悬停目标或键盘操作时暂缓公转，防止点击目标移动；当前选择ID不随运动更换。
- 加明确暂停/继续控件；系统减少动态默认静止公转和自转，但保持正确恒星方向照明；窗口不可见时停止绘制，首轮目标30帧/秒、静态背景独立缓存，不能每帧重渲整棵React树。
- WebGL不可用/上下文丢失时明确回退静态模式，旧PNG只作兼容兜底，不冒称光照/运动正确；降级策略在试作中核验后交审。

## 验证与范围

先做单星＋一个岩质/海洋天体的动态光照和运动试作，通过昼夜向量、表面移动/阴影不随转、同帧点击坐标、暂停/减少动态、手机深浅主题与上下文丢失检查后，交船长看效果；再扩七类与双星/黑洞。只星系表现域，地表开发和旧宇宙星图不重做，不推送未经审查的试作。

技能依据：ui-ux-pro-max的ux域「continuous animation pause reduced motion」命中Reduced Motion、Continuous Animation及Excessive Motion，提醒持续动画需克制和减少动态。天体运动承担空间状态展示，不机械套成加载动画；有条件支持，以慢速/暂停/操作期间稳定/不可见停画作为护栏。review-animations的Justified motion、GPU-only、Accessibility用于动态方案审查，不将持续场景运动误套菜单300ms入场预算。当前没有具体动画改动，因此不出虚构代码审查结论。

与旧静态方案的变更：新增实时光照、表面自转、显示公转、暂停和运动坐标同步；取消PNG作为正常路径的最终着色本体，不变更原核心数据。以上方向和建议时间须船长确认后实现。

## 试作实施与边界

- 当前仅`single`星系中的`rocky`/`ocean`使用实时着色和公转；其他类型/星系保持原静态路径，双星/黑洞与七类扩展尚未实施，不将范围预批准当作试作验收。
- `stellarPlanetShader.ts`复用PixelPlanets的周期随机噪声、三次插值与fbm，MIT版权许可随原本地资产分发。球面改经纬度纹理/法线向量，移除原light_origin参与地表噪声的耦合；不是原Godot shader逐字输出，不宣称两者图案完全一致。地表40秒、云层50秒相位分别推进，光照只从显示恒星/行星坐标取向，夜侧保留14%环境亮度。
- `stellarMotion`集中会话相位、公转显示坐标和光向；原世界坐标初相位不写回，按内外轨道顺序180~480秒展示周期，自转/公转不会加速探索工期，不增加存档字段、不消费探索随机数。
- `StellarMotionLayer`单个离屏WebGL画布顺序画动态天体，2D合成层只覆盖天体，不每帧重画背景；30帧目标下同拍推进/绘制/同步SVG本体、标记、标签与命中，原手势和定位取显示坐标，React只负责结构/控制状态。详情另一个WebGL画布订阅同相位，暂停/悬停/按下/键盘/确认/减少动态冻结，切星系/地表/关闭保留会话但不补离线时间，页面不可见停画。
- 显卡不可用或上下文丢失回退原PNG静态模式，警示图标和详情悬停使用`ui.stellarMotion.001`，只中文登记待译；恢复后重新编译renderer，继续使用原会话。未新装依赖、未引入Godot/图片服务/三维引擎。
