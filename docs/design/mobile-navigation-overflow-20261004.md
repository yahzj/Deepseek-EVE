# 手机导航栏溢出与遮挡修复

> 状态：已确认，已实现，自测通过，待合入验收（三号 · verify · 2026-10-04）
> 船长：「旧版界面左侧导航栏太窄了，多余的导航栏选项被挤出屏幕；导航栏出现滚动条但是无法拖动；新版界面下左侧导航栏被中间主窗口遮掩」。

## 修复

- 旧版手机导航宽度从80px调为120px，保证中文标签有可用宽度。
- 旧版外层导航关闭滚动，内部 `.app-classic-nav-scroll` 成为唯一纵向滚动容器，加入稳定滚动条留位和触摸纵向滚动，避免双层滚动条争抢手势。
- 新版手机左列从100px调为156px，与150px活动栏及间距匹配，防止活动栏伸入主区后被主窗口遮住。
- 桌面导航、手机横屏旋转逻辑、导航顺序与折叠偏好不变；同步生成 modern/classic 两份样式。

## 验证

- `classic-sidebars-20261004` 与 `mobile-viewport-20261004`：19条通过。
- `ui:layout-css:check`、`ui:rot-check`、四包typecheck通过。
- 已知限制：本轮未做浏览器截图观感验收；已有本地预览服务仍返回200，待船长在手机端实际滑动确认。
