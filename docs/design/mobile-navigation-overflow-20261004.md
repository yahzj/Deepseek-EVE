# 手机导航栏溢出与遮挡修复

> 状态：已确认，已回滚手机专用导航样式，自测中（三号 · verify · 2026-10-04）
> 船长：「旧版界面左侧导航栏太窄了，多余的导航栏选项被挤出屏幕；导航栏出现滚动条但是无法拖动；新版界面下左侧导航栏被中间主窗口遮掩」。

## 修复

- 移除旧版和新版的手机专用导航宽度、字号、图标和滚动覆写，恢复两套与网页版相同的导航规则样式。
- 手机仍保留整体旋转、视口和页面内容适配；导航不再因为手机模式被压成另一套布局。
- 桌面导航、导航顺序与折叠偏好不变；同步生成 modern/classic 两份样式。

## 验证

- `classic-sidebars-20261004` 与 `mobile-viewport-20261004`：19条通过，新增断言确认手机不再套窄版导航选择器。
- `ui:layout-css:check`、`ui:rot-check`、四包typecheck通过。
- 已知限制：本轮未做浏览器截图观感验收；已有本地预览服务仍返回200，待船长在手机端确认网页版导航在物理窄屏上的整体可达性。
