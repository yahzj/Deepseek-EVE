# 敌舰单位显示名（舰种名 × 规格词缀）

> 2026-09-09 船长拍板（聊天确认）；经办：大鲸鱼二号。状态：已确认·已实现（待合入验收）。

## 一、背景与问题

- 战斗界面敌舰名字此前两套并存：舰体上方行名 = "舰种名"（战术 × 血型 9 类，主舰本名 / 僚机「舰种名·僚机」，
  由界面层 battleViewCore 查表拼装）；血条小字 = 引擎单位名 = **悬赏名**（主舰）/ 悬赏名·僚机——既不一致，
  又把"悬赏/敌群名"当单位名用。
- 船长要求：同一悬赏内属性/规格不同的敌舰，名字必须不同。
- 现场澄清：穹顶墓园（穹顶守卫 2+2+1）波间单舰血档差仅 ≈14%（0.857 比值）——船长确认系看错，**不属于
  "不同属性"，不得加词**；灰霾带（escorts:1 = 1 主 + 1 僚两艘）同批疑误报，确认**不改卡面**。

## 二、定稿规则（船长拍板：舰种名 + 轻装/精锐词缀）

1. **名字单一来源**：舰种名表（9 类）与主/僚判定移入 core（combat.ts）；引擎 `createFoeSpecs` 建档即按
   `foeUnitNameOf(anomaly, tag)` 生成最终显示名（随 battle.units.name 透传）；战斗界面舰顶行名、血条小字、
   敌武器组名全部同源。悬赏/敌群名只用于卡面、来袭广播与日志（叙事位），不再充当单位名。
2. **词缀（前缀）**：`轻装` + 舰种名，判定 = 单舰规格 ≤ 本场最强档 × FOE_LIGHT_FRAC（0.6）：
   - 僚机（legacy `foe-N`(N≥1) 或 `*-e{i}`，份额 ×0.6）→ 轻装（替代旧「·僚机」字样与「悬赏名·僚机」）；
   - 主舰但所在波血档 hpShare ≤ 同卡最强波 ×0.6（如未来配 0.4 vs 1.0 的低血波）→ 轻装；
   - 波间差异不明显（比值 >0.6，如穹顶 0.857）→ 不加词；
   - 「精锐」档**预留**：词表/渲染无需改动，相对规格 >1 的头目单位出现时在 `foeUnitNameOf` 加分支即可。
3. **主/僚判定**（core `foeMainTagOf`，与渲染体量判定共用）：`foe-0` / `w{n}-foe-{k}` = 主；
   legacy `foe-N`(N≥1)、`*-e{i}` = 僚。
4. **旧档兼容**：存档 unit.name 字符串不再直接参与显示——界面一律按"异常 + 单位 tag"经
   `foeUnitNameOf` 实时推导（读档中断局自动显示新名）；字段零迁移。

## 三、实施

- core/combat.ts：FOE_CLASS/foeClassName/foeMainTagOf/foeUnitNameOf + FOE_LIGHT_WORD（词缀常量）、
  createFoeSpecs 建档命名改接；core/index.ts 导出。
- 界面：battleViewCore 删本地表（回退 core）；BattleScreen 行名/僵尸名/血条小字改 `foeNameOf(tag)`
  （异常缺失回退档内名），主/僚判定引用 core。
- 回归：tests/foe-naming.test.ts 5 组（单波本名、僚机轻装、低血波轻装、穹顶型不加词、多小队×escorts
  逐波展开、建档透传一致）。
