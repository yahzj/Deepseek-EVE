# 护盾充能力场装置：回盾量改按「装件舰（施放者）满盾」（2026-09-25）

状态：**进行中** —— 改动已落码，四闸门 ＋ `l10n` 待跑完；归档按 AGENTS.md §8
（船长验收后当批做：关键内容并入 `docs/glossary.md` 该词条 ＋ roadmap 一条 → 删本文件 → 重跑 `docs:index`）。

## 船长原话（照抄）

- 报障：「**护盾充能力场的文案描述有歧义，容易让玩家以为恢复量是根据每艘船变化的，而不是固定使用的船的护盾量**」
- 改判确认：「**原本设想的就是乙啊，说明之前的文案歧义确实大**」（乙 = 改机制 ＋ 改文案）
- 文案口径（Q1）：「**为队内所有舰船恢复护盾，恢复量为本舰护盾量的10%。**」
- Q2（多舰各带一件要不要加收敛）/ Q3（发不发公告）/ Q4（CPU 透支那条待办）：**一律「不管」**。

## 根因

2026-09-20 追问三答之三记作「10% 按**携带者自己的满盾**」，同句括号里被补注成
「（即每艘被治疗舰按它自己那本账算）」——**「携带者」= 装件舰还是受益舰**这句歧义没有当场澄清，
于是实现（`combat.pulseShieldFieldFor`）与 5 处文案一起按"每艘受益舰各按自身满盾"落地，
并被记进词典与封存卷。船长 2026-09-25 澄清：**原本设想就是按装件舰（使用船）的护盾量**。

⚠ **为什么一直没被发现**：`tests/shield-field.test.ts` 的测试世界里两艘都是同一船型
（护盾驳船 1000 对 1000）⇒ 新旧口径数值完全相同，**旧口径下没有任何用例能分辨**。

## 新口径（现行）

- **每跳给全队回的护盾量 = 施放者（装力场那艘船）满盾 × 该路比例**，全队**存活**单位拿**同一个绝对量**；
- 每人仍**夹在自己满盾内**（超出部分丢弃 —— 小盾舰会被旗舰级的一跳直接顶满并溢出）；
- **逐路**（MK2 一路 10 秒 / MK3 一路 8 秒）各按**各自施放者**的满盾算 —— 多舰各带一件时**各按自己满盾各跳一路**，
  全队叠加（Q2「不管」⇒ 不加收敛，沿用 2026-09-20「多舰各带一件 ⇒ 各自独立、可叠加」）。

## 边界（沿用不动）

施放者阵亡 ⇒ 本跳不跳 · 死亡单位不回盾 · 按**满盾**不按当前盾 · 仍能从 0 盾点起来 ·
同舰多件仍走 EVE 曲线 `stackWeight` 收敛 · 冷却仍 MK2 10 秒 / MK3 8 秒 · 不动 CPU（63 / 91）· 不动价格与稀有度。

## 数值影响（实测例，供船长手感参考）

| 场景 | 旧口径 | 新口径 |
| --- | --- | --- |
| 装件舰 = 邓氏鱼级旗舰（满盾 1248），僚舰 = 甲壳截击舰（满盾 30） | 装件舰 +125 · 僚舰 **+3** | 两舰**各 +125**（僚舰顶满并溢出 95） |
| 装件舰 = 小盾舰 | 大盾舰按自己满盾拿 | 大盾舰只拿小船满盾的比例 ⇒ 收益缩水 |
