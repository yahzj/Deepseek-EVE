# 顶栏声望容器改「当前余额」＋门槛提示改称「累计」（状态：进行中 · 2026-09-30 船长令）

> **船长原话（照抄）**：「**游戏窗口顶部的'声望·累计获得'需要修改，直接显示玩家当前XX声望。**」
>
> **范围**：顶栏那枚声望容器（两套外壳共用的 `standingChip`）＋ 所有把「累计获得」那本账称作
> 「当前」的门槛提示文案。**不碰**引擎口径：门槛照旧一律读**累计**（2026-09-26 令），兑换照旧只扣**可支配**。

## 1. 船长裁定（2026-09-30 · 集中提问后一次选定）

1. **顶栏数值** = **可支配**（当前余额；花掉会减）——与钱包并列，都是"手上能花的"；
2. **标签** = 只写「**声望**」（不再写「·累计获得」）；
3. **门槛提示**里那批「（当前 N）」**跟着改称「（累计 N）」**——否则"当前"一词会同时指两个数
   （顶上花掉会减、提示里不减）。

## 2. 两本账（查实记录，改前现状）

- `standingOf()` = **累计获得**（`state.standingsEarned`，只增不减）⇒ **全仓 40 余处门槛读它**（2026-09-26 令）。
- `spendableStandingOf()` = **可支配**（`state.standings`，只有章鱼人兑换扣它）。
- 改前顶栏读的是**累计**那本，标签写「声望·累计获得」，悬停写「累计获得：N」；
  **可支配**只在声望商店标题行（`ui.IndustryPage.119`「可支配 X · 累计获得 Y」）与兑换卡上出现。
