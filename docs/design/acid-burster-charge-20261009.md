# 酸液爆虫冲锋倍率下调

> 状态：已实现，自测完成，待船长验收/发布，一号main，2026-10-09。
> 船长原话：「酸液爆虫冲锋倍率调低，现在3500速度有些过快。」
> 批准：船长答「好的」，确认专属冲锋倍率改为2.5，其他效果不变。

## 核对结果

爆虫基础速度714m/s；专属挂件`foe-mount-c-acid-charge`的`charge_mul`为5，实战逐单位冲锋后为3570m/s。通过当前内容上下文和真实`createFoeSpecs`读取入侵先锋编队，五架爆虫均为此值。整队显示按存活单位速度平均，不是爆虫倍率外溢到其他舰。

## 推荐调整

- 专属冲锋倍率5→2.5，基础714不变，冲锋时1785m/s，原值减半。
- 只影响酸液爆虫；该专属挂件仅爆虫本体引用。不改通用C族冲锋档位、背巢巨兽或巢母。
- 保持10秒冷却、触发/解除条件、冲锋免网、自爆250米/近距死亡300米、伤害/破盾/腐蚀、血量、闪避、数量及奖励不变。
- 实施时修改核心静态挂件参数与数据侧入侵倍率契约基准，补实际速度与其他舰不变专项；不回改历史公告，不新写英文，不推送。

## 验证

确认后沿战斗域同类冲锋专项，核验真实开战/步进的速度、冷却与近距自爆不变，内容/类型/正常提交门禁及双端构建；全量核心回归留集中验收/发布。

实施只修改专属挂件静态倍率和入侵倍率契约基准，不回改历史公告或其他历史设计表。

## 实施与结果

- 核心静态挂件`foe-mount-c-acid-charge.charge_mul`与数据侧入侵倍率契约均改为2.5。其他挂件参数逐字段对照基线保持一致，基础速度714不变。
- 新增4项真实规格/步进专项：四张入侵卡均读取2.5倍率与1785冲锋速度；实际冷却回714、到期恢复冲锋、近距主动自爆保持；破盾乘区/腐蚀/爆发距离/命中率均保持。
- 自爆基础300会按敌卡配置放大，新用例保留同卡对照，不能将所有派生伤害强行断言300；未修改伤害配置。
- 六文件124项专项通过，四包类型、内容检查、经济平衡检查、桌面/网页最新构建通过。经济工具不含远征，不据此宣称战斗胜率已校准；完整core仍留集中验收/发布前。
- 仅战斗域，同类参照为既有逐单位冲锋挂件与冲锋专项；无跨域业务修改，无玩家档读取/写入、无新增依赖/英文、无推送。
