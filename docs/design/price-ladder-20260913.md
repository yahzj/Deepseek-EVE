   蝠鲼 30.34M · **皇带鱼 288.53M**（料/价 0.449~0.451）。

## §7 已知取舍与遗留（留档）

1. **渠道与价位脱节（待船长裁）**：玳瑁 / 旗鱼 / 座头鲸 / 蝠鲼 仍是 `rare`（稀有订单层）渠道，
   而它们现在的价位已与同档奇货同级 ⇒ **出率/寿命仍是"便宜货"的**（奇货渠道是 0.8%/10 分钟窗
   独立掷骰、寿命 6h；稀有渠道是每窗加权抽取）。要不要把这几行升到奇货渠道，等一句话。
2. **只收不卖四艘**（开拓 / 鲸王 / 皇带鱼 / 巨齿鲨）的**二手挂售价**随行价一起变（NPC 收购档 1.0L）。
3. **维修费档位**读 `priceIsk`（四档 ×0.4/×0.7/×1.0/×1.4）：本轮**三艘跨档**——玳瑁 1.0→**1.4**
   （修船 +40%）、旗鱼 0.7→**1.4**（+100%）、座头鲸 1.0→**1.4**（+40%）；剑鱼/蝠鲼/玄武**本就在
   1.4 档**（不变）；鲸王与皇带鱼是定制船（`priceIsk` 恒 0、走「甲+结构」归档）不受影响。
4. **T5 战斗旗舰（邓氏鱼）**口径 1B 已留档，仍待"是否定案上架"的裁定。
5. **声望上限 53**：门槛 40 的余量只有 13 点；若日后新增更高门槛（>45），需要同时加声望来源。
