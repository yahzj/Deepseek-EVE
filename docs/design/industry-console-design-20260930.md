## 一、新前提（本设计要承载的东西）

实验室不再是"一张燃料配方卡"，而是**消耗品总产线**：

| 类别 | 现在 | 后续 |
|---|---|---|
| **燃料** | 标准配方（600 单位/批 · 5 分钟 · 虚空晶 6/批） | **多配方并行存在，效率不同**（如「高浓配方」效率 160%：960 单位/批、虚空晶 14/批、曲率凝析物 ×3） |
| **战斗增益剂** | — | 玩家可开启的消耗品（战斗前/中生效） |
| **技能加速剂** | — | 第 3 批（2,000 虚空晶） |
| **召唤入侵（信号发射器）** | — | 第 2 批（10,000 虚空晶） |

⇒ 页面结构必须**按"配方目录"而不是"一件产物"来设计**：分类 × 效率 × 产出 × 工期，且**新东西加一行就出现**。

## 二、技能结论（`ui-ux-pro-max`）

1. **Master（一次检索定调，已落盘）**：查询 `sci-fi space station industrial HUD dark mode game console cockpit`
   → **风格 = HUD / Sci-Fi FUI**（关键词：Futuristic · technical · wireframe · neon · data · transparency）
   - 令牌：星空白 `#F8FAFC`（主）· 发射蓝 `#3B82F6`（强调/CTA）· 底 `#0B0B10` · 卡 `#1E1E23` · 弱底 `#232328` · 描边 `#1E293B` · 危险 `#EF4444`
   - 字体：**Share Tech Mono（标题）/ Fira Code（正文）**——等宽、HUD 味
   - 特效：辉光 · 扫掠线 · 走马灯 · 闪烁标记 · **细线绘制**；动效 Subtle（滚动/进入 300~400ms，须尊重 `prefers-reduced-motion`）
   - 密度：**8/10（Dense / Dashboard）**——与"工业页塞得下、一级页不滚"的既有约束同向
2. **四页覆盖（`--page`）**：首轮用"业务词"检索（refinery / assembler / shipyard / lab）**全部跑偏**（返回浅色营销风 Minimalism / Flat / Hero）。按技能自带的处置规则**收窄重试一次**（加 `sci-fi HUD dark` 词）后，**四页一致收敛到同一套 HUD 系统** ⇒ 结论：**四页共用一套壳，用"版式分区"而不是"换配色"来区分页面**（这也是仓库 §6"同级相似项优先"在视觉上最自然的落法）。
3. **图形建议**：产能/效率对比用 **Bullet chart**（区间条 ＋ 目标刻度）· 概览用 **Gauge**（技能 `--domain chart` 的输出）——草稿里两处都用上了。
4. ⚠ **合规提醒**：仓库 §6 明写「样式一律优先复刻同级相似项…不自造相似新样式」。本草案＝**新配色 ＋ 新字体 ＋ 新特效**，属于**必须船长明令才可偏离 §6** 的那一类 ⇒ 见第六节。

## 三、四页版式规格（草稿）

**共用壳（四页逐字一致）**：顶部页签（精炼炉 / 组装机 / 造船厂 / 实验室）→ **角标面板**（左上/右下 `L` 形细线）→ 发丝线表格（等宽数字、右对齐）→ 进度条（扫掠）→ 底部走马灯读数。

| 页 | 版式分区 | 关键组件 |
|---|---|---|
| **精炼炉** | 左「**工位矩阵**」（多台并行：工位号 · 资源 · 每批 · 本批进度 · 周期 · 劳动者 · 停炉）＋ 右「**产出仪表**」（Gauge 精炼速率 ＋ 按资源分档的 Bullet 产能条）＋ 右下「资源选择」分档 chip ＋ INPUT 走马灯 | 工位表 · Gauge · Bullet · 分档 chip · 开工行（主控/核心下拉） |
| **组装机** | 左「**制造队列**」（每作业一卡：产物 ×N · 蓝图档 chip · 进度条 · **材料齐备度 Bullet** · 剩余时间）＋ 右「**蓝图书架**」（分档 chip ＋ 三列小表：产物/档/工期/状态） | 队列卡 · 齐备度 Bullet · 档位 chip（稀有条/奇货条） |
| **造船厂** | 左「**干船坞**」（舰船线稿占位 ＋ 骨架进度大条 ＋ 材料/材料值/工期三格 ＋ 取消）＋ 右「**可造舰船**」（舰级 chip ＋ 材料值/工期表） | 干船坞视图 · 大进度条 · 三格读数 · 舰级 chip |
| **实验室** | 左「**配方目录**」（分类 chip：燃料/战斗增益/技能加速/召唤入侵 ＋ 每行：产物 · **效率 chip** ＋ 单位产出/工期/虚空晶 · **效率 Bullet**）＋ 右「选中配方 · 投料」（五行料表：每批/仓库/余量条）＋ 右下「运行中」（多线并行 · 各自进度 ＋ 停线）＋ FUEL 走马灯 | **配方目录（本批核心）** · 效率 chip/Bullet · 投料表 · 多线运行名册 |

**实验室的三条设计决定（草稿口径）**：
1. **配方目录是主视图**，不是"一件产物的详情页"——新增消耗品＝表里多一行，UI 零改动；
2. **效率是一等公民**：每个配方一枚 **效率 chip ＋ Bullet 条**（区间条 = 同产物各配方区间，目标刻度 = 当前最优），玩家一眼看出"哪个配方更划算"；
3. **投料/运行照旧**：选中配方后右侧给五行投料表（沿用现有"仓库/余量/行情"读法）＋ 运行线名册（可多线并行，与精炼炉的多工位同款语言）。

## 五、落地代价（估算）

1. **一次性的样式层**：新增约 30~40 个 CSS 变量/类（令牌 + 面板/角标/表格/进度/Bullet/Gauge/chip），落成 `app-hud-*` 命名空间；**不动**现有 `.app-*`（可灰阶回退）。
2. **四页改造**：精炼炉（工位矩阵视图要看现有 `refineRunViews` 字段是否够 → 结论：够，只有"劳动者名/周期/批数"三项）、组装机（队列卡复用现有制造线视图）、造船厂（干船坞＝新增一个线稿占位组件）、实验室（本次已实现的部分要按"目录"重构）。
3. **风险**：① 一级页不滚的约束下，四页信息量增加 ⇒ 需要给每页定"必须装下"的清单（我建议先按 1340×900 画布验收）；② 等宽字体对中文的回退（`Share Tech Mono` 无 CJK ⇒ 中文走系统字体，字形宽度会变 ⇒ 数字列要用 `tabular-nums` 锁宽）；③ 扫掠/辉光对低端机的开销（技能给的 performance 提示：`cost:moderate`，须给 `prefers-reduced-motion` 与"关特效"开关）。
4. **分批建议**：① 只做实验室（最小验证，1 批）→ ② 精炼炉 → ③ 组装机 → ④ 造船厂（每批独立验收；不夹带在跃迁燃料链里）。

**图标化落点（"少字多图标"的具体做法）**：页签 = 图标＋名（精炼炉/组装机/造船厂/实验室各一枚专属线稿）·
顶栏读数 = 图标＋数字（产出倍率 / 在跑工位 / 燃料库存）· 表格首列 = 物品或核心图标（`RowGlyph`）·
动作 = 纯图标按钮（`▶` 起炉 / 核心起炉 / `■` 停炉停线 / 市场）· 效率与余量 = **图形**（Bullet 条 / 余量条）
而不是文字描述 · 长句（规格、口径、注意事项）**只挂 `title`**，页面上不铺开。

**覆盖度（诚实标注）**：精炼炉与实验室是**本页自绘的 HUD 版**；组装机 / 造船厂**暂时内嵌既有面板**
（功能完整、观感仍是旧卡片），它们的 HUD 化按"一批一批来"排后续（与本节第五节的 ①~④ 分批一致）。

**说明草稿与实现的差异**：`tools/_ui-artifacts/industry-hud-design.html`（四页草稿）是**图标化之前**
的一版；**现状以实现为准**（页面里图标已补齐、文字已收短）。
