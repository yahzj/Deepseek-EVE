# 信号空间自动探索普通资源额度修复

> 状态：实现、专项、整库回归及网页版发布核验完成；桌面发行按船长指令暂停｜经办：二号｜日期：2026-11-09
> 船长确认背景：玩家反馈 `7f2e89b25` 后自动探索收益明显下降；确认采用“部分回滚 + 重新平衡”，保留真实采集器/打捞器门槛，恢复普通资源的有界保留额度。

## 目标

保留 `7f2e89b25` 修复的真实设备统计，避免无设备时虚构矿脉或打捞产出；把预留策略应用于当前估算器的普通地点作业回合，让浅层无需收集的普通资源不再占用后续探索预算。

当前新算法的特殊奖励本来就不占普通货舱，因此只裁掉最终普通资源数量并不能增加下潜。第一版65%～85%最终货舱裁切草稿仅使普通产出下降，已在提交前撤掉；不得将这版草稿描述为收益修复成果。

## 当前口径

- 新派队继续使用舰队能力估算器，不恢复旧随机地图模拟。
- 采集器和打捞器缺失时，对应普通作业线保持关闭；不恢复 `Math.max(1, n)` 虚假设备。
- 普通残骸和母矿共用完整货舱；稀有残骸、货柜、谜质和核心仍沿既有独立规则。
- 下潜途中普通作业累计目标为 `0.25 + 0.75 × max((层数−1)/8, 已用探索回合/总探索回合)`，限定在25%～100%；目标体积等于该比例乘货舱容量。
- 用本层潜在普通产量、已规划普通量及累计目标决定本层普通地点作业比例，仅省去跳过普通地点对应的移动/作业预算；扫描、出口、守卫以及特殊地点预算保留。
- 使用不含设备回收效率的潜在体积排程，作业设备升级不倒过来增加浅层回合开销；设备台数和效率只进入实际回收量。
- 仅在本层预算充足且战力达到守卫阈值、允许下潜时采用额度。守卫不通过、回合不足或最深层时恢复本层普通作业，不为无法到达的深层空留货舱。
- 战力仍用现有舰船、实际已装载无人机、光环与有限支援估算，不新增第二套战力评分；不绕过失败守卫。
- 收益系数仍在普通资源容量裁切之后应用，T3 科技的 60%/70%/80% 口径不改。
- 已出发的估算任务按出发时冻结的奖励结算，不重算旧任务；无估算版本的旧模拟与实验自动任务不改。

## 取舍

本次不再对最终普通货舱施加65%～85%总裁切。中途少收浅层普通资源可改变残骸/母矿的比例；末层收集与完整货舱上限仍在。分类均值与普通量下降样本必须单列，不以总体积或工具通过冒称总信用点收益已平衡。无设备队伍、无武装队伍和无法通过守卫的队伍仍按原门槛处理，不发放额外保底。
