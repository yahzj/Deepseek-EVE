# 证券交易所 · AI 市场生态设计（让市场「活」起来）

> 状态：设计稿，未实现　｜　日期：2026-11-03
> 船长口径（2026-11-03）：「主要是好玩，股市拟真只是底层的东西，可以变的，可以写点决策算法封包成一个 AI 在市场里活动，不就活起来了」
> 关联：`stock-exchange-server-20261103.md`（4.7 AI 生态）、`stock-exchange-pacing-emotion-20261103.md`（节奏与情绪）

---

## 结论先行

1. **拟真是底座，不是目标**。撮合、订单类型、保证金这些「真股市」机制可以为了好玩而调整；玩家感知不到「真」，只感知到「这市场有人、有性格、我能读懂并利用」。
2. **AI 要从「四类功能」升级成「N 个有人格的市场玩家」**：有名字、有性格参数、有情绪状态、有记忆，会犯错、会被割、会学乖。
3. **乐趣来自三件事**：可读（玩家能总结出「这家伙就这毛病」）、可利用（每个 AI 都有破绽与代价）、可归因（输赢能说清是被谁干的）。
4. **公平红线**：AI 不读未来价格、不读玩家未公开订单、不用无限资金。玩家可以输，但不能觉得「系统作弊」。
5. **AI 是可调旋钮**：玩家少时 AI 活跃撑场；玩家多时 AI 退居流动性；新手期 AI 让利，老手期 AI 适应反制。

## 一、设计原则（好玩优先）

| 原则 | 含义 | 反例（不要） |
|---|---|---|
| **可读** | 每个 AI 的行为能压缩成一句人设，玩家观察 10 分钟能总结出来 | 纯随机下单，玩家读不出任何规律 |
| **可利用** | 每个 AI 都有明确破绽，玩家能靠观察赚它的钱 | 完美无缺的对手 = 玩家没有掌控感 |
| **可归因** | 战报能说明「你这波是被夜枭砸的」，而不是「系统随机」 | 爆仓只显示「已强平」 |
| **有记忆** | AI 记得被谁割过、哪招吃过亏，会调整 | 复读机，同一招永远有效 |
| **有节奏** | AI 活跃度有波峰波谷，配合事件 | 恒定强度，没有起伏 |
| **不耍赖** | 不用不可能的信息与无限资金 | AI 精准抄底逃顶（玩家必骂作弊） |

## 二、AI 角色卡（初版 6 个）

> 角色名仅作设计占位，正式名称走 l10n 表。

| 角色 | 一句话人设 | 行为特征 | 破绽 | 玩家能怎么利用 |
|---|---|---|---|---|
| **铁砧**（做市商） | 永远挂双边，赚价差，不赌方向 | 五档常驻报价，库存偏斜 | 库存满时被迫单边报价 / 撤单 | 预判它什么时候必须报价，挂低价接它的货 |
| **红隼**（追涨游资） | 涨 3% 就追，跌 2% 就跑 | 5 分钟收益触发追买，小单密集 | 见顶就跑、容易被诱多 | 先拉后砸，把它骗在山顶 |
| **磐石**（死扛基金） | 越跌越买，只信内在价值 | 低于锚点分批建仓，单笔大 | 弹药有限、回撤容忍有上限 | 逼到它弹尽粮绝，抢它的筹码 |
| **夜枭**（空头猎手） | 专挑高估值做空 | 高估时分批开空，事件后加仓 | 逼空时被迫回补 | 制造逼空，让它高价平仓 |
| **群星**（羊群散户） | 看新闻追热点，恐慌时踩踏 | 情绪驱动，跟风买卖 | 互相踩踏、不理性 | 反向操作，或在踩踏前离场 |
| **深潮**（巨鲸） | 偶尔大单扫货，动作慢但体量大 | 低频、大额、带足迹 | 建仓慢、提前有盘口痕迹 | 跟单，或提前埋伏被它扫的标的 |

> 六个角色覆盖三种玩家需求：**对手盘**（红隼/群星）、**可学习的目标**（铁砧/磐石）、**戏剧性来源**（夜枭/深潮）。

## 三、决策算法封包（每个 AI 一个 agent）

```
Agent = {
  id, persona,                     // 身份与人设
  params: { 风险偏好, 反应速度, 记忆长度, 从众度, 贪婪阈值, 恐惧阈值 },
  capital, positions,              // 有限资本与持仓
  emotion: 平静 | 贪婪 | 恐惧 | 亢奋 | 恐慌,
  memory: { 被谁割过, 哪种形态吃过亏, 最近盈亏 },
}
```

**每拍决策流水线**（顺序钉死，便于回放）：

```
1. 读输入：盘口 / 逐笔 / 事件 / 自己的持仓与情绪 / 记忆
2. 更新情绪：盈亏、波动率、事件冲击 → 情绪状态迁移
3. 评估效用：预期收益 − 风险 − 情绪偏移（贪婪时放大仓位，恐惧时缩量）
4. 产出指令：挂单 / 撤单 / 吃单 / 观望
5. 记决策理由：写回放日志（调参与排查用）
```

- **确定性**：随机走服务端 PRNG，同种子可回放整段剧情。
- **参数可热更**：存 DB，不重启即可调参与做活动。
- **资本有限**：AI 会亏钱、会被打爆；系统补给受控（见第五节）。

## 四、让市场「活」的四个机制

### 4.1 对手记忆

- AI 按玩家 id 记录「被割过几次」，对同一玩家降低对手优先级、提高报价。
- 效果：玩家不能靠同一招无限薅同一个 AI，但换策略仍能赚——**逼玩家进化，而不是封杀玩家**。

### 4.2 策略适应

- 检测玩家长时间使用同一形态（如反复诱多），AI 调整参数反制（更谨慎、更少追高）。
- **红线**：适应必须基于公开可见的历史行为，不能读玩家私密订单。

### 4.3 情绪传染

- 一个 AI 恐慌 → 同性格 AI 一定概率跟随（踩踏），但传染强度衰减、有上限。
- 效果：制造真实的「闪崩」与「踩踏」，但不会无限连锁把市场打死。

### 4.4 剧本事件

- 条件触发的「故事」：AI 联盟逼空、巨鲸扫货、机构调仓、羊群踩踏。
- 每个剧本有明确触发条件与持续时间，玩家可从中获利或受害，事后能复盘。

## 五、经济约束（AI 不能是印钞机）

| 问题 | 设计 |
|---|---|
| AI 输光 → 市场没人做市 | AI 资本池按全服活跃度受控补给，补给量写审计 |
| AI 赢太多 → 玩家觉得被收割 | AI 利润一部分进「做市商激励池」，用于窄价差回馈玩家 |
| AI 无限资金 → 玩家无法逼空 | 单 AI 资金上限 + 单一标的敞口上限 |
| AI 破产 → 剧情断层 | 破产 AI 进入「重组」状态，N 小时后带新资本回归（剧情化） |

**红线**：AI 的亏损不能由系统凭空兜底；补给必须有来源（税池/激励池）与上限。

## 六、可见性：让玩家「感觉到」市场是活的

| 呈现 | 内容 |
|---|---|
| 市场参与者面板 | 做市商/游资/机构/散户的成交占比与活跃度（不暴露具体身份） |
| 盘口人格痕迹 | 同一 AI 的挂单有习惯（价格尾数、挂单量、刷新频率），玩家可读 |
| 战报归因 | 「你被夜枭砸盘了」「群星踩踏导致滑点扩大」 |
| 财经快讯 | 「红隼资本增持 SMHI」「深潮扫货 UGMC」——把 AI 行为写成新闻，增强叙事 |
| 情绪温度计 | 全市场贪婪/恐惧指数（由 AI 情绪聚合），玩家可作反向指标 |

## 七、难度与节奏旋钮

| 玩家阶段 | AI 行为 |
|---|---|
| 新手（前 N 次交易） | 做市商价差更窄、游资更蠢、羊群更慢；让玩家先赢几次 |
| 常规 | 标准参数 |
| 高玩（累计收益/交易次数达标） | AI 适应增强、巨鲸出现频率提高、逼空剧本概率上调 |
| 在线人数少 | AI 活跃度自动上调，保证盘口不空 |
| 在线人数多 | AI 退居流动性提供者，把对手盘让给真人 |

## 八、实现形态（whale-server 侧）

```
src/exchange/agents/
├── types.ts          // Agent / Persona / Emotion / Memory
├── registry.ts       // 六个角色的注册表与参数
├── behaviors/        // 每个角色一个决策函数（纯函数，输入状态输出指令）
├── emotion.ts        // 情绪状态机与迁移
├── memory.ts         // 对手记忆与策略适应
├── scripts.ts        // 剧本事件（逼空联盟/踩踏/扫货）
└── replay.ts         // 决策日志与回放
```

- 每拍顺序：**撮合 → 强平 → 情绪更新 → AI 决策 → AI 下单 → 下一拍**（与既有「步序钉死」一致）。
- 角色参数与剧本表存 DB，可热更；每次参数变更写审计。
- 与玩家使用同一套下单接口，**不享受任何特权**。

## 九、怎么验证「活起来了」

1. **可读性测试**：让玩家玩 10 分钟，问「你觉得市场里有几种人？各有什么毛病？」能答出来 = 可读。
2. **可归因测试**：爆仓后问「这波是谁干的？」，能指向具体角色 = 可归因。
3. **适应性测试**：同一招连用 5 次，第 6 次收益明显下降 = AI 会学（但不能变成封杀）。
4. **戏剧性测试**：连续玩 3 天，是否至少遇到一次「值得讲给别人听」的事件。
5. **反作弊感测试**：玩家是否说过「这 AI 在作弊」——出现即失败，回退参数重调。
