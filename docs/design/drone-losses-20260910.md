# 无人机可被击落（2026-09-10，**已确认并实施**）

> **状态：船长已确认并实施**。船长指令（原话）：「调整完后开始实施无人机可被击落。」
> 损失持久性**船长选乙：永久损失（耗材流）**——被点防击落的无人机战后从清单永久扣除，需重新补充。
> 定位契约（`docs/design/drone-roles-20260910.md`）已先落地：四型的血量/闪避/抗性现在**真正参与战斗**。
> 经办：引擎与平衡 = 二号；表现层（机群递减/被击落演出）= 三号（待对接，见 §六 数据契约）。

## 一、要解决的问题

现状：无人机是"不消耗、不被击落"的纯火力模块——四型的生存包（血厚/闪避/脆）**没有任何战斗意义**，
无人机流因此只有"火力/射程"一个维度，缺一个天然制衡（这也是 C6 评估里无人机流偏强的根因之一）。

目标：让敌方**点防**真实射击机群 —— 机群规模随战斗递减、DPS 随之下降；
攻坚机靠血厚硬扛、侦察机靠闪避、哨戒机靠距离（在点防射程外安全）。

## 二、机制设计（拟）

### 1. 敌方近防炮（Point Defense，2026-09-10 船长口径）

| 概念 | 口径 |
| --- | --- |
| 装备条件 | **威胁 ≥ 60** 的敌舰才装近防炮（低于此值无敌近防炮） |
| 判定节奏 | **每艘点防舰每 0.5 秒判定一次**（多舰叠加；判定独立于敌舰的常规攻击） |
| 目标选择 | 随机挑一架**正在攻击的放飞无人机**——**哨戒机不被打**（近防炮不理会狙击平台） |
| 命中 | `pdAcc − 机型闪避`（不叠敌方通用命中加成，突出"闪避"价值） |
| 伤害 | 每次命中 `pdDmg`（走该机型三层抗性：盾→甲→结构） |
| 距离 | **不看距离**——放飞出去就在威胁之下（"毕竟你要飞过去"） |
| 定位 | 近防炮**只打无人机**，不参与敌舰对玩家的常规攻击 |
| 上限 | 单场最多击落本场放飞总数的 50%（防团灭） |

### 2. 逐架生存与击落

- 放飞时每架无人机按机型 `DroneDefense` 生成**独立血量池**（盾/甲/结构 + 三系抗性 + 闪避）。
- 命中后按 `pdDmg` 走三层消费；血量归零 = **本场击落**：该架立即停火（不再产生弹道/伤害），
  同机型其余架不受影响；战斗界面机群数量随之递减。

### 3. 与定位的对应关系（设计意图与现实）

| 机型 | 近防炮下的表现 |
| --- | --- |
| 侦察机（闪避 0.45 / 血 19） | 命中率仅 `0.55−0.45 = 0.10`——几乎打不中（闪避兑现） |
| 战斗机（0.25 / 40） | 中庸 |
| 攻坚机（0.10 / 97） | 几乎必被打中，但**要打很多轮才掉一架**——耐消耗 |
| 哨戒机（0.18 / 23） | **免疫**（近防炮不打哨戒无人机）——火力平台受保护 |

> **实测后的现实提示（重要）**：哨戒机免疫 + 攻坚机是唯一靶子，导致 **D3（哨戒机为重心的编成）
> 反而最安全**：被击落的基本全是攻坚机，而编队火力核心（雷鸥 6 架）不受影响，故硬卡仍全胜。
> 若希望"厚甲者更安全"的直觉也成立，可选方案：让近防炮也打哨戒机（但降低对其命中）、
> 或对高血量机型做伤害加权——**待船长定方向**。

### 4. 反制手段（本轮**不做**，观察后再定）

候选：无人机电子对抗装置（降点防命中）、中继天线顺带削点防、或战术导控给"抗点防"。
先看首轮数据，避免一次上太多变量。

## 三、损失持久性（**关键取舍，请船长选**）

| 选项 | 内容 | 影响 |
| --- | --- | --- |
| **甲（推荐）** | **本场折损、战后归队**——被击落的无人机只在本场消失，战斗结束返回清单 | 只影响单场表现与战术（长卡更吃力、重复清剿更谨慎）；经济不受冲击；实现干净、易回滚 |
| **乙** | **永久损失**——战后从清单扣除对应架数，需重新购买/制造补足 | 最硬核、最有分量；但会把无人机流变成"耗材流"，与"免弹药、免货舱"的定位冲突，且需要同步做经济补偿（降价/回收/修理）与存档字段 |
| **丙** | **可修复损失**——战损进入"待修"状态，消耗修理组件或回港修复；未修复不能出战 | 折中方案；需要新增状态字段与工业/维修链路，工程量最大 |

**我的建议：先甲**（本场折损），把乙/丙留作后续独立批次——理由是"点防机制本身"已经能带来
"机群递减、攻坚耐打、哨戒靠距离"的全部战术变化，而永久损失会立刻冲击经济与重复清剿体验，
宜等点防数值稳定后再决定要不要加。

## 七、实测（`npm run battle:pd-tune`，满技能，5 种子，王鲭 4 高槽，D3 满编 4 猎鹰 + 6 雷鸥）

> **口径修正（2026-09-10 自检发现）**：早期两版工具给王鲭配了 **3 中 + 3 低支援件**，
> 超出该船实际布局（中 2 / 低 2）——`drone-vs-gun` 经 repair 链被自动裁成 2+2（炮击向：
> 盾容+索敌 / 稳定器+射速，对无人机火力无效＝白占 CPU），`pd-tune` 未裁则虚高。
> 现已统一为**合法且符合流派**的配装（无人机向 = 盾容+陀螺 / 甲容+装甲板）。

**船长确认口径（2026-09-10）**：「如果没有特意说明，默认按 0.5/5 来算」——
即**未特意说明的敌舰一律**：每 **0.5 秒**判定一次（逐舰独立、多舰叠加）/ 判定**命中率 0.5** /
每发**伤害 5**；单场击落上限 50% 保留；哨戒机免疫。后续如需按敌族/卡做差异，另行说明即可覆盖。

**结构性事实（决定调参手感）**：
- D3 编队里"非哨戒机"只有 **4 架攻坚机**，所以 2.2~4.0 架的实际含义是"**攻坚机小队被打掉一半到全灭**"；
  想让硬卡更温和只能压低伤害档，或让玩家多带攻坚机（满舱 16 猎鹰时 4 架只占四分之一）。
- 由于哨戒机免疫、且 D3 的火力核心是 6 架雷鸥，**硬卡胜率不受影响**——近防炮的现实压力是
  "**打得更久 + 攻坚机要补货**"，不是"打不过"。
- 反直觉副作用：**哨戒机为重心（D3）反而最安全**，攻坚机成了唯一靶子。若要让"厚甲更扛"的直觉成立，
  可考虑让近防炮也打哨戒机（对其低命中）——**待船长定方向**。

## 八、表现层数据契约（给三号对接）

| 字段 | 位置 | 含义 |

| `state.droneLossNotice` | 结算后写入 | 一次性提示（已接 toast）：机型与架数摘要 |
