- **状态**：进行中（实现完成 · 等船长**看观感**——观感审查权在船长，2026-09-13 船长定）
- **船长令**：**「按你推荐来」**（上一批报告里挂着的三件事之 ③：打捞页 AI 徽章配色方案）
- **本批落点（模块自报 §2.1）**：**打捞与矿带界面**（星图/作业卡这一片）；**参照的同类子模块** =

## 一、改的是什么

上一批已修掉"图标传错色"（船长 2026-10-02 报障「卡片内 AI 工作的图标颜色不对」⇒ 图标改走
`currentColor`，继承徽标墨色）。剩下的那一件是**徽标底色**：它一直是**固定青**（`--wui-cyan`），
挂在哪种卡上都一样 —— 而全仓早就有一套"这一枚单位在干什么"的活动色。

**改法**（两处调用点各挂一个修饰类）：

| 卡片 | 修饰类 | 底色 |
|---|---|---|
| **矿带卡**（`BeltCard`，AI 在采矿） | `is-work-mine` | `--wui-work-mine`（采矿色） |
| **残骸打捞卡**（`WreckCard`，含「全部」那张，AI 在打捞） | `is-work-salvage` | `--wui-work-salvage`（打捞色） |
| 其它（不挂修饰类） | — | 照旧 `--wui-cyan`（缺省不变） |

形状、字号、圆角、内距、文字色（墨色 `--wui-x222`）与图标（`currentColor`）**一个字未动** ——
本批只让"底色"承担信息："这一枚 AI 在采矿还是在打捞"。

## 二、涉及文件

- `apps/desktop/src/renderer/src/styles.css`：`.app-belt-ai-badge` 后加两条修饰类（+16 行，**不动原规则**）；
- `apps/desktop/src/renderer/src/ui/layout-css/styles-modern.css` / `styles-classic.css`：
  由 `npm run ui:layout-css` 重新生成（生成件，+16 行 ×2）；
- `apps/desktop/src/renderer/src/pages/MapPage.tsx`：两处徽标的 `className` 各加一个修饰类 ＋ 注释说明。
