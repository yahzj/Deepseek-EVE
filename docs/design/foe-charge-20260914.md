## 二、BUG 根因（船长报障「冲锋到达目标距离后并不会解除」）

距离拔河（`stepBattle`）：`rate = steerStep(dist, myDesire, meV) + steerStep(dist, foeDesire, foeV)`。

- 当 `foeDesire < dist < myDesire` 时：我方以 `meV` 外拉、敌方以 `foeV` 内推 ⇒ `rate = meV − foeV`；
- **我方更快**（`meV > foeV`，即使敌方已乘冲锋倍率）⇒ 距离一路涨到 `myDesire` 就**停在那里**
  （`steerStep` 有 0.5 m 死区，不抖动）；
- 于是 `arrived = distanceM <= desireM`（敌方期望交距）**永不可达** ⇒ 冲锋永不解除、`foeChargeCdUntilMs`
  永不写入、界面标记一直亮着。冲锋倍率越大越容易触发这个死结（倍率只把停住的位置往下压一点）。

**修法**：加一条**事件型**出口——在冲的单位炮台**打中我方**那一刻立即解除并起冷却。
在冲的单位既然已经进了自己射程（这也是触发条件之一不再成立的前提），炮台迟早打中 ⇒ 必然收场；
原 `arrived` 保留为兜底（双方都往内压时仍按"压到目标距离"解除）。
用例 `thruster-charge.test.ts` 的「🔴 BUG 修复」条把这条钉住：造一个**距离永远压不到目标距离**的场景
（我方 9,000 m / 敌方 2,601 m、我方更快），断言 `minSeen > 2,601` 且**仍然解除**、冷却 10 秒。

## 三、新口径（一句话版）

**触发**（取或）：① 距离在自己武器射程之外 ② 距离 > 期望交距 + `foeChargeTriggerMarginM`(1,000)。
**加速**：该单位**自己**的机动 ×（舰级 `foeChargeMul` ?? 全局 `foeChargeMul`）——**逐单位、不外溢**。
**解除**（取或）：① **自身炮台命中我方** ② 压到期望交距。
**冷却**：解除后 `foeChargeCooldownMs` = **10 秒**（期内不再起冲，期满且触发条件仍成立可再冲）。
**编队接近速度** = 存活单位的「空速 ×各自倍率」**取平均**。

读法举例（噬口猎杀令第 3 波 = 畸变幼虫 ×3 + 噬口巨兽 ×1）：

| 单位 | 空速 | 倍率 | 该项 |
|---|---|---|---|
| 畸变幼虫 ×3 | 544 | ×1.5 | 816 |
| 噬口巨兽 ×1 | 297 | ×3 | 891 |
| **编队接近速度** | | | **(816×3 + 891) ÷ 4 = 834.8 m/s** |

（旧 `max` 补丁会给 891 m/s；若"倍率外溢到整队"则会是 1,929×… 量级的更高值——用例对这两条都有反证。）

**"命中"的判据**（船长确认）：**炮台主武器判定命中即算**——掷命中的（C 族 `energyForm: 'spit'`）要真掷中，
光束必中的（`beam`）照算；**机群 / 近防炮命中不算**（那是舰载机与防御武器打的，不是"自身炮台"）。

**读数解读（如实）**

1. **小虫会冲之后，C 族各卡的交战距离整体被压近**（终局交距普遍 −1,000 ~ −1,500 m），
   我方承伤相应上升（残血% 最大跌幅：星髓虫群 A3 **66% → 37.1%**）。这是船长要的"小虫也吃冲锋"的直接后果。
2. **噬口猎杀令四行仍全 0%**（本批没有翻转这张卡的胜负，交距在 1,000~2,700 m 之间摆动）。
3. **噪声提醒**：每格仅 5 种子，且命中/选靶是确定性 RNG 链——时机一变整链重排，
   个别格会出现"反方向"抖动（例：巢群游猎 A1 胜率 40% → 60%）。**判强弱要看 A0~A3 四行同向**，
   不要单看一格（纪律见 `docs/design/foe-baseline-audit-20260911.md` §四）。
4. 若船长实测觉得 C 族小虫过凶，可调的两个旋钮：小虫倍率 1.5（或只让噬口卡的小虫冲）、
   以及 `foeChargeTriggerMarginM`（1,000 → 更大 = 更少起冲）。

## 七、边界与不做

- **不入档**：`foeCharges` 是运行态（`save.ts` 登记表 `kind: 'runtime'`，逐条写明理由）⇒ 战中重载**重置冲锋循环**
  （与 2026-09-10 起的历史口径一致，不升存档版本、不加迁移）。
- **不等于"每波重置"**：状态按战斗 tag（`foe-0` / `w0-foe-2` / `w1-foe-0-e1`）存；单位阵亡即清掉它的条目
  （tag 在一场内唯一，不会残留到后续波次）。
- **机群 / 近防炮命中不解除**（口径见 §三），未来若给敌舰加"冲锋 + 机群"混编需重新裁定。
- **老路（威胁门槛 + brawl）仍不实装**：`foeChargeEnabled` 默认 `false`，本批只动舰级级 opt-in 通道。
- `foeChargeMaxHoldMs` 仍是**停用字段**（2026-09-11 起），本批未复活。
- 文档同步：`docs/design/foe-c-range-20260914.md` §七 的 ×4 已被本批取代（该节末尾已加指针）；
  `thruster-charge-20260910.md` / `foe-faction-c-alien-20260911.md` §十 的旧描述由本文件接续。
