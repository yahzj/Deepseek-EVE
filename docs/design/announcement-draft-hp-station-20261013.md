- date：`2026-10-13`

1. 玩家与敌方舰船的护盾、装甲和结构血量整体提高约50%，舰船插件的固定血量加成同步提高；无人机血量和常规恢复量保持不变。
2. 新开启的入侵旗舰共享血池提高至30万；已经锁定的血池保持原值，已累计的伤害与贡献保留。
3. 玩家舰船装配任意有效高槽装备后禁用基础舰炮，拆空高槽后恢复；舰载武器在近盲区内仍可开火，对舰伤害降为正常的30%，无人机与近防对机群的规则不变。
4. 玩家出勤期间可进行仓库交易与逆向研究；装卸货物、出售船上货物和站内维修按目标舰停靠状态检查，空闲副船不受主控位置影响，母港与已建成副站适用相同规则。
5. 玩家从采矿或打捞切换至站内作业、长途运输或建站交付时，舰船按原航程返港，到港后自动检查条件并启动；待办随存档保留，活动栏可取消待办，取消后舰船仍继续返港。
