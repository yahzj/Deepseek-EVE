# V7 设计文档：舰队重构 / 自动采矿循环 / UI 总菜单改版

## 背景与目标

按玩家要求重构信息架构，并落地此前确认的四项机制决策：
**每艘船独立货仓 / 无限物品仓库 / 舰船损毁（耐久+弃船）/ 采矿并入星图页 + 满舱自动返航卸货**。

## 存档结构 v7（一次大重构）

旧结构：全局 `inventory`（货仓）+ `fitted`（装备）+ `shipBay`（拥有列表）。
新结构（迁移链 v6→v7 无损，v0..v5 自动逐级迁移）：

```jsonc
{
  "version": 7,
  "shipId": "sandcat",                  // 当前驾驶
  "fleet": {                            // 舰队：每艘船自持状态
    "sandcat": {
      "durability": 0.85,               // 耐久 0~1
      "cargo": { "ore-veldspar": 800 }, // 货仓（随船）
      "fitted": { "miner": null, "cargo": null, "turret": null } // 装备（随船）
    }
  },
  "warehouse": { "items": {} },         // 物品仓库：无限容量、永不遗失
  "moduleBay": {},                      // 装备库（空间站库存，不随船）
  "blueprints": [],
  "aiCoreLevel": 0,                     // AI 核心 0~5
  "mining": { "active": false, "beltId": null,
              "phase": "mining|returning|outbound",
              "cycleAccMs": 0, "phaseAccMs": 0, "tripUnits": 0,
              "autoCycle": true, "stopAfterTrip": false },
  "expedition": { /* 含 eventId/eventFired（v6 既有） */ },
  ...
}
```

迁移要点：旧货仓/旧装备归属"当时的当前船"→ 移入该船 fleet 条目；船坞其它船为空船；
仓库初始为空；AI 核心 0 级；采矿作业进入状态机（在途采矿按"正在采掘"接续）。

## 玩法规则

### 双仓语义

- **货仓（cargo）**：随船。挖矿、远征战利品、途中事件矿物都入货仓，占船容量；
  弃船时货仓内容遗失；切换驾驶看到另一艘船自己的货仓。
- **物品仓库（warehouse）**：飞行员资产。无限容量、永不遗失；
  **精炼产物直接入仓库、制造材料从仓库扣除**（精炼原料自动先货仓后仓库取用）；
  矿石自动卸货/手动卸货都进仓库；仓库物品可卖出，也可按剩余舱容装船。
- 卖出入口拆分：货仓卖（sellCargoItem）与仓库卖（sellWareItem），均享声望加成。

### 自动采矿循环（采矿并入「星图」页）

采矿作业 = 状态机：**采掘 →（满舱）返航 → 到港自动卸货入仓库 → 出航 → 采掘**。
- `autoCycle`（默认开）：满舱自动周转；可勾选 `stopAfterTrip`「本次返航后停止」；
  离线结算共用同一状态机（剩余时间管理器保证一次大推进可穿越多阶段，时间不丢失）。
- **AI 核心**（0~5 级，舰船页 ISK 升级：1万/4万/12万/30万/80万）：
  每级 -15% 往返周转耗时（基础单程 4 分钟）；它是未来"非主控舰船自动执行指令"的前置资产。
- 日志克制：开始/满舱转返航/卸货完成/富矿脉/循环结束。

### 耐久 · 维修 · 弃船（远征失利）

- 每艘船有耐久 0~1；**远征每次失利扣 15%~30%**（随机）；
- 扣后耐久归零 → 必弃船；否则按**弃船率**掷骰：
  `弃船率 = clamp(3%~50%, 威胁/(威胁+2×火力)) × (0.4+0.6×耐久) × (1−0.4×动力 agility)`；
  船数据新增 `agility`（沙猫 0.6 → 鲸王 0.25，大船难脱身）。
- 弃船 = 船 + 货仓 + 船上装备全损；若唯一一艘被弃 → **协会免费补发沙猫保底**；
- 未弃船：收维修费（= 期望奖励×50%）且耐久不回——在「舰船」页花
  `缺失耐久 × 货舱 m³ × 60 ISK` 维修回满。

## UI 总菜单改版（底部导航 + 右侧固定日志）

```
┌ 顶栏：名称 / 飞行员 / ISK / 在线时长 / 保存 / 重置 ┐
│  主窗口（按底部菜单切换，可滚动）      │ 事件日志 │
│  · 舰船：舰队（耐久条/维修/切换）+ AI核心 + 商店   │（固定 320px，│
│  · 装配：当前船三槽 + 装备库          │ 常驻）    │
│  · 货仓：当前船货仓（卖出/一键卸入仓库）           │
│  · 物品：物品仓库（卖出/装船）         │          │
│  · 工业：精炼台 + 蓝图制造（装备/舰船）│          │
│  · 技能：队列 + 全技能宽行             │          │
│  · 星图：本地矿带开采（自动循环设置）+ 星图与悬赏  │
└ 底部总菜单：舰船 · 装配 · 货仓 · 物品 · 工业 · 技能 · 星图 ┘
```

- 日志前缀显示游戏内时钟（如 `3:12`）；页面统一 `Panel` 风格组件。

## 非目标（本版不做）

- 多船同时执行指令（AI 核心已预留，见 roadmap）；
- 舰船损毁的保险/救援系统；声望扣减；
- 更多战斗形态（远征仍是唯一战斗场景）。
