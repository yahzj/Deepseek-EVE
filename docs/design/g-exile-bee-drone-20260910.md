# G 族专属装备改造：流亡蜂无人机（2026-09-10 · 状态：已确认，实现中）

> 船长指令：「G 的流亡蜂群巢改为侦查无人机：流亡蜂无人机，我们进行相应的设计」。
> 本文是该改造的**唯一权威设计稿**；三处关键裁决由船长逐条拍板（见 §3）。

## 1. 为什么这次动得比"换一件装备"深

G 族第一件原本是**模块**（`mod-lair-drone-rack-g`「流亡蜂群巢」，无人机甲板 +55 m³ / CPU 30）。
船长要求改成**无人机物品**（`drone-exile-bee`「流亡蜂无人机」）。两者的落库通道完全不同：

| | 模块（装备） | 无人机（物品） |
|---|---|---|
| 定义位置 | `packages/data/src/modules.ts`（`ModuleDef`） | `packages/data/src/items.ts`（`ItemDef`） |
| 入库位置 | 装备库 `state.moduleBay` | 物品仓库 `state.warehouse` |
| 装配/使用 | 装到槽位 | 放进各船机舱清单 `fleet[x].droneLoad` |
| 消耗性 | 永久持有 | **消耗品**：会被点防击落、永久损失 |

于是"专属装备池"（`FOE_LAIR_GEAR` / `rollRareBoxExtra`）必须从"只装模块 id"扩成"可混装模块与物品"，
且"集齐前不重复"的持有判定、开箱提示、`content:check` 的「来源唯一契约」都要跟着改。

## 2. 改动清单

**删除（撤下）**
- `mod-lair-drone-rack-g`「流亡蜂群巢」从 `modules.ts` 与 G 族池移除。老档若持有该件，
  走既有"悬空件"清理路径（`repairDeprecatedModules`）退回；该件上线不足一天，实际影响可忽略。

**新增（物品）**
- `drone-exile-bee`「流亡蜂无人机」：`kind: 'drone'`、`droneClass: 'scout'`（侦察机）、
  **`exclusive: true`（专属型号：只在高级箱产出，无蓝图、不上市场、不入常规掉落池）**。

**引擎/内容**
- `ItemDef.exclusive`：专属型号标记（契约与护栏据此放行"专属强化型"）。
- `rollRareBoxExtra` 返回值新增 `drones: [{ id, count }]`，命中专属无人机时**一次给 10 架**进物品仓库。
- 专属无人机的**持有判定** = 物品仓库 + 各船机舱现存架数之和（`ownedDroneCount`）——
  手上还有就不会重复掉（G 池优先给另外两件模块）；**打光之后它重新进池**，等于"再刷一次就能补回来"。
- 四型定位契约（`data/droneRoles.ts`）扩展：**锚点机型显式化**（蜂鸟/赤鸢/猎鹰/雷鸥）+
  **专属强化型豁免区间校验**（仍受硬边界约束：闪避 0~0.9、三层血 > 0、单发 > 0、射程 > 0、命中 0~2），
  阶梯校验改为按**锚点**比较 —— 于是"专属强化型 + 制式型"同类共存合法，**四型定位本身不变**。

## 3. 船长裁决（2026-09-10）

| # | 议题 | 裁决 |
|---|---|---|
| ① | 补给方式（消耗品 vs 不可造） | **A 案**：一次掉 **×10 架**，仍不可造（无蓝图、不上市场），打光后再刷可补 |
| ② | 数值档 | **A 档基础 + 输出提高到 6 点**：闪避 **0.55** / 三层血 **15**（6/3/6）/ 单发 **6** / 射程 **2500** / 命中 0.75 / 体积 5 m³ |
| ③ | 单发 6 与四型契约的冲突 | **CPU 提到 5 + 契约登记"专属强化型豁免"**（它火力与制式战斗机赤鸢持平，但每点 CPU 仍比赤鸢的 7 便宜） |

### 单发 6 的代价（写进档，供日后校准）

- 契约原口径：侦察机单发 ≤ 制式侦察机的 1.4 倍（蜂鸟 3 → 上限 4.2），且必须**严格低于**战斗机（赤鸢 6）。
  本机型由船长裁决**豁免**：它是"专属强化侦察机"，火力与制式战斗机持平。
- 对比制式：蜂鸟（3 / CPU 4 / 闪避 0.45 / 血 19）、赤鸢（6 / CPU 7 / 闪避 0.25 / 血 40）。
  流亡蜂 = **赤鸢的火力 + 蜂鸟更飘的闪避（0.55）+ 更省 CPU（5）**，代价是三层血只有 15（最薄）、
  且**不可造、一次只给 10 架**。
- 实战口径：无人机单发进战斗再 **×2**（2026-09-10 船长定），故 6 → **12 点/发**，
  再乘导控阵列与船体无人机加成（G2 导控 +45%、梭鱼 +12% → 约 19.5/发）。

## 4. 验收口径

- `content:check`：G 族池 = 1 物品 + 2 模块且 id 全部可解析；专属无人机无蓝图/无市场卡/无碎片配方/不进常规掉落池；
  四型契约对专属型只做硬边界校验、阶梯与区间仍以四台制式锚点为准。
- `core` 回归：掉落确实给 10 架并进物品仓库；持有期间不再重复掉、打光后重新进池；
  机舱/CPU 上限照常生效（装不下就放飞不了，与其它机型同规）。
- 老档：持有「流亡蜂群巢」的档载入后被清理，不报错、不残留。
