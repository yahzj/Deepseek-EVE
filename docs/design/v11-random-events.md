# V11 设计：随机事件系统（已实现）

> 状态：用户 2026-09-04 逐条拍板后实现（触发时点 v3 版：随机到达式）。
> 与二号区域零重叠：不引用物品表、不触碰其文件；存档仅新增 1 字段（events.nextAtGameMs）。

## 一、触发机制（到达式，v3 已确认）

- 状态：`state.events.nextAtGameMs`（下次事件时刻；0 = 未播种）。存档 v10→v11 小迁移补默认。
- 间隔：每次触发后掷 `I = minGap + (maxGap − minGap) × u^gapPower`，
  默认 **10 + 20×u² 分钟**：
  - 最短 10 分钟（此前绝不触发）；**硬上限 30 分钟（到点 100% 触发）**；
  - 间隔越短概率越低（密度随间隔单调递增），平均 ≈17 分钟，约 1.4 件/小时（低频轻量）；
- 推进：`advanceEvents`（engine 中位于 AI 之后、市场窗口之前——事件单可被同一推进撮合）。
  首次播种以"本次推进起点"起算；`while nextAt ≤ gameMs` 循环触发（离线跨多件逐件触发）；
  在线每秒 tick 与离线大推进同一路径；rng 序列固定 → 回档/重放一致。
- 事件日志统一前缀 `✦ `（桌面据此弹小卡）；每件日志记在推进时刻（近似现有子系统口径）。

## 二、事件池（文案合计 70 条 + 市场模板）

1. **宇宙杂讯/奇遇**（35 条，权重 40）：漂流货柜、协会广播、星门脉冲、信标、旧日志等
   —— 纯文本或轻量 ISK（约 80~1500）；
2. **航行叙事**（35 条，权重 35）：舰桥日志/航道见闻风味（不改造远征途中事件链）；
3. **市场大类 A · 行情突变动**（权重 15）：
   - 协会收购周：随机常驻池商品 `shock +0.10`；
   - 站台倾销潮：随机池商品 `shock −0.08` 且池库存 +15%；
   - 短波行情：全池商品 shock ±0.03 微扰；
   - 突现大宗单：随机池商品推大额收购/抛售单（数量 ≈ 流量×30~60，价格现价 ±2%，20 分钟有效）；
4. **市场大类 B · 市场奇货**（权重 10）：
   - 神秘出货：随机 rare/exotic（模块/蓝图/船，不含核心与矿物）当场刷供应单 ×1，
     价格 = 均衡价 ×0.95~1.05，寿命按稀有度（9/4 分钟）；
   - 神秘买家：同范围商品以 ≈现货价水平（常态收购价 2~3 倍）的高价收购单 ×1，寿命同上。

数值集中在 `balance.events`（节奏与四类权重）与 `core/events.ts`（文案表与实现），
商品名运行时经 `goodName`（不依赖物品表结构）。
