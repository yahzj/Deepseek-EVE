# 市场分类调整：货物改名 · 奢侈品子分类 · 货柜独立成一级类型（2026-09-16）

> **状态：进行中**（工作文档；船长验收 + 合入 main 后按 AGENTS.md §8 归档三步：并入 roadmap ＋ 词典登记 → 删本文件 → 重跑 `docs:index`）

## 一、船长原话（照抄）

1. 「**目前奢侈品有哪些？给市场的添加奢侈品分类，放入物品下，物品改名叫货物。**」
2. 「**将货柜添加到市场的分类里，和货物同级**」

## 二、现状（动手前查的）

- **一级类型（改前）**：全部类型 / **物品**（原矿·原材料·气体·冰矿，动态碎片）/ 消耗品 / 残骸 /
  高槽装备 / 中槽装备 / 低槽装备 / 舰船 / 蓝图 / 核心。
- **「物品」下实际住了 7 个大类 37 条**（`_` 探针实测）：货柜 10 · 原矿 8 · 原材料 8 · 气体 4 ·
  奢侈品 3 · 冰矿 3 · 虫洞谜质 1 —— 其中**只有原矿/原材料/气体/冰矿有子分类**，
  **货柜 10 条与虫洞谜质 1 条当时任何子分类都筛不到**（只有"全部物品"看得见）。
- **同类先例两处**：「残骸」2026-09-08 独立成一级类型 · 「消耗品」2026-09-11 独立
  （键集合单点 = `CONSUME_KIND_KEYS`，剔除判定在 `subPasses` 与 `MarketPage.kindPasses` 两处）⇒ 本批照此办理。

## 三、落码

| # | 文件 | 改动 |
|---|---|---|
| 1 | `ui/itemSubs.ts` | `ITEM_SUBS` 补一档「**奢侈品**」（key = `luxury`）；新增 **`CONTAINER_KIND_KEYS = ['container']`**（货柜键集合单点）；`subPasses` 的 `item` 分支同时剔除消耗品与货柜、新增 `container` 分支；文件头注补本批口径 |
| 2 | `MarketPage.tsx` | `KIND_TEXT`：`item` =「**货物**」（原「物品」）· 新增 `container` =「**货柜**」；`KIND_OPTIONS` 在 `'item'` 之后插入 `'container'`；`kindPasses` 新增 `container` 分支，并在 `item` 分支剔除货柜 |
| 3 | `tools/content-check.ts` | 新增「**市场类型契约**」（扫 UI 源码的非注释行）：① 必须有 `container: '货柜'`；② 下拉里「货柜」紧跟「货物」；③ 一级类型名不得变回「物品」；④ `CONTAINER_KIND_KEYS` 必须在；⑤ 「奢侈品」子分类必须在 |
| — | **数据层** | **零改动**：货柜的商品行 / 稀有度档 / 价格一字未动——本批只是**筛选口径**（与"残骸/消耗品独立"那两次同性质） |
