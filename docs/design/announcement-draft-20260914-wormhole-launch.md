## v2 落库稿（2026-09-14 一号审查后 · **可直接粘贴进 `announcements.ts`**）

> 改动依据（逐条证据见 `docs/review/announcement-factcheck-20260914.md` §2~§3）：
> ①全损措辞按实现改写（共享货仓 + 沉船压格 + 手动抛货）②「内容倾向」→**内容原型**、第一档写**均衡深区**
> ③「驻守敌族徽记」→**族徽** ④谜质储存器**不算产出**（本趟生效、离开即消失）⑤「拆解台」→**工业页「货柜拆解」**
> ⑥标题去掉「裂隙」⑦补上「进入/派队即消耗该处虫洞」。数字断言**一处未改**（全部核对通过）。

1. 深空工业协会声望达到 40 后，星图「出港」界面新增「扫描虫洞」选项卡：在那里让主控就地展开扫描阵列（扫描期间主控被占用），进度走满即发现一处虫洞——未出发的虫洞最多同时存五处，中途停扫保留进度，被打断也不清进度。
2. 每一处虫洞上面标着两件事：**内容原型**（均衡深区 / 残骸富集 / 遗迹密集 / 母矿脉 / 交火密集）与**驻守敌族的族徽**。一处虫洞整趟只属于那一族——敌人编成、稀有残骸、遗迹货柜、专属装备与专属舰船图纸都出自该族，挑哪一族由玩家自己决定。
3. 一次最多带四艘船进洞，带入舰船的折算总质量决定可探索回合数：旗舰过重会压塌入口，编队总质量超过 16,000 的进不去。洞内按回合推进（扫描、前往、激活、打捞、采集、开战、深入），随时可以选「撤离」；但自第 2 层起，撤离要先打赢一场撤离战，交火没结束就走不了。船被击沉即永久损失，沉船还会连带压掉货舱格数——装不下的货要在货仓页自己抛弃；整队失联则本趟一无所得。
4. 洞内产出：原矿「虚空母矿」（回港精炼可得虚空晶）、五族专属装备与装备图纸、专属舰船的一次性图纸、遗迹安全货柜与图纸货柜（都占货仓格，带回空间站后在工业页的「货柜拆解」里开箱），AI 核心在撤离成功时直接进核心账本。洞内还会捡到谜质储存器：放进货仓就在本趟生效，离开虫洞即消失。越深越值钱——每深入一层，收益 ×1.2、威胁 ×1.16。
5. 不想亲自跑，也可以在「扫描虫洞」页对某一处派队自动探索：最多四条副船、约五分钟，收益按手动一趟的四成直接进仓库；参与舰与 AI 核心在这期间被占用，舰船不会丢（只掉结构与装甲，回站自理）。亲自进入或派队，都会消耗掉那一处虫洞。

## 正文要点（**v1 · 留档对比用 · 含 `**` 记号，勿直接落库**）

1. **协会声望达到 40 后，可在星图「出港 · 扫描虫洞」标签展开扫描**：扫满一个窗口就能标出一处可进入的虫洞，
   最多同时存五处；扫描期间遇袭不打断进度，停扫也保留进度。
2. **每一处虫洞都不一样**：进洞前就能看到它的「内容倾向」（残骸富集 / 遗迹密集 / 母矿脉 / 交火密集 / 均衡）
   与「驻守敌族徽记」；**同一处虫洞整趟只有一个敌族**，稀有残骸、遗迹货柜与专属装备图纸都出自那一族。
3. **进洞要编队**：最多带四艘船，带入舰船的**折算质量**决定可探索回合数（旗舰与超重编队进不去）；
   洞内以回合推进——扫描、前往、打捞、采集、开战、深入，随时可以选「撤离」；
   **但自第 2 层起，撤离要先打赢一场撤离战，交火中没有撤退这条路**。
   **船被打沉，该船与它带回的货一起丢失**；整队失联即本趟没有产出。
4. **洞内产出**：虚空母矿、五族专属装备与舰船图纸、遗迹安全货柜与图纸货柜、谜质储存器等；
   货柜要带回空间站用拆解台打开，AI 核心在撤离成功时直接计入核心账本；虚空母矿回港可精炼出虚空晶。
   **每深入一层收益 ×1.2、威胁 ×1.16**——越深收益涨得越快。
5. **不想亲自跑也可以派队**：每处虫洞都能「自动探索」——最多四条船、约五分钟，收益按手动一趟的四成
   直接入仓库；任务期间船只与 AI 核心被占用，**不会损失舰船**（只掉结构 / 装甲，回站自修）。
