## 范围与落点

- 新版底部导航、旧版左侧导航恢复各自网页版规则，不回退其他模块或整个仓库版本。
- styles.css撤除手机专用导航宽度、按钮尺寸、字号、图标、间距、滚动覆写；新版左列恢复150px网页版宽度。
- 旧版出港形状/最低高度及容器矮高压缩规则不再排除手机；折叠偏好依旧手机/桌面分别保存，不改变玩家选择。
- layout-css-split.ts停止从冻结基准注入旋转导航特殊规则，两份样式重新生成。未直接改生成件或冻结基准。
- 手机旋转、视口、顶栏、日志抽屉、模态窗口与内容适配均保留。活动栏及业务、存档、个人档不改。
- 模块为导航外壳样式，同类参照是现有网页版；遵循用户明确回滚指令，不新设计手机导航。
- 第一段提交a9ebf551撤除主体覆盖，后续补清生成器与出港残留。旧批工作文档曾在首段同步调整状态；本批其余验证统一记在此稿，历史决策留Git记录。
