# 云端入口切 8443（2026-11-05）

状态：已上线、本地合入，未推送、未走船长验收与全量回归。服务器 nginx 已增开 8443，客户端默认入口已切 `https://game.bajibaji.party:8443`；80/443 仍被腾讯云按未备案域名拦截。

## 船长原话

- 2026-11-05 00:23：「https://game.bajibaji.party/ 这个是不是连接很不稳定」
- 2026-11-05 00:29：「域名是在 Cloudflare 买的…是腾讯云那边在拦截吗？」
- 2026-11-05 00:43：「C可以吗？服务器凭据简单 密码Qwer1234~」（批准 Cloudflare Tunnel 方案并给 SSH 凭据）
- 2026-11-05 00:52：「8443我放行了。」（腾讯云防火墙放行 TCP 8443）

## 现象与定位（均为本机+外部多点实测）

| 探测 | 结果 |
| --- | --- |
| `http://game.bajibaji.party/` | 全球 302 → `dnspod.qcloud.com/static/webblock.html`（腾讯云未备案拦截页） |
| `https://game.bajibaji.party/`（带 SNI 443） | 本机 20/20、check-host 境外 5/6 节点、Cloudflare 回源（525）全部失败；TCP 建连后约 25ms 收 RST |
| `https://123.207.188.192/`（裸 IP、无 SNI） | 全球 4/4 节点 200，证书链正确（LE，CN=game.bajibaji.party） |
| `https://game.bajibaji.party:8443/` | 200，TLS 握手约 50–100ms |

结论：源站与证书健康，是腾讯云对未备案域名的 80/443 拦截（RST 注入），体感即「连接很不稳定」。DNS（阿里/DNSPod/1.1.1.1 一致）、本机 Clash（规则 DIRECT，未接管流量）、nginx 与 Node 服务均排除。

## 方案

1. **服务器**：新增 `/etc/nginx/sites-available/whale-game-8443`（symlink 到 `sites-enabled`），与 443 块同构：`listen 8443 ssl; listen [::]:8443 ssl;`，同一 Let's Encrypt 证书（`/etc/letsencrypt/live/game.bajibaji.party/`），路由不变（`/internal/` → 404，`/api/exchange/` → 127.0.0.1:8788，`/` → 127.0.0.1:8787，含 WS Upgrade 与 300s 超时）。ufw 与腾讯云轻量防火墙均放行 TCP 8443。
2. **客户端**：`apps/desktop/src/renderer/src/features/cloud/preferences.ts` 的 `DEFAULT_CLOUD_SERVER` 改为 `https://game.bajibaji.party:8443`；`FALLBACK_CLOUD_SERVER` 保持 `http://123.207.188.192`（明文，仅网络层失败时单次兜底）。`normalizeCloudServerURL` 返回 `url.origin` 会保留端口，`cloudChatSocketUrl` 在 HTTPS 入口下自动生成 `wss://game.bajibaji.party:8443/api/chat/ws`，无需改 api.ts。
3. **CSP**：`web/index.html` 与 `apps/desktop/src/renderer/index.html` 的 connect-src 增加 `https://game.bajibaji.party:8443 wss://game.bajibaji.party:8443`（`https:` 方案源已覆盖 https 任意端口，wss 需显式）。
4. **Cloudflare Tunnel（原方案 C）**：已安装 cloudflared 2026.10.7、隧道可注册并发流量，但边缘全落在洛杉矶（lax01/05/07/09/12），服务器 ping 1.1.1.1 约 70ms、本机约 269ms，端到端预计 RTT 约 300ms（直连仅 18ms），故停用：`systemctl disable --now cloudflared`（二进制保留；隧道 ID `5bca6790-7ce1-418f-a2ed-71f32c2c0dd6` 已于 2026-11-05 由船长在 Cloudflare 面板删除，未配过 public hostname）。

## 已知限制与未决

- 8443 属绕过拦截的临时通道，不保证长期有效；若被补拦，回滚到 IP 明文直连（FALLBACK 已具备）或走备案（`.party` 无法备案，需换 `.com`/`.cn` 并接入腾讯云）。
- 443 上的存量访问仍失败；旧域名 `shit.fuckrapper.online` 的 443 块同样被拦，未清理。
- 网页版 CSP 仍保留 `http://[::1]:*` / `ws://[::1]:*`（非法 CSP source，Chromium 忽略），未在本批处理。
- 备案与 Cloudflare 橙云代理（回源仍 525，不可用）待船长决定；隧道已删除，如复用需重建。

## 回滚

客户端：`DEFAULT_CLOUD_SERVER` 与 CSP 改回 443 版本。服务器：删除 `sites-enabled/whale-game-8443` 软链并 `sudo nginx -t && sudo systemctl reload nginx`；如需隧道：先在 Cloudflare 面板重建隧道并重新 `cloudflared service install <token>`，再配 hostname。
