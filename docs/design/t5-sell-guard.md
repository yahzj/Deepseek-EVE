- 原句（T5）：A：出售舰船二次确认；船型（工业/武装/重装/航运）标签明显颜色区分。
  B（结构级）：玩家可拥有重复舰船（fleet 需实例化 key）。
- 问答确认：Q1甲 界面层二次确认（引擎零改动）；Q2甲 船名出现的主要界面统一配色；
  Q3甲 **本批只做 A**，B 单独立项；Q4 方向记录（B 用）：重复船自动编号「#2」+
  **允许玩家自由修改舰船名称**（自定义船名）。
- 追加确认（卖船补充）：① **船只锁定防误售**（跨会话持久化 → 存档兼容字段）；
  ② 出售确认内若船上有装备/货物 → **醒目红色警示**并禁用确认按钮。

## 实现

### 1. 卖船二次确认（ShipPage 舰队卡，内联）
- 点「市价出售」→ 该卡展开确认面板：「确认出售「船名」？」+ 说明（按市场收购价即时成交；
  无收购单转限价卖单可撤销）+ 有收购报价时给「预计到手约 X ISK（税后以实际成交计）」；
- 确认/取消按钮；确认后才调引擎 sellShipAt。引擎与存档行为零改动。

### 2. 确认内醒目警示
- 预检本船 fitted 与 cargo：装配 N 件装备 → 红条「⚠ 该船仍装配着装备（名称…），必须先卸下才能出售！」；
  货仓有货 → 红条列出单位数；任一存在 → **确认按钮禁用**（引擎本就不允许，这里是提前告知）。

### 3. 船只锁定（防误售）
- 舰船页每张舰队卡右上「🔒 锁定 / 🔓 解锁」（驾驶中/AI 执勤中也可见，仅防出售不影响其它）；
- core：`shipyard.lockShip/isShipLocked`；`market.shipSellable` 增加拒绝原因
  「该船已锁定防误售：先到舰船页解锁。」（出售/挂卖单统一走它）；
- 存档：`shipLocks`（船 id → true）——v16.1 兼容字段先例（normalize 兜底、只收 true、
  **剪掉不在舰队中的船**、无版本号）；
- 锁定的船出售按钮整体隐藏（卡上另有 🔒 锁定 chip 说明）。

### 4. 船型配色（角色四色集中定义，只动 renderer）
- industrial 工业=绿 / armed 武装=红 / armored 重装=橙 / hauler 航运=蓝；
- 落点：舰船页舰队卡与市场卡角色徽标、手册舰船列表角色徽标、货仓页查看 chip 加角色色点；
  下拉框与战斗小剧场不上色。
