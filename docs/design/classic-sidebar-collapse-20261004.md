## 已确认方案

- 左侧新增箭头图标按钮，默认展开；收窄到56px，只显示导航图标、选中状态与徽标，悬停/读屏保留名称，全部页面可达。

- 桌面旧版日志取消宽度过渡，短淡出后一次释放占位；展开先恢复原宽再淡入。保留组件、筛选和滚动位置，隐藏内容退出键盘焦点。手机抽屉和现代版保持现状。
- 参照现有 Glyph、app-btn、导航徽标、窗口还原回调与日志内滚，不另建图标体系；共享UI外壳域，不跨玩法模块。
- 技能依据：ui-ux-pro-max icons 域 icon-context-accessibility（名称/展开状态）；ux 域 Transform Performance（只动画 opacity/transform，不动画宽高）。
- 已审新提示：ui.App.174「收窄导航 / Collapse navigation」、ui.App.175「展开导航 / Expand navigation」。原导航名称与还原标题复用，不改字。
