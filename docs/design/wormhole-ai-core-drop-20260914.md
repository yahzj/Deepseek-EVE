# 虫洞 · 遗迹打捞掉落 AI 核心（2026-09-14 · 状态：已确认）

> 船长原话（照抄）：「**在遗迹的打捞内，添加阿尔法、贝塔、伽马 AI 核心的掉落。AI 核心单独占 1 格。
> 出率为 10%，不挤占旧有出率。三种核心根据稀有度区分出货权重。**」
> 同日两条改判：「**核心加入虫洞掉落后，移除市场的贝塔和阿尔法AI核心的出售订单并备注。**」
> 「**同时按级别大幅提高AI核心的价值。阿尔法核心定价为1000万。**」

## 一、裁定链（按时间序，全部为船长原话要点）

| # | 议题 | 裁定 |
|---|---|---|
| 1 | 核心到手后的落地形式 | **甲**：撤离成功**自动入核心库**（`state.aiCores`）、**不进仓库** |
| 2 | 层门槛 | **乙**：**层 1 也给 10%**（不看层数） |
| 3 | 三档权重 | **甲**：伽马 60 / 贝塔 30 / 阿尔法 10 |
| 4 | 自动探索（批次 3）是否也吃 | **甲**：也吃，按「手动期望 × 40%」折算（= **4%/趟**） |
| 5 | 结算单 | **甲**：另加一格「AI 核心 N 枚」（附「按行价约 N 信用点」小字） |
| 6 | 市场 | **贝塔 / 阿尔法移除出售订单**（→ `playerBuyable: false` 只收不卖，**回卖保留**）＋ 备注 |
| 7 | 四档价值 | 基础 **2.5 万**（不动）· 伽马 **20 万** · 贝塔 **150 万** · 阿尔法 **1000 万** |

## 二、两条"实现上的必然"（先摆出来再动手的那两条）

1. **必须有"洞内实物形态"这一层**：AI 核心在游戏里**不是物品、是一本账**（`state.aiCores`：市场买卖 /
   技能上限 / 副船与产线占用全按它走），而**虫洞货仓只认物品 id**（占格、拖拽、临时空间、散落、结算
   全按物品走）⇒ 想让它"占 1 格"就必须先有物品卡。
2. **新分类 `aicore`，不复用 `container`**：拆解台的资格判据是 `def.kind === 'container'` —— 复用会让
   核心出现在拆解台、还会被丢进货柜抽奖（`wormholeUnboxRoll` 抽不出东西）。

## 三、落点（权威件）

### 3.1 物品（`packages/data/src/items.ts` → `AI_CORE_ITEMS`）
三种：`ai-core-gamma` / `ai-core-beta` / `ai-core-alpha`，`kind: 'aicore'`、**`unitM3: 500`**
（= 500 m³/格 × **1 格**）、`baseSellPriceIsk: 1`（兜底，不上市交易）、**`unreleased: true`**（施工期）。
各自补一条 `unreleased` 市场卡（`basePrice 1` / `demandMultiplier 0`，防套利）。

### 3.2 形状（`packages/core/src/wormholeHold.ts`）
`WORMHOLE_SHAPE_CORE = { w: 1, h: 1 }` 并登记三个 id ⇒ **每一枚核心 = 独立一件、各占 1 格**
（是**形状件**而非可叠加散货：散货按 `units ÷ 每格单位数` 合并占格，那会变成"多枚挤一格"）。

### 3.3 掉落（`packages/core/src/wormholeSalvage.ts`）
- `WORMHOLE_CORE_SHARE = 0.1`；`WORMHOLE_CORE_WEIGHTS = { gamma: 60, beta: 30, alpha: 10 }`；
- `wormholeRollCore(state, cell)`：**先 10%、命中后按权重抽一种**；**无层门槛**（层 1 起就给）；
- **不挤占的机制**：走**自己的一条每格独立流**
  `wormholeStream(runSeed*71 + depth*733 + (q*31 + r*37)*17 + 13)` —— 与货柜那条
  (`*53 + depth*911 + … +7`)、收尾战那条 (`*17 + depth*613 + … +5`) 盐值全不同
  ⇒ **不消费 `state.rng`、不动旧掷骰的序列**；
- 落在遗迹格**打捞结束那一刻**掷（与"遗迹专属掉落"同点位、但完全独立）。

### 3.4 带回（`packages/core/src/wormholeBattle.ts`）
- 新增导出 `deliverWormholeCores(state, ids)`（**唯一入账点**：撤离带回与用例同源）；
- `deliverExtraction` 里把核心**从 `boxesAll` 里摘出来**再走 `gainAiCore` —— **绝不能进
  `wormholeDeliverRelics`**（那条会 `addWare` 进仓库 ⇒ 变成"仓库里有 3 个核心却不能用"的两本账）；
- 结算单加 `cores` + `coresIsk`（行价参考估值；**不计入「到手合计」**）；
- **半路全损**：走不到这里 ⇒ 核心随背包一起丢（现成口径）。

### 3.5 自动探索（`packages/core/src/wormholeAuto.ts`）
`WORMHOLE_AUTO_MANUAL.cores = 0.1`（手动期望）⇒ 命中率 = `0.1 × 40%` = **4%/趟**；命中后按同一权重抽。
⚠ 核心**不入仓库** ⇒ 不能进 `gains`（那条循环是 `state.warehouse.items` 累加），直接 `gainAiCore`，
报告里用新字段 `WormholeAutoReport.cores` **单列一行**。

### 3.6 市场（`packages/data/src/marketCatalog.ts`）
| key | 行价 | 可买入 |
|---|---|---|
| `core-basic` | 25,000（不动） | ✅ |
| `core-gamma` | **200,000**（原 9 万） | ✅（船长只点了贝塔与阿尔法） |
| `core-beta` | **1,500,000**（原 28 万） | ❌ `playerBuyable: false` |
| `core-alpha` | **10,000,000**（原 90 万） | ❌ `playerBuyable: false` |

「只收不卖」= 照**残骸 / 皇带鱼成品**的现成口径：市场不出售现货（买入被明确拒绝
`buyOrderBlockedReason` → '该商品只收不卖，市场不出售现货。'），**NPC 仍按行价收购** ⇒ 捞到一枚
阿尔法可回卖 **1000 万**。

### 3.7 界面
- `ui/Glyphs.tsx`：新增 `ai-core` 线稿（载板 + 运算核心圆 + 两道引脚；**不是箱体语言**，核心不是箱）
  ＋ 大类级键 `aicore`（同线稿）＋ 三档色调（伽马青绿 / 贝塔琥珀 / 阿尔法炽橙）；
- `panels/Wormhole.tsx`：货仓格短标签 `核心`（与货柜的 `图纸` 同一档）；结算单第 **5** 格

- `panels/WormholeScan.tsx`：自动探索报告里核心**单列一行**（「另带回：…（已直接接入核心库）」）。

### 3.8 契约与用例
`tools/content-check.ts` 四处扩写：**物品总数 70 → 73** · **AI 核心契约**（3 种存在 ·
`kind:'aicore'` · `unreleased` · **500 m³ = 1 格** · 形状 1×1 已登记 · 反查得出账本键 ·
四档行价与只收不卖逐条钉住）· **图标契约**（`aicore` 大类 + `ai-core` + 三档色调）·
**掉落契约**（10% + 60/30/10 且按稀有度递减 + **核心不得混进任何既有抽取池**）·
**配方豁免谓词**补 `aicore`。

新用例 `packages/core/tests/wormhole-core-drop.test.ts`（7 例）：形状/账本键双向映射 · 出货率 ≈10%
与权重 ≈60/30/10（2400 格坐标）· **层 1 与层 3 同率** · **不挤占**（核心掷骰前后货柜那串结果
逐格逐字相同、`state.rng.count` 一位不动）· **入核心账且仓库里没有** · 市场只收不卖与四档行价 ·

## 五、零影响声明
不动任何既有概率、不动旧掉落池、不动市场那本账的其余商品、**不落档改动**（核心入库走现成的

## 六、边界（本轮不做 / 已知留档）
1. **`lostIsk`（"没带回来的货"）仍只算散货**：它读 `run.bag`，**看不到货仓/临时空间里的形状件**
   （货柜、核心、谜质）。这是**本轮之前就有的口径**，改它会动到船长已经看过的那个数字 ⇒
   只报备、不动。⇒ **风险点**：阿尔法核心 1000 万，全损丢一枚时那行会偏低。
2. **施工期闸门未撤**：三种核心物品卡与市场卡全部 `unreleased` ⇒ 上线动作 = 删这些字段
   （与货柜 / 谜质 / 虚空母矿同一套做法）。
3. **伽马仍可市场购入**（船长只点了贝塔与阿尔法）——若日后要一并下架，改一个字即可。
