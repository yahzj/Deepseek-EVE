**bullets（5 条）**

1. 低安遭遇的受损改为按来袭敌群的火力结算：敌群越强，一口咬得越狠；同一片星域里，威胁越高的悬赏敌群越危险；
2. 承伤顺序改为先扣装甲、装甲被打穿才伤结构——装甲厚的船能多扛几轮，结构仍保留 5% 底线，不会被凭空打没；
3. 遭遇了结时结构已低于 50% 的船会自动收手返港：驾驶船停下采掘 / 打捞 / 扫描并返航最近已建成站，副船中止任务召回；
4. 撤退只负责把船带回港：船不会自动维修，维修仍由玩家安排（副船结构低于 50% 时需先修好才能再次指派）；
5. 低安遭遇点「⚔ 迎战」同样加入保险：本场结构损失过半即自动脱离，轻损退出——不产缴获，也不额外扣损。
