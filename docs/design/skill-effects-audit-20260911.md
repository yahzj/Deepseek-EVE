   78 个技能全部登记来源（平衡表 27 条 + 引擎参数对象 6 条 + 内联表 57 条），83 个每级值逐条核对，

## 2. 核查方法（引擎为准）

技能效果值散在三处，本轮把三处都覆盖到了：

| 来源 | 形态 | 数量 | 例子 |
|---|---|---|---|
| **平衡表** | `DEFAULT_BALANCE` 里 `xxxSkillId` / `skillIds` / `familySkillIds` 与同层 `xxxPerLevel` 成对 | 27 条 | `mining.yieldPerLevel 0.06` ↔「采矿技术 每级 +6%」 |
| **引擎参数对象** | 引擎导出的具名常量表 | 6 条 | `combat.DRONE_SKILL.warfarePerLevel 0.05` ↔「无人机作战学 每级 +5%」 |
| **内联常量** | 数值直接写在模块函数里（`1 - 0.04 * lv` 之类） | 57 条 | `mining.ts` astro-geology `+0.04/级` ↔「星质地质学 每级再 +4%」 |

做法：用临时探针把**全仓技能读取点连同上下文**抽出来（`skills.trained[...]` 的 87 处调用点），逐条与说明对照；
核对口径含"乘算式"（×1.2/级、×1.1/级）与"跨技能合计"（如精炼基础 120% + 精炼学 30% + 高级回收 15% = **165%**）。
探针用完即删（仓库 `_` 探针 0 个）。

**逐项抽查（要点）**：精炼 165% 合计 ✓；炮术学 +5%/级（`gunneryDmgPerLevel`）× 族专精 +5%/级 ✓；
规避机动学"满级降至 75%" = 缺口复合 ×(1−25%) ✓（不是 0.95⁵）；富矿勘探 ×1.2/级 + 基础 3%/分钟 + 连续 2 循环 ×3 ✓；
残骸富集识别 ×1.2/级（`Math.pow(1.2, lv)`）✓；离线作业 +20%/级（基础 8 小时 = `DEFAULT_OFFLINE_CAP_MS`）✓；
抗性调谐 +2%/级 且上限 90% ✓；无人机六技能 5/4/4/6/2% 与回收 20% + 6%/级（上限 50%）✓；维修/贸易/货舱/技能训练各族全部一致。

## 3. 转正的护栏：`content-check`「技能说明契约」

1. **平衡表自动配对**：键名前缀相配（`yield…` ↔ `yield…`、`taxSkillAId/taxSkillBId` ↔ `taxCutPerLevel`、
   `familySkillIds` ↔ `familySkillPerLevel`、`industrySkillSlots` 记录即"技能→每级工位"），
   要求技能说明的 `⟦⟧` 里出现该每级值（或它的满级倍数、或乘算式 `1+N`）。
2. **引擎参数对象**：`DRONE_SKILL` 六条逐一钉住。
3. **内联常量登记表 + 现场复核**：登记 `技能 id → 每级值 → 接线位置`；能定位到源码的条目会**读取源码**，
   在该技能读取点 ±400 字范围内确认数值仍在——引擎改了数而说明没改，这里会拦下。
4. **反向断言**：说明里带 `⟦数值⟧` 的技能必须在上述三处之一登记（防新技能写一组没人负责的数）。
5. **未接线只警告不拦**：`call: null` 的条目进 ⚠ 清单（与"蓝图命名差异只提示"同口径）。

**负向验证（三处全中，随后还原）**：

- 改平衡表 `mining.yieldPerLevel 0.06 → 0.09` → `✗ 技能「采矿技术」说明写的是 ⟦6⟧，而 balance.mining 是每级 0.09`；
- 改引擎参数 `DRONE_SKILL.warfarePerLevel 0.05 → 0.08` → `✗ 技能「无人机作战学」说明写的是 ⟦5⟧，而 combat.DRONE_SKILL.warfarePerLevel 是每级 0.08`；
- 改内联常量 `mining.ts` astro-geology `0.04 → 0.07` → `✗ astro-geology 的每级值 0.04 在 mining.ts 的读取点附近已找不到`。
- 还原后全绿：`· 技能说明契约：78 个技能登记来源…核对 83 个技能的每级值、其中 47 条做了引擎现场复核；未接线 1 个`。

## 4. 待船长裁决：`cartography` 星图测绘学

现状：技能可学（rank2、5 级），说明承诺「前往扫描点的航行耗时每级缩短 6%」，**引擎无任何读取**。三个选项：

- **甲（推荐）接活到"扫描返航段"**：`explore.ts finishScan` 的返航段（`travelLegMs(state, ctx, mins) * 2`，去程并入返航）
  再乘 `(1 − 6% × 星级)` ⇒ 满级返航 −30%。与说明"航行耗时"语义最贴近、与既有航行技能族同源（乘算），
  影响温和（只影响扫描循环的返航段）。
- **乙 接活到"就地扫描窗口"**：与信号分析学（−8%/级）、信号过滤学（−6%/级）同处叠加 ⇒ 三技能满级扫描窗口
  0.42 × 0.70 ≈ **0.29**（10 分钟 → 约 2.9 分钟）。**探索解锁速度提升明显**，属偏强的接活方式。
- **丙 清除技能**：删掉技能目录条目 + 说明/界面/训练队列引用，并处理已练等级的存档（需一句迁移口径：
  已投入的等级是否折返训练时间或 ISK）。
