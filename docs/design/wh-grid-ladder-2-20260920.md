## 一、阶梯：改回"每 2 层 +1 环"、**不封顶**

| 项 | 第一批（作废） | **本批（现行）** | 旧旧口径（更早） |
|---|---|---|---|
| 半径 | `2 + (层−1)`（每层 +1） | **`2 + ⌊(层−1) ÷ 2⌋`（每 2 层 +1）** | `min(4, 2 + ⌊(层−1)÷2⌋)`（**封顶 R=4**） |

**差别只在"节拍"与"封顶"两点**：节拍回到每 2 层（= 更早那版的节奏），封顶**取消**（层 7 起继续长）。
⇒ 层 1~2 = R2 · 层 3~4 = R3 · 层 5~6 = R4 · 层 7~8 = R5 · 层 9~10 = R6 …（旧口径层 7 起恒 61 格，现在继续涨）。

- **波数、遗迹/谜质保底、空占比 −1%/层、星云 +2%/层封顶 80%、回合预算**一律**不动**。

## 三、地图可拖动（新功能）

**口径**：放大后（`zoom > 1`）**按住地图即可拖动**，拖的是整张盘（格子 / 舰影 / 路径预览线一起走）。

| 面 | 做法 |
|---|---|
| 手势 | `pointerdown` 记起点、**捕获指针**（拖出地图框也不断线）；`pointermove` 累加平移；`pointerup/cancel` 收尾 |
| 阈值 | 位移 **< 4px 当点击格子**（不进入拖动）⇒ 手抖不会把"点格前往"变成拖图 |
| 夹取 | `wormholeMapPanClamp`：每轴夹在 `±(z−1)·半幅` 内 ⇒ **怎么拖都不会把盘面拖丢**；`z = 1`（适应窗口）无余量 ⇒ 拖动自然不生效 |
| 与点击 | 拖过之后**吃掉紧随的那次 `click`**（`mapDragAteClickRef`，下一次 `pointerdown` 清）⇒ 拖完不会顺手走一步 |
| 与缩放 | 平移叠在**同一个缩放层 transform** 上（锚点仍以玩家格为中心）；拖动中加 `.is-panning` **关掉 220ms 过渡**（否则每帧追动画，手感发飘） |
| 复位 | 换层/进出洞与「适应」按钮都复位平移（与自动缩放同一处：`layerKeyForFx` 那条 effect） |
| 触屏 | `.app-wh-mapbox { touch-action: none; cursor: grab }` + `.is-panning { cursor: grabbing }` ⇒ 手指按在图上就是拖图，不滚页面 |
| 说明 | 图例 ⓘ 那句（`ui.Wormhole.145`）补"放大后按住地图可以拖动查看"（**改既有 id 的值**，不新增 id、中英同步） |

**不做**（本批）：双指捏合缩放（滚轮/按钮已够）· 拖动惯性/边界回弹 · 拖动时的小地图或"回到玩家"按钮。

### 三·补 **报障修正：站在盘边时看不到对侧**（船长 2026-09-20 追加）

> 船长原话：「**虫洞内当拖动地图时，无法看到太远的位置是为什么（比如我在地图最下方，无法放大后拖动
> 查看地图上方的位置。）**」

**根因（首版夹取写错了）**：缩放层是"**以玩家所在格为锚点**"放大 ⇒ 屏幕位移 = `(z−1)·(内容点 − 锚点)`，
离锚点越远的内容被推得越开。**可拖范围因此是不对称的**：上/左最多 `k·锚点`、下/右最多 `k·(幅 − 锚点)`。
首版写成了**对称的 `±(z−1)·半幅`** —— 站盘心时恰好等价（所以我当时没发现），一旦站到边上就只剩一半：
站在 `r=+R` 时，盘顶需要 `pan.y ≥ (z−1)·锚点y`，而旧夹取只给 `(z−1)·h/2` ⇒ **盘顶永远差一半看不到**。

**修法**：`wormholeMapPanClamp(pan, zoom, box, anchor)` 改按锚点分轴算区间——
`x ∈ [−k·(w−anchor.x), +k·anchor.x]`、`y ∈ [−k·(h−anchor.y), +k·anchor.y]`。
两条性质同时成立：**① 盘面任何一格都拖得到**（含站盘底看盘顶）；**② 怎么拖都不露框外空白**（内容始终盖满地图框）。

**读数核对**（临时探针，真调几何函数；`k = z−1`）：

| 场景 | z | 旧夹取 | 新夹取 | 盘顶屏幕 y（0 = 框顶） |
|---|---|---|---|---|
| R4 · 站盘底 `r=+4` | 1.5 | 只给 108（需 198） | **198** | 旧 **−90 ❌** → 新 **0 ✅** |
| R4 · 站盘底 | 2.5 | 只给 324（需 594） | **594** | 旧 **−270 ❌** → 新 **0 ✅** |
| R6 · 站盘底 `r=+6` | 1.5 | 只给 153（需 288） | **288** | 旧 **−135 ❌** → 新 **0 ✅** |
| R6 · 站最右 `q=+6` | 2.5 | 459 | 459 | 两种都 ✅（该向本来就够） |
| R4 · 站盘心 | 1.5 / 2.5 | 108 / 324 | 同 | 两种都 ✅（**旧口径只在锚点居中时成立** —— 首版漏测的正是"站在边上"） |

反向也核过：夹到另一端时盘底 `y` 恰 = 框高、最右 `x` 恰 = 框宽 ⇒ **不露空白**。

**顺带做的整理**：几何口径（缩放档常数 / `viewBox` 尺寸 / 锚点 / 夹取 / 自动缩放）从 `panels/Wormhole.tsx`
抽到新模块 **`panels/wormholeMapGeom.ts`**（纯函数、无导入）—— 面板本身 import 了 `spaceBg` 的
`import.meta.glob`，纯 node 下加载不了，抽出来才能让上面这张读数表**用探针真调同一份实现**核对
（不是照抄公式另写一遍）。面板的 `hereX/hereY` 也改成走同一个 helper（锚点只有一处定义）。
