# 实际出勤编队采集与打捞

状态：已按船长2026-11-12「合并到主树，并推送部署，推进小版本」指令完成合并推送及0.1.6网页版部署，完整核心回归和线上产物核验通过。二号，`d2/workspace`；发布结果见`release-0.1.6-20261112.md`。公告草稿独立待审。

船长报障：「编队的返航卸货只卸载了主驾的，编队内其他的船没有卸货。以及编队打捞/采集看起来没有生效，只按主驾计算」。经办提出实际出勤舰船按各自装配、周期和货仓独立作业、产物进入各自货仓、返港统一卸货，船长答复「确定」。此确认取代此前工业遇袭方案中普通矿带只由主驾采集的范围限制。

## 实施边界

- 仅普通矿带采集（矿石、气体、冰矿）与星系打捞及其出勤返航；复用单舰参数、正式随机源、残骸共享池与实体货仓。共享存档、货仓、换驾驶与页面取数只为本域服务。
- 实际作业名单沿用出发快照，舰船独立计时、采集技能与装备按单舰原规则计算，不额外乘舰队收益系数；打捞只计算实际装配的设备。港内准备名单不能临时加入在途作业，独立AI不参与本队产出。
- 整队同去同返：任一作业舰装不下完整下一轮时按原自动循环规则停工或整队返航；各舰不借用其他舰货仓。返航取全队各舰原有载货比例与航速计算所得的最长时长，燃料按该航段点火一次。
- 自动、手动停止、换驾驶返航都卸实际出勤队；保留在途锁、不提前卸货、不重复入库，不卸港内闲船。旧在途无出勤快照仍只认原主驾。
- 单舰固有的基础采集能力沿用原规则，无采集器不额外禁采；随行舰不复制主驾装备。富矿额外产量受本舰剩余空间裁切，不能超容量。星图每小时产出及打捞设备数读取全队，采矿卡原主驾循环行保留；离线汇总覆盖本趟实际作业队货仓。
- 采矿增加可选逐舰循环/富矿进度，主驾保留原字段；打捞逐设备进度改为舰船、设备序号和周期组合键，兼容旧周期键，存档白名单同步维护。停止或新开作业清理进度，自动周转保留富矿窗口。
- 不改信号空间手动作业、自动探索、独立AI收益、遇袭参数、技能数值、玩家文案或公告；不读取个人存档，不发布桌面版。
