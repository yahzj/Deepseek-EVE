# 手机端换设备：铁人档导入被闸门拒 —— 存档重置 ＋ 模式框加「导入存档」（2026-09-28）

- **状态：已办（待船长验收）**
- **船长原话（照抄）**：「**是手机端玩的，玩家已经将存档发送过来了，是测试存档文件夹的
  save-20260928-230327.json.json。将这个存档的模式选择重置为未选择状态（玩家导入存档后重新选择）。
  可以加入一个'导入存档'入口。**」

## 一、根因（拿真档实证，不是推测）

玩家手机端（网页版）换设备后要用「导入存档」把旧档搬过去，被 **铁人档装载闸门** 拒了。
判据 = `ironmanLoadVerdict`：`阈值 = max(当前档代次, 本机账本代次)`，**来档本身是铁人档** ∧
`来档代次 < 阈值` ⇒ 拒绝（文案 `ui.engine.051`）；唯一豁免是"来档 ≥ 48 小时"的救援。
**代次 = 存盘次数**（每 15 秒一次 ＋ 每个动作后一次）⇒ 他在新设备上"先进游戏、选了铁人"之后，
代次一路 +1，很快就超过了这份旧档的 **6079**。

**实测读数**（`tools/` 临时探针，只读，用完即删）：

| 情形 | 结果 |
|---|---|
| 原样导入（`on: true`、来档 6079、新设备阈值 9000） | **拒绝（阈值 9000）** ← 就是玩家遇到的"无法导入" |
| 重置后导入（`on: false`、来档 6079、新设备阈值 9000） | **放行** |

⇒ 闸门只看"来档是不是铁人档"：**把它降回普通档，闸门整条不适用**（与阈值无关）。

## 二、处置 ①：重置那份存档的模式选择

文件：`docs/test-saves/save-20260928-230327.json.json`（**未跟踪**，原件已备份到 `out/_save-backup/`）。

**定点替换**（只动这一段，其余字节原样；UTF-8 无 BOM）：

```
- "ironman":{"on":true,"seq":6079,"sinceWallMs":1790469860219}
+ "ironman":{"on":false,"seq":6079}
```

- **`sinceWallMs` 必须去掉**：`ironmanModeChosen` = 「曾开过铁人（`on` 或 `sinceWallMs`）**或**已选过普通」
  ⇒ 留着它就等于"已经选过"，模式框永远不再弹、也就谈不上"重新选择"。
- **`seq: 6079` 保留**：它是"曾经到过哪一代"的痕迹；导入后 `syncIronmanHead` 会把**本机账本顶到 6079**
  ⇒ 他这条命的历史代次不丢，之后也回滚不到 6079 以下（对自己这份档的反回滚纪律照旧有效）。
- **`on` 写 `false`**（而不是删掉整块）⇒ 阅读性更好；`on:false + 无 sinceWallMs` 时
  `ironmanOn` / `ironmanEver` 都为假 ✓。
- 真读档器复核：`ironmanOn=false` · `ironmanModeChosen=false`（**模式框会弹**）· `ironmanSeq=6079` ·
  JSON 可解析 · 字节数 499140 → 499113（差 27 = 正好是删掉的那一段）。

⚠ **一个副作用要讲清**：「铁人」**隐藏徽章**的判据 `ironmanEver` = `on || sinceWallMs` ⇒ 重置后
**这段历史的徽章记录没了**；他在模式框里**重新选铁人**之后，`sinceWallMs` 重新写、徽章从那一刻起重新算。
**要"重新选择"就必然丢掉这条记录**（两者的判据是同一个），二者不可兼得 —— 若船长更看重徽章，得改判。

## 三、处置 ②：模式选择框上加「导入存档」入口

`apps/desktop/src/renderer/src/panels/ModeChoice.tsx`：

- 为什么放这里：本框是**强制二选一**（不设关闭键、进游戏之后才弹），而"导入"原本只在游戏内的存档页
  ⇒ 换设备/换浏览器来的玩家**必须先过这一关**才能碰到导入按钮；偏偏**选铁人就开始抬代次**
  ⇒「先进游戏 → 选铁人 → 再导入」这条路必然踩上面那个坑。入口挪到本框 ⇒ 玩家**先导入、再选模式**。
- 复用（不另造同义文案/样式，§6 同级复刻）：按钮 `ui.SaveManager.014`（「导入存档…」）·
  悬停 `ui.SaveManager.013` · 失败 `ui.SaveManager.029`（＋引擎的具体原因）· 成功 `ui.SaveManager.003` ·
  处理中 `ui.SaveManager.017` · 排布 `.app-save-actions`。
- **新增一条说明文案**（待船长审）：`ui.Ironman.044`
  zh「换设备或换浏览器：先导入存档，再选模式。」/ en「Switching device or browser: import your save first,
  then choose a mode.」
- 导入后本框**自动重判**（`App` 按 `engine.modeChoiceNeeded()` 挂载）：新档若已选过模式 ⇒ 本框自动卸载；
  没选过（例如刚被重置过的这一份）⇒ 照常请他选这一次。
