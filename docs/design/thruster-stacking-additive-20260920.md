# 推进器多件：由「EVE 曲线乘算」改为「折权加算」（2026-09-20）

> **状态：进行中**（已实现，四闸门全绿，待船长验收）
>
> **船长原话（照抄）**：「**基础改为加算，但是依旧有多件衰减**」
> 背景 = 我上一条答复里摆出的现象：EVE 曲线 `Π(1+pᵢ·wᵢ)` 对**大额件反而放大**
> （2× 微型跃迁引擎 MK3 合计 **×11.10**，比"全额加算"的 ×6.00 还高）。

## 一、改了什么

| 项 | 旧 | **新** |
|---|---|---|
| 合成式 | `Π(1 + pᵢ × wᵢ)`（`curveMult` · 乘积形） | **`1 + Σ pᵢ × wᵢ`（`weightedSum` · 折权后相加）** |
| 权重 | 100% / 87% / 57% / 28% / 11%…（`stackWeight`，**不变**） | 同左（**多件衰减照旧**） |
| 收敛分组 | `curve`（与命中/跃迁速度/目标锁定同池） | **`weighted`**（与无人机射程中继天线同组） |
| 收敛池 | 全部带 `speedBonusPct` 的已装件（任意槽位，按加成从强到弱排位） | **不变** |
| 生效窗口 | 只在推进器**爆发窗口**（默认 60/60；MWD 10/60） | **不变** |

**代码落点**：`equipment.ts` 的 `stackingOf`（速度 → `weighted`）· `combat.ts` 的 `speedEq = 1 + weightedSum(propSpeeds)`
（原 `curveMult`）· 注释口径同步（`equipment.ts` 头部与分组表 · `combat.ts` · `types.ts` 的
`warpSpeedBonusPct` 条说明"速度已不在这条曲线上"）。**UI 一字未改**——`weighted` 与 `curve` 本来就同一档文案
（「多装递减」＋装配页"第 N 件按权重 %"）。

## 二、改前 / 改后（含 N 件的爆发期速度倍率）

| 装法 | 1 件 | 2 件 | 3 件 | 4 件 |
|---|---|---|---|---|
| 矢量推进器 MK1 (+30%) | ×1.30 → ×1.30 | ×1.64 → **×1.56** | ×1.92 → **×1.73** | ×2.08 → **×1.82** |
| 矢量推进器 MK2 (+60%) | ×1.60 → ×1.60 | ×2.43 → **×2.12** | ×3.27 → **×2.46** | ×3.82 → **×2.63** |
| 矢量推进器 MK3 (+100%) | ×2.00 → ×2.00 | ×3.74 → **×2.87** | ×5.87 → **×3.44** | ×7.53 → **×3.72** |
| 微型跃迁引擎 MK1 (+80%) | ×1.80 → ×1.80 | ×3.05 → **×2.50** | ×4.44 → **×2.95** | ×5.45 → **×3.18** |
| 微型跃迁引擎 MK2 (+150%) | ×2.50 → ×2.50 | ×5.76 → **×3.80** | ×10.69 → **×4.66** | ×15.22 → **×5.08** |
| **微型跃迁引擎 MK3 (+250%)** | ×3.50 → ×3.50 | **×11.10 → ×5.67** | **×26.95 → ×7.10** | **×46.01 → ×7.81** |
| 混装 MWD MK3 ＋ 矢量 MK3 | — | ×6.54 → **×4.37** | — | — |
| 全族五件（MWD3＋矢量3＋幽灵＋MWD1＋跃迁计算机） | — | — | — | — → **×5.12**（旧 ×12.36） |

⇒ **意图达成**：大额件不再被乘积形放大（MWD MK3 四件从 ×46 收到 ×7.8），**但件件递减照旧**
（每多一件的边际收益 < 上一件），总额仍随件数上升。
