# 虫洞盘面：同类地点扎堆的修正（生成器分配前洗牌）· 2026-09-20

> 状态：进行中
> 船长原话：问「**虫洞内相似地点是否会扎堆出现？**」→ 追问后裁定「**按甲来**」（甲 = 分配信号类型前把候选池洗牌）。
> 范围：**只改"哪一格归哪一类"**。各类格数、遗迹/谜质保底、信标不落入口、同种子同盘、空地点分布、
> 残骸 70/30 的逐格掷骰**一律不变**；老档不受影响（盘面随档保存，只有新开的洞用新盘面）。

## 一、诊断（是系统性的，不是随机凑堆）

生成器 `packages/core/src/wormholeGrid.ts` 的 `wormholeMakeGrid`：

1. 挑"空地点"用的是**洗过牌的副本**（`shuffled`，Fisher–Yates）——但那只用来挑空地；
2. 分配信号类型用的 `pool` 是 `others.filter(非空)` ⇒ **保留 `hexDiskCells` 的行优先顺序**（r 从 −R 到 R、行内 q 升序）；
3. 随后按 `order = 舰船 → 残骸 → 资源 → 谜质 → 信标` **逐类连续占位**（`signalOfCell.set(pool[at++], q)`）
   ⇒ 每类信号就是 `pool` 里一段**连续区间**，映射到盘面 = 一条**横向带**；
4. 第 818 行原注释 `poolShuffled = pool // 已按上面洗牌后的相对顺序` **与实现不符**（那次洗牌没作用到 `pool`）。

**修前实测**（600 种子 × 层 1~5 = 3000 张盘；对照 = 同格数随机重排标签）：

| 读数 | 实测 | 随机对照 |
|---|---|---|
| 同类相邻率 | 0.317 | 0.251（**1.26 倍**）|
| 同类平均六边距离 | 2.860 | 3.037 |
| 同行同类连 ≥3 格的盘占比 | **57.0%** | 11.9% |
| 同类 3 格以上六邻连片的盘占比 | 77.4% | 51.7% |
| 最大同行连段 / 最大连片（均值） | 2.96 / 4.98 | 1.81 / 2.84 |

行带也偏：**谜质只出现在 r≥0 的行、矿脉只出现在 r≥−1 的行**（盘上半部分看不见它们）。

## 二、修法（甲案）

`wormholeMakeGrid` 里改为：**分配前把 `pool` 也洗一次牌**，再按原顺序逐类连续占位。

- 用**独立随机流**（`wormholeStream(seed * 7919 + depth * 104729 + 17)`）⇒ 挑空地那次洗牌与后面
  逐格 `pickPlace` 的骰子**一律不受影响**（空地点分布、"残骸 70/30"的读数照旧）；
- 各类**格数**（`quota`，含"遗迹下限借格"之后的结果）一字不变 ⇒ 信号配额、遗迹/谜质保底、信标数照旧；
- 仍然**同 `(seed, depth)` 必得同盘**；
- 原注释那行按实际改写（写明"原先没洗牌"这个根因，防止以后再被"简化"回去）。

**修后实测**（400 种子 × 层 1~5 = 2000 张盘）：

| 读数 | 实测 | 随机对照 | 修前 |
|---|---|---|---|
| 同类相邻率倍数 | **1.012** | 1.0 | 1.264 |
| 同类平均六边距离 | 3.031 | 3.031 | 2.860 |
| 同行同类 3 连的盘占比 | **12.2%** | 11.2% | 57.0% |
| 同类 3 格连片盘占比 | 53.4% | 51.5% | 77.4% |
| 每类地点行跨度 | 全部 −4..4 | — | 谜质 0..4 · 矿脉 −1..3 |

## 三、连带修的三个既有用例（都是被这次修正"激活"的旧脆弱假设）

修正后"舰船信号散在全盘" ⇒ **路径拦截**（2026-09-16：直线路径上有未清掉的舰船信号 ⇒ 截断并开战）
会真的触发，三个用例原先挑格子的方式（依赖"同类成带"这个副作用）随之失效：

| 用例 | 原做法 | 改法 |
|---|---|---|
| `wormhole-grid.test.ts` 信标→出口已知 | 取 `cells` 里第一个非入口格当信标 | 改取**相邻格**（路径为空不被拦）；前往出口前清掉路径上的舰船信号 |
| `wormhole-salvage.test.ts` 走到舰船信号格即开打 | 同上（注释本就写"找一个邻格"，代码没照做） | 改取**相邻格** |
| `wormhole-matter.test.ts` 洞内战斗增益快照 | 前往任意舰船信号格（不确认拦截） | 传 `confirmIntercept: true`（拦截点本身也是舰船信号格，到达即开战，与用例口径一致） |

另新增回归断言（`wormhole-grid.test.ts`）：**同类相邻率对随机对照的倍数 < 1.12** + **同行同类 3 连的盘占比 < 30%**
——把"不再扎堆"钉住，防止日后又退化。
