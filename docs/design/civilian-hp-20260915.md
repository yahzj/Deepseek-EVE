# 非战斗舰血量提档（同档官方战斗舰总血中位 ×0.8）

**状态：已确认**（船长 2026-09-15 四问四答「全取推荐」后落码；本稿为实现记录与口径存档）
**落点**：`packages/data/src/ships.ts`（33 行数值 + 头注）· `tools/content-check.ts`（常驻契约）· `tools/ship-hp-table.ts` + `npm run ship:hp`（读数工具）

## 一、船长原话（照抄）

> **提高所有非战斗舰船的血量，使其约等于同级官方战斗舰船血量的 0.8**

## 二、口径（四问四答，全取推荐）

| 问题 | 裁定 |
|---|---|
| 基准取中位还是均值 | **中位 ×0.8**——不被极端值带偏（T1 鲣鱼 126 拉低均值、T3 玳瑁 910 拉高均值） |
| 三层怎么放大 | **按原比例同乘**，取整余数记入结构层 ⇒ **总血恰好命中目标**（占比关系一字不变） |
| 沙猫（T1 白送船）算不算 | **算**——教学船一起提，避免新手第一艘船仍是"皮薄" |
| 价格 / 货仓 / 槽位 / CPU / 产出 | **一律不动**——本批只改三层血 |

## 三、「官方战斗舰」判据

- 同档 `role` ∈ {`armed`, `armored`} 的玩家舰（含侦察 / 电子 / 重装等子分类）；
- **排除虫洞专属 `sh-wh-*`**（那批是洞内掠夺舰，不属于「官方同级」）。

## 七、零存档迁移（已核）

存档只存**耐久比例**（`durability`）与**装甲比例**（`armorPct`），层满值由 `hullLayerCaps` 从定义现推 ⇒ **老档的船自动按新上限计算**（等价于绝对血量上涨）；**不动存档版本号、不写迁移**。

## 八、护栏与工具

- **常驻契约**：`content:check`「非战斗舰血量契约」——`role` 为 `industrial` / `hauler` 的船，三层总和必须等于本档目标（表 `CIVILIAN_HP_TARGET` 与 `ships.ts` 头注同源，改一处必改另一处）。
  **负向验证**：沙猫 `hullHp` 95 → 96 ⇒ 契约恰好点名 2 艘（沙猫 + 掘洞级，T1 总血 183 ≠ 182），复原即绿。
- **读数工具**：`npm run ship:hp`（`tools/ship-hp-table.ts`）——全船按档 × 角色列三层血 · 各档官方战斗舰的中位 / 均值 / 极值 + 目标核对 · 11 艘现状与"按比例放大建议" · 一口遇袭占比。

## 九、已知取舍与连带

1. 只抬生存、不抬产出 / 载货 / 造价 ⇒ 采矿与运输的经济读数**不变**；
2. 教学与演习场容错变大（沙猫 80% → 100%）；
3. 低安遇袭的"皮薄"威慑下降（T3 以上不再被一口破甲）；
4. 战力 / 胜率预估随血量抬升（预估按血量算）；
5. 已登记的后继可选（船长未要求、本轮不做）：官方战斗舰血量若调整，`CIVILIAN_HP_TARGET` 与本稿中位表需按 `npm run ship:hp` 重算。
