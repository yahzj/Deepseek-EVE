# 侦察舰特性：隐秘行动装置 CPU 减半 ＋ 免推进器失效（2026-09-16）

> **状态：进行中**（工作文档；船长验收 + 合入 main 后按 AGENTS.md §8 归档三步：并入 roadmap ＋ 词典改写 → 删本文件 → 重跑 `docs:index`）

## 一、船长原话（照抄）

1. 「**侦查舰添加特性，隐秘行动装置所需CPU降低50%，且移除推进器失效惩罚。装置限制说明改为：与任何类型推进器一起使用时失效。**」
2. 澄清：「**修改的是隐秘行动装置的限制说明**」（⇒ 那句只是**装置说明文案**的措辞，不是改引擎规则）。
3. 四答：**范围 = 只有「侦察舰」子分类那两艘** · **CPU 取整 = 向上取整（55 → 28）** ·
   **推进器惩罚 = 完全移除** · **展示 = 特性栏 ＋ 装配页标注都要**。

## 二、现状（动手前查的）

- **「侦察舰」是子分类**（`ShipDef.subClass`），**全仓恰好两艘**：**鹦鹉螺级测绘巡洋舰**（`sh-nautilus` · T3 · CPU 340）·
  **幽影侦察舰**（`sh-wh-g-frigate` · T1 · CPU 175）。
- **舰船特性的现行做法**＝**数据字段驱动**（2026-09-16「后勤舰特性」那批从"代码硬判子分类"改成字段
  `repairPulseTargetsFleet` ⇒ 引擎与界面「船体特性」栏同源）⇒ 本特性照此办理。
- **隐秘行动装置现行口径**：任一 `slot: 'propulsion'` 的件在装 ⇒ 隐身窗口判 0（8 件，含微型跃迁引擎）；
  CPU **MK2 55 / MK3 80**；说明里那句原文是「装着推进器时装置直接失效（船一动就藏不住）」。
- **CPU 汇总现无"逐船折算"口子**：`fittedCpuUsed(fitted, ctx)` 只逐件相加 ⇒ 要加一个可选的本船参数，
  装配校验 / 面板 / 战斗建档三处同源。

## 六、待船长复核的一处（我多加了半句，如实登记）

船长指定的措辞是「**与任何类型推进器一起使用时失效**」。我在装置说明里写成
「**与任何类型推进器一起使用时失效（船一动就藏不住）——侦察舰不受此限。**」——
**多出的「——侦察舰不受此限」不是船长原话**。理由：不加这半句，说明对侦察舰就是**错的**
（引擎已豁免），而 §5 要求"游戏内可见文案必须符合游戏设定"。
若船长认为装置说明只该写通用规则、例外只走舰船特性栏，**一句话我删掉那半句**（`modules.ts` 两处，删完即净）。
