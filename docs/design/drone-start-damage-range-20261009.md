# 无人机启动时间、伤害飘字与装配靶场

> **状态：已实现，待船长验收/公告审核/发布**（一号 · main · 2026-10-09）
> 船长原话：「无人机的 ‘首次出击等待’，文本替换为‘无人机启动时间’，并且移除叠加上限。增压加速腔速度上限从+25%提高到+35%。战斗场景内，伤害数字的字体放大，加粗，残留时间延长，如果可以使用skill进行美观优化。在装配界面添加一个进入靶场的按钮，点击后出现一个靶机让玩家测试舰船伤害。」
> 范围/不做：无人机启动效果显示/合成、增压腔峰值、战斗飘字、装配靶场；需确认跨装配/战斗/无人机范围。保留未发布星图UI提交，不自动推送或开展位图素材。
> 批准依据：船长补充「无人机出击加速器的装备文本上写了削减上限」「方案已经确认，查清后开始实现」。查实为fleetDecay提示误套60%封顶；修正说明，不删10ms下限或多件惩罚，不改变全队电子压制封顶。靶场与其他数值/视觉按本方案实施。

## 一、已核对事实

- `droneLaunchGapMsOf`使用船体/旧机库独立乘区、新件同池折权乘法；没有启动削减总额60%硬封顶。`weightedGap`的单件参数最大0.9是输入限制，多件递减具有自然收敛；另有`DRONE_LAUNCH_MIN_GAP_MS = 10`启动时间下限。`WEIGHTED_GAP_FLEET_CAP = 0.6`用于全队电子射程压制，不能为本需求误删。
- 需改显示包括`ui.shipInfo.074/167`、`ui.launchCalibration.001/004`、加速器/机库说明和船体特性；显示改名不自动改变复活入队或武器装填规则，不改装备名称/ID。
- 开工基线增压腔为常驻5%→25%、60秒峰值；本批改为35%，不再有推进器周期。
- 开工基线飘字寿命1500ms、900字重但等宽字体常只有700；本批22px加轻描边、2400ms、同目标九格错位，金额仍来自实收伤害。
- 真实战斗入口与蒙特卡洛评估已有隔离快照思路；靶场可以复用核心计算，不另写命中/抗性/无人机/装填公式。

## 二、推荐方案

### 启动时间

所有对应玩家显示改称「无人机启动时间」，参数行用「无人机启动时间 −{p1}%」，说明用「缩短本舰无人机启动时间，多装递减。」。基础500ms、三型号削减30/35/40%、航母30%、旧机库独立乘区和复活旧规则保持，未要求改装备名称。

船长补充指向装备文本中的削减上限，已查实为详情共用提示误套全队电子压制60%封顶。仅移除错误的封顶说明；保留10ms时间下限、已批准多件递减与乘法，不改全队射程压制60%上限，不改无人机攻击间隔。

### 增压加速腔

保持5%初始、60秒线性爬升、常驻与多装递减，峰值改35%；30秒为20%，60秒后保持35%。CPU30、价格280万、掉落与制造资格不改，相关参数显示由实际数据读取。

### 战斗伤害数字

建议伤害数字逻辑字号22px（不随视口宽度缩放），700~900字重加轻描边/高对比阴影，使现有字体实际看起来更粗；MISS使用较轻的18px灰字。停留1500→2400ms，前段迅速出现，中段清晰停留，末段缓慢淡出/小幅上移，不持续缩放弹跳。

保留伤害属性颜色和同拍同目标合计语义，数字仅显示实收伤害，不夸大数据或改变战斗伤害；同目标相邻飘字采用稳定小范围错位，不能挡住血条/舰名或因延长寿命无限积累DOM。暂不增加“暴击”标记，游戏没有对应判据。保留暂停、倍速与减少动态约束，动画只走transform/opacity，不大范围filter。

技能依据：`ui-ux-pro-max`Number Formatting建议千位分隔/缩写、Contrast Readability要求对比清晰；检索未得到同目标飘字排布的直接规则，该项为本游戏密集齐射场景的工程建议。`review-animations`强调Justified motion、GPU-only properties、减少动态和频率适配；长2400ms是伤害信息寿命，不是菜单操作延迟，短反馈入场仍应迅速，不能机械套用所有UI动画300ms上限。`frontend-design`用于克制排版、与舰体线稿/现有战斗配色一致，不新造霓虹皮肤或引入动画依赖。

### 装配靶场

- 装配目标栏新增图标加文字命令「进入靶场」，测试当前正在编辑的舰船（包括非主控舰），不是无条件改用驾驶船。
- 建立独立本地模拟快照，复制实际技能、舰体、装备、插件、战损和装载无人机，弹药采用当前选择档位，虚拟弹药/维修供给充分；不写玩家真档、不扣库、不磨损、不损失库存、不奖励、不计任务/成就/声望/实战胜率，不暂停或覆盖真实活动。不增加随档字段。
- 默认一个不反击、不移动、零闪避/零抗性靶机，护盾/装甲/结构各10000，可选择测试层；选中层在测试中恢复以便持续观察，实际层位克制保留，不把零抗性等同各伤害系完全等效。
- 提供固定交战距离，默认5000米，数字输入/滑条调整距离；靶机不拉扯交距，便于测射程、近盲与远端衰减。默认60秒，可暂停、重置和退出，重置从无人机启动与首次装填重新计时；改距离可用于观察，不重置已累计账。
- 场景展示船/靶机及真实伤害飘字，旁栏给累计实收伤害、实际累计DPS（包含初始装填/启动等待）、命中次数/发射次数、各武器与无人机贡献。采样按游戏模拟时间，不用动画墙钟伪算；对无法归属的伤害不按名称字符串猜来源。
- 虚拟供给用途明确显示，结果不承诺能打赢同标签敌人；不把悬赏训练任务`ano-training`当新靶场，不进入真实出航/奖励/返航链。没有对应武器的纯货舰可看到无输出状态，不借靶场让非法装备生效。
- 一次只测一艘当前装配舰，不新增编队靶场、敌机防空靶或PVP；退出销毁模拟，打开新场重新读取最新装配。不在运行中偷偷改真实配装。

## 三、文案与范围审批
