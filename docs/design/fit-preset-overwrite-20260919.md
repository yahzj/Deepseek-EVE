# 装配方案「替换」按钮：用当前装配覆盖目标方案（2026-09-19 船长令）

状态：**已实现 · 待船长实机验收**（验收后按 §8 归档：关键结论并入 roadmap/词典、删本稿）
范围：装配方案浮层（`FitPage.tsx`）＋ core 单点（`fitPresets.ts`）＋ 引擎包装（`engine.ts`）
不做：不改"保存/套用/改名/删除"的既有语义；不加方案数量上限；不动存档结构（**零迁移**）

## 一、船长原话（照抄）

> 在装配方案中，给方案加个替换按钮，点击后将当前装配覆盖进目标方案，覆盖之前需要玩家确认。

## 二、落码

| 层 | 改动 |
|---|---|
| core | 新增 `overwriteFitPreset(state, ctx, shipId, index)`：把**当前这艘船的实装**（三类槽位 ＋ 无人机舱装载）写进第 `index` 套方案的**内容**，**方案名与位置保持原样、不新建**；空装配沿用 `captureFit` 的判据拒绝（提示用「一键卸下全部装备」） |
| core 重构 | 把 `saveFitPreset` 里的"采集当前装配"抽成私有 `captureFit()`（保存与替换共用同一把尺，避免两处漂移） |
| 引擎 | `overwriteFitPresetAt(shipId, index)`（成功即落盘 ＋ 通知），与既有的 `saveFitPresetFor` / `applyFitPresetAt` 同形 |
| 界面 | 方案行加「**替换**」按钮（标题提示"用当前这艘船的装配覆盖这一套方案"）⇒ 点击进入**行内两步确认**：`用当前装配覆盖这一套？ ［确认覆盖］［取消］` ⇒ 确认后调引擎并在成功时收起该方案的旧明细（内容变了，下次展开重算） |
| 日志 | 成功写一条 `已用当前装配覆盖方案「X」（船型 · 简报）`（与"已保存装配方案「X」"区分，便于回看） |

**与「保存」的分工**：保存 = 新建一套（或按**同名**覆盖，名字要玩家给）；替换 = 指定那一套直接换内容、不动名字与位置。
