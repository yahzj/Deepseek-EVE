# 网页版：存档「优先保存到本地文件」（2026-09-25）

状态：**已实现 · 待船长验收**（未推送）
船长原话（照抄）：
- 「**存档能否除了浏览器默认存档，优先保存到本地？就很我本地运行一样**」
- 追问两点后裁定：「**按你推荐来**」⇒ ① 做；② 冲突判据 **甲案：按档内 `savedAtWallMs` 取较新**。

## 一、机制

网页版原本只有浏览器存储（`localStorage`），被清站点数据/磁盘紧张清理就会丢（MacBook · Safari 报障那批）。
本批让它也能写**玩家自己选的本地文件**，跟桌面版（`%APPDATA%\whale-idle\save.json`）一个思路：

| 环节 | 做法 |
| --- | --- |
| 绑定 | 设置 → 存储状态 →「**绑定本地存档文件**」→ 系统"另存为"框（默认建议 `大鲸鱼-深空放置-save.json`）→ 句柄存 **IndexedDB**（句柄不能进 localStorage） |
| 落盘 | **双写**：① 先写绑定的文件（`createWritable`）② 再写浏览器存储（保底）；文件写失败 ⇒ 走既有告警（进度不会丢） |
| 启动读 | 文件与浏览器存储**都读**，按档内 `savedAtWallMs` **取较新**（甲案）；读不出时刻的那份视为最旧 |
| 权限 | 浏览器重启后可能收回读写权限 ⇒ 状态显示「需点一次『重新连接』」，点一下恢复静默双写 |
| 解绑 | 删句柄（浏览器存储那份照旧） |
| 不支持的浏览器 | Safari / Firefox 没有 `showSaveFilePicker` ⇒ 按钮**禁用**＋说明（改用 Chrome/Edge 打开本页，或把本页「添加到程序坞」并定期「导出存档」） |

**同产物、不靠构建开关**：桌面端本来就走文件（`window.whale` 无 `saveFile` 这一组）⇒ 界面按 `undefined` 走"本机文件"那支。

## 二、取舍（明说）

- 首次绑定**必须玩家点一下**（浏览器安全要求，网页不能自己建文件）；绑定后才是"静默写同一个文件"。
- 那句"优先"= **双写 ＋ 取较新**，不是"只写文件" ⇒ 换浏览器/多设备仍能各自继续玩。
- 每次落盘两次 IO（15 秒一拍，成本可忽略）。
- **Safari 做不到**（没有该 API）：那位 MacBook 玩家要么换 Chrome/Edge，要么靠「导出存档」＋告警；
  Safari 侧唯一能改善持久性的是把本页「添加到程序坞」（成为已安装的网页应用后不再受 7 天清理）。
- 「权限被收回」那条路径**无头浏览器构造不出来**（OPFS 句柄恒为 granted）：代码路径写了、
  界面有入口，但真机验证要等真实浏览器重启后由玩家/船长复测。

## 三、实测读数（`npm run save:webfile-check`；假扮"另存为"对话框返回**真 OPFS 句柄**，其余全走真代码）

| # | 情形 | 结果 |
| --- | --- | --- |
| ① | 未绑定 | 状态行「…· 本地文件 未绑定」；落盘只写浏览器存储；**不碰文件**（文件不存在） |
| ② | 点「绑定本地存档文件」 | 状态行「本地文件 whale-save.json · 已连接」＋提示条「已绑定本地存档文件：whale-save.json」；当场把当前存档写进文件（时刻一致） |
| ③ | 再落一次盘 | **文件时刻 = 浏览器存储时刻**（双写成立） |
| ④ | 文件塞入"更新的"档（哨兵钱包 111,222,333，`savedAtWallMs` +60s）⇒ 重载 | 界面钱包 = **111,222,333** ⇒ 读到的是**文件**那份 |
| ⑤ | 文件塞入"更旧的"档（哨兵 999,888,777，`savedAtWallMs` −120s）⇒ 重载 | 界面钱包**不是** 999,888,777 ⇒ 浏览器那份获胜（甲案） |
| ⑥ | 点「解绑」 | 状态行回到「本地文件 未绑定」；此后落盘不再改文件 |
| ⑦ | 没有 `showSaveFilePicker`（Safari/Firefox 那种） | 按钮**存在但禁用**；状态行给出说明；游戏仍以浏览器存储正常运行 |

另：上一批的 `npm run save:guard-check`（不给写存储 / 旧档读不出来 / 放行写入）**回归复跑全过**。

## 六、给玩家的用法（请转达）

1. 用 **Chrome / Edge** 打开网页版 → 设置 → 存储状态 → 点「**绑定本地存档文件**」→ 选一个位置
   （建议「文稿」目录），之后每次落盘都会写进这个文件，浏览器数据被清也能从这个文件恢复；
2. 换过浏览器或过很久再打开，若显示「需点一次『重新连接』」，点一下即可；
3. **Safari 玩家**：本浏览器不支持直接写文件 —— 请改用 Chrome/Edge，或把本页「添加到程序坞」，
   并养成定期点「导出存档」的习惯。
