## 3. 实现（改动清单）

- `apps/desktop/src/renderer/src/panels/BattleScreen.tsx`
  - **新增顶部读数区** `.app-bts-topdock > .app-bts-dock`：倍速 → 图例 chip → 装填冷却平铺（原样搬，零改写）；
    放在页头之后、战场之前 ⇒ **不参与等比缩放**（口径同 2026-09-26 船长令）。
  - **距离尺整条搬到底栏**，与拖动条合成**距离轴** `.app-bts-axisRow`：尺的标记一字未动
    （双方速度 / 远端·近端 / 刻度 ＋ 双方射程带 ＋ 当前距离游标与米数）；
    原 `<input type=range>` 改挂 `.app-bts-knob` **绝对定位叠在刻度上**（`.app-bts-axisTrack` 里），
    **拖动逻辑一字未动**（rAF 合帧 ＋ 160ms 节流提交，连 2026-09-13 那两条注释一并带过来）。
  - **删除**旧的 `.app-bts-sliderRow`（左右"拉开/贴脸"标签、`app-bts-here` 当前距离小竖条）——
    刻度上的游标＋米数 chip 就是"当前距离"这一读数的唯一出处，不再画两遍；
    `ui.BattleScreen.070`（当前实际距离）改挂到游标本体，不再悬空。
  - **无障碍挪位**：`role="img"`／`aria-label`（`ui.BattleScreen.112`）从整条尺挪到**刻度**上——
    拖动旋钮是叠在刻度上的真控件，`role="img"` 留在外层会把它一起吞掉（读屏不可达）。
- `apps/desktop/src/renderer/src/ui/layout-css/styles-{classic,modern}.css`：`npm run ui:layout-css` 重新生成。
- `apps/desktop/src/renderer/src/styles.css`
  - 新增 `.app-bts-topdock` · `.app-bts-axisRow` · `.app-bts-axisTrack` · `.app-bts-knob`（轨道透明、金色抓手）；
  - `.app-bts-ruler` 从"自己 clamp 宽 + 居中"改为 `flex: 1`（宽度由底栏分配）；
  - 删死代码：`.app-bts-here` / `.app-bts-sliderRow` / `.app-bts-sliderWrap` / `.app-bts-sideLabel` 四条规则
    与三处 transition 选择器里的 `.app-bts-here`；
  - 手机（`is-mobile-rot`）那批跟着改：滑条行/容器两条随合并删除、轴行沿用放大间距、
    **旋钮轨道在手机上强制透明**（否则那根 12px 渐变轨道会盖住刻度）、`≤640px` 的
    `min-width: 680px` 只留给车道（距离尺已不在舞台上，不能再按"标尺与车道同一滚动容器"假设写）。
- `tools/ui-battle-fit.ts`（正式工具，随版式更新读数口径）：页面上现在有**两个** `.app-bts-dock`
  ⇒ 「读数的底栏」改成显式选 `.app-battle-controls .app-bts-dock`，并**新增顶部读数区列**与
  "读数区不裁内容"判据（原来 `querySelector('.app-bts-dock')` 会量到顶部那块）。
