## 推荐第一批：C01＋C08

1. 主进程的主档保存、恢复、备份进入同一 FIFO 操作队列；快照入队即固定，失败传播且不会毒化后续队列。唯一临时名只解决路径冲突，不能替代 FIFO。
2. 盘外账本自身读改写串行，保存应等待该事务的账本处理。账本失败继续沿既有降级政策，不默认让已提交的主档回滚或不可保存；明确标注降级，避免把原先“账本失败不阻断”静默改成整场失败。
3. backupNow 必须检查 persist 结果，false 时不调用备份。并核对并发动作后备份究竟对应哪份快照，不能仅把布尔检查当完整事务。
4. 依赖可注入，新增修复前为红的保存交错、保存/恢复并发、失败后恢复、账本回执、备份失败与正常路径测试；真实文件测试仅使用自建临时目录。
5. 只改保存域与必要桥接，保留外部 API，不重构整份 GameEngine；不改存档字段、救援条件、铁人奖励或全部离线时间轴。
