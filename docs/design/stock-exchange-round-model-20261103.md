# 股市 · 回合制行情与撮合模型（5 分钟一轮，可配）

> 状态：设计已定（船长 2026-11-03：「tick 不用那么严格，做成 5 分钟（可调）同步一次；玩家 5 分钟内操作买卖 10 次，批量挂单给服务端；服务器压力小一点」）
> 影响：替换原「1 秒 tick / 连续撮合」口径；Go G1 与前端刷新节奏按本文修改。

---

## 结论先行

1. **回合制**：全服统一回合时钟，默认 **300 秒一回合**（`WHALE_EXCH_ROUND_SEC`，可调）；回合边界对齐 Unix 纪元（`:00/:05/:10...`）。
2. **每回合流程**：`开放接收 → 锁定（默认提前 10 秒）→ 批量撮合 → 结算/广播`；回合内玩家可随时提交委托，但**统一在回合末撮合**。
3. **玩家配额**：每账号每回合最多 **10 笔**买卖（`WHALE_EXCH_ROUND_MAX_ORDERS`，可调）；前端本地排队计数，超限禁止提交。
4. **前端节流**：大盘数据与账户**每回合刷新一次**（不再 1 秒轮询/推送）；回合内价格不动，只更新本地排队单与倒计时。
5. **撮合方式**：回合末做**批量集合竞价**——同一标的所有买卖单集中撮合，产生**单一成交价**（最大成交量原则，平局取参考价最近）；未成交限价单默认**本回合有效**（不跨回合），除非后续加「跨回合 GTC」。
6. **K 线**：基础周期 5 分钟（每回合一根）；前端 1m 周期由 5m 数据前向填充（回合内价格不变），5m/1h 正常聚合。
7. **服务器压力**：每标的每 5 分钟只撮合一次；WS 每回合广播一次；AI 人格每回合决策一次。
8. **回合制反而更公平**：所有玩家同一价格成交，消除「网速快的人抢单」；同时更贴放置游戏节奏。

## 一、回合状态机

```
ROUND(t) ──开放接收（0~290s）──▶ 锁定（290~300s，拒新单）──▶ 撮合（<1s）──▶ 结算+广播 ──▶ ROUND(t+1)
```

- `roundNo = floor(now / roundSec)`；`nextRoundAt = (roundNo+1) * roundSec`。
- 锁定窗口内提交 → 返回 `409 round_locked`，前端提示「本回合已锁定，下回合可提交」。
- 撮合失败/异常：本回合撤销全部委托、资金解冻，记录 `round_abort`，下回合继续（宁可不成交，不产生脏数据）。

## 二、接口变更（相对 G0/G1）

| 接口 | 变更 |
|---|---|
| `GET /api/exchange/round` | 新增：`{roundNo, startedAt, nextRoundAt, locked, maxOrders, usedOrders}` |
| `POST /api/exchange/orders` | 改为「提交进本回合队列」，立即返回 `status:"queued"`，不回撮合结果 |
| `POST /api/exchange/orders/batch` | 新增：一次提交 ≤ 剩余配额的多笔委托（前端批量） |
| `GET /api/exchange/orders` | 返回本回合排队中 + 历史委托（含 `queued/filled/cancelled/expired`） |
| `DELETE /api/exchange/orders/{id}` | 仅回合开放期内可撤（锁定后拒绝） |
| `GET /api/exchange/stocks` / `book` / `trades` / `klines` | 内容为**上一回合收盘快照**；回合内不变 |
| WS `/api/exchange/stream` | 每回合结束广播一次：`stocks`（新价）、`book`（新盘口）、`trades`（本回合成交）、`account`/`orders`（本人变化）、`round`（新回合号）；回合内只心跳 |
| `/api/exchange/meta` | 增加 `roundSec`、`maxOrdersPerRound` |

- 配额 `usedOrders` 按**已提交委托数**计（撤单不返还配额，防刷）；可调。

## 三、撮合算法（集合竞价）

1. 收集本标的全部买单/卖单（价格优先，价格相同按提交时间优先）。
2. 候选价 = 所有限价单价格（含市价单按保护价映射）；对每个候选价计算可成交量，取**成交量最大**者。
3. 平局：取与上一回合收盘价最近者；再平局取较低价（对买方有利）。
4. 成交分配：按价格-时间优先依次成交，成交价统一为候选价；市价单以候选价成交，剩余撤销。
5. 冻结/解冻：提交时冻结资金/持股；未成交部分在回合结算时解冻（限价单本回合有效）。
6. 禁自成交：同一账号买卖单在竞价中互相跳过（不成交）。
7. 记录 `roundNo` 于订单/成交，审计可回放。

## 四、前端节奏

- 进入股市页：拉 `/round` + 全量快照；显示「距下回合 mm:ss」。
- 回合内：本地排队（最多 10 笔），可撤可改；点「提交本回合」批量发送，或循环自动提交。
- 回合结束：收到 WS `round` 事件 → 刷新全量数据 → 更新持仓/盈亏/成交。
- 断线重连：重连后拉 `/round` + 快照，合并本地未提交队列；已提交未撮合的以服务端为准。
- 行情图：5m K 线，每回合追加一根。

## 五、可配置项

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `WHALE_EXCH_ROUND_SEC` | 300 | 回合长度（秒），服务端下发前端 |
| `WHALE_EXCH_ROUND_LOCK_SEC` | 10 | 回合末锁定窗口 |
| `WHALE_EXCH_ROUND_MAX_ORDERS` | 10 | 每账号每回合委托上限 |
| `WHALE_EXCH_ROUND_ORDER_TTL` | 1 | 委托存活回合数（1=仅本回合） |

## 六、对 AI 人格的影响

- 人格每回合决策一次（读上一回合盘口/成交，产生本回合委托），与玩家同规则、同撮合。
- 做市人格：每回合双边报价（跨回合挂单需 TTL>1，见后续）。
- 事件/逼空按回合推进，快讯随回合广播。

## 七、验收

1. 回合时钟对齐：客户端与服务端 `roundNo` 一致，倒计时误差 < 1s。
2. 配额：第 11 笔被拒；锁定窗口提交被拒；撤单不返还配额。
3. 竞价：多买卖单产生单一成交价；无交叉则不成交；自成交跳过；未成交解冻。
4. 压力：4 标的 × 100 并发玩家，回合撮合耗时 < 50ms；WS 每回合 1 次广播。
5. 断线/重启：回合中重启 → 未结算委托恢复（或按 `round_abort` 撤销并解冻），资金不丢。
