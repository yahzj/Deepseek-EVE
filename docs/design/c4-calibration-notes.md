## 触发

船长实测（v18b 战斗档）反馈："战斗基本没问题，但数据极度不平衡"，随后给出两点具体体感：
1. **敌我射程对比失衡**：后期我方射程极高（动能 MK3 10.5 km / 导弹 12.4 km / 激光 13 km），
   而最高级悬赏敌人依旧"手短"（敌方战术射程带封顶 brawl 2.2 km / orbit 4.6 km / kite 9.2 km）
   → 后期可在敌射程外风筝白嫖；
2. **高级船血量过少（含高级敌人）**：玩家 T1 矿船 23 hp、T4 旗舰货舰仅 98 hp（玄武重装 261 最高）；
   敌方血量 = threat × 2.6（threat 96 目标总血仅 ~250）、敌 dps = threat × 1.1 → 秒杀局。

## 探针矩阵发现（tools/_cal-probe 已删，脚本模式见下）

- 胜率随威胁**非单调悬崖跳变**（如隼枭+动能MK3：threat 40→52%、42→22%、45→3%、52→12%）——威胁标注不可信；
- 支援件（V18.1）超模：虎鲨双动能+满支援在多数威胁 90+%，巨灵鲸+满支援 26 档威胁全 98%；
- 技能满（炮术5×族技能5）叠加后中低威胁通吃；
- 裸船（基础舰炮）threat 6 = 50%，但 threat 10/12 即 5~12%——入门悬崖；
- 激光面板偏强（必中 + 最高面板 DPS 5.0/8.4/9.5）。

## 校准草案（数值要点，恢复后需重新确认）

- 目标帧：同级战斗 30~50 s；胜率随威胁单调；射程对位（敌 ≈ 挑战者武器射程）；裸船可打 threat 6。
- 敌方射程随威胁成长：`战术带 × (1 + (threat−10)/90)`（threat100 → ×2.0；kite 9.2 → 18.4 km 等）。
- 血池放大：ships.ts 三层血量 ×3；`foeHpPerThreat 2.6 → 7.8`；`foeDpsPerThreat 1.1 → 0.8`。
- 激光降档倾向：MK2 3.0→2.7、MK3 4.2→3.8、proto 5.1→4.7（必中溢价收敛）；动能/导弹暂不动。
- 支援件回调：待矩阵复核后单独提案（倾向索敌 0.16→0.13、稳定 0.15→0.12 档）。
- 工具：battle-calibrate 升级 V18 形状（三族×MK×支援×技能×全威胁 + 单调性/悬崖检测）。
