# T4 采矿换船与显式行程（状态：已确认）

> 🔁 2026-09-05 语义更新（船长定稿：取消启程段）：采矿**下达即视为已抵达矿带、立即开掘**（无"出航"相位）；
> 空船去程时间**并入返航腿**（返航 = 原返航单程 + 原去程单程，自动循环每趟总行程时间不变）；
> 旧档遗留 outbound 相位仍按原腿推进兼容。详见 roadmap 变更记录。

> 来源：船长测试反馈单 T4（roadmap 置顶，批次 B）。2026-09-04 经两轮问答+设计总结确认后实现。
> 关联：`docs/roadmap.md` T1–T11 清单、`docs/architecture.md` 里程碑表。

## 需求与确认口径（两轮）

- 原句：采矿作业中可切换舰船（重置本轮进度并按新船计算）；前往矿带/返航作显式行程
  （时间与悬赏一致展示）；空间站本地矿带也安排（可较短的）前往/返航时间。
- 首轮问答确认：Q1甲 采矿页"换船重采"（闲置船接管、完整重跑）；Q2甲改良 旧船按原定计划
  自动返航（活动栏倒计时，到港自动整仓卸入物品仓库）；Q3甲 前往矿带显式化（本地也走）；
  Q4 数值因实测影响过大中途停下让船长重定。
- 数值定稿（船长）：① 所有矿船新特性——**空船出门跃迁速度×2**：出航（前往）单程 = 满载
  返航单程的一半；满舱回城按正常速度；② 本地基准单程 = **120 秒**（≈本地：出航 60s / 返航 120s）。
- **延后项（边界2）**：远征中采矿/采矿中远征的互斥解除（远征中选择采矿 = 取消远征并从
  当前位置计算路程前往矿带）——船长指示延后，随后续星图相关改动一并处理，本批不实现。

## 规则改动

### 1. 显式"前往矿带"行程（主控与 AI 副船同源）
- 点开采先进入 `出航（前往矿带）` → 到带才开始采掘；满舱自动循环照旧（返航→卸货→再出航）。
- **腿分方向（T4 定稿）**：
  - `oneLegMs` = 满载/返航单程 = 进出港基准 120s（`balance.mining.localLegMs`）+ 星系航程
    （按该船跃迁速度+航行技能，travel.ts）；
  - `oneOutboundLegMs` = 空船出航单程 = 正常腿 ÷ 2（本地 60s；调试模式两者均固定 1 秒）；
  - 主控 `advanceMining` 与 AI 采矿推进都按方向取腿；进度/剩余/百分比按当前阶段实际腿显示。
- 活动条与矿带卡：出航/返航阶段显示精确剩余（"前往矿带 · 剩 X" / "返航卸货 · 剩 X"）。
- 附带改进：远处矿带首次前往到港即点亮星系（此前首轮不点亮、靠返程才补）。

### 2. 换船重采 `switchMiningShip`（采矿页新控件）
- 候选 = 闲置船（非驾驶、无 AI 任务、不在善后返航）且能执行当前矿带作业（有舰船数据）；
- 执行后：① 作业立即重置；② 旧船入 `shipReturns` 账本自动返航——采掘中（在带）走完整
  返航腿；返航中继续剩余；出航中折返（空船速度×2 → 折算为已走 2×空船时间）；③ 新船成为
  驾驶船，按自己的跃迁/循环/货舱参数完整重跑（含显式前往）。
- 返航账本到港 → 整仓卸入物品仓库 + 日志；账本在活动条显示倒计时（不可终止）。
- **守卫**：返航中的船不可选为换船目标/派 AI/出售/切驾驶；主控采矿中"舰队切驾驶"拒绝并
  提示走换船重采（shipyard.changeShip 文案更新）；`market.shipSellable`/`idleAiShipIds` 同步。
- 手动"停止开采"维持原语义（停在哪算哪、货随船，不触发自动返航）——船长确认的边界 1。

## ⚠ 更新（2026-09-04 船长真档回归后推翻）

- **取消「换船重采」**：不再需要在采矿页选船重采；采矿作业中直接到「舰船」页切换驾驶即可成功，
  旧船按当前阶段自动返航卸货（shipReturns 善后账本，活动栏倒计时），采矿作业随之结束（不自动续采）；
- 实现：核心善后逻辑移入 `shipyard.retireMiningShip`（changeShip 采矿分支调用；腿与折算口径见
  `location.miningReturnLegMs`）；采矿页换船控件与 `switchMiningShip` 已删除；新船不再自动接续矿带作业。

## ⚠ 更新（2026-09-04：T4 延后项完成——船长定稿转场语义）

- **远征 ↔ 采矿互斥解除（确认口径）**：采矿中点悬赏「出击」= 转战——警告（含当前驾驶船型提示，
  防"开着战斗船挖矿"误操作）→ 确认后采矿终止（同手动停止：货随船、进度清零），
  远征从**矿带所在星系**出发（本地矿带 = 母港；异地矿带立即转战）；远征中点矿带「开始开采」=
  转场——警告 → 确认后远征取消（**交火中除外**：须先打完或撤退），连击同步停止（若由连击发起），
  采矿照常从母港/空间站出发；两者均为两步确认。
- 实现：core 新增 `startExpeditionFromMining`（expedition.ts）与 `startMiningFromExpedition`（mining.ts）
  两枚转场入口——**原 startMining/startExpedition 的互斥拒绝保持不变**（连击/自动路径不被污染），
  共用抽取的 `expeditionPreflight` / `miningPreflight` 前置检查（预检失败不动原作业，可安全回滚）；
  UI：悬赏卡「转战出发」（含驾驶船名/船型提示）、矿带卡「再点确认开采」（含远征取消/连击停止提示）。
- 测试：t4.test.ts 新增 7 组转场用例（本地/异地矿带出发点、预检回滚、回落普通行为、连击停止、交火拒绝）。
