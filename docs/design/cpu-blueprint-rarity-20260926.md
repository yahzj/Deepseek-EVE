## 一、先说清一处实情（改前实测）

**这两张蓝图本就在库里**，不是缺件：
- `packages/data/src/blueprints.ts` 有 `bp-cpu-1`（协处理器 MK1 蓝图 · 书价 776,000 · 材料≈产物价×0.45）与
  `bp-cpu-2`（MK2 · 书价 4,850,000）；都是**永久蓝图**（非一次性）。
- `marketCatalog.ts` 两条**稀有订单行**都在（`rarity: 'rare'`，无声望门槛），`content:check` 的「未上线闸门」
  也确认它们对玩家可见。
- 它们与产物**同档**：`mod-cpu-1` = 档 2 / `bp-cpu-1` = 档 2；`mod-cpu-2` = 档 3 / `bp-cpu-2` = 档 3。

**全仓惯例**（本轮探针实测 129 张装备蓝图）：蓝图档 − 产物档 = **同档 121 张** · 差 +1 六张
（重型炮台/激光/导弹 MK2 与三系稳定器 MK2）· 差 −1 两张（`bp-hullrep-1` / `bp-shieldchg-2`，即既有"书价漂移预警"户）。

⇒ 本条令的实际落法 = **把这两张图的稀有度各上调一级**。

  档 4 在稀有订单里有既有先例（那 5 艘巡洋舰）。
