> 船长 2026-09-05 需求：模拟真实玩家从零开始玩到通关（挖矿/制造/市场/技能/战斗全链），寻找 BUG。

> 工具：`tools/playthrough-sim.ts`（主仓库入库；副本同步运行），运行 ~1-6 分钟/次（debugQuick 模式）。

## 一、怎么跑

```powershell
# 副本（推荐，隔离二号改动）：先把副本同步到目标基线
cd H:\大鲸鱼\Deepseek-EVE-verify
npx tsx tools/playthrough-sim.ts --max-days 80 --seed 20260905 --report report.txt
```

参数：`--max-days N`（默认 60）· `--seed N` · `--real-training`（关闭 debugQuick 用真实训练时长）· `--report 路径`。
默认 debugQuick：技能 1s/级、扫描 1s、制造 1s——聚焦**系统链一致性**；数值平衡归二号 C4，不在本工具范围。

## 二、模拟玩家策略（内置 AI 决策）

1. 技能：全部 62 技能按组顺序练满 5 级（覆盖训练/连锁/效果接线全表）；
2. 采矿：按矿带价值排序、声望与探索可达者优先（单趟制，回港结算）；
3. 市场：卸货 → `marketSellHolding` 市价卖（保留矿物 120/矿石气冰 150 供精炼制造；**弹药/无人机/装备不卖**——踩坑教训 2026-09-05：早期版把买来的武器弹药当持有卖掉造成"战力黑洞"）；
4. 精炼（pilot 限频 6h/轮）+ 蓝图（市场买书 → learn → 制造一件，每图一次防抽血）；
5. 换船配装：白送隼枭→按 powerBonus 梯度买更高档武装舰（已拥有去重 + 每日限一次）；高槽动能炮按钱包逐档（kin-1→3），中盾低甲 + 支援件 + 弹药/无人机补给；
6. 远征：只打未首胜目标推声望（重复打无声望是机制）；打不过→farm 最高收益可赢目标刷钱升装；
7. 探索：frontier 逐跳扫描点亮全 20 星系；AI 副船采矿 5 名额；遭遇/随机事件由引擎自动推进。
