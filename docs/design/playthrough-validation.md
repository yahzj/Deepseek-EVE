> v1.1（二号，2026-09-05）：目标制 + B3 打捞回收闭环，详见第七节。

## 一、怎么跑

```powershell
# 副本（推荐，隔离二号改动）：先把副本同步到目标基线
cd H:\大鲸鱼\Deepseek-EVE-verify
npx tsx tools/playthrough-sim.ts --max-days 80 --seed 20260905 --report report.txt
```

参数：`--max-days N`（默认 60）· `--seed N` · `--real-training`（关闭 debugQuick 用真实训练时长）· `--report 路径`
· `--goal boss|tril|collect|all`（v1.1：可逗号组合；boss=通关连打 5/5、tril=现金 ≥1 万亿、
collect=全收集（全舰船+全可造蓝图+全装备）；默认 boss 保持 v1.0 语义）·
`--snap-days N`（v1.2：资产/战斗力增长快照间隔游戏天，默认 real 1 / debug 0.02；见第八节）。
默认 debugQuick：技能 1s/级、扫描 1s、制造 1s——聚焦**系统链一致性**；数值平衡归二号 C4，不在本工具范围。

## 二、模拟玩家策略（内置 AI 决策）

1. 技能：全部 62 技能按组顺序练满 5 级（覆盖训练/连锁/效果接线全表）；
2. 采矿：按矿带价值排序、声望与探索可达者优先（单趟制，回港结算）；
3. 市场：卸货 → `marketSellHolding` 市价卖（保留矿物 120/矿石气冰 150 供精炼制造；**弹药/无人机/装备不卖**——踩坑教训 2026-09-05：早期版把买来的武器弹药当持有卖掉造成"战力黑洞"）；
4. 精炼（pilot 限频 6h/轮）+ 蓝图（市场买书 → learn → 制造一件，每图一次防抽血）；
5. 换船配装：白送隼枭→按 powerBonus 梯度买更高档武装舰（已拥有去重 + 每日限一次）；高槽动能炮按钱包逐档（kin-1→3），中盾低甲 + 支援件 + 弹药/无人机补给；
6. 远征：只打未首胜目标推声望（重复打无声望是机制）；打不过→farm 最高收益可赢目标刷钱升装；
7. 探索：frontier 逐跳扫描点亮全 20 星系；AI 副船采矿 5 名额；遭遇/随机事件由引擎自动推进。

## 六、策略黑洞：记录与解救（船长 2026-09-05 定）

> 船长口径："策略黑洞依旧需要记录和报告（模拟玩家弱智行为不算引擎 bug，但要看见）；不过当 AI 陷入黑洞过久、影响测试时长时，需要将其解救。"

- **记录**：报告单列「策略黑洞记录」段（触发天数/形态/解救动作），与「异常（引擎 warn/断言）」分开——黑洞 ≠ 引擎 bug；
- **侦测**：主线推进指纹 = 新首胜数/点亮星系数/驾驶船/现金粗桶（500 万级），纯赚钱波动不算推进；连续 6 天无推进 = 黑洞；
- **分级解救**（每 3 天冷却、逐级升级）：
  - L1：召回作业 + 清仓变现（矿/气/冰全卖，弹药/无人机/装备保留）+ 归位采矿；
  - L2：注资（80 万 + 现金 50%）用于升级船与武器；
  - L3+：再注资 200 万维持观察；
- **终局受阻判定**（防 60 天空转 farm）：训练毕业（62 技能满）+ 顶配武装（≥3 门武器）+ 声望解锁 + 星系全亮后仍 10 天打不过 boss（胜率 <85%）→ 记录黑洞并**提前终止**，报告标注"疑似平衡项，转 C4 复核"（当前基线触发：顶配大白鲨级×5 门对穹顶守卫 67%，第 11.06 天终止，墙钟 ~8s 出结论）；
- 模拟器自身策略缺陷（买错卖错重复买等）不入 bug 清单，但黑洞记录可见它们何时发生、困了多久。

## 七、v1.1：目标制 + B3 打捞/回收闭环（二号 2026-09-05，船长拍板）

**新增目标**（`--goal`，默认 boss 不变）：
- boss：终局悬赏连打 5/5（原通关语义，保留终局受阻黑洞提前终止）；
- tril：现金 ≥1 万亿 ISK（debugQuick 只压缩等待、不放大收益，属超长程探针目标，报告会注明预期未竟）；
- collect：全舰船 19/19 + 全可造蓝图（市场有书可购口径 12/12）+ 全装备（市场可购 75/75）。

**B3 行为接入**：AI 打捞任务（采矿名额轮换 + 现场补装打捞器，单趟自动返港）+ 主控低频打捞会话
（≥0.5 天一次）+ 残骸回收炉（优先 AI 核心驱动，核心不足自动买）——五个打捞/回收技能的乘区
随真实作业被反复触发（整备/漂流物/富集识别走打捞，回收/提纯走炉）。

**模拟器自身缺陷修复记录**（引擎无恙，属策略层；按纪律记录去向）：
1. `missingMaterials` 返回人话提示却被当数据结构用（m.itemId/m.count 从不买料→制造永不启动）→ 改按蓝图定义补料；
2. 卖货保留量固定 120，把刚买的造件材料又卖回市场 → 按「当前待造蓝图」动态保留；
3. useFreeFalconet 每回港强切回白送隼枭 → 升级船白买、终局战力被封顶（顶配 68% 假黑洞）→ 改「空闲换驾舰队最强武装/装甲船」；
4. AI 采矿是无限循环任务、名额不释放 → 打捞 0 次 → 每天至多召回一艘采矿船轮换 + 空闲船现场补装打捞器；
5. doRefineCraft 会无限重复制造同一张已造蓝图 → 制造统一并入 doLearnCraft（每图一件）；
6. 回收炉用 pilot 驱动会长期锁死主控（扫描/远征/收集全卡）→ 优先 AI 核心驱动 + 自动补买核心；
7. 审计口径：B3 乙案残骸计数=体积可为小数 → audit 对残骸类放行小数（其余仍强制整数）。

**验证结果**：种子 20260905/1/42 × boss（80d）+ 种子 1/42 × all（60d）全部 **0 引擎异常**；B3 活动量级见上表。
**副本同步备忘**：GitHub origin 落后主仓（未推送），副本加 `mainlocal → H:\大鲸鱼\Deepseek-EVE` 远端，
