## 六、踩坑（接手别再踩）

1. **🔴 不要动其他人的工作区**：`d2` / `verify` 只读。本会话最严重的教训 —— 在 verify 里 `reset --hard main`
   清掉了**已暂存**的在途改动（当时误判"工作区干净"）；所幸三号那一刻**已经提交**（`4b3f68b0`，父提交正是 main），
   从对象库确认后恢复并合入 main。**改任何树前必看 `git status`：已暂存 ≠ 干净。**
2. **CRLF-blob 陷阱**：个别文件在库里是 **CRLF blob**（`Expedition.tsx` 曾如此、`l10n/table.ts` 亦然）；
   用 LF 写回会产生"整文件重写"式 diff。落盘前先 `git cat-file blob HEAD:<path>` 量行尾，
   必要时按 blob 行尾写（`-c core.autocrlf=false` **不足以**绕 `.gitattributes` 的 `text=auto`，需 plumbing）。
3. **PowerShell 的 `-match` 会覆盖 `$Matches`**：解析 tsc / git 输出时先把需要的捕获组取出来，再做第二次匹配。
4. **临时探针**：`_` 前缀、用完即删（本会话删了 4 个）。源码文本普查/切接用 ASCII 锚点 ＋ .NET 显式 UTF-8。
5. **数行数**：用 `(Get-Content <file>).Count`，别用 `Measure-Object -Line`（对字符串数组不是行数）。
