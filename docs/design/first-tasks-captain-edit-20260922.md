## 四之二、市场交易判据放宽（船长 2026-09-22：「第一次挂单允许玩家挂买单或者直接市价购买卖出都算完成」）

- **判据本身不变**（仍是 `firstStats.orders ≥ 1`；键名与存档形状都不动）——**放宽的是"哪些动作算一笔"**：

  | 动作 | 落点 | 本轮变化 |
  |---|---|---|
  | 挂卖单 | `placeSellOrder` · 界面 `listSellHolding`（物品/整船两条）· `placeShipSellOrder` · `placeStoredShipSellOrder` | 原样（界面那条是 09-20 补的） |

  | **市价卖出** | `sellAtMarket`（物品页「市价卖出」也走它）· `sellStoredShipAtMarket`（整船） | **新增记账** |
  | **市价买入** | `buyAtMarket` | **新增记账** |

- **单点**：`market.bumpFirstMarketTrade(state)`——四条路**互不嵌套**（逐条核过调用图：
