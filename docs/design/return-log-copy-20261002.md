## 2. 现场取证（**先看同族怎么写，再动手** · whale-copy §0 第 2 步）

同一函数 `advanceShipReturns`（`packages/core/src/mining.ts`）下的**既有已批准**同族文案：

| id | 中文 | 与本次 6 条的关系 |
|---|---|---|
| `core.mining.031` / `.032` | {p1} 已随**远征善后**返航到港：货仓已卸入物品仓库（{p2} 单位）。／（货仓为空） | **善后族**——`.038`~`.041` 是它的逐字克隆（`善后` → `停止`） |
| `core.mining.033` / `.034` | {p1} 已随**打捞善后**返航到港：残骸已卸入物品仓库（{p2} m³ 当量）。／（货仓为空） | 同上；⚠ **打捞的善后文案本来就挂 `core.mining.*` 前缀** |
| `core.mining.035` / `.036` | {p1} 已返港并卸货（换船善后）…／{p1} 已随换船善后返港（货仓为空）。 | 换船族（`.036` 用「返港」，与「返航到港」并存） |
| `core.salvaging.017` / `core.shipyard.019` | 打捞/采矿已随**换船结束**：{p1} 从「{p2}」**自动**返航空间站{p3}——约 {p4} 秒后到港。 | **发车族**——`.029`/`.042` 是它的克隆（`已随换船结束` → `已停止`） |

**两条结论（都推翻了我自己上一轮的判断）**：

1. **id 前缀不是缺陷，是房规** —— `advanceShipReturns` 就在 `mining.ts`，它名下**全部**到港日志（远征善后 /
   打捞善后 / 换船善后 / 打捞停止 / 开采停止）一律挂 `core.mining.*`。把 `.039`/`.040` 改成
   `core.salvaging.*` 只会**破坏这一族的同构**（`.033`/`.034` 还是 mining 前缀），**故不动**。
2. **唯一真缺陷 = `p3` 把「到港」说了两遍** —— `core.salvaging.018`（共享片段，被 `.017` `.019` `.029` `.042`
   四条日志当 `p3` 用）原文是「（到港整仓卸货）」，插进句子里就成了：

   > 打捞已停止：鲲鹏号 从「赫尔墨斯」返航空间站**（到港**整仓卸货**）**——约 120 秒后**到港**。

   ⇒ 一处改、四条日志同时受益（不是本批新引入的，是这一族一直带着的）。

**为什么用「卸空货仓」**：本族玩家向用词是「卸货 / 货舱 / 仓」（`.014` 满舱自动返航空间站卸货 · `.027` 自动返航卸货 ·
`.035` 已返港并卸货），而「整仓」在本表里**只出现在这一条片段里**；去掉重复的「到港」后，剩下的意思就是
"这一趟的货会卸下来"，用「卸空货仓」最直白。

## 4. 评过但**不动**的项（whale-copy §5.3：没问题就别强改）

| 项 | 结论 | 理由 |
|---|---|---|
| `.038`~`.041` 的「**已随**开采停止返航到港」 | **保留** | 与同族 `.031`~`.034`「已随远征/打捞善后返航到港」**逐字同构**，二号就是照它克隆的；「随」在这族里是固定句式。改「因／…后」会**拆散这一族**，收益不抵代价。 |
| `.029`/`.042` 未用「**自动**返航空间站」 | **保留** | 与落点同一处的既有分岔一致：`mining.ts:1029` 起，**换船**分支（id `.019`）才写「自动」（玩家换了船、需要交代船为什么自己飞回来），**停止**分支（id `.042`）不写。不是漏字。 |
| 「——约 {p4} 秒后到港」的破折号 | **保留** | 与同族 `.017`/`.019` **逐字同款**，不是新发明的连接符。 |

> 若船长更想要更顺的口语版（例：「{p1} 开采停止后已返航到港：原矿已卸入物品仓库（{p2} 单位）。」），

## 5. ⚠ 待裁：换船那条日志「正文 ≠ id」（本批**未动**，等船长一句话）

**事实**：`salvaging.ts` 的 `retireSalvageShip` 里，**换船分支**（唯一调用者 = `shipyard.ts:172` 换驾驶）

⇒ 后果：**界面按 id 渲染 ⇒ 玩家看到的是「已随换船结束」；存档里存的正文却是「打捞已停止」**（两句话不是同一句）。

|---|---|
| `017` 的表文（现在玩家实际看到的那句） | 该分支的内联正文（`ae8d3d10` 写的） |
| 同函数注释：「玩家手点停止/换船 ⇒「已随换船结束」」 | 用例 `tests/salvaging.test.ts:193` 断言 `text.includes('打捞已停止')` |

⇒ 先停下请船长裁决」，不擅改。我一度按 id 侧改过正文，**被用例当场抓住**（`salvaging.test.ts` 1 条红），已回滚。
