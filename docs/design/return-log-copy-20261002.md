## 5. 「正文 ≠ id」那处冲突（**已裁决 · 甲案已落码**）

来历 = `ae8d3d10`（二号 2026-10-02）拆"两条路分开说"时把 `if (auto)` 分支的正文复制进 `else`、保留 id，并把用例断言改成了「打捞已停止」。

凭据 3 : 2 —— 支持换船口径：① `017` 表文 ② 同函数注释 ③ **采矿同族** `core.shipyard.019`（正文与表文都是换船口径）；
支持停止口径：① 该分支正文 ② 用例旧断言。
（**更正**：早前汇报里说"用例有两处支持正文侧"不准确——`salvaging.test.ts:468` 那条属**手动停止**路径（`.029`），与 017 无关。）

**裁决与落码**：船长「按你推荐」⇒ 甲案 ⇒ 正文改回换船口径 ＋ `salvaging.test.ts:193` 断言改回 `打捞已随换船结束`。
