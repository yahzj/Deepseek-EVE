**本会话踩到并记账的坑（接手别再踩）**：
1. **FX 类改动必须验到「像素」**：只验"元素在 / `opacity=1` / 子节点数对"会漏掉「渐变引用不成立 ⇒ 一个像素都不画」
   ——那一轮我白改了两次，最后靠**真 Chrome 无头 `--screenshot`** 才看见（§33）。
2. **拿源码文本做护栏/普查时，类型注解里的 `[]`/`{}` 会骗过"从声明处找括号"** ⇒ 一律**从 `=` 之后**再找。
3. `.NET ReadAllText/WriteAllText` **必须绝对路径**（相对路径按进程 cwd 解析，不是 PowerShell 的 cwd）。
4. here-string 产出 **LF** ⇒ 写中文盘后要**归一 CRLF**，并复检 **BOM**（钩子/`sh` 脚本要保持 LF，别转）。
5. `git add -A` 会把 `tools/_commit-msg.txt`（提交信息临时文件）也加进去 ⇒ 提交前 `git reset` 掉它。
6. PowerShell 双引号字符串里**别放 `"`**（用单引号 here-string）；`$_` 在 here-string 里会炸。
