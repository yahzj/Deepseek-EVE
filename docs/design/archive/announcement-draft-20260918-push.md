## 二、电子舰：压制敌方武器射程

- **id**：`ann-ew-range-20260918`
- **title**：电子舰新特性：压制敌方武器射程
- **date**：2026-09-18
- **tag**：数值
- **bullets**（4 条）：

1. 电子舰新增船体特性：编队中每有一艘电子舰，敌方全部武器的最大射程降低 15%；多艘同时编入时按乘法叠加，敌方自身的射程加成与之相加结算。
2. 射程削弱有下限：基础射程不足 3,000m 的武器不受影响，其余最低压到 3,000m。
3. 敌方的接战距离随射程削弱同步收缩——被压制的敌人会更靠近才开火。
4. 鹦鹉螺级测绘巡洋舰的槽位调整为 3/4/4（总槽位数不变）。

**断言出处**（二号工作文档 `docs/design/ew-range-debuff-20260918.md` 与代码）：`ShipDef.foeRangeDebuffPct`（两艘电子舰 =

`sh-nautilus` slots 4/4/3 → 3/4/4。
