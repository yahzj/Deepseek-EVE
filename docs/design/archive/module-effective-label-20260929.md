## 三、写法（与维修装置那条同一形状、同一纪律）

- **只对"已装上船"的卡出这一行**（仓库 / 市场 / 手册不上船 ⇒ 仍只显示原值）——与 2026-09-29 维修那条逐字同规；
- 行名 = `ui.shipInfo.222`「**装上后**」；值形：
  - 折权族：`机动速度 +26%（原 +30%）`（`ui.shipInfo.221`）
  - 缺口族：`护盾动能抗性 47%（本件 +50%）`（`ui.shipInfo.220`）
  - 一件多字段 ⇒ 用 ` · ` 连；
- **数值一律由 core 单点现算**（`combat.fittedEffectParamsOf`）——界面不自己折权（与 `repairStatsFor` 同一条纪律：显示值与实战值不许漂移）；
- **位序**由装配页按"高→中→低槽位序、同收敛族计数"给出（第 2 件吃 87% 衰减）。
