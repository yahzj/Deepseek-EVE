## ⭐ 卡 2（推荐发）· 敌对派系活跃

- id：`2026-09-11-faction-activity`
- title：敌对派系活跃：自家地盘不再被选，剿灭可一键循环
- tag：玩法
- bullets：
  - 玩家**已经建成空间站的星系，不会再被选为「敌对派系活跃」**——自家地盘不再被骚扰；
  - 任务中心那条「敌对派系活跃」卡片上新增「**循环剿灭**」：点一下即持续清剿该星系的常驻悬赏，直到手动停止（打赢自动返航，冷却结束自动再出发）；
  - 货仓装不下缴获、或修理组件耗尽导致耐久不足时，循环会自动暂停；
  - 它与其它悬赏卡上的「重复清剿」是**同一个开关**——在这边开启会停掉那边；
  - 规则不变：该星系全部常驻悬赏奖金 +10%、敌人威胁 +10%，胜利有概率掉稀有残骸；每天 0 点重新选。
- 依据：`e594e43`（已建站星系排除出抽取范围）、`6cbb3c1`（置顶卡「循环剿灭」按钮）；代码入口 `core/sideTasks.ts factionPoolOf`、`panels/Expedition.tsx`。

## ⭐ 卡 3（推荐发）· 市场供应量

- id：`2026-09-11-market-supply`
- title：市场货架补足：按玩家的生产能力供货
- tag：经济
- bullets：
  - 站内常驻供应量按**玩家的生产能力**重新标定：矿石、气体、冰矿与精炼矿物的现货整体上一个台阶（越稀缺的品类提高越多，最紧的气冰类从个位数提到近千）；
  - 弹药、修理组件与无人机的货架同步补足：基础弹药从每窗百余发提到上万发，高级弹药与军用修理组件的现货也明显变多；
  - 收购侧同步放大：采回来、炼出来、造出来的货更容易被市场吃下，不再"挖了卖不掉"；
  - **单价不变**，变的是能买到、能卖出的量。
- 依据：`403d0d3`（矿石/气冰/矿物池按产能标定）、`b23859a`（消耗品池按产能标定）；工具 `npm run liquidity:audit`。
