## 三、接手必读口径（7 条）

1. **虫洞的目标函数是「专属产出」不是 ISK**（船长 2026-09-13 当场校正）：
   「进虫洞的目的是获得专属装备（稀有残骸，虫洞专属），资产收益只是附带的」。
   `wormholeLootValueIsk` **默认不计高级箱价值** ⇒ 用 ISK 挑配置会方向性错误。
2. **五族稀有残骸全在「常」回收档 ⇒ 高级箱专属命中率只有 5%** ⇒ 每趟专属装备期望 ≈ 0.10 件（约 10 趟 1 件）。
3. **层 1 盘面只有 ~1.07 个遗迹格**（改造前 0.54）⇒ 浅层"专属产出"的上限由**盘面**决定，不是回合。
4. **深潜目前不成立**：多拿 22% 专属残骸 = 每趟多赔 0.5~1 艘船；要成立得动**威胁/回合**那一侧（建议①②在探索稿 §7）。
5. **星云的判据单点在 `revealOf`**（四档：unknown / signal / **nebula** / known）——界面**不许**再直读 `c.place` 上色（那是真相；本批修过这处真泄露）。
6. **遗迹下限是"硬保证"**：先补残骸信号、再**兜底翻转**（不够就把舰船墓场翻成遗迹，只换不重掷）。
   只补信号不保证出遗迹（层 1 实测 **24% 的盘一张都没有**）。
7. **空占比的量纲 = 占"可分配池"**（不是占总格数）；层 1 逐格未变（19 格 / 10 空）。

## 五、血泪（本次会话踩到 / 学到的，供后人省时间）

1. **🔴 不许关浏览器进程**（船长 2026-09-13 新规）：我**犯过一次**——用 `Stop-Process` 关自己的无头 Chrome。
   正确做法：`run_in_background: true` 起、`job_kill` 收；或留住 PID 只收自己那一个；**拿不准就让它跑着并写明**。
   船长的浏览器**自己也带 `--remote-debugging-port`** ⇒ 任何"按命令行筛调试端口"的写法都会误杀他的窗口。
2. **🔴 观感审查权在船长**：UI 改动**实现 + 四闸门跑完就交他看**；**不许自己截图当"改好了"的依据**。
   例外只有两类：① 读数型问题（溢出不溢出 / 滚不滚 / 跨窗口几何 / 帧数）② 他明确要求。
3. **PowerShell 会吃掉 `$1` 与 `$变量`**：往文件里写含 `${...}` 的 TS 探针时，**别用 here-string 双引号**——
   我因此写出过一个"恒真判据"的探针，白跑一轮；改用 `write` 工具写探针源码。
4. **工具按 id 锚定改数据时，锚点的缩进必须实测**：数据项是**四空格**缩进（两空格那个是类型定义），
   我猜错过一次 ⇒ 178 条一条没改还报"成功"。
5. **别在文案里"凭印象写数字"**：我给掘洞/飞鱼两条舰编了读数，被 `content-check` 的「蓝图说明契约」当场抓出。
   **改文案里的数字前一律先查真实数据**。
6. **合并后"父提交有的行还在"要真核**：本次两侧各 652 / 658 非空行、缺失 0 才算过；
   roadmap 冲突按「并集·最新在上」解（我方在上）。
7. **`write` 工具产出 LF**：中文盘写完必须用 .NET `WriteAllText` + `UTF8Encoding($false)` 归一 CRLF，
   **且必须绝对路径**（相对路径按进程 CWD 解析）。
8. **无头探针要挂后台任务**，并按 §六 每 2 分钟查一次输出（别"挂上去就不管"）。
