# 舰船尺寸分级重构 + 巡洋舰线(设计定稿 v3,2026-09-09 船长逐轮拍板;状态:已确认-实现中,不合并 main)

> 已确认决议(2026-09-09 多轮):①全船统一 5 档、允许空缺;②分级依据 = 舰船质量
> (armored 因装甲厚重 ×0.65 修正);③稀有度 = 同类型内上调,不改尺寸类型;④船名尽量不动但规范:
> 大分类按规格、旧规格词(炮舰/巡舰/母舰/艇…)作子分类;⑤官方派系分支部门世界观,战斗舰归
> 「掠食者」(非猎食者);海鲜命名统一(最低级不再鸟名);⑥巡洋(T3)及以上入奇货渠道,其余下放常规市场;
> ⑦主力舰及以上本批不入场(新船只到巡洋);⑧本批战斗内容完成前只提交 d2,不合并 main;
> ⑨无人机舰也海鲜化(须贴群体行动意象)。

## 一、最终规则
1. **大分类尺寸档**:T1 护卫 / T2 驱逐 / T3 巡洋 / T4 主力 / T5 旗舰;
2. **落档**:等效质量 = massKg ×(armored?0.65:1);档区间 护卫 0.4~2.4M / 驱逐 2.4~5.8M /
   巡洋 5.8~13M / 主力 13~29M / 旗舰 ≥29M(等比 ~×2.2;重装给修正所以"超重"装甲舰不升档);
3. **稀有度同型内上调**:奇货精装 = 同级高配(价格/声望可抵上一档普通),不改大分类;
4. **命名**(掠食者·海鲜,鸟名清除):
   | 现名 | 新名 | 大分类 | 子分类(原规格词保留在名内) |
   |---|---|---|---|
   | 隼枭级武装艇 | **鲣鱼级护卫舰** | T1 护卫 | 入门战斗 |
   | 伯劳级武装护卫舰 | **马鲛级护卫舰** | T1 护卫 | 制式护卫 |
   | 蜂群级无人机护卫 | **梭鱼级无人机护卫** | T2 驱逐 | 无人机护卫型 |
   | 哨兵级无人机母舰 | **王鲭级无人机母舰** | T3 巡洋 | 无人机母舰型 |
   其余家族名保持;大白鲨级炮舰 = T2 驱逐·炮舰型·奇货精装(即玩家口中"战斗只到驱逐/炮艇"的现状顶);
5. **渠道**:T3 及以上 = exotic(奇货)或蓝图;T2 及以下 = 市场常规;内容批次只新增到 T3。
6. 显示:UI 增加大分类标注(定位行/图鉴 = `武装 · 驱逐舰 T2 · 炮舰型` 之类);子分类词在船名与标注。
