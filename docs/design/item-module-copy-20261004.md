## 写法与同类参照

使用本仓 description / 英文覆盖路径；新正文存唯一双语表，既有英文名称原样保留。正文讲这件物品是什么、有什么用、限制是什么，不复述槽位/渠道/稀有标签，不比较另一件装备，不解释设计理由。参数行已有的数值不手写，见 docs/data-map.md 的甲案。

## 初步发现

- 安全货柜描述 2×2 已过期，实际 3×2；精确体积和格型应由参数/货仓渲染，不再在正文里写死。
- 信号发射器的「势力从已出现势力中指定」与现行随机族池不一致；保留默认与指定星系的区别、站点禁令和高安处罚。
- 无人机说明有跨机型比较和绝对化，不能把族专属定位写成全局断言。
- 物品说明与通讯不同，不写角色对白或鼓动玩家购买。

## 本轮实施

- 111 种物品与 170 件装备说明已逐类重写，中文与英文只写唯一表。相同系列共享 108 组装备说明，物品 111 组；不新增第二套数值派生。
- 原矿/气/冰：依照 refine 产出写用途，不保证价值；原材料与零件：写制造用途，不暗示可直接装配。
- 无人机：保留伤害类型、作用距离特点和防御取舍，不写跨机型数字比较或全局最强。
- 货柜：写带回后拆解与物品池，去掉过期格数；实际格型从 wormholeShapeOf 提供，安全柜 3×2 在参数行显示。
- 谜质装置：逐种写本趟作用与成功撤离析出，不用「谜质吹出一阵风」等重复拟人句。
- 奢侈品：保留物件特征和贸易用途，不编拍卖估值倍数、消耗次数或特殊解锁。
- 黑匣：说明插件材料用途；消耗品：说明用途与限制，不复制时间/倍率/处罚数字。
- 制式装备：按系列写效果对象及限制；抗性不冒称容量，机库不冒称放飞算力。
- 势力装备：逐件写清伤害方式、副作用、范围和触发；巨构损管不冒称有致命保护。
- 插件：效果与不可拆换、装船后不可入库出售一并保留；射程插件短行补读正向 plugRangeBonusPct。
- 通用参数行补齐原先由正文或短行承担的护盾投射、射程压制、充能、连射、装填自加速、受击跃迁与插件效果，沿 shipInfo 同类行实现；无样式或玩法改动。
- 隐秘行动装置保留船长指定的「与任何类型推进器一起使用时失效」措辞，附侦察舰已有豁免，不放宽契约。
- id 扫描旧实现只认 core/ui，导致 item/mod 真引用报未接线；扩到既有合法域并加剥注释/动态模板负例测试，没有新增本地化域。
