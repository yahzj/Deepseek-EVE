## 条目 5（工业自动化扩到手动，2026-09-08 复核代码后口径）
- 现状：industry.ts 189-190 / manufacturing.ts 174-175——精炼炉与组装机均只在 **worker≠pilot** 分支应用 −5%/级（下限 60%）。手动精炼吃炉心熔炼学 −4%/级、手动制造吃工业理论×批量生产学。
- **方案 ①（推荐，全面）**：工业自动化对主控手动同样生效——手动精炼在炉心熔炼学之后再乘一区（−5%/级）；手动制造在 工业理论×批量生产学 之后再乘一区。乘区互叠后实际下限仍被现有各下限兜住（精炼双满 ×0.8×0.75=0.60；制造双满 ×0.6×0.75=0.45 > 制造 0.4 下限），即不会产生无下限极端值。**提醒：手动组装线提速 = 组装机产出速率变化，属二号维护的经济面；本次不动任何收入/价格公式，只动耗时乘区。**
