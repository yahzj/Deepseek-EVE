| # | 项 | 改前 | 改后 |
|---|---|---|---|
| ① | 减速效果 | 机动 **×0.1**（减速 90%） | 机动 **×0.5**（减速 **50%**） |
| ② | 我方**投网射程** | 无（且文案写「开战即钉」） | **3800 米**内才张网；文案去掉「开战即钉」 |
| ③ | **断开距离**（敌我通用） | 4000 米（只约束我方那件） | **4500 米**；**敌我两套网都吃这条** |
| ④ | 断开是否消耗冷却 | —（原无此机制） | **算一次使用** ⇒ 我方网断开立刻进满一轮周期冷却（20 秒） |

- 单点常量（`packages/core/src/combat.ts`）：
  - **`MY_WEB_RANGE_M = 3_800`**（我方投网射程，带船长原话注释）；
  - **`WEB_BREAK_DIST_M = 4_500`**（**敌我通用**断开距离，带船长原话注释）。
- **滞回带**（3800 ~ 4500 米）：已张开的网**保持**（拉到 3900~4500 米不会掉），只是**张不了新网**；
  超过 4500 米才断。我方网断开 ⇒ 清目标 ＋ 清减益 ＋ 写日志 ＋ **冷却 = 现在 + 20 秒**。
- **敌方网断开**（`expireFoeWebs`）：交战距离 > 4500 米 ⇒ 清账本 ＋ 日志「劫掠捕获网已失效：X 摆脱了束缚
  （距离超过 4500 米）。」；⚠ 敌方网**整场只张一次**（既有口径 `foeWebFired`）⇒ **断开后本场不再补发**，
  要恢复只能指望另一艘还没发过网的敌舰（2026-09-25「打空不算用掉」那条口径不变）。
- 判据用的是每拍更新的**交战距离 `b.distanceM`**（`stepBattle` 内既有标量，无新增状态字段）。
- 效果仍是**三层**（机动 ×0.5 · 推进器全关 · 闪避归零），**不含"武器射程下降"**（船长 2026-09-26 前令）；
  敌方那件仍是**四层**（多一条射程 −500 米），数值一字未动。

## 敌我两套捕获网是否联动？（答船长第 2 问）

**不联动，是两套完全独立的数据与状态。** 证据：

| | 我方「墨潮捕获网」 | 敌方「劫掠捕获网」 |
|---|---|---|
| 数据来源 | `packages/data/src/modules.ts` 的 `ModuleDef.captureWebCycleMs`（`mod-lair-web-h`，周期 20 秒 / CPU 44 / 高槽） | `packages/core/src/foeMounts.ts` 的 `FoeMountDef.web`（`foe-mount-capture-web`，A 族劫掠电子舰件） |
| 效果参数 | 机动 ×0.5 · 关推进器 · 闪避归零（**无射程削减**） | 机动 ×0.1（减速 90%）· 关推进器 · 闪避归零 · **射程 −500 米** |
| 触发/射程 | 我方周期装置；**交战距离 ≤ 3800 米**才张网 | 敌方**自身第一次开火**时发动（无独立射程 ⇒ 等效 = 它的武器射程 4,275 米） |
| 运行时账本 | `BattleState.myWebs`（我方携带者周期账本）＋ `BattleState.foeWebDebuffs`（我钉在敌舰上的减益） | `BattleState.meWebDebuffs`（敌网钉在我方舰上的减益） |
| 施加器 | `applyFoeWebDebuff` | `applyMeWebDebuff`（多一层 `rangeDownM`） |
| 断开后 | 进 20 秒冷却，冷却结束且距离回到 3800 米内可**再张** | 该舰本场**不再张**（整场只张一次） |

三个账本在存档里是**三个独立键**（`save.ts`）；两套各自有推进/解除逻辑（`advanceMyCaptureWebs` / `expireFoeWebs`）。
**唯一的共享点 = 本轮新加的断开距离**：`WEB_BREAK_DIST_M` 是**一条判据、两边各读一次**（这是船长明确要的
「这个断开对敌我都有效」），**不是数据联动**——各方的效果、周期、解除后的行为仍各自独立。
演出上两边都用 `web: true` 的蓝色连线（船长 2026-09-16 定的同一款光效）——只是画面同款。
