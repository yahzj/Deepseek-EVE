# 黑市对白下方重复商品名移除

> 状态：已实现，待船长验收（三号 · verify · 2026-10-06）
> 船长原话：「没问题了，但是当我点击一张黑市的卡片后，监视器对话框的下方会出现商品名称」。
> 范围：市场表现层，删除商人右栏重复的选中商品名及无引用样式，保留选货对白/姿态、富详情与购买确认。
> 不做：不改已通过的头像、监视器、台词、商品、价格、交易、存档；不访问个人档、不推送。

## 根因与改法

`BlackMarketPage.tsx`在`good`存在时渲染`app-bm-picked`，所以点选商品就会在对白下方追加名称。这是早期补充完整名称的显示，不是交易或数据错误；现在主动富详情与购买确认已完整展示名称，该行重复且占用商人栏空间，删除元素与对应样式。

`ui-ux-pro-max` ux域`Compact Label Overflow`要求完整值对鼠标/键盘/触屏可达；本批保留同页富详情和确认的完整名称，不恢复纯文本title，不新增披露方式。功能域为市场，参照已有商品详情与确认，无跨模块。
