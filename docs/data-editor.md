# 大鲸鱼数据编辑器

> 开发工具，编辑本仓库的静态参数，不修改玩家存档或已经安装的游戏。

## 启动

便携程序：`apps/data-editor/release/大鲸鱼数据编辑器-0.1.0-x64.exe`。双击无需安装编辑器或手敲命令；该文件未数字签名，Windows可能显示来源提示。开发命令为`npm run data:editor`，重新打包为`npm run data:editor-pack`。

加载`H:\大鲸鱼\Deepseek-EVE-zero`，顶部确认目录、分支与「可编辑」。主树、main/master及游离HEAD只读；工具只信任该仓库的工作树，不执行未知项目脚本。完整检查需要本机Git及项目已安装的开发依赖，缺失时拒绝保存，不静默安装。

## 编辑与保存

1. 按名称/ID搜索，在舰船、装备、舰船插件、物品/无人机、商品中选条目。
2. 修改右侧数值，失焦或回车确认草稿。百分比可切原值；倍率、毫秒、秒和体积按各字段单位，未设置不当作0。
3. 多选条目可对比，批量设值、加减或乘倍率；预览后应用草稿，非法一项不会部分应用。撤销/重做只操作草稿。
4. 查看下方联动变更，再保存。保存前在隔离源码候选中运行五包类型、内容与完整core测试；检查失败保留草稿，目标JSON不写。耗时取决于本机，通常需要一至两分钟，不代表卡住。
5. 保存成功才写JSON，原文备份到所选工作区的`tools/_data-editor/backups/<事务ID>/`。最近备份恢复先核对全部目标哈希，外部修改/基线变化时停止，不能抹掉其他人修改。

**可编辑范围**：46艘舰船、158件装备、12件插件、111种物品与无人机、537条直接静态商品记录。派生商品、代码公式、级别及插件槽、文案/ID/引用/结构/行为开关不由数值面板改写。某字段缺省或代码继承时不凭空增加；代码算术只作只读展示。

舰船商品key与舰船ID可能不同，关联按refId定位。同值价格在预览列明联动；商品基准价不是实时成交价。蓝图书价尚在代码中，不能单改市场一处；配方、书价规则或登记例外不会由工具猜测修改。

原有数值标定/历史守护用例继续执行。某些舰船/装备数字受这些断言限制，即使字段类型合法仍可能被拒绝；须按既有平衡流程批准对应变更，不提供强制通过、不改测试或删除护栏。迁移专用全值对照不是日常保存硬锁，仅显式验收命令运行。

## 生效与构建

数据随游戏构建发布；修改后开发版需重载，正式程序需新构建，不在运行中热换已有战斗/订单。编辑器「构建」先检查并在隔离目录生成桌面/网页产物，保留于`tools/_data-editor/builds/<ID>/desktop/out`及`web/dist`，反馈完整路径，不覆盖正在玩的游戏。发布、Git提交/合入/推送仍按原流程，编辑器不自动操作。

## 权威来源

`packages/data/src/static/{ships,modules,plugs,items,market}.json`保存唯一静态参数。各TS模块继续绑定原名称/文案与派生公式，`staticDataGroup`装配成原catalog接口；不复制最终SimContext快照，不引入SQL。

格式为`whale-static-data`、版本1，与个人存档版本不同。`staticFieldTypes.json`是字段形状契约，不是数值副本；新增字段需按类型与校验流程更新，不能为了吞掉非法数据重生成。迁移辅助工具`data-static-migrate.ts`/`data-static-fields.ts`只用于原始搬表及显式维护，不用于日常编辑，已迁移表拒绝重复覆盖。

旧`content:export/import`继续支持Excel/CSV；迁移表回写JSON，不再修改TS数字。未导入的Excel手改不能被自动导出覆盖；导入只读/跳过项有明确反馈。

## 验证入口

- `npm run data:migration-check`：固定`f30834cf`原始表与中英文完整目录等价，含次序/缺省/过滤/派生及旧CLI回归，仅用于迁移验收；后续有意调参不应期望旧全值相同。
- `npm run data:editor-test`：字段/草稿/事务/冲突/恢复测试，隔离临时仓库。
- `node tools/data-editor-native-check.cjs --portable --no-screenshots`：真实便携EXE、同仓自建fixture、真实输入/保存/拒绝/恢复，运行完整检查，不访问个人档。
- `node tools/data-editor-visual-check.cjs`：隐藏自建Electron，实际1320×860、1040×700、800×520窗口几何与capturePage，非空像素读数，不替代船长观感验收。

截图与报告在忽略目录`tools/_ui-artifacts/`，备份/候选/构建在`tools/_data-editor/`，不入库。恢复时只处理工具自己的事务。源码、测试与文档均在零号实施，交付EXE不等于主树已迁移或已推送。
