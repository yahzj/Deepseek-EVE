# 大鲸鱼 · 深空工业

以《EVE 星战前夜》为蓝本的**文字挂机游戏**（桌面端）。已完成 M0~V12（实时战斗引擎 P1）：
技能训练、采矿-精炼-制造经济、带星图与文字战报的远征玩法、舰队与 AI 副船、
NPC 订单簿市场，以及 V10 的"深空市场大扩容"（占位导入，战斗机制后置启用）。

## 在线网页版（GitHub Pages）

- 同一份代码可构建为纯浏览器可玩的网页版（独立工程 web/：cd web && npm ci && npm run build，只装 react/vite、不装 Electron），由 GitHub Actions 自动部署到 Pages；
- 网页版存档保存在浏览器 localStorage（自带备份/恢复面板），与桌面版文件存档相互独立；
- 推送 main 分支即触发部署：仓库 Settings → Pages → Source 选 **GitHub Actions** 即可。

## 现状（M0 + M1 + M2 已完成）

**M0（底层）**
- ✅ 技能训练队列：12 个 EVE 风格技能（4 组），可排队、可移除、可清空
- ✅ 离线结算：关游戏再打开，按离开时长补进度（上限 8 小时，超出部分放弃）
- ✅ 版本化存档：自动保存 + 旧档自动迁移 + 损坏容错（存在系统用户目录）
- ✅ 桌面窗口界面（EVE 风深色主题）+ 单元测试覆盖引擎核心

**M1（采矿经济闭环）**
- ✅ 采矿作业：选矿带自动循环采掘（4 条矿带 × 4 种矿石），**货舱满了自动停**
- ✅ 技能实际生效：采矿技术 +6% 产量/级、采矿护卫舰 -3% 循环时间/级
- ✅ 精炼：矿石 → 矿物（收率 = 50% + 精炼学 8%/级 + 高级回收 4%/级，上限 95%）
- ✅ 市场：原矿/矿物按牌价卖给空间站换 ISK；攒钱买更大的船（沙猫 → 掘洞 → 鲸吞）
- ✅ 离线采矿：离线期间矿船继续挖，回来有"离线采集报告"
- ✅ 彩蛋：每循环 1% 概率撞见"富矿脉"，产量翻倍（种子随机，可复现）

**M2（蓝图制造链）**
- ✅ 蓝图商店：4 张蓝图（强化采集器 MK1/MK2、货舱扩展 MK1/MK2），ISK 购买后永久可造
- ✅ 制造作业：矿物材料 + 制造费开工即扣；工业理论每级 -5% 耗时（开工锁定）；到点自动入库
- ✅ 装配台：采集器槽（+产量）/ 货舱槽（+容量），换装旧件自动退回装备库
- ✅ 完整成长螺旋：挖矿 → 精炼 → 造装备 → 挖更快/装更多

**M3（星图 · 远征 · 声望 + 界面整合）**

## 环境要求

- Node.js ≥ 20（开发环境实测 v26）
- npm（建议 10+，实测 11）

## 快速开始

```bash
# 1. 安装依赖（本仓库已装好则跳过；首次或换机器需要）
npm install

# 2. 启动游戏（开发模式，带热更新）
npm run dev
```

开发模式下会自动打开游戏窗口。**关闭窗口 = 退出**，进度靠自动保存（每 15 秒
+ 每次操作后 + 启动时）。

> 首次 `npm install` 若 Electron 下载卡住（国内网络），在命令前设置：
> ```powershell
> $env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
> npm install
> ```
> 有代理则在命令前加：`$env:HTTP_PROXY="http://127.0.0.1:7897"; $env:HTTPS_PROXY="http://127.0.0.1:7897"`

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 开发模式启动游戏（热更新） |
| `npm run test` | 运行核心引擎单元测试 |
| `npm run typecheck` | 全部子项目 TypeScript 类型检查 |
| `npm run content:check` | 内容完整性体检（市场/配方/引用无死物品） |
| `npm run build` | 构建生产版（产物在 `apps/desktop/out`） |
| `npm run build && npm run start -w @whale/desktop` | 以生产版启动 |

## 目录结构

```
apps/desktop      桌面外壳（Electron：窗口、存档读写、界面）
packages/core     引擎核心（纯 TypeScript，无框架依赖——所有游戏规则都在这里）
packages/data     静态内容数据（技能表等；加内容 = 加数据，引擎零改动）
packages/ui       界面组件库（面板/进度条/日志，EVE 风样式）
docs/             架构文档与设计文档
```

## 存档位置

Windows：`%APPDATA%\whale-idle\save.json`（卸载重装游戏也不丢）。
重置档案在游戏右上角"重置档案"按钮。
