# Conventions & Workflows

## 汇报与沟通

- 沟通语言：中文。专有名词与单位可直接用，少堆英文缩写。
- 汇报格式：每次汇报第一行必须写「报告老大喵」，结论先行，结构包括：
  1. 修改文件清单
  2. 行为变化与设计实现
  3. 验证结果（命令与输出状态）
  4. 已知取舍

## Serena 与代码检索铁律

- **Serena 优先**: 默认使用 Serena MCP 进行代码符号增删改查、定义跳转和引用查找。
- **>500 行禁盲读**: 超过 500 行的代码/数据文件严禁直接盲目通读。必须使用 Serena MCP 查引用 (`find_referencing_symbols`)、查定义 (`find_declaration`)、查结构 (`get_symbols_overview`) 定位目标后精准读写。

## 主子代理协作流水线

- **修改必开子代理**: 只要涉及到具体干活与代码修改，主代理必须启动子代理 (Subagent) 执行。
- **主代理路由与并行作业**: 主代理负责全局架构把关、需求拆解与精准派工，让子代理并行施工，提升工程吞吐并隔离主上下文。
- **主代理统一验收**: 所有子代理完成后，主代理收拢成果并亲自运行测试、契约检查与构建验证，统一汇报给船长。

## 本地化与文案

- 新玩家文本必须在 `packages/data/src/l10n/table.ts` 登记稳定 id。
- 未经明确开始准备英文时，只写中文，配 `en: ''`、`enDeferred: true` 并登记 `docs/l10n-pending.md`。

## UI 规范

- 科技感 HUD 终端风格，切角/缺角、细线条、微发光与严谨排版。
- 浮层/提示统一通过 `ui/Tooltip.tsx`。
- 一级页面不加全局滚动条，复杂长内容收纳进二级卡片或窗口内。
