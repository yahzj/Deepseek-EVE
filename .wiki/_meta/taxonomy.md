# 库级词表（Domain）

> 本库只装领域词；知识类型轴（concept / pitfall / decision / index / todo / enum / table）由插件基础词表提供。
> 规则：小写 + 连字符；每页最多 5 个标签；领域词按「≥2 页」才进本表。

## Domain

- `architecture` — 项目架构、模块边界与依赖方向
- `workflow` — 开发协作流程、验证与提交纪律
- `docs` — 文档体系、术语与阅读纪律
- `data` — 数据/内容编辑、存档与迁移边界
- `gameplay` — 玩法机制：战斗与舰队、虫洞与信号、工业与经济、证券交易所
- `ui` — 界面呈现与体验：UI/UX、性能、字体配色、本地化与文案
