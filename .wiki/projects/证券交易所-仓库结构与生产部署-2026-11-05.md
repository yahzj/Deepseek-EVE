- Go 模块名仍是 `whale-server-go`（目录改名、模块没改），文档与实例前缀沿用旧名时不要误判为另一个仓。
- 生产两个 systemd 单元：`whale-server.service`（8787）与 `whale-exchange.service`（8788），nginx 在前；Go 二进制与 DB 都在 `/home/ubuntu/whale-exchange/`。

## 二、生产拓扑

- nginx：443 域名 + 80 IP 明文通道（`allowlist 127.0.0.1` 与固定出口 IP），`/internal/*` 一律 404。
- `whale-server.service` → `127.0.0.1:8787`（Node）。
- `whale-exchange.service` → `127.0.0.1:8788`（Go）。
- Go 二进制：`/home/ubuntu/whale-exchange/whale-exchange`，回滚副本 `whale-exchange.prev`。
- SQLite：`/home/ubuntu/whale-exchange/data/whale-exchange.db`；账号库 `/home/ubuntu/whale-server/data/whale-server.db`。
- 关键环境变量（写在 unit 文件里，**不写就回默认**）：
  - `EXCHANGE_ADDR=127.0.0.1:8788`
  - `EXCHANGE_DB=.../whale-exchange.db`
  - `WHALE_AUTH_DB=.../whale-server.db`
  - `EXCHANGE_ROUND_SEC=300`
  - `EXCHANGE_LOCAL_SAVE_MODE=1`（存档币本地为准）
  - `EXCHANGE_SHORT_ENABLED=1`
  - `EXCHANGE_BORROW_POOL=100000`、`EXCHANGE_BORROW_RATE_BP=5`
  - `EXCHANGE_COMMISSION_BP=1`、`EXCHANGE_STAMP_BP=1`（买卖各 0.01%；**代码默认 0**，不写就是免佣）

## 三、部署步骤（Windows 开发机 → Linux 生产）

1. 交叉编译：
   ```powershell
   cd D:\Documents\GitHub\deepseek-EVE-Background\exchange-server-go
   $env:GOOS="linux"; $env:GOARCH="amd64"
   go build -ldflags "-s -w" -o whale-exchange-linux ./cmd/exchange
   ```
2. 本机无 sshpass/plink/Posh-SSH，用 Python `paramiko` 做非交互 SSH/SFTP（脚本放临时目录，用完即删）。
3. 上传到 `/home/ubuntu/whale-exchange/whale-exchange.new`，然后：
   ```
   cp -f whale-exchange whale-exchange.prev
   mv -f whale-exchange.new whale-exchange
   chmod +x whale-exchange
   ```
4. 重启必须带 sudo 非交互：`sudo -n systemctl restart whale-exchange`（直接 `systemctl restart` 会报 `Interactive authentication required`）。
5. 验证：`systemctl is-active whale-exchange`、`/api/exchange/meta`（看 `commissionBp`/`stampBp`/`roundSec`）、`/api/exchange/stocks`（8 只）。

## 四、踩过的坑

- **父仓不含 Go 代码（已修）**：并入前 `git ls-tree HEAD --name-only` 里没有 `exchange-server-go`，clone 下来只能看到 Node 部分。2026-11-05 处理顺序是「`git bundle` 备份完整历史 → 删子仓 `.git` → 父仓 `git add` → 推送」；bundle 在 `D:\Documents\GitHub\_archive\exchange-server-go-history-20261105.bundle`。以后改 Go 代码直接在父仓提交，不要再在子目录 `git init`。
- **旧目录还被旧 Serena 实例占用**：`D:\Documents\GitHub\whale-server-go`、`D:\Documents\GitHub\whale-server` 删除时报「being used by another process」，因为 `serena-go` / `serena-server` 两个 MCP 实例以它们为项目根；要删先改 `~/.dsh/cordis.patch.yml` 的路径并重启 DSH。
- **模块名与目录名不一致**：`go.mod` 仍是 `module whale-server-go`，`serena-go` 实例也按旧名配置，改名会牵动 import 路径与 DSH 配置。
- **环境变量默认值是 0**：`commissionBp`/`stampBp` 代码默认 0，靠 systemd 注入才变成 1；重装 unit 文件会静默回到免佣。
- **服务器没有 sqlite3 命令行**：查/改 DB 只能用 `python3 -c 'import sqlite3...'` 或上传脚本执行后删除。
- **本机直连 GitHub 可能失败**：出现过 `api.github.com` 走 `127.0.0.1:1088` 代理报错、`git ls-remote` 报 `schannel: failed to receive handshake`，此时无法核对远端内容，只能以本地路径与 GitHub 网页为准。
- **`exchange_klines` 列名**：`(code, interval, bucket_ts, o, h, l, c, v)`，没有 `t`；改历史数据要按这个结构写 SQL。
