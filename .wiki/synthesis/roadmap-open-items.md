**结论先行**：`docs/roadmap.md` 是**当前待办的唯一入口**，只保留当前待办、未决与待复核三类的摘要；它不授权实施——「待复核」不等于确认存在缺陷，「挂起」不等于可以开工，重启任何事项都要先核当前代码并重新确认范围。

## 二、三类待办口径

| 类别 | 含义 | 当前代表 |
|---|---|---|
| 待验收 | 实现与自测已完成，等船长看结果 | 国庆审查遗留、赏金分档三档保底、声音系统追加批 |
| 待裁决 | 方案已写出，缺一个明确取舍 | 第二阶段第二十二节「备料动态、开工锁料」；优先 AI 是否跨页常驻；训练队列整段搬动/取消语义；手册富卡是否新增强调；工业书架缺料标识颜色；精炼炉专属无人机掉落授权 |
| 待授权开工 | 范围已讨论，未获实施许可 | 第二阶段人类复苏与玩家空间站大版本；C7 新敌舰与深层卡；T12 装备三级筛选 |

新增取舍一律先走四步闸门（集中提问→中文设计总结→显式确认→实现登记）；沉默或「你看着办」不构成范围确认。

这些事项曾被登记，但完成状态**不能只凭旧勾选框判断**；工作时先查现行源码与确定性复现，不自动阅读旧记录（`docs/roadmap.md:42`）。

另两项（浏览器导入特定机型反馈、旧审查未决与架构候选）按玩家当前复现条件与当前实现核查，不沿旧行号、数量或方案直接开工（`docs/roadmap.md:51`、`docs/roadmap.md:55`）。

## 六、更新纪律

- **本页只放当前待办、未决与待复核**；批次流水、历史数值与已结清交接不进本页（`docs/roadmap.md:3`）。
- 没有船长明确查阅要求，禁止读取或检索旧记录，包括 Git 历史；旧文件里的引用不授予查阅权限（`docs/roadmap.md:4`）。
- 三类措辞各有含义：「待复核」不等于确认存在缺陷；「挂起」不等于实施授权；重开事项先核对当前代码并确认范围（`docs/roadmap.md:5`）。
- 已办结任务、本地化交接、旧版存档迁移、历史补偿、版本里程碑和发布验证流水不再重复（`docs/roadmap.md:61`）。
- 旧交接里的提交合入、推送领先、临时件数量与批次归档状态，一律按当前 Git 与文件核实，不做即时待办（`docs/roadmap.md:63`）。
- 事项结清后：结论并入现行文档、过程移入归档、重跑 `npm run docs:index`（归档流程见 `docs/development-conventions.md:138`，命令见 `docs/data-map.md:33`）；本页只留摘要。
