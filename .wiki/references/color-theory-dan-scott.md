> 知识地图参考页：本指南基于澳大利亚著名风景画家、Draw Paint Academy 创始人丹·斯科特（Dan Scott）的经典著作《Color Theory Cheat Sheet》（色彩理论速查指南），系统梳理色彩三大知觉属性（Value / Hue / Saturation）、色轮几何关系、受限调色板（Limited Palette）调色法及色彩心理触发机制，并深度映射至《大鲸鱼-深空放置》暗色 Sci-Fi HUD 终端、多层防御状态体系、品质阶梯与视觉工效学工程实践。

## 结论先行

- **明度为骨，色相为皮**：明度（Value）是决定视觉结构可读性与信息层级的最核心属性（正如艺术界格言：“Value does all the work, color gets all the credit”——明度干了所有的苦活，色彩却赢得了所有的赞美）。在没有建立起清晰的明度阶梯前，任何盲目堆砌鲜艳色相的做法都会导致界面沦为混乱的视觉杂音。
- **冷暖对比与补色互抑**：混入互补色（Complementary Color）是抑制色彩纯度、调配高质量浊色（Tone）与和谐中性色的科学法则。直接使用纯黑（#000000 管装死黑）调深颜色会造成视觉空洞与脏浊，必须通过冷暖互补调配具备环境呼吸感的“自然黑”（Natural Black）。
- **受限调色板（Limited Palette）的工程价值**：优秀的调色系统绝不依赖于无限色谱，而在于高度克制的核心基础色。通过严格受限的语义色彩集合，能在全系统范围内自发构建高凝聚力的色彩和谐（Color Harmony）。
- **《大鲸鱼-深空放置》科幻 HUD 终端的核心映射原则**：
  1. **Low-key 暗色基底与自然黑阶梯**：以 `--wui-bg-deep: 8 11 16`（#080b10 极深蓝黑）作为深空基底，坚决避免 `#000000` 纯死黑；容器、边框、文字建立严密递进的明度预算，保障暗环境下数小时放置不产生视觉疲劳。
  2. **状态语义与三层防御色温架构**：采用**分裂互补与三元色**解构舰船防御系统（护盾青蓝、装甲暗红、结构黄金）；警报状态运用极致冷暖对比（青绿常态 vs 猩红入侵告警），强化视知觉警觉度。
  3. **饱和度克制与信息层级法则**：90% 常态数据保持中低饱和度（Tone / 浊色），高饱和度（Vivid / Chroma）严格作为即时行动触发与危急警报的特权，坚决杜绝“彩虹式霓虹光污染”。
  4. **品质阶梯与色相跨度**：白灰绿蓝紫橙金严格遵循牛顿色轮的均匀色相隔离，并配合明度与饱和度双重递增，确保全色盲与低对比环境下的清晰辨识度。

## 二、色彩理论核心体系精要

### 1. 色彩三大属性的科学界定与阶梯划分

在艺术与界面工程中，理解颜色的最快方式是将它拆解为三个独立但相互交织的维度：

- **明度（Value）**：
  - **定义**：表征色彩在感知上的明暗程度，完全独立于色相与纯度。
  - **阶梯划分**：艺术与工业界通常使用 1 至 9 或 10 级的灰阶标尺（Value Scale）。1 级代表纯白（光子反射率最高），10 级（或 9 级）代表纯黑（完全吸收光线）。
  - **决定性地位**：明度决定了人眼视网膜杆状细胞（视杆细胞对光强敏感，对色彩不敏感）的神经激活水平。若将一幅画或一个界面转换为黑白灰度图后无法区分文字与背景，那么无论其色相搭配多么艳丽，在可用性层面均属彻底失败。
- **饱和度（Saturation / Chroma / Purity / Vividness）**：
  - **定义**：衡量色彩纯粹、鲜艳或生动的物理强度。高饱和度的颜色如耀眼的激光红，低饱和度的颜色则接近中性灰。
  - **衰减机制**：往任何纯色中混入灰色、白色、黑色或其互补色，都会导致饱和度迅速下降。
  - **注意力经济**：视网膜对高饱和度区域产生极强的本能注意抢占，因此高饱和度色彩必须被视为极其昂贵的“稀缺注意力货币”。
- **色相（Hue）**：
  - **定义**：光波在电磁波谱上的主导波长（Dominant Wavelength）。
  - **认知特征**：红（~700nm）、黄（~580nm）、绿（~530nm）、青蓝（~480nm）、紫（~400nm）。色相负责赋予物体独特的语义代号与情感基调。

### 2. 色彩术语精解

- **浅色（Tint）**：
  - 纯色加上白色（`Hue + White`）。明度升高，饱和度下降。常用于界面中的高亮文本、悬停发光状态及弱化阴影的高光切角。
- **暗色（Shade）**：
  - 纯色加上黑色（`Hue + Black`）。明度降低，饱和度同时下降。常用于凹陷面板、阴影投射和背景景深。
- **浊色（Tone）**：
  - 纯色加上灰色（`Hue + Gray` 或 `Hue + 互补色`）。色相保持不变，但鲜艳度被钝化，呈现出极具质感、优雅低调的中性倾向。**现代专业科幻 HUD 终端 80% 以上的非警报色均为 Tone**。
- **高调（High-Key） vs 低调（Low-Key）**：
  - **高调（High-Key）**：画面或界面的主要明度范围分布在 1~4 级高明度区间（浅灰、米白、高亮）。呈现出通透、明亮、轻快的视觉心智（如医院、科研实验室、日间明亮主题）。
  - **低调（Low-Key）**：画面主要明度范围沉降在 7~10 级深暗区间（深灰、幽蓝、玄黑）。营造出深邃、神秘、专注与厚重的氛围。**宇宙深空与舰船操控终端天然属于 Low-Key 范畴**。
- **色温（Temperature）**：
  - **暖色（Warm Colors）**：红、橙、黄。在空间知觉上具有**前进感（Advancing）**与**膨胀感**，易诱发肾上腺素激增与紧迫感。
  - **冷色（Cool Colors）**：青、蓝、紫、冷绿。在空间知觉上具有**后退感（Receding）**与**收缩感**，诱发理性、冷静与距离感。
  - **相对冷暖法则**：冷暖是相对的而非绝对的——例如，偏黄的柠檬绿（Warm Green）相对于偏青的薄荷绿（Cool Green）是暖的；群青（偏红的蓝）相对于酞菁蓝（偏绿的蓝）是暖的。

### 3. 色轮结构与调色法则

#### 艾萨克·牛顿色轮的几何架构
自艾萨克·牛顿在 17 世纪通过三棱镜折射首创闭合色轮以来，色轮成为理解色彩相互作用的最强工具：
1. **三原色（Primary Colors）**：红（Red）、黄（Yellow）、蓝（Blue）——不可由其他颜色调配得出的基本基石。
2. **三次生色（Secondary Colors）**：绿（Green = 蓝 + 黄）、橙（Orange = 红 + 黄）、紫（Purple = 红 + 蓝）——由相邻两原色等量混合而成。
3. **六三次色（Tertiary Colors）**：红橙、黄橙、黄绿、蓝绿、蓝紫、红紫——由原色与相邻次生色混合产生，补全了十二色相环。

#### 调色法则（Color Mixing Principles）
- **受限调色板（Limited Palette）的力量**：
  - 丹·斯科特特别强调：使用红、黄、蓝三原色加白色，几乎可以调出自然界的所有色彩。
  - 强迫自己使用极简的基础调色板，能彻底杜绝界面配色杂乱无章的“色彩脏乱（Muddy Color）”，自然达成浑然一体的系统调和。
- **补色互抑降饱和（Complementary Muting）**：
  - 位于色轮 180° 正相对的两个颜色称为互补色（如橙与蓝、红与绿、黄与紫）。
  - 当互补色并置时，由于视觉侧抑制效应，它们会产生极具张力的边缘争抢；
  - 但**当互补色相混合时，它们会相互吞噬纯度，迅速浊化为沉静高级的中性灰或暗褐色**（例如：向刺眼的橙色中滴入微量深蓝，即可获得极其雅致的工业铜褐色）。
- **自然黑与阴影调配（Natural Black vs. Tube Black）**：
  - **管装死黑的弊病**：直接使用绝对黑色（`#000000`）会导致画面出现如同“黑洞”般的扁平死寂感，抹杀了空间的空气感与光照反射。
  - **自然黑调制秘方**：丹·斯科特指出，画家通常使用**深蓝（Dark Blue / 普鲁士蓝）混合生褐（Raw Umber）或熟褐（Burnt Sienna）**来调制自然黑。这种调配出的阴影不仅深邃，且内蕴冷暖色调的呼吸感，与深空界面的星云微光天然共鸣。
- **加深与提亮手法**：
  - **加深**：加入深蓝、深棕或互补色，不仅能降低明度，还能保持色彩的厚度；
  - **提亮**：加入微量黄色或白色。加黄能在提亮的同时赋予阳光与能量感，加白则带来漫反射与通透感。

### 4. 经典配色方案体系（Color Schemes）

| 配色方案 | 色轮几何关系 | 视觉特征与认知张力 | 典型应用情境 |
| :--- | :--- | :--- | :--- |
| **单色方案 (Monochromatic)** | 单一色相，仅调整 Tint、Shade 和 Tone | 极致纯粹、统一性极高，无任何色相冲突，完全依靠明度阶梯驱动 | 极简仪表盘、雷达单一遥测信道、暗黑控制终端底色 |
| **类似色方案 (Analogous)** | 色轮上相邻 30°~60° 的 2~3 个颜色（如绿、青绿、天蓝） | 柔和过渡、宁静舒适、自然界常见生态流转 | 常态巡航状态栏、工业制造队列、生命维持系统 |
| **互补色方案 (Complementary)** | 色轮 180° 直线相对的两个极端色（如青蓝 vs 橙红） | 对比度最强烈、视觉冲击力最大，两色争夺中枢神经兴奋度 | 敌我识别系统（蓝方友军 vs 红方敌军）、锁定与破盾告警 |
| **分裂互补 (Split-Comp.)** | 基准色 + 互补色两侧各偏离 30° 的两个色彩 | 兼具互补色的张力，同时消解了两极对立的生硬感，容错率高 | 舰船防御环体系（护盾天蓝 vs 装甲朱红与结构金黄） |
| **三元配色 (Triadic)** | 色轮上间隔 120° 等边三角形的三色（如红、黄、蓝） | 鲜活饱满、平衡且充满动态生机，即便降低饱和度依然保持层次分明 | 核心三大资源平衡舱（能源/矿石/合金）、三方势力战局图 |
| **矩形/四元 (Tetradic)** | 两组互补色构成的矩形对角线分布 | 变化最为丰富、色谱覆盖最全；必须选定一种主导色，其余作为辅色 | 复杂星域全维态势图、大型空间站跨系统监控中枢 |

### 5. 色彩心理触发机制（Psychological Triggers）

丹·斯科特指出，色彩对人类认知行为具有下意识的操控力，能够直接扭曲人对客观事实的感知体验：

- **红色（Red）**：
  - **心理触发**：危险（Danger）、警戒、高能、攻击性、心率加速。
  - **生物进化根源**：血液溢出的预警信号，人类对红光波长的视网膜反应最迅速。
- **橙色（Orange）**：
  - **心理触发**：活力（Vitality）、工程活动、机械动力、创造力。
  - **认知特征**：比红色温和，但比黄色更具行动号召力，代表工业运转与作业中。
- **黄色（Yellow）**：
  - **心理触发**：能量（Energy）、光照（Light）、希望、电离。
  - **知觉特性**：在黑暗背景下明度最高、最醒目的色相，常用于结构警示与能源载荷提示。
- **绿色（Green）**：
  - **心理触发**：健康（Health）、自然、安全、财富、系统平稳。
  - **心理阻抗**：人眼对 555nm 绿光感知敏锐度最高，长时间注视最不易产生视神经疲劳。
- **蓝色（Blue）**：
  - **心理触发**：信任（Trust）、稳固（Security）、科技感、虚空宁静。
  - **空间属性**：典型的后退收缩色，能够有效平息焦虑，赋予用户沉着掌控力。
- **紫色（Purple）**：
  - **心理触发**：神秘、灵能、尊贵（Royalty）、变异、非常规稀缺品。
  - **感知特异**：自然界罕见，天然带有超现实与异质感。
- **知觉的主观性与语境依赖**：
  - 丹·斯科特以莫奈的两幅巨作为例：在《国会大厦·日落》（1904）中，浓郁的暗紫与血橙唤起壮丽甚至末日般的肃穆压迫；而在《睡莲》（1897-1899）中，低饱和的青蓝与冷绿则带来绝对的静止与冥想。色彩的情绪完全取决于**受限调色板内的冷暖相对平衡与明度支配**。

### 1. 深空 Low-key 暗色基底与明度阶梯（Value Ladder）

#### 为什么深空 HUD 必须坚决摒弃“管装死黑”（#000000）
- **工程弊病**：若直接使用 OLED 纯黑 `#000000` 作为窗口、卡片或游戏主界面背景，由于显示屏像素完全不发光，与明亮文字（`#ffffff`）之间会产生高达 21:1 的过载明度差。玩家在暗室中长时间放置盯盘，瞳孔处于扩张状态，强烈的黑白边缘光晕（Halation Effect）会导致极度严重的眼底干涩与视觉残留疲劳。
- **自然黑落地法则**：
  - 严格践行丹·斯科特「暗蓝调熟褐」的自然黑混合法则：
  - 基底遮罩：`--wui-scrim: 6 8 12`（#06080c，极深冷灰蓝，提供深不见底的星际虚空感）。
  - 主视口深层：`--wui-bg-deep: 8 11 16`（#080b10，明度 L~5%，保留微量冷青色基底）。

#### 5 级表面明度系统（Surface Elevation Budget）
在科幻终端中，界面的进深与容器关系不依赖浮夸的投影，而是严格依赖**明度阶梯（Value Ladder）**的递增：

| 层级名称 | Token 变量 | RGB 色值 | 相对明度 (L) | 视觉功能与空间隐喻 |
| :--- | :--- | :--- | :--- | :--- |
| **L0 星空深井** | `--wui-bg-deep` | `8 11 16` | 4.7% | 视口最底层星空背景，无边际沉浸区 |
| **L1 凹陷轨道** | `--wui-bg-sunken` | `20 29 43` | 12.4% | 装配槽位插座、滑块凹槽、滚动条底轨 |
| **L2 主面板容器** | `--wui-bg-panel` | `24 34 50` | 14.5% | 舰船装配舱、仓库网格、日志卡片背景 |
| **L3 交互按钮/条目**| `--wui-bg-btn` | `28 39 55` | 16.3% | 常态可点击按键、列表项容器底色 |
| **L4 悬停高光层** | `--wui-bg-hover` | `32 44 62` | 18.8% | 鼠标悬浮、当前选中活动项 |
| **边界定义线** | `--wui-border` | `45 60 79` | 24.3% | 0.5px 或 1px 金属刻线，精准切割容器边缘 |

#### 文字与读数明度系统
- `--wui-text-dim` (`154 167 184`, L~66%)：次要单位、注释、未激活说明，提供低调信息存在感。
- `--wui-text-2` (`200 210 222`, L~83%)：常规遥测读数、数值标签，清晰不刺眼。
- `--wui-text` (`240 243 246`, L~95%)：主要标题、高危属性、装备名称，极致清脆。
- `--wui-text-hi` (`255 255 255`, L~100%)：瞬时触发告警白、暴击跳字。

### 2. 状态语义与警报色彩工程

#### 舰船三层防御体系的分裂互补配色方案
《大鲸鱼-深空放置》的舰船装配与战损计算拥有严谨的物理外壳划分。我们运用色轮的**分裂互补（Split-Complementary）与三元调和**，赋予其不可混淆的色温与认知映射：

```
                    [ 护盾 Shield ]
               --wui-tone-hp-shield: 63 159 216
                  (冷调青蓝，波长 ~485nm)
                        /         \
                       /           \
                      /             \
                     /               \
                    /                 \
   [ 装甲 Armor ]                      [ 结构 Hull ]
--wui-tone-hp-armor: 211 74 74      --wui-tone-hp-hull: 224 184 63
  (暖调深朱红，波长 ~630nm)             (暖调琥珀金，波长 ~575nm)
```

1. **护盾（Shield, `--wui-tone-hp-shield: 63 159 216`）**：
   - **理论归因**：冷色调（Cool Tint），色相在 200° 左右。象征最外层的电磁力场与高能偏转护盾。冷色具有扩张包裹感，给予玩家安全的第一层防护心理感知。
2. **装甲（Armor, `--wui-tone-hp-armor: 211 74 74`）**：
   - **理论归因**：暖色调（Warm Shade），色相在 0°~5° 之间。象征坚硬的烧蚀合金装甲板。一旦护盾破损扣除装甲，视觉瞬间由冷转暖，唤醒视网膜警觉。
3. **结构/船体（Hull, `--wui-tone-hp-hull: 224 184 63`）**：
   - **理论归因**：中高明度暖色（Warm Gold），色相在 45° 左右。象征核心承重骨架与反应堆围壳。当装甲归零露出金黄色结构血条时，高明度金黄与极度危险警报闪烁并存，迫使玩家集中注意力关注生存状态。

#### 负载红线与温度计预警
- **能量栅格（PG）与运算核心（CPU）**：
  - 常态负载：采用终端青绿 `--wui-accent: 79 216 196`（极佳的科技平静感，表示系统运转在安全工况内）。
  - 临界负载（85%~99%）：平滑切入琥珀黄 `--wui-amber: 217 160 90`（Tone 浊黄，提示余量告急）。
  - 超载断路（>=100%）：突变至固定深红 `--wui-danger-strong: 229 57 53`（#E53935 强制硬红，色相与背景冷色形成绝对互补）。

#### 战场态势的冷暖对撞（Temperature Contrast）
深空宇宙默认处于绝对的冷色与低饱和包围中（冷蓝星光、冷灰界面）。在雷达态势图中：
- 友方战舰与巡航路径以类似色 `--wui-blue-soft` 与 `--wui-mint` 平缓呈现；
- 当敌对隐形巡洋舰脱隐锁定或折跃截击时，界面瞬间划入饱和度高达 90% 的 `--wui-danger-map: 255 106 94`（高亮猩红）。
- **冷暖对比的生物学机制**：人眼从冷色背景中捕捉突兀暖色的时间（~120ms）远比在杂乱暖色中辨认另一种暖色（~380ms）快 3 倍，实现了零延迟的视知觉即时预警。

### 3. 物品/装备品质阶梯与色相跨度

在放置 RPG 核心循环中，装备与图纸的品质阶梯（Rarity Tier）是刺激多巴胺与建立成就感的核心载体。必须严格遵守牛顿色轮的均匀角度隔离（Hue Separation），防止因相邻色彩相近而产生认知混淆：

| 品质阶梯 | 代表色相与 Token | 色相角度 (Hue) | 饱和度 (S) | 明度 (L) | 视觉与心理层级 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **T1 普通 (Common)** | `--wui-text-dim` (`154 167 184`) | ~215° (灰蓝) | 16% (极低) | 66% (低) | 工业量产件，无多余光泽，完全融入背景 |
| **T2 优秀 (Standard)** | `--wui-text` (`240 243 246`) | 0° (冷白) | 0% (纯净) | 95% (高) | 军规强化部件，明亮清爽，略有质感提升 |
| **T3 稀有 (Rare)** | `--wui-green` (`111 220 143`) | 138° (翡翠绿) | 60% (中) | 65% (中高) | 尖端科研产物，健康与生命力，安全可靠 |
| **T4 精英 (Elite)** | `--wui-blue` (`143 208 255`) | 205° (天穹蓝) | 100% (高) | 78% (高) | 统合部特装件，高科技与能量聚能感 |
| **T5 史诗 (Epic)** | `--wui-purple` (`169 138 224`) | 262° (灵能紫) | 58% (中高) | 71% (中高) | 先驱者遗迹异构物，超现实神秘感与高贵感 |
| **T6 传奇 (Legendary)** | `--wui-rare` / `--wui-gold` (`232 180 90`) | 38° (帝国日曜金) | 76% (高) | 63% (高亮暖金)| 泰坦与旗舰专属构件，最高阶荣誉与财富 |
| **T7 异质 (Exotic)** | `--wui-exotic` (`255 138 216`) | 320° (暗物质品红) | 100% (极高) | 77% (耀眼) | 宇宙奇点辐射造物，绝对罕见的视觉异构 |

#### 品质色工效学准则
1. **色相间隔 >= 55°**：T3(绿 138°) → T4(蓝 205°) → T5(紫 262°) → T6(金 38°) → T7(品红 320°)，每个层级在色轮上均跨越至少 55 度以上，彻底消灭黄绿/蓝绿等临界混淆态。
2. **多模态冗余（Accessibility Fallback）**：依据唐·诺曼的意符理论，严禁仅依靠单色指示品质。每一级品质除文本色外，必须附带：
   - 罗马数字角标：`[I] / [II] / [III] / [IV] / [V] / [VI] / [EX]`；
   - 容器边框的细微切角数量与科技纹理差异。

### 4. 界面信息层级与饱和度克制法则

#### 拒绝“赛博朋克眩光病”（Neon Over-saturation）
许多劣质 Sci-Fi 游戏习惯将整个界面涂满高饱和度的纯青、洋红与亮黄，并叠加大面积的发光 Bloom 滤镜。这直接违背了丹·斯科特的调色法则：**当所有东西都在高呼“看我”时，实际上没有任何东西能被看清**。

#### 饱和度预算分配模型（Saturation Budgeting）
在《大鲸鱼-深空放置》的 HUD 设计中，推行严格的“90-8-2 饱和度预算”：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      HUD 终端 90-8-2 饱和度预算模型                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ [ 90% 面积: Low-key 浊色基底 ] ── S = 0% ~ 20%                              │
│   深空背景 (--wui-bg-deep) · 面板框架 (--wui-bg-panel) · 次要说明文字       │
│                                                                             │
│   [ 8% 面积: 交互指示与状态反馈 ] ── S = 35% ~ 65%                          │
│     常规可点击按钮 · 护盾装甲健康条 · 模块运行中指示灯 · 装备品质基色       │
│                                                                             │
│     [ 2% 面积: 即时行动唤醒 (CTA) & 极限告警 ] ── S = 80% ~ 100%           │
│       折跃点火 (Warp Jump) · 结构击穿告警 · 击沉倒计时 · 传奇装备掉落光柱  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **90% 面积分配给 Tone 浊色与中性灰（S: 0%~20%）**：
   - 界面底色、次级列表、分割线、常规标签必须使用加灰或互补色中和后的沉静色（如 `--wui-dim: 160 172 188`）。它们构成视觉声场中的“静音背景”，使用户能够专注浏览成百上千条生产制造队列与星系市场数据数小时而不头晕。
2. **8% 面积分配给功能状态与常态指示（S: 35%~65%）**：
   - 护盾与装甲健康条、进行中的装配槽位、技能训练进度条，采用中度饱和色彩，提供清晰、柔和的状态反馈。
3. **2% 面积分配给即时行动（CTA）与极限绝境（S: 80%~100%）**：
   - 「跃迁进入战场」、「确认组装传奇战舰」等核心行为呼召按钮，赋予高饱和青绿（`--wui-accent`）或金黄；
   - 舰体结构跌破 25% 时的危急红光闪烁，释放最高饱和纯红。此时高饱和度能够瞬间突破暗色背景，像探照灯一样直击用户眼球。

## 四、HUD 视觉配色审查清单

在进行 UI 开发、设计走查与 Code Review 时，严格对照下述清单核对颜色合规性：

| 审查维度 | 理论依据 (Dan Scott 法则) | 规范标准与合规判定 (Pass / Fail) | 常见违规现象与修复策略 |
| :--- | :--- | :--- | :--- |
| **基底黑纯度** | 自然黑调配法则（避免管装死黑） | **PASS**: 底层采用 `--wui-bg-deep` (`#080b10`) 或深青冷灰<br>**FAIL**: 出现硬编码的 `#000000` 或 `rgb(0,0,0)` 填充大面积容器 | **修正**: 将 `#000` 替换为语义 token `rgb(var(--wui-bg-deep))`，允许微光穿透 |
| **容器明度阶梯** | Value Ladder 空间层次推进 | **PASS**: 严格遵守 `L0(深底) < L1(凹槽) < L2(面板) < L3(按键) < L4(悬停)` 的明度递增序列<br>**FAIL**: 出现外层父容器比内层子卡片更亮的反直觉倒挂 | **修正**: 统一采用 `--wui-bg-panel`、`--wui-bg-sunken` 标准阶梯，杜绝随意调配 |
| **文字对比度** | 明度决定可读性 (WCAG 2.1 AA) | **PASS**: 正文与读数对比度 >= 4.5:1（大标题 >= 3.0:1）<br>**FAIL**: 在 `--wui-bg-panel` 上直接使用低明度暗灰字导致难以辨识 | **修正**: 必须使用 `--wui-text` 或 `--wui-text-2`；弱化说明最低不得低于 `--wui-text-dim` |
| **防御三元分配** | 分裂互补与冷暖色温语义 | **PASS**: 护盾为冷天蓝，装甲为深朱红，结构为琥珀金<br>**FAIL**: 护盾与装甲使用相近色（如浅紫与深粉），或结构使用冷色 | **修正**: 严格绑定 `--wui-tone-hp-shield`、`--wui-tone-hp-armor`、`--wui-tone-hp-hull` |
| **品质色相隔离** | 色轮几何均匀分布 (>= 55°) | **PASS**: 绿、蓝、紫、金、粉红在色轮上间隔均匀，且附带罗马数字角标<br>**FAIL**: 出现黄绿色与翠绿色混用，无法肉眼秒级辨认 | **修正**: 剔除中间过渡色，回归核心色相定义，并强制补全辅助意符角标 |
| **饱和度预算** | 90-8-2 饱和度预算与克制法则 | **PASS**: 全屏无大面积荧光霓虹漫反射，仅在警报与核心 CTA 上出现纯色<br>**FAIL**: 边框、大背景网格、滚动条全线使用高饱和荧光青与高亮紫 | **修正**: 将装饰性线条饱和度降至 Tone 浊色（降至 20% 纯度或使用半透明通道） |
| **冷暖告警对撞** | Temperature Contrast 视觉唤醒 | **PASS**: 危险入侵、破盾等致命告警强制使用暖猩红，与冷背景强烈对撞<br>**FAIL**: 危险报警采用冷紫或暗灰，淹没在常规背景数据中 | **修正**: 强制锁定 `--wui-danger-strong: 229 57 53`，不可被主题自定义覆写覆盖 |
