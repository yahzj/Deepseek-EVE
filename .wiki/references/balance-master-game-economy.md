# 《平衡掌控者：游戏数值经济设计》深度蒸馏

> **知识定位**：虚拟世界经济不是简单的数值加减，而是一个具有自我演化特性的非线性复杂自适应系统（Complex Adaptive System）。本篇结合《平衡掌控者：游戏数值经济设计》（Game Numerical Economy Design）核心理论，从微观交易行为上升到宏观通胀调控，为 [[project-overview|大鲸鱼-深空放置]] 搭建永续健康的金融与数值闭环。

---

## 结论先行

1. **虚拟经济核心恒等式**：虚拟世界的商品与货币不能自生自灭。任何脱离“**水龙头（Faucet）- 排水池（Sink）- 蓄水池（Stock）- 流通速度（Velocity）**”动态平衡的设计，最终都必将滑向不可逆的恶性通胀（Hyperinflation）或恶性通缩。
2. **货币层次论（Monetary Hierarchy）**：单一通用货币必然导致“生产端工作室化、消费端断崖化”。必须建立“**绑定信用点（Soulbound Currency / LP）**”与“**自由流通硬通货（Liquid ISK / PLEX）**”的双层/三层防波堤，单向传导，切断无成本资本外溢。
3. **通胀的本质成因**：由于数字资产具备**零边际生产成本（Zero Marginal Cost）**且玩家时间供给缺乏现实生存约束，加之数值成长曲线（Power Creep）带来的生产力倍增，玩家资产沉淀速度必然呈指数级增长。
4. **金融系统不是空中楼阁**：股票、债券、期货等衍生金融系统**绝不能独立于实体经济运行**。在《大鲸鱼-深空放置》中，股市系统必须充当**全服大后期高净值玩家（Whales）的超级流动性蓄水池**与**系统交易印花税的黑洞级销毁口**，并深度绑定工业制造（造船、装备）、物流运输与矿物供需。

## 二、宏观经济学底座：四要素动态闭环

在 MMORPG 与长期放置模拟系统中，货币与物资遵循广义质量守恒与交易流通规律。

### 1. 费雪方程式（Fisher Equation）的游戏化改造

经典货币数量论：
$$M \cdot V = P \cdot Q$$

在放置与虚拟星海经济体中，各项参数的物理映射如下：
- **$M$（Money Supply，货币存量）**：全服活跃玩家与不活跃玩家持有的有效流通 ISK 总量。
- **$V$（Velocity of Money，货币流通速度）**：单位时间内 ISK 在玩家间（通过订单簿、合同、交易行）易手的平均次数。
- **$P$（Price Level，物价总水平）**：核心通货/大宗工业品（如三钛合金、同位素燃料、巡洋舰船体）的加权平均价格。
- **$Q$（Quantity of Goods，物资流转总量）**：在统计周期内被生产、交易并投入实际消费（组装、战损爆船、燃料消耗）的物品总件数。

> [!WARNING] 虚拟世界的致命陷阱
> 现实世界中，货币供应量 $M$ 由央行与商业银行信贷严格控制；但在游戏中，**每一个能开火的玩家都是一座印钞机**！如果 $M$ 随挂机时间无节制飙升，而物品消耗 $Q$ 无法线性同步放大，唯一的数学结果就是物价 $P$ 发生恶性飞涨，新手玩家将被彻底剥夺生存权。

### 2. 水龙头与排水池模型（Faucet-Sink-Stock）

```mermaid
flowchart LR
    subgraph Faucets [流入端 / 水龙头 (Inflow)]
        F1[NPC悬赏 Bounties]
        F2[星系任务 / 派遣奖励]
        F3[系统收购矿石/残骸]
        F4[成就 / 签到一次性注入]
    end

    subgraph Reservoirs [资产池 (Stock)]
        S1[(活跃流动 ISK)]
        S2[(非活跃休眠 ISK)]
        S3[(股市 / 长期质押资金)]
    end

    subgraph Sinks [流出端 / 排水池 (Outflow)]
        K1[系统交易印花税 / 挂单费]
        K2[舰船建造与蓝图授权费]
        K3[战损残骸永久损毁 50%]
        K4[工业精炼手续费 / 强化失败]
        K5[星系空间站主权维护费]
    end

    F1 -->|注入| S1
    F2 -->|注入| S1
    F3 -->|注入| S1
    F4 -->|注入| S1

    S1 <-->|交易/买卖| S3
    S1 -.长期不上线.-> S2

    S1 -->|永久销毁| K1
    S1 -->|永久销毁| K2
    S1 -->|装备化/爆船销毁| K3
    S1 -->|永久销毁| K4
    S1 -->|周期沉没| K5
```

- **净流量平衡方程**：
  $$\Delta Stock = \sum Inflow - \sum Outflow$$
  - 当 $\Delta Stock > 0$：全服资金蓄水池扩张。若无深坑沉淀，货币流通速度 $V$ 会急剧下降或压迫物价 $P$ 上行。
  - 理想稳态：$\Delta Stock \approx 0$ 或者使 $\Delta Stock$ 的增速严格与活跃玩家的真实承载力保持等比匹配。

## 三、货币层次与价值隔离墙（Currency Tiering）

单一货币是通胀失控的温床。必须划分货币的**使用自由度**与**流通边界**。

| 货币层次 | 资产形态 | 获取途径 | 流通性 | 核心职能 |
| :--- | :--- | :--- | :--- | :--- |
| **M0（基础硬通货）** | Liquid ISK（流动信用点） | 刷怪悬赏、玩家间贸易、矿产出售 | **完全自由流通**（订单簿、合同） | 全服价值尺度、市场计价单位、股市投资媒介 |
| **M1（定向绑定币）** | Bound ISK / LP（军团忠诚点） | 军团日常、阵营战派遣、离线挂机基础保底 | **不可流通**（角色强绑定，零转账） | 基础技能升级、基础弹药补给、绑定装配兑换 |
| **M2（超级价值锚）** | PLEX / 稀有核心 (Titan Core) | 官方活动、极高危星系首通、外部真实兑换 | **全服高度流动** | 终极抗通胀避险资产、月卡时间、定制涂装 |

### 价值隔离墙单向导通原则

```
┌────────────────────────────────────────────────────────┐
│               价值隔离墙流向（只进不出 / 单向闸门）    │
└────────────────────────────────────────────────────────┘
  【硬通货 Liquid ISK】
         │
         ▼  (兑换/消耗，不可逆转)
  【绑定点数 Bound Points / 技能点】
         │
         ▼  (投入角色属性，成为不可交易的沉没成本)
  【角色终生战力 / 科技树】
```

1. **不可反向兑现**：绑定币（Bound Points）绝不能以任何直接或间接机制兑换回 Liquid ISK，否则绑定币立即退化为通胀推手。
2. **生产材料消耗倾斜**：日常制造高阶装备，必须同时消耗 **Liquid ISK（系统税） + 绑定 LP + 物理矿物**，形成强耦合联动。

## 四、恶性通胀成因与动态治理组合拳

### 1. 恶性通胀的四大深层病理

1. **零边际生产成本（Zero Marginal Cost）**：
   现实中开采一吨铁矿需要消耗柴油、机械损耗和工人工资。虚拟游戏中，脚本多开一台挖矿机只需消耗服务器少许带宽和算力，产出无边际惩罚。
2. **消耗断层（Sink Discontinuity）**：
   设计初期规划了买船、买装备的消耗；但玩家达到 T3、T4 顶级配装后，**装备不再损毁**，导致老玩家只产出、零消耗，资产呈滚雪球式淤积。
3. **工作室与脚本冲击**：
   自动化脚本 7×24 小时不间断打金，瞬间打穿设计预估的人均每天 2 小时产出上限，造成单向注水海啸。
4. **无成本资金沉淀（Free Wealth Accumulation）**：
   现实中富豪持有现金面临通胀税，持有地产面临物业税与遗产税；游戏内玩家仓库堆积 100 亿 ISK 不需要支付任何管理保管费，造成资本固化。

### 2. 治理组合拳方案

#### 机制 A：动态产销负反馈机制（Dynamic Bounty System - DBS）

借鉴 EVE Online 的 DBS 机制，星系的悬赏产出效率与该星系的活跃度、击杀数、风险系数动态挂钩：

$$Multiplier_{system} = f(\text{RiskLevel}, \text{TotalKills}_{24h}) \times (1 - \alpha \cdot \frac{\text{ISK\_Minted}_{current}}{\text{Threshold}})$$

- **繁荣惩罚**：若某星系短时间内被大量挂机刷怪，该星系的基础悬赏系数自动从 150% 阶梯式熔断衰减至 30%，迫使生产力迁移或停滞。
- **储备银行介入**：悬赏金额的一部分（例如 30%）并不直接发放到钱包，而是注入星系“储备金库（ESS）”，挂机者必须坚守该金库一段时间或面临被其他玩家/海盗掠夺的风险。

#### 机制 B：阶梯式沉没深坑（Tiered Sinks）

- **无上限研发与优化**：引入类似“超空间矩阵过载调试”功能，消耗以指数递增的 ISK，换取微弱的递减收益（10 亿 ISK 换取 0.05% 的巡航速度提升），专为消耗全服前 1% 巨鲸玩家的流动性。
- **空间站与主权维护费（Upkeep）**：持有超级星系或军团空间站，每日需系统按固定比例扣除巨额维护费；账户余额不足则进入锚定衰减状态，直至解体。

#### 机制 C：严格的系统交易摩擦成本

- 任何市场订单簿（CLOB）挂单必须扣除 **不可退还的挂单手续费（Listing Fee）**（例如 1.5%）。
- 撮合成功后由卖家承担 **交易印花税（Sales Tax）**（例如 3.5%）。
- 频繁改单/撤单收取阶梯式惩罚费，彻底打击高频撤单洗盘行为。

## 五、《大鲸鱼-深空放置》项目深度映射

在 `packages/core/` 中，经济系统与现有的市场体系（`packages/core/src/market/`）紧密相关。我们需要明确股市（Stock Exchange）在项目宏观大盘中的角色。

### 1. 股市绝非独立小游戏：巨鲸流动性蓄水池

```
   ┌────────────────────────────────────────────────────────┐
   │        全服 ISK 宏观蓄水池与股市黑洞循环               │
   └────────────────────────────────────────────────────────┘

    【生产流水 (Inflow)】
      刷怪悬赏 ──┐
      行星开采 ──┼───> [ 活跃玩家钱包：Liquid ISK ]
      快递物流 ──┘              │
                                │ (资本积累，突破 1000 万 ISK)
                                ▼
                       [ 星海证券交易所 (Stock Market) ]
                       ┌─────────────────────────────┐
                       │ · 购买航天军团 / 巨头企业股票 │
                       │ · 资金深度锁定在流动性池子    │
                       └─────────────────────────────┘
                                │
                ┌───────────────┴───────────────┐
                ▼                               ▼
       【系统印花税黑洞】               【真实实体锚定分红】
       买卖双方各扣 2% 印花税           企业根据全服矿物消耗、
       ──> 直接在 GameState 中销毁!     战损补船需求向股东派发股息
```

1. **蓄水功能**：当核心玩家度过开荒期，日常维护开销远小于挂机悬赏产出时，必须有一个体量足够的投机与投资场所吸纳海量资金。股市提供了这种高风险、高流动性、可被系统收割的场所。
2. **通胀黑洞功能**：股票每次撮合成交，系统直接征收 **双向 2% 印花税**。该部分 ISK **永久脱离流通，不回流任何 NPC 钱包**，相当于中央银行公开市场操作的“抽水机”。

### 2. 实体经济与企业股价的物理锚定

虚假的人工随机构造走势（Random Walk）无法提供长期博弈深度。股票必须与游戏世界中的宏观实体指标挂钩：
- **采矿巨头企业（如 联合矿业）**：股价与全服矿石开采量、三钛合金当前价格正相关；若星区发生动乱、矿船频繁被击沉，该企业出矿量受损，财报利润下滑，股价下跌。
- **军工制造联合体（如 迦兰特重工）**：股价与全服军火装配、战损补船速度正相关。全服击杀数上升，造船需求井喷，军工企业派发高额股息。

### 3. 动态宏观经济监控器伪代码实现

在 `packages/core/src/economy/macroMonitor.ts` 中构建确定性监控状态机：

```typescript
/**
 * 确定性宏观经济调控状态机
 * 周期性（每世界日/固定 Tick）评估全服资金水位，并动态调整产销系数
 */

export interface MacroEconomyState {
  totalLiquidIsk: number;       // 全服流动 ISK 存量
  dailyMintedIsk: number;       // 过去 24h 新铸造 ISK (水龙头)
  dailyDestroyedIsk: number;    // 过去 24h 销毁 ISK (排水池)
  stockMarketLockedIsk: number; // 股市中沉淀锁定的资金
  targetInflationRate: number;  // 目标通胀率 (如 0.01 = 1%)
  currentTaxRate: number;       // 当前动态印花税率 (基准 0.02)
  bountyDampener: number;       // 全局悬赏衰减乘数 (1.0 = 100%)
}

export function evaluateMacroEconomy(
  state: MacroEconomyState,
  activePlayerCount: number
): void {
  const netInjection = state.dailyMintedIsk - state.dailyDestroyedIsk;
  const perCapitaIsk = state.totalLiquidIsk / Math.max(1, activePlayerCount);

  // 1. 监控水龙头与排水池净流量
  const burnRatio = state.dailyDestroyedIsk / Math.max(1, state.dailyMintedIsk);

  // 2. 若销毁率低于 70%（入大于出），启动阶梯式自我防御机制
  if (burnRatio < 0.70) {
    // 提升交易税与股市印花税，最高加成至 5%
    state.currentTaxRate = Math.min(0.05, state.currentTaxRate + 0.002);
    
    // 启动悬赏阻尼器，抑制源头放水 (最低降至 60%)
    state.bountyDampener = Math.max(0.60, state.bountyDampener - 0.05);
  } else if (burnRatio > 1.20) {
    // 若通缩过猛（销毁严重超出产出），释放流动性
    state.currentTaxRate = Math.max(0.01, state.currentTaxRate - 0.001);
    state.bountyDampener = Math.min(1.00, state.bountyDampener + 0.02);
  }

  // 3. 重置日度统计计数器
  state.dailyMintedIsk = 0;
  state.dailyDestroyedIsk = 0;
}
```
